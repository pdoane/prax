## Unicode data

Generated by `tools/gen/gen_unicode.py` and `tools/gen/gen_locale.py` from the Unicode Character Database 17.0.0
(https://www.unicode.org/Public/17.0.0/ucd/), Table 5 of UAX #31 (https://www.unicode.org/reports/tr31/tr31-45.html),
and CLDR (https://github.com/unicode-org/cldr), including CLDR's copies of the IANA Language Subtag Registry and the ISO
639-3 code tables of the ISO 639-3 Registration Authority, SIL International:

- `lib/unicode/src/unicode_data.cpp`, `unicode_bidi_data.cpp`, `unicode_line_break_data.cpp`,
  `unicode_normalization_data.cpp`, `unicode_idna_data.cpp`
- `lib/locale/include/pr/locale_common.h`, `locale_full.h`
- `lib/locale/src/locale_data.h`, `lib/locale/src/locale_data.cpp`

Copyright © 1991-2026 Unicode, Inc. Used under the Unicode License v3 (below).

## OpenType language system and script tags

`tools/gen/language/opentype.txt`, and the OpenType tags in the language tables above, record the OpenType language system
and script tag registries (https://learn.microsoft.com/en-us/typography/opentype/spec/languagetags and
https://learn.microsoft.com/en-us/typography/opentype/spec/scripttags), part of the OpenType specification, © Microsoft
Corporation.

## CSS and other W3C specifications

`suites/prax` quotes the CSS specifications of the CSS Working Group (https://drafts.csswg.org/) and the FX Task
Force (https://drafts.fxtf.org/). The tables that `tools/gen/gen_css.py`, `tools/gen/gen_dom.py` and `tools/gen/gen_webidl.py`
generate under `lib/css`, `lib/dom`, `lib/html` and `lib/webidl` derive from the definitions and IDL of W3C specifications, as webref extracts them.

document. https://www.w3.org/copyright/software-license-2023/. Used under the W3C Software and Document License
(below).

## WHATWG standards

`lib/html_entity/src/html_entity.cpp` is generated by `tools/gen/gen_html.py` from the HTML Standard's
`entities.json`; the other tables that `tools/gen/gen_html.py`, `tools/gen/gen_dom.py`, `tools/gen/gen_url.py` and
`tools/gen/gen_webidl.py` generate derive from the HTML Standard (https://html.spec.whatwg.org/), the DOM Standard
(https://dom.spec.whatwg.org/), the URL Standard (https://url.spec.whatwg.org/) and the other WHATWG standards whose IDL
webref extracts. The material is converted into C++ tables.

Copyright © WHATWG (Apple, Google, Mozilla, Microsoft). Licensed under the Creative Commons Attribution 4.0
International License, https://creativecommons.org/licenses/by/4.0/.

## RFC 7932 (Brotli)

`lib/compress/backends/builtin/src/brotli_tables.cpp` and `brotli_tables.h` are generated by `tools/gen/gen_brotli.py`
from RFC 7932 (https://www.rfc-editor.org/rfc/rfc7932): its static dictionary (appendix A), its word transformations
(appendix B) and its context lookup tables (section 7.1).

Copyright (c) 2016 IETF Trust and the persons identified as authors of the code (Jyrki Alakuijala, Zoltan Szabadka).
All rights reserved. Used under the BSD License of the IETF Trust Legal Provisions (below).

## Nerd Fonts

The `NerdFontSymbols` font bundle (`lib/font_bundle`) and the tests that draw its icons rely on the private-use code
points that Nerd Fonts (https://github.com/ryanoasis/nerd-fonts) assigns to its icons. The bundle's font, Symbols Nerd
Font Mono, is fetched from Nerd Fonts' release v3.5.1 and is not part of this repository.

Copyright (c) 2014 Ryan L McIntyre. Used under the MIT License (below). The font's glyphs keep the licenses of the icon
sets that they come from, as the release's README lists them: Codicons and Font Awesome under the Creative Commons

Octicons, Seti UI, Hack's extra glyphs, Powerline Symbols, Powerline Extra Symbols and the IEC power symbols under the
MIT License.
