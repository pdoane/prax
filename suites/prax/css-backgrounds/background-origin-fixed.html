background-origin: none with fixed

Each figure is a frame, a document of its own, 200 by 100. CSS Backgrounds 4 §2.9

No effect with fixed

If the 'background-attachment' value for this layer is fixed, then this property has no effect: in this case the background positioning area is the initial containing block. Each frame's body has no margin, and holds a box as before, fixed, with an orange 30px square.
