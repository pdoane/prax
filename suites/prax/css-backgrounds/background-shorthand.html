CSS Backgrounds 4 · 2.12 Backgrounds Shorthand: the background property

The background shorthand: size, boxes and layers

The number of comma-separated items defines the number of background image layers. CSS Backgrounds 4 §2.12 Each box has a 10px dashed border, 10px of padding and a content box 60 by 20.

Each layer reset, then set

For each layer, the shorthand, whose color is in the last layer, sets each longhand to that property's initial value, then assigns any explicit values specified for this layer in the declaration.

One box, or two

If one <visual-box> value is present, then it sets both 'background-origin' and 'background-clip' to that value. If two <visual-box> values are present, then the first sets 'background-origin' and the second 'background-clip'.
