CSS Backgrounds 4 · 2.11 Background Image Layers: the background-tbd shorthand property

background-tbd: the layers without the color

The 'background-tbd' property is a shorthand property that sets all the same properties as the 'background' shorthand except for 'background-color', allowing authors to easily declare and position background images while letting 'background-color' cascade through independently.
