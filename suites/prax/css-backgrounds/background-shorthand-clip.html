The background shorthand: values only background-clip takes

If one <visual-box> value is present, then it sets both 'background-origin' and 'background-clip' to that value. However, if a value is set that is only valid in 'background-clip', then it sets 'background-clip' to that value and 'background-origin' to border-box. CSS Backgrounds 4 §2.12
