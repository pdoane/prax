CSS Backgrounds 4 · 2.9 Positioning Area: the background-origin property

background-origin: the positioning area

This property determines the background positioning area: the area within which any background images are positioned. CSS Backgrounds 4 §2.9 Each box has a 10px dashed border, 10px of padding and a content box 60 by 20, and an orange 20px square drawn once.

Padding, border or content box

Positioned in one area, clipped to another

A note: If 'background-clip' is padding-box, 'background-origin' is border-box, 'background-position' is top left (the initial value), and the element has a non-zero border, then the top and left edges of the background image will be clipped.
