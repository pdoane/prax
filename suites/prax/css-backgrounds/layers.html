CSS Backgrounds 4 · 3 Layering Multiple Background Images

Layers of background images

The number of layers is determined by the number of comma-separated values in the 'background-image' property. CSS Backgrounds 4 §3 Each dashed box is 140 by 60.

The first image is closest to the user

The first image in the list is the layer closest to the user, the next one is painted behind the first, and so on. The background color, if present, is painted below all of the other layers. A note: a border image is painted on top of the background layers.

The lists are matched up from the first value

excess values at the end are not used. If a property doesn't have enough comma-separated values to match the number of layers, the UA must calculate its used value by repeating the list of values until there are enough. Three images: a blue, an orange and a green 20px square.
