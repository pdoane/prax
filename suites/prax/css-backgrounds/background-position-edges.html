CSS Backgrounds 4 · 2.7 Background Positioning Shorthand: the background-position shorthand property

background-position: offsets from any edge

If three or four values are given, then each <length-percentage> represents an offset and must be preceded by a keyword, which specifies from which edge the offset is given. CSS Backgrounds 4 §2.7 Each dashed box is 140 by 60, with a blue 20px square drawn once.

Four values, or three

If three values are given, the missing offset is assumed to be zero.

Percentages, center, and offsets outward

Positive values represent an offset inward from the edge of the background positioning area. Negative values represent an offset outward from the edge of the background positioning area.
