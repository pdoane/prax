CSS Backgrounds 4 · 2.2 Image Sources: the background-image property

background-image: layers that draw nothing

A value of none counts as a background image layer but draws nothing. An image that is empty (zero width or zero height), that fails to download, or that cannot be displayed (e.g., because it is not in a supported image format) likewise counts as a layer but draws nothing. CSS Backgrounds 4 §2.2
