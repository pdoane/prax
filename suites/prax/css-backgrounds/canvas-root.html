CSS Backgrounds 4 · 4.1 The Canvas Background and the Root Element

The canvas background: sized and placed by the root

The background of the root element becomes the canvas background and its background painting area extends to cover the entire canvas. However, any images are sized and positioned relative to the root element’s box as if they were painted for that element alone. CSS Backgrounds 4 §4.1 Each figure is a frame, 200 by 100, whose root element has margin: 20px; height: 60px, so its box is 160 by 60, and a dashed outline. Its body has no margin.
