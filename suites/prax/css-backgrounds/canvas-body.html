The canvas background: from the body

if the computed value of 'background-image' on the root element is none and its 'background-color' is transparent, user agents must instead propagate the computed values of the background properties from that element's first HTML BODY or XHTML body child element. The used values of that BODY element's background properties are their initial values, and the propagated values are treated as if they were specified on the root element.
