CSS Backgrounds 4 · 2.5 Affixing Images: the background-attachment property, fixed

background-attachment: fixed

fixed: The background is fixed with regard to the viewport. CSS Backgrounds 4 §2.5 Each figure is a frame, a document of its own, 200 by 100.

fixed does not move with a scroll container

A note: There is only one viewport per view. Even if an box is a scroll container, a fixed background doesn't move with the box. The frame holds one box as big as itself, with the same eight lines, scrolled 40px.

Seen only in the painting area

Even if the image is fixed, it is still only visible when it is in the background painting area of the box or otherwise unclipped. Thus, unless the image is tiled, it may be invisible. The frame holds a dashed box 80 by 40, 60px from the left and 40px from the top, with an orange image fixed at 0 0.
