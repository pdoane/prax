Bullets and symbols in content

A <symbolic-glyph> in content is The predefined symbolic counter style, without its 'prefix' or 'suffix', as drawn by the UA for 'list-style-type'. CSS Generated Content 3 §2.9

disc, circle and square

Each is drawn as the list marker of that style is, with no counter and no suffix space.

A disclosure marker without a counter

A disclosure widget can point its marker at the widget’s state without involving a counter: summary::marker { content: disclosure-closed; }, and disclosure-open when the details is open. Each summary has list-style-type: none, so only content gives it a marker.
