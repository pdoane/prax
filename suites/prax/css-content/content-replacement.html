The content property: replacing a box

The 'content' property specifies the box’s contents for stylistic purposes. It can replace the box with an image (turning it into a replaced element), or provide it with arbitrary inline-level content (text and images). CSS Generated Content 3 §1

An image makes the element a replaced element

Makes the element or pseudo-element a replaced element, filled with the specified <image>. Its normal contents are suppressed and do not generate boxes. Each div holds the text "hidden text".

An image on ::before

The value makes ::before a replaced element too, sized by width and height.
