CSS Generated Content 3 · 1.2 Alternative Text for Accessibility

Alternative text is not drawn

The 'content' property thus accepts alternative text to be specified after a slash ('/') after the last <content-list>. If such alternative text is provided, it must be used for speech output instead. What is drawn is the “visual content” before the slash. CSS Generated Content 3 §1.2

The visual content is drawn, the alternative text is not

The alternative text is supplied to the accessibility tree for rendering to speech, braille, etc. instead of the “visual content” provided before the slash. §1

Counters and empty alternative text

<alt-text> = [ <string> | <counter> | <attr()> ]+; empty alternative text lets purely decorative text to be elided in speech output.
