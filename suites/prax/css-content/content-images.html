CSS Generated Content 3 · 2.2 2D Images: <image> values

Images in a content list

An <image> among other values Represents an anonymous inline replaced element filled with the specified <image>. CSS Generated Content 3 §2.2

Inline replaced elements on the line

Each image sits on the baseline at its natural size, as an img would.

An image that cannot be displayed

If an <image> represents an invalid image, the user agent must (consistently) do one of the following: “Skip” the <image>, generating nothing for it. Display some indication that the image can't be displayed in place of the <image>, such as a “broken image” icon.
