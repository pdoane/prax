CSS Generated Content 3 · 2.4.1 Quotation Mark System: the quotes property

The quotes property: the parent's language

This property specifies the quotation mark system for the element, defining how the 'content' property’s 'open-quote' and 'close-quote' values behave. CSS Generated Content 3 §2.4.1

auto: chosen by the parent's language

A typographically appropriate quotation mark system is automatically chosen by the UA based on the content language of the parent (or, if there is no parent, of the element itself). Each stage is lang=en, with a q in a French span.

A language that is kept as it inherits

bikeshed-this: If the inherited value is 'auto', computes to the content language of the parent, which behaves like 'auto' as resolved by that content language. Otherwise, computes to the inherited value. The name is a placeholder (csswg-drafts#5478); what it does is defined.
