CSS Generated Content 3 · 1 Inserting and Replacing Content: the content property

The content property on elements

Of the values that are not an image, on an element only normal and none mean anything, and both leave its contents drawn. CSS Generated Content 3 §1

A content list on an element; none on an element

On regular elements, this value has no effect. For none: On regular elements, this behaves as 'normal'. In neither case does it prevent any pseudo-elements which have this element or pseudo-element as an originating element from being generated.
