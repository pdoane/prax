Strings and attr(): text like any other

A <string> Represents an anonymous inline box filled with the specified text. CSS Generated Content 3 §2.1

White space in strings

White space in the string is handled the same as in literal text, and controlled by the properties in [CSS-TEXT-3] and elsewhere. In particular, white space character can collapse, even across multiple strings. The stage's text is set in .pr-measure, so each character and space is 10px wide.

attr(): the attribute's value as a string

The attr() functional notation represents the string stored as the specified attribute’s value.
