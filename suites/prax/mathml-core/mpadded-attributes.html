MathML Core · 3.3.6.1 Inner box and requested parameters

mpadded: the requested size

If the height attribute is absent, invalid or a percentage then the requested height is the inner line-ascent. Otherwise the requested height is the resolved value of the height attribute, clamping negative values to 0. The depth is the same, and the requested width is the resolved value of the width property. MathML Core §3.3.6.1 Each mpadded holds 1/(1 + x²) at 30px and is outlined; dashed lines mark the heights its attributes give.
