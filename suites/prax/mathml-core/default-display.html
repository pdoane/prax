MathML Core · 3.1.1 Box Model

The display of MathML elements

For Tabular MathML elements mtable, mtr, mtd it is respectively equal to inline-table, table-row and table-cell. For all but the first children of the maction and semantics elements, it is equal to none. For all the other MathML elements it is equal to block math. MathML Core §3.1.1

Tables, and hidden children
