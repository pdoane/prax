MathML Core · 3.2.2 Identifier <mi>

mi: identifiers, italic when alone

The user agent stylesheet must contain the following property in order to implement automatic italic via the text-transform value mi { text-transform: math-auto; }. The mathvariant attribute, if present, must be an ASCII case-insensitive match of normal. In that case, the user agent is expected to treat the attribute as a presentational hint setting the element's text-transform property to none. MathML Core §3.2.2
