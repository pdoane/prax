mathcolor, mathbackground and mathsize

The mathcolor and mathbackground attributes, if present, must have a value that is a <color>. In that case, the user agent is expected to treat these attributes as a presentational hint setting the element's color and background-color properties The mathsize attribute […] as a presentational hint setting the element's font-size property to the corresponding value.
