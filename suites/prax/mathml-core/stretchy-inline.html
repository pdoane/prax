MathML Core · 3.4.2.2 Algorithm for stretching operators along the inline axis

Stretching along the inline axis

Calculate the target size T to the maximum inline size of the margin boxes of child boxes that have been laid out in the previous step. Lay out or relayout all the elements of LToStretch with inline stretch size constraint T.
