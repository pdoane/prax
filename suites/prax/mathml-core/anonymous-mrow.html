MathML Core · 3.1.3 Anonymous <mrow> boxes

Anonymous mrow boxes

If a MathML element generates an anonymous <mrow> box then it wraps its children in an anonymous <mrow> box. the <msqrt> element adds proper spacing around its <mo>+</mo> child while the <mtd> element stretches its <mo> children vertically. MathML Core §3.1.3
