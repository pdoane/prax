MathML Core · 4.2 The math-auto transform

text-transform: math-auto

On text nodes containing a single character, if the computed value is math-auto and the character is present in the "Original" column of Italic mappings then it is converted to the corresponding character from the "italic" column. MathML Core §4.2 The font is PR Noto Sans Math, which has the italic forms.

On any element

A text node, not an element
