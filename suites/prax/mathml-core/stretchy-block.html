MathML Core · 3.3.1.1 Algorithm for stretching operators along the block axis

Stretching along the block axis

Calculate the unconstrained target sizes Uascent and Udescent as respectively the maximum ink ascent and maximum ink descent of the margin boxes of in-flow children that have been laid out in the previous step. MathML Core §3.3.1.1 A symmetric operator covers as much above the axis as below; its glyph is the first variant that covers that. MathML Core §3.2.4.3 The formulas are set in PR Noto Sans Math, whose MATH constants shared/fonts.css lists in units of a 1000-unit em; a dashed blue line marks the height that the caption computes from them.
