MathML Core · 4.1 The display: block math and display: inline math value

display: block math and inline math

For elements that are not MathML elements, if the specified value of display is block math or inline math then the computed value is block flow and inline flow respectively. For the mtable element the computed value is block table and inline table respectively. Unknown MathML elements behave the same as the mrow element. MathML Core §4.1
