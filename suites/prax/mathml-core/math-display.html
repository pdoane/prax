MathML Core · 2.1.1 The Top-Level <math> Element

The math element: inline and block

If the display attribute is absent or has an invalid value, the User Agent stylesheet treats it the same as inline. if the computed display property is equal to block math then that math content box is rendered horizontally centered within the content box. MathML Core §2.1.1 Each math element is tinted blue, and holds x over 2.

Inline, in the line of text

Block, on a line of its own and centered

The math style that each gives

Inline math is math-style: compact and block math normal.
