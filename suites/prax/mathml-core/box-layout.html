MathML Core · 3.1.2 Layout Algorithms

Padding, border and margin on a numerator

The baselines of the padding box are the same as the one of the content box. if the line-over border is positive then the ink-over baseline is set to the line-over edge of the border box and if the line-under border is positive then the ink-under baseline is set to the line-under edge of the border box. The baselines of the margin box are the same as the one of the border box. MathML Core §3.1.2 The formulas are set in PR Noto Sans Math, whose MATH constants shared/fonts.css lists in units of a 1000-unit em; a dashed blue line marks the height that the caption computes from them. Each fraction is ½ in display style at 50px; the numerator 1 is tinted. FractionNumeratorDisplayStyleShiftUp, 704, puts its baseline at 35.2px, the line; the gap rule, FractionNumDisplayStyleGapMin, 150, 7.5px over the bar, decides only if the numerator's ink reaches lower.

Only a border counts as ink
