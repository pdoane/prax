MathML Core · 3.5.3 Entry in Table or Matrix <mtd>

mtd: cells

The mtd is laid out as a table-cell with content centered in the cell and a default padding. mtd { text-align: center; padding: 0.5ex 0.4em; } The columnspan (respectively rowspan) attribute has the same syntax and semantics as the colspan (respectively rowspan) attribute on the <td> element The <mtd> element generates an anonymous <mrow> box.
