MathML Core · 3.3.3.3 Root with index

mroot: placing the index

The inline offset of the index is AdjustedRadicalKernBeforeDegree. AdjustedRadicalKernAfterDegree is max(−inline size of the index's margin box, RadicalKernAfterDegree). The alphabetic baseline of the index is shifted away from the line-under edge by a distance of RadicalDegreeBottomRaisePercent × the block size of B + the line-descent of the index's margin box. MathML Core §3.3.3.3 The formulas are set in PR Noto Sans Math, whose MATH constants shared/fonts.css lists in units of a 1000-unit em; a dashed blue line marks the height that the caption computes from them.
