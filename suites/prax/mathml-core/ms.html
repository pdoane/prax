MathML Core · 3.2.6 String Literal <ms>

ms: string literals

Its layout algorithm is the same as the mtext element. In MathML3, it was possible to use the lquote and rquote attributes to respectively specify the strings to use as opening and closing quotes. These are no longer supported and the quotes must instead be specified as part of the text of the <ms> element. MathML Core §3.2.6
