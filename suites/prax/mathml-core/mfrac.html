MathML Core · 3.3.2 Fractions <mfrac>

mfrac: fractions

If the attribute is absent or has an invalid value, FractionRuleThickness is used as the default value. A percentage is interpreted relative to that default value. A negative value is interpreted as 0. The <mfrac> element sets displaystyle to false, or if it was already false increments scriptlevel by 1, within its children. MathML Core §3.3.2
