MathML Core · 3.4.2.4 Base with overscript

mover: accents

OverShift is AccentBaseHeight minus the line-ascent of the mover base's margin box if this difference is nonnegative. Or 0 otherwise. The alphabetic baseline of the mover overscript is shifted away from the alphabetic baseline and towards the line-over by a distance equal to the ink line-ascent of the base + OverShift. MathML Core §3.4.2.4 The formulas are set in PR Noto Sans Math, whose MATH constants shared/fonts.css lists in units of a 1000-unit em; a dashed blue line marks the height that the caption computes from them.
