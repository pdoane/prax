dir: right-to-left formulas

The dir attribute, if present, must be an ASCII case-insensitive match to ltr or rtl. In that case, the user agent is expected to treat the attribute as a presentational hint setting the element's direction property to the corresponding value. MathML Core §2.1.4 Each number is tinted blue.
