MathML Core · 2.2.4 Text layout

Line spacing from the typographic metrics

Because math fonts generally contain very tall glyphs such as big integrals, using typographic metrics is important to avoid excessive line spacing of text. As a consequence, user agents must take into account the USE_TYPO_METRICS flag from the OS/2 table when performing text layout. MathML Core §2.2.4 PR Noto Sans Math sets the flag; its typographic ascent and descent are 1069 and 423 units, a line of 1.492em, and its Windows ones 3105 and 2550, 5.655em.
