MathML Core · 2.1.1 The Top-Level <math> Element

The math element resets what it inherits

the user agent stylesheet should set the font-family to the math value on the <math> element instead of inheriting it. several CSS properties that can be set on a parent container such as font-style, font-weight, direction or text-indent etc are not expected to apply to the math formula and so the user agent stylesheet has rules to reset them by default.
