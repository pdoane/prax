MathML Core · 3.3.3 Radicals <msqrt>, <mroot>

msqrt and mroot

The msqrt element is used for square roots, while the mroot element is used to draw radicals with indices, e.g. a cube root. The <mroot> element increments scriptlevel by 2, and sets displaystyle to "false" in all but its first child. If the <mroot> has less or more than two in-flow children, its layout algorithm is the same as the mrow element. MathML Core §3.3.3
