MathML Core · 3.4.2.1 Children of <munder>, <mover>, <munderover>

movablelimits, and the wrong number of children

If the <munder>, <mover> or <munderover> elements have a computed math-style property equal to compact and their base is an embellished operator with the movablelimits property, then their layout algorithms are respectively the same as the ones described for <msub>, <msup> and <msubsup> MathML Core §3.4.2.1
