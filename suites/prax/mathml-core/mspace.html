MathML Core · 3.2.5 Space <mspace>

mspace: a space of a given size

The min-content inline size, max-content inline size and inline size of the math content are equal to the resolved value of the width property. The block size of the math content is equal to the resolved value of the height property. The line-ascent of the math content is equal to the requested line-ascent, the height attribute's value.
