MathML Core · 2.2.3 DOM and JavaScript

Attributes changed by script

User agents supporting Web application APIs must ensure that they keep the visual rendering of MathML synchronized with the DOM tree, in particular perform necessary updates when MathML attributes are modified dynamically. MathML Core §2.2.3 Each formula is parsed one way, and the page's script changes it when it loads; each caption describes the formula after the change.
