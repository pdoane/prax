MathML Core · 3.2.4.1 Embellished operators

Embellished operators

A MathML Core element is an embellished operator if it is An mo element; a scripted element or an mfrac, whose first in-flow child exists and is an embellished operator; a grouping element or mpadded, whose in-flow children consist (in any order) of one embellished operator and zero or more space-like elements.
