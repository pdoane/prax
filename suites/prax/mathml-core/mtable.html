MathML Core · 3.5.1 Table or Matrix <mtable>

mtable: a table centered on the axis

The mtable is laid out as an inline-table and sets displaystyle to false. The center of the table is aligned with the math axis. MathML Core §3.5.1 The formulas are set in PR Noto Sans Math, whose MATH constants shared/fonts.css lists in units of a 1000-unit em; a dashed blue line marks the height that the caption computes from them.
