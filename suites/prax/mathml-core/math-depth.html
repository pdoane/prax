MathML Core · 4.5 The math-depth property

math-depth and font-size: math

If the specified value of font-size is math then the computed value of font-size is obtained by multiplying the inherited value of font-size by a nonzero scale factor: If A ≤ 0 and B ≥ 2 then multiply S by scriptScriptPercentScaleDown and decrement E by 2. Otherwise if A = 1 then multiply S by scriptScriptPercentScaleDown / scriptPercentScaleDown and decrement E by 1. Otherwise if B = 1 then multiply S by scriptPercentScaleDown and decrement E by 1. Multiply S by CE. MathML Core §4.5 The formulas are at 50px in PR Noto Sans Math, whose ScriptPercentScaleDown is 60 and ScriptScriptPercentScaleDown 50; C is 0.71.
