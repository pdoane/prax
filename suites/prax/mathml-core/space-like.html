MathML Core · 3.2.5.1 Definition of space-like elements

Space-like elements and operator forms

A MathML Core element is a space-like element if it is an mtext or mspace; or a grouping element or mpadded all of whose in-flow children are space-like. Note that an mphantom is not automatically defined to be space-like, unless its content is space-like. MathML Core §3.2.5.1 An operator's form counts a row's children without its space-like ones. Tokens are tinted, operators orange.
