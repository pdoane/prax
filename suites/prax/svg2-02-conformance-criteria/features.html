SVG 2 · 2.2.1 Features

Processing modes and their features

The features that can be enabled or disabled depending on the processing mode are as follows: declarative animation, references to external resources, script execution and interaction. SVG 2 §2.2.1 Each stage shows support/features.svg, four squares in dashed outlines: a script's, orange until the script turns it blue; an animation's, a set from 0s that turns it blue; the suite's flag, an external file; and a blue data URL, which no mode disables.

Dynamic interactive, and secure animated

Dynamic interactive mode imposes no restrictions on any feature of the SVG language. §2.2.2 Secure animated mode: script execution no, external references no, declarative animation yes. §2.2.4 When declarative animations are disabled in an SVG document, any animation elements or CSS Transitions or Animations must not be applied or run.
