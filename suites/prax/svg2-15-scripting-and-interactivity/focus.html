SVG 2 · 15.7 Focus

Focus in SVG

SVG uses the same focus model as HTML, modified for SVG as described in this section. SVG 2 §15.7 Each focusable shape is stroked dark blue while it has the focus. The logs list the focus and click events that reach the stage.

Focusable, in one order with HTML

Focusable are any directly rendered element with a valid integer ‘tabindex’ attribute and all ‘a’ elements that are valid links. For documents that contain a mix of inline HTML and SVG, focus is handled for the document as a whole (with a combined sequential focus order). An HTML button #html, then an SVG with #rect (tabindex="0"), a link #link, and #plain, with neither.
