SVG 2 · 15.7 Focus

Focus: not when not rendered

SVG uses the same focus model as HTML, modified for SVG as described in this section. SVG 2 §15.7 Each focusable shape is stroked dark blue while it has the focus. The logs list the focus and click events that reach the stage.

Not when not rendered

A non-rendered element can never receive focus, regardless of the value of the ‘tabindex’ attribute. If a script programmatically assigns focus to a non-rendered or otherwise un-focusable element, the focusing call is aborted. Each button calls focus() on a rect with tabindex="0": #shown, and #gone with display="none", outlined dashed.
