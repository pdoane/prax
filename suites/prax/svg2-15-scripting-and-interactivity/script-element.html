SVG 2 · 15.9 The ‘script’ element

The script element

A ‘script’ element is equivalent to the ‘script’ element in HTML and thus is the place for scripts (e.g., ECMAScript). Any functions defined within any ‘script’ element have a "global" scope across the entire current document. Run, inline or by href, never rendered

A ‘script’ element must be processed as an HTML script element is, following prepare the script element, with its ‘href’ attribute in place of the HTML src attribute. The script's text content is never directly rendered.
