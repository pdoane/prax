SVG 2 · 15.4 Pointer events

The target of a pointer event

The target element is the topmost graphics element whose relevant graphical content is under the pointer at the time of the event. When an element is not displayed (i.e., when the display property on that element or one of its ancestors has a value of none), that element cannot be the target of pointer events.
