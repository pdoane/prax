SVG 2 · 15.5.2 Event processing

Processing a user interface event

The algorithm and order for processing user interface events for a given target element, after dispatching the DOM event, is as follows. SVG 2 §15.5.2

preventDefault stops the rest

If an event handler registered on this element invokes the preventDefault() DOM method, then no further processing for this element is performed; otherwise, for a hyperlink, if the hyperlink traversal changes the context of the content, no further processing for this element is performed.
