SVG 2 · 15.8.1 Animation event attributes

Animation event attributes

‘onbegin’, ‘onend’ and ‘onrepeat’ Specifies some script to execute when "bubbling" or "at target" phase listeners for the corresponding event are fired on the element the attribute is specified on. SVG 2 §15.8.1

begin, repeat, end

A square slides right by an animate that begins on a click on it, repeats twice, a second each, and ends. Its attributes write each event into the log: onbegin, onrepeat, onend. The square is orange while it runs, by a set that begins and ends with it.
