SVG 2 · 15.2 Supported events

load and error on external elements

The load event is dispatched only to structurally external elements and to the Window, when the corresponding external resources have finished loading. The load event and the error event on structurally external elements are mutually exclusive, only one of these events must be dispatched when processing the element in question. SVG 2 §15.2
