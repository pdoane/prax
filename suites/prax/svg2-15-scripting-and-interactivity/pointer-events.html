SVG 2 · 15.6 The ‘pointer-events’ property

pointer-events: fill and stroke

The ‘pointer-events’ property specifies under what circumstances a given element can be the target element for a pointer event. SVG 2 §15.6 Each circle has radius 20 and a stroke 10 wide, orange, and dark blue while it is under the pointer: hover its interior, then its stroke. Over a part that does not take the pointer, the stroke stays orange.

Painted, fill, stroke, none

visiblePainted, which auto is: the pointer is over a painted area if it is over the interior (i.e., fill) of the element and the ‘fill’ property has an actual value other than none or it is over the perimeter (i.e., stroke) of the element and the ‘stroke’ property is set to a value other than none. The first two circles have fill="none".

visibility, and the visible values

visibleFill, visibleStroke and visible need the visibility property is set to visible; painted, fill, stroke and all do not. Each circle here is visibility="hidden", outlined dashed; the log shows what takes a click.
