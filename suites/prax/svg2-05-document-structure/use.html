SVG 2 · 5.5 The ‘use’ element

The use element

The ‘use’ element references another element, a copy of which is rendered in place of the ‘use’ in the document. SVG 2 §5.5 Each stage is an SVG 160 by 60.

A copy of an element, or of a whole document

The referenced element may be a container element, in which case a copy of the complete SVG document subtree rooted at that element is used. The ‘use’ element can reference an entire SVG document by specifying an ‘href’ value without a fragment. The group is a blue square 40 by 40 and an orange circle beside it.

Not rendered: unresolved, invalid or circular

A ‘use’ that has an unresolved or invalid URL reference is not rendered. If the referenced element is a (shadow-including) ancestor of the ‘use’ element, then this is an invalid circular reference and the ‘use’ element is in error.
