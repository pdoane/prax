SVG 2 · 5.6.1 Conditional processing overview

Conditional processing

When an element is excluded because of conditional processing, it is treated as if it had a used value of none for the display property. SVG 2 §5.6.1 Each stage is an SVG 160 by 60. An empty requiredExtensions is false, so excludes its element.

Not displayed, but referenced

conditional processing attributes only affect the direct rendering of elements and do not prevent elements from being successfully referenced by other elements (such as via a ‘use’).

Never-rendered elements and their content

conditional processing will have no effect on never-rendered elements; conditional processing of child content of a never-rendered container element (e.g., a ‘clipPath’ or a ‘mask’) will affect whether that child content contributes to the graphical effect.
