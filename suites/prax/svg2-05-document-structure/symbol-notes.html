SVG 2 · 5.4.2 Notes on symbols

symbol: never rendered, clipped when used

‘symbol’ elements must never be rendered directly; their only usage is as something that can be referenced using the ‘use’ element. SVG 2 §5.4.2 Each stage is an SVG 160 by 60.

display: none, and inline for the instance

The user agent must set the display property on the ‘symbol’ element to none, as part of the user agent style sheet, and this declaration must have importance over any other CSS rule or presentation attribute. The generated instance of a ‘symbol’ that is the direct referenced element of a ‘use’ element must always have a computed value of inline for the display property.

overflow: hidden

Unless the overflow property is overridden, any graphics within the symbol which goes outside of the symbol's SVG viewport will be clipped. A circle of radius 30 in a symbol used 40 by 40 at 60, 10, outlined.
