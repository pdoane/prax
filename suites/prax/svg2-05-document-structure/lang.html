SVG 2 · 5.11.3 The ‘lang’ and ‘xml:lang’ attributes

The lang and xml:lang attributes

The ‘lang’ attribute (in no namespace) specifies the primary language for the element's contents and for any of the element's attributes that contain text. SVG 2 §5.11.3 Each stage is 160 by 60. A style sheet colors text by :lang(): French orange, German green, other text dark blue.

Set, inherited, and which wins

If these attributes are omitted from an element, then the language of this element is the same as the language of its parent element, if any. If both the ‘lang’ attribute in no namespace and the ‘lang’ attribute in the XML namespace are set on an element, user agents must use the ‘lang’ attribute in the XML namespace.
