SVG 2 · 5.7 The ‘desc’ and ‘title’ elements

The desc and title elements

‘desc’ and ‘title’ elements are not visually rendered as part of the graphics. The display value for the ‘desc’ and ‘title’ elements must always be set to none by the user agent style sheet, and this declaration must have importance over any other CSS rule or presentation attribute. A tooltip

existing user agents commonly render ‘title’ elements as a tooltip on hovering the parent element. It is a common practice, not a requirement.
