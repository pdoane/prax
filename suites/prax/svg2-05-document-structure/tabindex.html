SVG 2 · 5.11.5 The ‘tabindex’ attribute

The tabindex attribute

This content attribute allows authors to control whether an element is focusable, whether it is supposed to be reachable using sequential focus navigation, and what is to be the relative order of the element for the purposes of sequential focus navigation. SVG 2 §5.11.5

Focusable, in sequence or not, and in order

Four rects, each light blue and dark blue while it has the focus: #a tabindex="0", #b tabindex="-1", #c none, #d tabindex="1". The log lists the focus events that reach the stage.
