SVG 2 · 5.5.5 Event handling in use-element shadow trees

use: events in the shadow tree

Any event listeners defined on an element in the referenced graphics must also listen for the same event, at the same capture phase, on each instance of that element in a use-element shadow tree. SVG 2 §5.5.5

Listeners copied, targets retargeted

The event retargeting algorithm ensures that from the perspective of event listeners on the ‘use’ element or its ancestors, all events targetted to element instances in the shadow tree instead have a target of the ‘use’ element itself. The page's script listens for clicks on the original rect, logging rect with its target; the log shows clicks as the stage sees them.
