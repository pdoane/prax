SVG 2 · 5.3.2 The ‘defs’ element

The defs element

Elements that are descendants of a ‘defs’ are not rendered directly; the display value for the ‘defs’ element must always be set to none by the user agent style sheet, and this declaration must have importance over any other CSS rule or presentation attribute. SVG 2 §5.3.2 Each stage is an SVG 160 by 60.

Not rendered, and referenced

the descendants of a ‘defs’ are always present in the source tree and thus can always be referenced by other elements.
