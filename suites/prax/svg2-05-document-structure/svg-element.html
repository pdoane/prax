SVG 2 · 5.1.4 The ‘svg’ element

The svg element: position and size

The ‘x’ and ‘y’ attributes specify the top-left corner of the rectangular region into which an embedded ‘svg’ element is placed. On an outermost svg element, these attributes have no effect. SVG 2 §5.1.4 Each svg holds a purple rect as large as it.

x and y

Each stage is 160 by 60.

width and height

For outermost svg elements, the width and height attributes specify the intrinsic size of the SVG document fragment. For embedded ‘svg’ elements, they specify the size of the rectangular region into which the ‘svg’ element is placed. In either case, a computed style of auto is treated equivalent to 100%.
