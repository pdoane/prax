SVG 2 · 5.6.5 The ‘systemLanguage’ attribute

The systemLanguage attribute

For each tag in tags, for each user-lang in user languages: If tag is an ASCII case-insensitive match for user-lang, return true. If user-lang is an ASCII case-insensitive prefix of tag and the code point in tag immediately following the prefix is U+002D HYPHEN-MINUS (-), return true.
