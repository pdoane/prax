SVG 2 · 5.4 The ‘symbol’ element

symbol: x, y, width and height

A ‘symbol’ establishes a nested coordinate system for the graphics it contains. SVG 2 §5.4 Each stage is an SVG 160 by 60. Each symbol has viewBox="0 0 20 10" filled blue with an orange dot in its middle.

Geometry on the symbol

The ‘x’, ‘y’, width, and height geometry properties have the same effect as on an ‘svg’ element, when the ‘symbol’ is instantiated by a ‘use’ element. The working group since resolved that The CSS width/height properties are honored as presentation attributes for rect, image, foreignObject and outer-SVG elements and ignored by all other elements with the width/height attributes (svgwg#1057, which the text does not yet follow); it leaves x and y as the text gives them.
