SVG 2 · 5.9 HTML metadata elements

HTML metadata elements in SVG

For user agents that support HTML, the following HTML elements (in the HTML namespace) must be supported in SVG documents: the base element the link element the meta element the style element the script element SVG 2 §5.9 Each stage is an iframe of an SVG document 160 by 60.

base, and style

Note that the base element will affect all URL values in the document. In this way, target-fragment only references to elements in the same document remain valid, regardless of any changes to the document base URL.
