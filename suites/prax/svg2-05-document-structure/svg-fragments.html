SVG 2 · 5.1.1 Overview

SVG document fragments

An SVG document fragment consists of any number of SVG elements contained within an ‘svg’ element. SVG 2 §5.1.1 An SVG document fragment can stand by itself as a self-contained file or resource, in which case the SVG document fragment is an SVG document, or it can be embedded inline as a fragment within a parent HTML or XML document.
