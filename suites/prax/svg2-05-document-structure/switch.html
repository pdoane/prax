SVG 2 · 5.6.3 The ‘switch’ element

The switch element

The ‘switch’ element evaluates the ‘requiredExtensions’ and ‘systemLanguage’ attributes on its direct child elements in order, and then processes and renders the first child for which these attributes evaluate to true. All others will be bypassed and therefore not rendered. SVG 2 §5.6.3 Each stage is an SVG 160 by 60 with a switch of a blue square at 20, 10, an orange one at 60, 10 and a green one at 100, 10, each 40 by 40.

The first that tests true

An empty requiredExtensions tests false; with no attribute, a child tests true.

display and visibility do not count

setting display to none on a child of a ‘switch’ element has no effect on true/false testing associated with ‘switch’ element processing.
