CSS 2 · 15.3 Font family: the 'font-family' property

Font family: a list of alternatives

font-family takes a comma separated list of <family-name> and <generic-family>. Initial depends on the user agent, it applies to all elements, is inherited, and computes to the value as specified.

CSS Fonts 4 replaces this chapter. What is expected now: font-family: a list of alternatives.

Alternatives, in order

The property value is a prioritized list of font family names and/or generic family names. Unlike most other CSS properties, component values are separated by a comma to indicate that they are alternatives. CSS 2 §15.3

initial: the user agent's family

initial asks for the initial value, which depends on the user agent. CSS 2 §15.3
