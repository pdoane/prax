CSS 2 · 15.7 Font size: the 'font-size' property

Font size: larger and smaller by a ratio

A <relative-size> keyword is interpreted relative to the table of font sizes and the font size of the parent element. Possible values are: [ larger | smaller ]. Each grey bar is 10em wide, ten times its box's font size. CSS 2 §15.7

CSS Fonts 4 replaces this chapter. What is expected now: The absolute size keywords.

Between the entries

If the parent element's size is not close to a table entry, the UA is free to interpolate between table entries or round off to the closest one. The specification's blockquote { font-size: larger }. CSS 2 §15.7

Since CSS 2 · CSS Fonts 4 §2.5

The next entry, or a ratio

The table is now optional: larger may compute the font size to the next entry in the table, but User agents may instead use a simple ratio to increase or decrease the font size relative to the parent element. The specific ratio is unspecified, but should be around 1.2–1.5. CSS Fonts 4 §2.5
