CSS 2 · 15.6 Font boldness: the 'font-weight' property

Font weight: missing weights

Once the font family's weights are mapped onto the CSS scale, missing weights are selected as follows. A weight below 400 looks lighter first, one above 500 darker first. CSS 2 §15.6

CSS Fonts 4 replaces this chapter. What is expected now: Missing weights.

Looking down, then up; up, then down

If the desired weight is less than 400, weights below the desired weight are checked in descending order followed by weights above the desired weight in ascending order until a match is found. If the desired weight is greater than 500, weights above desired weight are checked in ascending order followed by weights below the desired weight in descending order. If the desired weight is 400, 500 is checked first; if the desired weight is 500, 400 is checked first and then the rule for desired weights less than 400 is used. CSS 2 §15.6
