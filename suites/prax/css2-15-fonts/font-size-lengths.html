CSS 2 · 15.7 Font size: the 'font-size' property

Font size: lengths and percentages

Length and percentage values should not take the font size table into account when calculating the font size of the element. Negative values are not allowed. Each grey bar is 10em wide. CSS 2 §15.7

CSS Fonts 4 replaces this chapter. What is expected now: font-size.

<length> and <percentage>

A percentage refers to the inherited font size, and On the 'font-size' property, these length units refer to the computed font size of the parent element. The specification's em { font-size: 150% } and em { font-size: 1.5em } are the same. CSS 2 §15.7

em elsewhere is the element's own size, which children inherit

On all other properties, 'em' and 'ex' length values refer to the computed font size of the current element. The computed value is an absolute length, and that is what is inherited. CSS 2 §15.7
