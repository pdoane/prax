CSS 2 · 15.6 Font boldness: the 'font-weight' property

Font weight

font-weight takes normal | bold | bolder | lighter | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 | 900. Initial normal, it applies to all elements and is inherited.

CSS Fonts 4 replaces this chapter. What is expected now: font-weight: numbers from 1 to 1000.

100 to 900

The values '100' to '900' form an ordered sequence, where each number indicates a weight that is at least as dark as its predecessor. CSS 2 §15.6

normal is 400, bold is 700

The keyword 'normal' is synonymous with '400', and 'bold' is synonymous with '700'. The specification's examples: p { font-weight: normal } /* 400 */ h1 { font-weight: 700 } /* bold */. CSS 2 §15.6
