CSS 2 · 15.2 Font matching algorithm

Font matching: style, variant and weight

The remaining properties are tested against the family according to the matching criteria described with each property. CSS 2 §15.2

CSS Fonts 4 replaces this chapter. What is expected now: Width, then style, then weight, Matching style, Matching weight.

font-style is tried first

'Italic' will be satisfied if there is either a face in the UA's font database labeled with the CSS keyword 'italic' (preferred) or 'oblique'. CSS 2 §15.2

font-variant next, then font-weight

'Small-caps' matches (1) a font labeled as 'small-caps', (2) a font in which the small caps are synthesized, or (3) a font where all lowercase letters are replaced by upper case letters. 'font-weight' is matched next, it will never fail. CSS 2 §15.2
