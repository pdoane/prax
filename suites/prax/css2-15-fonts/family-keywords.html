CSS 2 · 15.3 Font family: the 'font-family' property

Font family names and keywords

Style sheet designers are encouraged to offer a generic font family as a last alternative. Generic font family names are keywords and must NOT be quoted. CSS 2 §15.3

CSS Fonts 4 replaces this chapter. What is expected now: Generic families.

A quoted keyword is a family name

Unquoted font family names that happen to be the same as the keyword values 'inherit', 'default' and 'initial' or the generic font keywords ('serif', 'sans-serif', 'monospace', 'fantasy', and 'cursive') do not match the '<family-name>' type. CSS 2 §15.3
