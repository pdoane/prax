CSS 2 · 15.3.1 Generic font families

The five generic families

All five generic font families are defined to exist in all CSS implementations (they need not necessarily map to five distinct actual fonts). CSS 2 §15.3.1

CSS Fonts 4 replaces this chapter. What is expected now: Generic families.

serif, sans-serif, cursive, fantasy, monospace

Each figure names its generic family alone. Serif glyphs tend to have finishing strokes, flared or tapering ends, or have actual serifed endings; sans-serif ones have stroke endings that are plain; cursive ones generally have either joining strokes or other cursive characteristics beyond those of italic typefaces; fantasy fonts are primarily decorative. CSS 2 §15.3.1.1–4

monospace

The sole criterion of a monospace font is that all glyphs have the same fixed width. CSS 2 §15.3.1.5
