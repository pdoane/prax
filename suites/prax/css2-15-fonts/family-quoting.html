CSS 2 · 15.3 Font family: the 'font-family' property

Font family names worth quoting

Style sheet designers are encouraged to offer a generic font family as a last alternative. Generic font family names are keywords and must NOT be quoted. CSS 2 §15.3

CSS Fonts 4 replaces this chapter. What is expected now: font-family: a list of alternatives.

Quote names with spaces, digits or punctuation

To avoid mistakes in escaping, it is recommended to quote font family names that contain white space, digits, or punctuation characters other than hyphens, as in the specification's examples. CSS 2 §15.3
