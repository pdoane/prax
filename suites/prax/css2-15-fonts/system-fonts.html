CSS 2 · 15.8 Shorthand font property: the 'font' property

The font shorthand: system fonts

caption, icon, menu, message-box, small-caption and status-bar refer to system fonts. Each stage is drawn in the font the user agent picks for it, its platform's or a default of its own; the caption gives its size. CSS 2 §15.8

CSS Fonts 4 replaces this chapter. What is expected now: System font names, The system font.

Set as a whole

System fonts may only be set as a whole; that is, the font family, size, weight, style, etc. are all set at the same time. If no font with the indicated characteristics exists on a given platform, the user agent should either intelligently substitute ... or substitute a user agent default font. CSS 2 §15.8

Then altered individually

These values may then be altered individually if desired. The specification's button p { font: menu } button p em { font-weight: bolder }. CSS 2 §15.8
