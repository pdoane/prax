CSS 2 · 15.3.1 Generic font families

Generic families in any script

Generic font families are a fallback mechanism, a means of preserving some of the style sheet author's intent in the worst case when none of the specified fonts can be selected. CSS 2 §15.3.1

CSS Fonts 4 replaces this chapter. What is expected now: Generic families of one writing system, Generics by language.

serif and sans-serif in other scripts

CSS uses the term 'serif' to apply to a font for any script, although other names may be more familiar for particular scripts, such as Mincho (Japanese); for sans-serif, Gothic (Japanese). CSS 2 §15.3.1.1–2

The worst case

When no named family can be found, the generic family at the end of the list keeps the kind of font the author asked for. CSS 2 §15.3.1
