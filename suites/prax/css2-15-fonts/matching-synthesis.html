CSS 2 · 15.2 Font matching algorithm

Font matching: synthesized faces

CSS 2 matched font-style, then font-variant, then font-weight, and a family whose style failed gave way to the next family. CSS 2 §15.2

CSS Fonts 4 replaces this chapter. What is expected now: Synthetic faces.

Since CSS 2 · CSS Fonts 4 §5.2, §2.2.2

Style and weight never fail, and faces may be synthesized

A family's faces are narrowed using other font properties in the order given below: font-width, font-style, font-weight; font-variant is no longer among them. A style with no slanted face falls back to upright ones: If no match is found, italic values less than or equal to 0 are checked in descending order until a match is found. For families that lack any italic or oblique faces, user agents may create artificial oblique faces, if this is permitted by the value of the font-synthesis property. Synthesized bold faces must be treated as if they exist within the family. CSS Fonts 4 §5.2, §2.2.2
