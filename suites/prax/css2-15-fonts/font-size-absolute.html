CSS 2 · 15.7 Font size: the 'font-size' property

Font size: absolute keywords

font-size takes <absolute-size> | <relative-size> | <length> | <percentage>. Initial medium, it applies to all elements, is inherited, percentages refer to the inherited font size, and it computes to an absolute length.

CSS Fonts 4 replaces this chapter. What is expected now: font-size, The absolute size keywords.

<absolute-size>

An <absolute-size> keyword is an index to a table of font sizes computed and kept by the UA. Possible values are: [ xx-small | x-small | small | medium | large | x-large | xx-large ]. The 'medium' value is the user's preferred font size and is used as the reference middle value. CSS 2 §15.7

No smaller than 9 pixels

To preserve readability, a UA applying these guidelines should nevertheless avoid creating font-size resulting in less than 9 pixels per EM unit on a computer display. CSS 2 §15.7
