CSS 2 · 15.5 Small-caps: the 'font-variant' property

Font variant: small-caps

font-variant takes normal | small-caps. Initial normal, it applies to all elements, is inherited, and computes to the value as specified.

CSS Fonts 4 replaces this chapter. What is expected now: font-variant-caps, The font-variant shorthand.

normal and small-caps

In a small-caps font the lower case letters look similar to the uppercase ones, but in a smaller size and with slightly different proportions. It is acceptable (but not required) in CSS 2.2 if the small-caps font is a created by taking a normal font and replacing the lower case letters by scaled uppercase characters. CSS 2 §15.5

Since CSS 2 · CSS Fonts 4 §6.11, §6.6

font-variant is a shorthand

The font-variant property is a shorthand for all font-variant subproperties, and small-caps sets font-variant-caps. The value normal resets all subproperties of font-variant to their initial value. Small capitals are glyphs of the font, and if small-caps or all-small-caps is specified but small-caps glyphs are not available for a given font, user agents should simulate a small-caps font.
