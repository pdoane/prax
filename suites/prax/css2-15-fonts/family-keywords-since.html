CSS 2 · 15.3 Font family: the 'font-family' property

Generic family keywords since CSS 2

CSS 2 had five generic keywords, and kept inherit, default and initial from naming a family unquoted. CSS 2 §15.3

CSS Fonts 4 replaces this chapter. What is expected now: Generic families.

Since CSS 2 · CSS Fonts 4 §2.1.1, §2.1.2

More generic keywords, and every CSS-wide keyword

The generic families that always match are now serif | sans-serif | system-ui | cursive | fantasy | math | monospace, and Note that <generic-font-family> keywords cannot be quoted (otherwise they are interpreted as a <font-family-name>). Among unquoted names, Any identifier which could be misinterpreted as a pre-defined keyword in the font-family value definition, or the CSS-wide keywords, is not allowed. CSS Fonts 4 §2.1.1–2
