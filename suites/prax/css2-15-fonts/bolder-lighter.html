CSS 2 · 15.6 Font boldness: the 'font-weight' property

Font weight: bolder and lighter

Values of 'bolder' and 'lighter' indicate values relative to the weight of the parent element. Based on the inherited weight value, the weight used is calculated using the chart below. CSS 2 §15.6

CSS Fonts 4 replaces this chapter. What is expected now: bolder and lighter.

The chart

Each line is a parent of the weight at its start, holding a span with bolder and one with lighter, each followed by the chart's weight, set as a number in that weight. The chart: 100, 200, 300 → 400 and 100; 400, 500 → 700 and 100; 600, 700 → 900 and 400; 800, 900 → 900 and 700. CSS 2 §15.6

Children inherit the weight, not the keyword

Child elements inherit the calculated weight, not a value of 'bolder' or 'lighter'. The specification's strong { font-weight: bolder }, nested. CSS 2 §15.6
