CSS 2 · 15.4 Font styling: the 'font-style' property

Font style is inherited

The 'font-style' property selects between normal (sometimes referred to as "roman" or "upright"), italic and oblique faces within a font family. CSS 2 §15.4

CSS Fonts 4 replaces this chapter. What is expected now: font-style: italic and oblique.

Inherited

The specification's example: h1, h2, h3 { font-style: italic } h1 em { font-style: normal }. In the example above, emphasized text within 'H1' will appear in a normal face. CSS 2 §15.4
