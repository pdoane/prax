CSS 2 · 15.8 Shorthand font property: the 'font' property

The font shorthand resets

All font-related properties are first reset to their initial values, including those listed in the preceding paragraph. Then, those properties that are given explicit values in the 'font' shorthand are set to those values. CSS 2 §15.8

CSS Fonts 4 replaces this chapter. What is expected now: The font shorthand.

What is not given is normal

In the first three rules above, the 'font-style', 'font-variant' and 'font-weight' are not explicitly mentioned, which means they are all three set to their initial value ('normal'). Each stage is bold, italic and small-caps, on 40px lines, and its child sets font. CSS 2 §15.8

What the shorthand sets, resets, and leaves alone

In the shorthand, font-variant takes only <font-variant-css2> = normal | small-caps. Properties such as font-variant-ligatures and font-kerning are reset-only sub-properties, while font-palette and the font-synthesis longhands are not longhand properties of the font and thus are neither set nor reset by the font property.
