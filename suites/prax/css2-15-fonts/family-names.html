CSS 2 · 15.3 Font family: the 'font-family' property

Font family names

Font family names must either be given quoted as strings, or unquoted as a sequence of one or more identifiers. CSS 2 §15.3

CSS Fonts 4 replaces this chapter. What is expected now: font-family: a list of alternatives.

Quoted, or identifiers joined by single spaces

If a sequence of identifiers is given as a font family name, the computed value is the name converted to a string by joining all the identifiers in the sequence by single spaces. CSS 2 §15.3
