CSS 2 · 15.5 Small-caps: the 'font-variant' property

Font variant is inherited

Another type of variation within a font family is the small-caps. CSS 2 §15.5

CSS Fonts 4 replaces this chapter. What is expected now: font-variant-caps.

Inherited, and combined with font-style

The following example results in an 'H3' element in small-caps, with any emphasized words in oblique, and any emphasized words within an 'H3' oblique small-caps: h3 { font-variant: small-caps } em { font-style: oblique }. CSS 2 §15.5
