CSS Writing Modes 4 · 5.1.2 Mixed Vertical Orientations

Mixed orientation by Vertical_Orientation

When text-orientation is mixed, the UA must determine the orientation of each typographic character unit by its Vertical_Orientation property: typesetting it upright if its orientation property is U, Tu, or Tr; or typesetting it sideways (90° clockwise from horizontal) if its orientation property is R. CSS Writing Modes 4 §5.1.2

Each class in a mixed line

Each stage is vertical-rl, mixed. Typographic character units which are classified as Tr or Tu in [UAX50] are expected to have alternate glyphs or positioning for typesetting upright in vertical text. §5.1.1

Scripts that rotate the other way

Note that UAX50 does not handle scripts that rotate -90° in vertical contexts, so they will not be typeset correctly with mixed orientation. Use sideways-lr for such scripts. Ogham is written bottom to top.
