CSS Writing Modes 4 · 2.4.1 Bidi Paragraph Embedding Levels

The paragraph embedding level

In CSS, the paragraph embedding level must be set (following UAX9 clause HL1) according to the direction property of the paragraph's containing block rather than by the heuristic given in steps P2 and P3 of the Unicode algorithm. CSS Writing Modes 4 §2.4.1

From direction, not from the text

P2 and P3 would take each paragraph's direction from its first strong letter. CSS takes it from the block.

The exception: plaintext

when the computed unicode-bidi of the paragraph's containing block is plaintext, the Unicode heuristics in P2 and P3 are used as described in [UAX9], without the HL1 override.
