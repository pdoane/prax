CSS Writing Modes 4 · 5.1.1 Vertical Typesetting and Font Features

Upright and sideways typesetting

When typesetting text in vertical-rl and vertical-lr modes, text is typeset either “upright” or “sideways”. CSS Writing Modes 4 §5.1.1

Vertical metrics and features, or horizontal ones

Upright: The UA must synthesize vertical font metrics for fonts that lack them. (E.g. the OpenType vert feature must be enabled.) Sideways: using horizontal metrics and composition, and vertical typesetting features are not used. PR Noto Sans JP has vertical metrics and vert forms; PR Arimo has neither.
