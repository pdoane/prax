CSS Writing Modes 4 · 8.1 Propagation to the Initial Containing Block

The principal writing mode on the viewport

The principal writing mode is propagated to the initial containing block and to the viewport, thereby affecting the layout of the root element and the scrolling direction of the viewport. CSS Writing Modes 4 §8.1

The viewport scrolls from the start

Each frame's document is 500px wide, a bar whose start is dark blue and whose end is orange, wider than the 200px frame. The frame opens scrolled to where the document's writing mode starts.
