CSS Writing Modes 4 · 2.2 Embeddings and Overrides: the unicode-bidi property, plaintext

unicode-bidi: plaintext

This value behaves as isolate except that for the purposes of the Unicode bidirectional algorithm, the base directionality of each of the box's bidi paragraphs (if a block container) or isolated sequences (if an inline) is determined by following the heuristic in rules P2 and P3 of the Unicode bidirectional algorithm (rather than by using the direction property of the box). CSS Writing Modes 4 §2.2

On a block: each paragraph from its first strong letter

P2 and P3 take a paragraph's direction from its first strong character. Each stage is ltr; the first two are text-align: left, so that only the order changes.

On an inline: its own direction

The span is an isolated sequence whose direction its own text gives.
