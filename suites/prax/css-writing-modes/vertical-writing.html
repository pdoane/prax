CSS Writing Modes 4 · 3.1 Introduction to Vertical Writing

Vertical writing

Unlike languages that use the Latin script which are primarily laid out horizontally, Asian languages such as Chinese and Japanese can be laid out vertically. The section is non-normative. CSS Writing Modes 4 §3.1

The same text, horizontal and vertical

Indentation from the left edge in the left-to-right horizontal case translates to indentation from the top edge in the top-to-bottom vertical case. Each stage is indented 1em.

Latin and numbers in vertical text

Latin words can be rotated sideways, or each letter can be oriented upright; for two-digit numbers in dates, text is fit compactly into a single vertical character box.
