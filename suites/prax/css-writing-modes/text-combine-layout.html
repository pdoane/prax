CSS Writing Modes 4 · 9.1.2 Layout Rules

text-combine-upright: the 1em square

When combining text as for text-combine-upright: all, the glyphs of the combined text are bidi-isolated and composed horizontally (ignoring letter-spacing and any forced line breaks, but using the specified font settings), similar to the contents of an inline-block box with a horizontal writing mode and a line-height of 1em. CSS Writing Modes 4 §9.1.2

One square in the line

The effective size of the composition is assumed to be 1em square. Each stage holds 年, a combined span, and 月日, in 20px text: the span takes 20px of the column, as one character does.

Isolated and centered

The baseline of the resulting composition must be chosen such that the square is centered between the text-over and text-under baselines of its parent inline box.
