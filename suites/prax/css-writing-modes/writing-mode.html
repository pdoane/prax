CSS Writing Modes 4 · 3.2 Block Flow Direction: the writing-mode property

writing-mode: the block flow direction

This property specifies whether lines of text are laid out horizontally or vertically and the direction in which blocks progress. CSS Writing Modes 4 §3.2

Blocks stack in the block flow direction

Each stage is 80px square and holds blocks A, B and C, in that order. horizontal-tb: Top-to-bottom block flow direction. vertical-rl: Right-to-left block flow direction. vertical-lr: Left-to-right block flow direction.

Lines stack the same way

The property also gives the ordering direction of line boxes in a block container that contains inlines, and with it whether the line boxes' orientation (and thus the writing mode) is horizontal or vertical.
