CSS Writing Modes 4 · 2.4.5.2 Box Model of Reordering-induced Box Fragments

Edges of a split box

For each line box, UAs must take the fragments of each inline box and assign the margins, borders and padding in visual order (not logical order). The start-most fragment on the first line box in which the box appears has the start edge's margin, border, and padding; and the end-most fragment on the last line box in which the box appears has the end edge's margin, border, and padding. Left and right borders

Each tinted span has a blue left border 3px wide and a red right border 6px wide. In ltr, the left-most box fragment on the first line box has the left edge; in rtl, the right-most fragment of the first line box has the right edge.
