CSS Writing Modes 4 · 7.1 Principles of Layout in Vertical Writing Modes

Layout in vertical writing modes

Layout calculation rules (such as those in CSS2.1, Section 10.3) that apply to the horizontal dimension in horizontal writing modes instead apply to the vertical dimension in vertical writing modes. CSS Writing Modes 4 §7.1

Width rules use the height

The margin-left property still affects the lefthand margin, for example; however in a vertical-rl writing mode it takes part in margin collapsing in place of margin-bottom. Each stage is vertical-rl, 100px tall.

Left and right become start and end

Layout rules that depend on the direction property to choose between left and right are abstracted to the start and end sides.
