CSS Writing Modes 4 · 7.2 Dimensional Mapping

Dimensional mapping

The height properties (height, min-height, and max-height) refer to the physical height. However, the rules used to calculate box dimensions and positions are logical. CSS Writing Modes 4 §7.2

Physical sizes, percentages of the inline size

Each stage is vertical-rl, 100px square. Margin and padding percentages are calculated with respect to the inline size of the containing block in CSS3. Here the inline size is the height; the last two stages are 60px tall, so that it differs from their width.

border-spacing and line-height

The first and second values of the border-spacing property represent spacing between columns and rows respectively, not necessarily the horizontal and vertical spacing respectively. The line-height property always refers to the logical height.
