CSS Writing Modes 4 · 7.3.3 Auto-sizing Other Orthogonal Flow Roots

Orthogonal flows: other formatting contexts

For calculating the automatic inline size for other display types when the available inline space is infinite, if the box is block-level or the formatting context otherwise calculates an automatic inline size using its max-content size, use the same formula used for the block containers’ column-width (see above) in place of that max-content size: min(max-content, max(min-content, constraint)).
