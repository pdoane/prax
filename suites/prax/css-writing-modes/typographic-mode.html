CSS Writing Modes 4 · 3.2 Block Flow Direction: the writing-mode property, typographic modes

writing-mode: vertical and sideways typography

The typographic mode determines whether to use typographic conventions specific to vertical flow for vertical scripts (vertical typographic mode) or to use the typographic conventions of horizontal writing modes (horizontal typographic mode). This concept distinguishes vertical typesetting from rotated horizontal typesetting. CSS Writing Modes 4 §3.2
