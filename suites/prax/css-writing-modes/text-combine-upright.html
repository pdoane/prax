CSS Writing Modes 4 · 9.1 Horizontal-in-Vertical Composition: the text-combine-upright property

text-combine-upright

This property specifies the combination of multiple typographic character units into the space of a single typographic character unit. The resulting composition is treated as a single upright glyph for the purposes of layout and decoration. This property only has an effect in vertical writing modes. CSS Writing Modes 4 §9.1
