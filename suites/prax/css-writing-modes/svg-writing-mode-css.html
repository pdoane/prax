CSS Writing Modes 4 · 3.2.1.1 Supporting SVG1.1 writing-mode values in CSS syntax

SVG 1.1 writing-mode values in CSS

The values lr, lr-tb, rl, rl-tb, tb and tb-rl are obsolete in any context except SVG1 documents and are therefore optional for non-SVG UAs. UAs that wish to support these values in the context of CSS must compute them as follows. CSS Writing Modes 4 §3.2.1.1

tb and tb-rl draw as vertical-rl

Each tinted block is in a horizontal-tb stage, which it keeps where it does not take the value.

lr, lr-tb, rl and rl-tb draw as horizontal-tb

Each tinted block is in a vertical-lr stage, which it keeps where it does not take the value.
