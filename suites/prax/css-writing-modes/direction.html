CSS Writing Modes 4 · 2.1 Specifying Directionality: the direction property

direction: the inline base direction

This property specifies the inline base direction or directionality of any bidi paragraph, embedding, isolate, or override established by the box. CSS Writing Modes 4 §2.1

ltr and rtl

ltr: This value sets inline base direction (bidi directionality) to line-left-to-line-right. rtl: This value sets inline base direction (bidi directionality) to line-right-to-line-left.

On an inline box with unicode-bidi: normal

The direction property has no effect on bidi reordering when specified on inline boxes whose unicode-bidi value is normal, because the box does not open an additional level of embedding.
