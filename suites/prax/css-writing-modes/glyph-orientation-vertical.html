CSS Writing Modes 4 · 5.1.3 Obsolete: the SVG1.1 glyph-orientation-vertical property

glyph-orientation-vertical, a shorthand

While supporting this property is optional, UAs that do so must alias glyph-orientation-vertical as a shorthand of text-orientation: auto as mixed, 0deg and 0 as upright, 90deg and 90 as sideways. CSS Writing Modes 4 §5.1.3

The mapped values

Each stage holds "日本abc" under the caption's glyph-orientation-vertical. A UA that does not support the property keeps the text-orientation before it; Chrome and Firefox do not support it.
