CSS Writing Modes 4 · 7.6 Purely Physical Mappings

Purely physical values

The following values are purely physical in their definitions and do not respond to changes in writing mode: rect() in clip, the background properties, the border-image properties, and the offsets of the box-shadow and text-shadow properties. CSS Writing Modes 4 §7.6

In a vertical-rl, rtl box

Each stage is writing-mode: vertical-rl; direction: rtl, whose start corner is the bottom right; each value lands where it would in horizontal-tb.
