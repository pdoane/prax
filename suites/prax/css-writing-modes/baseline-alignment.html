CSS Writing Modes 4 · 4.4 Baseline Alignment

Baseline alignment

The dominant baseline (which can change based on the typographic mode) is used in CSS for alignment in two cases: glyphs from different fonts in one box, and a child box in its parent. CSS Writing Modes 4 §4.4

Glyphs from different fonts in one box

The glyphs are aligned by matching up the positions of the dominant baseline in their corresponding fonts. PR Arimo, its Japanese from PR Noto Sans JP.

A child in its parent

child is aligned to the parent by matching the parent's dominant baseline to the same baseline in the child; for super, the child is shifted. Each child is highlighted.
