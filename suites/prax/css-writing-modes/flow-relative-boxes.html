CSS Writing Modes 4 · 7.4 Flow-Relative Mappings, boxes

Flow-relative mappings: a box in its container

Flow-relative directions are calculated with respect to the writing mode of the containing block of the box and used to abstract layout rules related to the box properties (margins, borders, padding). For inline-level boxes, the writing mode of the parent box is used instead. CSS Writing Modes 4 §7.4

The over-constrained margin is the end margin

the margin that is dropped when a box's inline dimension is over-constrained is the end margin as determined by the writing mode of the containing block. Each stage is vertical-rl, 80px tall; A is 40px tall with 10px top and bottom margins.

Margins in the flow

Note this means only block-start and block-end margins ever collapse. In the first stage, between A and B is an empty block with 20px margins on all four sides. In the second, a purple inline-block has margin-top: 20px.
