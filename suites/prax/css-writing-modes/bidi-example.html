CSS Writing Modes 4 · 2.3 Example of Bidirectional Text

An example of bidirectional text

The specification's example, with Hebrew words for its uppercase ones: אאא for HEBREW1, בבב for HEBREW2, and so on through the alphabet, each of them three letters that read the same either way. The style sheet is the example's: [dir=rtl] {direction: rtl; unicode-bidi: isolate; }, and so for ltr. CSS Writing Modes 4 §2.3

A long line and a narrow one

The first section element is a block with a right-to-left base direction, the second section element is a block with a left-to-right base direction. The emphasis element is inline-level, and since its value for unicode-bidi is normal (the initial value), it has no effect on the ordering of the text. The quote element, on the other hand, creates an isolated sequence with the given internal directionality.
