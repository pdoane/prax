Path2D objects

Path2D objects can be used to declare paths that are then later used on objects implementing the CanvasDrawPath interface. HTML §4.12.5.1.7

From SVG path data

new Path2D(path): When path is a string, creates the path described by the argument, interpreted as SVG path data.
