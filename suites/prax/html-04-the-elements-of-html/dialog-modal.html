HTML · 4.11.4 The dialog element

Modal dialogs

showModal() must show a modal dialog: it adds the dialog to the top layer and sets subject's node document to be blocked by the modal dialog subject. HTML §4.11.4

In the top layer, over a backdrop, the rest inert

A modal dialog is fixed and centered in the viewport, and its ::backdrop is rgba(0,0,0,0.1) over everything else. §15.3.3 Blocked by it, the rest of the document is inert: no click or focus reaches it. §6.3.1

A close request closes it

With no closedby, a modal dialog is in the Close Request state: a close request fires cancel, then closes it. §4.11.4 §6.10.1
