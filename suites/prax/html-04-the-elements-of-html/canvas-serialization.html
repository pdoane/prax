HTML · 4.12.5.5 Serializing bitmaps to a file

Serializing a canvas

When a user agent is to create a serialization of the bitmap as a file, given a type and an optional quality, it must create an image file in the format given by type. HTML §4.12.5.5 Each canvas, at the left, is 60 by 40, transparent with a blue square of 20 at (20, 10); at the right is an img showing the file made from it. Edges are dashed red.

PNG, and types without alpha

For image types that do not support an alpha component, the serialized image must be the bitmap image composited onto an opaque black background using the source-over compositing operator. If the user agent does not support the requested type, then it must create the file using the PNG format.
