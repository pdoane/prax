HTML · 4.2.4.1 Processing the media attribute

The link element's media

if the link is an external resource link, then the media attribute is prescriptive. The user agent must apply the external resource when the media attribute's value matches the environment and the other relevant conditions apply, and must not apply it otherwise. HTML §4.2.4.1

The environment is the document's

Each frame's document links a style sheet that turns its box green. The frame is its viewport, 200px wide, though this page's is wider. The default, if the media attribute is omitted, is "all".

When the environment changes

The sheet has media="(min-width: 150px)", and the button narrows the frame to 100px, or widens it back.
