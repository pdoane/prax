HTML · 4.10.5.3.9 The list attribute

The list attribute

The list attribute is used to identify an element that lists predefined options suggested to the user. HTML §4.10.5.3.9

Suggestions while editing

If appropriate, the user agent should use the suggestion's label and value to identify the suggestion to the user. When the user selects a suggestion, the input element's value must be set to the selected suggestion's value, as if the user had written that value themself. §4.10.5.3.9

Tick marks on a slider

Predefined suggested values (provided by the list attribute) are expected to be shown as tick marks on the slider, which the slider can snap to. §15.5.8
