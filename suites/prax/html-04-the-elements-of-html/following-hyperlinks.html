Following hyperlinks

To follow a hyperlink, the user agent chooses a navigable by the link's target, Let targetNavigable be the first return value of applying the rules for choosing a navigable given targetAttributeValue, subject's node navigable, and noopener., and navigates it. HTML §4.6.5

A named frame

A target that names a navigable navigates that navigable. Below the link, a frame named follow-view.

The link's own navigable, or its parent

With no target, the link's own node navigable; with _parent, that navigable's parent. Each frame's document holds, in a dashed frame of its own, a document with a link.
