HTML · 4.11.2 The summary element

The summary element

The summary element represents a summary, caption, or legend for the rest of the contents of the summary element's parent details element, if any. HTML §4.11.2

Activating the summary toggles its details

If the open attribute is present on parent, then remove it. Otherwise, set parent's open attribute to the empty string. A key that activates it fires a click, as any activation does. §4.11.2

Only the summary for its parent details

Activation does nothing unless the element is the summary for its parent details: its parent is a details element and parent's first summary element child is this one. §4.11.2
