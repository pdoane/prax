HTML · 4.12.5.1.4 Line styles

Line joins

A stroke replaces each join with the join necessary to satisfy style's lineJoin type. HTML §4.12.5.1.4 In each figure the path itself is drawn over its stroke as a thin red line.

Joins

The "bevel" value means that this is all that is rendered at joins. The "round" value means that an arc connecting the two aforementioned corners of the join must be added at joins. The "miter" value means that a second triangle must (if it can given the miter length) be added at the join. Each path runs from (20, 80) up to (50, 20) and down to (80, 80), with width 16.

The miter limit

The miter limit ratio is the maximum allowed ratio of the miter length to half the line width. If the miter length would cause the miter limit ratio (as set by style's miterLimit attribute) to be exceeded, then this second triangle must not be added. The join above has a ratio of √5, about 2.24.
