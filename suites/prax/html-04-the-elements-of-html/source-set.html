HTML · 4.8.4.3.9 Updating the source set

Which source an img takes

Each img element independently considers its previous sibling source elements plus the img element itself for selecting an image source, ignoring any other (invalid) elements, including other img elements in the same picture element, or source elements that are following siblings of the relevant img element. The first source that qualifies

A source is passed over if it has no srcset, if source set has zero image sources, or if its media or type do not fit; the first one left gives the img its source set, and Return.
