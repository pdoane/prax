HTML · 4.13.7.5 Custom state pseudo-class

Custom states

The :state(identifier) pseudo-class must match all custom elements whose states set's set entries contains identifier. §4.16.3 internals.states.add(value) Adds the string value to the element's states set to be exposed as a pseudo-class. HTML §4.13.7.5

A state the page's style sheet matches

The page defines x-switch: a click adds the state on to its states set, or deletes it. The page's style sheet gives x-switch a red dashed border, and x-switch:state(on) a solid blue one on light blue.

On a shadow part

The switch's shadow tree has a "●" with part=knob, which the element's code gives the state lit while it is on, through an inner custom element's own internals. The page styles x-switch::part(knob) red and x-switch::part(knob):state(lit) green.
