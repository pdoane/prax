HTML · 4.15 Disabled elements

Disabled elements

An element is said to be actually disabled if it is one of the following: a disabled form control or fieldset, or an option or optgroup that is disabled or in a disabled select. HTML §4.15

What matches :disabled

This definition is used to determine what elements are focusable and which elements match the :enabled and :disabled pseudo classes. Here :disabled is outlined orange and :enabled green; an option or optgroup is tinted instead. §4.15

Not focusable

An actually disabled element is not a focusable area, so neither a click nor Tab focuses it. §4.15
