HTML · 4.10.9 The optgroup element

The optgroup element

The optgroup element represents a group of option elements with a common label. HTML §4.10.9

Groups, each under its label

User agents should show the option elements of such groups as being related to each other and separate from other option elements. Its disabled can be used to disable a group of option elements together. §4.10.9

A label from a legend

If optgroup's first element child is a legend element, then return the result of get HTML-aware text content given that legend element and true. Outside base appearance, it is expected to be rendered by displaying the element's label and children. §4.10.9 §15.5.16
