HTML · 4.9.1 The table element

The table element

The table element represents data with more than one dimension, in the form of a table. HTML §4.9.1 Each table's edge is dashed; its cells have a blue border, which only the figures set.

Rows and columns form a grid

Tables have rows, columns, and cells given by their descendants. The rows and columns form a grid; a table's cells must completely cover that grid without overlap. §4.9.1
