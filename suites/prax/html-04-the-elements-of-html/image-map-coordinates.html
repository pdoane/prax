Image map coordinates

Each area's coordinates are in CSS pixels from the top left of the image. HTML §4.8.14.2 Each image is 200 by 100 unless a figure says otherwise: a blue rectangle from 10, 10 to 60, 90, an orange circle at 100, 50 of radius 30, and a green triangle from 150 to 190 across. Each log lists the target of the clicks in its stage.

Coordinates on the image as drawn

For historical reasons, the coordinates must be interpreted relative to the displayed image after any stretching caused by the CSS 'width' and 'height' properties. Image maps are live; if the DOM is mutated, then the user agent must act as if it had rerun the algorithms for image maps.
