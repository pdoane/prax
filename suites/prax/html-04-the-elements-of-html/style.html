HTML · 4.2.6 The style element

The style element

The style element allows authors to embed CSS style sheets in their documents. In each frame, a style element's sheet turns the box green, or orange. HTML §4.2.6

media and type

The user agent must apply the styles when the media attribute's value matches the environment and the other relevant conditions apply, and must not apply them otherwise. If element's type attribute is present and its value is neither the empty string nor an ASCII case-insensitive match for "text/css", then return.

Titles name style sheet sets

The title attribute on style elements defines CSS style sheet sets. The first title is the preferred set, and a sheet of another title is not applied.
