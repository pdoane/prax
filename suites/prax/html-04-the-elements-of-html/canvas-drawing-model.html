HTML · 4.12.5.1.22 Drawing model

The drawing model

When a shape or image is painted, user agents must follow these steps, in the order given (or act as if they do): render it to image A, multiply by global alpha, filter A into B, render the shadow from B into C, then composite C and then B. HTML §4.12.5.1.22 The shape is a blue square of 40 at (30, 10).

The shadow comes from the filtered image

When shadows are drawn, render the shadow from image B, using the current shadow styles, creating image C.

Shadow and shape composited in turn

When shadows are drawn, composite C within the clipping region over the current output bitmap using the current compositing and blending operator. Composite B within the clipping region in the same way.
