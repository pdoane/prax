HTML · 4.11.4 The dialog element

Commands for dialogs

A button's commandfor and command run the command steps of a dialog, with the button as the source. HTML §4.11.4

show-modal and close

If command is the Show Modal state and element does not have an open attribute, then show a modal dialog given element and source. If command is in the Close state and element has an open attribute, then close the dialog element with source's optional value and source. §4.11.4

request-close

If command is in the Request Close state and element has an open attribute, then request to close the dialog: cancel is fired first, and a listener that cancels it keeps the dialog open. The page's script cancels it while the box is checked. §4.11.4
