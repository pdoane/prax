Resetting a form

Let reset be the result of firing an event named reset at form, with the bubbles and cancelable attributes initialized to true. If reset is true, then invoke the reset algorithm of each resettable element whose form owner is form. HTML §4.10.23

Each control back to its default

Changes made to form controls as part of these algorithms do not count as changes caused by the user (and thus, e.g., do not cause input events to fire). §4.10.23
