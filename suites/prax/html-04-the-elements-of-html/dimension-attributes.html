HTML · 4.8.17 Dimension attributes

Dimension attributes

The width and height attributes give the dimensions of the visual content of the element. User agents are expected to use these attributes as hints for the rendering. HTML §4.8.17 They map to the dimension properties 'width' and 'height', and on img and video map to the aspect-ratio property (using dimension rules). §15.4.3 Blue is an image 80 by 40; no-size.svg is blue with a white dot, with no natural size or ratio.
