HTML · 4.12.5.1 The 2D rendering context

The 2D context's coordinate space

The CanvasRenderingContext2D 2D rendering context represents a flat linear Cartesian surface whose origin (0,0) is at the top left corner, with the coordinate space having x values increasing when going right, and y values increasing when going down. HTML §4.12.5.1 Each canvas's edge is dashed red.

Origin at the top left, y down

The x-coordinate of the right-most edge is equal to the width of the rendering context's output bitmap.

Setting the size resets the bitmap

Setting width or height, even redundantly, runs the steps to set bitmap dimensions, which Reset the rendering context to its default state. §4.12.5
