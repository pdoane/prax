HTML · 4.10.5.1.18 Submit Button state (type=submit)

Submit buttons

The input element represents a button that, when activated, submits the form. HTML §4.10.5.1.18

Its label, and what a click submits

If the element has a value attribute, the button's label must be the value of that attribute; otherwise, it must be an implementation-defined string that means "Submit" or some such. §4.10.5.1.18

Enter in a field: implicit submission

Where the user can submit a form implicitly, for example, on some platforms hitting the "enter" key while a text control is focused, doing so must cause the user agent to fire a click event at that default button, the form's first submit button. With no submit button, the form is submitted unless it has more than one field that blocks implicit submission. §4.10.22.2
