HTML · 4.12.5 The canvas element

Canvas fallback content

The contents of the canvas element, if any, are the element's fallback content. In interactive visual media, if scripting is enabled for the canvas element, and if support for canvas elements has been enabled, then the canvas element represents embedded content consisting of a dynamically created image, the element's bitmap. HTML §4.12.5

The bitmap, not the fallback, is drawn

Focus reaches the fallback

When a canvas element represents embedded content, the user can still focus descendants of the canvas element (in the fallback content). When an element is focused, it is the target of keyboard interaction events (even though the element itself is not visible). The canvas holds a fallback button, id play.
