HTML · 4.8.4.2.2 Sizes attributes

sizes=auto

The keyword auto is a width that is computed in parse a sizes attribute. An img allows auto-sizes if its loading attribute is in the Lazy state and its sizes is auto or starts with auto,. HTML §4.8.4.2.2 Each img has one candidate, an orange image 160 by 80 described as 160w.

auto: the width it is drawn at

If the img element that initiated the image loading … allows auto-sizes and is being rendered, then auto is the concrete object size width. Without dimensions it will likely render with 300x150 dimensions because sizes="auto" implies contain-intrinsic-size: 300px 150px.
