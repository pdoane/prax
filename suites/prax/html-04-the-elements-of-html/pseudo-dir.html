HTML · 4.16.3 Pseudo-classes

:dir()

The :dir(ltr) pseudo-class must match all elements whose directionality is 'ltr'. The :dir(rtl) pseudo-class must match all elements whose directionality is 'rtl'. HTML §4.16.3

Directionality, not the direction property

Outlines: green :dir(ltr), orange :dir(rtl). Directionality comes from dir, inherited from the parent, or for dir=auto from the text. §4.16.3
