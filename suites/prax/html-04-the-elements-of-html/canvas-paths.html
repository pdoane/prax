Building paths

A path has a list of zero or more subpaths. Each subpath consists of a list of one or more points, connected by straight or curved line segments, and a flag indicating whether the subpath is closed or not. HTML §4.12.5.1.6 Every path is stroked blue, 3 wide; red marks the points the methods were given.

Lines, curves, and closing

A closed subpath is one where the last point of the subpath is connected to the first point of the subpath by a straight line. quadraticCurveTo and bezierCurveTo connect using a quadratic Bézier curve with control point (cpx, cpy) and a cubic Bézier curve with the given control points.

Rectangles

rect ends by creating a new subpath with the point (x, y) as the only point in the subpath.
