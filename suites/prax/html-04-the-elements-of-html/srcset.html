HTML · 4.8.4.2.1 Srcset attributes

srcset: pixel density

An image candidate string may have A pixel density descriptor, consisting of: ASCII whitespace, a valid floating-point number giving a number greater than zero representing the pixel density descriptor value, and a U+0078 LATIN SMALL LETTER X character. HTML §4.8.4.2.1 Each img has one candidate, an orange image 160 by 80, so the user agent has no choice to make.

The natural size, divided by the density

The density-corrected natural width is the image's intrinsicWidth divided by density, and its height likewise. §4.8.4.3
