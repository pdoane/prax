The canvas state

Objects that implement the CanvasState interface maintain a stack of drawing states. A drawing state holds the transformation, the clipping region, the styles and the line and text settings. HTML §4.12.5.1.3

save() and restore()

The save() method steps are to push a copy of the current drawing state onto the drawing state stack. The restore() method steps are to pop the top entry in the drawing state stack, and reset the drawing state it describes. If there is no saved state, then the method must do nothing.

reset()

To reset the rendering context to its default state: Clear canvas's bitmap to transparent black. Empty the list of subpaths in the context's current default path. Clear the context's drawing state stack. Reset everything that drawing state consists of to their initial values.
