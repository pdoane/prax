HTML · 4.12.4 The slot element

Assigning slots by hand

The slot element has manually assigned nodes, which is an ordered set of slottables set by assign(). HTML §4.12.4

The nodes that assign() gives

slot.assign(...nodes) Sets slot's manually assigned nodes to the given nodes. The host's shadow root has slotAssignment: "manual"; its tree is a blue frame, "Pick:" and one slot, whose own contents are "none". The host's children are the bold words red, green and blue. Each button calls assign() on the slot.
