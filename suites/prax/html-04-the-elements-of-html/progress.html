HTML · 4.10.13 The progress element

The progress element

The progress element represents the completion progress of a task. HTML §4.10.13

The current value against the maximum

The maximum is max if greater than zero, else 1.0; the value is value if greater than zero, else zero; the current value is the maximum value, if value is greater than the maximum value, and value otherwise. Each bar is 10em, the stage's 100px, wide. §4.10.13

Indeterminate, and in other directions

If the value attribute is omitted, then the progress bar is an indeterminate progress bar. The start is on the right and the end is on the left if the 'direction' property on this element has a computed value of 'rtl'; in a vertical writing mode, with the start on the top and the end on the bottom otherwise. §15.5.15
