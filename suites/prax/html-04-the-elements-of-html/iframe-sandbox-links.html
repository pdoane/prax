HTML · 4.8.5 The iframe element

Links out of a sandbox

When the sandbox attribute is set, links are prevented from targeting other navigables. HTML §4.8.5 Each frame's document is in its srcdoc.

Links to other navigables

A sandboxed document may navigate only itself and what it contains, unless allow-top-navigation or allow-popups say otherwise. Each upper frame has a link whose target names the frame below it.
