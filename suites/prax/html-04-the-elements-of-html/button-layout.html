HTML · 4.10.6 The button element

Button layout

A button element is expected to depict a button and to use button layout. HTML §15.5.3 §4.10.6

As wide as its content

If the computed value of 'inline-size' is 'auto', then the used value is the fit-content inline size. Otherwise, if the computed value of 'display' is a value such that the outer display type is 'inline', then behave as 'inline-block'. §15.5.3

Flex and grid lay out its content

The element is expected to establish a new formatting context for its contents. If the computed value of 'display' is 'inline-grid', 'grid', 'inline-flex', 'flex', 'none', or 'contents', then behave as the computed value. §15.5.3
