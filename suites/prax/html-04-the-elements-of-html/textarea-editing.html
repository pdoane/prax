HTML · 4.10.11 The textarea element

Editing a textarea

When a textarea is mutable, its raw value should be editable by the user. HTML §4.10.11

Editing, and not

Any time the user causes the element's raw value to change, the user agent must queue an element task to fire an event named input at the textarea element. A textarea element is mutable if it is neither disabled nor has a readonly attribute specified. §4.10.11

The placeholder

User agents should present this hint to the user when the element's value is the empty string and the control is not focused; U+000A LINE FEED (LF) characters in the hint, must be treated as line breaks when rendering the hint. §4.10.11
