HTML · 4.8.9 The audio element

The audio element

An audio element represents a sound or audio stream. HTML §4.8.9 tone.wav is a second of a tone, 16-bit PCM in a WAVE file, a format user agents must support. Brackets show where each audio element is.

Without controls, not displayed

audio elements without a controls attribute will not be displayed by the user agent. When an audio element is not exposing a user interface, the user agent is expected to force its 'display' property to compute to 'none', irrespective of CSS rules. §15.4.1

With controls, a line high

When it is exposing a user interface, the audio element is expected to be treated as a replaced element about one line high, as wide as is necessary to expose the user agent's user interface features. §15.4.1 Of its contents, User agents should not show this content to the user.
