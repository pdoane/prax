HTML · 4.10.22.2 Implicit submission

Implicit submission

If the user agent supports letting the user submit a form implicitly (for example, on some platforms hitting the "enter" key while a text control is focused implicitly submits the form), then doing so for a form, whose default button has activation behavior and is not disabled, must cause the user agent to fire a click event at that default button. HTML §4.10.22.2

The default button

A form element's default button is the first submit button in tree order whose form owner is that form element. The page's script cancels each submit here, after it is logged. §4.10.22.2

No submit button

If the form has no submit button, then the implicit submission mechanism must perform the following steps: If the form has more than one field that blocks implicit submission, then return. Text fields block it. §4.10.22.2
