HTML · 4.10.7 The select element

The size of a select

The select element is an element with default preferred size, and user agents are expected to apply the 'field-sizing' CSS property to select elements. HTML §15.5.16 §4.10.7

The width of its labels

The inline size of its intrinsic size is the width of the select's labels. The width of the select's labels is the wider of the width necessary to render the widest optgroup, and the width necessary to render the widest option element §15.5.16 The engines' developers have agreed that a drop-down box leaves group labels out, as every browser does, and a list box counts them (html#4502).

field-sizing: content

For a list box, If the 'field-sizing' property on the element has a computed value of 'content', return the height necessary to contain all rows for items. For a drop-down box, the inline size of the intrinsic size depends on the shown text. §15.5.16
