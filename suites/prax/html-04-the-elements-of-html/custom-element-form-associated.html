HTML · 4.13.7.3 Form-associated custom elements

Form-associated custom elements

Each form-associated custom element has submission value. It is used to provide one or more entries on form submission. HTML §4.13.7.3 The page defines x-check, form-associated: a click toggles it between "[ ]" and "[x]", and it calls setFormValue and, while unchecked, setValidity({valueMissing: true}, "Check this"). :invalid gives it a red border on orange.

Labels, reset and validity

It is labelable: for user agents where the label element's activation behavior impacts the labeled control, both built-in and custom elements will be impacted. §4.10.4 The reset algorithm for form-associated custom elements is to enqueue a custom element callback reaction with the element, callback name "formResetCallback" §4.13.3, and its callback unchecks it. The page cancels submit.

Read-only: barred from validation

If the readonly attribute is specified on a form-associated custom element, the element is barred from constraint validation. §4.13.3
