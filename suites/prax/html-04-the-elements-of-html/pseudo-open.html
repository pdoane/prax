HTML · 4.16.3 Pseudo-classes

:open

The :open pseudo-class must match any element falling into one of the following categories: details and dialog elements with an open attribute, select elements that are a drop-down box and whose drop-down boxes are open, and input elements that support a picker and whose pickers are open. HTML §4.16.3

Open, and closed again

An outline is orange, and green while its element matches :open. Each rule names one kind of element, so that a browser lacking one leaves the others. §4.16.3
