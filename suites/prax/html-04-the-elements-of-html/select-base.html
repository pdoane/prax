HTML · 4.10.7 The select element

The customizable select

select elements which render as a drop-down box support a base appearance, which each stage opts into with appearance: base-select. HTML §15.5.16 §4.10.7

The drop-down box, closed

A currentColor border, rounded by 0.5em, and a disclosure-open ::picker-icon at the end. §15.5.16

The picker, and the list box

A click opens ::picker(select) below the box; picking an option hides it. An option's ::checkmark, '\2713', shows when it is checked. A list box's rows are max(24px, 1lh) tall. §4.10.7
