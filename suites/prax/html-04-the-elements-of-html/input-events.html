HTML · 4.10.5.5 Common event behaviors

input and change

The input event fires whenever the user has modified the data of the control. The change event fires when the value is committed, if that makes sense for the control, or else when the control loses focus. HTML §4.10.5.5

Typing, then leaving

Examples of a user changing the element's value would include the user typing into a text control, pasting a new value into the control, or undoing an edit in that control. Some user interactions do not cause changes to the value, e.g., hitting the "delete" key in an empty text control. §4.10.5.5

Not for a script's changes

These events are not fired in response to changes made to the values of form controls by scripts. §4.10.5.5 The button sets value and checked.
