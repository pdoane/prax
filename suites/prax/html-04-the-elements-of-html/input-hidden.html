HTML · 4.10.5.1.1 Hidden state (type=hidden)

Hidden inputs

The input element represents a value that is not intended to be examined or manipulated by the user. HTML §4.10.5.1.1

Nothing to see, and still submitted

A hidden input is not interactive content and not labelable, and it generates no box: the rendering section's style sheet gives input[type=hidden i] display: none !important. §15.3.1
