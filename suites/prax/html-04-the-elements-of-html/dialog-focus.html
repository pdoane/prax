HTML · 4.11.4 The dialog element

Where a dialog puts the focus

The dialog focusing steps: If subject has the autofocus attribute, then set control to subject. If control is null, then set control to the focus delegate of subject. If control is null, then set control to subject. HTML §4.11.4

The control that takes the focus

Each button opens its dialog with showModal(), and what has the focus is outlined in red. The focus delegate honors autofocus on a descendant, or else is the first focusable descendant. Escape closes the dialog, and the focus returns to the button, the previously focused element. §4.11.4
