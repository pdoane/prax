The min and max attributes

The min and max attributes indicate the allowed range of values for the element. HTML §4.10.5.3.7

Underflow and overflow

A value less than the minimum is suffering from an underflow, one more than the maximum suffering from an overflow. §4.10.5.3.7 Each control is outlined green while it is valid and red while it is not.

A time range across midnight

An element has a reversed range if it has a periodic domain and its maximum is less than its minimum. Then a value is out of range only if it is more than the maximum and less than the minimum. §4.10.5.3.7
