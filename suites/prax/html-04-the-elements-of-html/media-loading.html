HTML · 4.8.11.5 Loading the media resource

Which resource, and from when

If either the media resource or the URL of the current media resource indicate a particular start time, then set the initial playback position to that time and, if jumped is still false, seek to that time. For example, with media formats that support media fragment syntax, the fragment can be used to indicate a start position.
