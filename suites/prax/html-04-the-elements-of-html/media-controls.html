The media controls

The controls attribute indicates that the author has not provided a scripted controller and would like the user agent to provide its own set of controls. HTML §4.8.11.13 The video, clip.mp4, is 160 by 80, two seconds of blue, orange, green and purple.

Controls that work through the DOM, and with scripting disabled

Playing, pausing, seeking and the volume must be implemented in terms of the DOM API described above, so that, e.g., all the same events fire. And the user agent should suppress any user interaction events while the user agent is interacting with this interface. If the attribute is present, or if scripting is disabled for the media element, then the user agent should expose a user interface to the user. Scripting is disabled in a frame sandboxed without allow-scripts.
