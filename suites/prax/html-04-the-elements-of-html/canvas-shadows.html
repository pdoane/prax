HTML · 4.12.5.1.19 Shadows

Canvas shadows

All drawing operations on an object which implements the CanvasShadowStyles interface are affected by the four global shadow attributes. HTML §4.12.5.1.19 Each shape is a blue square of 40, and the shadow color rgb(0 0 0 / 0.5) unless the caption says otherwise.

Offset, blur, and the transform

Copy the alpha component of A to B, offset by shadowOffsetX in the positive x direction. Let σ be half the value of shadowBlur. The offsets are not affected by the current transformation matrix.

When no shadow is drawn

Shadows are only drawn if the opacity component of the alpha component of the shadow color is nonzero and either the shadowBlur is nonzero, or the shadowOffsetX is nonzero, or the shadowOffsetY is nonzero. If the current compositing and blending operator is "copy", then shadows effectively won't render.
