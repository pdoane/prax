The bitmap becomes the canvas's contents

The natural dimensions of the canvas element when it represents embedded content are equal to the dimensions of the element's bitmap. §4.12.5

An opaque context

When an ImageBitmapRenderingContext object has its alpha flag set to false, the contents of the canvas element to which the context is bound are obtained by compositing the context's output bitmap onto an opaque black bitmap of the same size.
