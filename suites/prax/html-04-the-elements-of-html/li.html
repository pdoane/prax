HTML · 4.4.8 The li element

The li element

The li element represents a list item. If its parent element is an ol, ul, or menu element, then the element is an item of the parent element's list, as defined for those elements. HTML §4.4.8

value

The value attribute is used to determine the ordinal value of the list item, when the li's list owner is an ol element. Each item's number is the previous one's plus one, unless it has a value. As a presentational hint, the value sets the list-item counter. §15.3.7

type

As presentational hints, ol[type=a s], li[type=a s] { list-style-type: lower-alpha; } and so on, so an item can have a style of its own. §15.3.7
