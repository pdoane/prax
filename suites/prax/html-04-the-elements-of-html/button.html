HTML · 4.10.6 The button element

The button element

The button element represents a button labeled by its contents. HTML §4.10.6

Labeled by its contents

Its content is phrasing content, and The button element, when it generates a CSS box, is expected to depict a button and to use button layout. §15.5.4

Submit, reset, or nothing

A button (and its value) is only included in the form submission if the button itself was used to initiate the form submission. Without type, a button is a submit button if both the command and commandfor content attributes are not present, and the parent node is not a select element; the page's script cancels the second form's submission. §4.10.6
