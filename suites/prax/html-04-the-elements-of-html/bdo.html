The bdo element

The bdo element represents explicit text directionality formatting control for its children. It allows authors to override the Unicode bidirectional algorithm by explicitly specifying a direction override. HTML §4.5.25

An override

bdo, bdo[dir] { unicode-bidi: isolate-override; } §15.3.5 Every character is laid out in the bdo's direction, whatever its own.
