HTML · 4.11.4 The dialog element

The dialog element

The dialog element represents a transitory part of an application, in the form of a small window ("dialog box"). HTML §4.11.4

Shown only while open

A dialog element without an open attribute specified should not be shown to the user. An open one is centered across its containing block, with a solid border. §15.3.3

show() and close()

show() adds open and runs the dialog focusing steps; close() removes it, returns the focus to the previously focused element and queues a close event. Each fires beforetoggle and queues toggle. §4.11.4
