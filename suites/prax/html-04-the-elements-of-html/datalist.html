HTML · 4.10.8 The datalist element

The datalist element

The datalist element represents a set of option elements that represent predefined options for other controls. HTML §4.10.8

Nothing to see in the page

In the rendering, the datalist element represents nothing and it, along with its children, should be hidden. §4.10.8

Suggestions, and nothing to validate or submit

Each option element that is a descendant of the datalist element, that is not disabled, and whose value is a string that isn't the empty string, represents a suggestion. If an element has a datalist element ancestor, it is barred from constraint validation. Nor is it submitted. §4.10.8 §4.10.22.4
