HTML · 4.16.3 Pseudo-classes

:link and :visited

All a elements that have an href attribute, and all area elements that have an href attribute, must match one of :link and :visited. HTML §4.16.3

One or the other, and neither without href

Here :link is blue, :visited purple, and an a that matches neither is black. Which address counts as visited is the user agent's, within the privacy rules that Other specifications might apply. §4.16.3
