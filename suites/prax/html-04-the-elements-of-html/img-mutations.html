HTML · 4.8.4.3.2 Reacting to DOM mutations

Changing an img

The relevant mutations for an img include The element's src, srcset, or sizes attributes are set, changed, or removed. and The element's src attribute is set to the same value as the previous value. This must set the restart animation flag for the update the image data algorithm.
