HTML · 4.11.1 The details element

The details element

The details element represents a disclosure widget from which the user can obtain additional information or controls. HTML §4.11.1

The summary, and the rest only when open

If present, it indicates that both the summary and the additional information is to be shown to the user. If the attribute is absent, only the summary is to be shown. The marker is a disclosure-closed or disclosure-open triangle. §15.5.5

The user shows and hides it

To honor a request for the details to be shown, the user agent must set the open attribute on the element to the empty string. A toggle event follows each change, and changes in quick succession essentially get coalesced so that only one event is fired. §4.11.1
