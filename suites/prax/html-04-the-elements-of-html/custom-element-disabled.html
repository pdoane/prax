HTML · 4.13.3 Core concepts

Disabled form-associated custom elements

The disabled attribute is used to make the form-associated custom element non-interactive. HTML §4.13.3 The page's x-toggle is form-associated, with tabindex=0; a click toggles it "off" and "on". :disabled makes it dashed and grey.

Not focused, and not clicked

A form control that is disabled must prevent any click events that are queued on the user interaction task source from being dispatched on the element. §4.10.19.5 An actually disabled element is not focusable. §4.15

Told when that changes

When the disabled state of a form-associated custom element is changed, its formDisabledCallback is called, given the new state as an argument. §4.13.6 Its callback here writes "disabled" or "enabled".
