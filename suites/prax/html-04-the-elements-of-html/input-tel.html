HTML · 4.10.5.1.3 Telephone state (type=tel)

Telephone fields

The input element represents a control for editing a telephone number given in the element's value. HTML §4.10.5.1.3

Free-form, and never a type mismatch

Unlike the URL and Email types, the Telephone type does not enforce a particular syntax. Systems that need to enforce a particular format are encouraged to use the pattern attribute. §4.10.5.1.3 Each field is outlined green while it is valid and red while it is not (:valid, :invalid).
