The option element

The option element represents an option in a select element or as part of a list of suggestions in a datalist element. HTML §4.10.10

What an option shows

Its label is its label attribute if not empty, or else its text, with spaces collapsed; a select not in base appearance shows the result of getting an option element's label given the option and true, the text including images' alt. §4.10.10 §15.5.16
