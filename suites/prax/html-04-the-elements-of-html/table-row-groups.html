HTML · 4.9.5 The tbody element

Row groups

The tbody element represents a block of rows that consist of a body of data for the parent table element, if the tbody element has a parent and it is a table. HTML §4.9.5

Blocks of rows

Row groups correspond to tbody, thead, and tfoot elements. §4.9.12 thead { display: table-header-group }, tbody { display: table-row-group }. §15.3.8 These tables collapse their borders, and each group has a 3px orange border.
