HTML · 4.12.4 The slot element

The slot element

The slot element defines a slot. It is typically used in a shadow tree. A slot element represents its assigned nodes, if any, and its contents otherwise. HTML §4.12.4 Each host's shadow tree is a blue frame; the host's own children are bold.

Assigned nodes, or else its contents

Named slots

a slot element with a name attribute creates a named slot to which any element is assigned if that element has a slot attribute whose value matches that name attribute's value
