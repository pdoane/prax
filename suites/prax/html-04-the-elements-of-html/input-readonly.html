HTML · 4.10.5.3.3 The readonly attribute

Read-only controls

The readonly attribute is a boolean attribute that controls whether or not the user can edit the form control. When specified, the element is not mutable. HTML §4.10.5.3.3

Not editable, still a control

The difference between disabled and readonly is that read-only controls can still function, whereas disabled controls generally do not function as controls until they are enabled. §4.10.5.3.3

Barred from constraint validation

If the readonly attribute is specified on an input element, the element is barred from constraint validation. §4.10.5.3.3 Each field is outlined green while it is valid, red while it is not, and not at all while it is neither.
