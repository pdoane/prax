HTML · 4.2.5.3 Pragma directives

Refresh

This pragma acts as a timed redirect. The user agent performs one or more of: navigating when the refresh comes due, giving the user an interface to navigate, or nothing. HTML §4.2.5.3

After two seconds, a new document

After the refresh has come due (as defined below), if the user has not canceled the redirect and, if meta is given, document's active sandboxing flag set does not have the sandboxed automatic features browsing context flag set, then navigate document's node navigable to urlRecord. Each frame holds <meta http-equiv=refresh content="2; url=support/target.html?refreshed"> and the word "waiting". The button loads both frames again.
