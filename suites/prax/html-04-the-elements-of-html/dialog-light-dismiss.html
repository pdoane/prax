HTML · 4.11.5 Dialog light dismiss

Dialog light dismiss

"Light dismiss" means that clicking outside of a dialog element whose closedby attribute is in the Any state will close the dialog element. HTML §4.11.5

Down and up outside the same dialog

The nearest clicked dialog at pointerdown is kept; at pointerup, If sameTarget is false, then return. A press on the backdrop is outside the dialog: clientX and clientY are outside the bounds of target. §4.11.5

Only the topmost dialog closes

Let topmostDialog be the last element of document's open dialogs list. If ancestor is topmostDialog, then return. A click anywhere else, even in another open dialog, requests to close the topmost one. §4.11.5
