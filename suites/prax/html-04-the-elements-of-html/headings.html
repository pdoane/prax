HTML · 4.3.6 The h1, h2, h3, h4, h5, and h6 elements

Headings

These elements represent headings for their sections. These elements have a heading level given by the number in their name. The look of each level is the user agent's style sheet's. HTML §4.3.6 §15.3.6

A size and margins for each level, wherever it is

:heading { font-weight: bold; } :heading(1) { margin-block: 0.67em; font-size: 2.00em; } and so on: 1.5em, 1.17em, 1em, 0.83em, and 0.67em for levels 6 to 9. The stage's text is 10px, and each heading is tinted, with line-height: 1, so that its tint is as tall as its font size.
