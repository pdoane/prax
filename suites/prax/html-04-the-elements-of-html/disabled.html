HTML · 4.10.19.5 Enabling and disabling form controls: the disabled attribute

The disabled attribute

A button, input, select or textarea with disabled is disabled. A form control that is disabled must prevent any click events that are queued on the user interaction task source from being dispatched on the element. HTML §4.10.19.5

No click, and not submitted

The entry list skips a field if field is disabled. §4.10.22.4

Changed all the same

Being disabled does not prevent all modifications to the form control. they could be indirectly modified by user action, e.g., if other non-disabled elements in the control's radio button group were modified. §4.10.19.5
