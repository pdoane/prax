HTML · 4.2.6 The style element

Updating a style block

The user agent must run the update a style block algorithm whenever any of the following conditions occur, which removes the element's style sheet and creates one from its text again. HTML §4.2.6

A change of text, a new sheet

The user agent runs update a style block when The element is not on the stack of open elements of an HTML parser or XML parser, and its children changed steps run. The button appends #grown { background: #6aa36a } to an empty style element, as a text node.

Disconnected, no sheet

It also runs when The element is not on the stack of open elements of an HTML parser or XML parser, and it becomes connected or disconnected, and then If element is not connected, then return. The button removes a style element holding #kept { background: #6aa36a }, or puts it back.
