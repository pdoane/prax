HTML · 4.10.19.6 Form submission attributes

Form submission attributes

The corresponding attributes for form submission that may be specified on submit buttons are formaction, formenctype, formmethod, formnovalidate, and formtarget. When omitted, they default to the values given on the corresponding attributes on the form element. HTML §4.10.19.6

formaction and formtarget

The action of an element is the value of the element's formaction attribute, if the element is a submit button and has such an attribute, or the value of its form owner's action attribute. The form's target is the left frame. §4.10.19.6

formnovalidate

The no-validate state of an element is true if the element is a submit button and the element's formnovalidate attribute is present, or if the element's form owner's novalidate attribute is present, and false otherwise. The textarea is required and empty. §4.10.19.6
