HTML · 4.10.16 The legend element

The legend element

The legend element represents a caption for the rest of the contents of the legend element's parent fieldset element, if any. Each fieldset here has a 4px blue border and 10px inline padding; each legend an orange background. HTML §4.10.16

In the border

If the element has a rendered legend, then the border is expected to not be painted behind the rectangle of the legend's margin box. The space allocated for the element's border on the block-start side is expected to be the element's 'border-block-start-width' or the rendered legend's margin box size in the fieldset's block-flow direction, whichever is greater. §15.3.12

Placed as a block, unless floated

If the computed value of 'inline-size' is 'auto', then the used value is the fit-content inline size. It is positioned in the inline direction as is normal for blocks (e.g., taking into account margins and the 'justify-self' property); legend[align=right i] { justify-self: right; }. A rendered legend's used value of 'float' is 'none'. §15.3.12
