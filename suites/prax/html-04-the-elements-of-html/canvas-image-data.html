Pixel manipulation

The current path, transformation matrix, shadow attributes, global alpha, the clipping region, and current compositing and blending operator must not affect the methods described in this section. HTML §4.12.5.1.16 Each ImageData here is 40 by 40, made by the page with createImageData and filled opaque orange.

Pixels replaced wholesale

putImageData: pixels in the canvas are replaced wholesale, with no composition, alpha blending, no shadows, etc. If a dirty rectangle is provided, only the pixels from that rectangle are painted.

Reading back, past the edge

getImageData: Set the pixels values of imageData for areas of the source rectangle that are outside of the output bitmap to transparent black.
