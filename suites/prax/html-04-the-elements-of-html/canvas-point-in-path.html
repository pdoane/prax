HTML · 4.12.5.1.13 Drawing paths to the canvas

Hit testing a path

isPointInPath Returns true if the given point is in the current default path or the given path, using the given fill rule to determine what points are in the path. isPointInStroke Returns true if the given point would be in the region covered by the stroke of the current default path or the given path, given the current stroke style. HTML §4.12.5.1.13

Where a click lands

The canvas holds a ring, filled light blue with evenodd, and a line stroked light orange, 12 wide. On each click the page asks isPointInPath(ring, x, y, "evenodd") and isPointInStroke(line, x, y) at the click's offset, and draws a dot there: blue where the first is true, orange where the second is, grey where neither. The point is taken in the canvas coordinate space unaffected by the current transformation, and Points on the path itself must be considered to be inside the path.
