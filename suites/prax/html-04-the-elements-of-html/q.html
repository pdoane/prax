The q element

The q element represents some phrasing content quoted from another source. Its quotation marks will be inserted into the rendering by the user agent. HTML §4.5.7

Quotation marks before and after

q::before { content: open-quote; } q::after { content: close-quote; } §15.3.4 Each quote nested in another takes the next pair of marks, and the pairs are those of the element's language, as quotes: auto chooses.
