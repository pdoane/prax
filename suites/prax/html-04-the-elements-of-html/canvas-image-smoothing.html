Image smoothing

imageSmoothingEnabled Returns whether pattern fills and the drawImage() method will attempt to smooth images if their pixels don't line up exactly with the display, when scaling images up. HTML §4.12.5.1.18 The source is a canvas of 4 by 2 pixels, alternating blue and orange like a checkerboard, scaled up 40 times to 160 by 80.

Smoothed, or nearest neighbor

When scaling up, if the imageSmoothingEnabled attribute is set to true, the user agent should attempt to apply a smoothing algorithm; Otherwise, the image must be rendered using nearest-neighbor interpolation. §4.12.5.1.15
