HTML · 4.9.10 The th element

The th element

The th element represents a header cell in a table. HTML §4.9.10 Every cell here is 70px wide, wider than its word.

Bold, and centered

th { font-weight: bold; } User agents are expected to have a rule in their user agent style sheet that matches th elements that have a parent node whose computed value for the 'text-align' property is its initial value, whose declaration block consists of just a single declaration that sets the 'text-align' property to the value 'center'. §15.3.8

Not when the row sets an alignment

The rule matches only when the parent's text-align is its initial value; otherwise the header cell inherits the parent's alignment.
