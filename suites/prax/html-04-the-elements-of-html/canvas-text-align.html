HTML · 4.12.5.1.5 Text styles

Text alignment in a canvas

Text is drawn with its anchor point at the (x, y) given; the anchor is determined by the textAlign and textBaseline values. HTML §4.12.5.1.5 The text is 16px PR Noto Sans; each red line is the x or y given.

textAlign, and the direction

If textAlign is start and direction is 'ltr' the anchor is the left edge of the inline box; direction inherit takes the canvas element's.

textBaseline

top: The em-over baseline, hanging: The hanging baseline, middle: Halfway between the em-over baseline and the em-under baseline, alphabetic: The alphabetic baseline, ideographic: The ideographic-under baseline, bottom: The em-under baseline.
