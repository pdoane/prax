Autonomous custom elements

An autonomous custom element does not have any special meaning: it represents its children. HTML §4.13.3 The page defines x-plain, with no shadow tree, and x-framed, whose constructor attaches a shadow tree: a blue frame round a slot.

No behavior of its own

An autonomous element is not focusable or activated as a control is: simply defining and using an element called taco-button does not mean that such elements represent buttons. §4.13.1.5
