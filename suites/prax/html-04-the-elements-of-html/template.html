HTML · 4.12.3 The template element

The template element

The template element is used to declare fragments of HTML that can be cloned and inserted in the document by script. In a rendering, the template element represents nothing. HTML §4.12.3

Its contents are not drawn

The template contents of a template element are not children of the element itself. template { display: none; } §15.3.1

Clones of the contents are drawn

The page's script clones template.content three times into the list, filling each clone's text.
