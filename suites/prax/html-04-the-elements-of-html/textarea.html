HTML · 4.10.11 The textarea element

The textarea element

The textarea element represents a multiline plain text edit control for the element's raw value. Each textarea here is set in Cousine, whose average character width is its advance, 10px, on 20px lines. HTML §4.10.11

cols and rows

The cols attribute gives the character width, otherwise, it is 20; rows the character height, otherwise, it is 2. Its width is size×avg + sbw, its height the number of lines given by the element's character height, plus the height of a scrollbar. §4.10.11 §15.5.17

Wrapping

In visual renderings, the user agent should wrap the user's input in the rendering so that each line is no wider than this number of characters. textarea { white-space: pre-wrap; }, and wrap=off is a presentational hint setting the element's 'white-space' property to 'pre'. §15.5.17
