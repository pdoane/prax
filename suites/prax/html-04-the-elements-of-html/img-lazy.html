HTML · 4.8.3 The img element

Lazy loading an img

The loading attribute is a lazy loading attribute. Its purpose is to indicate the policy for loading images that are outside the viewport. HTML §4.8.3 It is fetched once it comes within the implementation-defined lazy load scroll margin of the viewport. Each img is 6000px down a scroller; the log lists its load.

Fetched when scrolled to, or when made eager

When the loading attribute's state is changed to the Eager state, the user agent must run these steps, which invoke the img's lazy load resumption steps.
