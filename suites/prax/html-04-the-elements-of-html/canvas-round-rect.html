HTML · 4.12.5.1.6 Building paths

roundRect

roundRect Adds a new closed subpath to the path representing the given rounded rectangle. If a list is provided, the number and order of these radii function in the same way as the CSS 'border-radius' property. HTML §4.12.5.1.6 Each shape is filled blue; its rectangle without corners is outlined in red.

One radius, several, and elliptical corners

Four radii go to upperLeft, upperRight, lowerRight and lowerLeft. When a value r in radii is an object with { x, y } properties, the corresponding corner(s) are drawn as elliptical arcs.

Corners scaled to fit, and flipped

Corner curves must not overlap. Scale all radii to prevent this. When w is negative, the rounded rectangle is flipped horizontally, which means that the radius values that normally apply to the left corners are used on the right and vice versa.
