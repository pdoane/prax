HTML · 4.10.5.1.10 Time state (type=time)

Time controls

The input element represents a control for setting the element's value to a string representing a specific time. HTML §4.10.5.1.10

To the minute, unless the step is finer

The step attribute is expressed in seconds. The default step is 60 seconds. §4.10.5.1.10 Each control is outlined green while it is valid and red while it is not.

Bad input

While the user interface describes input that the user agent cannot convert to a valid time string, the control is suffering from bad input. §4.10.5.1.10
