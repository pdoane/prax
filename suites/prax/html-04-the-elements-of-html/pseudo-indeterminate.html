HTML · 4.16.3 Pseudo-classes

:indeterminate

The :indeterminate pseudo-class must match any element falling into one of the following categories: a checkbox whose indeterminateness is true, a radio button whose radio button group contains no input elements whose checkedness state is true, and progress elements with no value content attribute. HTML §4.16.3

Three kinds of indeterminate

A label's text is green while its control matches :indeterminate, and a progress bar is outlined green. §4.16.3
