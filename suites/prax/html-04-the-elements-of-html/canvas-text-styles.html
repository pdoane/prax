Fonts and spacing in a canvas

Text is laid out in a hypothetical infinitely-wide CSS line box containing a single inline box containing the text, its font and spacing taken from the context. HTML §4.12.5.1.5 In the first card each letter of PR Noto Sans Mono is 0.6em wide, so 10px at calc(50px / 3).

Relative sizes, letter and word spacing

'em' units are interpreted relative to the computed value of the 'font-size' property of the font style source object, the canvas, whose font-size is calc(50px / 3) here.
