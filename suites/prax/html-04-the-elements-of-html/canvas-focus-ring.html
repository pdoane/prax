HTML · 4.12.5.1.14 Drawing focus rings

Focus rings in a canvas

drawFocusIfNeeded(path, element): If element is focused, draws a focus ring around path, following the platform conventions for focus rings. HTML §4.12.5.1.14

A ring for the focused fallback element

If element is not focused or is not a descendant of context's canvas element, then return. Draw a focus ring of the appropriate style along path, following platform conventions. The ring should not be subject to the fill or stroke style or the line styles. The canvas's fallback holds two checkboxes, a and b; the page draws a box and a label for each, then calls drawFocusIfNeeded with the path round them, on every focus, blur and change.
