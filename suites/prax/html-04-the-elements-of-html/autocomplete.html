HTML · 4.10.19.7.2 Processing model

Offering past values

The autocomplete content attribute can be used to hint to the user agent how to, or indeed whether to, provide such a feature. HTML §4.10.19.7.1

on and off

When an element's autofill field name is "off", the user agent should not remember the control's data, and should not offer past values to the user. When an element's autofill field name is not "off", the user agent may store the control's data, and may offer previously stored values to the user. §4.10.19.7.2

What kind of value

When the autofill field name is one of the names of the autofill fields described above, the user agent should provide suggestions that match the meaning of the field name. §4.10.19.7.2
