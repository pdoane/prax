HTML · 4.10.5.1.17 File Upload state (type=file)

File upload controls

The input element represents a list of selected files, each file consisting of a filename, a file type, and a file body (the contents of the file). HTML §4.10.5.1.17

A button, and the names of the files

It renders as an 'inline-block' box containing a span of text giving the filename(s) of the selected files, if any, followed by a button that matches ::file-selector-button. §15.5.11 The engines' developers have agreed that the text should not fix the order, since every browser puts the button first (html#4276).

Choosing files

The input activation behavior for such an element element is to show the picker; the user's choice fires input and change, and a dismissed prompt fires cancel. §4.10.5.1.17
