HTML · 4.10.17 The selectedcontent element

The selectedcontent element

The selectedcontent element reflects the contents of a select element's currently selected option element. HTML §4.10.17

A copy of the selected option

Every time the selected option of a select switches from one option to another, the selectedcontent element removes all of its children and replaces them with a new copy of the DOM structure of the select's selected option element. Each stage's select is in base appearance, its first child a button holding a selectedcontent; Safari's chevron is flagged on the customizable select's page. §4.10.17

Not the label attribute

The option element's label attribute can be used to render a visible label for the option, but the selectedcontent element will not reflect the content of the label attribute. §4.10.17
