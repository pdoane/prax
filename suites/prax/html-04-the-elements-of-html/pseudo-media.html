HTML · 4.16.3 Pseudo-classes

Media pseudo-classes

:playing and :paused match media elements whose paused is false or true; :seeking those that are seeking; :buffering those playing while loading with no more than the current frame; :stalled those buffering whose is currently stalled is true; :muted those that are muted; :volume-locked all of them when the user agent's volume locked is true.
