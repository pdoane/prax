HTML · 4.16.3 Pseudo-classes

:checked

The :checked pseudo-class must match any element falling into one of the following categories: a checkbox or a radio button whose checkedness is true, and an option whose selectedness is true. HTML §4.16.3

Checkedness and selectedness

A label's text is green while its control matches :checked, and so is an option that matches it. §4.16.3
