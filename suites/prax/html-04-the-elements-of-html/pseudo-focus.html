HTML · 4.16.3 Pseudo-classes

:focus

For the purposes of the CSS :focus pseudo-class, an element has the focus when it is not itself a navigable container, and it is in the current focus chain of the top-level traversable, or its shadow root is the root of an element that has the focus. HTML §4.16.3
