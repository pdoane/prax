HTML · 4.16.3 Pseudo-classes

:user-valid and :user-invalid

:user-valid and :user-invalid match input, textarea, and select elements whose user validity is true and that do, or do not, satisfy their constraints. HTML §4.16.3

After the user commits a change

User validity starts false. It becomes true when the user commits a change, or leaves a field whose value they changed. Borders: green :user-valid, orange :user-invalid, grey neither. §4.10.18.1

After an attempt to submit

Submitting a form sets the user validity of each of its submittable elements to true. §4.10.22.3
