HTML · 4.10.19.3 Limiting user input length: the maxlength attribute

The maxlength attribute

A form control maxlength attribute, controlled by the dirty value flag, declares a limit on the number of characters a user can input. Each textarea here has maxlength=10. HTML §4.10.19.3

Typing stops at the limit

User agents may prevent the user from causing the element's API value to be set to a value whose length is greater than the element's maximum allowed value length. §4.10.19.3

Too long, only after a user edit

If an element has a maximum allowed value length, its dirty value flag is true, its value was last changed by a user edit (as opposed to a change made by a script), and the length of the element's API value is greater than the element's maximum allowed value length, then the element is suffering from being too long. The page's script sets the textarea's value to 14 characters. §4.10.19.3
