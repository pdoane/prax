HTML · 4.10.5.1.5 Email state (type=email)

Email fields

How the Email state operates depends on whether the multiple attribute is specified or not. HTML §4.10.5.1.5

One address

While the value of the element is neither the empty string nor a single valid email address, the element is suffering from a type mismatch. §4.10.5.1.5 Each field is outlined green while it is valid and red while it is not.

A list of addresses

With multiple, the value is split on commas, each address stripped of whitespace, and joined separating each value from the next by a single U+002C COMMA character (,). §4.10.5.1.5
