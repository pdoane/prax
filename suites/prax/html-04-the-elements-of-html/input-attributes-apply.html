HTML · 4.10.5.3 Common input element attributes

Attributes that do not apply

When an attribute doesn't apply to an input element, user agents must ignore the attribute, regardless of the requirements and definitions below. HTML §4.10.5.3

Ignored, though present

Each state lists the attributes that apply to it. readonly does not apply to a checkbox: Only text controls can be made read-only, since for other controls (such as checkboxes and buttons) there is no useful distinction between being read-only and being disabled. §4.10.5.3.3 Each control is outlined green while it is valid and red while it is not.
