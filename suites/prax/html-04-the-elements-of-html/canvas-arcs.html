HTML · 4.12.5.1.6 Building paths

Arcs and ellipses

A path has a list of zero or more subpaths. Each subpath consists of a list of one or more points, connected by straight or curved line segments, and a flag indicating whether the subpath is closed or not. HTML §4.12.5.1.6 Every path is stroked blue, 3 wide; red marks the points the methods were given.

Arcs and ellipses

arc and ellipse add their arc, going counterclockwise if counterclockwise is true, and clockwise otherwise, after a straight line from the last point in the subpath to the start point of the arc.
