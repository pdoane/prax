HTML · 4.8.5 The iframe element

The iframe element

The iframe element represents its content navigable. HTML §4.8.5 doc.html is green, with its name at its top left.

A document from src, or from srcdoc

The srcdoc attribute gives the content of the page that the element's content navigable is to contain. If the src attribute and the srcdoc attribute are both specified together, the srcdoc attribute takes priority. Descendants of iframe elements represent nothing.

300 by 150, in a 2px inset border

The iframe is expected to be treated as a replaced element, with the rule iframe { border: 2px inset; }. §15.4.1 Without natural dimensions, a replaced element is 300 by 150. CSS 2 §10.3.2
