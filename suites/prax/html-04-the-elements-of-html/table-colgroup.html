The colgroup element

The colgroup element represents a group of one or more columns in the table that is its parent, if it has a parent and that is a table element. HTML §4.9.3 The cells have no background, so a column group's shows through them.

A span of columns

If the colgroup element contains no col elements, then the element may have a span content attribute specified §4.9.3 the colgroup element, if it contains no col element, is expected to be treated as if it had as many such children as its span attribute specifies. §15.3.8

Columns of its own

When the colgroup has any col element children, each col gives columns, and all the last columns in the table from x=xstart to x=xwidth-1 form a new column group: the span attribute has no part in it. §4.9.12.1
