HTML · 4.16.3 Pseudo-classes

:read-only and :read-write

:read-write matches mutable inputs to which readonly applies, textareas that are neither readonly nor disabled, and elements that are editing hosts or editable and are neither input elements nor textarea elements. The :read-only pseudo-class must match all other HTML elements. HTML §4.16.3
