Interactive validation

Submitting a form validates it: Report the problems with the constraints of at least one of the elements given in unhandled invalid controls to the user. HTML §4.10.21.2

Reported, and not submitted

An invalid event at each invalid control, in tree order; User agents may focus one of those elements. Both fields are required, the select's first option a placeholder. §4.10.21.2

Handled by the page

If notCanceled is true, then add field to unhandled invalid controls. The page's script cancels the invalid event at the first field and outlines it in red instead. §4.10.21.2
