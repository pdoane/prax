HTML · 4.10.19.2 Submitting element directionality: the dirname attribute

The dirname attribute

The dirname attribute on a form control element enables the submission of the directionality of the element, and gives the name of the control that contains this value during form submission. HTML §4.10.19.2

The direction of what was typed

In the entry list, Let dir be the string "ltr" if the directionality of the element is 'ltr', and "rtl" otherwise, an entry named by dirname. Each textarea has dir=auto, so its text sets its directionality. §4.10.22.4
