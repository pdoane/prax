HTML · 4.16.3 Pseudo-classes

:hover

The :hover pseudo-class matches an element while the user designates an element with a pointing device: an element that the user indicates using a pointing device. HTML §4.16.3

Ancestors, and a label's control

Additionally, any element that is the labeled control of a label element that is currently matching :hover, also matches :hover. (But, it does not count as being designated.) The fragment is the specification's: <p> <label for=c> <input id=a> </label> <span id=b> <input id=c> </span> </p>. Each element's border turns green while it matches :hover. §4.16.3
