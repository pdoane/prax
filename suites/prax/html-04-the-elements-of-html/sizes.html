HTML · 4.8.4.2.2 Sizes attributes

sizes: the width an image is laid out at

The <source-size-value> gives the intended layout width of the image. The author can specify different widths for different environments with <media-condition>s. HTML §4.8.4.2.2 Each img has one candidate, an orange image 160 by 80 described as 160w, whose density is the width descriptor value divided by source size. §4.8.4.3.12

A width, chosen by media condition

The first size whose <media-condition> is true, or a last one without a condition. §4.8.4.3.11

No sizes: 100vw
