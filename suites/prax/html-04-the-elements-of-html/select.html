HTML · 4.10.7 The select element

Drop-down box and list box

The select element represents a control for selecting amongst a set of options. A select element is either a list box or a drop-down box, depending on its attributes. HTML §4.10.7 §15.5.16

The display size decides

Without size, the element's display size is 4 if the element's multiple content attribute is present, and 1 otherwise. Without multiple, it is expected to render as a single-select drop-down box if its display size is 1, or as a single-select list box if its display size is greater than 1. §4.10.7

A placeholder label option

In a required drop-down box, a first option whose value is empty is its placeholder label option: the user agent is expected to render that option in a manner that conveys that it is a label, rather than a valid option of the control. §15.5.16
