HTML · 4.8.1 The picture element

The picture element

The picture element is a container which provides multiple sources to its contained img element to allow authors to declaratively control or give hints to the user agent about which image resource to use It represents its children. HTML §4.8.1 The img's own src is a blue image 80 by 40; the sources offer an orange one, 160 by 80 at 2x, so 80 by 40 too.

The img draws, from a source's image

The image given by the src and srcset attributes, and any previous sibling source elements' srcset attributes if the parent is a picture element, is the embedded content §4.8.3

The picture draws nothing of its own

the picture element itself does not display anything; it merely provides a context for its contained img element that enables it to choose from multiple URLs. The source element does not represent anything on its own. §4.8.2
