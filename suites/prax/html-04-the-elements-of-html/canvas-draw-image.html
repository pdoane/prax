Drawing images

drawImage paints the region of the image argument specified by the source rectangle on the region of the rendering context's output bitmap specified by the destination rectangle. HTML §4.12.5.1.15 The image is the 40 by 20 flag.

The three forms, and clipped sources

When the source rectangle is outside the source image, the source rectangle must be clipped to the source image and the destination rectangle must be clipped in the same proportion.

No natural size, and a canvas onto itself

No natural size: the default object size being the size of the output bitmap. Onto itself: the source to be copied before the image is drawn.
