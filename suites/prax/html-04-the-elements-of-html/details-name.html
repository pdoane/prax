HTML · 4.11.1 The details element

Exclusive accordions

The name content attribute gives the name of the group of related details elements that the element is a member of. Opening one member of this group causes other members of the group to close. HTML §4.11.1

Opening one closes the open one

When open is added, the user agent must ensure details exclusivity by closing other elements if needed. §4.11.1

A member that arrives open, while another is open, closes

On insertion, the user agent must ensure details exclusivity by closing the given element if needed, even when an attribute or element is inserted via the parser. §4.11.1
