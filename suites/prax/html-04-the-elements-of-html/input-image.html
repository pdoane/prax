Image buttons

The input element represents either an image from which a user can select a coordinate and submit the form, or alternatively a button from which the user can submit the form. HTML §4.10.5.1.19

A coordinate on the image

A click submits the coordinate as two entries, the name with ".x" and ".y" appended, from the image's edge, reaching into its border and padding: −(borderleft+paddingleft) ≤ x. §4.10.5.1.19

Without its image, a button
