HTML · 4.10.5.1.20 Reset Button state (type=reset)

Reset buttons

The input element represents a button that, when activated, resets the form. HTML §4.10.5.1.20

Back to the defaults

If the element has a value attribute, the button's label must be the value of that attribute; otherwise, it must be an implementation-defined string that means "Reset" or some such. Resetting an input sets its value back to its value attribute and its checkedness to its checked attribute. §4.10.5.1.20 §4.10.5
