HTML · 4.3.11.1 Heading levels & offsets

Heading offsets

The headingoffset content attribute allows authors to offset heading levels for descendants. A heading's level is its number plus the offsets of its inclusive ancestors, If level is greater than 9, then return 9. The user agent's style sheet sizes it by its level: 2em, 1.5em, 1.17em, 1em, 0.83em, then 0.67em. HTML §4.3.11.1 §15.3.6

Offsets add up

The stages' text is 10px; each heading is tinted, with line-height: 1, so its tint is as tall as its font size, and its margins are set to 10px. Elements with the attributes are outlined.

Where the offset stops

If inclusiveAncestor is an HTML element and has a headingreset attribute, then return offset. If inclusiveAncestor's parent is a shadow root, then set inclusiveAncestor to that shadow root's host and continue.
