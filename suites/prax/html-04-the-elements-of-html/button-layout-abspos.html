HTML · 4.10.6 The button element

Absolutely positioned buttons

A button element is expected to depict a button and to use button layout. HTML §15.5.3

Absolutely positioned

If the element is absolutely-positioned, then for the purpose of the CSS visual formatting model, act as if the element is a replaced element. §15.5.3 Since, the CSS Working Group resolved that Semi-replaced elements stretch in both directions in abspos (csswg-drafts#6789).
