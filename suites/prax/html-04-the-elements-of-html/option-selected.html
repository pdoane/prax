HTML · 4.10.10 The option element

The selected attribute

The selected attribute is a boolean attribute. It represents the default selectedness of the element. HTML §4.10.10

Dirtiness

The dirtiness of an option element is a boolean state, initially false. It controls whether adding or removing the selected content attribute has any effect. Picking an option sets its dirtiness. §4.10.10

Reset to the default

A select's reset algorithm: If optionElement has a selected attribute, then set optionElement's selectedness to true; otherwise set it to false. Set optionElement's dirtiness to false. §4.10.7
