HTML · 4.12.5.1.17 Compositing

Global alpha and compositing

Objects that implement the CanvasCompositing interface have a global alpha value and a current compositing and blending operator value that both affect all the drawing operations on this object. HTML §4.12.5.1.17 Each operator is walked in Compositing and Blending's pages; these show that every kind of drawing takes them.

Global alpha

The global alpha value gives an alpha value that is applied to shapes and images before they are composited onto the output bitmap. Each canvas has blue and orange stripes 20 wide behind what is drawn.

The operator, for every drawing

The current compositing and blending operator value controls how shapes and images are drawn onto the output bitmap, once they have had the global alpha and the current transformation matrix applied.
