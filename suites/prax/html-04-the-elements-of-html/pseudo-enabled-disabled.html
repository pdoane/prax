HTML · 4.16.3 Pseudo-classes

:enabled and :disabled

The :enabled pseudo-class must match any button, input, select, textarea, optgroup, option, fieldset element, or form-associated custom element that is not actually disabled. The :disabled pseudo-class must match any element that is actually disabled. HTML §4.16.3

Enabled, disabled, or neither

Outlines: green :enabled, orange :disabled, grey neither. §4.16.3
