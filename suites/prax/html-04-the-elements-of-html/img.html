HTML · 4.8.3 The img element

The img element

What an img element represents depends on the src attribute and the alt attribute. HTML §4.8.3 missing.png does not exist. Brackets show where each img is.

Without the image: the alt text, or nothing

Alt text is drawn as a non-replaced phrasing element whose content is the text, optionally with an icon indicating that an image is missing; nothing, as a replaced element whose natural dimensions are 0. §15.4.2

Alt text is text, not a box

A non-replaced phrasing element takes no width or height from the dimension attributes. §15.4.2
