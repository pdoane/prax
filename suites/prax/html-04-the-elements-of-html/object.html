HTML · 4.8.7 The object element

The object element

The object element can represent an external resource, which, depending on the type of the resource, will either be treated as an image or as a child navigable. HTML §4.8.7 Each object's fallback content is an orange "fallback".

An image, or a document

A type that starts with image/: The object element represents the specified image. Otherwise, as for HTML: The object element represents its content navigable. The element's contents are not part of what the object element represents.

Its children, when the resource cannot be shown

Fallback: The object element represents the element's children. This is the element's fallback content. It follows If the load failed (e.g. there was an HTTP 404 error, there was a DNS error), an image that cannot be rendered, a type not supported, and an object with no data.
