Which controls, which values, and formdata

A control is skipped if it is disabled, if it is a button but it is not submitter, if it is an unchecked checkbox or radio button, or if it has no name. A select adds each option element in the select element's list of options whose selectedness is true and that is not disabled; a checkbox without value, the string on.
