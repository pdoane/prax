HTML · 4.6.2 Links created by a and area elements

Activating a hyperlink

The activation behavior of an a or area element element given an event event is: to return if it has no href, else to download the hyperlink if it has a download attribute, and otherwise to follow it. HTML §4.6.2

With an href, and without

If element has no href attribute, then return. Each frame holds a link to support/target.html, which says "target.html" on green, and the query it was given.

A server-side image map

If element is an a element, and event's target is an img with an ismap attribute specified, the link is followed with the concatenation of U+003F (?), the value of x expressed as a base-ten integer using ASCII digits, U+002C (,), and the value of y, the click's distance from the image's left and top edges.
