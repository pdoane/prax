HTML · 4.12.5.1.13 Drawing paths to the canvas

Clipping

clip Further constrains the clipping region to the current default path or the given path, using the given fill rule to determine what points are in the path. When the context is initialized, its current clipping region must be set to the largest infinite surface (i.e. by default, no clipping occurs). HTML §4.12.5.1.13 In each figure the page clips, then fills the whole canvas with blue and orange stripes 10 wide.

A region that only narrows

The clip steps create a new clipping region by calculating the intersection of context's current clipping region and the area described by the intended path.

Fill rules, and open subpaths

Open subpaths must be implicitly closed when computing the clipping region, without affecting the actual subpaths.
