HTML · 4.8.15 MathML

MathML that its elements do not allow

The semantics of MathML elements are defined by MathML and other applicable specifications. HTML §4.8.15 Each stage sets its text at 20px.

Text and contents that MathML does not allow

User agents must handle text other than inter-element whitespace found in MathML elements whose content models do not allow straight text by pretending for the purposes of MathML content models, layout, and rendering that the text is actually wrapped in a MathML mtext element. User agents must act as if any MathML element whose contents does not match the element's content model was replaced, for the purposes of MathML layout and rendering, by a MathML merror element containing some appropriate error message.

Since, MathML's group resolved that such an element is laid out as an mrow instead, which MathML Core now says (mathml-core#136).
