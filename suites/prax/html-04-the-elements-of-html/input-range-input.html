HTML · 4.10.5.1.13 Range state (type=range)

Moving a range's thumb

In this state, the range and step constraints are enforced even during user input, and there is no way to set the value to the empty string. HTML §4.10.5.1.13

input as it moves, change when it is committed

The input event fires whenever the user has modified the data of the control. The change event fires when the value is committed, if that makes sense for the control, or else when the control loses focus. Dragging the knob commits when the user lets go. Whether a key commits is the control's own: HTML's example of a change without a commit step is a slider moved by the keyboard, whose corresponding change event, if any, will be fired when the control loses focus, but an example decides nothing. §4.10.5.5
