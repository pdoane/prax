HTML · 4.6.8.1 Link type "alternate"

Alternative style sheets

The alternate keyword modifies the meaning of the stylesheet keyword in the way described for that keyword. If the alternate keyword is also specified on the link element, then the link is an alternative style sheet, whose CSS style sheet has its alternate flag Set if the link is an alternative style sheet and el's explicitly enabled is false; unset otherwise.
