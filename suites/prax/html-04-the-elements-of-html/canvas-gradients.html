HTML · 4.12.5.1.10 Fill and stroke styles

Canvas gradients

Before the first stop, the color must be the color of the first stop. After the last stop, the color must be the color of the last stop. When there are no stops, the gradient is transparent black. HTML §4.12.5.1.10 Each gradient runs from blue to orange and fills the whole canvas; red marks its points.

Linear

If multiple stops are added at the same offset on a gradient, then they must be placed in the order added.

Radial and conic

Radial: a cone, touched by the two circles, areas outside the cone untouched. Conic: conic-gradient(from adjustedStartAnglerad at xpx ypx, angularColorStopList), adjustedStartAngle is given by startAngle + π/2.
