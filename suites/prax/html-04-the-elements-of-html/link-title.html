HTML · 4.2.4 The link element

The link element's title

The title attribute gives the title of the link. With one exception, it is purely advisory. HTML §4.2.4

Titles name style sheet sets

The exception is for style sheet links that are in a document tree, for which the title attribute defines CSS style sheet sets. The first titled set is the preferred one, and sheets of other titles are not applied. Each frame is a document of its own.
