HTML · 4.12.5.1.12 Drawing text to the bitmap

Drawing text

The fillText(text, x, y, maxWidth) and strokeText(text, x, y, maxWidth) methods render the given text at the given (x, y) coordinates ensuring that the text isn't wider than maxWidth if specified, using the current font, textAlign, and textBaseline values. HTML §4.12.5.1.12 The font is PR Noto Sans; red lines mark the x and y given.

Fill, stroke, and a maximum width

For strokeText(), the reverse holds. Text wider than maxWidth takes a more condensed font or a smaller font.

White space, and the measured box

Replace all ASCII whitespace in text with U+0020 SPACE characters. actualBoundingBoxAscent: The distance from the horizontal line indicated by the textBaseline attribute to the top of the bounding rectangle.
