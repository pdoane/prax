HTML · 4.10.20 APIs for the text control selections

The selection in a text control

All input elements to which these APIs apply, and all textarea elements, have either a selection or a text entry cursor position at all times HTML §4.10.20

Setting the selection

Set the selection of the text control to the sequence of code units within the relevant value starting with the code unit at the startth position (in logical order) and ending with the code unit at the (end-1)th position. If that changes the selection, fire an event named select at the element. Each button then focuses the textarea. §4.10.20

Replacing a range

setRangeText() replaces the text from start to end; its last argument determines how the selection will be set after the text has been replaced. Each button puts "The quick brown fox" back, selects "brown", replaces "quick" with "slow", and focuses the textarea. §4.10.20
