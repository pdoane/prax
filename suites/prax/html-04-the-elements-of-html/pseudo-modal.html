HTML · 4.16.3 Pseudo-classes

:modal

The :modal pseudo-class must match any element falling into one of the following categories: dialog elements whose is modal is true, and elements whose fullscreen flag is true. HTML §4.16.3

A modal dialog, not one shown

A border is orange, and green while its element matches :modal. §4.16.3

A fullscreen element

An element whose fullscreen flag is true matches it too. §4.16.3
