HTML · 4.10.21.3 The constraint validation API

reportValidity() and custom errors

Returns true if the element's value has no validity problems; otherwise, returns false, fires an invalid event at the element, and (if the event isn't canceled) reports the problem to the user. HTML §4.10.21.3

A custom error, and its message

When its value is not the empty string, the element is suffering from a custom error. The user agent should use the custom validity error message when alerting the user to the problem with the control. §4.10.21.1
