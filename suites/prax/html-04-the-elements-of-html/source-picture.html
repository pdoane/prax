HTML · 4.8.2 The source element

The source element in a picture

The source element allows authors to specify multiple alternative source sets for img elements HTML §4.8.2 The img's src is a blue image 80 by 40; each source offers an orange one, 160 by 80 at 2x, so 80 by 40 too.

media: skipped where it does not match

The user agent will skip to the next source element if the value does not match the environment.

type: skipped where the type is not supported

The type attribute gives the type of the images in the source set, to allow the user agent to skip to the next source element if it does not support the given type.
