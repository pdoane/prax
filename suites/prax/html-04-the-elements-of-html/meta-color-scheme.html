HTML · 4.2.5.1 Standard metadata names

Metadata name color-scheme

To aid user agents in rendering the page background with the desired color scheme immediately (rather than waiting for all CSS in the page to load), a 'color-scheme' value can be provided in a meta element. Its value determines the page's supported color-schemes. HTML §4.2.5.1

The first one in the document tree

The candidates are the meta elements in tree order where the element is in a document tree, and the first valid value is returned. Each frame's document holds "Text and a link"; its frame has color-scheme: light, which the document takes as its preference. CSS Color Adjustment 1 §2.1

Run again when one is inserted or removed

If any meta elements are inserted into the document or removed from the document, or existing meta elements have their name or content attributes changed, user agents must re-run the above algorithm. The button inserts <meta name=color-scheme content=dark> into the frame's head, or removes it.
