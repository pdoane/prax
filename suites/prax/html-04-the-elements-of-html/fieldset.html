HTML · 4.10.15 The fieldset element

The fieldset element

The fieldset element represents a set of form controls (or other content) grouped together, optionally with a caption. HTML §4.10.15

Disabled, all but the legend

The disabled attribute, when specified, causes all the form control descendants of the fieldset element, excluding those that are descendants of the fieldset element's first legend element child, if any, to be disabled. The page's script sets the fieldset's disabled from the checkbox. §4.10.15

Nested

A fieldset is a disabled fieldset if It is a descendant of another fieldset element whose disabled attribute is specified, and it is not a descendant of that fieldset element's first legend element child, if any. §4.10.15
