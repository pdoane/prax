HTML · 4.11.4 The dialog element

closedby

The closedby content attribute is an enumerated attribute that says which user actions close the dialog. HTML §4.11.4

Modal dialogs

any: Close requests or clicks outside close the dialog. closerequest: Close requests close the dialog. none: No user actions automatically close the dialog. §4.11.4

Dialogs that are not modal

With no attribute, the state is Auto, which is Close Request when the dialog is modal, and otherwise None. §4.11.4
