Customized built-in elements

A customized built-in element inherits the semantics of the element that it extends. HTML §4.13.3 all of the ways in which button is special apply to such "plastic buttons" as well: their focus behavior, ability to participate in form submission, the disabled attribute, and so on. §4.13.1.4

A button that counts

The page defines x-counter with {extends: "button"}; its constructor sets the button's text to "clicked 0 times" and adds one on each click. The stage holds <button is=x-counter id=counter>not upgraded</button>, then the same with disabled.
