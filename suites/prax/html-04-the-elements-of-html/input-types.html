HTML · 4.10.5 The input element

The input element's types

The input element represents a typed data field, usually with a form control to allow the user to edit the data. The type attribute controls the data type (and associated control) of the element. HTML §4.10.5

A control for each type

Each row is <input type=…> with no other attribute but a value where the type shows one. The control types are the standard's table's; how each looks is the browser's.
