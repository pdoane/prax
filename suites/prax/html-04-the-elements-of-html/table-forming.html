Forming a table

To determine which elements correspond to which slots in a table associated with a table element, to determine the dimensions of the table (xwidth and yheight), and to determine if there are any table model errors, user agents must use the following algorithm HTML §4.9.12.1 Cells that span are orange.

Each cell takes the next free slot

Cells: While xcurrent is less than xwidth and the slot with coordinate (xcurrent, ycurrent) already has a cell assigned to it, increase xcurrent by 1.

The grid grows to the widest row

If xwidth < xcurrent+colspan, then let xwidth be xcurrent+colspan.
