The hr element

The hr element represents a paragraph-level thematic break, e.g., a scene change in a story, or a transition to another topic within a section of a reference book. HTML §4.4.2

A gray inset line

hr { color: gray; border-style: inset; border-width: 1px; margin-block: 0.5em; margin-inline: auto; overflow: hidden; } §15.3.11 The stage's text is 10px on 20px lines.

Its old attributes

The obsolete attributes are presentational hints: The width attribute on an hr element maps to the dimension property 'width' on the element. hr[align=left i] { margin-left: 0; margin-right: auto; } hr[color], hr[noshade] { border-style: solid; } With noshade or color, size divided by two is each border's width; without, size minus two is the height.
