HTML · 4.10.5.1.15 Checkbox state (type=checkbox)

Checkboxes

The input element represents a two-state control that represents the element's checkedness state. HTML §4.10.5.1.15

A click toggles it, then input and change

A click toggles the checkedness before it is dispatched; then the input activation behavior is to Fire an event named input, then Fire an event named change. §4.10.5.1.15

Indeterminate

If the element's indeterminateness is true, then the control's selection should be obscured. A click toggles the checkedness and set this element's indeterminateness to false. §4.10.5 The page's script sets indeterminate on both boxes at load.
