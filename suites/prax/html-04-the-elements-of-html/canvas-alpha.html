HTML · 4.12.5.1.2 The canvas settings

An opaque canvas

When a CanvasSettings object's alpha is false, then its alpha component must be fixed to 1.0 (fully opaque) for all pixels, and attempts to change the alpha component of any pixel must be silently ignored. HTML §4.12.5.1.2 Each canvas is 160 by 60; the first three are created with getContext("2d", {alpha: false}).

Opaque black, and opaque after every operation

Thus, the bitmap of such a context starts off as opaque black instead of transparent black; clearRect() always results in opaque black pixels drawing a 50% transparent white square on a freshly created output bitmap with its alpha set to false will result in a fully-opaque gray square.
