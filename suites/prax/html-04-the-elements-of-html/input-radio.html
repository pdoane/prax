HTML · 4.10.5.1.16 Radio Button state (type=radio)

Radio buttons

The input element represents a control that, when used in conjunction with other input elements, forms a radio button group in which only one control can have its checkedness state set to true. HTML §4.10.5.1.16

Who is in a group

Two radio buttons share a group when they have the same form owner, or none, are in the same tree, and have the same non-empty name; checking one sets the checkedness state of all the other elements in the same radio button group to false. §4.10.5.1.16

Checked as they are inserted, and required

Becoming connected is one of those phenomena. If an element in the radio button group is required, and all of the input elements in the radio button group have a checkedness that is false, then the element is suffering from being missing. §4.10.5.1.16
