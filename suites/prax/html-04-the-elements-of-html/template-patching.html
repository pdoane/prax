HTML · 4.12.3 The template element

Patching content with template

The for content attribute identifies the ProcessingInstruction that marks the location at which to insert content (<?marker>) or the start of the range to replace (<?start>). HTML §4.12.3 In each figure the template comes after the dashed box, later in the stage.

Content inserted at a marker

When the parser meets a template with for, it prepares content patching, and the template's content goes to the marker's place instead of into the template. §13.2.6.4.4

A range replaced

The content between <?start name="recommended"> and <?end> is replaced with the template contents.
