HTML · 4.8.4.3.7 Selecting an image source

Choosing among candidates

In an implementation-defined manner, choose one image source from sourceSet. HTML §4.8.4.3.7 Blue is 80 by 40; orange and green are 160 by 80.

Any candidate, each at its density

Which candidate is the user agent's choice, typically by the display's pixel ratio, but whichever it takes is drawn at its own density, so these are 80 by 40 either way.

A repeated density: the later candidate is dropped

If an entry b in sourceSet has the same associated pixel density descriptor as an earlier entry a in sourceSet, then remove entry b. This leaves no choice.
