HTML · 4.16.3 Pseudo-classes

:default

The :default pseudo-class must match any element falling into one of the following categories: Submit buttons that are default buttons of their form owner, inputs that have a checked attribute, and option elements that have a selected attribute. HTML §4.16.3

What the markup chose, whatever the user does
