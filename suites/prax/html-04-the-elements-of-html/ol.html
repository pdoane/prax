The ol element

The ol element represents a list of items, where the items have been intentionally ordered, such that changing the order would change the meaning of the document. HTML §4.4.5

type

User agents should render the items of the list in a manner consistent with the state of the type attribute of the ol element. Numbers less than or equal to zero should always use the decimal system regardless of the type attribute. As presentational hints, ol[type=a s], li[type=a s] { list-style-type: lower-alpha; } and so on. §15.3.7
