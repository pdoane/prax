The viewport's scroll origin

The root viewport, which scrolls the page canvas, uses the principal writing mode for determining its scroll origin and initial scroll position. CSS Overflow 3 §2.3

From the body, through the root

The principal writing mode is the body's where the root's is not set otherwise. CSS Writing Modes 4 §8
