CSS Overflow 4 · 5.3.1 Line-clamp containers, floats

Floats in a line-clamp container

A line-clamp container is an independent block formatting context that additionally follows the rules in this section. A clamp point is its start, a point between two consecutive line boxes, or A point between two in-flow block-level sibling boxes. CSS Overflow 4 §5.3.1

Floats

floats which have not been made into visually suppressed boxes must be visually clipped to the unshaped block-end content edge of the line-clamp container. They do not introduce any clearance that would make the line-clamp container increase its height, and do not contribute to the scrollable overflow area. CSS Overflow 4 §5.3.1
