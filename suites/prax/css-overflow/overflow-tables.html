CSS Overflow 3 · 1.2 Module Interactions

Overflow on tables: the table grid box

When applied to display: table elements, the properties defined in this module apply to the table grid box (not the table wrapper box). CSS Overflow 3 §1.2

The grid clips; the caption is outside it

Each table has a blue 2px border, table-layout: fixed, 100px wide, a single cell holding a 150px wide A, and a caption whose text, on one line, is longer than the table is wide; the text is in a block of no width, so it does not widen the table. The caption belongs to the wrapper box, beside the grid box.
