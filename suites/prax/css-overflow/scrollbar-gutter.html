CSS Overflow 3 · 5.2 Reserving space for the scrollbar: the scrollbar-gutter property

scrollbar-gutter: auto, stable, both-edges

scrollbar-gutter: auto | stable && both-edges? The space between the inner border edge and the outer padding edge which user agents may reserve to display the scrollbar is called the scrollbar gutter. In the case of overlay scrollbars, no scrollbar gutter is present. CSS Overflow 3 §5.2

A gutter with nothing to scroll

Each box is 120 by 40, overflow: auto, tinted blue, and holds a white child 20px tall that fits, so there is no scroll bar. A gutter must be painted as an extension of the padding, so it shows blue beside the child. The boxes are styled with ::-webkit-scrollbar: Safari draws classic scroll bars 12px wide; Firefox draws overlay ones, which make no gutter, so its children all fill the box; Chrome draws none in these stills, its bars taking no room, yet reserves a 12px gutter for stable.
