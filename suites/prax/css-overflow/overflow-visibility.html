CSS Overflow 3 · 3.1.1 Interaction of visibility and overflow

A hidden scroll container

If visibility is hidden and overflow is scroll or auto: The user agent must not make any scrolling mechanism visible. To the extent that the scrolling mechanism that would normally be visible in the absence of visibility: hidden affects layout, it continues to do so, but is not painted. CSS Overflow 3 §3.1.1

No scroll bar, the same layout

Each box (its border drawn by a wrapper) is 120 by 40, overflow: scroll, styled with ::-webkit-scrollbar, and holds a blue child, visibility: visible, 80px tall. Safari draws classic scroll bars 12px wide here; Chrome and Firefox draw overlay ones, which take no room, so in both figures their child fills the box's width.

Scripts still scroll it

As would be the case with overflow: hidden, scrolling directly triggered by user interactions is disabled, but programmatic scrolling continues to take effect. CSS Overflow 3 §3.1.1 The box holds A, B and C, each visibility: visible; a script sets scrollTop = 20.
