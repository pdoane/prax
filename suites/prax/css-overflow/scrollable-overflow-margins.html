CSS Overflow 3 · 3.3 Calculating the Scrollable Overflow Area, margins

The scrollable overflow area: margins

The area unites The margin areas of grid item and flex item boxes for which the box establishes a containing block. The UA may additionally include the margin areas of other boxes for which the box establishes a containing block; however, the conditions under which such margin areas are included is undefined in this level. CSS Overflow 3 §3.3

Flex and grid items: margins included

Each dashed box is 120 by 40, overflow: auto, with no padding, and holds A 160px wide with a 40px right margin, and a 20px bottom margin in the second row. Captions read scrollWidth and scrollHeight.

Block boxes: undefined

The same A in a block container: the user agent may count its margin or not, and either is right.
