CSS Overflow 3 · 6.1.5 ellipsis interaction with scrolling interfaces

The ellipsis in a scroll container

If a non-clip text-overflow is set, then as more content is scrolled into view, implementations should show whatever additional content fits, only truncating content which would otherwise be clipped (or is necessary to make room for the ellipsis/string), until the element is scrolled far enough to display the edge of the content at which point that content should be displayed rather than an ellipsis/string.
