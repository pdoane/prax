line-clamp

line-clamp: none | [<'max-lines'> || <'block-ellipsis'>] -webkit-legacy? It allows limiting the contents of a block container to the specified number of lines; remaining content is fragmented away and neither rendered nor measured. Optionally, it also allows inserting content into the last line box to indicate the continuity of truncated/interrupted content. CSS Overflow 4 §5.1
