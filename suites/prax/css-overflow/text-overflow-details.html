CSS Overflow 3 · 6.1.2 ellipsing details

The ellipsis: rendering only

Ellipsing only affects rendering and must not affect layout nor dispatching of pointer events. CSS Overflow 3 §6.1.2

Styled as the block

The ellipsis is styled and baseline-aligned according to the block. Each box is 100px wide, text-overflow: ellipsis, in .pr-measure text, and the block's color is red.

After positioning, and too little room

Ellipsing occurs after relative positioning and other graphical transformations. If there is insufficient space for the ellipsis, then clip the rendering of the ellipsis itself (on the same side that neutral characters on the line would have otherwise been clipped with the text-overflow:clip value).
