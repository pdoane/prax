CSS Overflow 4 · 3.1 Managing Overflow: the overflow-x, overflow-y, and overflow properties

Overflow on replaced elements

This level extends the overflow-x and overflow-y properties (and overflow shorthand) to apply to replaced elements. On replaced elements, the used values of all computed values other than overflow/visible is overflow/clip. Host languages should define UA style sheet rules that apply a default value of overflow/clip to such elements and set their overflow-clip-margin to overflow-clip-margin/content-box.
