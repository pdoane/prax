CSS Overflow 3 · 3.1 Managing Overflow, the pair of values

overflow: the pair of values

The visible and clip values are known as the non-scrollable values. However, if the other axis specifies a scrollable value, a specified value of visible computes to overflow/auto, enabling scrolling in its axis. CSS Overflow 3 §3.1

visible beside a scrollable value

Each dashed box is 70 by 40 and holds A and B, 40px wide, then C, 100px wide and labelled "end" at its right end. A script sets scrollLeft and scrollTop to 30; each box scrolls only in an axis it may, at most 30 across and 20 down.

clip beside a scrollable value

If only one axis computes to a scrollable value (i.e. the other axis is overflow/clip), the box is a single-axis scroll container. CSS Overflow 3 §3.1 clip keeps its value and forbids scrolling in its axis.
