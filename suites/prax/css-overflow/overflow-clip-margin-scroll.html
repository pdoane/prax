overflow-clip-margin on a scroll container

If the box is a scroll container: the overflow clip edge is clamped to stay within the element's padding box. the border-box value ignores any specified offset (and, due to the previous bullet point, effectively acts as padding-box). CSS Overflow 3 §3.2
