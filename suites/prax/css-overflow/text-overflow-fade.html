CSS Overflow 4 · 4.1 Inline Overflow Ellipsis, fade

text-overflow: fade

text-overflow: [ clip | ellipsis | <string> | fade | <fade()> ]{1,2}. <string>: Render the given string to represent clipped inline content. If there is one value, it applies only to the end line box edge. If there are two values, the first value applies to the line-left edge, and the second value applies to the line-right edge. CSS Overflow 4 §4.1

fade

fade( <length-percentage> ): Clip inline content that overflows its line box. In addition, the UA must apply a fade out effect near the edge of the line box, reaching complete transparency at the edge. The argument determines the distance over which the fade effect is applied. fade: the distance over which the fading effect is applied is determined by the UA. 1em is suggested. CSS Overflow 4 §4.1
