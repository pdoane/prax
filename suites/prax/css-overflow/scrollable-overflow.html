CSS Overflow 3 · 2.2 Scrollable Overflow

Scrollable overflow: past the padding edge

The scrollable overflow of a box is the set of things extending outside of that box's padding edge for which a scrolling mechanism needs to be provided. the scrollable overflow rectangle is the minimal rectangle whose axes are aligned to the box's axes and that contains the scrollable overflow area. CSS Overflow 3 §2.2

What extends past the padding edge

Each dashed box is 120 by 40 with overflow: auto; captions read its scrollWidth and scrollHeight, the scrollable overflow rectangle's size.

Its own padding box is not overflow

The scrollable overflow rectangle contains the box's padding box, so content that stays inside it gives nothing to scroll.
