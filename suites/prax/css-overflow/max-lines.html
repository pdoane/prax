CSS Overflow 4 · 5.2 Forcing a Break After a Set Number of Lines: the max-lines property

max-lines

max-lines: auto || <integer [1,∞]>. Given an integer N, if the box is a line-clamp container, it has an line-based clamp point, set to the first possible clamp point after its Nth descendant in-flow line box. Only line boxes in the same block formatting context are counted: the contents of descendants that establish independent formatting contexts are skipped over while counting line boxes.
