CSS Overflow 4 · 4.1 Inline Overflow Ellipsis: the text-overflow property

text-overflow: a string, and both edges

text-overflow: [ clip | ellipsis | <string> | fade | <fade()> ]{1,2}. <string>: Render the given string to represent clipped inline content. If there is one value, it applies only to the end line box edge. If there are two values, the first value applies to the line-left edge, and the second value applies to the line-right edge.
