CSS Overflow 3 · 6.1.3 user interaction with ellipsis

Selecting ellipsed text

When the user is interacting with content (e.g. editing, selecting, scrolling), the user agent may treat text-overflow: ellipsis as text-overflow: clip. Selecting the ellipsis should select the ellipsed text. If all of the ellipsed text is selected, UAs should show selection of the ellipsis. Behavior of partially-selected ellipsed text is up to the UA. CSS Overflow 3 §6.1.3
