CSS Overflow 3 · 5.2 Reserving space for the scrollbar, overflow values

scrollbar-gutter and the overflow values

scrollbar-gutter: auto | stable && both-edges? The space between the inner border edge and the outer padding edge which user agents may reserve to display the scrollbar is called the scrollbar gutter. In the case of overlay scrollbars, no scrollbar gutter is present. CSS Overflow 3 §5.2

With overflow's other values

stable: the gutter is present when overflow is overflow/hidden, overflow/scroll, or overflow/auto, regardless of whether the box is actually overflowing. CSS Overflow 3 §5.2
