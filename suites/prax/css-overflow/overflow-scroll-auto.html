CSS Overflow 3 · 3.1 Managing Overflow, scroll and auto

overflow: scroll and auto

scroll: the content is clipped to the overflow clip edge, but can be scrolled into view. auto: Like overflow/scroll when the box has scrollable overflow; like overflow/hidden otherwise. CSS Overflow 3 §3.1

A scroll bar whether or not there is overflow

scroll: a visible scrolling mechanism should be displayed whether or not any of its content is clipped. auto: that mechanism will only be displayed if there is overflow. CSS Overflow 3 §3.1 Each box holds only B, which fits.
