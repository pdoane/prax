CSS Overflow 3 · 3.1.4 Overflow Viewport Propagation, containment

Containment stops propagation from the body

The body's values go to the viewport where the root's are visible, from a body element whose display value is also not display/none, the first such child element. CSS Overflow 3 §3.1.4

Containment stops the body's propagation

when any containments are active on either the HTML html or body elements, propagation of properties from the body element to the initial containing block, the viewport, or the canvas background, is disabled. CSS Containment 2 §2
