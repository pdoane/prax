CSS Overflow 3 · 3.1 Managing Overflow, the axes

The overflow longhands and shorthand

The overflow-x property specifies the handling of overflow in the horizontal axis, the overflow-y property specifies the handling of overflow in the vertical axis. overflow-block and overflow-inline likewise, in the block and inline axes. CSS Overflow 3 §3.1

One axis clipped

Each dashed box is 70 by 40 and holds a 100px wide A, then B and C. clip beside visible clips one axis alone.

Flow-relative axes

In vertical-rl the block axis is horizontal and the inline axis vertical. Each dashed box is 40 by 70 in vertical-rl, and holds A, 100px tall, then B and C to its left.
