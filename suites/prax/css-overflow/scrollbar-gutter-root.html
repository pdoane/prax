CSS Overflow 3 · 5.2 Reserving space for the scrollbar, the viewport

scrollbar-gutter on the root

As for the overflow property, when scrollbar-gutter is set on the root element, the user agent must apply it to the viewport instead, and the used value on the root element itself is scrollbar-gutter: auto. However, unlike the overflow property, the user agent must not propagate scrollbar-gutter from the HTML body element. CSS Overflow 3 §5.2

The viewport's gutter

Each frame is a document whose canvas is grey and whose body, blue, fills its width and is 40px tall, so nothing overflows. Its scroll bars are styled with ::-webkit-scrollbar: Safari draws classic ones 12px wide, as the last frame shows; Chrome and Firefox draw overlay ones here, which make no gutter, so each of their bodies fills the frame's width, as it should with overlay bars.
