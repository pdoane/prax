CSS Overflow 4 · 4.6 ellipsis interaction with scrolling interfaces

An ellipsis at both ends while scrolled

If that content's block container element is the same that's doing the scrolling, and the computed value of text-overflow has two values, with the value applying to the start edge being a non-clip value, then implementations must render an ellipsis/string in place of the clipped content, with the same details as described in the value definition above, except that the ellipsis/string is drawn in the start (rather than end) of the block's direction. If there is insufficient space for both start and end ellipses/strings, then only the end ellipsis/string should be rendered. CSS Overflow 4 §4.6
