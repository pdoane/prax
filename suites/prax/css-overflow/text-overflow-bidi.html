CSS Overflow 3 · 6.1.1 Bidi ellipsis examples

text-overflow in bidi text

These examples demonstrate which characters get hidden to make room for the ellipsis in a bidi situation: those visually at the end edge of the line. CSS Overflow 3 §6.1.1

The example's two lines

Each dashed box is overflow: hidden; white-space: pre; width: 9ch; text-overflow: ellipsis with "שלום 123456" in PR Cousine, a monospace font with Hebrew. The digits follow the Hebrew word with only a space between, so word, space and digits make one right-to-left run, the digits visually at its left.
