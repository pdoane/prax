CSS Overflow 3 · 4.1 Smooth Scrolling: the scroll-behavior Property

scroll-behavior: auto and smooth

The scroll-behavior property specifies the scrolling behavior for a scroll container, when scrolling happens due to navigation, scrolling APIs, or scroll snapping operations not initiated by the user. auto: scrolled in an instant fashion. smooth: scrolled in a smooth fashion using a user-agent-defined timing function over a user-agent-defined period of time. User agents may ignore this property. CSS Overflow 3 §4.1

From the root, not the body

When this property is specified on the root element, it applies to the viewport instead. Note: The scroll-behavior property of the HTML body element is not propagated to the viewport. CSS Overflow 3 §4.1 Each frame calls scrollTo(0, 40) and writes the scrollY it reads at once on its page.
