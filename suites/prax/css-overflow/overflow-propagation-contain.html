Which element gives the viewport its overflow

The body's values go to the viewport where the root's are visible, from a body element whose display value is also not display/none, the first such child element. CSS Overflow 3 §3.1.4

The first body that is displayed

The frame's document has two body elements, made by script; the first is display: none, the second, dashed, is overflow: hidden, 30px tall at 10, 10, and holds a box 60px tall and one 200px tall. A script calls scrollTo(0, 40). Read as the first body that is displayed, the first such child is the second, whose value would go to the viewport. The sentence can also be read as the first body child, which is displayed or not.
