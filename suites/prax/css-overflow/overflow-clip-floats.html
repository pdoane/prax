CSS Overflow 3 · 3.1 Managing Overflow, clip and floats

overflow: clip beside floats

A block box that becomes a scroll container also establishes an independent formatting context. clip does not cause the element to establish a new formatting context. Authors who also want the box to establish a formatting context can use display: flow-root together with overflow: clip. CSS Overflow 3 §3.1
