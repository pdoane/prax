CSS Overflow 4 · 4.2 Indicating Block-Axis Overflow: the block-ellipsis property

block-ellipsis

block-ellipsis: no-ellipsis | ellipsis | <string>, inherited. This property allows inserting content into the last line box before a clamp point or a (forced or unforced) region break to indicate the continuity of truncated / interrupted content. CSS Overflow 4 §4.2

At the end of the last line before the clamp

Each dashed box is 100px wide, continue: collapse; max-lines: 2, and holds three lines of .pr-measure text, "line one", "aaaa bbbb", "line three"; the clamp point follows the second. the block overflow ellipsis string is placed at the end of the line box reducing the space available to the other contents of the line. The user agent makes room by displacing content from the end of the line as if wrapping. CSS Overflow 4 §4.2
