CSS Lists and Counters 3 · 4.7 Outputting Counters: the counter() and counters() functions

counter() and counters()

Counters have no visible effect by themselves, but their values can be used with the counter() and counters() functions, whose used values represent counter values as strings or images. CSS Lists and Counters 3 §4.7

counters() in a marker

The example: li::marker { content: '(' counters(list-item,'.') ') '; }.

A counter that does not exist yet; a symbolic style

If no counter named <counter-name> exists on an element where 'counter()' or 'counters()' is used, one is first instantiated with a starting value of '0'. If the <counter-style> is one of the predefined symbolic styles, like 'disc', it might look different than when used in 'list-style-type'.
