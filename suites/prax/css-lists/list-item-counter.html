CSS Lists and Counters 3 · 4.6 The Implicit list-item Counter

The list-item counter in nested lists

unless the 'counter-increment' property explicitly specifies a different increment for the 'list-item' counter, it must be incremented by 1 on every list item, or if the counter is reversed, it must be incremented by -1 on every list item instead. CSS Lists and Counters 3 §4.6

Tiered numbering from the HTML attributes

The example: ol > li::marker { content: counters(list-item,'.') '.'; }, with value=5, start=3 and reversed on the lists and items.

Turned off; on any list item

This also allows to turn off the automatic list-item counter increment, by overriding it explicitly, e.g. 'counter-increment: list-item 0;'.
