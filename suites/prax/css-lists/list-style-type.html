CSS Lists and Counters 3 · 3.4 Text-based Markers: the list-style-type property

The list-style-type property: strings and counter styles

Specifies the marker string, which is used to fill the list item’s marker when its 'content' value is 'normal' and there is no marker image. CSS Lists and Counters 3 §3.4

A string

The element’s marker string is the specified <string>. No counter and no suffix are added.

A counter style

the marker string is the result of generating a counter representation of the 'list-item' counter value using the specified <counter-style>, prefixed by the 'prefix' of the <counter-style>, and followed by the 'suffix' of the <counter-style>. If the specified <counter-style> does not exist, 'decimal' is assumed.
