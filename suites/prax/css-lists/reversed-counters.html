CSS Lists and Counters 3 · 4.4.2 Instantiating Counters

Instantiating a reversed counter without a value

When a counter is instantiated without an initial value, the user agent must dynamically calculate the initial value at layout-time: the negated increments of the elements that increment or set it in its scope, summed up to the first that sets it, plus the set value, plus the last non-zero negated increment once more. Only reversed counters can be instantiated without an initial value. CSS Lists and Counters 3 §4.4.2
