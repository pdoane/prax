CSS Lists and Counters 3 · 3.5 Positioning Markers: The list-style-position property

Outside markers: on the inline-start side

CSS does not specify the precise location of the marker box or its position in the painting order, but does require that it be placed on the inline-start side of the box, using the writing mode of the box indicated by 'marker-side'. CSS Lists and Counters 3 §3.5 Each list has two items, tinted blue, and 30px of padding-inline-start.

Horizontal and vertical, left to right

Right to left

With direction: rtl, inline-start is the right in horizontal text and the bottom in vertical text.
