CSS Lists and Counters 3 · 4.1 Creating Counters: the counter-reset property

counter-reset: reversed counters

The 'counter-reset' property instantiates new counters on an element and sets them to the specified integer values. reversed(<counter-name>) <integer>? Instantiates a reversed counter of the given <counter-name> with a starting value of the given <integer>, or no starting value if not given. CSS Lists and Counters 3 §4.1

A reversed list-item counter counts down

A list item increments the list-item counter by -1 on every list item where the counter is reversed. §4.6

Only the implicit increment is reversed

An explicit counter-increment is used as written.
