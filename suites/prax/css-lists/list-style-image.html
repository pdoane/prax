CSS Lists and Counters 3 · 3.3 Image Markers: the list-style-image property

The list-style-image property: sizing the image

The marker image is sized using the default sizing algorithm [css-images-3] with no specified size and a default object size of 1em square. CSS Lists and Counters 3 §3.3

Gradients: 1em square

A gradient has no natural size or ratio, so the image is the default object size. Each stage sets the font size.
