CSS Lists and Counters 3 · 2 Declaring a List Item

List items: display: list-item

A list item is any element with its 'display' property set to 'list-item'. List items generate '::marker' pseudo-elements; no other elements do. Additionally, list items automatically increment an implied 'list-item' counter. CSS Lists and Counters 3 §2

Any element, and only list items

The stages hold div elements, not li; list-style-type: decimal.

Inline list items

Any element with list-item in its display is a list item, inline ones too, whose outside marker is equivalent to 'inside' §3.5. Each item is tinted blue.
