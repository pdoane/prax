CSS Lists and Counters 3 · 3.1 The ::marker Pseudo-Element

The ::marker pseudo-element

The marker box is generated by the ::marker pseudo-element of a list item as the list item’s first child, before the ::before pseudo-element (if it exists on the element). CSS Lists and Counters 3 §3.1

First child, before ::before

Inside markers show the order on the line; the items are tinted blue.

Markers of pseudo-elements, and of nothing else

Marker boxes only exist for list items: on any other element, the ::marker pseudo-element's 'content' property must compute to 'none', which suppresses its creation. A ::before that is a list item has a marker, which ::before::marker selects.
