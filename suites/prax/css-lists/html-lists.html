HTML's lists in CSS

This section is informative, not normative. The [HTML] Rendering chapter defines the normative default properties that apply to HTML lists; this sample style sheet is provided to illustrate the CSS features using familiar markup conventions. CSS Lists and Counters 3 §A

type, start and value

ol[type="a"] { list-style-type: lower-alpha; } ol[start] { counter-reset: list-item calc(attr(start integer, 1) - 1); } li[value] { counter-set: list-item attr(value integer, 1); }

marker-side and text-align

ol, ul { display: block; margin-block: 1em; marker-side: match-parent; padding-inline-start: 40px; } li { text-align: match-parent; } Items with dir=rtl in a left-to-right list.
