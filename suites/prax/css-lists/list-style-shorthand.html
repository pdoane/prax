The list-style shorthand: strings and symbols()

The 'list-style' property is a shorthand notation for setting the three properties 'list-style-type', 'list-style-image', and 'list-style-position' at the same place in the style sheet. Since CSS 2, its type may be a string or symbols(). CSS Lists and Counters 3 §3.6
