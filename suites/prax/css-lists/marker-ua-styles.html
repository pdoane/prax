CSS Lists and Counters 3 · 3.1.1 Properties Applying to ::marker, the default style sheet

The user agent's rule for ::marker

Additionally, UAs must add the following rule to their default style sheet: CSS Lists and Counters 3 §3.1.1

::marker, ::before::marker, ::after::marker {
  unicode-bidi: isolate;
  font-variant-numeric: tabular-nums;
  white-space: pre;
  text-transform: none;
}

Tabular figures

The items are set in Literata with proportional-nums, which the marker does not inherit: its own tabular-nums wins. The markers are inside.

Spaces kept; no text-transform

With white-space: pre, the spaces of a marker string are not collapsed. Added 'text-transform: none' to the UA default style sheet for '::marker'. (csswg-drafts#4206)
