CSS 2 · 17.6.3 Border styles

Border styles in tables

Some of the values of the 'border-style' have different meanings in tables than for other elements. Each table is a row of two cells with 8px grey borders.

inset

In the separated borders model, the border makes the entire box look as though it were embedded in the canvas. In the collapsing border model, drawn the same as 'ridge'. CSS 2 §17.6.3

outset

In the separated borders model, the border makes the entire box look as though it were coming out of the canvas. In the collapsing border model, drawn the same as 'groove'. CSS 2 §17.6.3
