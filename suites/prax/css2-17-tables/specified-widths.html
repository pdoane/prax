CSS 2 · 17.5.2.2 Automatic table layout

Automatic table layout: specified widths

Cells hold 30px blocks, have a 1px border and no padding: a cell's minimum content width (MCW) is 32px.

Specified widths and spanning cells

If the specified 'width' (W) of the cell is greater than MCW, W is the minimum cell width. For each cell that spans more than one column, increase the minimum widths of the columns it spans so that together, they are at least as wide as the cell. CSS 2 §17.5.2.2

Since CSS 2 · CSS Table 3 §3.8.2

A cell's width is not a minimum

A cell's width no longer counts toward its minimum: The outer min-content width of a table-cell is max(min-width, min-content width) adjusted by the cell intrinsic offsets. It counts only toward the width the column prefers: The outer max-content width of a table-cell in a constrained column is max(min-width, width, min-content width, min(max-width, width)) adjusted by the cell intrinsic offsets.
