CSS 2 · 17.6.1 The separated borders model

The separated borders model: border-spacing

border-spacing takes <length> <length>?. Initial 0, inherited, and it applies to table and inline-table elements; it computes to two absolute lengths. Each table is a div with a yellow background and a 2px border, and its cells are 30 by 20.

One length or two

The lengths specify the distance that separates adjoining cell borders. If one length is specified, it gives both the horizontal and vertical spacing. If two are specified, the first gives the horizontal spacing and the second the vertical spacing. Lengths may not be negative. CSS 2 §17.6.1

At the table's edges

The distance between the table border and the borders of the cells on the edge of the table is the table's padding for that side, plus the relevant border spacing distance. CSS 2 §17.6.1
