CSS 2 · 17.3 Columns

Columns: the example

Here are some examples of style rules that set properties on columns. Both tables have border-collapse: collapse, for the column borders to apply, and 12px text.

HTML's rules="cols"

The first two rules together implement the "rules" attribute of HTML 4 with a value of "cols". They are col { border-style: none solid } and table { border-style: hidden }. CSS 2 §17.3

A blue column of fixed size

The third rule makes the "totals" column blue, the final two rules shows how to make a column a fixed size, by using the fixed layout algorithm. They are col.totals { background: blue }, table { table-layout: fixed } and col.totals { width: 5em }. CSS 2 §17.3
