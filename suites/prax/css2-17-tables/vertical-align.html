CSS 2 · 17.5.3 Table height algorithms

Table height algorithms: vertical-align in cells

The 'vertical-align' property of each table cell determines its alignment within the row. Each cell's content has a baseline, a top, a middle, and a bottom, as does the row itself.

top, middle and bottom

top: The top of the cell box is aligned with the top of the first row it spans. bottom: The bottom of the cell box is aligned with the bottom of the last row it spans. middle: The center of the cell is aligned with the center of the rows it spans. CSS 2 §17.5.3

baseline, and values that do not apply

baseline: The baseline of the cell is put at the same height as the baseline of the first of the rows it spans. sub, super, text-top, text-bottom, <length>, <percentage>: These values do not apply to cells; the cell is aligned at the baseline instead. CSS 2 §17.5.3
