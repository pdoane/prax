CSS 2 · 17.4 Tables in the visual formatting model

The table wrapper box: inline tables

Each table has a 3px blue border, cells with 12px text, and an orange caption.

Block-level and inline-level wrappers

The table wrapper box is block-level for 'display: table', and inline-level; for 'display: inline-table'. The table box (not the table wrapper box) is used when doing baseline vertical alignment for an 'inline-table'. CSS 2 §17.4

Two formatting contexts

The table wrapper box establishes a block formatting context, and the table box establishes a table formatting context. CSS 2 §17.4
