CSS 2 · 17.5.3 Table height algorithms

Table height algorithms: minimum heights

Cells have a 1px border and hold an 18px block, so rows are 20px unless something makes them taller. Tables are outlined.

A table's height is a minimum

For the table's 'height', Any other value is treated as a minimum height. CSS 2 §17.5.3

A row's height

A row's height is the maximum of the row's computed 'height', the computed 'height' of each cell in the row, and the minimum height (MIN) required by the cells. The sum of the row heights involved must be great enough to encompass the cell spanning the rows. CSS 2 §17.5.3
