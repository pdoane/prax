CSS 2 · 17.3 Columns

Columns: borders and backgrounds

In the source document cells are descendants of rows, never of columns. Nevertheless, some aspects of cells can be influenced by setting properties on columns. Each table has three columns of 40px cells, and the middle col is styled.

'border'

The various border properties apply to columns only if 'border-collapse' is set to 'collapse' on the table element. In that case, borders set on columns and column groups are input to the conflict resolution algorithm that selects the border styles at every cell edge. CSS 2 §17.3

'background'

The background properties set the background for cells in the column, but only if both the cell and row have transparent backgrounds. CSS 2 §17.3
