CSS 2 · 17.6.2 The collapsing border model

The collapsing border model

In the collapsing border model, it is possible to specify borders that surround all or part of a cell, row, row group, column, and column group. Cells here have a 40px content box (teal), 5px left and right padding (yellow) and a 10px translucent blue border.

Borders on the grid lines

Borders are centered on the grid lines between the cells. For every row, row-width = (0.5 * border-width0) + padding-left1 + width1 + padding-right1 + border-width1 + padding-left2 +...+ padding-rightn + (0.5 * border-widthn). CSS 2 §17.6.2

No padding, half the border

Note that in this model, the width of the table includes half the table border. Also, in this model, a table does not have padding (but does have margins). CSS 2 §17.6.2
