CSS 2 · 17.6.1 The separated borders model

The separated borders model: the example

In this model, each cell has an individual border. The 'border-spacing' property specifies the distance between the borders of adjoining cells.

A table with border-spacing

The table in the figure below could be the result of a style sheet like this, with a tan table background and grey borders added so the 3D styles show. Note that each cell has its own border, and the table has a separate border as well. CSS 2 §17.6.1

table      { border: outset 10pt;
             border-collapse: separate;
             border-spacing: 15pt }
td         { border: inset 5pt }
td.special { border: inset 10pt }  /* The top-left cell */
