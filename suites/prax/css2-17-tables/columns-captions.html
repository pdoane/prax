CSS 2 · 17.2 The CSS table model

The table model: columns and captions

table-column (COL) Specifies that an element describes a column of cells. table-column-group (COLGROUP) Specifies that an element groups one or more columns. Every cell here is 50 by 20, and every element a div.

Columns are not rendered, but style their cells

Elements with 'display' set to 'table-column' or 'table-column-group' are not rendered (exactly as if they had 'display: none'), but they are useful, because they may have attributes which induce a certain style for the columns they represent. CSS 2 §17.2

Captions are rendered

table-caption (CAPTION): Specifies a caption for the table. All elements with 'display: table-caption' must be rendered. CSS 2 §17.2
