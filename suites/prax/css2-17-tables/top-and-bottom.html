CSS 2 · 17.6.2 The collapsing border model

The collapsing border model: top and bottom

Each table is outlined in dashed red at its border box, and its stage has 30px of padding on the left and top. Cells have 2px blue borders unless the caption says otherwise.

Top and bottom: the widest

The top border width of the table is equal to half of the maximum collapsed top border. The bottom border width is computed by examining all cells whose bottom borders collapse with the bottom of the table. CSS 2 §17.6.2
