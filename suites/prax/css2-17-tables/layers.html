Table layers and transparency

For the purposes of finding the background of each table cell, the different table elements may be thought of as being on six superimposed layers. The background set on an element in one of the layers will only be visible if the layers above it have a transparent background.

Six layers, bottom to top

The table, yellow; The next layer contains the column groups, orange; On top of the column groups are the areas representing the column boxes, red; Next is the layer containing the row groups, green; The next to last layer contains the rows, blue; The topmost layer contains the cells themselves, purple.
