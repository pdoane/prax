CSS 2 · 17.5 Visual layout of table contents

Visual layout: floated and positioned cells

Each dashed table has border-spacing: 10px and a row of three table-cell divs, 40 by 20. The orange one is floated or positioned.

No longer a cell

Positioning and floating of table cells can cause them not to be table cells anymore, according to the rules in section 9.7. When floating is used, the rules on anonymous table objects may cause an anonymous cell object to be created as well. CSS 2 §17.5
