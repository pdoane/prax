CSS 2 · 17.5.3 Table height algorithms

Table height algorithms: the order of alignment

To avoid ambiguous situations, the alignment of cells proceeds in the following order. Cells are baseline unless the caption says otherwise.

Baseline and top first, then bottom and middle

First the cells that are aligned on their baseline are positioned. This will establish the baseline of the row. Next the cells with 'vertical-align: top' are positioned. If any of the remaining cells, those aligned at the bottom or the middle, have a height that is larger than the current height of the row, the height of the row will be increased to the maximum of those cells, by lowering the bottom. Cell boxes that are smaller than the height of the row receive extra top or bottom padding. CSS 2 §17.5.3

Below the bottom border

Note that the baseline of a cell may end up below its bottom border: div { height: 0; overflow: hidden; }, with <td><div> Test </div></td>. CSS 2 §17.5.3
