CSS 2 · 17.2.1 Anonymous table objects

Anonymous table objects: irrelevant boxes

The first of three stages: Remove irrelevant boxes. Each stage has border-spacing: 10px, which its tables inherit, so every cell, anonymous or not, is 10px from its neighbors.

Inside columns and column groups

All child boxes of a 'table-column' parent are treated as if they had 'display: none'. If a child C of a 'table-column-group' parent is not a 'table-column' box, then it is treated as if it had 'display: none'. CSS 2 §17.2.1

White space between table boxes

A white-space-only anonymous inline child of a tabular container (a row, row group or table) whose siblings are either 'table-caption' or internal table boxes is treated as if it had 'display: none'. So is one between two immediate siblings each of which is either an internal table box or a 'table-caption' box, whatever its parent. CSS 2 §17.2.1
