CSS 2 · 17.2.1 Anonymous table objects

Anonymous table objects: the examples

The stages have border-spacing: 10px, which the anonymous tables inherit.

A row without a table

In this XML example, a 'table' element is assumed to contain the HBOX element, styled HBOX { display: table-row } and VBOX { display: table-cell }. CSS 2 §17.2.1

<HBOX>
  <VBOX>George</VBOX>
  <VBOX>4287</VBOX>
  <VBOX>1998</VBOX>
</HBOX>

Rows without cells

In this example, three 'table-cell' elements are assumed to contain the text in the ROWs. Note that the text is further encapsulated in anonymous inline boxes. The style sheet is STACK { display: inline-table }, ROW { display: table-row }, D { display: inline; font-weight: bolder }. CSS 2 §17.2.1

<STACK>
  <ROW>This is the <D>top</D> row.</ROW>
  <ROW>This is the <D>middle</D> row.</ROW>
  <ROW>This is the <D>bottom</D> row.</ROW>
</STACK>
