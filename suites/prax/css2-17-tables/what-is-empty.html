CSS 2 · 17.6.1.1 Borders and Backgrounds around empty cells: the 'empty-cells' property

Empty cells: what is empty

Every table has empty-cells: hide, so a cell drawn blue with a black border is not empty, and an empty one shows only the yellow table. The middle cell is the one that varies.

White space is empty

Cells are empty unless they contain one or more of the following: floating content (including empty elements), in-flow content (including empty elements) other than white space that has been collapsed away by the 'white-space' property handling. CSS 2 §17.6.1.1

Empty elements are content

An empty element in the flow, or an empty float, makes a cell not empty. CSS 2 §17.6.1.1
