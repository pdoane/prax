CSS 2 · 17.2.1 Anonymous table objects

Anonymous table objects

Document languages other than HTML may not contain all the elements in the CSS 2.2 table model. In these cases, the "missing" elements must be assumed in order for the table model to work. The anonymous tables inherit each stage's border-spacing: 10px: cells 10px apart and from the edges.

At least a table, a row and a cell

Any table element will automatically generate necessary anonymous table objects around itself, consisting of at least three nested objects corresponding to a 'table'/'inline-table' element, a 'table-row' element, and a 'table-cell' element. CSS 2 §17.2.1

Out-of-flow elements

For the purposes of these rules, out-of-flow elements are represented as inline elements of zero width and height. Their containing blocks are chosen accordingly. CSS 2 §17.2.1
