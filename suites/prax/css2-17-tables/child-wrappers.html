CSS 2 · 17.2.1 Anonymous table objects

Anonymous table objects: child wrappers

The second stage: Generate missing child wrappers. The tinted, dashed box is the table; it has border-spacing: 10px. Blue cells are elements; text outside them is in anonymous cells.

In a table and in a row group

If a child C of a 'table' or 'inline-table' box is not a proper table child, then generate an anonymous 'table-row' box around C and all consecutive siblings of C that are not proper table children. If a child C of a row group box is not a 'table-row' box, then generate an anonymous 'table-row' box around C and all consecutive siblings of C that are not 'table-row' boxes. CSS 2 §17.2.1

In a row

If a child C of a 'table-row' box is not a 'table-cell', then generate an anonymous 'table-cell' box around C and all consecutive siblings of C that are not 'table-cell' boxes. CSS 2 §17.2.1
