CSS 2 · 17.5.2.2 Automatic table layout

Automatic table layout: column groups

Cells hold 30px blocks with line breaks allowed between them, have a 1px border and no padding.

Column groups

For each column group element with a 'width' other than 'auto', increase the minimum widths of the columns it spans, so that together they are at least as wide as the column group's 'width'. CSS 2 §17.5.2.2
