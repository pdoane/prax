CSS 2 · 17.5.2.2 Automatic table layout

Automatic table layout: rows and columns

Cells hold 30px blocks with line breaks allowed between them, have a 1px border and no padding.

Rows and columns constrain each other

In this algorithm, rows (and row groups) and columns (and column groups) both constrain and are constrained by the dimensions of the cells they contain. Setting the width of a column may indirectly influence the height of a row, and vice versa. CSS 2 §17.5.2.2
