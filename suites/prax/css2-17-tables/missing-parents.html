CSS 2 · 17.2.1 Anonymous table objects

Anonymous table objects: missing parents

The third stage: Generate missing parents. Each stage has border-spacing: 10px, which anonymous tables inherit; blue and orange boxes are cells.

Rows around cells

For each 'table-cell' box C in a sequence of consecutive internal table and 'table-caption' siblings, if C's parent is not a 'table-row' then generate an anonymous 'table-row' box around C and all consecutive siblings of C that are 'table-cell' boxes. CSS 2 §17.2.1

Tables around misparented boxes

For each proper table child C in a sequence of consecutive proper table children, if C is misparented then generate an anonymous 'table' or 'inline-table' box T around C and all consecutive siblings of C that are proper table children. (If C's parent is an 'inline' box, then T must be an 'inline-table' box; otherwise it must be a 'table' box.) CSS 2 §17.2.1
