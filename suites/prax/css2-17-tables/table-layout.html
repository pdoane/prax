CSS 2 · 17.5.2 Table width algorithms: the 'table-layout' property

Table width algorithms: table-layout

table-layout takes auto | fixed. Initial auto, not inherited, and it applies to table and inline-table elements. Cells have a 1px border and no padding.

fixed and auto

The 'table-layout' property controls the algorithm used to lay out the table cells, rows, and columns. fixed: Use the fixed table layout algorithm. auto: Use any automatic table layout algorithm. CSS 2 §17.5.2

Section 10.3, overridden

If the margins of a table are set to '0' and the width to 'auto', the table will not automatically size to fill its containing block. Therefore a table can be centered using left and right 'auto' margins, for instance. CSS 2 §17.5.2
