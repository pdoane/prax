CSS 2 · 17.1 Introduction to tables

Introduction: a simple table

Authors may specify the visual formatting of a table as a rectangular grid of cells. Cells sit in rows and columns; rows and columns may be grouped, have borders, and align their data.

The specification's 3x3 table

This code creates one table (the TABLE element), three rows (the TR elements), three header cells (the TH elements), and six data cells (the TD elements). The rules center and embolden the header cells, collapse the borders, give row 1 a 3px solid blue border and rows 2 and 3 a 1px solid black one, and put the caption on top. CSS 2 §17.1

Any element can be a table element

CSS 2.2 allows authors to "map" document language elements to table elements via the 'display' property. FOO { display : table } and BAR { display : table-caption } make FOO act like an HTML TABLE element and BAR act like a CAPTION element. CSS 2 §17.1
