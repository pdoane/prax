CSS 2 · 17.5 Visual layout of table contents

Visual layout: overlapping cells

Spanning cells that collide. Cells are 40 by 20; the column-spanning cell is translucent orange.

Overlapping cells

If this position would cause a column-spanning cell to overlap a row-spanning cell from a prior row, CSS does not define the results: implementations may either overlap the cells (as is done in many HTML implementations) or may shift the later cell to the right to avoid such overlap. The specification's illegal (X)HTML snippet: CSS 2 §17.5

<tr><td>1 </td><td rowspan="2">2 </td><td>3 </td><td>4 </td></tr>
<tr><td colspan="2">5 </td></tr>

The cells overlap

Apply the HTML5 Table Formatting algorithm, where boxes act like the HTML element equivalent to their display type: a cell starts in the first free slot of its row, and its span may run over taken ones. Each slot of the table grid is covered by at least one table-cell (some of them anonymous), and at most two. CSS Table 3 §3.3.1, §2.1.1
