CSS 2 · 17.4 Tables in the visual formatting model

The table wrapper box

In terms of the visual formatting model, a table can behave like a block-level (for 'display: table') or inline-level (for 'display: inline-table') element. Each table below has a 3px blue border, two 50px cells and an orange caption.

The wrapper, the table and the captions

The table generates a principal block container box called the table wrapper box that contains the table box itself and any caption boxes (in document order). The caption boxes are principal block-level boxes that retain their own content, padding, margin, and border areas, and are rendered as normal block boxes inside the table wrapper box. CSS 2 §17.4

Its width, and percentages

The width of the table wrapper box is the border-edge width of the table box inside it, as described by section 17.5.2. Percentages on 'width' and 'height' on the table are relative to the table wrapper box's containing block, not the table wrapper box itself. CSS 2 §17.4
