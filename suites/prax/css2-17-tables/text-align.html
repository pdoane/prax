CSS 2 · 17.5.4 Horizontal alignment in a column

Horizontal alignment in a column

Each table is as wide as its stage; cells hold 30px inline blocks or text.

text-align on the cell

The horizontal alignment of inline-level content within a cell box can be specified by the value of the 'text-align' property on the cell. CSS 2 §17.5.4

Aligning a column

The specification's introduction: th { text-align: center; font-weight: bold } centers the text horizontally in the header cells. A whole column is aligned through its cells. CSS 2 §17.1, §17.5.4
