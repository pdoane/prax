CSS 2 · 17.6.2 The collapsing border model

The collapsing border model: the table's border

Tables are outlined in dashed red at their border box; cells have 2px blue borders.

Left and right: the first row

The left border width of the table is half of the first cell's collapsed left border, and the right border width of the table is half of the last cell's collapsed right border. If subsequent rows have larger collapsed left and right borders, then any excess spills into the margin area of the table. CSS 2 §17.6.2

Every side: the widest

The table's border on each side is resolved against all the cells along it: Once this is done, set the table-root border-{…}-width to half the maximum width found during the harmonization processes for that border, then set border-{…}-style to solid, and border-{…}-color to transparent.
