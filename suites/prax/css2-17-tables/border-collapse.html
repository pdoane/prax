CSS 2 · 17.6 Borders

Borders: border-collapse

border-collapse takes collapse | separate. Initial separate, inherited, and it applies to table and inline-table elements. Each table has a 4px blue border; its cells have 2px orange borders.

Two border models

There are two distinct models for setting borders on table cells in CSS. One is most suitable for so-called separated borders around individual cells, the other is suitable for borders that are continuous from one end of the table to the other. The value 'separate' selects the separated borders border model. The value 'collapse' selects the collapsing borders model. CSS 2 §17.6

Inherited

border-collapse is inherited, so a table inside a cell of a collapsing table collapses too. The tables here are divs, which no HTML default sets. CSS 2 §17.6
