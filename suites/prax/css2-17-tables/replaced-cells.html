CSS 2 · 17.2 The CSS table model

The table model: replaced elements

A blue 30 by 30 image given a table display value, in a table of 50px cells.

A replaced element as a cell

Replaced elements with these 'display' values are treated as their given display types during layout. For example, an image that is set to 'display: table-cell' will fill the available cell space, and its dimensions might contribute towards the table sizing algorithms, as with an ordinary cell. Since CSS 2 · CSS Display 3 §2.4

A replaced element is never a table box

When the display property of a replaced element computes to one of the layout-internal values, it is handled as having a used value of inline. White space collapsing and anonymous box generation must happen around those replaced elements based on that inline value, as if they never had a layout-internal display value applied to them.
