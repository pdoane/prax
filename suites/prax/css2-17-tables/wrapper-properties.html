CSS 2 · 17.4 Tables in the visual formatting model

The table wrapper box: whose properties

A table element's properties are split between the two boxes it generates. Each table has a 3px blue border and two 50px cells (106px wide), and an orange caption 20px tall.

Position, float, margins and offsets: the wrapper

The computed values of properties 'position', 'float', 'margin-*', 'top', 'right', 'bottom', and 'left' on the table element are used on the table wrapper box and not the table box. CSS 2 §17.4
