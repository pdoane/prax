CSS 2 · 17.5 Visual layout of table contents

Visual layout: spanning cells

Cells may span several rows or columns. CSS does not say how many; HTML's rowspan and colspan do. Spanning cells are orange; the others are 40 by 20.

Where a spanning cell goes

The top row of this rectangle is in the row specified by the cell's parent. The rectangle must be as far to the left as possible, but the part of the cell in the first column it occupies must not overlap with any other cell box (i.e., a row-spanning cell starting in a prior row), and the cell must be to the right of all cells in the same row that are earlier in the source document. CSS 2 §17.5

Shortened to fit

A cell box cannot extend beyond the last row box of a table or row group; the user agents must shorten it until it fits. CSS 2 §17.5
