CSS 2 · 17.6.2.1 Border conflict resolution

Border conflicts: the example

The following example illustrates the application of these precedence rules. Its cells have padding: 1em; here the vertical padding is halved to fit.

A table with collapsed borders

Five rows of three cells, and three COL elements. CSS 2 §17.6.2.1

table    { border-collapse: collapse;
           border: 5px solid yellow; }
*#col1   { border: 3px solid black; }
td       { border: 1px solid red;
           padding: 1em; }
td.cell5 { border: 5px dashed blue; }
td.cell6 { border: 5px solid green; }
  • The outer border is the table's 5px yellow, wider than column 1's 3px black and the cells' 1px red; at cell 6, green, set on a cell, beats the table's yellow of the same width and style.
  • Column 1's 3px black runs down between columns 1 and 2, beating the cells' 1px red, except beside cell 5, whose 5px blue dashes are wider. Cell 5 is outlined in blue dashes above and below too.
  • Between cells 5 and 6, both 5px: solid beats dashed, so it is green.
  • Everywhere else, the cells' 1px red.
