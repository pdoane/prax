CSS 2 · 17.5.5 Dynamic row and column effects

Dynamic row and column effects

The 'visibility' property takes the value 'collapse' for row, row group, column, and column group elements. Cells are 40 by 20; the orange cell spans two rows or columns.

Rows and row groups

This value causes the entire row or column to be removed from the display, and the space normally taken up by the row or column to be made available for other content. CSS 2 §17.5.5

Spanning cells are clipped; nothing else changes

Contents of spanned rows and columns that intersect the collapsed column or row are clipped. The suppression of the row or column, however, does not otherwise affect the layout of the table. CSS 2 §17.5.5
