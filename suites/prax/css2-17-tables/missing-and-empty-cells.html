Table layers: missing and empty cells

Yellow tables, border-spacing: 6px, transparent cells 40 by 20.

Row groups, missing cells and hidden empty cells

Each row group extends from the top left corner of its topmost cell in the first column to the bottom right corner of its bottommost cell in the last column. Missing cells are rendered as if an anonymous table-cell box occupied their position in the grid. With empty-cells: hide, empty cells are transparent through the cell, row, row group, column and column group backgrounds, letting the table background show through. CSS 2 §17.5.1

Since CSS 2 · CSS Table 3 §5.3.2

Missing cells paint no background

Cells paint their rows' and columns' backgrounds, but not the cells that fill out a short row: Anonymous table-cells added by the missing cells fixup step do not render any of their backgrounds. CSS Table 3 §5.3.2
