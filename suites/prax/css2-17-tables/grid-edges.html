CSS 2 · 17.5 Visual layout of table contents

Visual layout: the edges of rows and columns

Where a row's box begins and ends in each border model. Each row is green; the cells are transparent, with a 3px translucent blue border.

Where the edges of rows and columns are

The edges of the rows, columns, row groups and column groups in the collapsing borders model coincide with the hypothetical grid lines on which the borders of the cells are centered. In the separated borders model, the edges coincide with the border edges of cells. CSS 2 §17.5
