CSS 2 · 17.5 Visual layout of table contents

Visual layout: the grid

The visual layout of these boxes is governed by a rectangular, irregular grid of rows and columns. Every cell is 40 by 20.

Rows and row groups

Each row box occupies one row of grid cells. Together, the row boxes fill the table from top to bottom in the order they occur in the source document. A row group occupies the same grid cells as the rows it contains. CSS 2 §17.5

Columns and direction; no margins

The first column box may be either on the left or on the right, depending on the value of the 'direction' property of the table. Internal table elements do not have margins. CSS 2 §17.5
