SVG 2 · 9.5.1 Out-of-range elliptical arc parameters

Arcs: radii made positive, or scaled up

Arbitrary numerical values are permitted for all elliptical arc parameters (other than the boolean flags), with adjustments for invalid values. SVG 2 §9.5.1 Each stage is an SVG 160 by 60, in user units of 1px; each path is stroked dark blue, 4 wide, and not filled.

Negative radii, and radii too small

If either rx or ry have negative signs, these are dropped; the absolute value is used instead. If there is no solution, the ellipse is scaled up uniformly until there is exactly one solution (until the ellipse is just big enough).
