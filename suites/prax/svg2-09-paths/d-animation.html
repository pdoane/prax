SVG 2 · 9.3.2 Specifying path data: the ‘d’ property

The d property: interpolation

two 'd' property values can only be interpolated smoothly when the path data strings contain have the same structure, (i.e. exactly the same number and types of path data commands which are in the same order). SVG 2 §9.3.2 Each path, stroked 4 wide, runs to and fro between two path() values over 4 seconds; a still shows it a quarter of the way.

Each parameter as a number

each parameter to each path data command must be interpolated separately as real numbers.

Otherwise, discrete

If an animation is specified and the lists of path data commands do not have the same structure, then the values must be interpolated using the discrete animation type. Flags and booleans must be interpolated as fractions between zero and one, with any non-zero value considered to be a value of one/true.
