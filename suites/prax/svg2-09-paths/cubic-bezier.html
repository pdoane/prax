SVG 2 · 9.3.6 The cubic Bézier curve commands

Cubic Béziers: C and S

A cubic Bézier segment is defined by a start point, an end point, and two control points. SVG 2 §9.3.6 Each stage is an SVG 160 by 60 with a path stroked dark blue, 4 wide; on it, grey lines join each control point, ringed, to its end of the curve.

C: both control points given

Draws a cubic Bézier curve from the current point to (x,y) using (x1,y1) as the control point at the beginning of the curve and (x2,y2) as the control point at the end of the curve. Multiple sets of coordinates may be specified to draw a polybézier.

S: the first control point reflected

The first control point is assumed to be the reflection of the second control point on the previous command relative to the current point. (If there is no previous command or if the previous command was not an C, c, S or s, assume the first control point is coincident with the current point.) The reflected point is orange.
