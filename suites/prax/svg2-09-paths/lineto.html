SVG 2 · 9.3.5 The "lineto" commands

lineto: straight lines, and horizontal and vertical ones

The various "lineto" commands draw straight lines from the current point to a new point. SVG 2 §9.3.5 Each stage is an SVG 160 by 60, in user units of 1px; each path is stroked dark blue, 4 wide, and not filled.

L and l

Draw a line from the current point to the given (x,y) coordinate which becomes the new current point. A number of coordinates pairs may be specified to draw a polyline. When a relative l command is used, the end point of the line is (cpx + x, cpy + y).

H and V, h and v

Draws a horizontal line from the current point. Draws a vertical line from the current point. an h command with a positive x value draws a horizontal line in the direction of the positive x-axis. At the end of the command, the new current point is taken from the final coordinate value.
