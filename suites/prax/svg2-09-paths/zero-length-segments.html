SVG 2 · 9.5.3 Zero-length path segments

Zero-length segments: markers and caps

Path segments with zero length are not invalid, and will affect rendering in the following cases. SVG 2 §9.5.3 Each stage is an SVG 160 by 60, in user units of 1px.

A marker on every vertex

If markers are specified, then a marker is drawn on every applicable vertex, even if the given vertex is the end point of a zero-length path segment and even if "moveto" commands follow each other. Each path has marker-start, marker-mid and marker-end: an orange dot 12 across at half opacity, so that two on one vertex are darker than one.

Caps on zero-length subpaths

linecaps must be painted for zero-length subpaths when 'stroke-linecap' has a value of round or square. The strokes are blue, 20 wide.
