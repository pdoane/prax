SVG 2 · 9.3.7 The quadratic Bézier curve commands

Quadratic Béziers: Q and T

A quadratic Bézier segment is defined by a start point, an end point, and one control point. SVG 2 §9.3.7 Each stage is an SVG 160 by 60 with a path stroked dark blue, 4 wide; on it, grey lines join each control point, ringed, to the ends of its curve.

Q: the control point given

Draws a quadratic Bézier curve from the current point to (x,y) using (x1,y1) as the control point. Multiple sets of coordinates may be specified to draw a polybézier.

T: the control point reflected

The control point is assumed to be the reflection of the control point on the previous command relative to the current point. (If there is no previous command or if the previous command was not a Q, q, T or t, assume the control point is coincident with the current point.) The reflected points are orange.
