SVG 2 · 9.1 Introduction

Paths: outlines, filled and stroked

A path represents the outline of a shape which can be filled or stroked. SVG 2 §9.1 Each stage is an SVG 160 by 60, in user units of 1px, so its coordinates read off the guides.

A pen moved and dragged

A path is described using the concept of a current point. The position of the pen can be changed, and the outline of a shape (open or closed) can be traced by dragging the pen in either straight lines or curves. Each stage has a triangle, d="M 40 50 L 120 50 L 80 10 z".

Several subpaths, and holes

Compound paths (i.e., a path with multiple subpaths) are possible to allow effects such as "donut holes" in objects. Each path is a square from 20, 10 to 140, 50, drawn clockwise, then a second subpath, a rectangle from 60, 20 to 100, 40, filled blue with the initial fill-rule: nonzero §13.4.2.
