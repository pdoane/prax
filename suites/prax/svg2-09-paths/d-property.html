SVG 2 · 9.3.2 Specifying path data: the ‘d’ property

The d property: path data from markup or CSS

The 'd' property is used to specify the shape of a ‘path’ element. SVG 2 §9.3.2 Each stage is an SVG 160 by 60, in user units of 1px; each path is stroked dark blue, 4 wide, and not filled.

The attribute, or a style sheet's path()

The section gives the value as none | <string>; the working group resolved that The d property will support the shape function path() only for now, that The d attribute will only support SVG path string an no functional notation and that d will be a presentation attribute (svgwg#320, which the text does not yet follow).

none, and user units

The value none indicates that there is no path data for the element. For ‘path’ elements, this means that the element does not render. All coordinates and lengths specified within path data must be treated as being in user units in the current user coordinate system.
