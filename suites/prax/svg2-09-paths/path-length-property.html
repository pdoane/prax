SVG 2 · 9.6.2 The ‘path-length’ property

path-length: the author's length from CSS

The path-length property provides the author's computation of the total length of the path. This value is used to calibrate the user agent's own distance-along-a-path calculations with that of the author. SVG 2 §9.6.2 Each stage is an SVG 160 by 60 with a shape stroked dark blue, 6 wide, and dashed.

From a style sheet

It applies to ‘path’ and the basic shapes, and affects stroke operations ('stroke-dasharray', 'stroke-dashoffset'). The SVG ‘pathLength’ attribute maps to the path-length CSS property as a presentation attribute.
