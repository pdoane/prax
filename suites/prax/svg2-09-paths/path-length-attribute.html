SVG 2 · 9.6.1 The ‘pathLength’ attribute

pathLength: the author's length

The author's computation of the total length of the path, in user units. The user agent will scale all distance-along-a-path computations by the ratio of ‘pathLength’ to the user agent's own computed value for total path length. SVG 2 §9.6.1 Each stage is an SVG 160 by 60 with a shape stroked dark blue, 6 wide, and dashed.

Dashes measured in the author's length

‘pathLength’ potentially affects calculations for text on a path, motion animation and various stroke operations.

Zero

A value of zero is valid and must be treated as a scaling factor of infinity. A value of zero scaled infinitely must remain zero, while any non-percentage value greater than zero must become +Infinity.
