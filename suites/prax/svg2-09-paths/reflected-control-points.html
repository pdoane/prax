SVG 2 · 9.5.2 Reflected control points

Reflected control points

If the current point is (curx, cury) and the final control point of the previous path segment is (oldx2, oldy2), then the reflected point (i.e., (newx1, newy1), the first control point of the current path segment) is: (2*curx - oldx2, 2*cury - oldy2). SVG 2 §9.5.2 Each stage is an SVG 160 by 60 with a path stroked dark blue, 4 wide. On it, a grey line runs from each given control point, ringed, through the current point to its reflection, orange.

S and s

The S/s and T/t commands indicate that the first control point of the given cubic Bézier segment is calculated by reflecting the previous path segment's final control point relative to the current point.

T and t

A T's control point is the reflection of the previous one, which after a T was itself reflected.
