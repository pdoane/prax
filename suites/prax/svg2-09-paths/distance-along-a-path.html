SVG 2 · 9.6 Distance along a path

Distance along a path

Various operations, including text on a path and motion animation and various stroke operations, require that the user agent compute the distance along the geometry of a graphics element, such as a ‘path’. SVG 2 §9.6 Each stage is an SVG 160 by 60 with a path stroked dark blue, 6 wide, and dashed; the dashes start again at each subpath §13.5.7.

Only drawing commands have length

A "moveto" operation within a ‘path’ element is defined to have zero length. Only the various "lineto", "curveto" and "arcto" commands contribute to path length calculations. The total length is what pathLength is set against, so each dash shows it.
