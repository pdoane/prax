CSS Flexible Box Layout 2 · 8.3 Cross-axis Alignment: the align-items and align-self properties, baseline

align-items: baseline

all participating flex items on the line are aligned such that their baselines align, and the item with the largest distance between its baseline and its cross-start margin edge is placed flush against the cross-start edge of the line. CSS Flexible Box Layout 2 §8.3 Each item holds a word in text whose lines are 20px tall.

The item furthest from its baseline sits at cross-start

A baseline synthesized from the border box

If the item does not have a baseline in the necessary axis, then one is synthesized from the flex item's border box. An empty box has no baseline; its synthesized alphabetic baseline is its bottom edge CSS Box Alignment 3 §9.1.
