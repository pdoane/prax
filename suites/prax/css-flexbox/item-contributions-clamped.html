CSS Flexible Box Layout 2 · 9.10.3 Flex Item Intrinsic Size Contributions, clamping

Flex item contributions: flex base size, min and max

For this purpose, each contribution is capped by the item’s flex base size if the item is not growable, floored by the item’s flex base size if the item is not shrinkable, and then further clamped by the item's min/max main size.
