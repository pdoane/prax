CSS Flexible Box Layout 2 · 8.5 Flex Container Baselines, main-axis baseline set

A flex container's baseline, along its main axis

When the inline axis of the flex container matches its main axis, its baselines are determined as follows CSS Flexible Box Layout 2 §8.5. In each stage a dashed inline-flex container, align-items: flex-start, follows "ab"; its baseline is on the line's, in red.
