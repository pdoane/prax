CSS Flexible Box Layout 2 · 9.2 Line Length Determination, step 3

Step 3: the flex base size

The first of five cases that applies sets an item's flex base size; this page shows A to D, and the next E. Items here neither grow nor shrink, so the flex base size is the size they show. CSS Flexible Box Layout 2 §9.2

A: a definite flex basis, and B: a ratio and a definite cross size

A: If the item has a definite used flex basis, that's the flex base size. B: If the flex item has a preferred aspect ratio, a used flex basis of content, and a definite cross size, then the flex base size is calculated from its used cross size and the flex item’s aspect ratio.

C: under a constraint, and D: an orthogonal item in infinite space

C: If the used flex basis is content or depends on its available space, and the flex container is being sized under a min-content or max-content constraint [...], size the item under that constraint. D: Otherwise, if [...] the available main size is infinite, and the flex item's inline axis is parallel to the main axis, lay the item out using the rules for a box in an orthogonal flow. The flex base size is the item's max-content main size.
