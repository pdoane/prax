CSS Flexible Box Layout 2 · 3 Flex Containers, not block containers

What block properties do not do in a flex container

Flex containers are not block containers, and so some properties that were designed with the assumption of block layout don't apply in the context of flex layout. CSS Flexible Box Layout 2 §3

float, clear and vertical-align

float and clear do not create floating or clearance of flex item, and do not take it out-of-flow. vertical-align has no effect on a flex item. Items 40px wide.

No first line, no first letter

the ::first-line and ::first-letter pseudo-elements do not apply to flex containers, and flex containers do not contribute a first formatted line or first letter to their ancestors. Red marks a first line or letter. CSS Pseudo-Elements 4 §2.1.1
