CSS Flexible Box Layout 2 · 9.2 Line Length Determination, step 3, the hypothetical main size

Step 3: the hypothetical main size

The hypothetical main size is the item's flex base size clamped according to its used min and max main sizes (and flooring the content box size at zero). CSS Flexible Box Layout 2 §9.2 Every stage here is 100px wide.

Clamped, and floored at zero

Lines are collected by the hypothetical main size: each stage wraps items of flex: none.

The flex base size is neither clamped nor floored

When determining the flex base size, the item’s min and max main sizes are ignored (no clamping occurs). And an item with a specified size of zero, positive padding, and box-sizing: border-box will have an outer flex base size of zero—and hence a negative inner flex base size.
