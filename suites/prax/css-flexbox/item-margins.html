CSS Flexible Box Layout 2 · 4.2 Flex Item Margins and Paddings

Flex item margins and paddings

The margins of adjacent flex items do not collapse. Auto margins expand to absorb extra space in the corresponding dimension. (§8.1 shows them.) CSS Flexible Box Layout 2 §4.2

No collapsing

A and B each have margin: 10px 0, and are 40px wide.

Percentages against the inline size

Percentage margins and paddings on flex items, like those on block boxes, are resolved against the inline size of their containing block, e.g. left/right/top/bottom percentages all resolve against their containing block's width in horizontal writing modes. Each stage is 200px wide and 80px tall.
