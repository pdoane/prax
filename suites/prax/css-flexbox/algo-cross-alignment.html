CSS Flexible Box Layout 2 · 9.6 Cross-Axis Alignment, steps 14 to 16

Steps 14 to 16: items, container, lines

Align all flex items along the cross-axis per align-self, if neither of the item's cross-axis margins are auto. Determine the flex container's used cross size using the rules of the formatting context in which it participates. If a content-based cross size is needed, use the sum of the flex lines' cross sizes. Align all flex lines per align-content. CSS Flexible Box Layout 2 §9.6
