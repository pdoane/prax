Resolving flexible lengths: inflexible items

Size inflexible items. Freeze, setting its target main size to its hypothetical main size… any item that has a flex factor of zero; if using the flex grow factor: any item that has a flex base size greater than its hypothetical main size; if using the flex shrink factor: any item that has a flex base size smaller than its hypothetical main size CSS Flexible Box Layout 2 §9.8

A factor of zero: the factor in use

Each stage is 200px. Which factor is zero matters only if it is the one the line uses.

Already clamped

An item whose min or max size moved its hypothetical main size away from its flex base size, against the direction of flexing, is frozen at once.
