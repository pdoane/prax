CSS Flexible Box Layout 2 · 5.3 Flex Direction and Wrap: the flex-flow shorthand

flex-flow: direction and wrap together

The flex-flow property is a shorthand for setting the flex-direction and flex-wrap properties, which together define the flex container's main and cross axes. Its value is <'flex-direction'> || <'flex-wrap'>. CSS Flexible Box Layout 2 §5.3

The specification's examples

Each stage holds A, B, C and D, 40px wide.

Writing-mode sensitive

Note that the flex-flow directions are writing mode sensitive. In vertical Japanese, for example, a row flex container lays out its contents from top to bottom. Each container is flex-flow: row wrap, 100px square, and holds five city names.
