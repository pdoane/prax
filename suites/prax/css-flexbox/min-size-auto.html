CSS Flexible Box Layout 2 · 4.5 Automatic Minimum Size of Flex Items

min-width: auto on flex items: the content size

the used value of a main axis automatic minimum size on a flex item whose computed overflow value is non-scrollable is its content-based minimum size; for main-axis scroll containers the automatic minimum size is zero, as usual. CSS Flexible Box Layout 2 §4.5

No narrower than the content's min-content size

The content size suggestion is the min-content size in the main axis. Each dashed container is 60px wide and holds two items of the word "flex", 40px; together they want 80px, so they shrink. An item whose overflow is hidden, scroll or auto is a scroll container, whose automatic minimum size is 0; clip does not scroll.

In a column: min-height

The main axis is vertical, so min-height: auto is the automatic minimum. Each dashed container is 30px wide and 40px tall, and holds two items of "ab cd", two lines and 40px tall in 30px.
