CSS Flexible Box Layout 2 · 9.10.1.3 Multi-line Min-content Algorithm

The min-content size of a multi-line flex container

For a multi-line container, the min-content main size is simply the largest min-content contribution of all the non-collapsed flex items in the flex container. CSS Flexible Box Layout 2 §9.10.1.3

The largest contribution, not the sum

Each dashed container has width: min-content, and items "aaa bb", "cccc" and "dd": min-content contributions of 30px, 40px and 20px.
