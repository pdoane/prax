align-content: one line, and lines that overflow

Note, this property has no effect on a single-line flex container. CSS Flexible Box Layout 2 §8.4

Single-line, or multi-line with one line

In a multi-line flex container (even one with only a single line), the cross size of each line is the minimum size necessary to contain the flex items on the line §6. Each stage is 60px tall, align-content: center, and holds A, 20px tall, with no height of its own.

Negative free space

Each stage is 30px tall and wraps two items 120px wide into two lines of 20px: −10px of free space. center: If the leftover free-space is negative, the lines will overflow equally in both directions. space-between falls back to safe flex-start, space-around to safe center, stretch to flex-start.
