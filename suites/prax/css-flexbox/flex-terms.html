Main and cross: the terms of flex layout

A flex container is the box generated by an element with a computed display of flex or inline-flex. In-flow children of a flex container are called flex items and are laid out using the flex layout model. CSS Flexible Box Layout 2 §2

Main axis and cross axis

The main axis of a flex container is the primary axis along which flex items are laid out. The axis perpendicular to the main axis is called the cross axis. Flex lines are filled with items and placed into the container starting on the cross-start side of the flex container and going toward the cross-end side. Items 60px wide; the stages wrap.

The main size property

Its main size property is either its width or height property, whichever is in the main dimension. In flex layout, the main size is controlled by the flex property rather than directly by the main size property. Each item has width: 40px; height: 40px.
