CSS Flexible Box Layout 2 · 9.10 Intrinsic Sizes

Intrinsic sizes of flex containers

The intrinsic sizing of a flex container is used to produce various types of content-based automatic sizing, such as shrink-to-fit logical widths (which use the fit-content formula) and content-based logical heights (which use the max-content size). CSS Flexible Box Layout 2 §9.10

Shrink-to-fit widths

Each dashed flex container, the first three of "aaa" and "bb", 30px and 20px of text, is sized by the fit-content formula CSS Box Sizing 3 §2.1.

Content-based heights; auto margins as 0

A column container's automatic height is its max-content height. For these computations, auto margins on flex items are treated as 0.
