CSS Flexible Box Layout 2 · 5.2 Flex Line Wrapping: the flex-wrap property

flex-wrap: balance

The flex container is multi-line, and attempts to balance the lengths of the flex lines to be as similar as possible. CSS Flexible Box Layout 2 §5.2 Each stage holds A, B, C and D, 60px wide and flex: none, 240px in all.

Balanced lines, which wrap packs

balance can be combined with wrap or wrap-reverse to dictate which direction the flex lines are stacked in. If neither are specified, it behaves as if wrap was specified.
