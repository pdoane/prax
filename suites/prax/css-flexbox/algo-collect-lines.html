CSS Flexible Box Layout 2 · 9.3 Main Size Determination, step 5

Step 5: collecting items into lines

starting from the first uncollected item, collect consecutive items one by one until the first time that the next collected item would not fit into the flex container's inner main size [...]. If the very first uncollected item wouldn't fit, collect just it into the line. For this step, the size of a flex item is its outer hypothetical main size.
