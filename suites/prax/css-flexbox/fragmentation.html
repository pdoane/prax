CSS Flexible Box Layout 2 · 10 Fragmenting Flex Layout

Flex containers across columns

Flex containers can break across pages between items, between lines of items (in multi-line mode), and inside items. CSS Flexible Box Layout 2 §10 Pages cannot be shown here, but The same rules apply in any other fragmentation context: each stage is two columns 90px wide and 40px tall CSS Multi-column Layout 1 §3.2.

Between items, between lines

In a column flex container, Class A break opportunities occur between sibling flex items; in a row one, between sibling flex lines.

Forced breaks

In a column container, the break-before values on the first item are propagated to the flex container. Forced breaks on other items are applied to the item itself. In a row container, the break-before and break-after values on flex items are propagated to the flex line. The break-before values on the first line are propagated to the flex container. The narrow stages are two columns 53px wide; starred items are break-before: column, and grey blocks 20px tall.
