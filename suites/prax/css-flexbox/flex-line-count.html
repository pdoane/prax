CSS Flexible Box Layout 2 · 6.1 Minimum Flex Lines: the flex-line-count property

flex-line-count: a minimum number of lines

The flex-line-count property specifies a minimum flex line count that the flex container should create to balance the items across. CSS Flexible Box Layout 2 §6.1 Each stage's items are 40px wide and flex: none.

Lines to balance across

The minimum flex line count is clamped from above by the number of flex items in the flex container; it will only create as many lines as there are flex items.

The cross-axis space of each item

flex-line-count changes the available space in the cross axis for flex items: subtracting the size of N-1 gaps from the normal available space, then dividing the leftover by N; Percentages continue to resolve as normal; If the flex container is single-line [...], this property has no effect. Each stage is 100px tall with row-gap: 20px, flex-line-count: 2 and align-items: flex-start.
