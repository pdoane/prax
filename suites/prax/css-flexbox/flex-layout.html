CSS Flexible Box Layout 2 · 1 Introduction

Flex layout, a layout mode of its own

This module introduces a new layout mode, flex layout, which is designed for laying out more complex applications and webpages. CSS Flexible Box Layout 2 §1

The same children, block layout and flex layout

CSS 2.1's layout modes include block layout, designed for laying out documents. Each stage holds the same three children 40px wide: A of one 20px line, B 40px tall and C 30px.

Flexing and aligning

Flex layout is designed for laying out more complex applications: its items grow into the space there is and align in both axes.
