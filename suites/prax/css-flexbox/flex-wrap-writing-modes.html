CSS Flexible Box Layout 2 · 5.2 Flex Line Wrapping: the flex-wrap property, writing modes

flex-wrap in columns and other writing modes

For the values that are not wrap-reverse, the cross-start direction is equivalent to either the inline-start or block-start direction of the current writing mode (whichever is in the cross axis) and the cross-end direction is the opposite direction of cross-start. CSS Flexible Box Layout 2 §5.2

Columns and right to left

Each container holds A, B, C and D, 40px wide, and has align-content: flex-start, so its lines are packed at cross-start rather than stretched.
