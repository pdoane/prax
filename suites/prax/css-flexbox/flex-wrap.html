CSS Flexible Box Layout 2 · 5.2 Flex Line Wrapping: the flex-wrap property

flex-wrap: one line or many

The flex-wrap property controls whether the flex container is single-line or multi-line, and the direction of the cross-axis, which determines the direction new lines are stacked in. CSS Flexible Box Layout 2 §5.2

nowrap, wrap and wrap-reverse

Each stage holds A, B, C and D, 60px wide and flex: none, 240px in all. For the values that are not wrap-reverse, the cross-start direction is equivalent to either the inline-start or block-start direction of the current writing mode; When flex-wrap is wrap-reverse, the cross-start and cross-end directions are swapped.

Every line holds at least one item

Every line contains at least one flex item, unless the flex container itself is completely empty.
