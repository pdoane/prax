CSS Flexible Box Layout 2 · 9.9 Definite and Indefinite Sizes, cases 1 and 2

Definite main sizes after flexing

Although CSS Sizing defines definite and indefinite lengths, Flexbox has several additional cases where a length can be considered definite. CSS Flexible Box Layout 2 §9.9 Each stage is a column container; the blue item holds a purple child of height: 50%, which resolves only against a definite height.

1. The container's main size is definite

If the flex container has a definite main size, then the post-flexing main sizes of its flex items are treated as definite.

2. The flex basis is definite

If a flex item’s flex basis is definite, then its post-flexing main size is also definite. These containers have no height.
