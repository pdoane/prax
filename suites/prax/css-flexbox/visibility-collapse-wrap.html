CSS Flexible Box Layout 2 · 4.4 Collapsed Items, multi-line

visibility: collapse in a multi-line container

Flex line wrapping is re-done after collapsing, however, so the cross size of a flex container with multiple lines might or might not change. CSS Flexible Box Layout 2 §4.4

The items wrap again

Each dashed container is 100px wide and wraps, align-items: flex-start. A is 60px wide; B 60px wide and 40px tall; C 40px wide.

The cross size may stay

Now B is 40px wide, on A's line, and C 60px wide, on a line of its own.
