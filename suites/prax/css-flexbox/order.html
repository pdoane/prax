CSS Flexible Box Layout 2 · 5.4 Reordering and Accessibility: the order property

order: ordinal groups

The order property can be used to change flex items' ordering, laying them out in order-modified document order instead. CSS Flexible Box Layout 2 §5.4 Flex and grid containers lay out their contents in order-modified document order, starting from the lowest numbered ordinal group and going up. Items with the same ordinal group are laid out in the order they appear in the source document. CSS Display 4 §3

Lowest group first, ties in document order

Each stage holds A, B and C in that order in the document; order is 0 unless given.

Painting, and only flex and grid items

This also affects the painting order, exactly as if the flex items were reordered in the source document. Unless otherwise specified by a future specification, this property has no effect on boxes that are not flex items or grid items.
