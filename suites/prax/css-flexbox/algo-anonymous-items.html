CSS Flexible Box Layout 2 · 9.1 Initial Setup

Step 1: generate anonymous flex items

Generate anonymous flex items, as §4 describes. Flex layout works with the flex items in order-modified document order, not their original document order. CSS Flexible Box Layout 2 §9.1

Anonymous items are items like any other

The text is .pr-measure, 10px a letter; A is 40px wide. An anonymous item takes the initial values of its properties: order: 0 and flex: 0 1 auto.

Anonymous items align with align-items

For anonymous flex items, align-self always matches the value of align-items on their associated flex container. §8.3 Each stage is 60px tall, with align-items: center.
