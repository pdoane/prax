CSS Flexible Box Layout 2 · 4 Flex Items

Flex items: each child and each run of text

Each in-flow child of a flex container becomes a flex item, and each child text sequence is wrapped in an anonymous block container flex item. However, if the entire text sequences contains only document white space characters (i.e. characters that can be affected by the white-space property) it is instead not rendered (just as if its text nodes were display:none). Text between children

Text in each stage is .pr-measure, 10px a letter. The children A and B are 40px wide.

Inside an item

An inline child is blockified into one item, and a block inside it does not split it: flex items do not split around blocks. A flex item establishes an independent formatting context for its contents.
