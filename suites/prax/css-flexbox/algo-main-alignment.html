Step 12: distribute the remaining free space

If the remaining free space is positive and at least one main-axis margin on this line is auto, distribute the free space equally among these margins. Otherwise, set all auto margins to zero. Align the items along the main-axis per justify-content. CSS Flexible Box Layout 2 §9.5
