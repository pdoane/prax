Step 5: how many lines to balance across

If the flex container is multi-line and balancing, First determine how many flex lines will be produced by the non-balancing algorithm, above. For this purpose, floor the outer hypothetical main size of each flex item at zero. Let the balancing line count be the larger of this line count and the minimum flex line count. Then, balance flex items across balancing line count number of lines. CSS Flexible Box Layout 2 §9.3 Each stage is 200px wide.
