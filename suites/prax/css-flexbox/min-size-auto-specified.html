CSS Flexible Box Layout 2 · 4.5 Automatic Minimum Size of Flex Items, specified size suggestion

min-width: auto: capped by the specified size

For non-replaced elements, the content-based minimum size is the larger of the content size suggestion and the transferred size suggestion (if one exists), capped by the specified size suggestion (if one exists). In either case, the size is clamped by the maximum main size if it's definite. CSS Flexible Box Layout 2 §4.5

The specified size suggestion, and a definite maximum

If the item's preferred main size is definite and not automatic, then the specified size suggestion is that size. It is otherwise undefined. Each item holds "flexbox", 70px, alone in a dashed container 20px wide unless given.

In a column

Each dashed column container is 40px wide and 20px tall; its item holds "ab cd ef", three lines, 60px tall.
