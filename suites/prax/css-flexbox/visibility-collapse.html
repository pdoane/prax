CSS Flexible Box Layout 2 · 4.4 Collapsed Items

visibility: collapse on flex items

the collapsed flex item is removed from rendering entirely, but leaves behind a "strut" that keeps the flex line's cross-size stable. Thus, if a flex container has only one flex line, dynamically collapsing or uncollapsing items may change the flex container's main size, but is guaranteed to have no effect on its cross size. CSS Flexible Box Layout 2 §4.4

A strut keeps the cross size

Each dashed inline-flex container holds A, 40px wide, B, 40 by 60, and C, 40px wide; A and C have no height of their own, so they stretch to the line.

In a column, and still in the formatting structure

A column: the strut keeps the line's width, B's 60px; A, B and C are 20px tall. And effects that depend on a box appearing in the formatting structure (like incrementing counters or running animations and transitions) still operate on collapsed items.
