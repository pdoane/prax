CSS Flexible Box Layout 2 · 4.5 Automatic Minimum Size of Flex Items, transferred size suggestion

min-width: auto: through the aspect ratio

If the item has a preferred aspect ratio and its preferred cross size is definite, then the transferred size suggestion is that size (clamped by its minimum and maximum cross sizes if they are definite), converted through the aspect ratio. CSS Flexible Box Layout 2 §4.5

The larger of content and transferred sizes, capped by the specified size

For a non-replaced item, Use the larger of the content size suggestion and the transferred size suggestion. Each item has aspect-ratio: 2 / 1 and holds "ab", 20px, in a dashed container 40px wide.

The content size, clamped through the ratio

The content size suggestion is the min-content size, clamped, if it has a preferred aspect ratio, by any definite minimum and maximum cross sizes converted through the aspect ratio. Each item has aspect-ratio: 1 / 1, no height, and holds "flexbox", 70px, in a dashed container 20px wide.
