CSS Flexible Box Layout 2 · 8.5 Flex Container Baselines, cross-axis baseline set

A flex container's baseline, across its main axis

When the inline axis of the flex container matches its cross axis, the flex container's first/last cross-axis baseline set is generated from the alignment baseline of the startmost/endmost flex item. Scrolled boxes, and table cells

if the box contributing a baseline has an overflow value that allows scrolling, the box must be treated as being in its initial scroll position. When determining the baseline of a table cell, a flex container provides a baseline just as a line box or table-row does.
