CSS Flexible Box Layout 2 · 9.10.1.1 Ideal Algorithm: Max-content Size and Min-content Single-line Size

The ideal intrinsic sizing algorithm

The following algorithm calculates the flex container’s ideal intrinsic main sizes. It is not Web-compatible. CSS Flexible Box Layout 2 §9.10.1.1 A browser may follow it or the Web-compatible algorithm §9.10.1.2; each caption gives both.

The specification's example

if a flex container has a single flex item with flex-basis: 100px; but a max-content size of 200px, then when the item is flex-grow: 0, the flex container (and flex item) is 100px wide, but when the item is flex-grow: 1 or higher, the flex container (and flex item) is 200px wide. if the item has flex-grow: .5, then the flex container ends up 150px wide, ending up 125px wide. Here at half the scale: each dashed container is a float around an item of basis 50px and text "aaaa bbbbb", 100px.

Flex factors keep their ratio

The ideal size is the one at which every flex item is at least the size of its max-content contribution, but also has the correct ratio of its size to the size of the other items, as determined by its flexibility. The items are "aaaaa", 50px each, with flex: 1 1 0px and flex: 3 1 0px, a basis of 0.
