CSS Flexible Box Layout 2 · 9.10.1 Flex Container Intrinsic Main Sizes

Intrinsic main sizes of a flex container

For max-content sizes and for single-line min-content sizes, an implementation is conformant to CSS Flexible Box Layout if it conforms to either the Ideal Algorithm or the Web-compatible Algorithm. CSS Flexible Box Layout 2 §9.10.1

The max-content main size

the smallest size the flex container can take such that when flex layout is run with that container size, each flex item ends up at least as large as its max-content contribution, to the extent allowed by the items’ flexibility. Each dashed container is a row with width: max-content, of "aaa bbb" (70px) and "cc" (20px).

The min-content main size

the smallest size the flex container can take such that no items overflow it, and no item's contents overflow the item. Each container is a single-line row with width: min-content.
