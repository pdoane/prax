Resolving flexible lengths: growing

Determine the used flex factor. Sum the outer hypothetical main sizes of all items on the line. If the sum is less than the flex container's inner main size, use the flex grow factor for the rest of this algorithm; otherwise, use the flex shrink factor. CSS Flexible Box Layout 2 §9.8

Free space, shared by the grow factors

Calculate initial free space. Sum the outer sizes of all items on the line, and subtract this from the flex container's inner main size. For frozen items, use their outer target main size; for other items, use their outer flex base size. Then Set the item's target main size to its flex base size plus a fraction of the remaining free space proportional to the ratio. Each stage is 200px.
