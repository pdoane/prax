CSS Flexible Box Layout 2 · 7.2.3 The flex-basis property, percentages

flex-basis: percentages

Percentages are relative to the flex container's inner main size. For example, percentage values of flex-basis are resolved against the flex item's containing block (i.e. its flex container); and if that containing block's size is indefinite, the used value for flex-basis is content.
