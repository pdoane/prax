CSS Flexible Box Layout 2 · 4.3 Flex Item Z-Ordering

Flex items paint like inline blocks

Flex items paint exactly the same as inline blocks, except that order-modified document order is used in place of raw document order, and z-index values other than auto create a stacking context even if position is static (behaving exactly as if position were relative).
