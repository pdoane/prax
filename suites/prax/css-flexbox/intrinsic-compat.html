CSS Flexible Box Layout 2 · 9.10.1.2 Web-compatible Intrinsic Sizing Algorithm: Max-content Size and Min-content Single-line Size

The Web-compatible intrinsic sizing algorithm

The following algorithm has been demonstrated to be Web-compatible. CSS Flexible Box Layout 2 §9.10.1.2

max-content: the sum of max-content contributions

For the max-content size of a flex container, take the sum of the max-content contributions of all the non-collapsed flex items in the flex container. Each dashed row has width: max-content, and items "aaa" (30px) and "cccc" (40px).

min-content: the sum of min-content contributions

For the min-content size of a single-line container, take the sum of the min-content contributions of all the non-collapsed flex items in the flex container. Rows of "aaa bb" and "cccc" with width: min-content.
