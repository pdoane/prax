CSS Flexible Box Layout 2 · 4.5 Automatic Minimum Size of Flex Items, percentages

min-width: auto and percentages inside the item

For the purpose of calculating an intrinsic size of the box (e.g. the box's min-content size), a content-based minimum size causes the box's size in that axis to become indefinite (even if e.g. its width property specifies a definite size). Note this means that percentages calculated against this size will behave as auto. CSS Flexible Box Layout 2 §4.5

Indefinite while the minimum is found

Each blue item, width: 100px, is alone in a dashed container 20px wide, and holds an orange block of width: 50% of "flexbox", 70px. For the item's min-content size, 50% behaves as auto: 70px.
