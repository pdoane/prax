CSS Flexible Box Layout 2 · 9.10.3 Flex Item Intrinsic Size Contributions

Flex item contributions: content and preferred size

The main-size max-content contribution of a flex item is the larger of its outer max-content size and outer preferred size if that is not an automatic size. CSS Flexible Box Layout 2 §9.10.3

The larger of content and width

Each dashed row is width: max-content around one item of flex: auto, which can grow and shrink, so that its flex base size does not cap or floor its contribution §9.10.3.

The min-content contribution

The main-size min-content contribution of a flex item is the larger of its outer min-content size and outer preferred size if that is not an automatic size. Each row is width: min-content, of "aaa bbb" (min-content 30px) and "cc".
