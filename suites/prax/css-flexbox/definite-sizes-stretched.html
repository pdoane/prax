CSS Flexible Box Layout 2 · 9.9 Definite and Indefinite Sizes, cases 3 and 4

Definite cross sizes of stretched items

Flexbox has several additional cases where a length can be considered definite. CSS Flexible Box Layout 2 §9.9 Each stage is a row container; the blue items stretch, and hold a purple child of height: 50%.

3. A single line of definite cross size

If a single-line flex container has a definite cross size, the automatic preferred outer cross size of any stretched flex items is the flex container's inner cross size (clamped to the flex item’s min and max cross size) and is considered definite.

4. Once the line's cross size is known

Once the cross size of a flex line has been determined, the cross sizes of items in auto-sized flex containers are also considered definite for the purpose of layout. These containers have no height; B sets the line.
