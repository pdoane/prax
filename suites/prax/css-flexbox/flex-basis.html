CSS Flexible Box Layout 2 · 7.2.3 The flex-basis property

flex-basis: auto, content and lengths

The flex-basis property sets the flex basis. It accepts the same values as the width and height property, plus content. CSS Flexible Box Layout 2 §7.2.3 Each item here neither grows nor shrinks and has min-width: 0, so its width is its basis; its word "abcd" is 40px.

auto and content

auto retrieves the value of the main size property as the used flex-basis. If that value is itself auto, then the used value is content. content Indicates an automatic size based on the flex item’s content. §7.1

Lengths, and the box they size

Lengths resolve the same way as width in horizontal writing modes. As another corollary, flex-basis determines the size of the content box, unless otherwise specified such as by box-sizing.
