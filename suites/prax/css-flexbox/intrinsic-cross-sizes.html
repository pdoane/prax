CSS Flexible Box Layout 2 · 9.10.2 Flex Container Intrinsic Cross Sizes

Intrinsic cross sizes of a flex container

The min-content/max-content cross size of a single-line flex container is the largest min-content contribution/max-content contribution (respectively) of its flex items. CSS Flexible Box Layout 2 §9.10.2

Single-line: the largest contribution

Each dashed container is a column, so its width is its cross size, of "aaa bbb" (70px, or 30px wrapped) and "cccccc" (60px).

Row, multi-line: the sum of the lines

The min-content/max-content cross size is the sum of the flex line cross sizes resulting from sizing the flex container under a cross-axis min-content constraint/max-content constraint (respectively). Boxes 80px long in the main axis, of cross sizes 20px, 40px and 30px, wrap two to a line.
