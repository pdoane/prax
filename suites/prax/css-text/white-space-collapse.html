white-space-collapse

This property specifies whether and how white space is collapsed. CSS Text 4 §4.1 Each stage is 120px wide, of 10px letters, with tab-size: 4, and its source is "a", three spaces, "b", a newline, two spaces, "c", a tab, "d". The text is highlighted to show its spaces.

collapse, preserve and preserve-breaks

preserve-spaces and discard

preserve-spaces: This value prevents user agents from collapsing sequences of white space, and converts tabs and segment breaks to spaces. discard: This value directs user agents to “discard” all white space in the element. Whether a discarded space leaves its wrap opportunity is an open issue in the draft.
