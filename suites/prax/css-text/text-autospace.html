CSS Text 4 · 8.4 Automatic Contextual Spacing: the text-autospace property

text-autospace

Controls spacing between adjacent characters on the same line within the same inline formatting context using a set of character-class-based rules, allowing for automatic control over inter-script spacing and for spacing around punctuation.
