CSS Text 4 · 6.3.3 Hyphenation Size Limit: the hyphenate-limit-zone property

hyphenate-limit-zone

This property specifies the maximum amount of unfilled space (before justification) that may be left in the line box before hyphenation is triggered to pull part of a word from the next line back up into the current line. CSS Text 4 §6.3.3 No browser has the property. Each stage is lang=en, hyphens: manual, 120px wide, of 10px letters, and holds "a bit hyper&shy;active".

Hyphenate only past the zone

"a bit" leaves 70px unfilled; "hyper-" would fit in it.
