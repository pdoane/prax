CSS Text 4 · 6.2 Line Breaking Strictness: the line-break property

line-break: what only loose allows

loose: Breaks text using the least restrictive set of line-breaking rules. CSS Text 4 §6.2 In each figure, lang=ja, 100px wide, five 20px characters to a line, the stage above is normal and the one below loose. The character the rule is about is blue.

Iteration marks and inseparables

Forbidden for normal and strict, allowed in loose: breaks before iteration marks, breaks between inseparable characters (such as ‥ U+2025, … U+2026).

Centered punctuation, suffixes and prefixes

Allowed for loose if the writing system is Chinese or Japanese: breaks before certain centered punctuation marks, breaks before suffixes, breaks after prefixes. And if the preceding character is of class ID, breaks before hyphens.
