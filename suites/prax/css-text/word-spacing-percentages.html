CSS Text 4 · 8.1 Word Spacing: the word-spacing property

word-spacing: percentages and placement

Specifies extra spacing in addition to the intrinsic inter-word spacing defined by the font. Percentages inherit intact, and are resolved against the used 'font-size' of the current element CSS Text 4 §8.1 CSS 2's page has lengths. Letters are 10px wide, so a space is 10px.

A percentage of the font size

Only at separators left after collapsing

Additional spacing is applied to each word separator left in the text after the white space processing rules have been applied.
