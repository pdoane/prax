CSS Text 4 · 2.3 Order of Operations

The order of transforms

When multiple transformations need to be applied, they are applied in the following order: 'word-space-transform', 'capitalize', 'uppercase', and 'lowercase', 'full-width', 'full-size-kana' CSS Text 4 §2.3 Text is 20px PR Noto Sans JP.

Case before width

After collapsing, before trimming

Word space transformation and text transformation happen after Phase I: Collapsing and Transformation but before Phase II: Trimming and Positioning. This means for instance that 'full-width' only transforms spaces (U+0020) to U+3000 IDEOGRAPHIC SPACE within preserved white space. White space that was not removed or collapsed due to white space processing is called preserved white space. §4.1
