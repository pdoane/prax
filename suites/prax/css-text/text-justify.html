CSS Text 4 · 7.5 Justification Method: the text-justify property

text-justify

This property selects the justification method used when a line’s alignment is set to 'justify' (see 'text-align'). CSS Text 4 §7.5 Each stage is 200px wide and text-align: justify, and holds "one two six", highlighted, and "seventeens", which goes to the second line. The first line has 110px of 10px letters, so 90px to share.

none and inter-word

none: Justification is disabled: there are no justification opportunities within the text. inter-word: Justification adjusts spacing at word separators only (effectively varying the used 'word-spacing' on the line).

inter-character, and distribute

Space between two units should be applied under the same rules as for 'letter-spacing' §7.5.1, so none at the line's ends. inter-character: Justification adjusts spacing between each pair of adjacent typographic character units (effectively varying the used 'letter-spacing' on the line). For legacy reasons, UAs must also support the alternate keyword distribute which must compute to 'inter-character', thus having the exact same meaning and behavior.
