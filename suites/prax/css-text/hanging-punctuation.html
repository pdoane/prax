CSS Text 4 · 9.2.1 Hanging Punctuation: the hanging-punctuation property

hanging-punctuation: first and last

This property determines whether a punctuation mark, if one is present, hangs and may be placed outside the line box (or in the indent) at the start or at the end of a line of text. CSS Text 4 §9.2.1 Each stage is 120px wide; the text is highlighted, so a hanging mark shows outside the stage.

first

An opening bracket, quote, or ideographic space at the start of the first formatted line of an element hangs. This applies to all characters in the Unicode categories Ps, Pf, Pi plus the ASCII quote marks U+0027 ' APOSTROPHE and U+0022 " QUOTATION MARK and the IDEOGRAPHIC SPACE U+3000. Letters are 10px wide.

last, and one at each edge

A closing bracket or quote at the end of the last formatted line of an element hangs. At most one punctuation character may hang at each edge of the line. Each stage is right-aligned.
