CSS Text 4 · 6.3.1 Hyphenation Control: the hyphens property

hyphens: none, manual, auto

This property controls whether hyphenation is allowed to create more soft wrap opportunities within a line of text. CSS Text 4 §6.3.1 Each stage is lang=en, 70px wide, seven 10px letters to a line.

A soft hyphen

The stages hold "hyphen", U+00AD SOFT HYPHEN, "ation". manual, the initial value: Words are only hyphenated where there are characters inside the word that explicitly suggest hyphenation opportunities. none: Words are not hyphenated, even if characters inside the word explicitly define hyphenation opportunities.

auto

Words may be broken at hyphenation opportunities determined automatically by a language-appropriate hyphenation resource in addition to those indicated explicitly by a conditional hyphen. Automatic hyphenation opportunities elsewhere within a word must be ignored if the word contains a conditional hyphen.
