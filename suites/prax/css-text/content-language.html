CSS Text 4 · 1.3 Languages and Typesetting

The content language

In CSS, language-specific typographic tailorings are only applied when the content language is known (declared). untagged content ... is considered to have an unknown content language. CSS Text 4 §1.3 Each pair is the same text, tagged and untagged (lang="").

Hyphenation needs a language

The UA must therefore only automatically hyphenate text for which the content language is known and for which it has an appropriate hyphenation resource. §6.3.1 Each stage is 100px wide, of 10px letters, with hyphens: auto.

Breaking rules for Japanese need Japanese

Under line-break: normal, a break before U+301C WAVE DASH is allowed if the writing system is Chinese or Japanese, and are otherwise forbidden. §6.2 Each stage is 100px wide, five 20px characters; the wave dash is the sixth.
