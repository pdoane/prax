CSS Text 4 · D Scripts and Spacing

Scripts and spacing

This appendix categorizes some common scripts in Unicode 6.0 according to their justification and spacing behavior. Category descriptions are descriptive, not prescriptive; the determining factor is the prioritization of justification opportunities. CSS Text 4 §D The appendix is normative. Each stage is 120px wide, inter-character, its one line justified.

Block, clustered and cursive scripts, and Indic

Ambiguous characters, by writing system

Block scripts include Wide and Fullwidth characters, but Ambiguous characters are included only if the writing system is Chinese, Korean, or Japanese. The stages hold "○", U+25CB, Ambiguous, between Latin letters.
