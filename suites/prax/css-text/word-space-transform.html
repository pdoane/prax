CSS Text 4 · 2.2 Expanding Between Words: the word-space-transform property

word-space-transform

This property allows authors to change the rendering from one style to another without needing to change the markup. For the purpose of this property, expandable separators are any of: U+200B ZERO WIDTH SPACE characters, <wbr> elements, virtual expandable separators CSS Text 4 §2.2 Japanese is 20px PR Noto Sans JP, 20px a character.

space and ideographic-space

space: Expandable separators within the child text of this element are replaced by U+0020 SPACE. ideographic-space: ... are replaced by U+3000 IDEOGRAPHIC SPACE. The Japanese stages are むかしむかし、<wbr>あるところに、<wbr>おじいさんと.

Not beside a forced break

The user agent must not replace expandable separators immediately preceding or following a forced line break.
