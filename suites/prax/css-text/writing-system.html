CSS Text 4 · F Identifying the Content Writing System

The content writing system

When no writing system is explicitly indicated, UAs should assume the most common writing system of the declared content language for language-sensitive typographic behaviors such as line-breaking or justification. However, UAs must not assume that writing system if the author has explicitly declared a different one. CSS Text 4 §F The test: under line-break: normal, a break before 〜 is allowed only if the writing system is Chinese or Japanese. Each stage is 100px wide, five 20px characters, then 〜, in blue.
