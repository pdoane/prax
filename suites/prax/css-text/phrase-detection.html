CSS Text 4 · H Word and Phrase Detection

Word and phrase detection

By themselves, word and phrase boundaries are not observable, but properties like 'word-space-transform' or 'word-break' can cause visible effects at those positions. CSS Text 4 §H The appendix is normative. Each stage is lang=ja, word-break: auto-phrase, 120px wide, six characters to a line, and holds 窓ぎわのトットちゃん, phrases 窓ぎわの and トットちゃん, in a UA that detects Japanese phrases, as Chrome does; Safari and Firefox do not, and break as normal.

No boundary at a joiner

The user agent must not place a word or phrase boundary adjacent to any characters with the line breaking class GL, WJ, or ZWJ; when two would-be words or phrases are separated by such characters, they must be treated as a single one.

Boundaries ignore inline boxes

Inline box boundaries and out-of-flow elements must be ignored when determining word or phrase boundaries.
