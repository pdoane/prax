CSS Text 4 · 9.3 Bidirectionality and Line Boxes

The direction of each line box

The start and end sides of a line box are determined by the inline base direction of the line box. if its containing block has 'unicode-bidi: plaintext': If the bidi paragraph to which the line box belongs ... has strong directionality, the line box’s inline base direction is that direction. CSS Text 4 §9.3

Each paragraph its own direction

The specification's example: a pre, text-align: start, of lines in French and Persian alternately. every other line is right-aligned.

Empty or neutral lines take the line before

If the line box is empty ... or otherwise has no strong directionality (contains only weak or neutral characters), its inline base direction is taken from the preceding line box (if any), or, if this is the first line box in the containing block, from the 'direction' property of the containing block. The stages are direction: rtl, unicode-bidi: plaintext, pre, and text-align: start.
