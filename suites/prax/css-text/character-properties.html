The properties of a typographic character unit

For the purposes of CSS Text, the properties of a typographic character unit are given by the base character of its first grapheme cluster—except in two cases. CSS Text 4 §E The appendix is normative.

A space with a mark is a symbol

Grapheme clusters formed with a Space Separator (Zs) as the base are considered to be Modifier Symbols (Sk). So a space carrying a combining mark is not a word separator. Each stage has word-spacing: 20px; the words are highlighted.
