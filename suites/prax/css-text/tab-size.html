CSS Text 4 · 4.4 Tab Character Size: the tab-size property

tab-size

A <number> represents the measure as a multiple of the advance width of the space character (U+0020) of the nearest block container ancestor of the preserved tab, including its associated 'letter-spacing' and 'word-spacing'.
