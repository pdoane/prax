CSS Text 4 · 7.4 Last Line Alignment: the text-align-last property

text-align-last

This property describes how the last line of a block or a line right before a forced line break is aligned. If auto is specified, content on the affected line is aligned per 'text-align-all' unless 'text-align-all' is set to 'justify', in which case it is 'start'-aligned.
