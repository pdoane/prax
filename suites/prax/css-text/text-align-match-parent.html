CSS Text 4 · 7.1 Text Alignment: the text-align shorthand

text-align: match-parent

match-parent: This value behaves the same as 'inherit' (computes to its parent’s computed value) except that an inherited value of 'start' or 'end' is interpreted against the parent’s 'direction' value and results in a computed value of either 'left' or 'right'. Computes to 'start' when specified on the root element. CSS Text 4 §7.1 In each stage a left-to-right block, of one 30px box, is inside a parent; guides are 10px apart.
