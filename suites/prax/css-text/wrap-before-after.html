CSS Text 4 · 5.3 Controlling Breaks Between Boxes: the wrap-before/wrap-after properties

wrap-before and wrap-after

These properties specify modifications to break opportunities in line breaking (and flex line breaking [CSS3-FLEXBOX]). CSS Text 4 §5.3 No browser has them. Letters are 10px wide; the box they are set on is highlighted.

Forcing a break

line: Force a line break immediately before/after the box if the box is an inline-level box. flex: Force a flex line break immediately before/after the box if the box is a flex item in a multi-line flex container.

Avoiding a break

avoid: Line breaking is suppressed immediately before/after the box: the UA may only break there if there are no other valid break points in the line. Each stage is 70px wide, and holds "aa bb cc", "cc" in the box.
