CSS Text 4 · 6.1 Breaking Rules for Letters: the word-break property

word-break: auto-phrase and manual

auto-phrase: this value directs the user agent to perform language-specific content analysis to prioritize keeping natural phrases (of multiple words) together. If the content language of the element is unknown, or if the user agent does not know how to detect phrase boundaries for that particular language, this value must behave as 'normal'. CSS Text 4 §6.1 Each stage is 120px wide.

auto-phrase

The specification's title, 窓ぎわのトットちゃん, 20px a character, six to a line.

manual

manual: Behaves the same as 'normal', except that Lexical Word Breaking must not be performed. The stages are Thai, ภาษาไทยง่ายมาก, "Thai is very easy", with a <wbr> after ภาษาไทย.
