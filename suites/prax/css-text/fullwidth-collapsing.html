CSS Text 4 · 8.5.1 Fullwidth Punctuation Collapsing

Fullwidth punctuation collapsing

unless 'text-spacing-trim' is set to 'space-all' (or the font has proportional fullwidth punctuation glyphs), the UA must collapse the space typically associated with such full width glyphs when placed adjacently on a line CSS Text 4 §8.5.1 At 24px, a trimmed glyph is 12px narrower. In each figure the stage above is space-all, the one below normal.

An opening bracket after

Set half-width if the previous character is any of: a fullwidth opening punctuation, a fullwidth middle dot punctuation, an ideographic space (U+3000), a fullwidth closing punctuation of an equivalent or larger 'font-size'.

A closing bracket before

Set half-width if the next character is any of: a fullwidth closing punctuation, a fullwidth middle dot punctuation, an ideographic space (U+3000), a fullwidth opening punctuation of a larger 'font-size'.
