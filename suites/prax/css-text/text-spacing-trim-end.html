CSS Text 4 · 8.5 CJK Punctuation Spacing: the text-spacing-trim property

text-spacing-trim at the end of lines

normal: set fullwidth closing punctuation with half-width glyphs (flush) at the end of each line if it does not otherwise fit prior to justification, else set the punctuation with full-width glyphs. trim-both: set fullwidth closing punctuation with half-width glyphs (flush) at the end of each line.
