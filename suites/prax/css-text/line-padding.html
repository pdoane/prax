CSS Text 4 · 8.3 Line Start/End Padding: the line-padding property

line-padding

The extra spacing is applied only by the innermost inline box at the start/end of the line box, and is inserted between that inline box’s content edge and the adjacent inline-level content (text or atomic inline). This extra space is not a justification opportunity. CSS Text 4 §8.3 No browser has the property. Letters are 10px wide.

The specification's example

p { line-padding: 0.5em; text-align: center }, <span>Here is <em>some text</em></span>, the span black, the em green. The stage is 110px wide, so the line breaks between "some" and "text".

Not stretched by justification
