CSS Text 4 · 7.2 Character-based Alignment in a Table Column

Aligning on a character

When multiple cells in a column have an alignment character specified, the alignment character of each such cell in the column is centered along a single column-parallel axis and the rest of the text in the column shifted accordingly. CSS Text 4 §7.2 No browser has it. Letters are 10px wide.

The specification's column of figures

Each cell is text-align: "." center. If the alignment character appears more than once in the text, the first instance is used for alignment. If the alignment character does not appear in a cell at all, the string is aligned as if the alignment character had been inserted at the end of its contents.
