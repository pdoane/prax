CSS Text 4 · 2.1.1 Mapping Rules

Case mapping rules

The UA must use the full case mappings for Unicode characters, including any conditional casing rules, as defined in the Default Case Algorithms section of The Unicode Standard. CSS Text 4 §2.1.1 CSS 2's page shows titlecase and "ß" to "SS"; this one the conditional rules and Turkish's.

Conditional mappings

Language-specific rules, where the language is known

If (and only if) the content language of the element is, according to the rules of the document language, known, then any appropriate language-specific rules must be applied as well. These minimally include, but are not limited to, the language-specific rules in Unicode’s SpecialCasing.txt.
