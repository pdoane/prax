CSS Text 4 · 4 White Space Processing & Control Characters

Segment breaks and ignorable characters

For CSS processing, each document language–defined “segment break” or “newline sequence”—or if none are defined, each line feed (U+000A)—in the text is treated as a segment break, which is then interpreted for rendering as specified by the 'white-space' property. Line feeds, not carriage returns, in the DOM

Unlike HTML, the DOM does not give any particular meaning to carriage returns (U+000D), so they are not treated as segment breaks. Carriage returns (U+000D) are treated identically to spaces (U+0020) in all respects. Each stage is pre-line, of 10px letters, and its text is set by script.

Default-ignorable characters

As required by Unicode, unsupported Default_ignorable characters must be ignored for text rendering. Each stage is "a", the character, "b", of 10px letters.
