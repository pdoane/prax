CSS Text 4 · 8.2 Tracking: the letter-spacing property

letter-spacing and ligatures

When the effective spacing between two characters is not zero (due to either justification or a non-zero value of 'letter-spacing'), user agents should not apply optional ligatures, i.e. those that are not defined as required for fundamentally correct glyph shaping. However, ligatures and other font features specified via the low-level 'font-feature-settings' property take precedence over this rule.
