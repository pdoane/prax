CSS Text 4 · 8.5 CJK Punctuation Spacing: the text-spacing-trim property

text-spacing-trim at the start of lines

Controls spacing around CJK punctuation characters on the same line within the same inline formatting context using a set of character-class-based rules, allowing them to be set halfwidth or fullwidth based on their position and neighbors within the line. CSS Text 4 §8.5 Each stage is lang=ja, 120px wide, eight 15px characters to a line: 「あいうえおかき「さしす」, a <br>, 「た」. Lines 1 and 3 start after a start or a forced break, line 2 after a soft wrap. A full-width 「 has 7.5px blank before its ink.

Full-width, or trimmed, at each line's start

space-all: All fullwidth punctuation characters are set with full-width glyphs (spaced). normal: Set fullwidth opening punctuation with full-width glyphs (spaced) at the start of each line. trim-start: Set fullwidth opening punctuation with half-width glyphs (flush) at the start of each line. space-first: full-width on the first line of the block container and each line after a forced line break. trim-all: half-width without regards for the position within the line nor for adjacent characters.
