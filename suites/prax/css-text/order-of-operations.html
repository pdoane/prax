CSS Text 4 · A Text Processing Order of Operations

The order of text operations

The following list defines the order of text operations. (Implementations are not bound to this order as long as the resulting layout is the same.) CSS Text 4 §A The appendix is normative. Each figure shows a step taking effect before a later one.

Transforming before wrapping

Text transformation comes before text wrapping, so a transform that widens the text changes where lines break.

Hanging, then alignment

Hanging punctuation comes before justification and text alignment.
