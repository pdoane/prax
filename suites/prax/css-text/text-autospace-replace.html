CSS Text 4 · 8.4 Automatic Contextual Spacing: the text-autospace property

text-autospace: insert, replace, punctuation

insert: The specified spacing is automatically inserted if there are no space characters of any kind (Unicode general category Z) already there. replace: The specified spacing is automatically inserted even if there is already a space (U+0020) at that point; additionally, the space (U+0020) is removed. CSS Text 4 §8.4 Ideographs are 40px; the autospace is 5px.

punctuation, in French

if the element's content language is French, narrow no-break space (U+202F) and no-break space (U+00A0) is inserted where required by French typographic guidelines. Otherwise this value has no effect. The stages are « Oui ! » with no spaces in the source.
