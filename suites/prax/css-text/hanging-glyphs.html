CSS Text 4 · 9.2 Hanging Glyphs

Hanging glyphs

When a glyph at the start or end edge of a line hangs, it is not considered when measuring the line’s contents for fit, alignment, or justification. The hanging glyph is also not taken into account when computing intrinsic sizes (min-content size and max-content size), and any sizes derived thereof. CSS Text 4 §9.2 Preserved spaces under pre-wrap, which hang, show the rules. Letters are 10px wide; the text is highlighted.

Not in intrinsic sizes

Each box is shrink-to-fit, dashed, around pre-wrap text. Glyphs that conditionally hang are not taken into account when computing min-content sizes and any sizes derived thereof, but they are taken into account for max-content sizes.

Padding stops a glyph hanging

Non-zero inline-axis borders or padding between a hangable glyph and the edge of the line prevent the glyph from hanging. Each stage is 60px wide, right-aligned, pre-wrap; "aaaa", then two spaces in a span, then "bb".
