CSS Text 4 · 1.5 Text Processing

Text processing across boxes

For the purpose of determining adjacency for text processing (such as white space processing, text transformation, line-breaking, etc.), and thus in general within this specification, intervening inline box boundaries and out-of-flow elements must be ignored. CSS Text 4 §1.5
