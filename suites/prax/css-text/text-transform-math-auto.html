CSS Text 4 · 2.1 Case Transforms: the text-transform property

text-transform: math-auto

This property transforms text for styling purposes. CSS Text 4 §2.1 Its value math-auto is defined by MathML Core, to which the definition points: text that is a single character with a Mathematical Italic form is drawn as that form, so a lone "x" becomes U+1D465 MATHEMATICAL ITALIC SMALL X, and any other text is left as it is. The font is PR Noto Sans Math, which has the italic forms.

One letter alone

Each word is a span of its own, so its text is the span's.

In MathML

MathML Core's user agent style sheet gives mi elements math-auto.
