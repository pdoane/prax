CSS Text 4 · 1.4 Characters and Letters

Typographic character units

A UA must use the extended grapheme cluster (not legacy grapheme cluster), as defined in UAX29, as the basis for its typographic character unit. CSS Text 4 §1.4

Spacing goes between clusters, not inside them

Each stage has letter-spacing: 10px, added between units.

No break inside one

CSS never allows soft wrap opportunities within typographic character units. §6.5 The stage is 30px wide, with word-break: break-all, which allows a break between any two letters.
