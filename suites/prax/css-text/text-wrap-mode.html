CSS Text 4 · 5.1 Deciding Whether to Wrap: the text-wrap-mode property

text-wrap-mode

This property specifies whether inline-level content wraps at unforced soft wrap opportunities. CSS Text 4 §5.1 Each stage is 100px wide, of 10px letters.

wrap and nowrap

wrap: Lines may wrap at allowed soft wrap opportunities, as determined by the line-breaking rules in effect, in order to minimize inline-axis overflow. nowrap: Lines only break at forced line breaks; content that does not fit within the block container overflows it. It does not change how white space collapses.

Forced breaks, even under nowrap

Regardless of the 'text-wrap-mode' value, preserved segment breaks, and any Unicode character with the BK, CR, LF, and NL line breaking class, must be treated as forced line breaks. Each stage is nowrap.
