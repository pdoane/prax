CSS Text 4 · 8.2 Tracking: the letter-spacing property

letter-spacing: percentages

Percentages inherit intact, and are resolved against the used 'font-size' of the current element (and thus represent a size relative to the size of the text to which they apply), unlike em units which are resolved against the computed 'font-size' of the element from which they inherit, as an absolute length. CSS Text 4 §8.2 CSS 2's page has lengths. Letters are 10px wide.

Inherited as a percentage, not a length

Negative

Values may be negative, but there may be implementation-dependent limits.
