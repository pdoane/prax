CSS Text 4 · 6.1.1.2 Orthographic Breaking

Orthographic breaking

For scripts (such as Balinese) that use line breaking based on orthographic syllables, the UA must analyze the content to find the correct points to insert soft wrap opportunities. CSS Text 4 §6.1.1.2 At the time of writing, Unicode does not define how to perform this analysis, and treats all characters in these writing systems as having line breaking class AL.

Balinese

A run of Balinese, ᬅᬓ᭄ᬱᬭᬩᬮᬶ, "Balinese script", with no spaces: aksara (a, ksa, ra) and bali (ba, li). Each orthographic syllable, a consonant with any vowel sign or subjoined consonant, is a place a line may break.
