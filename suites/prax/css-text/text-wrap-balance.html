CSS Text 4 · 5.4 Selecting How to Wrap: the text-wrap-style property

text-wrap-style: balance

balance: Line breaks are chosen to balance the remaining (empty) space in each line box, if better balance than 'auto' is possible. This should avoid changing—and in the case of 5 or fewer lines must not change—the number of line boxes the block would contain if 'text-wrap' were set to 'auto'.
