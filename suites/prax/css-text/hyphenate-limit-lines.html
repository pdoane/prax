CSS Text 4 · 6.3.5 Hyphenation Line Limits: the hyphenate-limit-lines and hyphenate-limit-last properties

hyphenate-limit-lines and hyphenate-limit-last

This property indicates the maximum number of successive hyphenated lines in an element. CSS Text 4 §6.3.5 No browser has either property. Each stage is lang=en, hyphens: manual, 80px wide, eight 10px letters to a line; soft hyphens are marked here with "·".

hyphenate-limit-lines

The stages hold "abcd ef·gh ijk·lmn op".

hyphenate-limit-last

always: The last full line of the element, or the last line before any column, page, or spread break inside the element should not be hyphenated. The stages hold "abcd ef·gh".
