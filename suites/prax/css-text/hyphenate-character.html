CSS Text 4 · 6.3.2 Hyphens: the hyphenate-character property

hyphenate-character

This property specifies the string that is shown between parts of hyphenated words. CSS Text 4 §6.3.2 Each stage is lang=en, 70px wide, of 10px letters, and holds "hyphen", a soft hyphen, "ation".

A string, or none

<string>: Specifies the string that appears at the hyphenation break when hyphenating. Specifying the empty string "" is valid, and causes the UA to break at hyphenation opportunities without inserting a visible hyphenation character.

Automatic hyphens too

Both hyphens triggered by automatic hyphenation and hyphens triggered by soft hyphens are rendered according to 'hyphenate-character'.
