CSS 2 · 14.2 The background

The background: areas and inheritance

Authors may specify the background of an element (i.e., its rendering surface) as either a color or an image. CSS 2 §14.2

Content, padding and border areas

In terms of the box model, "background" refers to the background of the content, padding and border areas. Border colors and styles are set with the border properties. Margins are always transparent. CSS 2 §14.2

Not inherited, but transparent

Background properties are not inherited, but the parent box's background will shine through by default because of the initial 'transparent' value on 'background-color'. CSS 2 §14.2
