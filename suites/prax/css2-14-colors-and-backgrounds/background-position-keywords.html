CSS 2 · 14.2.1 Background properties

Background position: keywords

The image is a blue banner, 50 by 30, drawn once in a box 200 by 100.

Keywords are percentages

top: Equivalent to '0%' for the vertical position. right: Equivalent to '100%' for the horizontal position. bottom: Equivalent to '100%' for the vertical position. left: Equivalent to '0%' for the horizontal position. center: Equivalent to '50%' for the horizontal position if it is not otherwise given, or '50%' for the vertical position if it is. The specification's examples follow. CSS 2 §14.2.1
