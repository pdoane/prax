CSS 2 · 14.2 The background

The canvas: the root element's background

Each figure is a frame, a document of its own, whose root element has margin: 20px; height: 60px and a dashed outline, which takes no room. Its body has no margin. The guides are 10px apart.

It covers the entire canvas

The background of the root element becomes the background of the canvas and covers the entire canvas The root element does not paint this background again. CSS 2 §14.2

Anchored at the root element

The background is anchored (for 'background-position') at the same point as it would be if it was painted only for the root element itself. CSS 2 §14.2
