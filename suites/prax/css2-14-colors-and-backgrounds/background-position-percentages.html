CSS 2 · 14.2.1 Background properties

Background position: percentages

background-position takes percentages, lengths and keywords. Initial 0% 0%, applies to all elements, not inherited. The image is a 50px blue square, drawn once, with a white dot 14% across and 84% down it.

A point of the image on the same point of the box

A percentage X aligns the point X% across (for horizontal) or down (for vertical) the image with the point X% across (for horizontal) or down (for vertical) the element's padding box. Percentages refer to the size of the box itself. CSS 2 §14.2.1
