CSS 2 · 14.2.1 Background properties

Background repeat: the values

background-repeat takes repeat | repeat-x | repeat-y | no-repeat | inherit. Initial repeat, applies to all elements, not inherited.

How the image is tiled

If a background image is specified, this property specifies whether the image is repeated (tiled), and how. CSS 2 §14.2.1

Each dashed box is 180 by 80, with a 20px blue dot as its image at background-position: 40px 30px. A tile always passes through that point, and tiling runs both ways from it.
