CSS 2 · 14.2.1 Background properties

Background attachment: elements

Note that there is only one viewport per view. If an element has a scrolling mechanism (see 'overflow'), a 'fixed' background does not move with the element, and a 'scroll' background does not move with the scrolling mechanism. CSS 2 §14.2.1

An element that scrolls, and a document that scrolls

The image is a 30px blue square, drawn once. Dashed outlines are the elements that have it.

Only within the element

Even if the image is fixed, it is still only visible when it is in the content, padding or border area of the element. Thus, unless the image is tiled ('background-repeat: repeat'), it may be invisible. CSS 2 §14.2.1
