CSS 2 · 14.2.1 Background properties

Background attachment: the viewport

background-attachment takes scroll | fixed | inherit. Initial scroll, all elements, not inherited. Each frame is a document 300px tall, scrolled down.

Fixed to the viewport, or scrolled with the document

If a background image is specified, this property specifies whether it is fixed with regard to the viewport ('fixed') or scrolls along with the containing block ('scroll'). CSS 2 §14.2.1

A 30px square at 10px 10px, drawn once; scrolled 60px, a dashed box 110px down is 50px from the top.

A band glued to the viewport

The specification's example, body { background: red url("pendant.png"); background-repeat: repeat-y; background-attachment: fixed }, creates an infinite vertical band that remains "glued" to the viewport when the element is scrolled. CSS 2 §14.2.1
