CSS 2 · 14.2.1 Background properties

Background image: no intrinsic dimensions

An SVG image that gives neither a width nor a height, drawn once at the top left of a dashed padding box, the rectangle background-position works in.

A ratio alone

If the image has no intrinsic dimensions and has an intrinsic ratio the dimensions must be assumed to be the largest dimensions at that ratio such that neither dimension exceeds the dimensions of the rectangle that establishes the coordinate system for the 'background-position' property. CSS 2 §14.2.1

No ratio either

If the image has no intrinsic ratio either, then the dimensions must be assumed to be the rectangle that establishes the coordinate system for the 'background-position' property. CSS 2 §14.2.1
