CSS 2 · 14.2.1 Background properties

Background position: fixed images

Each figure is a frame, a document 300px tall scrolled down 60px, or an element in one. The image is a blue "logo", 50 by 30.

Placed in the viewport

If the background image is fixed within the viewport (see the 'background-attachment' property), the image is placed relative to the viewport instead of the element's padding box. CSS 2 §14.2.1

For any element

The same holds for an element that is not the root: its own padding box no longer matters. CSS 2 §14.2.1
