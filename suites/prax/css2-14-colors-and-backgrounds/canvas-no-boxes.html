CSS 2 · 14.2 The background

The canvas: no boxes

Each figure is a frame. The frame's canvas is transparent unless a background is given to it, so the stage's guides show through it.

No boxes: a transparent canvas

if no boxes are generated for the element whose background would be used for the background of the canvas, then the canvas background is transparent. (in CSS 2.2, that is the case when the element or an ancestor has 'display: none'.) CSS 2 §14.2

Since CSS 2 · CSS Backgrounds 4 §4

Only display: none

However, if the element whose background would be used for the canvas is display: none, then the canvas background is transparent. CSS Backgrounds 4 §4 An element can now generate no boxes without display: none: with display: contents its background is still propagated.
