CSS 2 · 14.2.1 Background properties

Background image: percentage dimensions

SVG images whose width or height is a percentage. Each dashed box is a padding box 160 by 60, the rectangle background-position works in, with the image drawn once at its top left.

Percentages of the positioning area

Intrinsic dimensions expressed as percentages must be resolved relative to the dimensions of the rectangle that establishes the coordinate system for the 'background-position' property. CSS 2 §14.2.1

Since CSS 2 · CSS Images 3 §4.1 · SVG 2 §8.12

A percentage is no natural size

CSS no longer resolves an image's own percentages: CSS does not define how the natural dimensions are found in general. CSS Images 3 §4.1 For SVG, 'auto' and percentage lengths must not be used to determine an intrinsic width or intrinsic height. SVG 2 §8.12 The image lacks that dimension, and is sized by the rules for a missing one.
