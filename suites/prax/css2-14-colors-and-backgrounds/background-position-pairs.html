CSS 2 · 14.2.1 Background properties

Background position: lengths and keywords together

The image is a 50 by 30 banner in a box 200 by 100. Each box's style sheet gives it 100% 50% first; the declaration in the caption follows.

Horizontal first

If at least one value is not a keyword, then the first value represents the horizontal position and the second represents the vertical position. CSS 2 §14.2.1

The other order: the earlier position stays

A vertical keyword cannot come first beside a length or percentage, and a declaration that does not match the grammar is ignored. CSS 2 §4.2
