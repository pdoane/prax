CSS 2 · 14.2.1 Background properties

Background image

background-image takes <uri> | none | inherit. Initial none, applies to all elements, not inherited. The image here is a blue dot in a 20px square.

On top of the background color

When the image is available, it is rendered on top of the background color. (Thus, the color is visible in the transparent parts of the image). The color will be used when the image is unavailable. CSS 2 §14.2.1

none, and not inherited

Values for this property are either <uri>, to specify the image, or 'none', when no image is used. p { background-image: none } CSS 2 §14.2.1

A dotted parent with 10px padding holds a child, outlined, whose top left corner is half a dot's square, 10px, into the dots.
