CSS 2 · 14.2 The background

The canvas: the body's background

Each figure is a frame whose body has margin: 20px; height: 60px and a dashed outline. The guides are 10px apart.

From the body, when the root has none

When the root has computed values of 'transparent' for 'background-color' and 'none' for 'background-image', user agents must instead use the computed value of the background properties from that element's first HTML "BODY" element or XHTML "body" element child when painting backgrounds for the canvas, and must not paint a background for that child element. CSS 2 §14.2

Anchored at the root, and the omitted tag

Such backgrounds must also be anchored at the same point as they would be if they were painted only for the root element. the rule for the BODY element will work even though the BODY tag has been omitted in the HTML source CSS 2 §14.2
