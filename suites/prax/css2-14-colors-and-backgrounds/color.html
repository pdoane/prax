CSS 2 · 14.1 Foreground color: the 'color' property

Foreground color: the color property

color takes <color> | inherit. The initial value depends on the user agent; it applies to all elements and is inherited.

The color of text

This property describes the foreground color of an element's text content. There are different ways to specify red: em { color: red } and em { color: rgb(255,0,0) }. CSS 2 §14.1

Inherited, on all elements

Inherited: yes. Applies to: all elements. CSS 2 §14.1
