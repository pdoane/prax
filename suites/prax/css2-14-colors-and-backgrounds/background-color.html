CSS 2 · 14.2.1 Background properties

Background color

background-color takes <color> | transparent | inherit. Initial transparent, applies to all elements, not inherited.

A color, or transparent

This property sets the background color of an element, either a <color> value or the keyword 'transparent', to make the underlying colors shine through. CSS 2 §14.2.1

Initial value and inheritance

Initial: transparent. Inherited: no. CSS 2 §14.2.1
