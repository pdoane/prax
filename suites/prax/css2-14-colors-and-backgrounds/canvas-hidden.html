CSS 2 · 14.2 The background

The canvas: visibility hidden

Each figure is a frame. The frame's canvas is transparent unless a background is given to it, so the stage's guides show through it.

Hidden boxes still give their background

Note that, if the element has 'visibility: hidden' but not 'display: none', boxes are generated for it and its background is used for the canvas. CSS 2 §14.2
