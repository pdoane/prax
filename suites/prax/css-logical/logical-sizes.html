CSS Logical Properties and Values 1 · 4.1 Logical Height and Logical Width

inline-size and block-size

These properties correspond to the 'height' and 'width' properties. The mapping depends on the element's 'writing-mode'. CSS Logical Properties and Values 1 §4.1 Each stage is 160 by 100px.

Lengths

Each A has inline-size: 100px; block-size: 40px.

Percentages

Percentages: As for the corresponding physical property: a width's of the containing block's width, a height's of its height. Each A has inline-size: 50%; block-size: 50%.
