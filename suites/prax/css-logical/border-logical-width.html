CSS Logical Properties and Values 1 · 4.5.1 Flow-Relative Border Widths

Flow-relative border widths

These properties correspond to the 'border-top-width', 'border-bottom-width', 'border-left-width', and 'border-right-width' properties. The mapping depends on the element's 'writing-mode', 'direction', and 'text-orientation'. CSS Logical Properties and Values 1 §4.5.1 Each box is 80px wide and 40px tall with a 2px border, in the stage's writing mode.

The longhands

Each box has border-block-start-width: 10px; border-inline-start-width: 20px.

border-block-width and border-inline-width

The first value represents the start edge width, and the second value represents the end edge width. Each box has border-block-width: 2px 10px; border-inline-width: 20px 4px.
