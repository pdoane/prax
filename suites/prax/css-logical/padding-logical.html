CSS Logical Properties and Values 1 · 4.4 Flow-Relative Padding

Flow-relative padding

These properties correspond to the 'padding-top', 'padding-bottom', 'padding-left', and 'padding-right' properties. The mapping depends on the element's 'writing-mode', 'direction', and 'text-orientation'. CSS Logical Properties and Values 1 §4.4 A's label shows where its content box starts.

The longhands

Each A has padding-block-start: 10px; padding-inline-start: 40px.

The longhands at the end

Each A has padding-block-end: 10px; padding-inline-end: 40px; A is only as long as its label and padding (inline-size: fit-content).
