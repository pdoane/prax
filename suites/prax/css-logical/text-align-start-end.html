CSS Logical Properties and Values 1 · 2.3 Flow-Relative Values for the text-align Property

text-align: start and end

text-align takes the new values start | end. They are defined in CSS Text: CSS Logical Properties and Values 1 §2.3 start: Inline-level content is aligned to the start edge of the line box. end: Inline-level content is aligned to the end edge of the line box. CSS Text 3 §6.1

start, then end

Each stage's first line has text-align: start, its second text-align: end.

In vertical-rl with rtl

The same in vertical-rl rtl, beside left and right, which are line-relative.
