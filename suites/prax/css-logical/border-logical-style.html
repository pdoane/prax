CSS Logical Properties and Values 1 · 4.5.2 Flow-Relative Border Styles

Flow-relative border styles

These properties correspond to the 'border-top-style', 'border-bottom-style', 'border-left-style', and 'border-right-style' properties. The mapping depends on the element's 'writing-mode', 'direction', and 'text-orientation'. CSS Logical Properties and Values 1 §4.5.2 Each box is 80 by 40px with a 6px solid border, in the stage's writing mode.

The longhands

Each box has border-block-start-style: dotted; border-inline-start-style: double.

border-block-style and border-inline-style

Each box has border-block-style: dashed none; border-inline-style: double dotted.
