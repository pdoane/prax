CSS Logical Properties and Values 1 · 4.6 Flow-Relative Corner Rounding

Flow-relative corner rounding

These properties correspond to the 'border-top-left-radius', 'border-bottom-left-radius', 'border-top-right-radius', and 'border-bottom-right-radius' properties. The mapping depends on the element's 'writing-mode', 'direction', and 'text-orientation', with the first start/end giving the block axis side, and the second the inline-axis side (i.e. patterned as 'border-block-inline-radius').
