CSS Logical Properties and Values 1 · 2.1 Logical Values for the caption-side Property

caption-side: block-start and block-end

The existing top and bottom values are idiosyncratically redefined as assigning to the block-start and block-end sides of the table, respectively. CSS Logical Properties and Values 1 §2.1

top and bottom

caption-side: top, the initial value, then bottom; direction plays no part.

The table wrapper's writing mode, not the caption's

The mapping on this property uses the writing mode of the caption’s containing block (that is, the table wrapper box). Each caption has a writing mode of its own.
