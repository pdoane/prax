CSS Logical Properties and Values 1 · 4.5.3 Flow-Relative Border Colors

Flow-relative border colors

These properties correspond to the 'border-top-color', 'border-bottom-color', 'border-left-color', and 'border-right-color' properties. The mapping depends on the element's 'writing-mode', 'direction', and 'text-orientation'.
