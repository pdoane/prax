CSS Multi-column Layout 1 · 5.1 Controlling Fragmentation: orphans and widows

orphans and widows in columns

The orphans property specifies the minimum number of line boxes in a block container that must be left in a fragment before a fragmentation break. The widows property specifies the minimum number of line boxes of a block container that must be left in a fragment after a break.
