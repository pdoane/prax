CSS Multi-column Layout 2 · 4.2 The Block Size of Columns, spanners

column-height and spanners

If a spanner is introduced that is taller than the set size, the row geometry will be maintained, and the spanner will overflow into the next row, crossing any row-gap. CSS Multi-column Layout 2 §4.2 Each stage has column-height: 40px, gap: 10px, column-fill: auto and red rules: rows of 40px, 10px apart.

A spanner taller than the row

The stage has columns: 2; A, 50px tall, spans the columns. A multicol row contains at least one multicol line or spanning element, so a spanner starts a row of its own.
