CSS Multi-column Layout 1 · 4.3 The Style Of Column Rules: the column-rule-style property

column-rule-style

The column-rule-style property sets the style of the rule between columns of an element. CSS Multi-column Layout 1 §4.3

The <line-style> values

Each stage is 100px wide, with two columns of 40px and a 20px gap; each rule is 6px wide and blue.

As in the collapsing border model

The <line-style> values are interpreted as in the collapsing border model. There, inset draws as ridge and outset as groove. The none and hidden values force the used value of column-rule-width to be 0.
