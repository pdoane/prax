CSS Multi-column Layout 1 · 8.2 Pagination and Overflow Outside Multicol Containers

Overflow columns

Columns that appear outside the multicol container in continuous contexts are called overflow columns. CSS Multi-column Layout 1 §8.2 Each stage has three columns of 60px; its overflow is visible.

A constrained height

a declaration that constrains the column height (e.g., using height or max-height). In this case, additional column boxes are created in the inline direction

Forced breaks

explicit column breaks. In this case, additional column boxes are created in the inline direction for continuous contexts. Each word is a block with break-after: column.
