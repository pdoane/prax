CSS Multi-column Layout 2 · 7.1 column-span

column-span: a number of columns, and auto

<integer>: The element spans the specified number of columns. Values must be greater than 0. If the specified integer value is equal to, or larger than the number of columns in the multicol element, the number of columns spanned will be the same as if column-span: all had been specified.
