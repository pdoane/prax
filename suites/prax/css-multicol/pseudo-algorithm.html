The pseudo-algorithm: N and W

The pseudo-algorithm below determines the used values for column-count (N) and column-width (W). There is one other variable in the pseudo-algorithm: U is the used width of the multi-column container. CSS Multi-column Layout 1 §3.4 Each letter is 10px wide; a dashed rule marks each gap.

N, then W

In short, with gap for column-gap and width for column-width:

column-width = auto:  N := column-count
column-count = auto:  N := max(1, floor((U + gap)/(width + gap)))
otherwise:            N := min(column-count, max(1, floor(...)))
                      W := max(0, (U + gap)/N - gap)
