CSS Multi-column Layout 2 · 4.8 Styling Columns: the ::column pseudo-element

The ::column pseudo-element

The ::column pseudo-element represents the individual columns in a multi-column container. Each ::column has the same size and position as its corresponding column. The ::column pseudo-element accepts only a very limited set of properties: scroll-margin, scroll-snap-align, and scroll-snap-stop. CSS Multi-column Layout 2 §4.8 Each stage scrolls (overflow: hidden), 40px tall, with columns of 60px and twelve words: six columns, three in view.

A scroll marker for each column

a ::column pseudo-element can have a ::scroll-marker pseudo-element of its own, as ::column::scroll-marker. The stage has scroll-marker-group: after CSS Overflow 5 §3.1.3, and each marker is a circle, filled when its column is the current one.

Snapping to columns

The stage has scroll-snap-type: x mandatory, and its ::column scroll-snap-align: start; a script scrolls it 50px.
