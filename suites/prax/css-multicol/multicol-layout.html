CSS Multi-column Layout 1 · 1 Introduction

Multi-column layout

The child elements of a multi-column container however continue in normal flow, that flow is arranged into a number of columns. These columns have a flexible inline size, and therefore respond to available space by changing the size or number of columns displayed. CSS Multi-column Layout 1 §1 Each stage is 200px wide, in text whose every letter is 10px wide on 20px lines.

A width, or a number

The number of columns can also be set explicitly in the style sheet: In this case, the number of columns is fixed and the column widths will vary depending on the available width.

Gaps, rules, and spanning

Column gaps are similar to padding areas. In the middle of the gap there will be a rule. The column-fill and column-span properties give style sheets a wider range of visual expressions in multi-column layouts.
