CSS Multi-column Layout 2 · 4.6 The Pseudo-algorithm

column-height alone

Level 2 adds column-height to the pseudo-algorithm's first line: if ((column-width = auto) and (column-count = auto) and (column-height = auto)) then exit; /* not a multicol container */, so column-height alone makes a multicol container.
