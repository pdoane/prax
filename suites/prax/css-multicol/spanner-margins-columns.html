CSS Multi-column Layout 1 · 6.1 Spanning An Element Across Columns, margins in columns

Spanner margins and the columns

As column boxes establish a new block formatting context, margins on elements inside a column box will not collapse with the margin of a spanner. CSS Multi-column Layout 1 §6.1 Each stage has three columns of 60px. A has margin: 20px 0, B margin: 10px 0; both span.

Not with margins inside the columns

"one", above A, is in a block with margin-bottom: 30px; "two", below B, in one with margin-top: 30px. At a forced break, adjoining margins before the break are truncated, but margins after the break are preserved. CSS Fragmentation 4 §5.2
