CSS Multi-column Layout 1 · 2 The Multi-Column Model, nesting

Nested multicol containers

Nested multi-column containers are allowed, but there may be implementation-specific limits. CSS Multi-column Layout 1 §2 The outer container has two columns of 95px and a dashed rule; the tinted inner one, two columns and a red rule, each column (95 + 10) / 2 − 10 = 42.5px wide.

Columns in a column

The inner container is a block in the outer's first column, and lays its own columns out in that column's 95px.

The inner container breaks across the outer columns

The outer columns are 40px tall (height: 40px; column-fill: auto), so the inner container is fragmented. Its columns in each outer column are a multicol line of their own; In fragmented contexts, only the last fragment is balanced. §7.1
