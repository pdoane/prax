CSS Multi-column Layout 1 · 8.1 Overflow Inside Multicol Containers

Overflow inside the columns

Except for cases where this would cause a column break, content that extends outside column boxes visibly overflows and is not clipped to the column box. CSS Multi-column Layout 1 §8.1 Each stage has three columns of 60px with 10px gaps.
