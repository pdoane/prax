CSS Multi-column Layout 1 · 3.5 Stacking Context

Columns and stacking

All column boxes in a multi-column container are in the same stacking context and the drawing order of their contents is as specified in CSS 2.1. Column boxes do not establish new stacking contexts. CSS Multi-column Layout 1 §3.5 Each stage is a stacking context; each multicol container has three columns of 60px, 40px tall.

z-index across columns

A, 40px tall, position: relative; left: 40px; z-index: 2, fills the first column; B, z-index: 1, comes later, in the second column, under A's right part.

A negative z-index goes under the container

The multicol container is not a stacking context, and has a light background. B, position: relative; top: 30px; z-index: -1, 30px tall, is in its second column.
