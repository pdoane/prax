CSS Multi-column Layout 1 · 3.2 The Number of Columns: the column-count property

column-count

<integer> describes the optimal number of columns into which the content of the element will be flowed. Values must be greater than 0. If both column-width and column-count have non-auto values, the integer value describes the maximum number of columns.
