CSS Multi-column Layout 2 · 4.5 The column-width, column-count, and column-height Shorthand

The columns shorthand and column-height

This is a shorthand property for setting column-width, column-count, and column-height. Omitted values are set to their initial values. This property also resets the column-wrap property to its initial value. The column-height comes after a slash: columns: 12em / 14em.
