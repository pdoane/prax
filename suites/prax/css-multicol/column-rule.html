CSS Multi-column Layout 1 · 4.5 Column Rule Shorthand: the column-rule property

The column-rule shorthand

This property is a shorthand for setting column-rule-width, column-rule-style, and column-rule-color at the same place in the style sheet. Omitted values are set to their initial values. CSS Multi-column Layout 1 §4.5

Width, style and color in any order

Each stage has two columns of 90px and a 20px gap.

What it omits, it resets

Each stage first declares column-rule-color: #c0392b, then the shorthand without a color; the text is color: #3f7a3f.
