CSS Multi-column Layout 1 · 3.4 The Pseudo-algorithm, actual counts

Used and actual column counts

The used value for column-count is calculated without regard for explicit column breaks or constrained column heights, while the actual value takes these into consideration. CSS Multi-column Layout 1 §3.4 Each stage has columns: 100px; column-gap: 0 and a red rule: a used count of 2.

More columns than used

In this example, the actual column-count is higher than the used column-count due to explicit column breaks: three paragraphs, each with break-after: column.

Fewer columns than used

The actual column-count may be lower than the used column-count. The stage has height: 40px; column-fill: auto, and holds one word.
