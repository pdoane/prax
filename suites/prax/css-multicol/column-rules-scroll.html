CSS Multi-column Layout 1 · 4 Column Gaps and Rules, scrolling

Rules in a scrolled multicol container

Column rules are painted just above the border of the multicol container. For scrollable multicol containers, note that while the border and background of the multicol container obviously aren't scrolled, the rules need to scroll along with the columns. CSS Multi-column Layout 1 §4
