CSS Multi-column Layout 1 · 7.1 Column Balancing, lines and overflow

column-fill, spanners and overflow

This property specifies whether content in a multi-column line that does not immediately precede a spanner is balanced across columns or not. In continuous contexts, this property does not have any effect when there are overflow columns. CSS Multi-column Layout 1 §7.1 Each stage has three columns of 60px; each word is on a line of its own.
