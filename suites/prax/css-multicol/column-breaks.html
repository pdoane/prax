CSS Multi-column Layout 1 · 5 Column Breaks

Column breaks

When content is laid out in multiple columns, the user agent must determine where column breaks are placed. The problem of breaking content into columns is similar to breaking content into pages, which is described in CSS 2.1, section 13.3.3 [CSS21]. CSS Multi-column Layout 1 §5 Each stage has three columns of 60px; the rules mark the gaps.

Between lines, not through them

A line of text is monolithic, as are scrollable boxes: it contains no possible break points. CSS Fragmentation 4 §4.1

Boxes are split at the break

The blue box has a 4px border and holds five lines. When a box breaks, its content box extends to fill any remaining fragmentainer extent CSS Fragmentation 4 §5.3, and with box-decoration-break: slice, the initial value, no border and no padding are inserted at a break. §5.4
