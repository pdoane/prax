CSS Multi-column Layout 2 · 4.4 The overflow direction: the column-wrap property

column-wrap

The column-wrap property controls the behavior of overflow columns. nowrap: Overflow columns are created in the inline direction. wrap: Overflow columns create a new multicol row in the block direction. auto: If column-height is not auto behaves as the value wrap otherwise acts as nowrap.
