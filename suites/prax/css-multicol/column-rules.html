CSS Multi-column Layout 1 · 4 Column Gaps and Rules

Gaps and rules between columns

Column gaps take up space. That is, column gaps will push apart content in adjacent columns. A column rule is drawn in the middle of the column gap with the endpoints at opposing content edges of the multicol container. Column rules do not take up space. CSS Multi-column Layout 1 §4

In the middle of the gap, between the content edges

Only between columns with content

Column rules are only drawn between two columns that both have content. Three columns, 40px tall (column-fill: auto).
