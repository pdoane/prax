CSS Multi-column Layout 1 · 4.1 Gutters Between Columns: the column-gap property

column-gap in multicol

The column-gap property is defined in [CSS3-ALIGN]. In a multi-column formatting context the used value of normal for the column-gap property is 1em. This ensures columns are readable when the initial values are used. If there is a column rule between columns, it will appear in the middle of the gap.
