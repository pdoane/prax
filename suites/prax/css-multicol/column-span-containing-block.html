CSS Multi-column Layout 1 · 6.1 Spanning An Element Across Columns, containing blocks

The spanner's containing block

The containing block of the spanner is the multicol container itself. Consequently, in cases where the spanner itself does not establish a containing block for absolutely positioned boxes inside the spanner, their containing block chain skips directly to the multicol container (skipping any ancestors between the spanner and the multicol container). CSS Multi-column Layout 1 §6.1 Each multicol container has three columns of 60px.
