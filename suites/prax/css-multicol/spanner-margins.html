CSS Multi-column Layout 1 · 6.1 Spanning An Element Across Columns, margins

Margins of spanners

Spanners are block-level boxes therefore the margins of two adjacent spanners will collapse with each other. CSS Multi-column Layout 1 §6.1 Each stage has three columns of 60px. A has margin: 20px 0, B margin: 10px 0; both span.

Between spanners, margins collapse

The margins of two spanners separated only by an absolutely positioned item will collapse with each other.
