watchFolder

Client method · available since 2.4

Calls the handler for newly discovered files. Successful paths are remembered; failures retry on the next poll.

watchFolder(path: string, options?: WatchOptions, handler: FileHandler): Watcher

Example

// Upload every CSV that lands in the drop folder.
const watcher = client.watchFolder("./drop", {
  match: "*.csv",
  interval: 2000,
}, async (file) => {
  await client.upload(file.path, { bucket: "reports" });
});
Interval limits. Intervals below 500 ms are raised to 500 ms and emit one warning event.

Options

NameTypeDescription
matchstringoptionalGlob applied to the file name. Files that do not match are ignored.
intervalnumberoptionalMilliseconds between reads. Defaults to 5000.
handlerfunctionrequiredCalled with a file record. A rejected promise retries the file on the next pass.
signalAbortSignaloptionalStops the watcher and rejects any handler still running.

Returns

A Watcher with close(), pause(), and an on() subscriber for the error and warning events.
