CSS Display 4 · B.1 HTML Elements, legend, button, details and fieldset

display: contents on legend, button, details, fieldset

Per HTML, a legend with display: contents is not a rendered legend, so it does not have magical display behavior. (Thus, it reacts to display: contents normally.) For button, details and fieldset, display: contents simply removes their principal box, and their contents render as normal. CSS Display 4 §B.1
