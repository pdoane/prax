CSS Display 4 · 6 Run-In Layout, sequences

Run-in sequences

A run-in sequence is a maximal sequence of consecutive sibling run-in boxes and intervening white space and/or out-of-flow boxes. No browser ships run-in; each figure is flagged for all three. CSS Display 4 §6

Sequences, and what follows

Its contents inlinified; the block's first letter is its own

A run-in box with a flow inner display type inlinifies its contents. As the earliest run-in represents the first text on the first formatted line of its containing block, a ::first-letter pseudo-element applied to that block element selects the first letter of the run-in, rather than the first letter of its own contents. The block's first letter is large and red.
