CSS Display 4 · A Glossary, independent formatting context

Independent formatting contexts

When a box establishes an independent formatting context ..., it essentially creates a new, independent layout environment. CSS Display 4 §A

Floats stay in, and stay out

the box establishing their formatting context grows to fully contain them, and floats from outside that box are not allowed to protrude into and affect the contents inside the box. Each blue box is a flow root.

Margins do not collapse across

margins do not collapse across formatting context boundaries. The orange child has a 10px top margin.

What makes one

making a box out-of-flow causes it to blockify as well as to establish an independent formatting context. So does a scroll container.
