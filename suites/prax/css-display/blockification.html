CSS Display 4 · 2.7 Automatic Box Type Transformations, blockification

Blockification

Some layout effects require blockification or inlinification of the box type, which sets the box’s computed outer display type to block or inline (respectively). CSS Display 4 §2.7

What blockifies

Absolute positioning or floating an element blockifies the box’s display type. A parent with a grid or flex 'display' value blockifies the box’s display type. Each orange box is a span with width: 60px; height: 30px, which apply only because it is now a block.

Of the computed value, inherited too

Blockification sets the computed outer display type, so it applies to whatever value the element gets, inherit among them. The parent is an inline span.
