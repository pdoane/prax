Kinds of boxes

The glossary names the boxes the module speaks of. CSS Display 4 §A

Inline box and atomic inline; floats inhibited

An atomic inline cannot split across lines (as inline boxes and ruby containers can). Some formatting contexts inhibit floating, so that an element with float: left is not necessarily out-of-flow.

Block container and block box

non-replaced inline blocks and non-replaced table cells, for example, are block containers but not block-level boxes. flex containers (display: flex), for example, are not block containers.
