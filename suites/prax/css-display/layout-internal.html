CSS Display 4 · 2.4 Layout-Internal Display Types

Layout-internal display types

This section defines those “layout-internal” 'display' values, which only have meaning within that particular layout mode. CSS Display 4 §2.4

Wrapped when misparented

Boxes with layout-specific display types generate anonymous wrapper boxes around themselves when placed in an incompatible parent: block box └anonymous table box └anonymous table-row-group box └anonymous table-row box └table-cell box.

Their inner display types

table-cell boxes have a flow-root inner display type. table-caption boxes have a flow-root inner display type. Each holds a 40px orange float and a word.
