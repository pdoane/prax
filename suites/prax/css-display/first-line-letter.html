CSS Display 4 · 1.1 Module interactions

Not on ::first-line or ::first-letter

None of the properties in this module apply to the ::first-line or ::first-letter pseudo-elements. CSS Display 4 §1.1

display on ::first-letter

Each paragraph's first letter is red, and is given a display that does not apply to it.

visibility on ::first-letter and ::first-line

Hiding the pseudo-element hides nothing: its text is drawn, in red.
