CSS Display 4 · B.2 SVG Elements, as none

SVG elements where contents is none

The intention here is that the display: none behavior applies whenever the "rendering context" inside the element is different than the context outside of it. CSS Display 4 §B.2

As none

An svg element that has CSS box layout (this includes all svg whose parent is an HTML element, as well as document root elements), and any other SVG elements: display: contents computes to display: none.
