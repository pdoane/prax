CSS Display 4 · 2.7 Automatic Box Type Transformations, inlinification

Inlinification

Containment in a ruby container inlinifies the box’s display type. Inlinification sets the outer display type to inline. In each stage, a display: ruby span holds base content and an annotation "text" above it. CSS Display 4 §2.7

A block stays a block container; an inline box inlinifies its children

If a block box (block flow) is inlinified, its inner display type is set to flow-root so that it remains a block container.

If an inline box (inline flow) is inlinified, it recursively inlinifies all of its in-flow children, so that no block-level descendants break up the inline formatting context in which it participates.

Layout-internal boxes are left alone

Inlinification has no effect on layout-internal boxes.
