CSS Display 4 · 2.7 Automatic Box Type Transformations, layout-internal types

Blockification of layout-internal types

Blockification sets the outer display type to block, and changes some inner display types with it. The stage is a flex container, so each child is blockified. CSS Display 4 §2.7

Layout-internal types become flow

If a layout-internal box is blockified, its inner display type converts to flow so that it becomes a block container.
