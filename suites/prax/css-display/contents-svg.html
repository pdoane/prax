CSS Display 4 · B.2 SVG Elements, hoisting

display: contents on SVG elements

The intention here is that the display: none behavior applies whenever the "rendering context" inside the element is different than the context outside of it. CSS Display 4 §B.2

Hoisted: containers, tspan, use

For SVG container elements that render, text content child elements and use, display: contents strips the element from the formatting tree, and hoists its contents up to display in its place. SVG presentation attributes ... continue to affect value processing and inheritance.
