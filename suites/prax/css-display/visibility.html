CSS Display 4 · 5 Invisibility: the visibility property

visibility

The 'visibility' property specifies whether the box is rendered. Invisible boxes still affect layout. Invisible boxes are not rendered (as if they were fully transparent). CSS Display 4 §5

hidden, force-hidden, collapse

Any boxes generated by the element are invisible. Descendants of the element can, however, be visible if they have visibility: visible. force-hidden: Any boxes generated by the element and its descendants are invisible (regardless of their 'visibility' value). collapse: In all other cases, however, (i.e. unless otherwise specified) this simply makes the box invisible, just like visibility/hidden.
