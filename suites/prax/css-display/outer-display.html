CSS Display 4 · 2.1 Outer Display Roles for Flow Layout

Outer display types: block, inline, run-in

The <display-outside> keywords specify the element's outer display type, which is essentially its principal box’s role in flow layout. The third, run-in, is shown with §6. CSS Display 4 §2.1

block and inline

The element generates a box that is block-level when placed in flow layout. The element generates a box that is inline-level when placed in flow layout. If a <display-outside> value is specified but <display-inside> is omitted, the element's inner display type defaults to flow.
