CSS Display 4 · 3 Display Order: the order property, painting

order and painting

This also affects the painting order, exactly as if the flex/grid items were reordered in the source document. CSS Display 4 §3

Later in order, painted later

Each stage is a flex row of 70px items, each pulled 30px over the one before it by a negative margin.

Positioned items too

Positioned descendants with z-index: auto paint in the order of the tree, so reordering them reorders their painting. Absolutely-positioned children of a flex/grid container are treated as having order: 0 for the purpose of determining their painting order relative to flex/grid items.
