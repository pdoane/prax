CSS Display 4 · 1 Introduction

The box tree

for each element, CSS generates zero or more boxes as specified by that element's 'display' property. CSS Display 4 §1

Zero, one or more boxes

Typically, an element generates a single box, the principal box. However, some 'display' values (e.g. display: list-item) generate more than one box. And some values (such as none or contents) cause the element and/or its descendants to not generate any boxes at all. Each stage holds an element with a 2px orange border and two children, A and B.

A property given to another box than the principal one

the 'border' properties applied to a table element are applied to its table grid box, not to its principal table wrapper box. The wrapper also holds the caption.
