CSS Fragmentation 4 · 5.3 Splitting Boxes

Items that span rows

When a box breaks, its content box extends to fill any remaining fragmentainer extent. CSS Fragmentation 4 §5.3 Each stage has three columns 60px tall.

Items that span rows

However, if the fragmented box is a grid item or table cell that spans multiple rows, and the fragmentation break splits its container between two of those rows, then the box should not extend into (or beyond) the gap between those rows.
