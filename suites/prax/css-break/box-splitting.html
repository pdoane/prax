CSS Fragmentation 4 · 5.3 Splitting Boxes

Boxes split at breaks

When a box breaks, its content box extends to fill any remaining fragmentainer extent (leaving room for any margins/borders/padding applied by box-decoration-break: clone) before the content resumes on the next fragmentainer. CSS Fragmentation 4 §5.3
