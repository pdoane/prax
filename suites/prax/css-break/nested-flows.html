CSS Fragmentation 4 · 2.2 Nested Fragmentation Flows

Columns across pages

Breaking a fragmentainer F effectively splits the fragmentainer into two fragmentainers (F1 and F2). the type of break between the two pieces F1 and F2 is the type of break created by the fragmentation context that split F, not the type of break normally created by F’s own fragmentation context. CSS Fragmentation 4 §2.2

A new row of columns on each page

Note that when a multi-column container breaks across pages, it generates a new row of columns on the next page for the rest of its content, so that a page break within a multi-column container is always both a page break and a column break. Two columns, 100px wide, of twenty lines; a page holds seven.
