CSS Fragmentation 4 · 3.1.2 Page Break Values

left and right

left: Force one or two page breaks before/after the principal box so that the next page is formatted as a left page. right: Force one or two page breaks before/after the principal box so that the next page is formatted as a right page. CSS Fragmentation 4 §3.1.2 B has the value. A left-to-right document starts on a right page, a right-to-left one on a left page. CSS Paged Media 3 §3.3
