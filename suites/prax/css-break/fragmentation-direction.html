CSS Fragmentation 4 · 2 Fragmentation Model and Terminology

The fragmentation direction

The fragmentation direction is The block flow direction of the fragmentation context, i.e. the direction in which content is fragmented. A given fragmentation context can only have one block flow direction across all its fragmentainers. CSS Fragmentation 4 §2

Vertical columns

A vertical-rl multi-column container 200px tall and 60px wide: two columns, one above the other, each 95px long and 60px wide, so three lines across.

A descendant whose block flow is perpendicular to the context's is fragmented in the context's direction, not its own: orthogonal flows across columns.
