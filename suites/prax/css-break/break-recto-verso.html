CSS Fragmentation 4 · 3.1.2 Page Break Values

recto and verso

recto: whichever is second (according to the page progression) in a page spread. verso: whichever is first (according to the page progression) in a page spread. CSS Fragmentation 4 §3.1.2 B has the value. A left-to-right document starts on a right page, a right-to-left one on a left page. CSS Paged Media 3 §3.3
