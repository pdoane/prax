CSS Fragmentation 4 · 3.1.1 Child→Parent Break Propagation

Breaks propagate to the parent

a break-before value on a first in-flow child box is propagated to its container. Likewise a break-after value on a last in-flow child box is propagated to its container. This propagation stops before it breaks through the nearest matching fragmentation context. CSS Fragmentation 4 §3.1.1 Each stage has three columns 60px tall; the tinted box has a 4px border.

From the first and last child

breaks are only allowed between siblings, not between a box and its container.
