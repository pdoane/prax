CSS Fragmentation 4 · 3.1.4 Region Break Values

region and avoid-region

These values only have an effect in multi-region contexts; if the flow is not linked across multiple regions, these values have no effect. region: Always force a region break before/after the principal box. avoid-region: Avoid a region break before/after the principal box.
