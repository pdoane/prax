CSS Fragmentation 4 · 4.1 Possible Break Points, monolithic content

Monolithic content

Some content is not fragmentable, for example many types of replaced elements (such as images or video), scrollable elements, or a single line of text content. Such content is considered monolithic: it contains no possible break points. CSS Fragmentation 4 §4.1 Each stage has three columns 60px tall; two Bs leave 20px in the first.

Not split

Forced breaks inside are ignored

Any forced breaks within such boxes therefore cannot split the box, and must therefore also be ignored by the box’s own fragmentation context.
