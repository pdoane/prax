CSS Fragmentation 4 · 3.3 Breaks Between Lines: orphans, widows

Fewer lines than orphans or widows

The orphans property specifies the minimum number of line boxes in a block container that must be left in a fragment before a fragmentation break. The widows property specifies the minimum number of line boxes of a block container that must be left in a fragment after a break. CSS Fragmentation 4 §3.3 In columns: orphans and widows in columns.

Fewer lines than the value

If a block contains fewer lines than the value of widows or orphans, the rule simply becomes that all lines in the block must be kept together. Three columns 60px tall; two Bs, then a paragraph of two lines.
