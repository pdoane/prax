CSS Color Adjustment 1 · 2.1 Opting Into a Preferred Color Scheme

The page color scheme

The page color scheme represents the color scheme that will be used for the page overall (queryable with the prefers-color-scheme media feature) and for all elements that don't specifically override the page color scheme with the 'color-scheme' property. In HTML, <meta name=color-scheme> gives the page's supported color schemes. CSS Color Adjustment 1 §2.1

The meta element names the page's schemes

The page color scheme is determined by finding the used color scheme, given the preferred color scheme and the page's supported color schemes. Each frame's document holds text and a link, and the frame has color-scheme: light, which its document takes as the preference.

An embedded document prefers its frame's scheme

In embedded documents (such as an iframe or an SVG img), the embedding element's element color scheme is used as the embedded document's preferred color scheme. These stages have color-scheme: dark and a Canvas background, and their frames inherit the scheme.
