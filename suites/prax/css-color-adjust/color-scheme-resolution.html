CSS Color Adjustment 1 · 2.3 Resolving Color Schemes

Resolving color schemes

To determine the used color scheme, given a color scheme support support and a color scheme preference preference. Each frame's document has a color-scheme on its root and a Canvas background; the frame has color-scheme: light or dark, which the document takes as the preference. CSS Color Adjustment 1 §2.3

A supported preference wins

If preference's color scheme is in support and supported by the UA, return that color scheme.

Otherwise the first supported scheme, or the default

If support is flagged as sole support, return the first supported color scheme in support. If support is null, or none of the color schemes in support are supported by the UA, return the UA default color scheme.
