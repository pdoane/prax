CSS Color Adjustment 1 · 2.1 Opting Into a Preferred Color Scheme

An SVG image's color scheme

In embedded documents (such as an iframe or an SVG img), the embedding element's element color scheme is used as the embedded document's preferred color scheme (treated as a normal color scheme preference), rather than the user's preference. CSS Color Adjustment 1 §2.1

Each element that shows the image gives it a scheme

The same image is shown by an img, then as a background-image. Its own style sheet fills its square orange under (prefers-color-scheme: dark), and blue otherwise. Each stage gives its scheme to both, whatever the user's preference.
