CSS Color Adjustment 1 · 2.4 Effects of the Used Color Scheme

Effects of the color scheme

For all elements, the user agent must match the following to the element color scheme: the colors of form controls and of the system colors, and light-dark(). CSS Color Adjustment 1 §2.4

Form controls

the default colors of form controls and other "specially-rendered" elements.

The canvas

On the root element, the element color scheme additionally must affect the surface color of the canvas. if the element color scheme of the element and the element color scheme of the embedded document’s root element do not match, then the UA must use an opaque canvas of the Canvas color appropriate to the embedded document’s root element's element color scheme instead of a transparent canvas. Each document's root has color-scheme: dark and no background.
