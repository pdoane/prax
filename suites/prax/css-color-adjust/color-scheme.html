CSS Color Adjustment 1 · 2.2 Overriding the Page Color Scheme: the color-scheme property

color-scheme

The 'color-scheme' property allows this, manually setting the element color scheme for an element and its descendants. Each chip has a Canvas background and CanvasText text, which follow its scheme. CSS Color Adjustment 1 §2.2

light, dark and normal

Indicates that the element supports a light and/or dark color scheme, as appropriate. The element color scheme is the same as the page color scheme.

Inherited; other names mean nothing

The property is inherited, so a chip inside a dark box is dark, unless it sets normal, which takes the page's scheme rather than its parent's. <custom-ident> values are meaningless, and exist only for future compatibility.
