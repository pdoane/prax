CSS Transforms 1 · 2 The Transform Rendering Model

A transform makes a stacking context, at level 0

any value other than none for the transform property results in the creation of a stacking context. CSS Transforms 1 §2 Each stage is a stacking context. Blue A, 80 by 40, comes first; orange B, a later block, overlaps its right half.

Painted as if positioned, with z-index: 0

Implementations must paint the layer it creates, within its parent stacking context, at the same stacking order that would be used if it were a positioned element with z-index: 0.

z-index: auto is treated as 0

If an element with a transform is positioned, the z-index property applies as described in [CSS2], except that auto is treated as 0 since a new stacking context is always created. A is relative and holds a purple child with z-index: -1.
