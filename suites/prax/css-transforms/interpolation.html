CSS Transforms 1 · 9 Interpolation of Transforms

Interpolating transform lists

Interpolation of transform function lists is performed as follows CSS Transforms 1 §9 Each blue box is a 40px square at (60, 30), on the dashed outline, its "A" at its top left, animating to and fro; a still shows the middle, p = 0.5.

A shorter list is padded with identity functions

extend the shorter list to the length of the longer list, setting the function at each additional position to the identity transform function matching the function at the corresponding position in the longer list.

Matching functions first, then matrices

While the functions have either the same name, or are derivatives of the same primitive transform function, interpolate the corresponding pair of functions; If the pair do not have a common name or primitive transform function, post-multiply the remaining transform functions into matrices.
