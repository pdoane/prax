CSS Transforms 2 · 11 SVG and 3D transform functions

3D transforms on SVG elements

This specification explicitly requires three-dimensional transform functions to apply to the container elements and all graphics elements. CSS Transforms 2 §11 Each stage is an svg, 160 by 80; the dashed outline is where a shape would be untransformed.

On graphics and container elements

A blue 80 by 40 shape at (40, 20), with transform-box: fill-box, about its own center.

Not on clip paths, gradients and patterns

On clipPath, linearGradient, radialGradient and pattern: If a transform list includes a three-dimensional transform function, the complete transform list must be ignored.
