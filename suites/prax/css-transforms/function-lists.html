CSS Transforms 1 · 8 The Transform Function Lists

Transform function lists: order, and transforms that cannot be undone

If a list of <transform-function>s is provided, then the net effect is as if each transform function had been specified separately in the order provided. CSS Transforms 1 §8

Order matters, and nesting is the same

a nested set of transforms is equivalent to a single list of transform functions. Each blue box is 40 by 20 at (20, 10), about its center.

A transform that cannot be undone is not displayed

If a transform function causes the current transformation matrix of an object to be non-invertible, the object and its content do not get displayed. Each blue box is 40 by 20 at (60, 40), on the dashed outline.
