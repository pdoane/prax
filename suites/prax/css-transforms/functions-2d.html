CSS Transforms 1 · 7.1 2D Transform Functions

2D transform functions: matrix, translate, scale

The set of allowed transform functions is given below. CSS Transforms 1 §7.1 Each blue box is 40 by 20 at (20, 30), where the dashed outline is, about its center, (40, 40). Rotations and skews follow.

translate() and scale()

translate(): If <ty> is not provided, ty has zero as a value. scale(): If the second parameter is not provided, it takes a value equal to the first.

matrix()

specifies a 2D transformation in the form of a transformation matrix of the six values a, b, c, d, e, f: x′ = a·x + c·y + e, y′ = b·x + d·y + f.
