CSS Transforms 2 · 5 Individual Transform Properties: the translate, scale, and rotate properties

translate, rotate and scale: 3D values, and none

If the third value is omitted or zero, this specifies a 2d translation, equivalent to the translate() function. Otherwise, this specifies a 3d translation, equivalent to the translate3d() function. In 3D

none is no transform; an identity is one

this value does not trigger the creation of a stacking context or containing block for all descendants, while all other values (including “identity” transforms like translate: 0px) create a stacking context and containing block for all descendants. Each stage is a stacking context; a blue box holds a purple child with z-index: -1, which goes behind the box's background unless the box is a stacking context.
