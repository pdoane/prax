CSS Transforms 2 · 7 The transform-style Property

transform-style

A computed value of preserve-3d for transform-style on a transformable element establishes both a stacking context and a containing block for all descendants. If the used value is preserve-3d then it also establishes or extends a 3D rendering context. CSS Transforms 2 §7 What a 3D rendering context does is on its own page; this one shows the rest, which follows the computed value, so a grouping property that makes the used value flat does not undo it.

A stacking context

Each stage is a stacking context; a blue box holds a purple child with z-index: -1, which goes behind the box's background unless the box is a stacking context.

A containing block for all descendants

Each stage is a containing block; a dashed box, not positioned, holds an orange box with position: absolute; right: 0; bottom: 0.
