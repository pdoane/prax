transform-box on CSS boxes

All transformations defined by the transform and transform-origin property are relative to the position and dimensions of the reference box of the element. content-box and border-box

SVG's keywords, and tables

For elements with associated CSS layout box, the used value for fill-box is content-box and for stroke-box and view-box is border-box. The reference box of a table is the border box of its table wrapper box, not its table box.
