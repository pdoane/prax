CSS Transforms 1 · 10 Interpolation of primitives and derived transform functions

Interpolating functions through their primitives

Two different types of transform functions that share the same primitive, or transform functions of the same type with different number of arguments can be interpolated. Both transform functions need a former conversion to the common primitive first and get interpolated numerically afterwards.
