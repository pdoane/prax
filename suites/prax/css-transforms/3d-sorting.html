CSS Transforms 2 · 4.1.2 3D Rendering Contexts

Sorting planes in a 3D rendering context

The element establishing the 3D rendering context, and each other 3D transformed element participating in the 3D rendering context, is rendered into its own plane. Intersection is performed between this set of planes. CSS Transforms 2 §4.1.2 Each stage has perspective: 200px and holds a 120 by 80 preserve-3d box at (20, 10). Blue A, 60 by 40, comes first, at (30, 20) in the stage; orange B, after it, at (70, 40).

Nearer covers farther, whatever the order

The establishing element's own plane

Its plane includes the element's backgrounds, borders, other box decorations, content, and descendant elements, excluding any descendant elements that have their own plane, at Z 0, since csswg-drafts#6238. Here the preserve-3d box has a light blue background.
