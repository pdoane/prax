Interpolating matrices

When interpolating between two matrices, each matrix is decomposed into the corresponding translation, rotation, scale, skew. Each corresponding component of the decomposed matrices gets interpolated numerically and recomposed back to a matrix in a final step. A matrix that cannot be undone animates discretely

If one of the matrices for interpolation is non-invertible, the used animation function must fall-back to a discrete animation, which switches at the middle. A 20px square at (60, 40), from matrix(2, 0, 0, 2, 0, 0) to matrix(1, 1, 1, 1, 0, 0), a line.
