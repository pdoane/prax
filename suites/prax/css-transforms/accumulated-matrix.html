CSS Transforms 2 · 4.1.4 Accumulated 3D Transformation Matrix Computation

The accumulated 3D matrix: offsets, scrolling and perspective

Compute a translation matrix which represents the offset (including the scroll offset) of current element from its parent element, and pre-multiply that matrix into the transform. If parent element has a value for perspective which is not none, pre-multiply the parent element's perspective matrix into the transform. CSS Transforms 2 §4.1.4

The scroll offset: parallax

Each stage scrolls, with perspective: 100px about its center, (80, 40). In it, a blue 40 by 20 box at (60, 30) has translateZ(-100px); an orange 20px square has none.

Only the parent's perspective

The loop takes a parent's perspective, and climbs only within the 3D rendering context. Each stage has perspective: 100px; the blue box translateZ(-100px).
