CSS Transforms 1 · 6.4 User coordinate space

Patterns, gradients and clip paths: their own coordinate systems

For all other transformable elements the transform attribute and transform property define a transformation in the current user coordinate system of the parent. A pattern, a gradient and a clip path are transformed in their own instead. CSS Transforms 1 §6.4 Each stage is an svg, 160 by 80.

A pattern, a gradient and a clip path

The reference box of the referencing rect element is used instead to solve the relative values of the transform-origin property. A pattern holds a blue rect, on the dashed outline, and fills the svg. Transforms are in the gradient coordinate system and in the clipping path coordinate space.
