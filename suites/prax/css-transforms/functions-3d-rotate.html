CSS Transforms 2 · 12.2 3D Transform Functions

3D transform functions: the rotations

rotate3d() specifies a 3D rotation by the angle specified in last parameter about the [x,y,z] direction vector described by the first three parameters. the rotation is clockwise as one looks from the end of the vector toward the origin.
