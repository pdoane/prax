CSS Transforms 1 · 4 The transform-origin Property

transform-origin: the point that stays put

The values of the transform and transform-origin properties are used to compute the transformation matrix: the transform is applied about the origin. CSS Transforms 1 §4 Each blue box, 100 by 60 at (30, 20) on the dashed outline, has scale(0.5): it shrinks toward its origin, which stays put.

Keywords and offsets, and a turn

The value for the horizontal and vertical offset represent an offset from the top left corner of the reference box. If only one value is specified, the second value is assumed to be center.
