CSS Transforms 2 · 4.1.2 3D Rendering Contexts

3D rendering contexts: who shares a 3D space

A 3D rendering context is a set of elements rooted in a common ancestor that, for the purposes of 3D-transform rendering, are considered to share a common three-dimensional coordinate system. Grouping properties flatten such a box.

Establishing a context, and intersecting in it

It is established by a transformable element whose used value for transform-style is preserve-3d and which itself is not part of a 3D rendering context. Its elements, if they intersect, then they are rendered with intersection.

Extending, and participating

A preserve-3d element in a context extends that 3D rendering context, and An element participates in a 3D rendering context if its parent establishes or extends it. Here A is inside a further box in the preserve-3d one.
