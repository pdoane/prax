CSS Transforms 2 · 4.1.5 Backface Visibility

The reverse side of an element

the reverse side looks like a mirror-image of the front side. CSS Transforms 2 §4.1.5 Each blue box is 80 by 40, on the dashed outline, with "AB" at its top left.

A mirror image, or nothing

the backface-visibility property allows the author to make an element invisible when its reverse side is towards the viewer, useful when you place two elements back-to-back, as you would to create a playing card.

Relative to the parent of the context's root

It is considered using the accumulated 3D transformation matrix, and is thus relative to the parent of the element that establishes the 3D rendering context. A box with rotateY(180deg) holds the blue box, untransformed and hidden.
