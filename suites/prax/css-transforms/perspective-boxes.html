CSS Transforms 2 · 4.2 Processing of Perspective-Transformed Boxes

Boxes behind the viewer, and at infinity

To transform each corner (a, b) of a box, the matrix must first be applied to (a, b, 0, 1), which will result in a four-dimensional point (x, y, z, w). CSS Transforms 2 §4.2 Each stage clips; the examples are the section's.

Behind the viewer, at the eye, partly behind

If w < 0 for all four corners of the transformed box, the box is not rendered. If w = 0, (x′, y′, z′) = (x ⋅ n, y ⋅ n, z ⋅ n), far away. If w < 0 for one to three corners of the transformed box, the box must be replaced by a polygon that has any parts with w < 0 cut out.
