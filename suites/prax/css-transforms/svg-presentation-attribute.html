CSS Transforms 1 · 6.1 SVG presentation attributes

The transform attribute in the cascade

SVG 2 defines the transform, patternTransform, gradientTransform attributes as presentation attributes, represented by the CSS transform property. CSS Transforms 1 §6.1 Each stage is an svg, 160 by 80; the dashed outline is where the shape would be untransformed.

The property overrides the attribute

Because of the participation to the CSS cascade, the transform style property overrides the transform attribute. A group holds a blue 40px square at (0, 0).

transform-origin is a presentation attribute too

The transform-origin CSS property is also a presentation attribute. A blue 60 by 40 rect at (60, 20), transform="rotate(90)".
