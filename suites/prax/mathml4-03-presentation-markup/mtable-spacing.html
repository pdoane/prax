MathML 4 · 3.5.1 Table or Matrix <mtable>

mtable: spacing and equal sizes

rowspacing: specifies how much space to add between rows. (default 1.0ex) columnspacing: specifies how much space to add between columns. (default 0.8em) equalrows: specifies whether to force all rows to have the same total height. MathML 4 §3.5.1 Each cell is outlined.
