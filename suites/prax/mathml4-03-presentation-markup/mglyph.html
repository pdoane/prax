MathML 4 · 3.2.1.1 Using images to represent symbols <mglyph/>

mglyph: images as symbols

The mglyph element provides a mechanism for displaying images to represent non-standard symbols. If only one of width and height is given, the image should be scaled to preserve the aspect ratio; if neither are given, the image should be displayed at its natural size. MathML 4 §3.2.1.1 The image is the suite's flag, 40 by 20.
