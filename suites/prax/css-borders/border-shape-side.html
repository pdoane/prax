CSS Borders and Box Decorations 4 · 7.6 Determining the Relevant Side

border-shape: the relevant side

An element's relevant side for border shape is the first side (in the order block-start, inline-start, block-end, and inline-end) that has a non-none border style, or block-start if they're all none. CSS Borders and Box Decorations 4 §7.6
