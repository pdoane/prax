CSS Borders and Box Decorations 4 · 7.5.2 Interaction with box-shadow

border-shape: shadows follow the shape

An outer box-shadow is cast as if the shape defined by the outer path were opaque. An inner box-shadow is cast as if everything outside the shape defined by the inner path were opaque. CSS Borders and Box Decorations 4 §7.5.2
