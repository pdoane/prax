CSS Borders and Box Decorations 4 · 7.5.4 Interaction with Layout

border-shape: no effect on layout

'border-shape' does not affect geometry or layout, which is still computed using the existing 'border-width' properties. The shaped border is purely a visual effect. CSS Borders and Box Decorations 4 §7.5.4
