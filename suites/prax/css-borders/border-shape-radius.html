CSS Borders and Box Decorations 4 · 7.5.1 Interaction with border-radius and corner-shape

border-shape: border-radius ignored

When an element's computed value of 'border-shape' is not none, its 'border-radius' is ignored, as if it was set to 0. 'corner-shape' is implicitly ignored, as it can only work in tandem with 'border-radius'. CSS Borders and Box Decorations 4 §7.5.1
