CSS Borders and Box Decorations 4 · 1.1 Module Interactions

::first-letter and ::first-line

All properties in this module apply to the ::first-letter pseudo-element. The border-radius properties also apply to the ::first-line pseudo-element. CSS Borders and Box Decorations 4 §1.1

::first-letter takes all of them

Each stage's text is "Handgloves", whose first letter is styled.

::first-line takes corners, not borders

The UA must not apply the border-color/style/width properties to ::first-line. The UA may (but is not required to) apply the 'border-image' or 'box-shadow' properties to ::first-line. Each stage holds "aaa bbb ccc ddd" in a block 120px wide, so the first line is "aaa bbb ccc".
