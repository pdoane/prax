CSS Borders and Box Decorations 4 · 3.4 Effect on Tables

border-radius on tables

The 'border-radius' properties do apply to table, inline-table, and table-cell boxes in separated borders mode (border-collapse: separate). When 'border-collapse' is collapse, they have no effect. CSS Borders and Box Decorations 4 §3.4 Each table, blue, has a 16px radius, and its two cells, orange, a 10px radius.
