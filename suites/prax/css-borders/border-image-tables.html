CSS Borders and Box Decorations 4 · 4.8 Effect on Tables

Border images on tables

The 'border-image' properties apply to the border of tables and inline tables that have 'border-collapse' set to collapse. However, this specification does not define how such an image border is rendered. CSS Borders and Box Decorations 4 §4.8 Each table has a 10px blue border and the image of orange corners and blue dots; its cells have 2px purple borders.

Separated, or collapsed

It is recommended that UAs do not apply border images to tables with collapsed borders until then.
