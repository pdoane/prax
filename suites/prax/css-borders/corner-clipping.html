CSS Borders and Box Decorations 4 · 3.1 Corner Clipping

Corner clipping

other effects that clip painting or event handling to the border, padding, or content edge must clip to their respective curves. For example, backgrounds clip to the curve specified by 'background-clip', 'overflow' values other than visible to the curved padding edge (when 'overflow' on both axes is not visible), replaced element content to the curved content edge CSS Borders and Box Decorations 4 §3.1

Overflow, clipped to the curved padding edge
