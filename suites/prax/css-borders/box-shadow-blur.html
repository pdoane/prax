CSS Borders and Box Decorations 4 · 6.3 Blurring shadows: the box-shadow-blur property

box-shadow-blur

The 'box-shadow-blur' property defines one or more blur radii for drop shadows. If the blur value is zero, the shadow’s edge is sharp. Otherwise, the larger the value, the more the shadow’s edge is blurred. CSS Borders and Box Decorations 4 §6.3 Each box is 104 by 44, with an orange shadow offset 0.
