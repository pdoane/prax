CSS Borders and Box Decorations 4 · 3.7 Corner Shaping: the corner-*-shape properties

corner-shape: from notch to square

The different corner shapes can all be expressed as different parameters to a superellipse. CSS Borders and Box Decorations 4 §3.7 Each blue box is 120 by 60 with border-radius: 30px.

The keywords

superellipse(K)

Values larger than 1 make it more "square" Values between 0 and 1 make it "flatter" Negative values define concave curves (a note)
