CSS Borders and Box Decorations 4 · 3.5 Corner Sizing: the border-*-*-radius properties

border-radius: quarter ellipses

The two <length-percentage> values of the 'border-*-radius' properties define the radii of a quarter ellipse that defines the shape of the corner of the outer border edge CSS Borders and Box Decorations 4 §3.5 Each blue box is 140 by 60.

One corner

If the second value is omitted it is copied from the first. If either length is zero, the corner is square, not rounded. Percentages for the horizontal radius refer to the width of the border box, whereas percentages for the vertical radius refer to the height of the border box.

The shorthand

If values are given before and after the slash, then the values before the slash set the horizontal radii and the values after the slash set the vertical radii. The four values for each radii are given in the order top-left, top-right, bottom-right, bottom-left.
