CSS Borders and Box Decorations 4 · 2.3 Line Thickness: the border-width properties

border-width: hairline

The hairline keyword is a UA-defined length, less than or equal to 1px and equal to an integer number of device pixels at the default page zoom, which represents a "just visible" line. CSS Borders and Box Decorations 4 §2.3
