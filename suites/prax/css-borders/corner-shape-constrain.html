CSS Borders and Box Decorations 4 · 3.9.5 Constraining opposite radii

corner-shape: opposite corners kept apart

When concave 'corner-shape' values are present (the superellipse parameter is negative), diagonally opposite corners might overlap each other. The used values of all border radii must be proportionally reduced by multiplying them by the minimum of the opposite corner scale factor and the adjacent corner scale factor.
