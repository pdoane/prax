CSS Borders and Box Decorations 4 · 6.6 Drop Shadows Shorthand: the box-shadow property

box-shadow: offsets, blur, spread, inset

Each shadow is given as a <spread-shadow>, outlining the 'box-shadow-offset' defined by two <length> values, and optional values for the 'box-shadow-blur', 'box-shadow-spread', 'box-shadow-color', and 'box-shadow-position'. Omitted lengths are 0; omitted colors default to transparent when the specified offset is none and to currentcolor otherwise.
