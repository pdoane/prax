CSS Borders and Box Decorations 4 · 3.8.1 Shaping The Corners Of One Side

corner-*-shape: the corners of one side

The 'corner-*-shape' shorthands set the two 'corner-*-*-shape' properties of the related side. If only one value is given, the second value defaults to the same value. CSS Borders and Box Decorations 4 §3.8.1 Each blue box is 120 by 60 with border-radius: 30px.

Physical and flow-relative sides

That is, corner-top-shape: round square sets corner-top-left-shape: round; corner-top-right-shape: square;.
