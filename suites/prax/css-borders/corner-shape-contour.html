corner-shape: computing the contoured path

This algorithm describes how to compute a path with shaped corners. To avoid the complexities of defining how superellipses intersect, the algorithm simplifies the process by specifying that each corner is "clipped out" of the path. CSS Borders and Box Decorations 4 §3.9.4.2

Insets that differ
