SVG 2 · 6.5 Element-specific styling: the ‘class’ and ‘style’ attributes

The class and style attributes

As with HTML, SVG supports the ‘class’ and ‘style’ attributes on all elements to support element-specific styling. SVG 2 §6.5 Each stage is an SVG 160 by 60 with a rect at 20, 10, orange by its fill attribute.

class

The ‘class’ attribute assigns one or more class names to an element, which can then be used for addressing by the styling language.

style

The ‘style’ attribute is used to supply a CSS declaration of an element. The attribute is parsed as a declaration-list.
