SVG 2 · 6.8 User agent style sheet

The user agent style sheet

The following user agent style sheet must be applied in all SVG user agents. SVG 2 §6.8 Each stage is an SVG 160 by 60 unless a caption says otherwise.

overflow: hidden

svg:not(:root), image, marker, pattern, symbol { overflow: hidden; } Dashed outlines mark each viewport, 40 by 40; its content is a circle larger than it.

transform-origin, and xml:space

*:not(svg), *:not(foreignObject) > svg { transform-origin: 0 0; } Root ‘svg’ elements and those in a non-SVG parent must transform around their center. *[xml|space=preserve] { white-space-collapse: preserve-spaces; }
