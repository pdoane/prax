SVG 2 · 6.2 Inline style sheets: the ‘style’ element

The style element

The ‘style’ element allows style sheets to be embedded directly within SVG content. The semantics and processing of a ‘style’ and its attributes must be the same as is defined for the HTML ‘style’ element. SVG 2 §6.2 Each stage is an SVG 160 by 60 holding a style element and a rect 120 by 40 at 20, 10, orange by its fill attribute; each style sheet makes it blue.
