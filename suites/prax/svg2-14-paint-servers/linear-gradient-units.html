SVG 2 · 14.2.2 Linear gradients

linearGradient: gradientUnits

Linear gradients are defined by a ‘linearGradient’ element. SVG 2 §14.2.2 Its gradientUnits Defines the coordinate system for attributes ‘x1’, ‘y1’, ‘x2’ and ‘y2’. §14.2.2.1 Each stage is an SVG 160 by 60. Each gradient is blue to its halfway point and orange after.

objectBoundingBox, the initial value, or userSpaceOnUse

The box, or for userSpaceOnUse the element's user space, where Percentages represent values relative to the current SVG viewport.

A box that is not square

When the object's bounding box is not square, the gradient normal which is initially perpendicular to the gradient vector within object bounding box space may render non-perpendicular relative to the gradient vector in user space. Each rect is 120 by 40 at 20, 10, from corner to corner.
