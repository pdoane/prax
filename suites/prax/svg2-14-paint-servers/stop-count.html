SVG 2 · 14.2.4.3 Notes on gradient stops

Gradient stops: none, or one

It is necessary that at least two stops defined to have a gradient effect. If no stops are defined, then painting shall occur as if ‘none’ were specified as the paint style. If one stop is defined, then paint with the solid color fill using the color defined for that gradient stop. SVG 2 §14.2.4.3 Each stage is an SVG 160 by 60 with a rect 120 by 40 at 20, 10.

No stops: none

Each rect is outlined dashed.

One stop: a solid color
