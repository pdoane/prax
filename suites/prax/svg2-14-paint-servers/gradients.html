SVG 2 · 14.2 Gradients

Gradients: interpolation and the element's transform

Gradients consist of smooth color transitions between points on a drawing surface. SVG 2 §14.2 Each stage is an SVG 160 by 60.

Linear, per channel

For linear and radial gradients, the color value between two stops along the gradient vector is the linear interpolation, per channel, of the color for each stop, weighted by the distance from each stop. Each rect is 120 by 40 at 20, 10; a bar 2 by 20 of the expected color sits on its middle, at x 79.

A copy in the element's geometry

Any transformations applied to the graphics element geometry also apply to the copied gradient vector and gradient normals. Any gradient transforms that are specified on the reference gradient are applied before any graphics element transformations are applied to the gradient. The gradient is blue on its left half, orange on its right; each square is 40 by 40 about 80, 30.
