SVG 2 · 14.3.1 Attributes

pattern: patternTransform, and a tile of no size

patternTransform Contains the definition of an optional additional transformation from the pattern coordinate system onto the target coordinate system. SVG 2 §14.3.1 Each stage is an SVG 160 by 60 with a rect 120 by 40 at 20, 10. Each tile is 20 by 20 with a blue stripe 10 wide on its left.

patternTransform, and transform

‘patternTransform’ gets mapped to the transform CSS property §6.6.

A width of zero

A value of zero disables rendering of the element (i.e., no paint is applied).
