SVG 2 · 14.1.1 Using paint servers as templates

Templates: a shadow tree of the template's children

If the current element has no child elements other than descriptive elements, the user agent must generate a shadow tree for this element, which must behave equivalently to a use-element shadow tree, except that the host is the current paint server element. SVG 2 §14.1.1 Each stage is an SVG 160 by 60 with a rect 120 by 40 at 20, 10.

Clones inherit from the host

The use-element shadow tree model for templating allows cloned content to inherit different styles than the original. The template's one stop is currentColor, and its color is blue.

A pattern's clones

The template is 40 by 40 tiles of a 20 by 20 square, whose fill it inherits from the pattern, blue.
