SVG 2 · 14.2.3 Radial gradients

radialGradient: gradientUnits

Radial gradients are defined by a ‘radialGradient’ element. SVG 2 §14.2.3 Its gradientUnits Defines the coordinate system for attributes ‘cx’, ‘cy’, ‘r’, ‘fx’, ‘fy’, and ‘fr’. §14.2.3.1 Each stage is an SVG 160 by 60. Each gradient is blue to half its radius, orange to its radius, and green beyond.

objectBoundingBox, the initial value

When the object's bounding box is not square, the rings that are conceptually circular within object bounding box space will render as elliptical due to application of the non-uniform scaling transformation from bounding box space to user coordinate system. The initial cx, cy and r are 50%.

userSpaceOnUse

The values are in the user coordinate system of the element painted, and Percentages represent values relative to the current SVG viewport.
