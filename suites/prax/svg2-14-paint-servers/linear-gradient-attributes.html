SVG 2 · 14.2.2.1 Attributes

linearGradient: the vector and spreadMethod

‘x1’, ‘y1’, ‘x2’ and ‘y2’ define a gradient vector for the linear gradient. This gradient vector provides starting and ending points onto which the gradient stops are mapped. SVG 2 §14.2.2.1 Each stage is an SVG 160 by 60 with a rect 100 by 40 at 30, 10. Each gradient runs from blue at 0 to orange at 1.

The vector

The initial values are x1 0%, y1 0%, x2 100% and y2 0%.

spreadMethod

It Indicates what happens if the gradient starts or ends inside the bounds of the target rectangle. Each vector is x1="0.4" x2="0.6", from x 70 to 90.
