SVG 2 · 14.2.4.3 Notes on gradient stops

Gradient stops: offsets clamped and ordered

Gradient offset values less than 0 (or less than 0%) are rounded up to 0%. Gradient offset values greater than 1 (or greater than 100%) are rounded down to 100%. SVG 2 §14.2.4.3 Each stage is an SVG 160 by 60 with a rect 120 by 40 at 20, 10.

Clamped to 0 and 1

Each vector runs from x 50 to 110, with stops at -1, blue, and 2, orange.

In order, and the latter at a tie

If a given gradient stop's offset value is not equal to or greater than all previous offset values, then the offset value is adjusted to be equal to the largest of all previous offset values. If two gradient stops have the same offset value, then the latter gradient stop controls the color value at the overlap point.
