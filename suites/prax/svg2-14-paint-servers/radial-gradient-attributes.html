SVG 2 · 14.2.3.1 Attributes

radialGradient: the end and start circles

‘cx’, ‘cy’ and ‘r’ define the end circle for the radial gradient. The gradient will be drawn such that the 100% gradient stop is mapped to the perimeter of this end circle. SVG 2 §14.2.3.1 Each stage is an SVG 160 by 60 with a rect 120 by 40 at 20, 10; each gradient, in user space, runs from blue at 0 to orange at 1.

The end circle and the start circle

‘fx’, ‘fy’, and ‘fr’ define the start circle for the radial gradient. The gradient will be drawn such that the 0% gradient stop is mapped to the perimeter of this start circle. The initial fx and fy are those of the center, and fr is 0. A dashed circle marks each end circle.

spreadMethod

It Has the same values and meanings as the ‘spreadMethod’ attribute on ‘linearGradient’ element. Each end circle has radius 10 about 80, 30.
