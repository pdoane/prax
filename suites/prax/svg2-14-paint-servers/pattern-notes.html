SVG 2 · 14.3.2 Notes on patterns

pattern: clipped to the tile, and its coordinates

SVG's user agent style sheet sets the overflow property for ‘pattern’ elements to hidden, which causes a rectangular clipping path to be created at the bounds of the pattern tile. SVG 2 §14.3.2 Each stage is an SVG 160 by 60 with a rect 160 by 60 at 0, 0; the patterns are in user space.

Clipped to the tile

The contents' coordinates

If there is no ‘viewBox’ attribute, then the new coordinate system has its origin at (x, y). If there is a ‘viewBox’ attribute, then the new coordinate system is fitted into the region defined by the ‘x’, ‘y’, ‘width’, ‘height’ and ‘patternUnits’ attributes on the ‘pattern’ element using the standard rules for ‘viewBox’ and ‘preserveAspectRatio’.
