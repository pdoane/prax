Paint servers: referenced, never rendered

Paint servers are used by including a URL reference in a ‘fill’ or ‘stroke’ property (i.e. fill="url(#MyLightPurple)"). SVG 2 §14.1 Each stage is an SVG 160 by 60. The gradient in the first card is blue on its left half and orange on its right.

Fill and stroke

A paint server allows the ‘fill’ or ‘stroke’ of an object to be defined by a resource found elsewhere. Each rect is 120 by 40 at 20, 10.

An element in the tree, never rendered

The display value for these elements must always be set to none by the user agent style sheet, and this declaration must have importance over any other CSS rule or presentation attribute. Paint-server elements are available for referencing even when the display property on the paint-server element or any of its ancestors is set to none. properties inherit into a paint-server element from its ancestors; properties do not inherit from the element referencing the paint server element.
