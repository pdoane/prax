CSS 2 · 12.4.1 Nested counters and scope

Nested counters: no scope

Grey lines reset n; the others increment it and show it in blue.

A counter in no scope

If 'counter-increment' or 'content' on an element or pseudo-element refers to a counter that is not in the scope of any 'counter-reset', implementations should behave as though a 'counter-reset' had reset the counter to 0 on that element or pseudo-element. CSS 2 §12.4.1

Before a reset

A reset's scope starts at the element that has it, so an element before it is in no scope and gets a counter of its own; the reset that follows starts a new one. CSS 2 §12.4.1
