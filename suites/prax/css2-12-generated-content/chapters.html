CSS 2 · 12.4.1 Nested counters and scope

Nested counters: chapters and sections

The specification's example shows a way to number chapters and sections with "Chapter 1", "1.1", "1.2", etc. CSS 2 §12.4

Counters on elements that are not nested

Another example, showing how scope works when counters are used on elements that are not nested: each H1 resets section, and its scope runs through the H2s that follow it as siblings, until the next H1's reset. CSS 2 §12.4.1

BODY { counter-reset: chapter; }
H1:before {
    content: "Chapter " counter(chapter) ". ";
    counter-increment: chapter; }
H1 { counter-reset: section; }
H2:before {
    content: counter(chapter) "." counter(section) " ";
    counter-increment: section; }
