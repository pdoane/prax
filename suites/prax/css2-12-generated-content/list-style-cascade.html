CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style shorthand: on lists, not items

Although authors may specify 'list-style' information directly on list item elements (e.g., "li" in HTML), they should do so with care. CSS 2 §12.5.1 Each figure is the specification's markup: an ol class=alpha item "level 1" holding a ul item "level 2".

Unexpected results due to cascade

The desired rendering would have level 1 list items with 'lower-alpha' labels and level 2 items with 'disc' labels. However, the cascading order will cause the first style rule (which includes specific class information) to mask the second. CSS 2 §12.5.1

ol.alpha li  { list-style: lower-alpha }
ul li        { list-style: disc }

Two solutions

The following rules solve the problem by employing a child selector instead. Another solution would be to specify 'list-style' information only on the list type elements: Inheritance will transfer the 'list-style' values from OL and UL elements to LI elements. This is the recommended way to specify list style information. CSS 2 §12.5.1
