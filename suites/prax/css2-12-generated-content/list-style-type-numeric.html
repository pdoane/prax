CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style-type property: numbering systems

Numbering systems are specified with: six keywords. Each list has three items, numbered 1 to 3, and in the first four an ol start=9 shows 9 and 10. CSS 2 §12.5.1

Decimal and roman

decimal: Decimal numbers, beginning with 1. decimal-leading-zero: Decimal numbers padded by initial zeros (e.g., 01, 02, 03, ..., 98, 99). lower-roman: Lowercase roman numerals (i, ii, iii, iv, v, etc.). upper-roman: Uppercase roman numerals (I, II, III, IV, V, etc.). CSS 2 §12.5.1

Georgian and Armenian

georgian: Traditional Georgian numbering (an, ban, gan, ..., he, tan, in, in-an, ...). armenian: Traditional uppercase Armenian numbering. CSS 2 §12.5.1
