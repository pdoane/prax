CSS 2 · 12.2 The 'content' property

The content property: none and normal

content takes normal | none | [ <string> | <uri> | <counter> | attr(<identifier>) | open-quote | close-quote | no-open-quote | no-close-quote ]+. Initial normal, not inherited, applies to :before and :after.

A pseudo-element with no content is not generated

none: The pseudo-element is not generated. normal: Computes to 'none' for the :before and :after pseudo-elements. In each figure the :before is styled as an orange 30 by 20 inline-block, which shows only if it is generated. CSS 2 §12.2
