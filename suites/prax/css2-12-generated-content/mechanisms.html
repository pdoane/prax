CSS 2 · 12 Generated content, automatic numbering, and lists

Generated content: two mechanisms

In some cases, authors may want user agents to render content that does not come from the document tree. Every word in these figures that is not in the page's source is generated.

Content that is not in the document

One familiar example of this is a numbered list; the author does not want to list the numbers explicitly, he or she wants the user agent to generate them automatically. Similarly, authors may want the user agent to insert the word "Figure" before the caption of a figure, or "Chapter 7" before the seventh chapter title. CSS 2 §12

The two mechanisms

In CSS 2.2, content may be generated by two mechanisms: The 'content' property, in conjunction with the :before and :after pseudo-elements. Elements with a value of 'list-item' for the 'display' property. CSS 2 §12
