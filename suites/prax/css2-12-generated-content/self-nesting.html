CSS 2 · 12.4.1 Nested counters and scope

Nested counters: self-nesting

Counters are "self-nesting", in the sense that resetting a counter in a descendant element or pseudo-element automatically creates a new instance of the counter. CSS 2 §12.4.1

Nested lists with one counter name

Thus, the following suffices to number nested list items. The result is very similar to that of setting 'display:list-item' and 'list-style: inside' on the LI element. The markup is the specification's fragment, two lists, the first nested three deep. CSS 2 §12.4.1

OL { counter-reset: item }
LI { display: block }
LI:before { content: counter(item) ". ";
            counter-increment: item }

In the specification's notation, an OL will create a counter, and all children of the OL will refer to that counter. The nested lists are item[1] and two item[2], each a new instance; item[0] goes on counting 3 and 4 after them. CSS 2 §12.4.1
