CSS 2 · 12.4 Automatic counters and numbering

Counters: none, names and inheritance

Each div shows its counters in blue.

none, and several names

The 'counter-increment' property accepts one or more names of counters (identifiers), each one optionally followed by an integer. The keywords 'none', 'inherit' and 'initial' must not be used as counter names. A value of 'none' on its own means no counters are reset, resp. incremented. CSS 2 §12.4

Not inherited

Neither property is inherited: a counter is reset or incremented once, by the element that has the property, not again by its children. CSS 2 §12.4
