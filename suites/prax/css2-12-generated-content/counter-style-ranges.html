CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style-type property: ranges

This specification does not define how alphabetic systems wrap at the end of the alphabet. For instance, after 26 list items, 'lower-latin' rendering is undefined. CSS 2 §12.5.1 A later specification defines it. Markers here are inside.

Since CSS 2 · CSS Counter Styles 3 §2, §3.1.4

Past the alphabet, and outside a style's range

The alphabetic system wraps from "a", "b", "c", to "aa", "ab", "ac". It is defined only over strictly positive counter values. If the counter value is outside the range of the counter style, exit this algorithm and instead generate a counter representation using the counter style’s fallback style and the same counter value. CSS Counter Styles 3 §2, §3.1.4 The roman styles are defined with range: 1 3999, armenian with range: 1 9999, and the fallback is decimal.
