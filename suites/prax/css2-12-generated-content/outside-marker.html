CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style-position property: the outside marker

CSS 2.2 does not specify the precise location of the marker box or its position in the painting order; what it does say about an outside marker is below. Each principal box is tinted blue. CSS 2 §12.5.1

Scrolling and overflow

The marker box is fixed with respect to the principal block box's border and does not scroll with the principal block box's content. In CSS 2.2, a UA may hide the marker if the element's 'overflow' is other than 'visible'. CSS 2 §12.5.1

The marker's effect on height

The size or contents of the marker box may affect the height of the principal block box and/or the height of its first line box, and in some cases may cause the creation of a new line box. CSS 2 §12.5.1
