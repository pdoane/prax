CSS 2 · 12.2 The 'content' property

The content property: attr()

attr(X): This function returns as a string the value of attribute X for the subject of the selector. CSS 2 §12.2

The value of an attribute, as a string

The string is not parsed by the CSS processor. If the subject of the selector does not have an attribute X, an empty string is returned. The case-sensitivity of attribute names depends on the document language. CSS 2 §12.2

Only the subject's attributes

In CSS 2.2, it is not possible to refer to attribute values for other elements than the subject of the selector. CSS 2 §12.2
