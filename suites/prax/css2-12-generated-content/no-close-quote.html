CSS 2 · 12.3.2 Inserting quotes with the 'content' property

Inserting quotes: phantom quotes

The keyword 'no-close-quote' decrements the quoting level, but does not insert a quotation mark. CSS 2 §12.3.2

A quotation of several paragraphs

Some typographic styles require open quotation marks to be repeated before every paragraph of a quote spanning several paragraphs, but only the last paragraph ends with a closing quotation mark. The specification's style sheet puts opening quotation marks on every paragraph in a BLOCKQUOTE, and inserts a single closing quote at the end. CSS 2 §12.3.2

blockquote p:before     { content: open-quote }
blockquote p:after      { content: no-close-quote }
blockquote p.last:after { content: close-quote }

no-open-quote

For symmetry, there is also a 'no-open-quote' keyword, which inserts nothing, but increments the quotation depth by one. CSS 2 §12.3.2
