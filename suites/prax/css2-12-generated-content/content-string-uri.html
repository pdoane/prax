CSS 2 · 12.2 The 'content' property

The content property: strings and URIs

Each figure is an element whose source text is "text"; everything before it is its :before.

<string>

<string>: Text content. The value is a list, and its parts are inserted one after another. CSS 2 §12.2

<uri>

The value is a URI that designates an external resource (such as an image). If the user agent cannot display the resource it must either leave it out as if it were not specified or display some indication that the resource cannot be displayed. CSS 2 §12.2
