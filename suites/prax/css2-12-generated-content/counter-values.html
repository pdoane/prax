counter-increment

The integer indicates by how much the counter is incremented for every occurrence of the element. The default increment is 1. Zero and negative integers are allowed. CSS 2 §12.4

counter-reset

The integer gives the value that the counter is set to on each occurrence of the element. The default is 0. CSS 2 §12.4
