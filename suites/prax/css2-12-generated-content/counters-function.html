CSS 2 · 12.4.1 Nested counters and scope

Nested counters: the counters() function

The 'counters()' function generates a string composed of all of the counters with the same name that are in scope, separated by a given string. CSS 2 §12.4.1

Numbering nested list items

The following style sheet numbers nested list items as "1", "1.1", "1.1.1", etc. CSS 2 §12.4.1

OL { counter-reset: item }
LI { display: block }
LI:before { content: counters(item, ".") " ";
            counter-increment: item }
