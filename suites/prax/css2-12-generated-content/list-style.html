CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style shorthand

list-style takes [ <'list-style-type'> || <'list-style-position'> || <'list-style-image'> ]. Initial: see the individual properties; inherited, applies to elements with display: list-item. Each item's principal box is tinted blue.

Three properties at once

The 'list-style' property is a shorthand notation for setting the three properties 'list-style-type', 'list-style-image', and 'list-style-position' at the same place in the style sheet. The specification's example: ul { list-style: upper-roman inside } and ul > li > ul { list-style: circle outside }. CSS 2 §12.5.1

An image and a type

A URI value may be combined with any other value: with ul { list-style: url("http://png.com/ellipse.png") disc }, the 'disc' will be used when the image is unavailable. Here the type is square, which is easier to tell from the default. CSS 2 §12.5.1
