CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style shorthand: none

Every list first has list-style-type: circle, then the list-style declaration shown.

none sets what is not otherwise specified

A value of 'none' within the 'list-style' property sets whichever of 'list-style-type' and 'list-style-image' are not otherwise specified to 'none'. For example, a value of 'none' for the 'list-style' property sets both 'list-style-type' and 'list-style-image' to 'none'. The result is that no list-item marker is displayed. CSS 2 §12.5.1
