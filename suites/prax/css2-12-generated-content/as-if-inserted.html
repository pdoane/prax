CSS 2 · 12.1 The :before and :after pseudo-elements

Before and after: as if real elements

The :before and :after pseudo-elements interact with other boxes as if they were real elements inserted just inside their associated element. CSS 2 §12.1 Each pair of figures must render the same.

A block before the content

The specification's first example: <p> Text </p> with p:before { display: block; content: 'Some'; } would render in exactly the same way as <p><span>Some</span> Text </p> with span { display: block }. CSS 2 §12.1

A block after the content

<h2> Header </h2> with h2:after { display: block; content: 'Thing'; } would render in exactly the same way as <h2> Header <span>Thing</span></h2> with span { display: block; }. CSS 2 §12.1
