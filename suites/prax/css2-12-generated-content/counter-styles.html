CSS 2 · 12.4.2 Counter styles

Counter styles

By default, counters are formatted with decimal numbers, but all the styles available for the 'list-style-type' property are also available for counters. CSS 2 §12.4.2 Generated text in blue.

The specification's example

The notation is counter(name, <'list-style-type'>). All the styles are allowed, including 'disc', 'circle', 'square', and 'none'. Here chno is 3, section 4, bq 2, p 5. CSS 2 §12.4.2
