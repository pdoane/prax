CSS 2 · 12.3.1 Specifying quotes with the 'quotes' property

The quotes property: auto

CSS 2 leaves the initial value of quotes to the user agent. A later specification names it. Every span has :before { content: open-quote } and :after { content: close-quote }, and no figure sets quotes.

Since CSS 2 · CSS Generated Content 3 §2.4.1

auto: the marks of the parent's language

quotes now takes auto | none | match-parent | [<string> <string>]+, with the initial value auto: A typographically appropriate quotation mark system is automatically chosen by the UA based on the content language of the parent (or, if there is no parent, of the element itself). CSS Generated Content 3 §2.4.1 What CSS 2 left to the user agent is now chosen by language, and by the language of the text around a quotation, not of the quotation itself.
