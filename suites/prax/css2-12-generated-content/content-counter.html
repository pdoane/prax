CSS 2 · 12.2 The 'content' property

The content property: counters

Counters may be specified with two different functions: 'counter()' or 'counters()'. In every figure an outer block resets n to 4; in the right-hand figures an indented inner block resets a second n to 3. CSS 2 §12.2

counter(name) and counter(name, style)

The generated text is the value of the innermost counter of the given name in scope at this pseudo-element; it is formatted in the indicated style ('decimal' by default). CSS 2 §12.2

counters(name, string) and counters(name, string, style)

The generated text is the value of all counters with the given name in scope at this pseudo-element, from outermost to innermost separated by the specified string. The counters are rendered in the indicated style ('decimal' by default). CSS 2 §12.2
