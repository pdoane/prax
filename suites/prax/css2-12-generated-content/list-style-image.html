CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style-image property

list-style-image takes <uri> | none. Initial none, inherited, applies to elements with display: list-item. The image in these figures is an orange 10 by 10 square.

An image replaces the marker

This property sets the image that will be used as the list item marker. When the image is available, it will replace the marker set with the 'list-style-type' marker. The specification's example: ul { list-style-image: url("http://png.com/ellipse.png") }. CSS 2 §12.5.1

An image that is not available

This property specifies appearance of the list item marker if 'list-style-image' has the value 'none' or if the image pointed to by the URI cannot be displayed. (of list-style-type) CSS 2 §12.5.1
