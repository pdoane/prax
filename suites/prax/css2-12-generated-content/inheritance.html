CSS 2 · 12.1 The :before and :after pseudo-elements

Before and after: inherited and initial values

A pseudo-element's own properties come from its element where they inherit, and from their initial values where they do not.

Inheritable properties come from the element

The :before and :after pseudo-elements inherit any inheritable properties from the element in the document tree to which they are attached. In the specification's example, The color of the quote mark will be red, but the font will be the same as the font of the rest of the Q element. CSS 2 §12.1

Other properties take their initial values

In a :before or :after pseudo-element declaration, non-inherited properties take their initial values. So, for example, because the initial value of the 'display' property is 'inline', the quote in the previous example is inserted as an inline box. The next example explicitly sets the 'display' property to 'block', so that the inserted text becomes a block. CSS 2 §12.1
