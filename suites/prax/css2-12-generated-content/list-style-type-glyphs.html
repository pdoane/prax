CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style-type property: glyphs

list-style-type takes disc | circle | square, the numbering and alphabetic keywords on the next pages, and none. Initial disc, inherited, applies to elements with display: list-item.

disc, circle, square and none

This property specifies appearance of the list item marker if 'list-style-image' has the value 'none' or if the image pointed to by the URI cannot be displayed. The value 'none' specifies no marker. Glyphs are specified with disc, circle, and square. Their exact rendering depends on the user agent. CSS 2 §12.5.1
