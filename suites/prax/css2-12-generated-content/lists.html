CSS 2 · 12.5 Lists

Lists: principal box and marker

An element with 'display: list-item' generates a principal block box for the element's content and, depending on the values of 'list-style-type' and 'list-style-image', possibly also a marker box as a visual indication that the element is a list item. CSS 2 §12.5

The marker box

The list properties allow style sheets to specify the marker type (image, glyph, or number), and the marker position with respect to the principal box (outside it or within it before content). They do not allow authors to specify distinct style (colors, fonts, alignment, etc.) for the marker or adjust its position with respect to the principal box; these may be derived from the principal box. CSS 2 §12.5

Backgrounds

The background properties apply to the principal box only; an 'outside' marker box is transparent. CSS 2 §12.5
