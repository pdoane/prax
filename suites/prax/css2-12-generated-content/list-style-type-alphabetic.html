The list-style-type property: alphabetic systems

Alphabetic systems are specified with: five keywords, two of them pairs of synonyms. Each list has three items. CSS 2 §12.5.1

Latin and Greek letters

lower-latin or lower-alpha: Lowercase ascii letters (a, b, c, ... z). upper-latin or upper-alpha: Uppercase ascii letters (A, B, C, ... Z). lower-greek: Lowercase classical Greek alpha, beta, gamma, ... (α, β, γ, ...) CSS 2 §12.5.1

The specification's example

With ol { list-style-type: lower-roman } the document might produce something like this: i, ii, iii. The list marker alignment (here, right justified) depends on the user agent. CSS 2 §12.5.1
