CSS 2 · 12.1 The :before and :after pseudo-elements

Before and after pseudo-elements

Authors specify the style and location of generated content with the :before and :after pseudo-elements. Each figure is a paragraph whose source text is "Keep dry."

Before and after the element's content

As their names indicate, the :before and :after pseudo-elements specify the location of content before and after an element's document tree content. The 'content' property, in conjunction with these pseudo-elements, specifies what is inserted. CSS 2 §12.1

The element's boxes include it

The formatting objects (e.g., boxes) generated by an element include generated content. The specification's example would cause a solid green border to be rendered around the entire paragraph, including the initial string. CSS 2 §12.1

p.memo:before { content: "Note: " }
p.memo        { border: solid green }
