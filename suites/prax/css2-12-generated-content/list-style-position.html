CSS 2 · 12.5.1 Lists: the 'list-style-type', 'list-style-image', 'list-style-position', and 'list-style' properties

The list-style-position property

list-style-position takes inside | outside. Initial outside, inherited, applies to elements with display: list-item. This property specifies the position of the marker box with respect to the principal block box. Each item's principal box is tinted blue. CSS 2 §12.5.1

Outside and inside

outside: The marker box is outside the principal block box. inside: The marker box is placed as the first inline box in the principal block box, before the element's content and before any :before pseudo-elements. The specification's example, with the list set on the ul and inherited by its items: CSS 2 §12.5.1

Right to left

CSS 2.2 does require that for list items whose 'direction' property is 'ltr' the marker box be on the left side of the content and for elements whose 'direction' property is 'rtl' the marker box be on the right side of the content. CSS 2 §12.5.1
