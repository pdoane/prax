CSS 2 · 12.3.1 Specifying quotes with the 'quotes' property

The quotes property: languages and characters

The specification's example chooses the quotation marks by language, with :lang().

Two levels in two languages

With the style sheet below, an English quotation would allow a user agent to produce "Quote me!", and a Norwegian one would produce: «Trøndere gråter når "Vinsjan på kaia" blir deklamert.» CSS 2 §12.3.1

q:lang(en) { quotes: '"' '"' "'" "'" }
q:lang(no) { quotes: "«" "»" '"' '"' }
q:before { content: open-quote }
q:after  { content: close-quote }
