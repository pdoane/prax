CSS Grid Layout 2 · 13.1 Sample Fragmentation Algorithm

Fragmenting a grid: rows that grow

A non-normative algorithm: lay out the grid by using the fragmentation container’s inline size and assume unlimited block size, then Layout the grid container using the values resolved in the previous step. CSS Grid Layout 2 §13.1 The rules it follows: UAs should attempt to minimize distortion of the grid container with respect to unfragmented flow. §13 Each stage is two columns, 60px wide and 60px tall; each grid has two 30px columns.

A row pushed to the next column grows

If a grid area’s size changes due to fragmentation (do not include items that span rows in this decision), increase the grid row size as necessary for rows that either: have a content min track sizing function. Each tall item is 40px with break-inside: avoid; the rows are auto.
