CSS Grid Layout 2 · 7.2.3.3 Interpolation/Combination of repeat()

Interpolating repeat()

If two repeat() notations that have the same first argument (repetition count) and the same number of tracks in their second argument (the track listing), they are combined by combining each component of their computed track lists by computed value (just like combining a top-level track list). They otherwise combine discretely. CSS Grid Layout 2 §7.2.3.3

Two repeat() notations

Each grid runs an animation of grid-template-columns running to and fro, which a still shows 40% of the way, and holds A, B and C. Smoothly, 20px goes to 60px there; discretely, the value stays the first one until halfway.
