CSS Grid Layout 2 · 12.5.1 Distributing Extra Space Across Spanned Tracks

Distributing extra space: up to the limits

Find the space to distribute: Subtract the affected size of every spanned track (not just the affected tracks) from the item's size contribution, flooring it at zero. CSS Grid Layout 2 §12.5.1 Blue spans two columns; bars under it show them. A 10px grid (dashed) has no free space: its columns are their base sizes.

Equally, freezing at the limit

distributing the space equally among these tracks, freezing a track’s item-incurred increase as its affected size + item-incurred increase reaches its limit. For base sizes, the limit is its growth limit, capped by its fit-content() argument if any.

Then to the tracks not affected

If extra space remains at this point, and the item spans both affected tracks and non-affected tracks, distribute space as for the previous step, but into the non-affected tracks instead. Columns minmax(min-content, 20px) minmax(0px, auto): only the first has an intrinsic minimum, so only it is affected when base sizes grow.
