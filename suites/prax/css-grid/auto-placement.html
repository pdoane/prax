CSS Grid Layout 2 · 8.5 Grid Item Placement Algorithm, steps 0 to 2

Placement algorithm: definite items first

The algorithm resolves automatic positions of grid items into definite positions, taking them in order-modified document order, not their original document order. CSS Grid Layout 2 §8.5 Each grid has four 40px columns; added columns are 40px, and rows 20px.

Steps 0 and 1, and order

Generate anonymous grid items: they are always auto-placed. Then Position anything that's not auto-positioned.

Step 2: items locked to a row

For each grid item with a definite row position, sparse packing sets its column-start to the earliest (smallest positive index) line index that ensures this item’s grid area will not overlap any occupied grid cells and that is past any grid items previously placed in this row by this step. Dense packing drops the last condition. X is at row 1, column 2; then come C, with no position, A, grid-row: 1; grid-column: span 2, and B, grid-row: 1.
