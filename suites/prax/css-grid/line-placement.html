CSS Grid Layout 2 · 8.3 Line-based Placement, numbers

Line-based placement: numbers

The four properties contribute a line, a span, or nothing (automatic) to its grid placement, thereby specifying the inline-start, block-start, inline-end, and block-end edges of its grid area. CSS Grid Layout 2 §8.3 Each grid has three explicit 40px columns, lines 1 to 4; columns it adds are 40px too, and rows 20px.

The Nth line, from either end

An integer Contributes the Nth grid line to the grid item’s placement. If a negative integer is given, it instead counts in reverse, starting from the end edge of the explicit grid.

Start and end follow the writing mode

Lines count from the start side: in rtl from the right, and in vertical-rl columns from the top and rows from the right. Each item is grid-column: 1 / 3; grid-row: 2.
