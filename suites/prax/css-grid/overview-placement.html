CSS Grid Layout 2 · 2.2 Placing Items

Placing items

The contents of the grid container are organized into individual grid items (analogous to flex items), which are then assigned to predefined areas in the grid. They can be explicitly placed using coordinates through the grid-placement properties or implicitly placed into empty areas using auto-placement. CSS Grid Layout 2 §2.2

grid-area, and grid-row with grid-column

Each grid has four 20px columns and three 20px rows, an area "a" at row 2, column 3, column lines 1 and 3 named sidebar-start and sidebar-end, and row lines 1 and 3 header-start and footer-end. In each stage, the upper grid's item A is placed with grid-area, the lower grid's B with the equivalent grid-row and grid-column: the two land in the same cells.
