CSS Grid Layout 2 · 10.2 With a Grid Container as Parent, and as containing block

Absolute positioning: a static position in the grid area

The static position of an absolutely-positioned child of a grid container is determined as if it were the sole grid item in a grid area whose edges coincide with the content edges of the grid container. CSS Grid Layout 2 §10.2 Each stage holds a grid container with 10px of padding and two 40px columns, its content box from 10 to 190px across and 10 to 40px down. S, 40 by 20px, is absolutely positioned with no offsets.

When the grid container is the containing block

However, if that grid container also establishes the box’s actual containing block, then the grid area specified by the grid-placement properties establishes its static-position rectangle instead. CSS Box Alignment 3 §A Here the grid container itself is position: relative.
