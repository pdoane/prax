The grid layout algorithm

The algorithm sizes the grid container, sizes and positions all the grid tracks, and lays out the grid items which have been placed into its grid areas. CSS Grid Layout 2 §12

Percentages: auto for the container's size, then resolved

2. Find the size of the grid container: During this phase, cyclic <percentage>s in track sizes are treated as auto. 3. Given the resulting grid container size, run the Grid Sizing Algorithm: During this phase, <percentage>s in track sizes are resolved against the grid container size. Each grid is dashed.

Grid areas are definite

4. Lay out the grid items into their respective containing blocks. Each grid area's width and height are considered definite for this purpose. the size of a grid item which is stretched is also considered definite. Each row is auto, and blue, 40px tall, sizes it.
