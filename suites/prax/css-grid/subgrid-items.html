CSS Grid Layout 2 · 3.4 Nested vs. Subgridded Items

Nested and subgridded items

A grid item can itself be a grid container by giving it display: grid. In the general case the layout of this nested grid’s contents will be independent of the layout of the parent grid it participates in. A nested grid can defer the definition of its rows and/or columns to its parent grid container, making it a subgrid. In this case, the grid items of the subgrid participate in sizing the parent grid, allowing the contents of both grids to align. CSS Grid Layout 2 §3.4

The specification's form

A list of labels and fields: the ul is grid: auto-flow / auto 1fr; each bordered li spans both columns and is a grid, its label in column 1 and its white field in column 2. We want the labels and inputs to align.

Either axis, or both

A subgrid is established by the subgrid keyword of grid-template-rows or grid-template-columns, and can be subgridded in either axis or in both. A grid that has no subgridded axis is a standalone grid. The outer grid has rows 20px 40px; the tinted item spans both and holds A and B, one per row.
