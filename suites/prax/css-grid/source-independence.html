Source-order independence

By combining grid layout with media queries, the author is able to use the same semantic markup, but rearrange the layout of elements independent of their source order. CSS Grid Layout 2 §1.1.2

One source, two templates

Each stage holds the same five elements in the same order: Title, Score, Stats, Board, Ctrls. Each is placed by grid-area into the area of its name; only the container's grid-template-areas and track sizes differ, and The reordering capabilities of grid layout intentionally affect only the visual rendering, leaving speech order and navigation based on the source order. The rows, columns and areas of the grid are defined visually using the grid-template-areas property. Each string is a row, and each word an area.
