CSS Grid Layout 2 · 9 Subgrids, sizing

Subgrids: their items size the parent's tracks

A subgrid acts as if it was completely empty for track sizing purposes in the subgridded dimension. The subgrid's own grid items participate in the sizing of its parent grid in the subgridded dimension(s) and are aligned to it in those dimensions. CSS Grid Layout 2 §9
