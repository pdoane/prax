CSS Grid Layout 2 · 12.5 Resolve Intrinsic Track Sizes, step 1

Shims for baseline-aligned items

Shim baseline-aligned items so their intrinsic size contributions reflect their baseline alignment. For the items in each baseline-sharing group, add a “shim” (effectively, additional margin) on the start/end side (for first/last-baseline alignment) of each item so that, when start/end-aligned together their baselines align as specified. CSS Grid Layout 2 §12.5

The shim counts toward the row's size

Consider these “shims” as part of the items’ intrinsic size contribution for the purpose of track sizing. Each grid, outlined, has one auto row and two 50px columns. Blue is "ab" with padding-top: 20px; orange is "ab" with padding-bottom: 20px; each is 40px tall, and their baselines are 20px apart; start-aligned, the row would be 40px.
