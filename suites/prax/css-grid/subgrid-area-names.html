CSS Grid Layout 2 · 9 Subgrids, named areas

Subgrids: the parent's named areas

When a subgrid overlaps a named grid area in its parent that was created by a grid-template-areas property declaration, implicitly-assigned line names are assigned to represent the parent’s named grid area within the subgrid. CSS Grid Layout 2 §9 Each parent grid has columns of 40, 60 and 80px and grid-template-areas: "aa bb bb", so bb is its last two columns, from 40 to 180px. The tinted, outlined box is a subgrid of its columns, and A is at grid-column: bb.

Whole or in part

If a named grid area only partially overlaps the subgrid, its implicitly-assigned line names will be assigned to the first and/or last line of the subgrid such that a named grid area exists representing that partially overlapped area of the subgrid.

Through two levels

all the explicitly-assigned line names inherit straight through to .inner, but the implicitly-assigned line names are calculated based on each subgrid's overlap of the original named grid area. The parent's lines are also named [x] [y] [z] [w]. An outer subgrid spans its columns 2 to 4; an inner subgrid, in the outer one's second column, spans the parent's third.
