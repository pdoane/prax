CSS Grid Layout 2 · 9 Subgrids, gaps

Subgrids: gaps of their own

half the size of the difference between the subgrid’s gutters (row-gap/column-gap) and its parent grid’s gutters is applied as an extra layer of (potentially negative) margin to the items not at those edges. A value of normal indicates that the subgrid has the same size gutters as its parent grid. CSS Grid Layout 2 §9

The parent's tracks stay as they are

The parent has columns 60px 1fr and a 40px gap: the second column is 100px, from 100px, where C is. The subgrid spans both, and holds A and B.

The difference counts in sizing

The parent has auto auto columns and a 20px gap. The subgrid spans both and holds "abcd" and "ef", 40 and 20px; under it, "x" and "y" mark the columns.
