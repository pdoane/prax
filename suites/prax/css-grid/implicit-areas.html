CSS Grid Layout 2 · 7.3.3 Implicitly-Named Areas

Areas named by their lines

Since a named grid area is referenced by the implicitly-assigned line names it produces, explicitly adding named lines of the same form (foo-start/foo-end) effectively creates a named grid area. Such implicitly-named areas do not appear in the value of grid-template-areas, but can still be referenced by the grid-placement properties. CSS Grid Layout 2 §7.3.3

nav-start and nav-end make an area nav

Each grid has grid-template-columns: 40px [nav-start] 40px 40px [nav-end] 40px and grid-template-rows: [nav-start] 20px [nav-end] 20px, and no grid-template-areas.

Only one edge named

The placement properties take each edge alone: grid-column-start: nav finds nav-start, and grid-column-end: nav finds nav-end.
