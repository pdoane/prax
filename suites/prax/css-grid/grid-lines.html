CSS Grid Layout 2 · 3.1 Grid Lines

Grid lines, by number and by name

Grid lines are the horizontal and vertical dividing lines of the grid. A grid line exists on either side of a column or row. They can be referred to by numerical index, or by an author-specified name. CSS Grid Layout 2 §3.1

The same item, placed two ways

The specification's two examples, scaled: both create three column grid lines and four row grid lines. Each stage, 100px tall, has columns 60px 1fr and rows 20px 1fr 20px. Item A is placed between column lines 2 and 3 and row lines 1 and 4.

A line on either side of each track

Three columns make four column lines. Each item is placed between two lines given by number.
