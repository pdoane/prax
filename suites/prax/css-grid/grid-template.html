CSS Grid Layout 2 · 7.4 Explicit Grid Shorthand: the grid-template property

The grid-template shorthand

The grid-template property is a shorthand for setting grid-template-columns, grid-template-rows, and grid-template-areas in a single declaration. CSS Grid Layout 2 §7.4

Rows / columns, and strings with sizes

<'grid-template-rows'> / <'grid-template-columns'> Sets grid-template-rows and grid-template-columns to the specified values, respectively, and sets grid-template-areas to none. With strings, it Sets grid-template-rows to the <track-size>s following each string.

Line names, and the implicit grid properties

The string form splices in the named lines defined before/after each size. And the grid-template property leaves the implicit grid properties unchanged. §7.1
