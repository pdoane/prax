CSS Grid Layout 2 · 5.1 Establishing Grid Containers: the grid and inline-grid display values

Grid containers: grid and inline-grid

A grid container that is not a subgrid establishes an independent grid formatting context for its contents. This is the same as establishing an independent block formatting context, except that grid layout is used instead of block layout. CSS Grid Layout 2 §5.1

Block-level and inline-level

grid causes an element to generate a grid container box that is block-level when placed in flow layout. inline-grid generates one that is inline-level. Each dashed container has two 40px columns holding A and B, between "one" and "two".

An independent formatting context

floats do not intrude into the grid container, and the grid container's margins do not collapse with the margins of its contents.
