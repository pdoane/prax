CSS Grid Layout 2 · 12.4 Initialize Track Sizes

Initializing track sizes

Each track has a base size, a <length> which grows throughout the algorithm and which will eventually be the track's final size, and a growth limit, a <length> which provides a desired maximum size for the base size. CSS Grid Layout 2 §12.3 Each grid below has its columns at its start (justify-content: start), and the text is 10px a letter.

Base size from the minimum, growth limit from the maximum

A fixed sizing function as minimum: Resolve to an absolute length and use that size as the track’s initial base size. An intrinsic one: Use an initial base size of zero. As maximum, a fixed function is the initial growth limit, and an intrinsic or flexible one infinity. CSS Grid Layout 2 §12.4 A grid sized under a min-content constraint keeps its base sizes; under max-content its tracks grow to their growth limits §12.6. Blue is in minmax(30px, 80px), orange in 40px.

A growth limit below the base size is raised to it

In all cases, if the growth limit is less than the base size, increase the growth limit to match the base size. Note: Gutters are treated as empty fixed-size tracks for the purpose of the track sizing algorithm.
