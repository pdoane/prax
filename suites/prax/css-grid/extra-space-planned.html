Distributing extra space: the planned increase

Maintain separately for each affected track a planned increase, initially set to 0. (This prevents the size increases from becoming order-dependent.) For each affected track, if the track’s item-incurred increase is larger than the track’s planned increase set the track’s planned increase to that value. Update the tracks' affected sizes by adding in the planned increase. CSS Grid Layout 2 §12.5.1
