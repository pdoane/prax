CSS Grid Layout 2 · 2.1 Declaring the Grid

Declaring the grid

The tracks (rows and columns) of the grid are declared and sized either explicitly through the explicit grid properties or are implicitly created when items are placed outside the explicit grid. The grid shorthand and its sub-properties define the parameters of the grid. CSS Grid Layout 2 §2.1

The specification's three grids

Each stage is the example's grid, scaled down; its items are named for where they go.
