Line-based placement: names

A <custom-ident>: First attempt to match the grid area’s edge to a named grid area: if there is a grid line whose line name is <custom-ident>-start (for grid-*-start) / <custom-ident>-end (for grid-*-end), contributes the first such line. Otherwise, treat this as if the integer 1 had been specified along with the <custom-ident>. CSS Grid Layout 2 §8.3

Counting only the lines of a name

If a name is given as a <custom-ident>, only lines with that name are counted. If not enough lines with that name exist, all implicit grid lines are assumed to have that name for the purpose of finding this position.
