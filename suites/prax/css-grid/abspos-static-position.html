CSS Grid Layout 2 · 10.2 With a Grid Container as Parent

Absolute positioning: the static position in a grid container

The static position of an absolutely-positioned child of a grid container is determined as if it were the sole grid item in a grid area whose edges coincide with the content edges of the grid container. CSS Grid Layout 2 §10.2 Each stage is a position: relative block holding a grid container with 10px of padding, the content box from 10 to 190px across and 10 to 40px down. S, 40 by 20px, is absolutely positioned with no offsets.

Not a grid item, and aligned in the content box

An absolutely-positioned child of a grid container is out-of-flow and not a grid item, and so does not affect the placement of other items or the sizing of the grid. Note that this position is affected by the values of justify-self and align-self on the child.
