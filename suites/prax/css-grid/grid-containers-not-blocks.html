CSS Grid Layout 2 · 5.1 Establishing Grid Containers, not block containers

Grid containers are not block containers

Grid containers are not block containers. CSS Grid Layout 2 §5.1

float, clear and vertical-align on items

float and clear have no effect on a grid item. vertical-align has no effect on a grid item. Each grid has two 60px columns.

::first-line and ::first-letter

the ::first-line and ::first-letter pseudo-elements do not apply to grid containers, and grid containers do not contribute a first formatted line or first letter to their ancestors. The red rules are set on a block holding a grid of "one two" and "three".
