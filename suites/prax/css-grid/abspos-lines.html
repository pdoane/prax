CSS Grid Layout 2 · 10.1 With a Grid Container as Containing Block, lines

Absolute positioning: lines that do not exist

If a grid-placement property refers to a non-existent line either by explicitly specifying such a line or by spanning outside of the existing implicit grid, it is instead treated as specifying auto (instead of creating new implicit grid lines). CSS Grid Layout 2 §10.1 Each stage is a position: relative grid container with two 50px columns, lines 1 to 3 at 0, 50 and 100px; the light box A is absolutely positioned, inset: 0.

A missing line is auto

Absolute positioning does not contribute to the sizing of any grid tracks or affect the size/configuration of the grid in any way. Remember that implicit lines are assumed to have all line names, so a referenced line might exist even though it is not explicitly named.

Only a span; no gutter at the edges

If the placement only contains a grid span, replace it with the two auto lines in that axis. there is no gutter between the first/last track of the implicit grid and the “auto” lines in the augmented grid. §11.1
