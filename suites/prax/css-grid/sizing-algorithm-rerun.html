The grid sizing algorithm: columns again

Then, if the min-content contribution of any grid item has changed based on the row sizes and alignment calculated in step 2, re-resolve the sizes of the grid columns with the new min-content and max-content contributions (once only). CSS Grid Layout 2 §12.1 This repetition is necessary for cases where the inline size of a grid item depends on the block size of its grid area. Examples include orthogonal flows and items with an aspect-ratio.

An orthogonal flow

Each grid is 60px tall, with columns 40px auto and one 1fr row. While the columns are sized first, the 1fr row has no definite maximum, so its space is taken as infinite; the rows then make it 60px, and the columns are sized again.

An aspect ratio

Blue is empty, with aspect-ratio: 1, justify-self: start and align-self: stretch: stretched to its row's height, its width follows from that height.
