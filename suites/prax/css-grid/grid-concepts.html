CSS Grid Layout 2 · 3 Grid Layout Concepts and Terminology

Grid layout concepts: rows and columns

The grid is an intersecting set of horizontal and vertical grid lines that divides the grid container’s space into grid areas, into which grid items (representing the grid container’s content) can be placed. CSS Grid Layout 2 §3

Columns along the block axis, rows along the inline axis

There are two sets of grid lines: one set defining columns that run along the block axis, and an orthogonal set defining rows along the inline axis. Each grid is grid-template-columns: 40px 60px and grid-template-rows: 20px 30px, with items 1 to 4 placed in order, along the first row and then the second.
