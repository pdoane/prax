CSS Grid Layout 2 · 8.4 Placement Shorthands

Placement shorthands

The grid-row and grid-column properties are shorthands for grid-row-start/grid-row-end and grid-column-start/grid-column-end, respectively. The grid-area property is a shorthand for grid-row-start, grid-column-start, grid-row-end and grid-column-end. CSS Grid Layout 2 §8.4 Each grid has five 40px columns and three 20px rows, with an area "a" over columns 2 to 4 of rows 2 and 3.

grid-column and grid-row: one value

When the second value is omitted, if the first value is a <custom-ident>, the grid-row-end/grid-column-end longhand is also set to that <custom-ident>; otherwise, it is set to auto.

grid-area: one to four values

Four values set, in turn, grid-row-start, grid-column-start, grid-row-end and grid-column-end. An omitted end is the start's <custom-ident> or else auto; When grid-column-start is omitted, if grid-row-start is a <custom-ident>, all four longhands are set to that value.
