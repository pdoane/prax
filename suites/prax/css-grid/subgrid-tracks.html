CSS Grid Layout 2 · 9 Subgrids, tracks and span

Subgrids: the parent's tracks

Placing the subgrid creates a correspondence between its subgridded tracks and those that it spans in its parent grid. The grid lines thus shared between the subgrid and its parent form the subgrid’s explicit grid, and its track sizes are governed by the parent grid. CSS Grid Layout 2 §9 Each parent grid has columns of 40, 60 and 80px; the tinted, outlined box is the subgrid.

Tracks taken from the parent

The parent also has rows of 20 and 40px. The subgrid has grid-column: 2 / 4; grid-row: 1 / 3; grid: subgrid / subgrid, and holds A, auto-placed, and B at grid-area: 2 / 2.
