CSS Grid Layout 2 · 13 Fragmenting Grid Layout

Grid containers across columns

Grid containers can break across pages between rows or columns and inside items. CSS Grid Layout 2 §13 The same rules apply in any other fragmentation context. Each stage is two columns, 60px wide and 60px tall, filled in order CSS Multi-column Layout 1 §3.2; each grid has two 30px columns and rows of 20px.

Between rows, and no gutter at the break

Class A break opportunities occur between rows or columns. If a grid is fragmented between tracks, the gutter spacing between those tracks must be suppressed. §11.1

Forced breaks

The break-before and break-after properties on grid items are propagated to their grid row. The break-before property on the first row and the break-after property on the last row are propagated to the grid container. Each starred item is break-before: column, or break-after: column where it says so.
