CSS Grid Layout 2 · 12.5 Resolve Intrinsic Track Sizes, step 2

Sizing tracks to non-spanning items

Size tracks to fit non-spanning items: For each track with an intrinsic track sizing function and not a flexible sizing function, consider the items in it with a span of 1. CSS Grid Layout 2 §12.5 Each grid has one column, its stage 150px wide, and blue holds "abcd efgh": a min-content contribution of 40px and a max-content contribution of 90px.

Minimums set the base size

If the track has a min-content min track sizing function, set its base size to the maximum of the items’ min-content contributions; for max-content, max-content contributions. A maximum of 0px is raised to the base size, so each track is its base size.

Maximums set the growth limit

If the track has a min-content max track sizing function, set its growth limit to the maximum of the items’ min-content contributions. For max-content, max-content contributions. For fit-content() maximums, furthermore clamp this growth limit by the fit-content() argument. With a base size of 0, each track then grows to its growth limit in the stage's free space §12.6.
