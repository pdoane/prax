CSS Grid Layout 2 · 7.8 Grid Definition Shorthand: the grid property

The grid shorthand

The grid property is a shorthand that sets all of the explicit grid properties (grid-template-rows, grid-template-columns, and grid-template-areas), and all the implicit grid properties (grid-auto-rows, grid-auto-columns, and grid-auto-flow), in a single declaration. (It does not reset the gutter properties.) CSS Grid Layout 2 §7.8

auto-flow on one side of the slash

These forms set the tracks in one axis explicitly, and grid-auto-flow by the side auto-flow is on, with dense if it's specified.
