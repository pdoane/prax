CSS Grid Layout 2 · 7.5 The Implicit Grid

The implicit grid

When grid items are positioned outside of these bounds, the grid container generates implicit grid tracks by adding implicit grid lines to the grid. These lines together with the explicit grid form the implicit grid. CSS Grid Layout 2 §7.5

Placed outside the explicit grid

Each grid has grid-template-columns: 40px 40px, and grid-auto-columns: 30px sizes the columns it adds. A is at grid-column: 1.

Auto-placement adds tracks too

Once the explicit grid is filled (or if there is no explicit grid) auto-placement will also cause the generation of implicit grid tracks. The auto properties also size any explicit grid tracks created by grid-template-areas but not explicitly sized.
