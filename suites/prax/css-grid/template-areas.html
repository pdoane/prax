grid-template-areas: named areas

This property specifies named grid areas, which are not associated with any particular grid item, but can be referenced from the grid-placement properties. CSS Grid Layout 2 §7.3 In each stage the tracks the strings create are sized by grid-auto-columns: 40px and grid-auto-rows: 20px.

A row for each string, a column for each cell

A row is created for every separate string listed for the grid-template-areas property, and a column is created for each cell in the string. A sequence of one or more "." (U+002E FULL STOP) is a null cell token, which represents an unnamed area in the grid container.

One area from many cells
