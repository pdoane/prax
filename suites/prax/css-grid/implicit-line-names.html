CSS Grid Layout 2 · 7.3.2 Implicitly-Assigned Line Names

Line names from named areas

For each named grid area foo, four implicitly-assigned line names are created: two named foo-start, naming the row-start and column-start lines of the named grid area, and two named foo-end, naming the row-end and column-end lines of the named grid area. CSS Grid Layout 2 §7.3.2

main-start and main-end

Three 40px columns and grid-template-areas: ". main .": the area main is the middle column of the first row. The names behave just like any other line names, except that they do not appear in the value of grid-template-rows/grid-template-columns.

More lines with the same name

Even if an explicitly-assigned line name with the same name is defined, the implicitly-assigned line names are just more lines with the same name. Here line 1 is also named main-start, by grid-template-columns: [main-start] 40px 40px 40px.
