CSS Grid Layout 2 · 6.3 Reordered Grid Items: the order property

order in a grid

The order property also applies to grid items. It affects their auto-placement and painting order. CSS Grid Layout 2 §6.3

Auto-placement

Auto-placement takes grid items in order-modified document order. §7.7 Each stage has three 60px columns and A, B, C in that source order.

Painting

The painting order of grid items is exactly the same as inline blocks, except that order-modified document order is used in place of raw document order. §6.5 A and B, 60px wide, share a cell; B has margin-left: 30px, so they overlap from 30 to 60px.
