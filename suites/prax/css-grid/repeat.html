CSS Grid Layout 2 · 7.2.3 Repeating Rows and Columns: the repeat() notation

Repeating rows and columns

The repeat() notation represents a repeated fragment of the track list, allowing a large number of columns or rows that exhibit a recurring pattern to be written in a more compact form. CSS Grid Layout 2 §7.2.3

The spec's example, made narrow: four 30px "main" columns, each between col-start and col-end, with 10px "gutter" columns around them. The items are at col-start 1 to col-start 4.
