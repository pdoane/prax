CSS Grid Layout 2 · 11.5 Aligning the Grid, distributed alignment

Distributed alignment widens the gutters

Note that certain values of justify-content and align-content can cause the tracks to be spaced apart (space-around, space-between, space-evenly) or to be resized (stretch). CSS Grid Layout 2 §11.5 The space is added to the relevant gutters CSS Box Alignment 3 §5.1.4.

Spanning items grow with the gutters

the spanning item’s grid area is increased to accommodate the extra space assigned to the gutters due to alignment. Note that alignment (unlike gap spacing) happens after the grid tracks are sized, so if the track sizes are determined by the contents of the spanned item, it will gain excess space in the alignment stage.
