CSS Grid Layout 2 · 6.1 Grid Item Display

Grid items are blockified

If the computed display value of an element's nearest ancestor element (skipping display:contents ancestors) is grid or inline-grid, the element's own display value is blockified. CSS Grid Layout 2 §6.1

Inline children become blocks

Each grid has 60px columns; an item that is a block stretches to fill its column, as an inline box would not.

No anonymous boxes, and a context of its own

two contiguous grid items with display: table-cell will become two separate display: block grid items, instead of being wrapped into a single anonymous table. And a grid item establishes an independent formatting context for its contents.
