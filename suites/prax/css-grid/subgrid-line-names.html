Subgrids: line numbers and names

The grid-placement properties of the subgrid’s grid items and the line numbers they use are scoped to the lines covered by the subgrid. CSS Grid Layout 2 §9 Each parent grid has columns of 40, 60 and 80px; the tinted, outlined box is a subgrid of its columns.

Numbers count from the subgrid

numeric indices count starting from the first line of the subgrid rather than the first line of the parent grid. Line numbering and placement rules obey the subgrid’s own writing mode. The subgrid spans the parent's columns 2 to 4, and A is at grid-column: 1.

The parent's line names

the subgridded lines automatically receive the explicitly-assigned line names specified on the corresponding lines of the parent grid. These names are in addition to any line names specified locally on the subgrid. The parent is [x] 40px [y] 60px [z] 80px [w], and the subgrid spans it all.
