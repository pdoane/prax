CSS Grid Layout 2 · 8.1.4 Auto Placement

Common patterns: auto placement

A grid item can be automatically placed into the next available empty grid cell, growing the grid if there's no space left. CSS Grid Layout 2 §8.1.4 Each grid has five 40px columns and no rows of its own; its rows, 20px, are added as items need them.

The next empty cell, across or down

grid-area: auto is the initial value. Whether the auto-placement algorithm searches across and adds rows, or searches across and adds columns, is controlled by the grid-auto-flow property.

With a span

Auto-placement can be combined with an explicit span, if the item should take up more than one cell: grid-area: span 2 / span 3 Auto-placed item, covering two rows and three columns. By default, the auto-placement algorithm looks linearly through the grid without backtracking; if it has to skip some empty spaces to place a larger item, it will not return to fill those spaces. Item 2 is span 2 / span 3.
