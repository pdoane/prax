CSS Grid Layout 2 · 12.7 Expand Flexible Tracks

Expanding flexible tracks

This step sizes flexible tracks using the largest value it can assign to an fr without exceeding the available space. For each flexible track, if the product of the used flex fraction and the track's flex factor is greater than the track's base size, set its base size to that product. CSS Grid Layout 2 §12.7

Definite free space

Otherwise, if the free space is a definite length: The used flex fraction is the result of finding the size of an fr using all of the grid tracks and a space to fill of the available grid space. §12.7.1 Each grid is as wide as its 150px stage, its edges dashed.

No free space, or a min-content constraint: zero

If the free space is zero or if sizing the grid container under a min-content constraint: The used flex fraction is zero. Then each flexible track keeps its base size.
