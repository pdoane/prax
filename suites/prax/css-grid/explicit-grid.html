CSS Grid Layout 2 · 7.1 The Explicit Grid

The explicit grid

The size of the explicit grid is determined by the larger of the number of rows/columns defined by grid-template-areas and the number of rows/columns sized by grid-template-rows/grid-template-columns. CSS Grid Layout 2 §7.1

Tracks from the areas, sizes from grid-auto-*

Any rows/columns defined by grid-template-areas but not sized by grid-template-rows/grid-template-columns take their size from the grid-auto-rows/grid-auto-columns properties. If these properties don't define any explicit tracks the explicit grid still contains one grid line in each axis. Each grid has grid-auto-columns: 20px.

Indexes count from the explicit grid's edges

Positive indexes count from the start side (starting from 1 for the start-most explicit line), while negative indexes count from the end side (starting from -1 for the end-most explicit line). Three explicit columns of 40px, each item on a row of its own.
