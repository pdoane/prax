CSS Grid Layout 2 · 6.6 Automatic Minimum Size of Grid Items

Automatic minimum size of grid items

The automatic minimum size of a grid item is its content-based minimum size if it is not a scroll container, it spans at least one track in that axis whose min track sizing function is auto, and if it spans more than one track in that axis, none of those tracks are flexible; Otherwise, the automatic minimum size is zero.
