CSS Grid Layout 2 · 8 Placing Grid Items

Placing grid items: a position and a span

Every grid item is associated with a grid area, a rectangular set of adjacent grid cells that the grid item occupies. Its placement consists of a grid position and a grid span. CSS Grid Layout 2 §8 Each stage is a grid of five 40px columns and 20px rows.

Start, end and span

A definite value for any two of Start, End, and Span in a given dimension implies a definite value for the third. If both lines are given, the span is implicit; with span, explicit; otherwise automatic, and its grid span is 1. A position not given is automatic (determined by auto-placement).

The grid area is the containing block

The grid area defines the containing block for the grid item.
