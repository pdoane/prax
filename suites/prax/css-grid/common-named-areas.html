CSS Grid Layout 2 · 8.1.1 Named Areas

Common patterns: named areas

An item can be placed into a named grid area (such as those produced by the template in grid-template-areas) by specifying the area’s name in grid-area CSS Grid Layout 2 §8.1.1

Into a named area

Each stage's grid has five 40px columns and four 20px rows, with the areas

"head head head head head"
"side main main main ."
"side main main main ."
"foot foot foot foot foot"

Partly aligned with an area

An item can also be partially aligned with a named grid area, with other edges aligned to some other line, as grid-row-start: main Align the row-start edge to the start edge of the "main" named area.
