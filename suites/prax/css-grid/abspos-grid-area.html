CSS Grid Layout 2 · 10.1 With a Grid Container as Containing Block

Absolute positioning: a grid area as containing block

If an absolutely positioned element's containing block is generated by a grid container, the containing block corresponds to the grid area determined by its grid-placement properties. The offset properties (top/right/bottom/left) then indicate offsets inwards from the corresponding edges of this containing block, as normal. CSS Grid Layout 2 §10.1 Each stage is a position: relative grid container, and A is absolutely positioned.

The grid area, and offsets inside it

Columns of 50, 100 and 50px, rows of 30px. Grids and the grid-placement properties are flow-relative, while the offset properties (left, right, top, and bottom) are physical.

auto: the padding edge

Instead of auto-placement, an auto value for a grid-placement property contributes a special line to the placement whose position is that of the corresponding padding edge of the grid container. Each container has 10px of padding and two 40px columns, centered, and two 30px rows: its lines are at 60, 100 and 140px across, and 10, 40 and 70px down. A has inset: 0.
