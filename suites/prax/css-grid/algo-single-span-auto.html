CSS Grid Layout 2 · 12.5 Resolve Intrinsic Track Sizes, step 2, auto minimums

Auto minimums of non-spanning items

If the track has an auto min track sizing function and the grid container is being sized under a min-/max-content constraint, set the track's base size to the maximum of its items’ limited min-content contributions; Otherwise, of their minimum contributions. CSS Grid Layout 2 §12.5 Blue holds "abcd efgh": min-content 40px, max-content 90px.

The minimum contribution

Where its preferred size is auto, its minimum contribution is the outer size that would result from assuming the item’s used minimum size as its preferred size; else the item’s minimum contribution is its min-content contribution. Each dashed grid is 10px wide, its column auto, so there is no free space and the column is its base size.

Under an intrinsic constraint: the limited min-content contribution

The limited contribution is the min-content contribution limited by the max track sizing function, or a fit-content() argument, if that is fixed and ultimately floored by its minimum contribution. Each grid is width: min-content; blue has min-width: 10px.
