CSS Grid Layout 2 · 8.1.2 Numeric Indexes and Spans

Common patterns: numeric indexes and spans

Grid items can be positioned and sized by number, which is particularly helpful for script-driven layouts. By default, a grid item has a span of 1. Different spans can be given explicitly CSS Grid Layout 2 §8.1.2

By number, in the writing mode

grid-row: 2 / span 5 Starts in the 2nd row, spans 5 rows down (ending in the 7th row). grid-row: span 5 / 7 Ends in the 7th row, spans 5 rows up (starting in the 2nd row). Columns 40px, rows 20px. Note that grid indexes are writing mode relative. For example, in a right-to-left language like Arabic, the first column is the rightmost column. In the narrow stages, three 30px columns and three 20px rows, A is grid-row: 2; grid-column: 1 / span 2.
