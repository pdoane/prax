CSS Grid Layout 2 · 7.6 Implicit Track Sizing: the grid-auto-rows and grid-auto-columns properties

grid-auto-rows and grid-auto-columns

The grid-auto-columns and grid-auto-rows properties specify the size of tracks not assigned a size by grid-template-rows or grid-template-columns. CSS Grid Layout 2 §7.6

One size

The specification's example: grid-template-columns: 20px; grid-auto-columns: 40px; grid-template-rows: 20px; grid-auto-rows: 40px, and A, B, C, D in the cells of two rows and two columns.

A pattern, forwards and backwards

If multiple track sizes are given, the pattern is repeated as necessary to find the size of the affected tracks. The first track after the last explicitly-sized track receives the first specified size, and so on forwards; and the last implicit grid track before the explicit grid receives the last specified size, and so on backwards. Each grid has one explicit 40px column and grid-auto-columns: 20px 40px.
