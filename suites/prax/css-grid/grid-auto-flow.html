CSS Grid Layout 2 · 7.7 Automatic Placement: the grid-auto-flow property

grid-auto-flow: row, column, dense

Grid items that aren't explicitly placed are automatically placed into an unoccupied space in the grid container by the auto-placement algorithm. grid-auto-flow controls how the auto-placement algorithm works. CSS Grid Layout 2 §7.7

row and column

row places items by filling each row in turn, adding new rows as necessary. column places them by filling each column in turn, adding new columns as necessary. And Auto-placement takes grid items in order-modified document order.

Sparse and dense

Without dense, the placement algorithm only ever moves “forward” in the grid when placing items, never backtracking to fill holes. dense attempts to fill in holes earlier in the grid if smaller items come up later. Four 40px columns; B has grid-column: span 4, and does not fit beside A.
