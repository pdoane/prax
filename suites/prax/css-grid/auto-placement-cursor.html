CSS Grid Layout 2 · 8.5 Grid Item Placement Algorithm, step 4, sparse

Placement algorithm: the cursor, sparse

Position the remaining grid items. Initially the auto-placement cursor is set to the start-most row and column lines in the implicit grid. Sparse packing only ever moves “forward” in the grid when placing items, never backtracking to fill holes. CSS Grid Layout 2 §8.5 Each grid has three 40px columns; rows are added, 20px.

An item with a definite column

Set the column position of the cursor to the grid item’s column-start line. If this is less than the previous column position of the cursor, increment the row position by 1. Then the row moves down until the item fits.

An item with no position

The cursor moves along the row until the item fits; if it would overflow the columns, the cursor goes to the next row's start-most column line in the implicit grid.
