CSS Grid Layout 2 · 7.2.1 Track Sizes, lengths and percentages

Track sizes: lengths and percentages

<percentage> values are relative to the inner inline size of the grid container in column grid tracks, and the inner block size of the grid container in row grid tracks. CSS Grid Layout 2 §7.2.1

Lengths and percentages of columns

A non-negative length or percentage; a percentage is of the content box, inside the padding.

Percentages of rows

Rows take percentages of the grid container's block size; each grid here is height: 80px.
