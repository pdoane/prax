CSS Grid Layout 2 · 11.3 Inline-axis Alignment: the justify-self and justify-items properties

justify-self in grid: baselines and their cycles

Grid items can be aligned in the inline dimension by using the justify-self property on the grid item or justify-items property on the grid container. CSS Grid Layout 2 §11.3 The values: CSS Box Alignment 3 §6.1.5.

Baselines in the inline axis

Each grid is vertical-rl, so its inline axis runs down and its rows are side by side, from the right. Its items are horizontal-tb with justify-items: baseline: blue has 26px text, orange 13px, and the red line is blue's baseline.

A size that depends on the track: fallback

If baseline alignment is specified on a grid item whose size in that axis depends on the size of an intrinsically-sized track, that item does not participate in baseline alignment, and instead uses its fallback alignment. Orange has height: 50%, its size in the grid's inline axis.
