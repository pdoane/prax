CSS Grid Layout 2 · 11.6 Grid Container Baselines

Grid container baselines

The first baseline set of a grid container is taken from the first available of the steps below. CSS Grid Layout 2 §11.6 Each stage: "x", then an inline-grid of two 50px columns; the red line is the line's baseline. A "low" item has 20px of padding above its text.

From baseline-aligned items in the first row

1. If any grid items intersecting the first (block-start–most) non-empty track participate in first baseline alignment along the relevant axis, generate a baseline set from their shared alignment baseline. 2. Otherwise, if any grid items intersecting that track participate in last baseline alignment, from that.

Otherwise from the first item that has a baseline

3. Otherwise, if any grid items intersecting that track have a baseline set in the relevant axis at all, take the baseline set from the first such grid item in grid order. 4. Otherwise, if there are any grid items at all, synthesize a baseline set from the first grid item in grid order.
