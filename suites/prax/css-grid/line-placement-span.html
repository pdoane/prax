CSS Grid Layout 2 · 8.3 Line-based Placement, spans

Line-based placement: spans

span Contributes a grid span to the grid item’s placement such that the corresponding edge of the grid item’s grid area is N lines from its opposite edge in the corresponding direction. If the <integer> is omitted, it defaults to 1. CSS Grid Layout 2 §8.3

A span of lines, or of named lines

If a name is given as a <custom-ident>, only lines with that name are counted. Eight 20px columns whose lines are named, in turn, A, B, C, A, B, C, A, B, C.

Implicit lines on the side searched

If not enough lines with that name exist, all implicit grid lines on the side of the explicit grid corresponding to the search direction are assumed to have that name for the purpose of counting this span. Added columns are 40px.
