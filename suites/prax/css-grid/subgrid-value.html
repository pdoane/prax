CSS Grid Layout 2 · 7.2 Explicit Track Sizing, subgrid

The subgrid value

The subgrid value indicates that the grid will adopt the spanned portion of its parent grid in that axis. Rather than being specified explicitly, the sizes of the grid rows/columns will be taken from the parent grid's definition. CSS Grid Layout 2 §7.2

The parent's tracks, and local names

The parent has columns of 30, 50 and 70px. if a <line-name-list> is given, the specified <line-names>s are assigned to the lines of the subgrid’s explicit grid, one per line, starting with line 1. The dashed subgrid is grid-column: 2 / 4.

No parent grid: none

If there is no parent grid, or if the grid container is otherwise forced to establish an independent formatting context (for example, due to layout containment or absolute positioning), the used value is the initial value, none, and the grid container is not a subgrid. Each dashed grid holds "abcd" and "ef".
