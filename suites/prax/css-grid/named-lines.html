CSS Grid Layout 2 · 7.2.2 Naming Grid Lines: the [<custom-ident>*] syntax

Naming grid lines

While grid lines can always be referred to by their numerical index, line names can make the grid-placement properties easier to understand and maintain. Line names can be explicitly assigned with the grid-template-rows and grid-template-columns properties. CSS Grid Layout 2 §7.2.2

Names in brackets, several to a line

The grid is [first nav-start] 50px [main-start] 1fr [last], the spec's example made narrow.

Not span, not auto

A line name cannot be span or auto, i.e. the <custom-ident> in the <line-names> production excludes the keywords span and auto. Each declaration below uses one, and is dropped: the grid has no explicit columns, and its items stack.
