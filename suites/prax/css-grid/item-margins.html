CSS Grid Layout 2 · 6.4 Grid Item Margins and Paddings

Grid item margins and paddings

As adjacent grid items are independently contained within the containing block formed by their grid areas, the margins of adjacent grid items do not collapse. CSS Grid Layout 2 §6.4

No collapsing; auto margins

Auto margins expand to absorb extra space in the corresponding dimension.

Percentages of the grid area's inline size

Percentage margins and paddings on grid items, like those on block boxes, are resolved against the inline size of their containing block, e.g. left/right/top/bottom percentages all resolve against their containing block’s width in horizontal writing modes.
