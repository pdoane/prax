CSS Grid Layout 2 · 7.2 Explicit Track Sizing: the grid-template-rows and grid-template-columns properties

grid-template-columns and grid-template-rows

These properties specify, as a space-separated track list, the line names and track sizing functions of the grid. The grid-template-columns property specifies the track list for the grid's columns, while grid-template-rows specifies the track list for the grid's rows. CSS Grid Layout 2 §7.2

none, and a track list

none Indicates that no explicit grid tracks are created by this property; a track list sizes each track: a length, a percentage of the grid container’s size, a measurement of the contents occupying the column or row, or a fraction of the free space in the grid. Each grid holds A, B and C.

Rows, and columns in the inline axis

Columns are tracks along the inline axis, rows along the block axis §3.
