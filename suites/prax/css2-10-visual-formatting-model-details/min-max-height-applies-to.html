CSS 2 · 10.7 Minimum and maximum heights: 'min-height' and 'max-height'

Min-height and max-height: what they apply to

Both apply to all elements but non-replaced inline elements, table columns, and column groups.

Not to non-replaced inline elements

The height of an inline, non-replaced element's box comes from its font, and neither property changes it. CSS 2 §10.7
