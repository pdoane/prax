Calculating widths and margins

Every box below is a blue div with width: auto and the text "box". The kind of box it generates decides what auto becomes.

The kind of box decides

The values of an element's 'width', 'margin-left', 'margin-right', 'left' and 'right' properties as used for layout depend on the type of box generated and on each other. In principle, the values used are the same as the computed values, with 'auto' replaced by some suitable value, and percentages calculated based on the containing block, but there are exceptions.
