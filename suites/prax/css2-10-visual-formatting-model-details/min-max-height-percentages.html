CSS 2 · 10.7 Minimum and maximum heights: 'min-height' and 'max-height'

Min-height and max-height: percentages

A percentage min-height or max-height is of the containing block's height, which may not be known before the box is laid out.

Percentages of an auto height

If the height of the containing block is not specified explicitly (i.e., it depends on content height), and this element is not absolutely positioned, the percentage value is treated as '0' (for 'min-height') or 'none' (for 'max-height'). CSS 2 §10.7
