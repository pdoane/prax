CSS 2 · 10.8.1 Leading and half-leading

The line-height property: normal

line-height takes normal | <number> | <length> | <percentage>. Initial normal, inherited, and it applies to all elements. Each stage's text is 10pt, with each line's span in orange.

normal

Tells user agents to set the used value to a "reasonable" value based on the font of the element. We recommend a used value for 'normal' between 1.0 to 1.2. CSS 2 §10.8.1

Since CSS 2 · CSS Inline Layout 3 §5.1, §5.3

normal from the fonts' metrics

Determine the preferred line height automatically based on the metrics of the used font. When its computed line-height is normal, the layout bounds of an inline box encloses all its glyphs, going from the highest A to the deepest D. CSS Inline Layout 3 §5.1, §5.3 Fallback fonts count too. Each block is 20px PR Arimo, which has no Japanese, then PR Noto Sans JP.
