CSS 2 · 10.8.1 Leading and half-leading

The vertical-align property: top and bottom

Each stage's text is 13px on 20px lines, with the line's baseline dashed in red. A grey 60px inline-block makes each line 60px tall.

Relative to the line box

Align the top of the aligned subtree with the top of the line box. (top) Align the bottom of the aligned subtree with the bottom of the line box. (bottom) CSS 2 §10.8.1

The aligned subtree

The aligned subtree of an inline element contains that element and the aligned subtrees of all children inline elements whose computed 'vertical-align' value is not 'top' or 'bottom'. The top of the aligned subtree is the highest of the tops of the boxes in the subtree, and the bottom is analogous. CSS 2 §10.8.1
