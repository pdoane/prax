CSS 2 · 10.8.1 Leading and half-leading

The vertical-align property: scroll containers inside

CSS 2 aligns an inline-block by its last line box, wherever it is. Each stage's text is 13px on 20px lines, with the line's baseline dashed in red. Each orange inline-block is aligned baseline and holds block boxes, tinted blue.

Since CSS 2 · CSS Box Alignment 3 §9.1

A scroll container inside

for legacy reasons if its 'baseline-source' is 'auto' (the initial value) a block-level or inline-level block container that is a block-axis scroll container always has a last baseline set, whose baselines all correspond to its block-end margin edge. CSS Box Alignment 3 §9.1 So a block with overflow: hidden inside the inline-block gives it its bottom margin edge.
