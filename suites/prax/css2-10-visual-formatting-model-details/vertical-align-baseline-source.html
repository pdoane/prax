CSS 2 · 10.8.1 Leading and half-leading

The vertical-align property: first and last baselines

CSS 2 aligns an inline-block by its last line. Each stage's text is 13px on 20px lines, with the line's baseline dashed in red, and each orange inline-block holds three lines.
