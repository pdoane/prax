CSS 2 · 10.5 Content height: the 'height' property

The height property: percentages and positioning

An absolutely positioned box's percentage height is of its containing block's padding box, which is always known; the root's is of the initial containing block.

Absolutely positioned: the padding box

Note: For absolutely positioned elements whose containing block is based on a block-level element, the percentage is calculated with respect to the height of the padding box of that element. the height of the containing block of an absolutely positioned element is independent of the size of the element itself, and thus a percentage height on such an element can always be resolved.
