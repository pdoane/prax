CSS 2 · 10.3.1 Inline, non-replaced elements

Widths: inline, non-replaced elements

An inline, non-replaced element is one such as span, whose content is laid out in lines. Each orange span sits between the letters a and b.

No width, and auto margins are 0

The 'width' property does not apply. A computed value of 'auto' for 'margin-left' or 'margin-right' becomes a used value of '0'. CSS 2 §10.3.1
