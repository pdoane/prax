CSS 2 · 10.3.3 Block-level, non-replaced elements in normal flow

Block widths: centering and over-constraint

Each blue box is a block in a 200px containing block, with no border or padding that counts: its width is what it shows.

Both margins auto

If both 'margin-left' and 'margin-right' are 'auto', their used values are equal. This horizontally centers the element with respect to the edges of the containing block. CSS 2 §10.3.3

Over-constrained

If all of the above have a computed value other than 'auto', the values are said to be "over-constrained" and one of the used values will have to be different from its computed value. If the 'direction' property of the containing block has the value 'ltr', the specified value of 'margin-right' is ignored and the value is calculated so as to make the equality true. If the value of 'direction' is 'rtl', this happens to 'margin-left' instead. Each box has width: 100px; margin: 0 20px. CSS 2 §10.3.3
