CSS 2 · 10.8.1 Leading and half-leading

The line-height property: values

line-height takes normal | <number> | <length> | <percentage>. Initial normal, inherited, and it applies to all elements.

<number>, <length> and <percentage>

The used value of the property is this number multiplied by the element's font size. The specified length is used in the calculation of the line box height. The computed value of the property is this percentage multiplied by the element's computed font size. Each stage is 10px text, and holds a block of 20px text: its own font size counts, not the stage's. CSS 2 §10.8.1

Since CSS 2 · CSS Values and Units 4 §9.1

A calculation, clamped

numeric functions returning out-of-range values never cause a declaration to become invalid. Instead, the value of a numeric function is clamped to the range allowed in the context it is used at computed value time if possible. CSS Values and Units 4 §9.1
