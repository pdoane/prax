CSS 2 · 10.3.3 Block-level, non-replaced elements in normal flow

Block widths: the constraint equation

A block's horizontal margins, borders, padding and width add up to its containing block's width, here the 200px stage.

margin border padding content

The equation, and an auto width

'margin-left' + 'border-left-width' + 'padding-left' + 'width' + 'padding-right' + 'border-right-width' + 'margin-right' = width of containing block If 'width' is set to 'auto', any other 'auto' values become '0' and 'width' follows from the resulting equality. CSS 2 §10.3.3

Exactly one auto

If there is exactly one value specified as 'auto', its used value follows from the equality. Each blue box has width: 100px. CSS 2 §10.3.3
