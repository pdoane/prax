CSS 2 · 10.1 Definition of "containing block"

Containing blocks: an inline ancestor

An absolute box's nearest positioned ancestor here is an orange inline: relative, on one line, with 10px 20px of padding and a 2px border.

The padding boxes of the inline's boxes

In the case that the ancestor is an inline element, the containing block is the bounding box around the padding boxes of the first and the last inline boxes generated for that element. In CSS 2.2, if the inline element is split across multiple lines, the containing block is undefined. CSS 2 §10.1

Since CSS 2 · CSS Positioned Layout 3 §2.1

The content edges of the inline's fragments

For an inline ancestor, the containing block is formed by forming a rectangle from the start-most content edges (in both axes) of the first box fragment of the ancestor, and the end-most content edges of the end-most box fragment(s) of the ancestor in each axis. CSS Positioned Layout 3 §2.1 The padding box becomes the content box, and a split inline is defined.
