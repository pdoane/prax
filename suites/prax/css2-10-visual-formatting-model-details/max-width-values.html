CSS 2 · 10.4 Minimum and maximum widths: 'min-width' and 'max-width'

Max-width: values

max-width takes <length> | <percentage> | none, initial none, not inherited. Each blue box has no padding, so its width is what it shows.

max-width

Specifies a fixed minimum or maximum used width. (Only on 'max-width') No limit on the width of the box. CSS 2 §10.4
