CSS 2 · 10.4 Minimum and maximum widths: 'min-width' and 'max-width'

Min-width: values

min-width takes <length> | <percentage>, initial 0, not inherited. Each blue box has no padding, so its width is what it shows.

min-width

These two properties allow authors to constrain content widths to a certain range. Specifies a fixed minimum or maximum used width. The percentage is calculated with respect to the width of the generated box's containing block. CSS 2 §10.4

Since CSS 2 · CSS Box Sizing 3 §3.1.2, §3.2

The initial value is auto

The initial value of auto is new; in [CSS2] the initial value was zero. For min-width/min-height, specifies an automatic minimum size. Unless otherwise defined by the relevant layout module, however, it resolves to a used value of 0. For backwards-compatibility, the resolved value of this keyword is zero for boxes of all [CSS2] display types CSS Box Sizing 3 §3.1.2, §3.2 A CSS 2 box behaves as before; only a newer layout, such as flex, sees auto.
