CSS 2 · 10.2 Content width: the 'width' property

The width property: percentages of a padding box

A percentage width is of the containing block, and an absolutely positioned box's containing block is its positioned ancestor's padding box. Each green box is relative, with a 120px content box and 20px of padding.

Absolutely positioned: the padding box

Note: For absolutely positioned elements whose containing block is based on a block container element, the percentage is calculated with respect to the width of the padding box of that element. CSS 2 §10.2
