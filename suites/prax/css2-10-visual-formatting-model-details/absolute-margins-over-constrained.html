CSS 2 · 10.6.4 Absolutely positioned, non-replaced elements

Absolute heights: auto margins and over-constraint

Each stage, 200 by 100, is the containing block of the orange box in it. Here none of 'top', 'height' and 'bottom' is 'auto'.

Auto margins

If none of the three are 'auto': If both 'margin-top' and 'margin-bottom' are 'auto', solve the equation under the extra constraint that the two margins get equal values. If one of 'margin-top' or 'margin-bottom' is 'auto', solve the equation for that value. CSS 2 §10.6.4

Over-constrained

If the values are over-constrained, ignore the value for 'bottom' and solve for that value. CSS 2 §10.6.4
