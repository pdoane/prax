CSS 2 · 10.3.5 Floating, non-replaced elements

Float widths: a block inside an inline

Each dashed box is a float whose width is shrink-to-fit. It holds a span, and in the span a blue block, which breaks the span into lines before and after it. Text is 13px on 20px lines.

Lines and blocks measured apart

Calculate the preferred width by formatting the content without breaking lines other than where explicit line breaks occur, and also calculate the preferred minimum width, e.g., by trying all possible line breaks.
