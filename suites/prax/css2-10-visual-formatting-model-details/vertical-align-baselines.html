CSS 2 · 10.8.1 Leading and half-leading

The vertical-align property: baselines of boxes

Each stage's text is 13px on 20px lines, with the line's baseline dashed in red. Each box is aligned baseline, the initial value.

Inline-blocks and inline tables

The baseline of an 'inline-block' is the baseline of its last line box in the normal flow, unless it has either no in-flow line boxes or if its 'overflow' property has a computed value other than 'visible', in which case the baseline is the bottom margin edge. The baseline of an 'inline-table' is the baseline of the first row of the table. CSS 2 §10.8.1

A box with no baseline

If the box does not have a baseline, align the bottom margin edge with the parent's baseline. CSS 2 §10.8.1
