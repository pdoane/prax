CSS 2 · 10.3.7 Absolutely positioned, non-replaced elements

Absolute widths: the static position

Each stage is the containing block; blue A is in flow, and orange B is absolutely positioned with left, width and right all auto.

For left and for right

The static position for 'left' is the distance from the left edge of the containing block to the left margin edge of a hypothetical box that would have been the first box of the element if its 'position' property had been 'static' and 'float' had been 'none'. The static position for 'right' is the same from the right edge. If all three of 'left', 'width', and 'right' are 'auto' and the static-position containing block is ltr, 'left' is the static position, else 'right' is. CSS 2 §10.3.7

Fixed boxes: the initial containing block

For the purposes of calculating the static position, the containing block of fixed positioned elements is the initial containing block instead of the viewport, and all scrollable boxes should be assumed to be scrolled to their origin. The frame is a viewport 200 by 100, scrolled down 40px. CSS 2 §10.3.7
