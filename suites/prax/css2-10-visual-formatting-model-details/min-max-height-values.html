CSS 2 · 10.7 Minimum and maximum heights: 'min-height' and 'max-height'

Min-height and max-height: values

min-height takes <length> | <percentage>, initial 0; max-height takes <length> | <percentage> | none, initial none. Neither is inherited.

<length>, <percentage> and none

Specifies a fixed minimum or maximum computed height. The percentage is calculated with respect to the height of the generated box's containing block. (Only on 'max-height') No limit on the height of the box. Each stage is 80px tall. CSS 2 §10.7

Since CSS 2 · CSS Box Sizing 3 §3.1.2, §3.2

The initial value of min-height is auto

The initial value of auto is new; in [CSS2] the initial value was zero. For backwards-compatibility, the resolved value of this keyword is zero for boxes of all [CSS2] display types CSS Box Sizing 3 §3.1.2, §3.2 As for min-width, a CSS 2 box behaves as with 0.
