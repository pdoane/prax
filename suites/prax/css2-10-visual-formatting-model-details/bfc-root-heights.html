CSS 2 · 10.6.7 'Auto' heights for block formatting context roots

Auto heights of formatting context roots

In certain cases (see, e.g., sections 10.6.4 and 10.6.6 above), the height of an element that establishes a block formatting context is computed as follows. The tinted, outlined box in each stage is such a root, display: flow-root.

Inline-level children: the line boxes

If it only has inline-level children, the height is the distance between the top of the topmost line box and the bottom of the bottommost line box. CSS 2 §10.6.7

Block-level children: their margin edges

If it has block-level children, the height is the distance between the top margin-edge of the topmost block-level child box and the bottom margin-edge of the bottommost block-level child box. Absolutely positioned children are ignored, and relatively positioned boxes are considered without their offset. CSS 2 §10.6.7
