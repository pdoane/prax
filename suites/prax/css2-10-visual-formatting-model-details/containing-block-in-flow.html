CSS 2 · 10.1 Definition of "containing block"

Containing blocks: the root and boxes in flow

The position and size of an element's box(es) are sometimes calculated relative to a certain rectangle, called the containing block of the element. Each frame below is a viewport 200 by 100.

The initial containing block

The containing block in which the root element lives is a rectangle called the initial containing block. For continuous media, it has the dimensions of the viewport and is anchored at the canvas origin The 'direction' property of the initial containing block is the same as for the root element. CSS 2 §10.1

Static and relative: the nearest block container

For other elements, if the element's position is 'relative' or 'static', the containing block is formed by the content edge of the nearest ancestor box that is a block container or which establishes a formatting context. CSS 2 §10.1
