CSS 2 · 10.3.3 Block-level, non-replaced elements in normal flow

Block widths: wider than the containing block

When a box is too wide for its containing block, auto margins cannot be negative to make room. Each stage is 200px wide; the boxes overflow it.

Auto margins treated as zero

If 'width' is not 'auto' and 'border-left-width' + 'padding-left' + 'width' + 'padding-right' + 'border-right-width' (plus any of 'margin-left' or 'margin-right' that are not 'auto') is larger than the width of the containing block, then any 'auto' values for 'margin-left' or 'margin-right' are, for the following rules, treated as zero. The equation is then over-constrained. CSS 2 §10.3.3
