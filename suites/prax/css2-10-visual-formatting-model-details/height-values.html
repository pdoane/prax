CSS 2 · 10.5 Content height: the 'height' property

The height property: values

height takes <length> | <percentage> | auto. Initial auto, not inherited. This property specifies the content height of boxes.

<length>, and auto

Specifies the height of the content area using a length value. Paragraphs of which the height of the contents exceeds 100 pixels will overflow according to the 'overflow' property. auto: The height depends on the values of other properties. CSS 2 §10.5

<percentage>

The percentage is calculated with respect to the height of the generated box's containing block. If the height of the containing block is not specified explicitly (i.e., it depends on content height), and this element is not absolutely positioned, the used height is calculated as if 'auto' was specified.
