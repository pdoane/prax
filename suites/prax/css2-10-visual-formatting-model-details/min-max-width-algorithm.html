CSS 2 · 10.4 Minimum and maximum widths: 'min-width' and 'max-width'

Min-width and max-width: the algorithm

The width rules run once, then again with 'max-width' or 'min-width' standing in for 'width', so the margins follow the new width. Each blue box has no padding.

max-width, then min-width

If the tentative used width is greater than 'max-width', the rules above are applied again, but this time using the computed value of 'max-width' as the computed value for 'width'. If the resulting width is smaller than 'min-width', the rules above are applied again, but this time using the value of 'min-width' as the computed value for 'width'. CSS 2 §10.4

The rules applied again

The width rules decide the margins as well, so with 'max-width' as 'width' the margins change too. These steps do not affect the real computed values of the above properties. CSS 2 §10.4
