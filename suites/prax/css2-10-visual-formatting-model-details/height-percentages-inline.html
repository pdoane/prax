CSS 2 · 10.5 Content height: the 'height' property

The height property: percentages on a line

An inline image's percentage height resolves against its containing block, which is the block container its line is in, through any inline boxes around it. Each purple box is an inline img of an SVG image 60 by 40, with height: 50%.

The block container's height

The percentage is calculated with respect to the height of the generated box's containing block. CSS 2 §10.5 For an element in flow, the containing block is formed by the content edge of the nearest block container ancestor box. CSS 2 §10.1

A containing block of auto height

If the height of the containing block is not specified explicitly (i.e., it depends on content height), and this element is not absolutely positioned, the used height is calculated as if 'auto' was specified. CSS 2 §10.5
