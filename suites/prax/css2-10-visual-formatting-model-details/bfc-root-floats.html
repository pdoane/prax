CSS 2 · 10.6.7 'Auto' heights for block formatting context roots

Auto heights of formatting context roots: floats

A block formatting context root grows to hold its floats. The tinted, outlined box in each stage is such a root, display: flow-root, holding a 20px block A.

Floats below the content

In addition, if the element has any floating descendants whose bottom margin edge is below the element's bottom content edge, then the height is increased to include those edges. CSS 2 §10.6.7

Only this context's floats

Only floats that participate in this block formatting context are taken into account, e.g., floats inside absolutely positioned descendants or other floats are not. CSS 2 §10.6.7
