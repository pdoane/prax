CSS 2 · 10.3.7 Absolutely positioned, non-replaced elements

Absolute widths: the static position on a line

Each stage, of 20px text on 40px lines, is the containing block. Between "abc" and "def" is an orange square, absolutely positioned with every inset auto, and a span unless the figure says.

Where the hypothetical box is on its line

The static position is that of a hypothetical box that would have been the first box of the element if its 'position' property had been 'static' and 'float' had been 'none'. In an rtl static-position containing block, set 'right' to the static position, to the right margin edge of that box. CSS 2 §10.3.7
