CSS 2 · 10.6.2 Inline replaced elements, block-level replaced elements in normal flow, 'inline-block' replaced elements in normal flow and floating replaced elements

Heights: replaced elements

The same rules give the height of a replaced element inline, as a block in flow, as an inline-block or floated. Each purple box is an img of an SVG image; most are 60 by 40, ratio 3:2.

Auto margins, and the intrinsic height

If 'margin-top', or 'margin-bottom' are 'auto', their used value is 0. If 'height' and 'width' both have computed values of 'auto' and the element also has an intrinsic height, then that intrinsic height is the used value of 'height'. CSS 2 §10.6.2

From the width and the intrinsic ratio

Otherwise, if 'height' has a computed value of 'auto', and the element has an intrinsic ratio then the used value of 'height' is: (used width) / (intrinsic ratio) CSS 2 §10.6.2
