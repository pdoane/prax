CSS 2 · 10.3.7 Absolutely positioned, non-replaced elements

Absolute widths: the equation and auto margins

Each stage is the 200px containing block of the absolutely positioned box in it.

The constraint

'left' + 'margin-left' + 'border-left-width' + 'padding-left' + 'width' + 'padding-right' + 'border-right-width' + 'margin-right' + 'right' = width of containing block CSS 2 §10.3.7

None of left, width and right auto: auto margins

If none of the three is 'auto': If both 'margin-left' and 'margin-right' are 'auto', solve the equation under the extra constraint that the two margins get equal values, unless this would make them negative, in which case when direction of the containing block is 'ltr' ('rtl'), set 'margin-left' ('margin-right') to zero and solve for 'margin-right' ('margin-left'). If one of 'margin-left' or 'margin-right' is 'auto', solve the equation for that value. Each box has left: 0; right: 0. CSS 2 §10.3.7
