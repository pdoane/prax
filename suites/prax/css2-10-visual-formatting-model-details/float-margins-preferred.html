CSS 2 · 10.3.5 Floating, non-replaced elements

Float widths: auto margins and the preferred width

A float's auto margins are 0, and its auto width shrinks to fit its content. Orange boxes are floats with text in them.

Auto margins are 0

If 'margin-left', or 'margin-right' are computed as 'auto', their used value is '0'. CSS 2 §10.3.5

Shrink-to-fit: the preferred width

If 'width' is computed as 'auto', the used value is the "shrink-to-fit" width. Roughly: calculate the preferred width by formatting the content without breaking lines other than where explicit line breaks occur CSS 2 §10.3.5
