CSS 2 · 10.1 Definition of "containing block"

Containing blocks: fixed and absolute

A positioned box's containing block is the viewport, a positioned ancestor's padding box, or the initial containing block. Each frame is a viewport 200 by 100, scrolled down 60px.

The viewport, and the initial containing block

If the element has 'position: fixed', the containing block is established by the viewport For 'position: absolute', If there is no such ancestor, the containing block is the initial containing block. CSS 2 §10.1

Absolute: the padding edge of the nearest positioned ancestor

If the element has 'position: absolute', the containing block is established by the nearest ancestor with a 'position' of 'absolute', 'relative' or 'fixed' the containing block is formed by the padding edge of the ancestor. CSS 2 §10.1
