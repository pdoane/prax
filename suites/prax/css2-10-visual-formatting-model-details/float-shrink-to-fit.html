CSS 2 · 10.3.5 Floating, non-replaced elements

Float widths: shrink-to-fit

The shrink-to-fit width is the preferred width, unless the content does not fit. Orange boxes are floats with text in them.

The available width

Thirdly, find the available width: in this case, this is the width of the containing block minus the used values of 'margin-left', 'border-left-width', 'padding-left', 'padding-right', 'border-right-width', 'margin-right', and the widths of any relevant scroll bars. Then the shrink-to-fit width is: min(max(preferred minimum width, available width), preferred width). CSS 2 §10.3.5
