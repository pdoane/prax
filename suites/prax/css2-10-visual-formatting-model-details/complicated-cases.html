CSS 2 · 10.6.6 Complicated cases

Heights: the complicated cases

Blocks whose 'overflow' is not 'visible', inline-blocks and floats take their auto heights from 10.6.7, which counts their floats. Blue boxes are 60px tall floats; the tinted, outlined box is the one measured.

Auto margins are 0, and the height follows 10.6.7

This section applies to: Block-level, non-replaced elements in normal flow when 'overflow' does not compute to 'visible', 'Inline-block', non-replaced elements. and Floating, non-replaced elements. If 'margin-top', or 'margin-bottom' are 'auto', their used value is 0. If 'height' is 'auto', the height depends on the element's descendants per 10.6.7. CSS 2 §10.6.6

An inline-block's margin box in the line

For 'inline-block' elements, the margin box is used when calculating the height of the line box. CSS 2 §10.6.6
