CSS 2 · 10.6.1 Inline, non-replaced elements

Heights: inline, non-replaced elements

An inline box's content area comes from its font; only its 'line-height' counts toward the line box. Each stage's text is 13px on 20px lines; orange is a span's background, translucent so overlaps show.

The content area is based on the font

The 'height' property does not apply. The height of the content area should be based on the font, but this specification does not specify how. CSS 2 §10.6.1

Padding, borders and margins do not count

The vertical padding, border and margin of an inline, non-replaced box start at the top and bottom of the content area, and has nothing to do with the 'line-height'. But only the 'line-height' is used when calculating the height of the line box. CSS 2 §10.6.1
