Heights: replaced elements without a size

Each purple box is an img of an SVG image with no intrinsic width, height or ratio, given width: 60px. CSS 2 makes it 150px tall.

Since CSS 2 · CSS Box Sizing 3 §5.1

150px, or the min-height

For a replaced element with no ratio and no size, for its max-content size: If the box has a <length> as its computed minimum size (min-width/min-height) in that dimension, use that size. Otherwise, use 300px for the width and/or 150px for the height as needed. CSS Box Sizing 3 §5.1 A min-height length replaces the 150px, and the device width no longer matters.
