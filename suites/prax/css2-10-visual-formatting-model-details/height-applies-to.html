CSS 2 · 10.5 Content height: the 'height' property

The height property: what it applies to

height applies to all elements but non-replaced inline elements, table columns, and column groups.

Not to non-replaced inline elements

This property does not apply to non-replaced inline elements. See the section on computing heights and margins for non-replaced inline elements for the rules used instead. CSS 2 §10.5

Not to columns

A column is as tall as its table. CSS 2 §10.5
