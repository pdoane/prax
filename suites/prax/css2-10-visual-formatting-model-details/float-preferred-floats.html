CSS 2 · 10.3.5 Floating, non-replaced elements

Float widths: floats inside

A float's preferred width when its content holds floats. Each dashed box is a float of auto width, shrinking to fit what is inside it.

What the browsers do where CSS 2 is silent

Roughly: calculate the preferred width by formatting the content without breaking lines other than where explicit line breaks occur, and also calculate the preferred minimum width, e.g., by trying all possible line breaks. CSS 2 does not define the exact algorithm. The browsers agree on each figure here. CSS 2 §10.3.5
