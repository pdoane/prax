CSS 2 · 10.2 Content width: the 'width' property

The width property: values

width takes <length> | <percentage> | auto. Initial auto, not inherited. This property specifies the content width of boxes. Teal is a box's content area, green its 10px of padding each side.

<length> and <percentage>

Specifies the width of the content area using a length unit. The percentage is calculated with respect to the width of the generated box's containing block. CSS 2 §10.2

auto, the initial value, and no inheritance

The width depends on the values of other properties. CSS 2 §10.2
