The height, then the static position

This situation is similar to the previous one, except that the element has an intrinsic height. The used value of 'height' is determined as for inline replaced elements. If both 'top' and 'bottom' have the value 'auto', replace 'top' with the element's static position. CSS 2 §10.6.5

Auto margins when bottom is auto

If 'bottom' is 'auto', replace any 'auto' on 'margin-top' or 'margin-bottom' with '0'. CSS 2 §10.6.5
