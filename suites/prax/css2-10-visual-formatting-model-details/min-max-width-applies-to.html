CSS 2 · 10.4 Minimum and maximum widths: 'min-width' and 'max-width'

Min-width and max-width: what they apply to

Both apply to all elements but non-replaced inline elements, table rows, and row groups.

Not to non-replaced inline elements

The width of an inline, non-replaced element is that of its content, and neither property changes it. CSS 2 §10.4
