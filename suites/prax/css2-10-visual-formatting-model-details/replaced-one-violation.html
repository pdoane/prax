CSS 2 · 10.4 Minimum and maximum widths: 'min-width' and 'max-width'

Min-width and max-width: replaced elements

Each purple box is an img of an SVG image 60 by 40, so w = 60, h = 40 and the ratio is 3:2, with width and height auto.

One constraint violated

However, for replaced elements with an intrinsic ratio and both 'width' and 'height' specified as 'auto', the algorithm is as follows: Select from the table the resolved height and width values for the appropriate constraint violation. Rows: w > max-width: max-width, max(max-width * h/w, min-height); w < min-width: min-width, min(min-width * h/w, max-height); and the same for heights. CSS 2 §10.4

The other limit still holds

In max(max-width * h/w, min-height), the scaled height may not go below 'min-height', even if the ratio is lost. CSS 2 §10.4
