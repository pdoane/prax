CSS 2 · 10.2 Content width: the 'width' property

The width property: what it applies to

width applies to all elements but non-replaced inline elements, table rows, and row groups.

Not to non-replaced inline elements

This property does not apply to non-replaced inline elements. The content width of a non-replaced inline element's boxes is that of the rendered content within them (before any relative offset of children). CSS 2 §10.2

Not to table rows

A row is as wide as its table. CSS 2 §10.2
