CSS 2 · 10.4 Minimum and maximum widths: 'min-width' and 'max-width'

Min-width and max-width: replaced, two violations

Each purple box is an img of an SVG image 60 by 40, so w = 60, h = 40 and the ratio is 3:2, with width and height auto.

Two constraints violated

When both (w > max-width) and (h > max-height), the tighter limit decides: where (max-width/w ≤ max-height/h), the width is max-width, otherwise the height is max-height. (w < min-width) and (h > max-height) gives min-width by max-height; (w > max-width) and (h < min-height) gives max-width by min-height. CSS 2 §10.4

A width that is not auto

Note: In cases where an explicit width or height is set and the other dimension is auto, applying a minimum or maximum constraint on the auto side can cause an over-constrained situation. CSS 2 §10.4
