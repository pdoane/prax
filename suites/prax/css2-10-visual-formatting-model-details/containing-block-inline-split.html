CSS 2 · 10.1 Definition of "containing block"

Containing blocks: an inline in several boxes

An absolute box's nearest positioned ancestor here is an orange inline: relative, with 6px of padding at each side, and generating more than one inline box. The absolute box has insets 0, and is tinted and outlined in blue.

Undefined in CSS 2

In CSS 2.2, if the inline element is split across multiple lines, the containing block is undefined. CSS 2 §10.1 Chrome, Safari and Firefox agree on what they draw: a rectangle from the start and top of the inline's first box to the end and bottom of its last, first and last as placed on the line. CSS Positioned Layout 3 says the same with content edges, and keeps it open as csswg-drafts#8284.
