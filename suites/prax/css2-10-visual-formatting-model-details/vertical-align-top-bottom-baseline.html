CSS 2 · 10.8.1 Leading and half-leading

The vertical-align property: top, bottom and the baseline

Boxes aligned top or bottom are placed against the line box, and the rest of the line is placed between them. The stage's text is 13px on 20px lines, with the line's baseline dashed in red.

Where the baseline goes

In case they are aligned 'top' or 'bottom', they must be aligned so as to minimize the line box height. If such boxes are tall enough, there are multiple solutions and CSS 2 does not define the position of the line box's baseline. CSS 2 §10.8
