CSS 2 · 10.3.9 'Inline-block', non-replaced elements in normal flow

Widths: inline-block, non-replaced elements

Each orange box is an inline-block with text in it, on a line of the 200px stage.

Shrink-to-fit

If 'width' is 'auto', the used value is the shrink-to-fit width as for floating elements. CSS 2 §10.3.9

Auto margins are 0

A computed value of 'auto' for 'margin-left' or 'margin-right' becomes a used value of '0'. CSS 2 §10.3.9
