CSS Box Alignment 3 · 6.2.1 Block-Level Boxes

align-self and blocks

The 'align-self' property does not apply to block-level boxes (including floats), because there is more than one item in the block axis. CSS Box Alignment 3 §6.2.1 Each stage is a block 60px tall.

No effect on blocks or floats

The block's contents move with align-content

The block itself aligns its contents as a whole: see align-content on blocks.
