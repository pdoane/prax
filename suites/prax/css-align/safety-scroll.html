CSS Box Alignment 3 · 4.4.1.1 Content Distribution for Scroll Containers

Default safety: scroll containers

In a scrollable axis of a scroll container, the default overflow alignment behavior for content distribution is unsafe. Non-normal values of the content-distribution properties instead alter the scrollable overflow area in order to allow access to the overflowing content. CSS Box Alignment 3 §4.4.1.1
