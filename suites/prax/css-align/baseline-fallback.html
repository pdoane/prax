CSS Box Alignment 3 · 4.2 Baseline Alignment, fallback

Baseline alignment without a group

If a box does not belong to a shared alignment context, then the fallback alignment is used. For example, align-content: baseline on a block box falls back to start alignment. CSS Box Alignment 3 §4.2

A block box

The fallback of first baseline for content-distribution is safe start, and of last baseline safe end. Each stage is a block 60px tall holding A.

Content distribution under baseline self-alignment

if its content-distribution property in the same axis is normal, its used content-distribution property in that axis is start or safe end for a baseline alignment preference of its baseline self-alignment of “first” or “last”, respectively. In a grid row 60px tall, A is one line; B is 50px tall with one line, both align-self: last baseline.
