Self-alignment and table cells

This property does not apply to table cells, because their position and size is fully constrained by table layout. CSS Box Alignment 3 §6.1.3 The same holds for align-self. CSS Box Alignment 3 §6.2.3

justify-self and align-self do nothing

Each stage is a table of one row, 40px tall, of two cells, each 100px wide.

A cell's content is aligned with align-content

To align what is in a cell, align-content on the cell does what vertical-align did: see align-content in table cells.
