CSS Box Alignment 3 · 6.1.1 Block-Level Boxes, details

justify-self on blocks: margins and floats

the rules for “over-constrained” computations in section 10.3.3 are ignored in favor of alignment as specified here and the used value of the margin properties are therefore not adjusted to correct for the over-constraint. CSS Box Alignment 3 §6.1.1

Over-constrained margins

A: width: 100px; margin-left: 20px; CSS 2 makes its right margin 80px.

Beside a float

for block-level elements that establish a block formatting context and are placed next to a float, the alignment container is reduced by the space taken up by the float. This property does not apply to floats.

Anonymous blocks

Anonymous block boxes always behave as normal. The stage, justify-items: center, holds "text", in an anonymous block, and block A.
