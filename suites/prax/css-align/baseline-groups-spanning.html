CSS Box Alignment 3 · 9.2 Baseline Alignment Grouping, spanning boxes

Spanning several alignment contexts

Boxes share an alignment context when they are, among others, grid items in the same row, along the grid's row (inline) axis, established by the grid container. CSS Box Alignment 3 §9.2 Items are highlighted.

Spanning several contexts

If a box spans multiple shared alignment contexts, then it participates in first/last baseline alignment within its start-most/end-most shared alignment context along that axis. Two rows of 35px; A spans both.
