CSS Box Alignment 3 · 4.1 Positional Alignment, self-start to flex-end

self-start, self-end, flex-start, flex-end

self-start Aligns the alignment subject to be flush with the edge of the alignment container corresponding to the alignment subject’s start side in the appropriate axis. CSS Box Alignment 3 §4.1

The subject's start, not the container's

In an ltr, horizontal-tb grid, A and B are direction: rtl; C and D are vertical-rl and rtl, so their start is at the bottom.

flex-start and flex-end outside flex layout

When used outside of a flex formatting context, this value behaves as start. left and right: If the property's axis is not parallel with either left↔right axis, this value behaves as start. For flex's own rules see CSS Flexible Box Layout 2 §8.
