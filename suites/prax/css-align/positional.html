CSS Box Alignment 3 · 4.1 Positional Alignment

Positional alignment: start, end, center, left, right

The positional alignment keywords specify a position for an alignment subject with respect to its alignment container. CSS Box Alignment 3 §4.1 Grids of three 20px rows; A justify-self: start, B center, C end.

start, center, end: by the writing mode

start Aligns the alignment subject to be flush with the alignment container’s start edge in the appropriate axis. center Centers the alignment subject within its alignment container.

left and right: physical, for justify-* only

left aligns flush with the alignment container’s line-left or physical left edge, whichever is in the appropriate axis. It is not a value of align-*.
