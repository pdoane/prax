CSS Box Alignment 3 · 4.3 Distributed Alignment

Distributed alignment

The distributed alignment values are used by 'justify-content' and 'align-content' to disperse a container’s extra space among its alignment subjects. CSS Box Alignment 3 §4.3 Each stage is a grid of three 40px columns, so 80px to share.

space-between, space-around, space-evenly

space-between: the first alignment subject is placed flush with the start edge, the last alignment subject is placed flush with the end edge. space-around: the spacing before the first and after the last alignment subject is half the size of the other spacing. space-evenly: all spacing is the same.

stretch: equally, not in proportion

any auto-sized alignment subjects have their size increased equally (not proportionally), while still respecting the constraints imposed by 'max-height'/'max-width'. Two auto columns hold A, 20px wide at least, and B, 60px.
