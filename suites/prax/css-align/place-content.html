CSS Box Alignment 3 · 5.2 Content-Distribution Shorthand: the place-content property

place-content

The first value is assigned to 'align-content'. The second value is assigned to 'justify-content'; if omitted, it is copied from the first value, unless that value is a <baseline-position> in which case it is defaulted to start.
