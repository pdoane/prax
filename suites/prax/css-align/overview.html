CSS Box Alignment 3 · 2 Overview of Alignment Properties

The six alignment properties

The box alignment properties in CSS are a set of 6 properties that control alignment of boxes within other boxes. They differ in which dimension they apply to, and whether they control the position of the box within its parent, or the box's content within itself. CSS Box Alignment 3 §2

Content within the element: justify-content, align-content

The element within its parent: justify-self, align-self

element within parent: one column and one row, filling the grid.

Items inside the box: justify-items, align-items

The '*-items' properties don't affect the element itself. They say what *-self: auto means in its children.
