CSS Box Alignment 3 · 5.1.1 Block Containers (Including Table Cells), table cells

align-content in table cells

For table cells, the behavior of align-content: normal depends on the computed value of 'vertical-align': top makes it behave as start and bottom makes it behave as end; otherwise middle makes it behave as center, and all other values make it behave as baseline.
