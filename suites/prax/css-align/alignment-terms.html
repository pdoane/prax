CSS Box Alignment 3 · 3 Alignment Terminology

Subject, container and fallback

Since this module defines alignment properties for all layout modes in CSS, some abstract terminology is introduced. CSS Box Alignment 3 §3 Each stage is a grid 200 by 50, one column.

The alignment subject: a margin box

For 'justify-self' and 'align-self', the alignment subject is the margin box of the box the property is set on.

The alignment container, in its own writing mode

The alignment container assumes the writing mode of the box establishing the containing block.

Fallback alignment

space-between can only operate when there is more than one alignment subject; In these cases a fallback alignment takes effect.
