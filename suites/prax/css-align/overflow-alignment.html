CSS Box Alignment 3 · 4.4 Overflow Alignment

safe and unsafe

“Unsafe” alignment honors the specified alignment mode in overflow situations, even if it causes data loss; “safe” alignment changes the alignment mode in overflow situations in an attempt to avoid data loss. CSS Box Alignment 3 §4.4

A grid item wider than its area

A 100px column, centered from 50 to 150px, holds A, 160px wide.

Items wider than a column flexbox

As the specification's example: a tinted column flex container 100px wide, its middle item 160px wide. The items' cross-axis alignment is align-self.
