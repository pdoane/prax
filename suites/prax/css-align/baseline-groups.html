CSS Box Alignment 3 · 9.2 Baseline Alignment Grouping

Baseline-sharing groups

A baseline-sharing group is composed of boxes that participate in baseline alignment together. They must Share an alignment context along an axis perpendicular to the axis they're being baseline-aligned in and Have compatible baseline alignment preferences. CSS Box Alignment 3 §9.2 Items are highlighted.

Contexts, and compatible preferences

Flex items share one in the same flex line. Preferences are compatible with the same block flow direction and same baseline alignment preference.

Opposite block flow, opposite preference

Also compatible: opposite block flow direction and opposite baseline alignment preference. In a grid column, aligned by justify-self: A vertical-rl, B vertical-lr, each two lines.
