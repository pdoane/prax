CSS Box Alignment 3 · 7.2 Block-Axis (or Cross-Axis) Default Alignment

align-items

This property specifies the default 'align-self' for all of the child boxes (including anonymous boxes) participating in this box's formatting context. Values have no special handling and are merely referenced by 'align-self'. CSS Box Alignment 3 §7.2 Each stage is 60px tall; A and B are align-self: auto, C start.

Grid and flex containers

No effect on blocks

align-self does not apply to block-level boxes, so neither does the default.
