CSS Box Alignment 3 · 4.3 Distributed Alignment, fallbacks

Distributed alignment's fallbacks

When space cannot be distributed in this way, these values behave as their fallback alignment. CSS Box Alignment 3 §4.3 Each stage is a grid of one column, 40px wide unless a caption says otherwise.

One subject

For space-between The default fallback alignment for this value is safe flex-start. For space-around and space-evenly it is safe center.

No auto-sized subject, and no room

For stretch The default fallback alignment for this value is flex-start. A safe fallback, when the subject overflows, is instead aligned as if the alignment mode were flex-start.
