CSS Box Alignment 3 · 4.2 Baseline Alignment

baseline, first baseline, last baseline

Baseline alignment is a form of positional alignment that aligns multiple alignment subjects within a shared alignment context (such as cells within a row) by matching up their alignment baselines. CSS Box Alignment 3 §4.2 Each stage is a grid row 80px tall of three items, highlighted, in PR Arimo at 13, 22 and 36px.

baseline is first baseline

baseline Computes to first baseline: the two align alike.

last baseline

aligns the alignment baseline of the box's last baseline set with the corresponding baseline of its baseline-sharing group. Its fallback, safe self-end, places the group in the row. Here the first item has two lines.
