CSS Box Alignment 3 · 9.1 Determining the Baselines of a Box, synthesis

Generated and synthesized baselines

To generate baselines for a box from a single baseline, use the baseline table from the font settings and first available font of that box. If a box that participates in baseline alignment has no baseline set, then its alignment baseline is synthesized. CSS Box Alignment 3 §9.1

The font's baseline, or its origin

A grid row, align-self: baseline: "X" of PR Baseline Diagnostic, its BASE alphabetic baseline 0.05em above the glyph origin, and "Ag" of PR Arimo, which has no BASE table.

Synthesized from edges

synthesize the alphabetic baseline from the line-under line. inline-level boxes synthesize from their margin edges, grid and flex items synthesize from their border edges. The empty box has a 4px border and a 10px bottom margin.
