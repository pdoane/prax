CSS Box Alignment 3 · 9.1 Determining the Baselines of a Box, tables

The baselines of tables

The first/last baseline set of a table box is the first/last baseline set of its first/last row (after any reordering of table row group box). CSS Box Alignment 3 §9.1 Each stage is a line of text, its baseline dashed.

The first row, after reordering

Rows without baseline-aligned cells

A row's first baseline set, if no cell is baseline-aligned: if the row is not empty, synthesize from the lowest and highest content edges of all the cells in the row.

A table in an inline-block

When finding the first/last baseline set of an inline-block, any baselines contributed by table boxes must be skipped.
