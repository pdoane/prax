CSS Box Alignment 3 · 5.1 The justify-content and align-content Properties

justify-content and align-content

Each property Aligns the contents of the box as a whole (as the alignment subject) within the box itself (as the alignment container). CSS Box Alignment 3 §5.1 The grids are 200 by 60, with two 50px columns and two 20px rows.

The contents as a whole

The four items move together, their places in the grid unchanged. For all layout modes, the alignment subject and alignment container both assume the writing mode of the box the '*-content' property is set on.

justify-content and block containers

justify-content applies to multicol containers, flex containers, and grid containers; it Does not apply to and has no effect on block containers.
