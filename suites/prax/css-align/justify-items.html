CSS Box Alignment 3 · 7.1 Inline-Axis (or Main-Axis) Default Alignment

justify-items

This property specifies the default 'justify-self' for all of the child boxes (including anonymous boxes) participating in this box's formatting context. CSS Box Alignment 3 §7.1 Its initial value is legacy, which computes to normal where no ancestor sets a legacy value.

Grid items

Each stage is a grid of one column; A and B are justify-self: auto, C start.

Block containers

It applies to all elements; the children of a block container take it as their justify-self, see justify-self on blocks.
