CSS Box Alignment 3 · 9.3 Aligning Boxes by Baseline

Aligning boxes by baseline

Generate the baseline-sharing group’s baseline table from the first available font of the group’s alignment context. Align each alignment subject by its specified alignment baseline to the group’s baseline table. CSS Box Alignment 3 §9.3

The dominant baseline of the context

Unless otherwise specified (e.g. via the 'alignment-baseline' property), the alignment baseline is the dominant baseline of the alignment context. Each stage is a vertical-rl grid of one row, 60px wide, its items align-self: baseline down it, of 13, 26 and 13px text.
