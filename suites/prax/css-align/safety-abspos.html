CSS Box Alignment 3 · 4.4.1.2 Self-Alignment for Absolutely Positioned Boxes

Default safety: absolutely positioned boxes

For an absolutely positioned box whose self-alignment is not normal, the default and safe overflow alignment behavior keeps it, as far as it can, inside the bounding rectangle of the alignment subject's inset-modified containing block and its original containing block. CSS Box Alignment 3 §4.4.1.2 Each stage is the containing block; A has left: 10px; right: 90px, so the inset-modified containing block, dashed, runs from 10 to 110px.

Wider than the inset-modified containing block

if the alignment subject fits within the overflow limit rect, align the alignment subject such that it fully covers the inset-modified containing block and is otherwise aligned as specified to the extent possible without overflowing the overflow limit rect. A is 140px wide, justify-self: center.

Wider than both

Otherwise, start-align the alignment subject within the overflow limit rect. A is 240px wide.
