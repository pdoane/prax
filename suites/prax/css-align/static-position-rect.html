CSS Box Alignment 3 · A Static Position Terminology

The static-position rectangle

When both insets in an axis are auto, the box aligns in its static-position rectangle, whose edges represent the static position of the box from each side of its containing block. CSS Box Alignment 3 §A Each stage is the containing block; A has all its insets auto.

Block and inline layout

For a block-level box, a zero-thickness rectangle spanning between the inline-axis sides of the box’s static-position containing block; for an inline-level box, spanning between the line-over/line-under sides of the line box.

Flex and grid layout

In a flex container it corresponds to the content edges of the flex container; in a grid container that is also the containing block, the grid area specified by the grid-placement properties establishes its static-position rectangle instead.
