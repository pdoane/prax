CSS Box Alignment 3 · 6.1.1 Block-Level Boxes

justify-self on blocks

For a block-level box the alignment container is The box's containing block, the subject The block's margin box, and normal The box lays out according to the default rules for block layout. CSS Box Alignment 3 §6.1.1 Each stage is a block holding blocks.

Fit-content, then aligned

The automatic size of a block-level box whose 'justify-self' is not normal is equivalent to fit-content (rather than e.g. stretch, as is typical for a non-replaced block-level box).

A table, aligned and with margins

The effect of these rules is that an auto-sized block-level table, for example, can be aligned while still having side margins. The table has margin: 0 20px.
