SVG 2 · 8.9 Units

Units, and percentages of the viewport

SVG follows the description and definition of common values and units from the CSS Values and Units Module [css-values] for attributes, presentation attributes and CSS properties. SVG 2 §8.9 Each stage is an SVG 160 by 60.

Units, in user space

A unit's length is in the user coordinate system, so a scale applies to it.

Percentages of the viewBox

For any x-coordinate value or width value expressed as a percentage of the SVG viewport, the value to use must be the percentage, in user units, of the width parameter of the ‘viewBox’ applied to that viewport. Other lengths take the normalized diagonal of the ‘viewBox’. Each has viewBox="0 0 320 120", units of half a pixel.
