SVG 2 · 8.10 Bounding boxes

Bounding boxes

The bounding box (or "bbox") of an element is the tightest fitting rectangle aligned with the axes of that element's user coordinate system that entirely encloses it and its descendants. SVG 2 §8.10 Each stage is an SVG 160 by 60. Under each shape, a copy with a filter whose region is its object bounding box, x="0" y="0" width="1" height="1", floods that box with orange at half opacity.

The geometry, without control points or stroke

control points for a curve which are not defined as lying along the line of the resulting curve […] must not contribute to the dimensions of the bounding box. The object bounding box is the bounding box that contains only an element's geometric shape.

A group: the union of what it renders

an element that is not in the rendering tree does not contribute to the bounding box of any ancestor element. Each group holds a blue square 20 by 20 at 20, 10 and a green one at 120, 30.
