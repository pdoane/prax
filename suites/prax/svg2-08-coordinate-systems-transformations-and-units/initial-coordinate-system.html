SVG 2 · 8.4 The initial coordinate system

The initial coordinate system

The origin of both coordinate systems must be at the origin of the SVG viewport, and one unit in the initial coordinate system must equal one CSS 2.1 px in the SVG viewport. SVG 2 §8.4 Each stage is an SVG 160 by 60.

Top left, x right, y down, upright

the initial viewport coordinate system (and therefore the initial user coordinate system) must have its origin at the top/left of the viewport, with the positive x-axis pointing towards the right, the positive y-axis pointing down, and text rendered with an "upright" orientation.
