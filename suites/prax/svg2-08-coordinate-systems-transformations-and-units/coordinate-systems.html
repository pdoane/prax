SVG 2 · 8.1 Introduction

SVG viewports, nested

Every SVG viewport defines a drawing region characterized by a size (width, height), and an origin, measured in abstract user units. SVG 2 §8.1 Each stage is an SVG 160 by 60; a dashed outline marks each nested svg, 60 by 40.

A nested viewport's origin, and its percentages

By default, a nested SVG viewport's viewport coordinate system is equivalent to the local coordinate system of the parent element, translated by the origin of the SVG viewport's element. Hence, nesting SVG viewports provides an opportunity to redefine the meaning of percentage units.

A transform on the viewport's element

However, a transform property on an SVG viewport's element will modify the viewport coordinate system relative to the parent element's user coordinate system. The nested svg is at 20, 10, holding a purple rect as large as it.
