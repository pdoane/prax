SVG 2 · 8.2 Computing the equivalent transform of an SVG viewport

The viewport's equivalent transform

This process converts the min-x, min-y, width and height values of a viewBox attribute, the position and size of the element on which the viewBox attribute is defined, and the value of the preserveAspectRatio attribute on that element into a translation and a scale that is applied to content contained by the element. SVG 2 §8.2 Each stage is an SVG 160 by 60. The content is a blue rect as large as the viewBox, with an orange dot of radius 5 at its middle.

Scale, then translate

If align is not ‘none’ and meetOrSlice is ‘meet’, set the larger of scale-x and scale-y to the smaller. Initialize translate-x to e-x - (vb-x * scale-x). If align contains ‘xMid’, add (e-width - vb-width * scale-x) / 2 to translate-x. The transform applied to content contained by the element is given by translate(translate-x, translate-y) scale(scale-x, scale-y).

none, and slice

Otherwise, if align is not ‘none’ and meetOrSlice is ‘slice’, set the smaller of scale-x and scale-y to the larger. With none, each scale stays its own.
