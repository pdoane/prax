SVG 2 · 8.6 The ‘viewBox’ attribute

viewBox: a rectangle mapped to the viewport

The value of the ‘viewBox’ attribute is a list of four numbers […] that specify a rectangle in user space that should be mapped to the bounds of the SVG viewport established by the given element. SVG 2 §8.6 Each stage is an SVG 160 by 60; the content is a blue rect 40 by 20 at 0, 0 with an orange dot at its middle.

Mapped, and a size of zero

A value of zero for <width> or <height> disables rendering of the element, consistent with the treatment of other zero-sized viewports. Each has preserveAspectRatio="none".

Not the element's own attributes; after its transform

the automatic transformation that is created due to a ‘viewBox’ does not affect the ‘x’, ‘y’, ‘width’ and ‘height’ attributes on the element. The first coordinate system is post-multiplied by the second coordinate system. Nested svg elements, outlined.
