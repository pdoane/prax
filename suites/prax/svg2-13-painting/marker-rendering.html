SVG 2 · 13.7.4 Rendering markers

Rendering markers: clipping and display

For each marker that is drawn, a temporary new user coordinate system is established so that the marker will be positioned and sized correctly. SVG 2 §13.7.4 Each stage is an SVG 160 by 60 with a line from 20, 30 to 140, 30.

Clipped to the marker's viewport

If the overflow property on the ‘marker’ element indicates that the marker needs to be clipped to its SVG viewport, then an implicit clipping path is established at the bounds of the SVG viewport. The user agent style sheet makes it hidden. The marker is 20 by 20, at the middle vertex, 80, 30, and holds a circle of radius 12.

Not rendered directly

Markers are not rendered directly and must be referenced by one of the marker properties to be rendered. ‘marker’ elements are available for referencing even when the display property on the ‘marker’ element or any of its ancestors is set to none.
