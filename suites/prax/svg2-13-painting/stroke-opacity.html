SVG 2 · 13.5.2 Stroke paint opacity: the ‘stroke-opacity’ property

stroke-opacity

The 'stroke-opacity' property specifies the opacity of the painting operation used to stroke the current object. SVG 2 §13.5.2 Each stage is an SVG 160 by 60.

One painting operation

The stroke is one shape, painted once §13.5.7, so where it covers itself it is no darker. The strokes are orange, 10 wide.

Separate elements, and clamping

Any values outside the range 0 (fully transparent) to 1 (fully opaque) must be clamped to this range.
