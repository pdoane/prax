SVG 2 · 13.2 Specifying paint

context-fill and context-stroke in markers

The context-fill and context-stroke values are a reference to the paint layers generated for the 'fill' or 'stroke' property, respectively, of the context element of the element being painted. SVG 2 §13.2 Each stage is an SVG 160 by 60.

A marker's context element

If the element is within a ‘marker’, and is being rendered as part of that marker due to being referenced via a marker property, then the context element is the element referencing that ‘marker’. The arrow is a marker 16 across whose triangle has fill="context-stroke"; the square, 12 across, has fill="context-fill" and stroke="context-stroke".

No context element

Otherwise, there is no context element. If there is no context element and these keywords are used, then no paint is applied.
