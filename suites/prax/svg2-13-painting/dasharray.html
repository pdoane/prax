SVG 2 · 13.5.6 Dashing strokes: the ‘stroke-dasharray’ and ‘stroke-dashoffset’ properties

stroke-dasharray

The 'stroke-dasharray' property controls the pattern of dashes and gaps used to form the shape of a path's stroke. SVG 2 §13.5.6 Each stage is an SVG 160 by 60; the lines are stroked dark blue, 10 wide, with butt caps.

Dashes and gaps, repeated

The first value and every second value in the list after it specifies the length of a dash, and every other value specifies the length of a gap between the dashes. If the list has an odd number of values, then it is repeated to yield an even number of values. The dashing pattern is reset and begins again at the start of each subpath.

All zeros, and percentages

If all of the values in the list are zero, then the stroke is rendered as a solid line without any dashing. Percentages refer to the normalized diagonal of the current SVG viewport.
