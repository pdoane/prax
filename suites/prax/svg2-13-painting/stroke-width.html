SVG 2 · 13.5.3 Stroke width: the ‘stroke-width’ property

stroke-width

This property specifies the width of the stroke on the current object. A zero value causes no stroke to be painted. SVG 2 §13.5.3 Each stage is an SVG 160 by 60; the lines run from x 20 to 140 along y 30, stroked dark blue.

Numbers, in user units

A <number> value represents a value in user units.

Lengths and percentages

Percentages refer to the normalized diagonal of the current SVG viewport, √((w² + h²) / 2) §8.9.
