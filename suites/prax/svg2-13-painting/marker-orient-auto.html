SVG 2 · 13.7.4 Rendering markers

Rendering markers: orient="auto"

When orienting a marker automatically, due to specifying ‘orient’ as 'auto', the following rules are used. SVG 2 §13.7.4 Each stage is an SVG 160 by 60. The markers are arrows 16 across. The ends of open paths, which point in the path's direction, are on 9.4's page.

Half way between, at other vertices

Otherwise, the marker is oriented in a direction half way between the direction at the end of the preceding segment and the direction at the start of the following segment. The arrows are marker-mid.

The start and end of a closed subpath

If the vertex is the start or end of an open subpath, then the marker is oriented in the path direction. The start and end of a closed subpath are not, so they take the half-way direction too, between the closing line and the first, as svgwg#300 confirmed. The start arrow is green, the end orange.
