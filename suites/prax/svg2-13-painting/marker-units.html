SVG 2 · 13.7.1 The ‘marker’ element

marker: markerUnits, markerWidth and markerHeight

The ‘markerUnits’ attribute defines the coordinate system for attributes ‘markerWidth’, ‘markerHeight’ and the contents of the ‘marker’. SVG 2 §13.7.1 Each stage is an SVG 160 by 60 with a dark blue line from 30, 30 to 130, 30 and a marker at each end.

strokeWidth and userSpaceOnUse

strokeWidth, the initial value: a coordinate system which has a single unit equal to the size in user units of the painted stroke width of the element referencing the marker. userSpaceOnUse: values in the current user coordinate system in place for the element referencing the marker. The first two markers have no markerUnits, markerWidth or markerHeight, so they are 3 by 3, and a circle of radius 1.5 fills them.

A size of zero

A value of zero for either attribute results in nothing being rendered for the marker.
