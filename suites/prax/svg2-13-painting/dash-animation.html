SVG 2 · 13.5.6 Dashing strokes: the ‘stroke-dasharray’ and ‘stroke-dashoffset’ properties

Dashes in motion

'stroke-dasharray' values are not additive. For interpolation, 'stroke-dasharray' values are combined as follows. SVG 2 §13.5.6 Each line runs from x 20 to 140, stroked dark blue 10 wide, to and fro between two values over 4 seconds; a still shows it a quarter of the way.

Two lists, repeated to the same length

repeat both dash patterns of start and end value list until the length of elements in both value lists match. Each item is then combined by computed value.

The offset

stroke-dashoffset is animated by computed value.
