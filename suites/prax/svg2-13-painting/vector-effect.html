SVG 2 · 13.6 Vector effects

non-scaling-stroke

With the non-scaling-stroke vector effect, stroke outline shall be calculated in the "host" coordinate space instead of user coordinate system. More precisely: the viewport coordinate system of the furthest ancestral SVG viewport. SVG 2 §13.6 Each stage is an SVG 160 by 60, the host; the strokes are dark blue.

Not scaled by the transform

The resulting visual effect of this modification is that stroke width is not dependent on the transformations of the element (including non-uniform scaling and shear transformations) and zoom level.

The furthest viewport, markers and dashes

first, the shape's path is transformed into the host coordinate space. Stroke outline is calculated in the host coordinate space. The resulting outline is transformed back to the user coordinate system.
