SVG 2 · 13.7.2 Vertex markers: the ‘marker-start’, ‘marker-mid’ and ‘marker-end’ properties

Vertex markers: which vertices

For all shapes, the path that must be used when calculating marker positions is the equivalent path. SVG 2 §13.7.2 Each stage is an SVG 160 by 60. The markers are dots 14 across at 60% opacity: green for the start, blue for the middle, orange for the end.

The first and last vertices of shapes

For all shape elements, except ‘polyline’ and ‘path’, the last vertex is the same as the first vertex. In this case, if the value of 'marker-start' and 'marker-end' are both not none, then two markers will be rendered on that final vertex. svgwg#753 made them at risk.

A path's closed subpaths

'marker-start' must only be rendered on the first vertex of the path data. 'marker-end' must only be rendered on the final vertex of the path data. 'marker-mid' must be rendered on every vertex other than the first vertex of the path data and the last vertex of the path data. If the reference is not valid, then no marker will be drawn at the given vertex or vertices.
