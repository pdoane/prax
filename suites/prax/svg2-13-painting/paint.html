SVG 2 · 13.2 Specifying paint

Paint: none, a color or a paint server

A paint specification describes a way of putting color values on to the canvas and is composed of one or more paint layers. SVG 2 §13.2 Each stage is an SVG 160 by 60 holding a rectangle 120 by 40 at 20, 10, outlined dark blue, whose fill is the paint shown.

The values

none: No paint is applied in this layer. A <color>: A solid color paint. A <url>: A URL reference to a paint server element, which is an element that defines a paint server […], optionally followed by a fall-back value that is used if the paint server reference cannot be resolved.

A reference that fails

the <color> value or the value none is a fallback value to use if the paint server reference in the layer is invalid (due to pointing to an element that does not exist or which is not a valid paint server). If a paint server reference in a <paint> is invalid, and no fall-back value is given, no paint is rendered for that layer.
