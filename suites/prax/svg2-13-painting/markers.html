SVG 2 · 13.7 Markers

Markers: start, middle and end

A marker is a graphical object that is painted at particular positions along any shape element. SVG 2 §13.7 Each stage is an SVG 160 by 60. The markers are squares 20 across: green for marker-start, blue for marker-mid, orange for marker-end.

Vertex markers, painted from start to end

The 'marker-start' and 'marker-end' properties can be used to place markers at the first and last vertex of a shape, and the 'marker-mid' property can be used to place markers at all other vertices (aside from the first and last). Markers on a given element are painted in the following order, from bottom to top: any marker specified by 'marker-start'; the 'marker-mid' markers, in order of their position along the path; any marker specified by 'marker-end'.

Animated markers

Markers can be animated, and as with ‘use’ elements, the animated effects will show on all current uses of the markers within the document.
