SVG 2 · 13.10.1 The ‘shape-rendering’ property

shape-rendering

The 'shape-rendering' property provides a hint to the implementation about what tradeoffs to make as it renders vector graphics elements such as ‘path’ elements and basic shapes such as circles and rectangles. SVG 2 §13.10.1 Each stage is an SVG 160 by 60 with a blue circle of radius 20 at 50, 30 and a blue rectangle from 90.5, 10.5 to 130.5, 50.5, half a pixel off the guides. What each value draws is the user agent's choice.

Precision and crisp edges

crispEdges: To achieve crisp edges, the user agent might turn off anti-aliasing for all lines and curves or possibly just for straight lines which are close to vertical or horizontal. Also, the user agent might adjust line positions and line widths to align edges with device pixels.
