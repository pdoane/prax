SVG 2 · 13.9 Color space for interpolation: the ‘color-interpolation’ property

color-interpolation

The 'color-interpolation' property chooses between color operations occurring in the sRGB color space or in a (light energy linear) linearized RGB color space. SVG 2 §13.9 Each stage is an SVG 160 by 60. Halfway from black to white is #808080 in sRGB, and in linearized RGB 0.5, which is #bcbcbc in sRGB.

Between gradient stops

It controls interpolating between gradient stops. For gradients which make use of the ‘href’ attribute to reference another gradient, the gradient uses the 'color-interpolation' property value from the gradient element which is directly referenced by the 'fill' or 'stroke' property. The gradients run from black at x 20 to white at 140.

Compositing

It controls compositing and blending of graphics elements into the current background. When a child element is blended into a background, the value of the 'color-interpolation' property on the child determines the type of blending.
