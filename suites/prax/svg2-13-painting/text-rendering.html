SVG 2 · 13.10.2 The ‘text-rendering’ property

text-rendering

The 'text-rendering' property provides a hint to the implementation about what tradeoffs to make as it renders text. SVG 2 §13.10.2 Each stage is an SVG 160 by 60. What each value draws is the user agent's choice.

Geometric precision

geometricPrecision: This option will usually cause the user agent to suspend the use of hinting so that glyph outlines are drawn with comparable geometric precision to the rendering of path data. The text is 5.5px, in a scale(6), so 33px on the stage.

Legibility and speed

optimizeLegibility: The user agent will often choose whether to apply anti-aliasing techniques, built-in font hinting or both to produce the most legible text. optimizeSpeed: This option will sometimes cause the user agent to turn off text anti-aliasing.
