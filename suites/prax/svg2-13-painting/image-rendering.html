SVG 2 · 13.10.3 The ‘image-rendering’ property

image-rendering

The 'image-rendering' property provides a hint to the implementation about how to make speed vs. quality tradeoffs as it performs image processing. SVG 2 §13.10.3 Each stage is an SVG 160 by 60 with an image of 4 by 4 pixels, blue and orange in a checkerboard, drawn 40 by 40 at 60, 10: each pixel covers 10 by 10.

Resampling

auto: The user agent shall employ a resampling algorithm at least as good as nearest neighbor resampling, but bilinear resampling is strongly preferred. optimizeQuality: The user agent shall employ a resampling algorithm at least as good as bilinear resampling. optimizeSpeed: The user agent should use a resampling algorithm which achieves the goal of fast rendering, at least as good as nearest neighbor.
