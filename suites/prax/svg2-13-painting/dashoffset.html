SVG 2 · 13.5.6 Dashing strokes: the ‘stroke-dasharray’ and ‘stroke-dashoffset’ properties

stroke-dashoffset

The 'stroke-dashoffset' property specifies the distance into the repeated dash pattern to start the stroke dashing at the beginning of the path. SVG 2 §13.5.6 Each stage is an SVG 160 by 60; the lines run from x 20 to 140, stroked dark blue 10 wide, dashed 20 10, whose pattern is 30 long.

Into the pattern

Negative offsets

If the value is negative, then the effect is the same as dash offset d: d = s - (abs(stroke-dashoffset) mod s), where s is the sum of the dash array values.
