CSS Images 3 · 5.1 Orienting an Image on the Page: the image-orientation property

image-orientation: turning images upright

The image-orientation property provides a way to apply an “out-of-band” rotation to image source data to correctly orient an image. CSS Images 3 §5.1 This property is optional for implementations. Each image is encoded 100 by 50: green and yellow over blue and red. Its EXIF metadata says how to turn it.

from-image, the initial value, and none

from-image computes to the angle that the metadata specifies is necessary to correctly orient the image. none: the image is oriented as encoded.

Layout uses the turned image

All CSS layout and rendering processes use the image after rotation, exactly as if the image were originally encoded in its rotated form. Other transformations, such as those in [CSS-TRANSFORMS-1], are applied to the image after image-orientation is applied.
