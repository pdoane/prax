Object size negotiation

Using the natural dimensions, the specified size, and the default object size for the context the object is used in, CSS then computes a concrete object size. CSS asks the object to render itself at the concrete object size. CSS Images 3 §4.2 Each dashed box is 140 by 40, with a background image drawn once at background-size: 80px 40px, at its left.

The object renders itself at that size

The object may adjust itself to match the concrete object size in some way, or even render itself larger or smaller than the concrete object size to satisfy sizing constraints of its own. Each image is 40 by 20 at its natural size.

Then clipped

Unless otherwise specified by CSS, the object is then clipped to the concrete object size.
