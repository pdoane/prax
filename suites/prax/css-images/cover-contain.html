CSS Images 3 · 4.3.2 Cover and Contain Constraint Sizing

Cover and contain constraints

Two other common specified sizes are the contain constraint and the cover constraint, both of which are resolved against a specified constraint rectangle using the object’s preferred aspect ratio CSS Images 3 §4.3.2 Each dashed box is 140 by 60, the constraint rectangle, with a background drawn once at its top left by background-size.

Largest inside, smallest outside

A contain constraint is resolved by setting the concrete object size to the largest rectangle that has the object’s natural aspect ratio and additionally has neither width nor height larger than the constraint rectangle's width and height; a cover constraint, the smallest rectangle with neither width nor height smaller. The flag is a PNG of 2:1.

No ratio: the rectangle

In both cases, if the object doesn't have a natural aspect ratio, the concrete object size is the specified constraint rectangle. The image is a gradient from blue to orange, which has no natural dimensions.
