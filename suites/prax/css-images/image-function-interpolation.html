CSS Images 4 · 7.2 Interpolating image()

Interpolating image() colors

If two image() functions are to be interpolated, and they both have a single <color> argument, their interpolated value is an image() function with an interpolated <color>, using the standard rules for <color> interpolation. CSS Images 4 §7.2
