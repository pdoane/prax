CSS Images 3 · 4.4 Examples of CSS Object Sizing

Object sizing in each context

The following examples show how the CSS 2.1 and CSS3 Backgrounds & Borders sizing algorithms correspond to concepts defined in this specification. CSS Images 3 §4.4 The flags are four colors in quarters: a PNG 40 by 20, and an SVG with only a 2:1 ratio.

list-style-image: a 1em square

They use the default sizing algorithm with no specified size and a default object size of 1em square. The list's font size is 20px.

content and border-image

Objects inserted via the CSS2.1 content property are anonymous replaced elements, and are sized the same way. A border image is first sized with no specified size, and the border image area as the default object size.
