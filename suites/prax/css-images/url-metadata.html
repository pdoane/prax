CSS Images 3 · 2.1.2 Image Metadata

Metadata before the image data

User agents should ignore any layout-impacting metadata (such as orientation or resolution) that occurs after the image data begins. CSS Images 3 §2.1.2

An orientation, early and late

Each PNG holds an upright letter F, with an eXIf chunk whose orientation turns it a quarter turn clockwise. Each is drawn 80 by 80, with image-orientation's initial from-image.

A decoder that cannot tell

If a user agent cannot ignore the metadata based its location in the image (for example, if the decoder being used does not report where in the image the metadata was located), it must use the metadata in all cases. Such a user agent turns the third F as well; which kind a user agent is, a page cannot see.
