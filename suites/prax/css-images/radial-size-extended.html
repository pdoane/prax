radial-gradient(): two keywords, and a circle's percentage

This level extends the <radial-size> options to include the additions from the circle() and ellipse() <basic-shape> values CSS Images 4 §3.2.2 Orange inside the ending shape, light blue beyond.

A keyword for each radius

Two-component values indicate the horizontal (first) and vertical (second) radii of the ellipse. Each box is 160 by 80, its gradient centered at 40px 30px: 40 from the left, 120 from the right, 30 from the top, 50 from the bottom.

A circle's percentage

For circle, a <percentage> value is resolved against the “scaled diagonal” of the gradient box's width and height: sqrt(width² + height²)/sqrt(2). Each box is 170 by 70: its scaled diagonal is 130.
