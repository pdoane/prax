CSS Images 4 · 3.2.1 Adding <color-interpolation-method>

radial-gradient(): the interpolation color space

This level adds a <color-interpolation-method> argument to radial-gradient() and repeating-radial-gradient(), indicating the color space and path to use when interpolating colors on the gradient line. CSS Images 4 §3.2.1 Each box is 160 by 80.

The same stops in three spaces

The specification's example: The middle gradient uses gamma-encoded sRGB, the result is clearly too dark at the midpoint. Each is farthest-side at left bottom, color(display-p3 0.918 0.2 0.161), #081.

A hue path

In a polar space the method names a path for the hue. From red to red, shorter hue stays red; longer hue goes the whole way round, so halfway out the hue is 180°, cyan.
