CSS Images 4 · 2.1 Image File Formats

PNG and SVG, in every property

At minimum, the UA must support the following image file formats when referenced from an <image> value, for all the properties in which using <image> is valid: PNG and SVG, as specified in [SVG11], using the secure static mode. CSS Images 4 §2.1
