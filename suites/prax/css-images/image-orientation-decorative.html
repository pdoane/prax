CSS Images 3 · 5.1 Orienting an Image on the Page: the image-orientation property

image-orientation: decorative images, and angles

The property applies as well as to decorative images applied via CSS rules (such as background-image and other <image> properties). CSS Images 3 §5.1 The image is encoded 100 by 50, green and yellow over blue and red; its EXIF 6 says a quarter turn right.

Backgrounds and border images

Each dashed box is 60 by 60. Border images (see border-image) are sliced after rotation.

An angle, and flip

Deprecated and optional: an angle turns to the right, then flip flipped horizontally. This value only applies to content images; decorative images continue to behave as from-image.
