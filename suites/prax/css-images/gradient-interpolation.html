Interpolating gradients

Interpolate each component and color-stop of the gradients independently. CSS Images 4 §7.4 Each gradient is animated to and fro; a still shows it at 50%. Its stops are hard, blue then orange. Each flagged browser shows the end gradient: it switches at 50%.

Linear: the angle

For linear gradients, the only component is the angle. Two keyword directions more than 180deg apart: add 360deg to the direction of the gradient with the smaller angle.

Color stops: position and color

for each pair of color-stops, interpolate the position and color independently.
