Interpolating stripes()

Both the starting and ending image must have the same number of <color-stripe>s. for each pair of stripes, interpolate the thickness and color independently. CSS Images 4 §7.5 Each box has a 40px border whose border-color, a stripes() of blue then orange, is animated to and fro; a still shows it at 50%. CSS Borders 4 draws the stripes in bands from the padding edge out. The border is grey where stripes() is not supported.

Thicknesses

A thickness left out is 1fr, a share of what the other stripes leave of the border's 40px.

<flex> values are interpolated as <length-percentage>s using the following formula: max(0, 100% - sum-of-percents - sum-of-fixed) * flex value / max(1, sum-of-flexes)
