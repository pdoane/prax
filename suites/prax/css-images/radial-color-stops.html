CSS Images 3 · 3.2.2 Placing Color Stops

radial-gradient(): the gradient line is a ray

The gradient line's starting point is at the center of the gradient, and it extends toward the right, with the ending point on the point where the gradient line intersects the ending shape. CSS Images 3 §3.2.2 Each box is 160 by 60, its gradient centered.

Ellipses through each point

The color of the gradient at any point is determined by first finding the unique ellipse passing through that point with the same center, orientation, and ratio between major and minor axises as the ending-shape.

Before 0% and past 100%

Locations greater than 100% simply specify a location a correspondingly greater distance from the center of the gradient. Before 0%, color stops placed there can affect the color of non-negative locations.
