CSS Images 4 · 3.1 Linear Gradients: the linear-gradient() notation

linear-gradient(): the color interpolation method

This level adds a <color-interpolation-method> argument to linear-gradient() and repeating-linear-gradient(), indicating the color space and path to use when interpolating colors on the gradient line. CSS Images 4 §3.1 Each gradient runs from red at the left to blue at the right. A square cut from a gradient's middle is followed by the color expected there.

The space decides the colors between the stops

In HSL, red's hue is 0deg and blue's 240deg: the default shorter path goes down through magenta, longer up through yellow, lime and cyan. CSS Color 4 §13.5

Before or after the direction

The direction and the method may come in either order: [ <angle> | to <side-or-corner> ] || <color-interpolation-method>.
