radial-gradient(): explicit sizes

If the ending-shape is an ellipse, its axises are aligned with the horizontal and vertical axises. CSS Images 3 §3.2.1 Each box is 160 by 60, its gradient centered: orange inside the ending shape, light blue beyond it.

A circle's radius

<length [0,∞]>: Gives the radius of the circle explicitly.

An ellipse's radii

<length-percentage [0,∞]>{2}: The first value represents the horizontal radius, the second the vertical radius. Percentages values are relative to the corresponding dimension of the gradient box.
