CSS Images 3 · 3.1.1 linear-gradient() syntax

linear-gradient(): toward a corner

If the argument instead specifies a corner of the box such as to top left, the gradient line must be angled such that it points into the same quadrant as the specified corner, and is perpendicular to a line intersecting the two neighboring corners of the gradient box. CSS Images 3 §3.1.1

The 50% line joins the neighboring corners

This causes a color-stop at 50% to intersect the two neighboring corners. Each dashed box is 140 by 40, blue to 50% of its gradient line, then orange.
