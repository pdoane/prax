CSS Images 3 · 3.2.1 radial-gradient() Syntax

radial-gradient(): the ending shape and the center

If <radial-shape> is omitted, the ending shape defaults to a circle if the <radial-size> is a single <length>, and to an ellipse otherwise. CSS Images 3 §3.2.1 Each box is 160 by 60, orange inside the ending shape and light blue beyond it.

Circle or ellipse

The center

The <position> is resolved using the center-point as the object area and the gradient box as the positioning area. If this argument is omitted, it defaults to center. A point has no size, so 100% puts the center on the far edge.
