CSS Images 3 · 3.2.1 radial-gradient() Syntax

radial-gradient(): a circle's size by keyword

<radial-size> Determines the size of the gradient's ending shape. If omitted it defaults to farthest-corner. CSS Images 3 §3.2.1 Each box is 160 by 80, orange inside the ending shape, light blue beyond it.

Sides and corners, near and far

closest-side: exactly meets the side of the gradient box closest to the gradient's center; closest-corner: passes through the corner of the gradient box closest to the gradient's center; the farthest likewise. The first four circles are at 40px 30px: 40 from the left, 30 from the top, 50 from the bottom, 120 from the right; the top left corner is 50 away, the bottom right 130. The last two are farthest-side, centered 20 outside the box: consider the gradient box edges as extending infinitely in both directions, rather than being finite line segments.
