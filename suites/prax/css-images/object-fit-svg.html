CSS Images 4 · 5.1 Sizing Objects: the object-fit property

object-fit with SVG content

the concrete object size (or, in this case, the size of the content) does not directly scale the object itself - it is merely passed to the object as information about the size of the visible canvas. CSS Images 4 §5.1 Each image is 80 by 60, on light orange.

SVG draws itself into the size

raster images always scale to the given size, while SVG uses the given size as the size of the "SVG Viewport", says a Note.

none, with no natural size

none: determine the object's concrete object size using the default sizing algorithm with no specified size, and a default object size equal to the replaced element's used width and height. Each SVG has no natural height.
