CSS Images 4 · 7.1 Interpolating <image>

Interpolating images by cross-fading

All images can be interpolated: images are interpolated by scaling them to the size of the start image and cross-fading the two while they transition to the size of the end image. at each point in the interpolation the image is equal to cross-fade( (100% - t) start image, end image).
