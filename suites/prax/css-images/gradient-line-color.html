CSS Images 4 · 3.5.2 Coloring the Gradient Line

Coloring the gradient line

Between each pair of color stops, the gradient line’s color is interpolated between the colors of the two color stops, with the interpolation taking place in the specified color space, with missing components, hue and premultiplied alpha as CSS Color 4 defines them. CSS Images 4 §3.5.2 The default space, Oklab, or sRGB between legacy colors, is CSS Color's to show. Each bar is to right and 200px wide.

Before the first stop and after the last

Before the first color stop, the gradient line is the color of the first color stop, and after the last color stop, the gradient line is the color of the last color stop.

Premultiplied alpha, and a missing hue

In OKLCh, the conversion of the neutral #888 to oklch gives a missing hue component, so in the first gradient segment, the hue is taken from red and in the second segment it is taken from green.
