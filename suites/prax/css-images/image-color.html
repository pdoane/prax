CSS Images 4 · 2.5 Image Fallbacks and Annotations: the image() notation

image(): a solid-color image

The image() function represents a solid-color image of the specified color with no natural dimensions. CSS Images 4 §2.5 Each dashed box is 80 by 40.

A color, sized as a gradient is

With no natural dimensions, the image takes the size its context gives it.

A tint over another image

An example: one can use this as a simple way to “tint” a background image, by overlaying a partially-transparent color over the top of the other image, equivalent to a single color stop gradient.
