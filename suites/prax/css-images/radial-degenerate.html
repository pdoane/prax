CSS Images 3 · 3.2.3 Degenerate Radial Gradients

Degenerate radial gradients

In these degenerate cases, the gradient must be rendered as follows CSS Images 3 §3.2.3 Each box is 160 by 60, orange to 30px along the ray and light blue past it: a stop in px keeps its place whatever the ending shape's size.

Zero radius, zero width, zero height

A circle of zero radius: Render as if the ending shape was a circle whose radius was an arbitrary very small number greater than zero. Zero width: Render as if the ending shape was an ellipse whose height was an arbitrary very large number and whose width was an arbitrary very small number greater than zero. Zero height, the reverse.
