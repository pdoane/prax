CSS Images 4 · 7.4 Interpolating <gradient>

Gradients that do not interpolate directly

If they fail the third one only, they must be abruptly transitioned at 50% (unless otherwise specified by a future specification). If they fail either of the first two constraints, they must be interpolated using cross-fade() as for generic images. CSS Images 4 §7.4 Each gradient is animated to and fro; a still shows the frame the caption gives. Its stops are hard, blue then orange.

Cross-faded

Both the starting and ending gradient must be expressed with the same function. Both the starting and ending gradient must have the same number of color-stops. Where neither holds, at 50% each pixel is half the one gradient's color and half the other's: where blue meets orange, a greyish brown.

Lengths and percentages: abrupt at 50%

Neither gradient uses a combination of <length> and <percentage> color stops. From stops at 20px and 20px 100%, which mix them, to stops at 80% and 80% 100%.
