CSS Images 4 · 2.6.1 cross-fade() Sizing

cross-fade(): its natural size

The dimensions of the image represented by a cross-fade() are a weighted average of dimensions of the <image> arguments to the function; the <color> arguments have no effect. CSS Images 4 §2.6.1 Each dashed box is 80 by 60 with one background image, not repeated and not sized, so drawn at its natural size. The flags are the same four quarters, 40 by 20 and 80 by 40.

A weighted average

Return a natural width and natural height that are weighted averages of the width and height of each item in images, according to their corresponding percentages.

Colors, and no images

If argument is not an <image>, or is an <image> with no natural dimensions, continue. If images is empty, return no natural dimensions.
