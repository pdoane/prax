The gradient box

A gradient is drawn into a box with the dimensions of the concrete object size, referred to as the gradient box. However, the gradient itself has no natural dimensions. CSS Images 3 §3 Each gradient here changes abruptly from blue to orange at 50%.

The box the gradient is sized to

if you use a gradient as a background, by default the gradient will draw into a gradient box the size of the element's padding box. for a gradient used as a list-style-image, the box would be a 1em square.

No natural dimensions

Each dashed box is 140 by 40, with background-size: 40px auto, drawn once at the top left. With no natural height or ratio, the gradient's height comes from the background positioning area.
