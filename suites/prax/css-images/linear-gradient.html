CSS Images 3 · 3.1 Linear Gradients: the linear-gradient() notation

linear-gradient(): lines perpendicular to the gradient line

The image is constructed by creating an infinite canvas and painting it with lines perpendicular to the gradient line, with the color of the painted line being the color of the gradient line where the two intersect. CSS Images 3 §3.1

The color is constant across the gradient line

Each gradient is blue to 50% of its gradient line, then orange, so the edge between them is one of the painted lines: it runs through the center of the box, at a right angle to the gradient's direction.
