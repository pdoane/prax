CSS Images 4 · 5.1 Sizing Objects: the object-fit property

object-fit: the scale-down flag

This level makes scale-down a flag on contain and cover: fill | none | [contain | cover] || scale-down. CSS Images 4 §5.1 Each image shows the 40 by 20 flag on light orange.

cover scale-down

If the scale-down flag is used, size the content as if none or cover were specified, whichever would result in a smaller concrete object size.

contain scale-down, and scale-down alone

Equivalent to contain scale-down. In 80 by 60, contain is 80 by 40, so the smaller is none's 40 by 20.
