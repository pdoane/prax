CSS Images 4 · 3.3.1 conic-gradient() Syntax

conic-gradient(): from an angle, at a position

[ from [ <angle> | <zero> ] ]? [ at <position> ]? CSS Images 4 §3.3.1 Each box is 140 by 80. Its gradient is blue 25%, orange 0 50%, green 0 75%, purple 0: a quarter turn of each, clockwise.

from: the whole gradient turned

The entire gradient is rotated by this angle. If omitted, defaults to 0deg. The unit identifier may be omitted if the <angle> is zero.

at: the gradient center

The position is resolved using the center-point as the object area and the gradient box as the positioning area. If this argument is omitted, it defaults to center.
