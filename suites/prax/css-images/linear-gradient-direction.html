CSS Images 3 · 3.1.1 linear-gradient() syntax

linear-gradient(): the direction of the gradient line

The first argument to the function specifies the gradient line, which gives the gradient a direction and determines how color-stops are positioned. It may be omitted; if so, it defaults to to bottom. CSS Images 3 §3.1.1 Each box is 80 by 40, blue for the first 25% of its gradient line and orange after, so the blue band is at the start of the line: 10px of a vertical line, 20px of a horizontal one.

An angle

For the purpose of this argument, 0deg points upward, and positive angles represent clockwise rotation, so 90deg point toward the right.

Keywords for the sides

If the argument is to top, to right, to bottom, or to left, the angle of the gradient line is 0deg, 90deg, 180deg, or 270deg, respectively.
