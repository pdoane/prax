CSS Images 4 · 2.6 Combining images: the cross-fade() notation

cross-fade(): how much of each image

The <percentage> represents how much of each image is retained when it is blended with the other images. CSS Images 4 §2.6 Each dashed box is 80 by 40 on white, its background image sized 80 by 40.

Percentages, given and omitted

If any percentages are omitted, all the specified percentages are summed together and subtracted from 100%, the result is floored at 0%, then divided equally between all images with omitted percentages. If a <color> is provided, it represents a solid-color image.

Sums other than 100%

A Note: under 100%, there's an additional transparent argument; over it, the details rescale them so that they sum to exactly 100%. §2.6.2's steps do so.
