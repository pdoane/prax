CSS Images 3 · 2.1.1 Ambiguous Reference-or-Image URLs

A URL that is an element or an image

If an ambiguous image URL is a fragment-only URL, then it must be treated as an element reference. Otherwise, if the ambiguous image URL has a fragment that references an element in the resource that is an appropriate type of element for the context in which the <url> appears (such as a <mask> element for the mask-image property), it is interpreted as an element reference. Otherwise, it is treated as an <image>. CSS Images 3 §2.1.1

A mask element: a reference

Each box is a blue 40px square with a mask-image. Each <mask> named here holds a white circle as wide as the box it masks.

Anything else: an image

masks.svg drawn as an image is 40 by 40, and only its <g> paints: a black bar across its top 10px. As an image, a mask keeps what the image's alpha covers.
