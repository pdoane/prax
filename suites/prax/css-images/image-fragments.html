CSS Images 5 · 2.1.2 Image Fragments

image(): a part of an image

When a URL specified in image() represents a portion of a resource (e.g. by the use of media fragment identifiers) that portion is clipped out of its context and used as a standalone image. CSS Images 5 §2.1.2

xywh= clips out a rectangle

implementations that support the image() notation must support the xywh=#,#,#,# form of media fragment identifiers for images specified via image(). The sprite sheet: nine 20px cells, the nth n eighths orange. Each dashed box is 100 by 40, its background drawn once at the top left.

A fragment not understood: invalid

If a URL uses a fragment identifier syntax that the implementation does not understand, or does not consider valid for that type of image, the URL must be treated as representing an invalid image.
