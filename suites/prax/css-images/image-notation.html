CSS Images 5 · 2.1 Image Fallbacks and Annotations: the image() notation

image(): a URL, and its orientation

The image() function allows an author to: use media fragments to clip out a portion of an image; use a solid color as an image; fallback to a solid-color image, when the image at the specified url can't be downloaded or decoded; automatically respect the image orientation specified in the image's metadata CSS Images 5 §2.1

A string is a URL

A <string> used in image() represents a <url>. Each dashed box is 100 by 40, with its background drawn once at the top left. The image is a flag 40 by 20, four colors in quarters.

Oriented whatever image-orientation says

If the image has an orientation specified in its metadata, such as EXIF, the UA must rotate or flip the image to correctly orient it as the metadata specifies. The JPEG is stored 100 by 50, with an EXIF orientation that turns it a quarter turn clockwise. The box is 100 by 100, with image-orientation: none.
