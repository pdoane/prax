image-set(): an image at its resolution

The image-set() function allows an author to ignore most of these issues, simply providing multiple resolutions of an image and letting the UA decide which is most appropriate in a given situation. CSS Images 4 §2.4

The resolution sizes a raster image

If the image reference is for a raster image, it also specifies the image’s natural resolution, overriding any other source of data that might supply a natural resolution. The flags are 40 by 20 and 80 by 40 image pixels; each box is 140 by 40, no-repeat.
