CSS Images 5 · 3.1 Setting The Viewbox: the object-view-box property

object-view-box

The object-view-box property specifies a "view box" over an element, which allows zooming or panning over the element's contents. CSS Images 5 §3.1 Each image is the flag PNG, 40 by 20 in four colors, on a light orange background.

The view box is the natural size

For all purposes, the element is now treated as having natural sizes equal to the view box's width and height. If the element does not have both a natural width and a natural height, this value has no effect.

Zooming in and out

its contents are scaled and translated such that the element's contents retain the same position and size, relative to the view box's final size and position. Each image is width: 80px, its height from the view box's ratio.
