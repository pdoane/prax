CSS Images 3 · 3.3 Repeating Gradients: the repeating-linear-gradient() and repeating-radial-gradient() notations

Repeating gradients too fine to draw

If the distance between the first and last color-stops is zero (or rounds to zero due to implementation limitations), the implementation must find the average color of a gradient with the same number and color of color-stops, but with the first and last color-stop an arbitrary non-zero distance apart, and the remaining color-stops equally spaced between them. CSS Images 3 §3.3 Each dashed box is 160 by 40.

The average color

To average, each pair of adjacent stops adds half its share of the line to each of its two colors, in premultiplied sRGB.

A radial gradient with no height

If the width of the ending shape of a repeating radial gradient is non-zero and the height is zero, it is drawn in the average color.
