CSS Images 3 · 4.1 Object-Sizing Terminology

Natural dimensions

The term natural dimensions refers to the set of the natural height, natural width, and natural aspect ratio (the ratio between the width and height), each of which may or may not exist for a given object. CSS Images 3 §4.1 Each image is an img of auto size on a light orange background, in a column 80px wide; each is a flag of four colors.

All three, or one

Raster images are an example of an object with all three natural dimensions. SVG images designed to scale might have only a natural aspect ratio; SVG images can also be created with only a natural width or height. CSS gradients, defined in this specification, are an example of an object with no natural dimensions at all. If an object has a degenerate natural aspect ratio (at least one part being zero or infinity), it is treated as having no natural aspect ratio.
