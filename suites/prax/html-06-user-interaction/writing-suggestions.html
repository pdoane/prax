HTML · 6.8.6 Writing suggestions

Writing suggestions

User agents offer writing suggestions as users type into editable regions, either in form controls (e.g., the textarea element) or in elements in an editing host. This specification does not define the user interface for writing suggestions. HTML §6.8.6

Turned off on the element or an ancestor

User agents should offer none If element has an inclusive ancestor with a writingsuggestions content attribute that's not in the Default and the nearest such ancestor's writingsuggestions content attribute is in the False state. The attribute's invalid value default and empty value default are both the True state. §6.8.6
