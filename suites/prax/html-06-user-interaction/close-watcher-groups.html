HTML · 6.10.2 Close watcher infrastructure

Groups of close watchers

The grouping of close watchers is designed so that if multiple close watchers are created without history-action activation, they are grouped together, so that a user-triggered close request will close all of the close watchers in a group. HTML §6.10.2

One group per activation

A new watcher starts a group If manager's groups's size is less than manager's allowed number of groups; otherwise it is appended to the last group. Each user activation, after a watcher is created, allows one more group. A close request will process the last group: For each closeWatcher of group, in reverse order. §6.10.2
