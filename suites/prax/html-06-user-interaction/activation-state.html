HTML · 6.4.1 Data model

Sticky and transient activation

For the purpose of tracking user activation, each Window W has two relevant values, a last activation timestamp and a last history-action activation timestamp, from which its activation states follow. HTML §6.4.1

Sticky stays, transient expires

Sticky activation is W's historical activation state, indicating whether the user has ever interacted in W. Transient activation is W's current activation state, indicating whether the user has interacted in W recently. This starts with a false value, and remains true for a limited time after every activation notification W gets. The transient activation duration is expected be at most a few seconds. §6.4.1
