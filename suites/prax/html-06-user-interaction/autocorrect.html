Autocorrection

Some methods of entering text assist users by automatically correcting misspelled words while typing, a process also known as autocorrection. The autocorrect attribute allows authors to control such behavior. HTML §6.8.8

On, off, from the form, and never for some types

Off: The user agent is not allowed to automatically correct spelling while the user types. The used state comes from the element's attribute, else the state of element's form owner's autocorrect attribute; but If element is an input element whose type attribute is in one of the URL, Email, or Password states, then return Off. §6.8.8
