HTML · 6.7.3 Processing model

When an access key does nothing

When the user presses the key combination corresponding to the assigned access key for an element, if the element defines a command, the command's Hidden State facet is false (visible), the command's Disabled State facet is also false (enabled), the element is in a document that has a non-null browsing context, and neither the element nor any of its ancestors has a hidden attribute specified, then the user agent must trigger the Action of the command. HTML §6.7.3

Disabled, inert, or hidden

A button's Disabled State is true if the element or one of its ancestors is inert, or if the element's disabled state is set. §4.11.3.3
