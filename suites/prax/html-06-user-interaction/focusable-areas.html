HTML · 6.6.2 Data model

Focusable areas

The term focusable area is used to refer to regions of the interface that can further become the target of such keyboard input. HTML §6.6.2

Which elements

An element is a focusable area if the element's tabindex value is non-null, or the element is determined by the user agent to be focusable, is not actually disabled, is not inert, and is either being rendered, delegating its rendering to its children, or being used as relevant canvas fallback content. §6.6.2
