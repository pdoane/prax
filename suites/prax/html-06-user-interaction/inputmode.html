HTML · 6.8.9 Input modalities: the inputmode attribute

The inputmode attribute

The inputmode content attribute is an enumerated attribute that specifies what kind of input mechanism would be most helpful for users entering content. HTML §6.8.9

The virtual keyboard for each keyword

none: The user agent should not display a virtual keyboard. numeric: a virtual keyboard capable of numeric input; decimal: Numeric keys and the format separator for the locale should be shown. tel: keys for the digits 0 to 9, the "#" character, and the "*" character. email: keys such as that for the "@" character and the "." character. url: keys such as that for the "/" and "." characters. search: a virtual keyboard optimized for search. §6.8.9
