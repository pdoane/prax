HTML · 6.3.2 The inert attribute

The inert attribute and the flat tree

The inert attribute is a boolean attribute that indicates, by its presence, that the element and all its flat tree descendants which don't otherwise escape inertness (such as modal dialogs) are to be made inert by the user agent. HTML §6.3.2

Slotted into an inert element

The shadow tree of the host holds <div inert><slot></slot></div>, faded. The button slotted is the host's child, not a descendant of the inert div, but it is one in the flat tree. §6.3.2
