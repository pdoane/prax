HTML · 6.11.6 Events summary

The drag-and-drop events

dragstart, drag and dragend go to the Source node; dragenter to the Immediate user selection or the body element; dragleave to the Previous target element; dragover and drop to the Current target element. All of these events bubble, are composed, and the effectAllowed attribute always has the value it had after the dragstart event. HTML §6.11.6

A drag from the card to the zone

The zone cancels dragenter, dragover and drop. The log leaves out a repeat of the line above it, as drag and dragover repeat while the drag goes on. §6.11.6
