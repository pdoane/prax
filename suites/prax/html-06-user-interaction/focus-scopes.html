HTML · 6.6.2 Data model

Focus navigation scope owners

A node is a focus navigation scope owner if it is a Document, a shadow host, a slot, or an element which is the popover trigger of an element in the popover showing state. HTML §6.6.2

A slot

If element's parent is a shadow host, then return element's assigned slot. The host's children are x then y; its shadow tree has the slot for y before the slot for x. §6.6.2

A popover's trigger

If element is in the popover showing state and has a popover trigger set, then return element's popover trigger. The popover is the last element of the page. §6.6.2
