Popover light dismiss

"Light dismiss" means that clicking outside of a popover whose popover attribute is in the Auto or Hint state will close the popover. This is in addition to how such popovers respond to close requests. HTML §6.12.2

Outside, inside, and the button that showed it

On pointerup, the popovers closed are those above the topmost clicked popover, which counts the popover that a clicked button targets. Nothing closes when the pointerdown found another: If sameTarget is false, then return. §6.12.2
