HTML · 6.5 Activation behavior of elements

Activation without a click

Certain elements in HTML have an activation behavior, which means that the user can activate them. This is always caused by a click event. HTML §6.5

By the keyboard

When the user triggers an element with a defined activation behavior in a manner other than clicking it, the default action of the interaction event must be to fire a click event at the element. §6.5

click() acts as a click

click() Acts as if the element was clicked. If this element is a form control that is disabled, then return. §6.5
