HTML · 6.4.2 Processing model

What activates a window

When a user interaction causes firing of an activation triggering input event in a Document document, the user agent must perform the following activation notification steps before dispatching the event. HTML §6.4.2

The triggering events

They are keydown, provided the key is neither the Esc key nor a shortcut key reserved by the user agent; mousedown; pointerdown, provided the event's pointerType is "mouse"; pointerup, provided the event's pointerType is not "mouse"; or touchend. §6.4.2

Up and down the frames

The windows notified are the document's, those of each of document's ancestor navigables, and those of its descendant navigables, filtered to include only those navigables whose active document's origin is same origin with document's origin. §6.4.2
