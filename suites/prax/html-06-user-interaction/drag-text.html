HTML · 6.11.5 Processing model

Dropping text into a text control

A text control, editing host or editable element accepts dragged text without a listener: when the dragged data has text, the user agent will Set the current target element to the immediate user selection anyway, and the drop's default action is to Insert the actual data of the first item in the drag data store item list to have a drag data item type string of "text/plain". HTML §6.11.5

Into a field, and out of one

When the drop succeeds, the operation is move, and the source is a selection in a text control, The user agent should delete the dragged selection from the relevant text control. §6.11.5
