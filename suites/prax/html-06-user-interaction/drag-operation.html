HTML · 6.11.5 Processing model

The current drag operation

If the dragover event is canceled, the user agent will set the current drag operation based on the values of the effectAllowed and dropEffect attributes, then Update the drag feedback (e.g. the mouse cursor) to match the current drag operation. HTML §6.11.5

Copy, link, move, or none

Each zone cancels dragenter and dragover and sets the dropEffect it names; the card's dragstart sets effectAllowed from the menu. A drop effect the allowed effects do not include gives "none": No operation allowed, dropping here will cancel the drag-and-drop operation. §6.11.5
