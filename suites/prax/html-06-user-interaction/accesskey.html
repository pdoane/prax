HTML · 6.7.2 The accesskey attribute

The accesskey attribute

The accesskey attribute's value is used by the user agent as a guide for creating a keyboard shortcut that activates or focuses the element. HTML §6.7.2

Activating, or focusing

The modifiers are the user agent's: Alt in Chrome on Windows and Linux, Alt+Shift in Firefox, Control+Option on a Mac. A button's command's Action is to fire a click event at the element; that of another element with an access key is to Run the focusing steps for the element, then Fire a click event at the element. §4.11.3

Alternatives, in order

The value is an ordered set of unique space-separated tokens, each one code point. If the value does not correspond to a key on the system's keyboard, then skip the remainder of these steps for this value. §6.7.3
