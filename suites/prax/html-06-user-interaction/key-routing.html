HTML · 6.6.4 Processing model

Where key events go

When a key event is routed, Let target area be the currently focused area of the top-level traversable. Let target node be target area's DOM anchor. HTML §6.6.4

The focused element, or else the body

If target node is a Document that has a body element, then let target node be the body element of that Document. §6.6.4

Not to the inside of a frame that is not focused

A key goes to the focused area of the top-level traversable, wherever the pointer is: a frame's document gets it only when the focus is in it. §6.6.4
