APIs gated by user activation

APIs that are dependent on user activation are classified into different levels. HTML §6.4.3

Gated: only while the activation lasts

Transient activation-gated APIs require the transient activation state to be true, but they don't consume it. showPicker() is one. §6.4.3

Consuming: once per activation

Transient activation-consuming APIs require the transient activation state to be true, and they consume user activation in each call to prevent multiple calls per user activation. requestFullscreen() is one. §6.4.3
