The focusable area for an element

The focusing steps first set new focus target to the result of getting the focusable area for new focus target when it is not a focusable area itself. The buttons do not take the focus when pressed. HTML §6.6.4

A scroll container and a frame

If focus target is an element with one or more scrollable regions that are focusable areas: Return the element's first scrollable region. If focus target is a navigable container with a non-null content navigable: Return the navigable container's content navigable's active document. §6.6.4

The document element

If focus target is the document element of its Document: Return the Document's viewport. §6.6.4
