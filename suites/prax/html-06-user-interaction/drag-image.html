An image, and where the cursor holds it

If image is an img element, then set the drag data store bitmap to the element's image (at its natural size). Set the drag data store hot spot coordinate to the given x, y coordinate. The feedback uses it as hints for where to put the cursor relative to the resulting image. §6.11.3 §6.11.5
