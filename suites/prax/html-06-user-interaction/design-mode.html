HTML · 6.8.2 Making entire documents editable

designMode

document.designMode Returns "on" if the document is editable, and "off" if it isn't. Can be set, to change the document's current state. This focuses the document and resets the selection in that document. HTML §6.8.2

The whole document, editable

An editing host is a child HTML element of a Document whose design mode enabled is true. The checkbox sets the frame's designMode. §6.8.4
