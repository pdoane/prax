HTML · 6.6.2 Data model

Focus and being rendered

A focusable area is an element that is either being rendered, delegating its rendering to its children, or being used as relevant canvas fallback content. HTML §6.6.2

A focused element that stops being rendered

The page's script hides the box a second after it takes the focus. The next update of the rendering then finds that the focused area of doc is not a focusable area, and will run the focusing steps for doc's viewport. This will usually fire blur events. §8.1.7.3

Delegating its rendering to its children

An element with display: contents has no box of its own but is still a focusable area. §6.6.2
