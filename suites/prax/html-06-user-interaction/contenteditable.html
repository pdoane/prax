HTML · 6.8.1 Making document regions editable

The contenteditable attribute

The contenteditable content attribute is an enumerated attribute whose keywords are true, false and plaintext-only. In the last state, Only the element's raw text content is editable; rich formatting is disabled. HTML §6.8.1

True, and the empty value

The attribute's empty value default is the True state. §6.8.1

Inherit, and False within

The attribute's missing value default and invalid value default are both the Inherit state. The inherit state indicates that the element is editable (or not) based on the parent element's state. §6.8.1
