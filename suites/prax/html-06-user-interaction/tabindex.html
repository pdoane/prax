HTML · 6.6.3 The tabindex attribute

The order of tabindex

Positive numbers specify the relative position of the element's focusable areas in the sequential focus navigation order, and negative numbers indicate that the control is not sequentially focusable. HTML §6.6.3

Positive values first, then the rest in tree order

An element with a positive value is placed before any focusable area whose DOM anchor is an element whose tabindex attribute has a value less than or equal to zero. The relative ordering within a tabindex-ordered focus navigation scope for elements and focusable areas that belong to the same focus navigation scope and whose tabindex value is zero should be in shadow-including tree order. §6.6.3
