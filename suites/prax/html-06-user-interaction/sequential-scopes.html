HTML · 6.6.5 Sequential focus navigation

Focus navigation scopes

Per the rules defining the flattened tabindex-ordered focus navigation scope, the ordering is not necessarily related to the tree order of the Document. HTML §6.6.5

Into shadow trees and frames

The order is given by the flattened tabindex-ordered focus navigation scope of the Document. A shadow host and a navigable container own scopes of their own, which take their places in it. §6.6.5
