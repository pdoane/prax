HTML · 6.8.5 Spelling and grammar checking

Spelling and grammar checking

If the checking is enabled for a word/sentence/text, the user agent should indicate spelling and grammar errors in that text. If checking is disabled, the user agent should not indicate spelling or grammar errors for that text. HTML §6.8.5

The attribute, on the element or an ancestor

if the element with which the text is associated has a spellcheck content attribute, then: if that attribute is in the True state, then checking is enabled; otherwise, if that attribute is in the False state, then checking is disabled. Otherwise, if there is an ancestor element with a spellcheck content attribute that is not in the Default state, the nearest one decides. §6.8.5

Text in an editing host

The element that decides is the immediate parent of the first character of the word. §6.8.5
