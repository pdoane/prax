HTML · 6.6.3 The tabindex attribute

tabindex within scopes

A positive value places the element in the tabindex-ordered focus navigation scope where the element is a part of so that, relative to other elements and focusable areas that belong to the same focus navigation scope, it comes in the order of its value. HTML §6.6.3

A value orders only its own scope

The shadow tree's s1 has tabindex=1; it is ordered within the host's scope, and the host, without a tabindex, comes after the page's positive values. §6.6.3

A negative value on a scope owner

The tabindex-ordered scope contains all elements in owner's focus navigation scope that are themselves focus navigation scope owners, except the elements whose tabindex value is a negative integer. §6.6.2
