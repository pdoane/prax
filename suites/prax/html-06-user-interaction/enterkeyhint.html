HTML · 6.8.10 Input modalities: the enterkeyhint attribute

The enterkeyhint attribute

The enterkeyhint content attribute is an enumerated attribute that specifies what action label (or icon) to present for the enter key on virtual keyboards. HTML §6.8.10

A cue for each operation

For each keyword, The user agent should present a cue for the operation it names: enter, done, go, next, previous, search or send. §6.8.10
