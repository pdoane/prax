HTML · 6.6.2 Data model

The focused element removed

One focusable area in each Document is designated the focused area of the document. Which control is so designated changes over time, based on algorithms in this specification. HTML §6.6.2

A focused element removed

When the focused element is removed from the document, set document's focused area to document's viewport. This does not perform the unfocusing steps, focusing steps, or focus update steps, so no blur is fired. §2.1.4
