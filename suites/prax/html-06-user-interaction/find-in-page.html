Find-in-page

This section defines find-in-page — a common user-agent mechanism which allows users to search through the contents of the page for particular information. HTML §6.9.1

The active match, scrolled into view

One of the matches is identified to the user as the active match. It is highlighted and scrolled into view. The user can navigate through the matches by advancing the active match using the find-in-page interface. §6.9.1
