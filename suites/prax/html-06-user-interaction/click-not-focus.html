Not focused by click()

Being focusable is a statement about whether an element can be focused programmatically, e.g. via the focus() method or autofocus attribute. HTML §6.6.2

Not by click()

Note that focusing is not an activation behavior, i.e. calling the click() method on an element or dispatching a synthetic click event on it won't cause the element to get focused. §6.6.2
