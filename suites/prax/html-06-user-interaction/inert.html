Inert subtrees

A node (in particular elements and text nodes) can be inert. The figures make nodes inert with the inert attribute. HTML §6.3

Not hit, not focused

When a node is inert, Hit-testing must act as if the 'pointer-events' CSS property were set to 'none'. Inert nodes generally cannot be focused §6.3
