SVG 2 · 10.6 The ‘polyline’ element

polyline: connected segments, open

The ‘polyline’ element defines a set of connected straight line segments. Typically, ‘polyline’ elements define open shapes. SVG 2 §10.6 Each stage is an SVG 160 by 60, in user units of 1px.

The points

The points that make up the polyline. All coordinate values are in the user coordinate system. The initial value, (none), indicates that the polyline element is valid but does not render. Stroked dark blue, 4 wide, and not filled.

Its path: a moveto, then a lineto to each point

perform an absolute moveto operation to the first coordinate pair in the list of points for each subsequent coordinate pair, perform an absolute lineto operation to that coordinate pair. No closepath: the path stays open.
