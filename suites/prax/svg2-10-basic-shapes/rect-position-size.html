SVG 2 · 10.2 The ‘rect’ element

rect: position and size

The ‘rect’ element defines a rectangle which is axis-aligned with the current user coordinate system. SVG 2 §10.2 Each stage is an SVG 160 by 60, in user units of 1px.

x and y, width and height

The ‘x’ and ‘y’ coordinates refer to the left and top edges of the rectangle, in the current user coordinate system. The width and height properties define the overall width and height of the rectangle.

A width or height of zero

A computed value of zero for either dimension disables rendering of the element. Stroked orange, 10 wide.
