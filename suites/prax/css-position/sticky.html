CSS Positioned Layout 3 · 3.4 Sticky positioning

Sticky positioning: kept inside the scrollport

If an inset is not auto and the corresponding border edge of the box would be outside the corresponding edge of the sticky view rectangle, then the box must be visually shifted (as for relative positioning) to be inward of that sticky view rectangle edge. CSS Positioned Layout 3 §3.4 A light blue block 40px tall comes first.

Shifted only when it would leave

Each axis, and each box, apart

If both inset properties in a given axis are auto, no offsets are added in that axis; the element stays where it was laid out in that axis. Multiple sticky positioned boxes in the same container are offset independently, and therefore might overlap. The first two stages hold content 400px wide, scrolled 60px down and 30px right.
