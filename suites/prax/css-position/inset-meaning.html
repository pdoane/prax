What the insets are measured from

The precise location of a positioned box is controlled by the inset properties. The interpretation of these inset properties varies by positioning scheme. CSS Positioned Layout 3 §3 In each relative stage, a light blue block 30px tall comes before orange B, which has top: 20px; left: 20px.

Three references

for absolute positioning, they represent insets from the containing block. for relative positioning, they represent insets from the box’s original margin edge. for sticky positioning, they represent insets from the scrollport edge.
