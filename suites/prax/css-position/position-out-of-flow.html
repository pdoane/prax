CSS Positioned Layout 3 · 2 Choosing A Positioning Scheme: position property

Absolute and fixed boxes: blockified, not floated, independent

A position value of absolute or fixed blockifies the box, causes float to compute to none, and forces the box to establish an independent formatting context. CSS Positioned Layout 3 §2 Each stage is the containing block.

Orange: a span with position: absolute; top: 20px; left: 20px, and a width and height, which apply only to a box that is not inline. Blue: a box with float: left and position: absolute; top: 20px; right: 20px.
