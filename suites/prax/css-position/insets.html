CSS Positioned Layout 3 · 3.1 Box Insets: the top, right, bottom, left, inset-block-start, inset-inline-start, inset-block-end, and inset-inline-end properties

The inset properties: lengths and percentages

These inset properties represent an inward “inset” on the corresponding side of the box. CSS Positioned Layout 3 §3.1 Each orange box is 40 by 20. CSS 2's pages show lengths and percentages of a containing block without padding.

Percentages

<percentage>: The inset is a percentage relative to the containing block’s size in the corresponding axis (e.g. width for left or right, height for top and bottom).

Sticky percentages: the scrollport

For sticky positioned boxes, the inset is instead relative to the relevant scrollport’s size. The stage scrolls, is scrolled 100px, and holds a block 300px tall, the box's containing block.
