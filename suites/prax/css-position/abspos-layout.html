The absolute positioning layout model

Absolute positioning lays it out in its containing block (after the final size of the containing block has been determined): the inset-modified containing block, then the size, then auto margins, then alignment. CSS Positioned Layout 3 §4 Each stage is relative, 160 by 80, the containing block; where there is a dashed rectangle, it is an empty box with the orange box's insets, which fills the inset-modified containing block.

Percentages of the containing block, not of the room

Next, its width and height are resolved against this definite available space, as its preferred size capped by its maximum size (if any), floored by its minimum size. Percentages, however, are resolved against the absolute-position containing block size. The orange box has inset: 10px 40px, room 80 by 60.
