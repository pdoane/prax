CSS Positioned Layout 4 · 3.3 Top Layer Manipulation

Adding to and removing from the top layer

Features such as popovers and modal dialogs use the algorithms of this section to move an element into and out of the top layer. CSS Positioned Layout 4 §3.3 Each frame is a document, 160 by 80, run by a script.

Added at the end

To add an element to the top layer: If el is already contained in doc’s top layer, Remove el from both doc’s top layer and pending top layer removals. Append el to doc’s top layer.

Removed

An element is rendered in the top layer while it is in it and el has overlay: auto; removing it takes away the UA's overlay: auto.
