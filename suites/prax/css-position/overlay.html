CSS Positioned Layout 4 · 3.4 Controlling the Top Layer: the overlay property

The overlay property

the overlay property determines whether it is actually rendered in the top layer or not. CSS Positioned Layout 4 §3.4 In each frame, a dashed box that clips holds an orange box 100 by 40.

Not for authors to set

User agents must have the following rule in their UA stylesheet: * { overlay: none !important; }

Leaving the top layer when a transition ends

An element removed from the top layer is pending removal until its overlay is none; in a transition, values of p such that 0 < p < 1 map to auto. User agents may, at their discretion, remove a running transition on overlay.
