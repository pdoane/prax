CSS Positioned Layout 4 · 2 Scrollable Containing Block

Containing blocks in a scroll container

Unless otherwise specified, absolutely positioned boxes use the local containing block. CSS Positioned Layout 4 §2 Each stage is a relative scroll container 100px tall, holding content 300px tall whose first and last 20px are light blue.

The local containing block

It is the padding box, affixed to the scrollable overflow area. The orange box has bottom: 0.

The scrollable containing block

It corresponds to the padding edge of the scroll container’s scrollable overflow area; position-area values other than none can opt absolutely positioned boxes into it, as csswg-drafts#12552 resolved. The orange box has position-area: bottom; place-self: stretch: it fills the area below the green anchor.
