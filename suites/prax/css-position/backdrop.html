CSS Positioned Layout 4 · 3.2 The ::backdrop Pseudo-Element

The ::backdrop pseudo-element

Each element rendered in the top layer has a ::backdrop pseudo-element. They're automatically rendered as a separate item in the top layer, below their originating element. The ::backdrop pseudo-element is a fully styleable pseudo-element. CSS Positioned Layout 4 §3.2 Each frame is a document, 160 by 80, with a green block; its popovers, which a script shows, have backdrops of translucent blue.

Below its element, above the document

The UA style sheet has ::backdrop { position: fixed; inset: 0; }.
