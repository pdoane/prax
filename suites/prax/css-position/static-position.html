CSS Positioned Layout 3 · 3.5.3 Calculating the Static Position and the “Static-Position Rectangle”

The static position: the hypothetical box

When both inset properties in a given axis are auto, they are resolved into a static position by aligning the box into its static-position rectangle, as if static. CSS Positioned Layout 3 §3.5.3 Each stage is relative, the containing block; the orange boxes have all four insets auto.

As if not floated, not cleared, with no auto margins

Finding the static position and the static-position rectangle assumes that both float and clear (as well as position) have their initial values. Lastly, all auto margins on the box itself are treated as zero. In the first two, a green float 60px wide comes first.

The static-position containing block's writing mode

Alignment uses the static-position containing block as the effective containing block, including using its writing mode for resolving alignment axes and directions. Here a dashed static block has its own writing mode.
