CSS Positioned Layout 4 · 3.1 Top Layer Styling

How the top layer lays out its elements

How every element rendered in the top layer is rendered. CSS Positioned Layout 4 §3.1 Each frame shows an orange popover, 60 by 20.

Its containing block and position

If its position property computes to fixed, its containing block is the viewport; otherwise, it's the initial containing block. If its specified position property is not absolute or fixed, it computes to absolute.

Its static position, and its display

Unless overridden by another specification, its static position for left, right, and top is zero. If its specified display property is contents, it computes to block. It is not rendered if its shadow-including inclusive ancestor has the display: none.
