CSS Positioned Layout 3 · 2.1 Containing Blocks of Positioned Boxes

Containing blocks of inline boxes, across lines

For an inline ancestor, the containing block is formed by forming a rectangle from the start-most content edges (in both axes) of the first box fragment of the ancestor, and the end-most content edges of the end-most box fragment(s) of the ancestor in each axis. CSS Positioned Layout 3 §2.1

From the first fragment's start to the last one's end

The tinted span is relative and runs over two lines of 10px letters; it holds an absolute box with inset: 0, outlined in blue. The containing block formed by a fragmented inline box was undefined in CSS2.

Content edges, not padding edges

The rectangle is made of content edges, where CSS 2 had the padding boxes. CSS 2 §10.1 Here the span has 10px of padding.

Chrome, Safari and Firefox cover the padding too, as CSS 2 did. The containing block of a split inline box is an open issue (csswg-drafts#8284), so no browser is flagged.
