CSS Positioned Layout 3 · 3.4 Sticky positioning

Sticky positioning in tables, flex and grid layout

Sticky positioning is similar to relative positioning except the offsets are automatically calculated in reference to the nearest scrollport. CSS Positioned Layout 3 §3.4 It applies to every box that position does, kept within the containing block its formatting context gives it. Each stage scrolls, and is scrolled 60px; the sticky boxes have top: 0.
