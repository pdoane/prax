CSS Positioned Layout 3 · 3.3 Relative Positioning

Relative positioning: which inset wins, by the containing block's writing mode

For a relatively positioned box, the inset properties move the box inward from the respective edge, without changing its size. CSS Positioned Layout 3 §3.3 CSS 2's pages show the cases with one inset auto or both.

Over-constrained: the start side wins

If neither is auto, the position is over-constrained; (with respect to the writing mode of its containing block) the computed end side value is ignored, and its used value becomes the negation of the start side. Each orange box, 40 by 40, has left: 20px; right: 50px.

In the vertical axis

Each box has top: 20px; bottom: 30px.
