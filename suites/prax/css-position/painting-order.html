CSS Positioned Layout 4 · 4 Painting Order and Stacking Contexts

Painting a document

To paint a document: Paint a stacking context given doc's root element and canvas. Then, for each element in the top layer, its ::backdrop and then the element. CSS Positioned Layout 4 §4 CSS 2's Appendix E pages show the order within a stacking context; the top layer's pages, what follows the root.

The canvas

The canvas is transparent if contained within another. If root is a root element's principal box, paint root's background over the entire canvas. Each frame is a document.

Outlines in band or out of band

Outlines are drawn in band, painted along each element, or out of band, painted at the end of the stacking context. It is recommended that UAs use out-of-band outlines. Blue has a purple outline; orange, the next block, is pulled up over it.
