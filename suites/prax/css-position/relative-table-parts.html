CSS Positioned Layout 3 · 3.3 Relative Positioning

Relative positioning of rows, row groups and columns

If specified on a table-row-group, table-header-group, table-footer-group, or table-row box the shift affects all the contents of the box, including all table cells that originate in the affected row, but not those that don't. CSS Positioned Layout 3 §3.3 Each table has three rows; the cells of the row or group that has position: relative; top: 10px; left: 20px are blue.

Since position does not apply to table-column-group or table-column boxes, they are not affected by relative positioning.
