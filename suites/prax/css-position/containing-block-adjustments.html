CSS Positioned Layout 3 · 2.1.1 Further Adjustments to the Containing Block

Containing blocks adjusted by grid areas and position areas

Some features can alter the effective containing block rectangle of absolutely positioned boxes. These are applied in the following order, with earlier steps modifying the containing block that later steps see. CSS Positioned Layout 3 §2.1.1 Each stage is relative, a grid of two columns 100px wide, and so the containing block of the orange box.

1. The grid area

The grid-placement properties on an absolutely positioned box whose containing block is generated by a grid container can change the containing block rectangle to a specified grid area. CSS Grid Layout 2 §10.1

2. Then the position area

The position-area and position-try properties can change the containing block rectangle to a specified area of an position-area grid. CSS Anchor Positioning 1 §3.1 A green anchor sits from 120 to 160 across. The orange box has position-area: left span-all, from the containing block's left edge to the anchor's, and fills it.
