Resolving auto insets

How an auto inset is resolved, before the box is sized into the inset-modified containing block. CSS Positioned Layout 3 §3.5.1 Each stage is relative, and the containing block.

One auto inset: zero

If only one inset property in a given axis is auto, it is set to zero. The tinted box's width and right are auto: it fits its 10px letters into the room from its left to the stage's right edge.

Both auto: the static position, by alignment

for self-end alignment or its equivalent, Set its end-edge inset property to the static position, and its start-edge inset property to zero. Start is the reverse; center centers the room on the static position. treat normal as start and any baseline or stretch alignment value as its fallback alignment. In each stage, a blue block 40px tall comes before an orange box 20px tall whose top and bottom are auto.
