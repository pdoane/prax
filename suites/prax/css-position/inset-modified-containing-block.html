The inset-modified containing block

For an absolutely positioned box, the inset properties effectively reduce the containing block into which it is sized and positioned by the specified amounts. The resulting rectangle is called the inset-modified containing block. CSS Positioned Layout 3 §3.5 Each stage is relative, 160 by 80, the containing block. The orange box has inset: 10px 20px 20px 40px, which makes a rectangle from 40, 10 to 140, 60; the dashed outline is a second, empty box with the same insets.
