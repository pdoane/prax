CSS Positioned Layout 3 · 3.5.2 Resolving Overconstrained Insets

Insets that leave less than no room

If the inset-modified containing block size in any axis is less than zero, then the weaker inset in the affected axis is reduced to make it zero. With neither inset auto, the weaker inset is the inset of the end edge (where end is interpreted relative to the writing mode of the containing block). CSS Positioned Layout 3 §3.5.2
