Sticky positioning: the nearest scrollport

The insets are from the scrollport of the nearest scroll container with a matching scrollable axis. CSS Positioned Layout 3 §3.4 Each stage is scrolled 60px down; in it, a dashed block holds a light blue block 40px tall, then A, with top: 0.

The nearest scroll container, whether it scrolls or not

A single-axis scroll container

The sticky view rectangle can be constructed from edges of two different scrollports, if the nearest scroll container is a single-axis scroll container. If only one axis computes to a scrollable value (i.e. the other axis is clip), the box is a single-axis scroll container.
