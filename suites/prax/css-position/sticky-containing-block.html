CSS Positioned Layout 3 · 3.4 Sticky positioning

Sticky positioning: held inside the containing block

The box is shifted insofar as it can while its position box remains contained within its containing block. The position box is its margin box, except that for any side for which the distance between its margin edge and the corresponding edge of its containing block is less than its corresponding margin, that distance is used in place of that margin.
