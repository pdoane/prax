CSS Positioned Layout 3 · 2.1 Containing Blocks of Positioned Boxes

Containing blocks of fixed boxes

For a box with position: fixed, The containing block is established by the nearest ancestor box that establishes an fixed positioning containing block. If no ancestor establishes one, the box's fixed positioning containing block is the initial fixed containing block: in continuous media, the layout viewport. CSS Positioned Layout 3 §2.1

The layout viewport, not the initial containing block

Each frame's document is 300px tall, scrolled 30px down. A tinted box has inset: 0 and a dashed border.

The nearest ancestor that establishes one

A relative box establishes a containing block for absolute boxes only. Each frame holds a transformed dashed box, at 10, 10, and in it a relative tinted box at 40, 30; in that, an orange box with top: 0; right: 0.
