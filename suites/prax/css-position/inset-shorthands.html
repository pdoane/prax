The inset shorthands

inset: like margin, on the physical sides

The inset property is a shorthand property that sets all of the inset properties in a single declaration, assigning values to the longhands representing each side exactly as the margin property does for its longhands. CSS Positioned Layout 3 §3.2

inset-block and inset-inline: start, then end

The first component value sets the start side, the second sets the end; if omitted, the second value defaults to the first.
