Containing blocks from transforms

Properties that can cause a box to establish a fixed positioning containing block include transform, will-change, contain… CSS Positioned Layout 3 §2.1 In each frame, a static dashed box with the property named holds an orange fixed box and a blue absolute one, with top: 0; right: 0 and bottom: 0; left: 0.

Any transform, even one that moves nothing

any value other than none for the transform property also causes the element to establish a containing block for all descendants. CSS Transforms 1 §2 The individual transform properties too, all values but none (including “identity” transforms like translate: 0px). CSS Transforms 2 §5

Perspective, and boxes a transform does not apply to

perspective also establishes a containing block for all descendants, just like the transform property does. CSS Transforms 2 §8 A transform applies only to a transformable element, which a non-replaced inline box is not. CSS Transforms 1 §3
