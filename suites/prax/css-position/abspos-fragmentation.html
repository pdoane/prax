CSS Positioned Layout 3 · 4.4 Fragmenting Absolutely-positioned Elements

Absolutely positioned boxes in columns

In a fragmented flow, an absolutely positioned box is positioned relative to its containing block ignoring any fragmentation breaks (as if the flow were continuous). The box may subsequently be broken over several fragmentation containers. CSS Positioned Layout 3 §4.4 Each stage has two columns 100px tall and 90px wide; in them, a tinted relative block 200px tall, broken into the two columns, is the containing block of the orange box.
