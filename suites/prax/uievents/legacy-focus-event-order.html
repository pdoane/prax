The following is the typical sequence of events when a focus is shifted between elements, including the deprecated DOMFocusIn and DOMFocusOut events. UI Events §8.2.2

The order of Focus Event Order

This section's table puts focusin first, Sent before first target element receives focus: focusin, focus, DOMFocusIn; then focusout, focusin, blur, DOMFocusOut, focus, DOMFocusIn. §8.2.2 That was UI Events' order until its group resolved to specify the order that every browser ships (uievents#88), which Focus Event Order now gives: focus, focusin; then blur, focusout, focus, focusin; and DOMFocusIn and DOMFocusOut come after focus and blur. §3.3.2
