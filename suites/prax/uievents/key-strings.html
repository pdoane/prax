UI Events KeyboardEvent key Values · 2.1 Unicode Values

Key strings

A key string is a string containing a 0 or 1 non-control characters ("base" characters) followed by 0 or more combining characters. The string MUST be in Normalized Form C (NFC). UI Events KeyboardEvent key Values §2.1

Precomposed characters

"ô" = U+00F4 (NOT "o" + " ̂" (U+006F U+0302) because pre-composed characters must be used if available). The page's script lists the code points of each key value, as points. §2.1

Whitespace

With the exception of Tab and Enter (see § 2.1.1 Control Characters), all non-control whitespace Unicode characters are considered to be valid key strings. §2.1
