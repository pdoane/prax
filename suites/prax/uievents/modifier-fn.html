UI Events · 4.3.1 Modifier keys

A modifier that changes the key

In some cases, modifier keys change the key value for a key event. on some MacOS keyboards, the key labeled "delete" functions the same as the Backspace key on the Windows OS when unmodified, but when modified by the Fn key, acts as the Delete key, and the value of key will match the most appropriate function of the key in its current modified state.
