UI Events KeyboardEvent key Values · 2.1.1 Control Characters

Control characters by name

A small number of characters in the Unicode "Cc" General Category are supported as named key attribute values. UI Events KeyboardEvent key Values §2.1.1

Named, not characters

U+0008 is "Backspace", U+0009 "Tab", U+000D "Enter", U+001B "Escape", U+007F "Delete". The page's script cancels each keydown in the box, so Tab and Backspace stay in it. §2.1.1
