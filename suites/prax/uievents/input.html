input

A user agent MUST dispatch this event immediately after the DOM has been updated. UI Events §3.4.3.2

Too late to cancel

input is Cancelable No, and has no default action: the update has happened. The page's script calls preventDefault() on every input in the field. §3.4.3.2

Only when the DOM changed

input follows a key only for keys which have updated the DOM. §3.5.5
