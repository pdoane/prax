UI Events · 3.3.4.2 focus

focus

A user agent MUST dispatch this event when an event target receives focus. The focus MUST be given to the element before the dispatch of this event type. UI Events §3.3.4.2

The focus is already there

The page's script records which element has the focus, document.activeElement, as each event reaches the stage, as focused. When focus arrives, the element receiving the focus already has it. §3.3.4.2
