UI Events · 3.5.2 Keyboard Event Key Location

Where a key is

The location attribute can be used to disambiguate between key values that can be generated by different physical keys on the keyboard UI Events §3.5.2

Left and right, standard and numpad

The location distinguishes, for example, the left and right Shift key or the physical arrow keys vs. the numpad arrow keys (when NumLock is off). For all other keys not listed in this table, the location attribute MUST always be set to DOM_KEY_LOCATION_STANDARD. §3.5.2
