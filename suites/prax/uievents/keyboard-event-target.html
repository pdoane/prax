UI Events · 3.5.5 Keyboard Event Order

Where key events go

The event target of a key event is the currently focused element which is processing the keyboard activity. UI Events §3.5.5

Tab moves the target

The event target might change between different key events. For example, a keydown event for the Tab key will likely have a different event target than the keyup event on the same keystroke. §3.5.5

With nothing focused

If no suitable element is in focus, the event target will be the HTML body element if available, otherwise the root element. §3.5.5
