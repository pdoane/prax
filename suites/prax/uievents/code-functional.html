Functional keys

The functional keys (not to be confused with the function keys described later) are those keys in the alphanumeric section that provide general editing functions that are common to all locales (like Shift, Tab, Enter and Backspace). UI Events KeyboardEvent code Values §3.1.2

Left and right, and the input mode keys

Each functional key has a code of its own: "ShiftLeft" and "ShiftRight", "MetaLeft" for The Windows, ⌘, Command or other OS symbol key, "Backspace" Labelled Delete on Apple keyboards. even though some of these Japanese and Korean keys occupy the same physical location on the keyboard, they use different code values. The page's script draws the keys and cancels each keydown in the map, so that Tab, Space and the arrows stay in it; a pressed key turns blue, and stays tinted. §3.1.2
