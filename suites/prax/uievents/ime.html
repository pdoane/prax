UI Events · 4.3.3 Input Method Editors

An input method editor

Keyboard events cannot be used to determine the current state of the input method editor, which can be obtained through the data attribute of the CompositionEvent interface. UI Events §4.3.3

市, by way of 詩

The example types s and i, giving し; Convert gives 詩 (poem), Convert again 市 (city), and Accept commits it. The keys Convert and Accept MAY be replaced by others depending on the input device in use and the configuration of the IME, e.g., it can be respectively U+0020 (Space key) and Enter. §4.3.3
