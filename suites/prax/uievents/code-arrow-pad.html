The arrow pad

The arrow pad contains the 4 arrow keys. The keys are commonly arranged in an "upside-down T" configuration. UI Events KeyboardEvent code Values §3.3

The upside-down T

"ArrowDown", "ArrowLeft", "ArrowRight", "ArrowUp", all required. The page's script draws the keys and cancels each keydown in the map, so that Tab, Space and the arrows stay in it; a pressed key turns blue, and stays tinted. §3.3
