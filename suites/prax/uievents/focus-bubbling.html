UI Events · 3.3.4 Focus Event Types

Which focus events bubble

blur: This event type is similar to focusout, but does not bubble. focusin: This event type is similar to focus, but does bubble. UI Events §3.3.4

At an ancestor

Every focus event passes the parent of its target on the way down, in the capture phase; only focusin and focusout come back up to it. The page's script listens at the parent, #parent, in the bubbling phase, and lists what reaches it there in the second log. §3.3.4.3 §3.3.4.4
