A key's value: a string or a name

A key attribute value MUST always contain a value that falls into one of these two categories (even if the value is "Unidentified"). UI Events KeyboardEvent key Values §2

A character or a named key

A key value is either A key string that corresponds to the character typed by the user, taking into account the user's current locale setting, modifier state, and any system-level keyboard mapping overrides that are in effect, or A named key attribute value, as defined by the tables in this document. §2

Two keys, one value

It is acceptable for multiple keys on a keyboard to generate the same key attribute value. §2
