UI Events · 3.3.3 Document Focus and Focus Context

The document's focus and the system's

When switching between focus contexts, the document's currently focused element and focus ring normally remain in their current state. UI Events §3.3.3

Away and back

if a document has three focusable elements, with the second element focused, when a user changes operating system focus to another application and then back to the browser, the second element will still be focused within the document, and tabbing will change the focus to the third element. §3.3.3

Only the document's targets

the event target identified in the event details MUST only be part of the document or documents in the window, never a part of the browser or operating system, even when switching from one focus context to another. §3.3.3
