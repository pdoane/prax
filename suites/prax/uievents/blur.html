UI Events · 3.3.4.1 blur

blur

A user agent MUST dispatch this event when an event target loses focus. The focus MUST be taken from the element before the dispatch of this event type. UI Events §3.3.4.1

The focus is already gone

The page's script records which element has the focus, document.activeElement, as each event reaches the stage, as focused. When blur arrives, the element losing the focus no longer has it. §3.3.4.1
