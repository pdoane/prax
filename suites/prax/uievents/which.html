UI Events · 7.1.1 Interface UIEvent (supplemental)

which

User agents have traditionally included a which attribute so that KeyboardEvents and MouseEvents could record supplemental event info. The section is informative. UI Events §7.1.1

A mouse button

For MouseEvents, this contains a value equal to the value stored in button+1. §7.1.1

A key

For KeyboardEvents, this holds a system- and implementation-dependent numerical code signifying the unmodified identifier associated with the key pressed. In most cases, the value is identical to keyCode. §7.1.1
