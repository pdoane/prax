UI Events · 3.5.5 Keyboard Event Order

The order of keyboard events

The keyboard events defined in this specification occur in a set order relative to one another, for any given key UI Events §3.5.5

keydown, beforeinput, input, keyup

keydown; then beforeinput, for a key that produces a character value; then the key's default actions, such as inserting a character into the document; then input, for a key that updated the document; then keyup. §3.5.5
