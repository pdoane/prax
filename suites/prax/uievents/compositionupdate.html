UI Events · 3.6.7.2 compositionupdate

compositionupdate

A user agent SHOULD dispatch this event during a composition session when a text composition system updates its active text passage with a new character, which is reflected in the string in data. UI Events §3.6.7.2

Before the control changes

In text composition systems which keep the ongoing composition in sync with the input control, the compositionupdate event MUST be dispatched before the control is updated. The page's script records the field's value as each event reaches it, as value. §3.6.7.2

A canceled session

If the composition session is canceled, this event will be fired immediately before the compositionend event, and the data attribute will be set to the empty string. §3.6.7.2
