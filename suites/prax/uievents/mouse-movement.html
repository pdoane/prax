UI Events · 5.2.3 set PointerLock attributes for mousemove

How far the mouse moved

Each mousemove's movementX and movementY are how far the pointer moved since the last mousemove, and 0 for the first. UI Events §5.2.3

Since the last mousemove

Set event.movementX = event.screenX - last mouse move's x-coordinate; Set event.movementY = event.screenX - last mouse move's y-coordinate. §5.2.3
