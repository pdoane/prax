UI Events · 4.3.4 Default actions and cancelable keyboard events

Canceling a dead key

If the key is part of a sequence of several keystrokes, whether it is a dead key or it is contributing to an Input Method Editor sequence, the keystroke MUST be ignored (not taken into account) only if the default action is canceled on the keydown event. UI Events §4.3.4

A dead key canceled

Canceling a dead key on a keyup event has no effect on beforeinput or input events. The page's script cancels each keydown of a dead key in the field. §4.3.4
