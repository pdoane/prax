UI Events · 4.3.4 Default actions and cancelable keyboard events

Canceling a key

Canceling the default action of a keydown event MUST NOT affect its respective keyup event, but it MUST prevent the respective beforeinput and input (and keypress if supported) events from being generated. UI Events §4.3.4

A keydown canceled

The page's script cancels each keydown of q in the field. §4.3.4

A modifier still counts

If the key is a modifier key, the keystroke MUST still be taken into account for the modifiers states. The page's script also cancels each keydown of Shift in the box. §4.3.4
