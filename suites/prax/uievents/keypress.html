UI Events · 8.3.1.1 keypress

keypress

If supported by a user agent, this event MUST be dispatched when a key is pressed down, if and only if that key normally produces a character value. UI Events §8.3.1.1

Only for a key that types a character

This event type MUST be generated after the key mapping. It MUST NOT be fired when using an input method editor. §8.3.1.1

Canceled

If this event is canceled, it should prevent the input event from firing, in addition to canceling the default action. The page's script cancels each keypress in the field. §8.3.1.1
