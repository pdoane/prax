DOMFocusIn

A user agent MUST dispatch this event when an event target receives focus. The focus MUST be given to the element before the dispatch of this event type. This event type MUST be dispatched after the event type focus. It is deprecated, and a user agent need not support it. UI Events §8.2.1.1
