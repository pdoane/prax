UI Events · 4.3.2 Dead keys

A dead key aborted

This process might be aborted when a user types an unsupported base character (that is, a base character for which the active diacritical mark is not available) after pressing a dead key. UI Events §4.3.2

A letter the accent does not take

The specification's example: keydown of the letter with isComposing, compositionupdate and compositionend with no data, then the letter's keyup. §4.3.2
