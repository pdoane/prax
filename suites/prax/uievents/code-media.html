Media keys

Media keys are extra keys added to a keyboard that provide media related functionality like play, pause or volume control. These keys do not have a standard location on the keyboard. UI Events KeyboardEvent code Values §3.6

Merged with the function keys

On laptop keyboards, these keys are often merged with the function keys, with the media key interpretation being the primary function of the key and the function key interpretation requiring the Fn key to be pressed at the same time. In this configuration the code should be set to match the function key ("F1" ... "F12"). §3.6
