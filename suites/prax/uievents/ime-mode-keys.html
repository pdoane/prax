UI Events · 4.3.3.1 Input Method Editor mode keys

Keys that switch an input method

Some keys on certain devices are intended to activate input method editor functionality, or to change the mode of an active input method editor. UI Events §4.3.3.1

Kana and Hangul

When one of these keys is pressed, and no IME is currently active, the appropriate IME is expected to be activated in the mode indicated by the key (if available). The keys include "HangulMode", "KanaMode", "Hiragana" and "Alphanumeric". §4.3.3.1
