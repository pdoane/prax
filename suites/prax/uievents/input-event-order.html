UI Events · 3.4.2 Input Event Order

The order of input events

The input events defined in this specification MUST occur in a set order relative to one another. beforeinput, then DOM element is updated, then input. UI Events §3.4.2

Before and after the update

The page's script records the field's value as each event reaches it, as value. §3.4.2

In an editing host

The same order holds for any Element with contenteditable attribute enabled; the page's script records its text. §3.4.3.1
