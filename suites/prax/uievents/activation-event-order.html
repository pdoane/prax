UI Events · 8.1.2 Activation event order

The order of activation

If the DOMActivate event is supported by the user agent, then the events MUST be dispatched in a set order relative to each other: click, DOMActivate, then All other default actions, including the activation behavior. UI Events §8.1.2

By the mouse

The button submits its form, which is its activation behavior; the page's script cancels the submission, so the page stays. §8.1.2

By a key

If the focused element is activated by a key event: keydown, then click, default action; synthesized; isTrusted="true", then DOMActivate, then the activation behavior. §8.1.2
