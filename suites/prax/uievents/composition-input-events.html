UI Events · 3.6.6 Input Events During Composition

Input events in a composition

During the composition session, the compositionupdate MUST be dispatched after the beforeinput is sent, but before the input event is sent. UI Events §3.6.6

Each update

beforeinput, compositionupdate, then Any DOM updates occur at this point, then input. The page's script records the field's value as each event reaches it, as value. §3.6.6

Nothing at the end

Since there are no DOM updates associated with the compositionend event, beforeinput and input events should not be sent at that time. §3.6.6
