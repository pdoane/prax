UI Events KeyboardEvent code Values · 3.2 Control Pad Section

The control pad

The control pad section of the keyboard is the set of (usually 6) keys that perform navigating and editing operations, for example, Home, PageUp and Insert. UI Events KeyboardEvent code Values §3.2

Six keys, and Help

"Delete": The forward delete key. Note that on Apple keyboards, the key labelled Delete on the main part of the keyboard should be encoded as "Backspace". "Help": Not present on standard PC keyboards. The page's script draws the keys and cancels each keydown in the map, so that Tab, Space and the arrows stay in it; a pressed key turns blue, and stays tinted. §3.2
