UI Events · 4.3.2 Dead keys

Dead keys

The dead keys (across all keyboard layouts and mappings) are represented by the key value Dead. UI Events §4.3.2

A dead key and its letter

In response to any dead key press, composition events must be dispatched by the user agent and the compositionupdate event's data value must be the character value of the current state of the dead key combining sequence. §4.3.2
