UI Events · 3.1 List of Event Types

What each event type is

Each event MUST be associated with a type, called event type and available as the type attribute on the event object. Each type's definition says whether it bubbles and whether it is cancelable, and the user agent's own events are trusted. UI Events §3.1

Typing

keydown: Bubbles Yes, Cancelable Yes; beforeinput: Bubbles Yes, Cancelable Yes; input: Bubbles Yes, Cancelable No; keyup: Bubbles Yes, Cancelable Yes. §3.1

Moving the focus

focus and blur: Bubbles No; focusin and focusout: Bubbles Yes; all four: Cancelable No. §3.1
