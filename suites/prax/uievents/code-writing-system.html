UI Events KeyboardEvent code Values · 3.1.1 Writing System Keys

Writing system keys

The writing system keys are those that change meaning (i.e., they produce different key values) based on the current locale and keyboard layout. UI Events KeyboardEvent code Values §3.1.1

Named for the US key in that place

Wherever possible, the code names are based on the name for the US key in that position (i.e., they are based on the US keyboard layout). The "Digit2" and "KeyQ" keys are writing system keys that generate "2" and "q" when the US locale is active and "é" and "a" when the French locale is active. The page's script draws the keys and cancels each keydown in the map, so that Tab, Space and the arrows stay in it; a pressed key turns blue, and stays tinted. §3.1.1
