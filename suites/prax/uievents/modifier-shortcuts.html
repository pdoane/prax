UI Events · 4.3.1 Modifier keys

Modifiers that type nothing, and locks

Some modifiers are activated while the key is being pressed down or maintained pressed such as Alt, Control, Shift, AltGraph, or Meta. Other modifiers are activated depending on their state such as CapsLock, NumLock, or ScrollLock. UI Events §4.3.1

Control and a letter

With Control held, V gives key="v" with ctrlKey, and No beforeinput or input events are generated. §4.3.1

A lock's state

Change in the state happens when the modifier key is being pressed down. The page's script records getModifierState("CapsLock") as each event reaches the box, as capsLock. §4.3.1
