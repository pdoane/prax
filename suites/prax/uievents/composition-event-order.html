UI Events · 3.6.2 Composition Event Order

The order of composition events

The Composition Events defined in this specification MUST occur in the following set order relative to one another UI Events §3.6.2

A session

compositionstart, then any number of compositionupdate events, then compositionend. Conceptually, a composition session consists of one compositionstart event, one or more compositionupdate events, and one compositionend event, with the value of the data attribute persisting between each stage of this event chain during each session. §3.6
