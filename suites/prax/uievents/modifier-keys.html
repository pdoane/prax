UI Events · 4.3.1 Modifier keys

Modifier keys

Keyboard input uses modifier keys to change the normal behavior of a key. Like other keys, modifier keys generate keydown and keyup events UI Events §4.3.1

Shift and Q

The KeyboardEvent interface provides convenient attributes for some common modifiers keys: ctrlKey, shiftKey, altKey, metaKey. §4.3.1

Shift released first

The key value for the Q key will revert to its unshifted value for the keyup event when the Shift key is released before the Q key. §4.3.1
