UI Events · 3.5.1 Interface KeyboardEvent

KeyboardEvent

The KeyboardEvent interface provides specific contextual information associated with keyboard devices. Each keyboard event references a key using a value. UI Events §3.5.1

A key and its value

Keyboard events are commonly directed at the element that has the focus. key holds a key attribute value corresponding to the key pressed. code holds a string that identifies the physical key being pressed. §3.5.1

A key held down

Holding down a key MUST result in the repeating the events keydown, beforeinput, input in this order, at a rate determined by the system configuration. §3.5.1
