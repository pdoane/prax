UI Events · 3.6.5 Key Events During Composition

Keys during a composition

During the composition session, keydown and keyup events MUST still be sent, and these events MUST have the isComposing attribute set to true. UI Events §3.6.5

isComposing

The keydown that starts a composition has isComposing false; every key event after compositionstart has it true, up to the keydown that ends the composition; the keyup after compositionend has it false again. §3.6.5
