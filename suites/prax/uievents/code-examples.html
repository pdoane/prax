code when key changes

Regardless of the current locale or the modifier key state, pressing the key labelled 2 on a US keyboard always results in "Digit2" in the code attribute. UI Events §4.2.3

Shift released first

Note that the values contained in the key attribute does not match between the keydown and keyup events for the 2 key. The code attribute provides a consistent value that is not affected by the current modifier state. §4.2.3

The right Alt

Checking the code attribute permits matching the right Alt key (AltRight) without worrying about which layout is currently in effect. §4.2.3
