The function row

The function section runs along the top of the keyboard (above the alphanumeric section) and contains the function keys and a few additional special keys (for example, Esc and Print Screen). UI Events KeyboardEvent code Values §3.5

F1 to F12, whatever else they do

On some keyboards (especially those found on laptops or other portable computers), the function keys (F1 ... F12) are defined to have other primary functions (like controlling display brightness or audio volume) and require that a separate Fn key be pressed to make them act as function keys. Because of this, the code is always set to the function key name. The page's script draws the keys and cancels each keydown in the map, so that Tab, Space and the arrows stay in it; a pressed key turns blue, and stays tinted. §3.5
