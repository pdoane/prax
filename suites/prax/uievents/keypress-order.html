UI Events · 8.3.2 keypress event order

When keypress comes

The keypress event type MUST be dispatched after the keydown event and before the keyup event associated with the same key. UI Events §8.3.2

Before beforeinput

The text says The keypress event type MUST be dispatched after the beforeinput event and before the input event associated with the same key. §8.3.2 Since, the engines' developers have agreed to send keypress first, in the order that Chrome and Safari shipped and that Firefox's editing rests on, and the specification's editor took it into his key event algorithm (uievents#220).
