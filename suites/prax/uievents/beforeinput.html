UI Events · 3.4.3.1 beforeinput

beforeinput

A user agent MUST dispatch this event when the DOM is about to be updated. It is cancelable, and its default action is to Update the DOM element. UI Events §3.4.3.1

Canceled, nothing changes

The page's script cancels each beforeinput in the field whose data is a digit, so the field takes letters but no digits. §3.4.3.1

In an editing host

Its targets include any Element with contenteditable attribute enabled; the same script cancels digits there. §3.4.3.1
