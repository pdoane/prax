UI Events · 3.2.3.5 select

select

A user agent MUST dispatch this event when a user selects some text. This event is dispatched after the selection has occurred. UI Events §3.2.3.5

After the selection

The event's target is the element whose text content has been selected. The page's script records the field's selected text as each event reaches it, as selected. §3.2.3.5

In a text area

in [HTML5], select events can be dispatched only on form input and textarea elements. §3.2.3.5
