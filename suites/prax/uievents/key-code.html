UI Events · 7.3.1 How to determine keyCode for keydown and keyup events

keyCode for keydown and keyup

The keyCode for keydown or keyup events is calculated as follows. The section is informative. UI Events §7.3.1

Letters and digits

If input key when pressed without modifiers would insert a numerical character (0-9), return the ASCII code of that numerical character. If input key when pressed without modifiers would insert a lower case character in the a-z alphabetical range, return the ASCII code of the upper case equivalent. §7.3.1

Keys an input method takes

If an Input Method Editor is processing key input and the event is keydown, return 229. §7.3.1
