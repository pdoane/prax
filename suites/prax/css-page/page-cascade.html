CSS Paged Media 3 · 4.4 Cascading in the page context

Specificity of page selectors

Declarations in page and margin contexts cascade just like declarations in style rule for elements. CSS Paged Media 3 §4.4 The root's blue background marks each page area. Safari paints the root's background on the last page only as far down as the content.

Names, then :first and :blank, then :left and :right

Specificities are compared by comparing the three components in order (f, g, h): f counts page type names, g :first and :blank, h :left and :right.
