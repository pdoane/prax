CSS Paged Media 3 · 5.3.2.2 Resolving auto widths

Widths of the side boxes

If the middle box (B) is not generated, distribute the available width to A and C CSS Paged Media 3 §5.3.2.2 A is @top-left, in blue, and C @top-right, in orange, on pages with no margin at the sides, so the available width is 240px. A letter is 10px wide. Safari paints the root's background on the last page only as far down as the content.

One auto width

If only one box has 'width: auto', its used width is resolved so that the sum of the outer widths equals available width.

Two, in proportion to their content

If the sum of the outer max-content widths is less than the available width, call that difference the flex space. Each box gets its max-content width and a share of the flex space in proportion to it; Otherwise if the sum of the outer min-content widths is less than the available width, each gets its min-content width and a share in proportion to max-content minus min-content.
