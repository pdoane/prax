CSS Paged Media 3 · 3 The Page Model

The page box and the page area

As with other CSS boxes, a page box consists of margin, border, padding, and content areas. The content area of a page box is called the page area. CSS Paged Media 3 §3 In each figure the root's blue background marks the page area, and the pages are printed 240 by 160. Safari paints the root's background on the last page only as far down as the content.

Margin, border, padding and page area

The content of the document is flowed into one or more page boxes. The page background covers the page box; the document canvas, here blue, covers its border box.
