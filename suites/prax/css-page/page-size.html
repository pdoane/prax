CSS Paged Media 3 · 7.1 Page size: the size property

The size descriptor

This property specifies the target size and orientation of the page box's containing block. In the general case, where one page box is rendered onto one page sheet, the 'size' property also indicates the size of the destination page sheet. CSS Paged Media 3 §7.1 Safari paints the root's background on the last page only as far down as the content.

Lengths

If two length values are specified, the first establishes the page box width, and the second the page box height. If only one length value is specified, it sets both the width and height of the page box (i.e., the box is a square). The suite's pages use two lengths in px, as the stills read them.

Media names and orientation

A page size can be specified using one of the following media names. This is the equivalent of specifying 'size' using length values. A5 is 148mm wide and 210 mm high, A4 210 mm wide and 297 mm high, letter 8.5 inches wide and 11 inches high. The <page-size> names can be used in conjunction with 'landscape' or 'portrait' to indicate both size and orientation. size: A4 landscape sets the width of the page box to be 297mm and the height to be 210mm. At such sizes a page would not fit this sheet, so these are not printed here.
