CSS Paged Media 3 · 8.1 Using named pages: page

Named pages

The 'page' property is used to specify a particular type of page (called a named page) on which an element must be displayed. If necessary, a forced page break is introduced and a new page generated of the specified type. CSS Paged Media 3 §8.1 Pages of type wide have 40px margins; others 10px. Safari paints the root's background on the last page only as far down as the content.

A break where the type changes

If for any two boxes meeting at a class A break point, the end page value of the box preceding the break and start page value of the box succeeding the break do not match, then a page break is forced between the two boxes
