CSS Paged Media 3 · 6 Page Properties

Page properties

Properties that apply to the page-margin boxes can also be set within the page context: if inheritable or explicitly inherited (with the 'inherit' keyword in the margin context), they will inherit to the page-margin boxes. CSS Paged Media 3 §6 Safari paints the root's background on the last page only as far down as the content.

Inheritance

page-margin boxes inherit from the page context. The page context inherits from the root element. A page context that takes initial values instead is also conformant.

Units and percentages

When used on the 'font-size' property in the margin context, they are relative to the font of the page context. For right and left values, percentages are relative to the width of the containing block; for top and bottom values, percentages are relative to the height of the containing block.
