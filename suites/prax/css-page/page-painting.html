CSS Paged Media 3 · 3.1 Page Backgrounds and Painting Order

Page backgrounds and painting order

In the page model, the page background behaves similar to the root background: its background painting area is the bleed area, which covers the entire page box, including its margins (regardless of 'background-clip'). CSS Paged Media 3 §3.1

The page background

Page backgrounds are anchored within the page box's padding area by default However if 'background-attachment' is 'fixed' then the image is positioned relative to the page box including its margins The image is a 40 by 20 blue rectangle.

The canvas, then the content, then the page-margin boxes

The document canvas background is drawn as the page box's background: by default its background painting area covers the page box's border box. Page-margin boxes paint in order from @top-left-corner clockwise, and The 'z-index' property applies to page-margin boxes.
