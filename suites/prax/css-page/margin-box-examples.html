Page headers

The following is a collection of examples of page-margin box usage. CSS Paged Media 3 §5.4 Each page is 240 by 90 with a 40px top margin and none at the sides; its header text is 9px, room for four lines, and each header box is tinted. Safari paints the root's background on the last page only as far down as the content.

The specification's six headers

Because there are no contents defined for the top-center or the top-right page-margin boxes, the extent of the top-left page-margin box is allowed to cross the center of the page box.
