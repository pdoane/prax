CSS Paged Media 3 · 4.4 Cascading in the page context

Page contexts cascade

Page contexts cascade, so the following stylesheet would style pages with 25 millimeter margins and 14 point type in the page-margin boxes CSS Paged Media 3 §4.4 Safari paints the root's background on the last page only as far down as the content.

Declarations from several rules

Each declaration is cascaded on its own, so two rules that match a page both contribute to it.

Margin contexts cascade too

The specification's example: the first page will have blue text in the top-left page-margin box and green text in the top-right page-margin box, while subsequent pages will have red text in the page-margin boxes.
