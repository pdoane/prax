CSS Paged Media 3 · 4.2.3 Blank-page pseudo-class: :blank

The :blank page

The :blank pseudo-class matches content-empty pages that appear as a result of forced page breaks. CSS Paged Media 3 §4.2.3 Safari paints the root's background on the last page only as far down as the content.

The page a forced break leaves empty

break-before: right on a box that would start on a left page forces two breaks, so that it starts on a right page, and leaves a content-empty left page between them. The root's blue background marks each page area.

Also matched by :left or :right

A page matched by :blank can also be matched by other page pseudo-classes. :blank is the more specific, so its content: none removes the header.
