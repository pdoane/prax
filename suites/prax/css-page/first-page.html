CSS Paged Media 3 · 4.2.2 First-page pseudo-class: :first

The :first page

The :first pseudo-class matches the first printed page of a document. CSS Paged Media 3 §4.2.2 Safari paints the root's background on the last page only as far down as the content.

Only the first page

The specification's example: @page { margin: 2cm }, and a 10cm top margin on the first page, at the scale of these pages.
