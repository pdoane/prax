CSS Paged Media 3 · 5.3.2.3 Handling min-width and max-width

min-width and max-width of page-margin boxes

The 'min-width' and 'max-width' properties apply to page-margin boxes in the variable dimension like on normal elements, except that the three boxes on the same side are considered together. CSS Paged Media 3 §5.3.2.3 The pages have no margin at the sides: 240px across. Safari paints the root's background on the last page only as far down as the content.

The rules applied again

If the tentative used width of any of the three boxes is greater than 'max-width', the rules above are applied again, but this time using the computed value of 'max-width' as the computed value for 'width'. Likewise for 'min-width'.
