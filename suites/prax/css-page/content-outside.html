CSS Paged Media 3 · 3.2 Content outside the page box

Content outside the page box

When formatting content in the page model, some content may end up outside the page box. A specification for the exact formatting of such elements lies outside the scope of this document. CSS Paged Media 3 §3.2 Safari paints the root's background on the last page only as far down as the content.

Recommended principles

Content should be allowed slightly beyond the page box to allow pages to "bleed". User agents SHOULD avoid generating a large number of content-empty pages to honor the positioning of elements These are recommendations: the captions say what each browser does.

Content-empty pages

A Content-empty page is a page box whose page area contains no printable content other than backgrounds and/or borders. A page box whose page area contains generated content, or content whose visibility is hidden, or invisible content such as a zero-width space is not a content-empty page. The term decides which pages :blank matches, shown in §4.2.3.
