CSS Paged Media 3 · 7.5 Positioning the page box on the sheet

A page box smaller than the sheet

When the page box is smaller than the page sheet, the user agent should either center the page box on the sheet or position the page box in the upper left corner of the page sheet CSS Paged Media 3 §7.5 Safari paints the root's background on the last page only as far down as the content.
