Auto margins of page-margin boxes

If the 'margin-left' or 'margin-right' property of any of the three boxes computes to 'auto', the used value is zero. CSS Paged Media 3 §5.3.2.1 Each page has 30px margins above and below, none at the sides. Safari paints the root's background on the last page only as far down as the content.
