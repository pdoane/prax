CSS Paged Media 3 · 5.2 Populating page-margin boxes

Which page-margin boxes are generated

A page-margin box is generated if and only if the computed value of its 'content' property is not 'none'. Otherwise, no box is generated, as for elements with 'display: none'. CSS Paged Media 3 §5.2 Safari paints the root's background on the last page only as far down as the content.

content: normal computes to none

As with the :before and :after pseudo-elements, a specified 'content: normal' on a page-margin box computes to 'none'. The specification's example creates a green box in each corner of the page except the bottom-left corner.
