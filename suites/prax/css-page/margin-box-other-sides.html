CSS Paged Media 3 · 5.3.2.5 Boxes on other sides

Boxes on the other sides

The used values for @left-top, @left-middle and @left-bottom boxes are established by the same rules, with "width" replaced by "height", "left" by "top", "right" by "bottom" and "center" by "middle". CSS Paged Media 3 §5.3.2.5 Safari paints the root's background on the last page only as far down as the content.

Heights down the left and right

The pages have margins of 20px above and below and 40px at the sides, so the available height is 120px. Each box's content is one line, 20px tall.

Across the bottom

The used values for @bottom-left, @bottom-center and @bottom-right page-margin boxes are established by the same rules as for @top-left, @top-center, and @top-right, respectively.
