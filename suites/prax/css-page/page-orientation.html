CSS Paged Media 3 · 7.1.2 Rotating The Printed Page: the page-orientation property

page-orientation

After the page has been laid out, if the output medium supports rotation, this value indicates that the page must be displayed rotated a quarter turn to the left (counter-clockwise) of how it was laid out. CSS Paged Media 3 §7.1.2 A PDF supports rotation. Safari paints the root's background on the last page only as far down as the content.

Rotated after layout

Margin boxes and other positional things have no special interaction with this property; they'll be laid out as normal in the unrotated page, then rotated along with everything else.
