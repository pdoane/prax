CSS Paged Media 3 · 5.3.1 Page-Margin Box Layout Terminology

The containing blocks of page-margin boxes

For a corner page-margin box, it is the rectangle defined by the intersection of the two page margins meeting at that corner. For all other page-margin boxes, the containing block is the rectangle formed by the encapsulating page margin minus the containing blocks of the adjacent corners' page-margin boxes. CSS Paged Media 3 §5.3.1 Safari paints the root's background on the last page only as far down as the content.

Between the page's border edges

The available width is the distance between the page box's left right border edges: the page area with the page's padding and border. These pages have margins of 40px above and below and 30px at the sides, a 4px yellow border and 6px of padding.
