CSS Paged Media 3 · 5.1 At-rules for page-margin boxes

Margin at-rules

Page-margin boxes are created by margin at-rules inside the page context. A margin at-rule is an at-rule that identifies the page-margin box (e.g. @top-left) and a block of descriptors (said to be in the margin context). CSS Paged Media 3 §5.1 Safari paints the root's background on the last page only as far down as the content.
