CSS Paged Media 3 · 6.1 Page-based counters

The page and pages counters

A counter named page is automatically created and incremented by 1 on every page of the document, unless the 'counter-increment' property in the page context explicitly specifies a different increment for the page counter. Additionally, a counter named pages is automatically created by the UA. Its value is always the total number of pages in the document. CSS Paged Media 3 §6.1 Safari paints the root's background on the last page only as far down as the content.

pages cannot be changed

The value of pages cannot be manipulated: while 'counter-reset' and 'counter-increment' statements that set it are valid, they have no effect.
