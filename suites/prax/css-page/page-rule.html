CSS Paged Media 3 · 4.1 The @page Rule

The @page rule

Authors can specify various aspects of a page box, such as its dimensions, orientation, and margins, within an @page rule. CSS Paged Media 3 §4.1 The root's blue background marks each page area. Safari paints the root's background on the last page only as far down as the content.

Every page, or the pages its selectors match

@page rules without a selector list apply to every page. Other @page rules apply to pages that match at least one of their selectors. Properties declared within the page context apply to the page box.
