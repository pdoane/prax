CSS Paged Media 3 · 7.4 Rendering page boxes that do not fit a page sheet

A page box that does not fit the sheet

If a page box does not match the target page sheet dimensions, the user agent should do one of the following (in order of preference): Render the page box at the indicated size on a larger page sheet. Rotate the page box 90° if this will make the page box fit the page sheet. Scale the page box to fit the page sheet.
