CSS Paged Media 3 · 3.3 Page Progression

Page progression

In documents with a left-to-right page progression the first page of the document is a right page, and vice versa. CSS Paged Media 3 §3.3 In each figure, a left page has a 60px left margin and a right page a 60px right margin, the binding edges. Safari paints the root's background on the last page only as far down as the content.

From the principal writing mode

If text is laid out in horizontal lines, the page progression is the same as the inline base direction. If text is laid out in vertical lines, the page progression is the same as the block flow direction.
