CSS Paged Media 3 · 6 Page Properties

vertical-align in page-margin boxes

On page-margin boxes, the 'vertical-align' property behaves as specified for table cells. It always performs alignment in the vertical dimension, regardless of writing mode. CSS Paged Media 3 §6 Safari paints the root's background on the last page only as far down as the content.

As in a table cell

The pages have a 60px top margin, so each top box is 60px tall, and its one line is placed in it as a cell's content would be.
