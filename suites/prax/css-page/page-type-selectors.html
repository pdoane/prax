CSS Paged Media 3 · 4.2 Page selectors

Page type selectors

A page type selector is a case-sensitive CSS identifier. It matches pages of the named page type generated by the 'page' property. CSS Paged Media 3 §4.2 Each document's pages are 10px from the edges unless a rule matches them. Safari paints the root's background on the last page only as far down as the content.

A name matches pages of that type

A page selector is said to match a given page if and only if all of its components match the page.

auto never matches

A page type name of 'auto' (ASCII case-insensitive) does not make the rule invalid, but must never match.
