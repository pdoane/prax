Start and end page values

a start 'page' value and end 'page' value is determined for each box as the value (if any) propagated from its first or last child box (respectively), else the used value on the box itself. A child propagates its own start or end page value if and only if the 'page' property applies to it. CSS Paged Media 3 §8.1 Pages of type wide have 40px margins; others 10px.
