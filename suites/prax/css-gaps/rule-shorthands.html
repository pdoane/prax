CSS Gaps 1 · 4.4 Gap decoration shorthands

column-rule, row-rule and rule

These shorthand properties set values for the 'column-rule-width', 'column-rule-style', and 'column-rule-color' properties, or the 'row-rule-width', 'row-rule-style', and 'row-rule-color' properties, respectively. rule sets 'column-rule' and 'row-rule' to the same values. CSS Gaps 1 §4.4

Width, style and color in any order

A <gap-rule> is <line-width> || <line-style> || <color>; what it leaves out is reset to the initial value.
