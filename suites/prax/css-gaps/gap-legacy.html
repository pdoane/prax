CSS Gaps 1 · 2.4 Legacy Gap Properties

grid-row-gap, grid-column-gap and grid-gap

For compatibility with legacy content, these grid-prefixed names must be supported as follows: grid-row-gap, grid-column-gap and grid-gap each as a legacy name alias of row-gap, column-gap and gap. CSS Gaps 1 §2.4

The old names set the new properties

An alias is the same property under a second name, so it reaches every container the property applies to, and whichever of the two names comes later wins.
