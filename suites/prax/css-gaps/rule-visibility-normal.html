CSS Gaps 1 · 3.4 Gap decoration visibility, normal

rule-visibility-items: normal

normal, the initial value: Behavior depends on the type of container. CSS Gaps 1 §3.4

In a grid, and in multicol

In a grid, Behaves the same as 'all'. In multicol, On 'column-rule-visibility-items', behaves the same as 'between'. On 'row-rule-visibility-items', behaves the same as 'all'. Column rules are red, row rules black.
