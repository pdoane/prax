CSS Gaps 1 · 2.3 Percentages In gap Properties

Percentage gaps

'gap' always resolves percentages against the corresponding size of the content box of the element. When this size is definite, the behavior is well-defined and consistent across layout modes. CSS Gaps 1 §2.3

Against a definite size

Each container is the stage's 100px width; the last is 60px tall.

Against a size that depends on the gap

In Grid Layout ... cyclic percentage sizes resolve against zero for determining intrinsic size contributions, but resolve against the box’s content box when laying out the box’s contents. In Flex Layout ... Cyclic percentage sizes resolve against zero in all cases. The dashed frames float, sized by their 40px items.
