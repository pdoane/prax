Determining the segments

To determine a gap's segments, its endpoints are taken in order along it. Each segment starts at a start endpoint; while the union with the next pair is not discontiguous, and, for intersection, is flanked by spanning items, the segment takes in the next pair; then its ends are offset by the insets. CSS Gaps 1 §3.1.2.2

none: one segment, end to end

If break is 'none', a single segment runs from the first item in endpoints to the last, with no test for items in the way, and the insets apply to its two ends only. The items here are translucent.

normal and intersection: as many segments as it takes

With any other value, each segment is offset on its own, so a 5px inset shows where each one ends.
