CSS Gaps 1 · 2.3 Percentages In gap Properties

Percentage gaps in flex containers sized by their content

In Flex Layout ... Cyclic percentage sizes resolve against zero in all cases. CSS Gaps 1 §2.3 Each dashed frame is a flex container of 40 by 20px items whose size, in the gap's axis, comes from those items.

In the block axis

A container's auto height comes from its content, here and in its layout: each row-gap: 20% is 0, and the items touch.

In the inline axis

A min-content width comes from the items too: the column-gap: 50% is 0, so it is 40px and A and B touch.
