rule-overlap

This property sets the paint order for overlapping gap decorations. CSS Gaps 1 §3.5

Which is on top where they cross

Column rules are red, row rules black, each 6px wide.

In a flex container

A flex line's column rules meet the row rule where they end; with column-rule-inset: -8px they run on across it.
