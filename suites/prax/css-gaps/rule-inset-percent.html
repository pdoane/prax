CSS Gaps 1 · 3.3 Adjusting gap decoration endpoints, percentages

Percentage insets and overlap-join

The inset properties take <length-percentage> | overlap-join; Percentages are resolved against the crossing gap width. CSS Gaps 1 §3.3

Against the crossing gap, or joined

At a junction, the crossing gap width is the size of the gap junction in the same dimension as the gap in which the segment endpoint lies; at Other segment endpoints, The crossing gap width is '0'. For overlap-join, At a junction segment endpoint, the gap decoration extends into the gap junction by half the crossing gap width, plus half the used value of the crossing gap's 'column-rule-width' or 'row-rule-width'; At a cap segment endpoint, 'overlap-join' is treated as '0'. Each grid has rule-break: intersection; column rules are red, row rules black.
