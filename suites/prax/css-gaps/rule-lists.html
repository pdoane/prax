CSS Gaps 1 · 4.5 Lists of values and the repeat() notation

Lists of rule values and repeat()

Each of the properties in this section accepts a comma-separated list of values. Setting multiple values in this way allows for varying gap decorations within a given container. CSS Gaps 1 §4.5

A list, and an integer repeater

Each flexbox has ten items and nine gaps, with 6px solid rules. An integer repeater expands out to the list of values in the second argument, repeated as many times as specified by the first argument.

An auto repeater

An auto repeater will be used to fill in values for gaps that would not otherwise receive values from other parts of the list.
