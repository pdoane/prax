CSS Gaps 1 · 4.6 Assigning gap decoration values to gaps

Assigning values to gaps

Beginning from the first item in values and the first item in gaps, assign each value to the corresponding gap. If there are fewer values than gaps, repeat beginning from the first item in values, as many times as needed. CSS Gaps 1 §4.6

In placement order, across flex lines

Each flexbox has 6px column rules and column-rule-color: red, blue, green. Values go starting at the side where placement begins, and across flex lines the pattern does not restart at the beginning of each flex line.

With an auto repeater

Values before the auto repeater go to the first gaps, those after it to the last, in order; the repeater fills the rest. (The step reads using the first trailing count items in values, but the partition before it counts the items after the repeater, so those are the ones meant.)
