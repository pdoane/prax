CSS Gaps 1 · 4.7 Interpolation of list values

Interpolating lists of rule values

When interpolating 'repeat()' values, or lists of values for 'rule-color' or 'rule-width', the interpolation proceeds in two steps: Expand any integer repeater into its equivalent list of values, then Apply the repeatable list interpolation algorithm to the expanded lists. CSS Gaps 1 §4.7

Auto repeaters

When both from and to contain auto-repeaters, and the length of their segments match, each part interpolates with its counterpart; If the length of leading values in from and leading values in to don't match, we fall back to discrete interpolation.
