CSS Gaps 1 · 3.2 Break behaviors at intersections

rule-break in a grid

These properties set the behavior for breaking decorations within a given gap into segments at visible "T" or "cross" intersections formed by items in the container. rule-break sets 'column-rule-break' and 'row-rule-break' to the same value. CSS Gaps 1 §3.2

none, normal and intersection

Each grid has three rows of three, A spanning the first two columns; the items are translucent. Column rules are red, row rules black.
