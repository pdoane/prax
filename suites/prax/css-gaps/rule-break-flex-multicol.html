CSS Gaps 1 · 3.2 Break behaviors at intersections, flex and multicol

rule-break in flex and multicol

For normal, Behavior depends on the type of container. In flex containers it Behaves the same as 'none'. In multicol, On 'column-rule-break', behaves the same as 'intersection'. On 'row-rule-break', behaves the same as 'none'. CSS Gaps 1 §3.2

Flex

Two lines whose gaps do not line up. each flex line has its own distinct gaps between items, so a column rule never crosses a line. Column rules are red, row rules black.

Multicol

Rows of three columns from column-height: 20px; column-wrap: wrap.
