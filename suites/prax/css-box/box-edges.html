CSS Box Model 4 · 2.1 Boxes and Edges

Boxes and edges

The perimeter of each of the four areas (content, padding, border, and margin) is called an edge, and each edge can be broken down into a top, right, bottom, and left side. CSS Box Model 4 §2.1

marginborderpaddingcontent

A zero width puts two edges together

If the padding has zero width on a given side, the padding edge coincides with the content edge on that side. The same holds for the border edge where the border is zero, and the margin edge where the margin is.

The four boxes

The sides of each edge make a box: the content box, padding box, border box and margin box. Other properties lay out against them: a percentage width against the containing block's content box, an absolutely positioned box against its padding box.
