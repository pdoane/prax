Box-edge keywords on CSS boxes

The following <box> CSS keywords are defined for use in properties (such as 'transform-box' and 'background-clip') that need to refer to various box edges. CSS Box Model 4 §2.3

content-box, padding-box, border-box, margin-box

A 10px margin, dashed border and padding; background-clip says where the green background stops. Then a blue box with a 20px margin and a purple outline 6px outside its border, clipped with clip-path.

SVG's keywords on a CSS box

fill-box: (In a CSS box context, treated as content-box.) stroke-box and view-box: treated as border-box. Each purple box has a 60px content box and 20px of padding each side, so its border box is 100px; translateX(50%) moves it half its reference box's width.
