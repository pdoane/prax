CSS Box Model 4 · 2 The CSS Box Model

The box model: four areas

Each box has a content area (which contains its content-- text, descendant boxes, an image or other replaced element content, etc.) and optional surrounding padding, border, and margin areas; the size of each area is specified by corresponding properties, and can be zero (or in the case of margins, negative). marginborderpaddingcontent

Each area has its own size, and can be zero

The margin, border, and padding can be broken down into top, right, bottom, and left segments, each of which can be controlled independently by its corresponding property.

Backgrounds under content, padding and border; margins transparent

The background of the content, padding, and border areas of a box is specified by its 'background' properties. The border area can additionally be painted with a border style using the 'border' properties. Margins are always transparent.
