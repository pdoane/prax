CSS Box Model 4 · 3.3 Margins at Container Edges: the margin-trim property

margin-trim

This property allows the container to trim the margins of its children where they adjoin the container’s edges. It takes none | block | [ block-start || block-end ] and applies to block containers, multi-column containers. CSS Box Model 4 §3.3

The values

block-start, block-end: For in-flow boxes contained by this box, margins adjacent to the box’s specified edges are truncated to zero. block Computes to block-start block-end. Each dashed container holds A and B, each with margin: 20px 0.

In a multi-column container

Each container has two columns and margin-trim: block.
