CSS Box Model 4 · 2.1 Boxes and Edges, shaped edges

Shaped and unshaped edges

Properties like 'border-radius' can change the shape of the box’s edges as used for painting and clipping; these effects typically do not affect layout however. CSS Box Model 4 §2.1

Painting and clipping follow the shaped edge

Each box has border-radius: 40px and a 10px border, and holds a blue child 60px tall that fills its content box.

Layout follows the unshaped edge
