CSS Box Model 4 · 3.3 Margins at Container Edges: the margin-trim property, adjacency

margin-trim: alignment, floats, other containers

It applies to block containers, multi-column containers, and trims margins For in-flow boxes contained by this box. CSS Box Model 4 §3.3 Each dashed container holds A and B, each with margin: 10px 0.

Alignment does not change adjacency

Adjacency is not sensitive to space governed by box alignment. Each container is 90px tall with align-content: end.

Not floats, nor flex or grid items

Floats are not in flow. A flex or grid container is not a block container, so margin-trim: block does nothing on one in this draft, though an earlier draft trimmed their items.
