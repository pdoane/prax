Box-edge keywords on SVG elements

fill-box Refers to the object bounding box or its edges. stroke-box Refers to the stroke bounding box or its edges. view-box Refers to the nearest SVG viewport’s origin box, which is a rectangle with the width and height of the SVG viewport, positioned such that its top left corner is anchored at the coordinate system origin.
