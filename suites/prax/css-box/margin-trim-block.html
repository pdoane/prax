CSS Box Model 4 · 3.3.1 Trimming Block Container Content

margin-trim in a block container

For block containers specifically, 'margin-trim' discards: The block-start margin of a block-level first child, when trimming at the block-start edge. The block-end margin of a block-level last child, when trimming at the block-end edge. Any margin collapsed with these margins. CSS Box Model 4 §3.3.1 Each dashed container has margin-trim: block.

Margins collapsed with the trimmed ones

A trimmed margin also truncates any descendant margins collapsed with such a margin (but not its own, its siblings’, or its ancestors’).

Only block-level children

It has no effect on any margins of inline-level descendants.
