CSS Box Model 4 · 3 Margins

Margins

Margins surround the border edge of a box, providing spacing between boxes. Both sets of properties control the same set of margins: they are just different ways of indexing each side. CSS Box Model 4 §3

margin

One margin, two names

In a left-to-right box, margin-left and margin-inline-start are the same margin, so the later declaration wins; in a right-to-left one, margin-inline-start is the right margin.

Margins at a break are truncated

The section's note: margins adjoining a fragmentation break are sometimes truncated. When an unforced break occurs between or within in-flow boxes, any margins adjoining the break are truncated to zero. CSS Fragmentation 4 §5.2
