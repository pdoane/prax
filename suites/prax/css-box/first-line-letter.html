CSS Box Model 4 · 1.2 Module Interactions

Margins and padding on ::first-letter and ::first-line

All properties in this module apply to the ::first-line and ::first-letter pseudo-elements. CSS Box Model 4 §1.2 The tint is each pseudo-element's background, which covers its padding but not its margin.

::first-letter

Each stage's first letter is a 30px float, tinted.

::first-line

Each stage's first line is tinted. The first line's inline box takes the padding and margin at its start.
