CSS Box Model 4 · 3.1 Page-relative (Physical) Margin Properties, percentages

Margin percentages: the inline size, in every writing mode

Percentages: refer to logical width of containing block: its inline size, which is its width in horizontal writing and its height in vertical writing, whichever side the margin is on. CSS Box Model 4 §3.1 Each stage is 200px wide and 100px tall; the orange tint is the box's margin area.

Horizontal: of the width

Vertical: of the height
