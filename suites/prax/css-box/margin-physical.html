CSS Box Model 4 · 3.1 Page-relative (Physical) Margin Properties

margin-top, margin-right, margin-bottom, margin-left

These properties set the top, right, bottom, and left margin of a box, respectively. Each takes <length-percentage> | auto, and is 0 initially. CSS Box Model 4 §3.1

margin

Each side, and auto

Negative margins

Negative values for margin properties are allowed, but there may be implementation-specific limits.

Not on internal table elements

They apply to all elements except internal table elements, ruby base containers, and ruby annotation containers.
