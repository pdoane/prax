CSS Box Model 4 · 5 Borders

Borders

Borders fill the border area, to visually delineate the edges of the box. Both sets of properties control the same set of borders: they are just different ways of indexing each side. CSS Box Model 4 §5 CSS 2's chapter 8 pages walk the physical border properties; CSS Logical's, the flow-relative ones.

One border, two names

Each box declares a physical border property, then a flow-relative one, or the other way round. The later declaration wins where the two name the same side.
