Pointer Events · 11.3 Mouse Event Order

A target removed mid-click

If the target (e.g. the target element) is removed from the DOM during the mouse events sequence, the remaining events of the sequence MUST NOT be fired on that element. Pointer Events §11.3

Removed by its mousedown

If the target element is removed from the DOM as the result of a mousedown event, no events for that element will be dispatched for mouseup, click, or dblclick, nor any default activation events. However, the mouseup event will still be dispatched on the element that is exposed to the mouse after the removal of the initial target element. §11.3 A mousedown listener removes the box, and puts it back two seconds later.

Removed by its mouseup

Similarly, if the target element is removed from the DOM during the dispatch of a mouseup event, the click and subsequent events will not be dispatched. §11.3 A mouseup listener removes the box, and puts it back two seconds later.
