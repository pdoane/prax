Pointer Events · 7.3 Details of touch-action values

The pan values

The user agent MAY consider direct manipulation interactions that begin on the element only for the purposes of panning that starts in any of the directions specified by all of the listed values. Pointer Events §7.3

One axis

when panning is restricted to a single axis (for instance, with pan-x or pan-y), the axis cannot be changed during panning. §7.3 Each box starts scrolled to its middle. All four figures need a touch screen.

One direction to start

Once panning has started, the direction may be reversed by the user even if panning that starts in the reversed direction is disallowed. §7.3
