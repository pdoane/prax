Pointer Events · 3.3.7 pointercancel

pointercancel

The user agent MUST fire a pointer event named pointercancel when it detects a scenario to suppress a pointer event stream. Pointer Events §3.3.7

Where the pointer last was

The values of the following properties of the pointercancel event MUST match the values of the last dispatched pointer event with the same pointerId: width, height, pressure, tangentialPressure, tiltX, tiltY, twist, altitudeAngle, azimuthAngle, pointerType, isPrimary, and the coordinates inherited from Mouse Events. the event's cancelable attribute MUST be false. §3.3.7
