Pointer Events · 10 Compatibility mapping with mouse events

Compatibility mouse events

At a high level, compatibility mouse events are intended to be "interleaved" with their respective pointer events. The compatibility mapping with mouse events is an OPTIONAL feature of this specification. Pointer Events §10

Interleaved

Unless otherwise noted, the target of any mapped mouse event SHOULD be the same target as the respective pointer event §10

What canceling cannot prevent

Mouse events can only be prevented when the pointer is down. Hovering pointers (e.g. a mouse with no buttons pressed) cannot have their mouse events prevented. Compatibility mouse events can't be prevented when a pointer event EventListener is set to be passive [DOM]. §10 A listener cancels every pointermove over the first box; a passive one tries to cancel pointerdown over the second.
