Pointer Events · 3.3.10 gotpointercapture

gotpointercapture

The user agent MUST fire a pointer event named gotpointercapture when an element receives pointer capture. Pointer Events §3.3.10

At the capturing element, and the events after it

This event is fired at the element that is receiving pointer capture. Subsequent events for that pointer will be fired at this element. §3.3.10 A pointerdown listener captures the pointer to the box, which is green while it has capture.
