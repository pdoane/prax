Pointer Events · 11.4.11 mouseup

mouseup

A user agent MUST dispatch this event when a pointing device button is released over an element. Pointer Events §11.4.11

Over the element where it is released

detail: indicates the current click count incremented by one. §11.4.11

Outside the window

In some implementation environments, such as a browser, a mouseup event can be dispatched even if the pointing device has left the boundary of the user agent, e.g., if the user began a drag operation with a mouse button pressed. §11.4.11
