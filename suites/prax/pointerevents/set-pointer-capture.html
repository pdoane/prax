Setting pointer capture

Pointer capture is set on an element of type Element by calling the element.setPointerCapture(pointerId) method. Pointer Events §8.2

As if over the capturing element

For subsequent events of the pointer, the capturing target will substitute the normal hit testing result as if the pointer is always over the capturing target, and they MUST always be targeted at this element until capture is released. §4 A pointerdown listener on A captures the pointer; a box turns orange while it is hovered.

Only while a button is down

If the pointer is not in the active buttons state or the element's node document is not the active document of the pointer, then terminate these steps. §8.2 A pointerover listener on D asks for capture.
