Pointer Events · 11.4.7 mouseleave

mouseleave

A user agent MUST dispatch this event when a pointing device is moved off of the boundaries of an element and all of its descendent elements. Pointer Events §11.4.7

Not when moving onto a descendant

This event type is similar to mouseout, but differs in that does not bubble, and that it MUST NOT be dispatched until the pointing device has left the boundaries of the element and the boundaries of all of its children. §11.4.7 The log listens on outer alone, ignoring events that only pass through it on their way to inner.
