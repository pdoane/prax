Pointer Events · 3.3.3 pointerdown

pointerdown

The user agent MUST fire a pointer event named pointerdown when a pointer enters the active buttons state. Pointer Events §3.3.3

Entering the active buttons state

For mouse, this is when the device transitions from no buttons depressed to at least one button depressed. For touch, this is when physical contact is made with the digitizer. For pen, this is when the pen either makes physical contact with the digitizer without any button depressed, or transitions from no buttons depressed to at least one button depressed while hovering. §3.3.3 The page cancels the context menu over the box.

Canceling it

Authors can prevent the firing of certain compatibility mouse events by canceling the pointerdown event (if the isPrimary property is true). Note, however, that this does not prevent the mouseover, mouseenter, mouseout, or mouseleave events from firing. §3.3.3 A listener cancels pointerdown on the box.
