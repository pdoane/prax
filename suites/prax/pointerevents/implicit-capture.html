Pointer Events · 8.4 Implicit pointer capture

Implicit pointer capture

Inputs that implement direct manipulation interactions for panning and zooming (such as touch or stylus on a touchscreen) SHOULD behave exactly as if setPointerCapture was called on the target element just before the invocation of any pointerdown listeners. Pointer Events §8.4

A finger stays with what it touched

The hasPointerCapture API may be used (for instance, in a pointerdown listener) to determine whether this has occurred. §8.4 The log shows hasCapture where the target has capture as pointerdown's listeners run.

Released in pointerdown

If releasePointerCapture is not called for the pointer before the next pointer event is fired, then a gotpointercapture event will be dispatched to the target (as normal) indicating that capture is active. §8.4 A pointerdown listener on c releases the capture.
