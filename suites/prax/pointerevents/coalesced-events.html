Pointer Events · 9.1 Coalesced events

Coalesced events

For performance reasons, user agents may choose not to send a pointermove event every time a measurable property (such as coordinates, pressure, tangential pressure, tilt, twist, or contact geometry) of a pointer is updated. Pointer Events §9.1

The moves inside a move

For trusted pointermove and pointerrawupdate events, the list is a sequence of all PointerEvents that were coalesced into this event. As a result, the coalesced events lists for these events always contain at least one event. The coalesced events list MUST be chronologically sorted by timeStamp, so the first event will have the smallest timeStamp. §9.1
