Pointer Events · 8.1 Introduction

Pointer capture

Pointer capture allows the events for a particular pointer (including any compatibility mouse events) to be retargeted to a particular element other than the normal hit test result of the pointer's location. Pointer Events §8.1

A slider's thumb

Pointer capture can be set on the slider thumb element, allowing the user to slide the control back and forth even if the pointer slides off of the thumb. §8.1 Each thumb follows the pointermove and mousemove events that reach it while it is pressed; the first captures the pointer when pressed, the second does not.
