Pointer Events · 3.1.1.2 The button property

The button that changed

To identify button state transitions in any pointer event (and not just pointerdown and pointerup), the button property indicates the device button whose state change fired the event. Pointer Events §3.1.1.2

A number for each button

Left mouse, touch contact or pen contact: 0. Middle mouse: 1. Right mouse or pen barrel button: 2. X1 (back): 3. X2 (forward): 4. Pen eraser: 5. §3.1.1.2 The page cancels the context menu, the back and forward buttons' navigation, and the middle button's scrolling over the boxes.

No change: −1

Neither buttons nor touch/pen contact changed since last event: −1. §3.1.1.2 A mouse event's is set only for mousedown and mouseup: Set event.button to 0 §11.2.6
