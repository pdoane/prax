Pointer Events · 11.4.5 mousedown

mousedown

A user agent MUST dispatch this event when a pointing device button is pressed over an element. Pointer Events §11.4.5

The click count, plus one

detail: indicates the current click count incremented by one. For example, if no click happened before the mousedown, detail will contain the value 1 §11.4.5

Canceled: no selection, no drag

Many implementations use the mousedown event to begin a variety of contextually dependent default actions. These default actions can be prevented if this event is canceled. Some of these default actions could include: beginning a drag/drop interaction with an image or link, starting text selection, etc. §11.4.5 A listener cancels mousedown on the second line.
