Pointer Events · 11.4.6 mouseenter

mouseenter

A user agent MUST dispatch this event when a pointing device is moved onto the boundaries of an element or one of its descendent elements. Pointer Events §11.4.6

Not when moving onto a descendant

This event type is similar to mouseover, but differs in that it does not bubble, and MUST NOT be dispatched when the pointer device moves from an element onto the boundaries of one of its descendent elements. §11.4.6 Each log listens on outer alone, ignoring events that only pass through it on their way to inner.
