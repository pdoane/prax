Pointer Events · 3.1.1.1 Chorded button interactions

Chorded buttons

Pointer Events do not fire overlapping pointerdown and pointerup events for chorded button presses (depressing an additional button while another button on the pointer device is already depressed). Pointer Events §3.1.1.1

One pointerdown, two mousedowns

Instead, chorded button presses can be detected by inspecting changes to the button and buttons properties. In the Mouse Event model, each button press produces a mousedown and mouseup event. §3.1.1.1 The page cancels contextmenu over the box, so the right button opens no menu.
