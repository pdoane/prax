Pointer Events · 12 Wheel Events and interfaces

Wheel event transactions

Wheels are devices that can be rotated in one or more spatial dimensions, and which can be associated with a pointer device. Pointer Events §12

One target for a gesture

A user agent MUST create a wheel event transaction when the first wheel event is fired, so that all subsequent wheel events within a implementation-specific amount of time can be targetted at the same element. If a series of wheel events targetted in a scrollable element start above a child element, later events for the same user gesture may occur over the child element. §12
