Pointer Events · 10.1 Tracking the effective position of the legacy mouse pointer

One legacy mouse for two pointers

For compatibility with scripts relying on MouseEvents, the mouse transition events (mouseover, mouseout, mouseenter and mouseleave) SHOULD simulate the movement of a single legacy mouse input. Pointer Events §10.1

A mouse and a finger

Dispatch mouseover, mouseout, mouseenter and mouseleave events as per Mouse Events for a mouse moving from the current effective legacy mouse pointer position to T. Button 1 receives no pointerout event (because the "real" mouse pointer didn't leave the button rectangle within this period), but Button 1 receives a mouseout event when the effective position of the legacy mouse pointer moves to Button 2 on touch tap. §10.1
