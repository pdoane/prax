pointerType and pointerId

A unique identifier for the pointer causing the event. Indicates the device type that caused the event (such as mouse, pen, touch). Pointer Events §3.1

The same device, by persistentDeviceId

If the pointer is uniquely identifiable, the assigned persistentDeviceId to that pointing device will remain constant for the remainder of the session. The persistentDeviceId value of 0 MUST be reserved and used to indicate events whose generating device could not be identified. §3.1
