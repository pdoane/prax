Pointer Events · 11.3 Mouse Event Order

Mouse event order

Certain mouse events defined in this specification MUST occur in a set order relative to one another. Pointer Events §11.3

Into A, into B inside it, and out

When a pointing device is moved into an element A, and then into a nested element B and then back out again, the following sequence of events MUST occur: mouseover A, mouseenter A; mouseout A, mouseover B, mouseenter B; mouseout B, mouseleave B, mouseover A; mouseout A, mouseleave A. §11.3
