Pointer Events · 11.4.4 dblclick

dblclick

A user agent MUST dispatch this event when the primary button of a pointing device is clicked twice over an element. Pointer Events §11.4.4

Not stopped by canceling click

Canceling the click event does not affect the firing of a dblclick event. §11.4.4 A listener cancels every click on the box.

Only the primary button

Secondary buttons MUST NOT fire dblclick events. §11.4.4 The page cancels the context menu and the middle button's scrolling over the box.
