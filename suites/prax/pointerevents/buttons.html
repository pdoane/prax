Pointer Events · 3.1.1.3 The buttons property

The buttons held

The buttons property gives the current state of the device buttons as a bitmask (same as in MouseEvent, but with an expanded set of possible values). Pointer Events §3.1.1.3

A bit for each button

Left mouse, touch contact or pen contact: 1. Right mouse or pen barrel button: 2. Middle mouse: 4. X1 (back): 8. X2 (forward): 16. Pen eraser: 32. Mouse moved with no buttons pressed, Pen moved while hovering with no buttons pressed: 0. §3.1.1.3 The page cancels the context menu, navigation and middle-button scrolling over the box.
