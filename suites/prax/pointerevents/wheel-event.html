Pointer Events · 12.1 WheelEvent interface

WheelEvent

The WheelEvent interface provides specific contextual information associated with wheel events. Pointer Events §12.1

Deltas and their unit

In user agents where the default action of the wheel event is to scroll, the value MUST be the measurement along the y-axis (in pixels, lines, or pages) to be scrolled in the case where the event is not cancelled. The default value is DOM_DELTA_PIXEL (pixels). §12.1

Momentum after the fingers lift

This attribute must be true if this event is synthesized by the platform to simulate scroll inertia after the user has ended the physical scroll interaction (e.g. lifted the finger from a trackpad after a fling), and false otherwise. §12.1
