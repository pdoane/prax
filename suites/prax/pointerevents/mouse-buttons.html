Pointer Events · 11.1 MouseEvent interface

Mouse buttons

During mouse events caused by the depression or release of a mouse button, button MUST be used to indicate which pointer device button changed state. Pointer Events §11.1

button, and buttons

During any mouse events, buttons MUST be used to indicate which combination of mouse buttons are currently being pressed, expressed as a bitmask. For example, the value 3 indicates that the left and right button are currently both pressed, while the value 5 indicates that the left and middle button are currently both pressed. §11.1 The page cancels the context menu, navigation and middle-button scrolling over the box.

button is not updated by a move

The value of button is not updated for events not caused by the depression/release of a mouse button. In these scenarios, take care not to interpret the value 0 as the left button, but rather as the default value. §11.1
