Pointer Events · 11.4.9 mouseout

mouseout

A user agent MUST dispatch this event when a pointing device is moved off of the boundaries of an element or when the element is moved to be no longer underneath the primary pointing device. Pointer Events §11.4.9

To where it goes

the element whose bounds the mouse pointer is entering (in the case of a mouseout or mouseleave or focusout event) §11.1
