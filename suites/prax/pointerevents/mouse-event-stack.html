Pointer Events · 11.3 Mouse Event Order

Mouse events on stacked elements

Sometimes elements can be visually overlapped using CSS. In the following example, three elements labeled A, B, and C all have the same dimensions and absolute position on a web page. Element C is a child of B, and B is a child of A in the DOM Pointer Events §11.3

One over, three enters

When the pointing device is moved from outside the element stack to the element labeled C and then moved out again, the following series of events MUST occur: mouseover C, mouseenter A, mouseenter B, mouseenter C; then mouseout C, mouseleave C, mouseleave B, mouseleave A. The mouseover/mouseout events are only fired once, while mouseenter/mouseleave events are fired three times (once to each element). §11.3
