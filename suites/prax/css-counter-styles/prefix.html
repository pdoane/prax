CSS Counter Styles 3 · 3.3 Symbols before the marker: the prefix descriptor

The prefix descriptor

The 'prefix' descriptor specifies a <symbol> that is prepended to the marker representation. Prefixes come before any negative sign. CSS Counter Styles 3 §3.3

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

Before the representation, and before the sign

Not in counter()

Prefixes are only added by the algorithm for constructing the default contents of the ::marker pseudo-element; the prefix is not added automatically when the 'counter()' or 'counters()' functions are used.
