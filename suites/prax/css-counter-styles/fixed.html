CSS Counter Styles 3 · 3.1.2 Exhaustible Symbols: the fixed system

The fixed system

The fixed counter system runs through its list of counter symbols once, then falls back. Once the list of counter symbols is exhausted, further values cannot be represented by this counter style, and must instead be represented by the fallback counter style. CSS Counter Styles 3 §3.1.2

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

Once through, then the fallback

The first symbol value

When this system is specified, it may optionally have an integer provided after it, which sets the first symbol value. If it is omitted, the first symbol value is 1.
