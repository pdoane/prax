CSS Counter Styles 3 · 3.8 Marker characters: the symbols and additive-symbols descriptors

The symbols and additive-symbols descriptors

Counter symbols may be strings, images, or identifiers, and the three types can be mixed in a single descriptor. Counter representations are constructed by concatenating counter symbols together. Identifiers are rendered as strings containing the same characters. Images are rendered as inline replaced elements. CSS Counter Styles 3 §3.8

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

Strings and identifiers; hex escapes

Hex escapes, used in several of the counter styles defined in this specification, "eat" the following space, so two spaces must be put after a hex escape to separate it from the following one.

Images, 1em square by default; additive tuples

The default object size of an image counter symbol is a 1em by 1em square. Note: The <image> syntax in <symbol> is currently at-risk. Additive tuples pair a weight with a symbol.
