CSS Counter Styles 3 · 3.1.3 Repeating Symbols: the symbolic system

The symbolic system

The symbolic counter system cycles repeatedly through its provided symbols, doubling, tripling, etc. the symbols on each successive pass through the list. This system is defined only over strictly positive counter values. CSS Counter Styles 3 §3.1.3

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.
