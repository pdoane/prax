CSS Counter Styles 3 · 7.1.1 Limited-range Implementation (required)

Limited range: -9999 to 9999

The Korean and Japanese variants of these counter styles can, if limited to the range of -9999 to 9999, be expressed as @counter-style rules. Outside the implementation-supported range, the fallback is 'cjk-decimal'. CSS Counter Styles 3 §7.1

9999, then 10000 in cjk-decimal

A browser that implements the optional extended range (7.1.2) goes on past 9999 instead, as Chrome does for the Chinese and Korean styles (壹萬) and Firefox for all three here, its japanese-formal giving 壱萬.
