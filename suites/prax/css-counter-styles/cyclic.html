CSS Counter Styles 3 · 3.1.1 Cycling Symbols: the cyclic system

The cyclic system

The cyclic counter system cycles repeatedly through its provided symbols, looping back to the beginning when it reaches the end of the list. If there are N counter symbols and a representation is being constructed for the integer value, the representation is the counter symbol at index ( (value-1) mod N) of the list of counter symbols (0-indexed). CSS Counter Styles 3 §3.1.1

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

One symbol, and several

Zero and negative values

This system is defined over all counter values. The index is the mathematical remainder, never negative.
