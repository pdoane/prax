CSS Counter Styles 3 · 3.7 Defining fallback: the fallback descriptor

The fallback descriptor

The 'fallback' descriptor specifies a fallback counter style to be used when the current counter style can't create a representation for a given counter value. CSS Counter Styles 3 §3.7

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

Unknown names and loops: decimal

If the value of the 'fallback' descriptor isn't the name of any defined counter style, the used value of the 'fallback' descriptor is 'decimal' instead. Similarly, while following fallbacks to find a counter style that can render the given counter value, if a loop in the specified fallbacks is detected, the 'decimal' style must be used instead. A circle that is no loop is not an error.
