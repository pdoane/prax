CSS Counter Styles 3 · 3.5 Limiting the counter scope: the range descriptor

The range descriptor

The 'range' descriptor defines the ranges over which the counter style is defined. If a counter style is used to represent a counter value outside of its ranges, the counter style instead drops down to its fallback counter style. CSS Counter Styles 3 §3.5

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

A list of ranges, and infinite

This range is inclusive - it contains both the lower and upper bound numbers. The range of the counter style is the union of all the ranges defined in the list.

auto

For 'alphabetic' and 'symbolic' systems, the range is 1 to positive infinity. For 'extends' systems, the range is whatever 'auto' would produce for the extended system; if extending a complex predefined style the range is the style's defined range.
