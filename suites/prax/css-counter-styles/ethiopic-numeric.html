CSS Counter Styles 3 · 7.2 Ethiopic Numeric Counter Style: ethiopic-numeric

ethiopic-numeric

The ethiopic-numeric counter style is defined for all positive non-zero numbers. the 'range' is '1 infinite', the 'suffix' is "/ " (U+002F SOLIDUS followed by a U+0020 SPACE). CSS Counter Styles 3 §7.2
