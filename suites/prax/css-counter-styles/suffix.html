CSS Counter Styles 3 · 3.4 Symbols after the marker: the suffix descriptor

The suffix descriptor

The 'suffix' descriptor specifies a <symbol> that is appended to the marker representation. Suffixes are added to the representation after negative signs. Its initial value is ". ". CSS Counter Styles 3 §3.4

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.
