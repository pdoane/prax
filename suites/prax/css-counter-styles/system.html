CSS Counter Styles 3 · 3.1 Counter algorithms: the system descriptor

The system descriptor: one set of symbols, six algorithms

The 'system' descriptor specifies which algorithm will be used to construct the counter's representation based on the counter value. CSS Counter Styles 3 §3.1

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

symbols: a b c, values 1 to 5

Each list counts 1 to 5 with the symbols "a", "b" and "c" and the initial suffix ". ". The last has no system, whose initial value is symbolic.
