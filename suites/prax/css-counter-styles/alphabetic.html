The alphabetic system

The alphabetic counter system interprets the list of counter symbols as digits to an alphabetic numbering system, similar to the default 'lower-alpha' counter style, which wraps from "a", "b", "c", to "aa", "ab", "ac". Alphabetic numbering systems do not contain a digit representing 0. This system is defined only over strictly positive counter values. CSS Counter Styles 3 §3.1.4

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.
