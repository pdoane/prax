CSS Counter Styles 3 · 6.1 Numeric, decimal and roman

Numeric styles: decimal, roman, cjk-decimal

The following stylesheet uses the @counter-style rule to redefine all of the counter styles defined in CSS 2 and CSS 2.1. This stylesheet is normative-- UAs must include it in their UA stylesheet. The markers are inside; each item's text is its value in decimal. CSS Counter Styles 3 §6.1

Decimal, padded, and Han

cjk-decimal Han decimal numbers (e.g., 一, 二, 三, ..., 九八, 九九, 一〇〇). Its suffix is "、" and its range 0 and up.
