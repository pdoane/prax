The symbols() function

The symbols() function defines an anonymous counter style with no name, a 'prefix' of '""' (empty string) and 'suffix' of '" "' (U+0020 SPACE), a 'range' of 'auto', a 'fallback' of 'decimal', a 'negative' of '"\2D"' ("-" hyphen-minus), a 'pad' of '0 ""', and a 'speak-as' of 'auto'. or 'symbolic' if the system was omitted. CSS Counter Styles 3 §4

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.
