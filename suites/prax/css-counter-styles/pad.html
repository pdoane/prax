CSS Counter Styles 3 · 3.6 Zero-Padding and Constant-Width Representations: the pad descriptor

The pad descriptor

The 'pad' descriptor allows an author to specify a "fixed-width" counter style, where representations shorter than the pad value are padded with a particular <symbol>. Representations larger than the specified pad value are constructed as normal. CSS Counter Styles 3 §3.6 The stages are in .pr-measure's monospace, every character 10px.

Where an outside marker sits is not specified (CSS Lists and Counters 3 §3.5): Safari sets the markers about 6px further from the text than Chrome and Firefox.

The example

This will cause, for example, 1 to be represented as "001", 20 to be represented as "020", 300 to be represented as "300", 4000 to be represented as "4000", and -5 to be represented as "-05".
