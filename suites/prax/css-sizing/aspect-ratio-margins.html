CSS Box Sizing 4 · 4.2.1 Margin-collapsing

aspect-ratio and collapsing margins

For the purpose of margin collapsing, if the block axis is the ratio-dependent axis, it is not considered to have a computed block-size of auto. CSS Box Sizing 4 §4.2.1 A box whose height is auto and is empty collapses its own top and bottom margins together; one whose height comes from its ratio does not, even when that height is zero.

An empty box of zero width between A and B

Between A and B is an empty block of width: 0; margin: 20px 0, outlined red.
