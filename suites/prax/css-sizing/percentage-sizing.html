CSS Box Sizing 3 · 4.1 Percentage Sizing

Percentage sizing

Percentages specify sizing of a box with respect to the box’s containing block. CSS Box Sizing 3 §4.1

A percentage of a percentage

The spec's example, at 160px: an article of height: 160px holds a figure of height: 50%, which holds an image of height: 50%. the <figure> would be 30em tall = 50% of the definite 60em height of the <article>; the <img> would be 15em tall = 50% of the <figure>’s height (which is itself definite because it's a percentage resolved against a definite length).
