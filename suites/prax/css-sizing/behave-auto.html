CSS Box Sizing 3 · 3.2.1 “Behaving as auto”

Behaving as auto

To have a common term for both when width/height computes to auto and when it is defined to behave as if auto were specified (as in the case of block percentage heights resolving against an indefinite size, see CSS2§10.5), the property is said to behave as auto in both of these cases. CSS Box Sizing 3 §3.2.1

A percentage height against an indefinite height

In each stage, a dashed parent holds a box of height: 50%.

As auto, not as zero

Behaving as auto is not the same as resolving against zero.
