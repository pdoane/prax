CSS Box Sizing 3 · 5.2.1 Intrinsic Contributions of Percentage-Sized Boxes, replaced

Cyclic percentages in replaced elements

If the box is replaced, a cyclic percentage in the value of any max size property or preferred size property (width/max-width/height/max-height), is resolved against zero when calculating the min-content contribution in the corresponding axis. For the max-content contribution, the whole value is treated as that property’s initial value.
