CSS Box Sizing 3 · 3.1.3 Maximum Size Properties

max-width, max-height, max-inline-size and max-block-size

The max-width and max-height (physical) and max-inline-size and max-block-size (flow-relative) are sizing properties that specify the maximum width (“max width”) and maximum height (“max height”) or maximum inline size (“max inline size) and maximum block size (“max block size) of the box, respectively.
