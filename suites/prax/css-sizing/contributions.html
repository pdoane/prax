CSS Box Sizing 3 · 2.2 Intrinsic Size Contributions

Contributions are outer sizes

Intrinsic size contributions are based on the outer size of the box; for this purpose auto margins are treated as zero. CSS Box Sizing 3 §2.2

Margins count, auto margins as zero

Each dashed float shrinks to the contribution of the blue block in it, a block of width: 60px; the float's width reads back below.
