CSS Box Sizing 4 · 4.2 Effects of Preferred Aspect Ratio on Automatic Sizes

The ratio-dependent axis

When a box has a preferred aspect ratio, its automatic sizes are calculated the same as for a replaced element with a natural aspect ratio and no natural size in that axis. The axis in which the preferred size calculation depends on this aspect ratio is called the ratio-dependent axis, and the resulting size is definite if its input sizes are also definite.
