Stretch-fit sizing: widths

Stretch-fit sizing tries to set the box’s used size to the length necessary to make its principal box’s outer size as close to filling the containing block as possible while still respecting the constraints imposed by min-height/min-width/max-height/max-width. CSS Box Sizing 3 §4.2

The margin box fills the containing block

Sizes the margin box to fill the containing block exactly, treating auto margins as zero. Each stage is 150px wide.
