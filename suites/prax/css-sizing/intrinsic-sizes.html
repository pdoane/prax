CSS Box Sizing 3 · 5.1 Intrinsic Sizes

Intrinsic sizes: a float in a zero or infinite space

The min-content size of a box in each axis is the size it would have if it was a float given an auto preferred size in that axis (and no minimum or maximum size in that axis) and if its containing block was zero-sized in that axis. The max-content size likewise, if its containing block was infinitely-sized in that axis. CSS Box Sizing 3 §5.1

Without the box's own limits

The intrinsic sizes leave out the box's own minimum and maximum; a keyword then meets them as any width does.
