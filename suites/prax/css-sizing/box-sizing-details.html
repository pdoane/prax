CSS Box Sizing 3 · 3.3 Box Edges for Sizing: the box-sizing property, its reach

What box-sizing affects

box-sizing affects the interpretation of all sizing properties, including flex-basis. Values affected by box-sizing include both raw <length-percentage> values and those used in functional notations such as fit-content(). In contrast, non-quantitative values such as auto and min-content are not influenced by the box-sizing property.
