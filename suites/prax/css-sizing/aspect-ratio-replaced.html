CSS Box Sizing 4 · 4.1 Preferred Aspect Ratios, replaced elements

aspect-ratio on replaced elements

The property allows altering the effective aspect ratio of replaced elements. CSS Box Sizing 4 §4 With auto && <ratio>, the preferred aspect ratio is the specified ratio of width / height unless it is a replaced element with a natural aspect ratio, in which case that aspect ratio is used instead. §4.1

An image 80 by 40 by nature, 2:1, at width: 60px

Only a natural width, or nothing

If a replaced element's only natural dimension is a natural width or a natural height, giving it a preferred aspect ratio also gives it an natural height or width, whichever was missing, by transferring the existing size through the preferred aspect ratio. These SVGs have width='80' and no height or viewBox.
