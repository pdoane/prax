The keywords in width

stretch Applies stretch-fit sizing, attempting to match the size of the box’s margin box to the size of its containing block. min-content: Use the min-content size in the relevant axis; max-content: Use the max-content size; fit-content: Use the fit-content size in the relevant axis, i.e. min(max-content, max(min-content, stretch)).
