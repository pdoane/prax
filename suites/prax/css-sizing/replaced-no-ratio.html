CSS Box Sizing 3 · 5.1 Intrinsic Sizes, no ratio

Replaced elements with neither a ratio nor a size

If it has no preferred aspect ratio: For both the min-content size and max-content size: If the box has a <length> as its computed minimum size (min-width/min-height) in that dimension, use that size. Otherwise, use 300px for the width and/or 150px for the height as needed.
