CSS Box Sizing 3 · 3.1.2 Minimum Size Properties

min-width, min-height, min-inline-size and min-block-size

The min-width and min-height (physical) and min-inline-size and min-block-size (flow-relative) are sizing properties that specify the minimum width (“min width”) and minimum height (“min height”) or minimum inline size (“min inline size”) and minimum block size (“min block size”) of the box, respectively.
