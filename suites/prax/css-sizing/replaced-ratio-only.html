CSS Box Sizing 3 · 5.1 Intrinsic Sizes, a ratio and no size

Replaced elements with only a ratio

For a replaced element without natural sizes, If it has a non-degenerate preferred aspect ratio: For the min-content size, use zero. For the max-content size, the stretch fit into a definite available space; Otherwise if the box has a <length> as its computed value for min-width or min-height, use that size and calculate the other dimension using the aspect ratio; Otherwise use an inline size matching the corresponding dimension of the initial containing block.
