CSS Box Sizing 3 · 3.2.2 Containing or Excluding Floats

Containing and excluding floats

Although block box boundaries are typically pervious to floats, sometimes an author needs them to contain their own (descendant) floats or to exclude floats from outside. For Block layout, specifying display: flow-root will make the box a formatting context root, which has this behavior. CSS Box Sizing 3 §3.2.2
