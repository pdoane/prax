Stretch-fit, min-content, max-content and fit-content

The fit-content size is, If the available space in a given axis is definite, equal to clamp(min-content size, stretch-fit size, max-content size). CSS Box Sizing 3 §2.1 Text here is PR Cousine at 15px, 9px a character: "abc def ehg" is 99px on one line, and its widest word 27px.

fit-content in three containing blocks

The spec's example: div > div { width: fit-content; } in containing blocks of 2ch, 9ch and 16ch, each ending at the red dashed line. In the narrowest containing block (2ch), the box takes its min-content size; In the middle containing block (9ch), the box takes its stretch-fit size; In the widest containing block (16ch), the box takes its max-content size.
