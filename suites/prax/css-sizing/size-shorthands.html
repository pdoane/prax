CSS Box Sizing 4 · 3.1 Sizing Properties

size, min-size and max-size

The size property is a shorthand that sets width and height in a single declaration. If the second value is omitted, it is copied from the first. min-size and max-size do the same for the minimums and maximums. CSS Box Sizing 4 §3.1 Each stage is 150 by 70.
