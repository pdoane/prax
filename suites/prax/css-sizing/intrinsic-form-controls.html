CSS Box Sizing 3 · 5.1 Intrinsic Sizes, text inputs

Form controls sized to their text

The min-content and max-content keywords of the sizing properties thus represent content-based sizes for form controls which render their value as text contained within their box. If the input control has designated placeholder text to be overlaid in its value display area, then that text is also measured.
