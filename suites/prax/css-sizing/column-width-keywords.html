CSS Box Sizing 3 · 3.4 New Column Sizing Values

column-width: the sizing keywords

When used as values for column-width, the new keywords specify the optimal column width. The column width never varies by column. When the column width is informed by the multi-column container's contents (as in the keywords above), all of its contents are taken under consideration and the calculated width is shared by all the columns. Optimal widths from the contents

Each stage is a multi-column container 200px wide with column-gap: 10px and red rules between columns, holding six orange lines of "abc def" (63px, its words 27px). As many columns as fit at the optimal width are made, then widened to fill the container.
