CSS Box Sizing 4 · 5.6 New Column Sizing Values: fit-content()

column-width: fit-content()

fit-content(<length-percentage>) Specifies the optimal column width as min(max-content size, max(min-content size, <length-percentage>)). CSS Box Sizing 4 §5.6 Level 4 adds the function to level 3's keywords, which column-width-keywords shows.
