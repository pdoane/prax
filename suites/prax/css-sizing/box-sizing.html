CSS Box Sizing 3 · 3.3 Box Edges for Sizing: the box-sizing property

box-sizing: content-box and border-box

The box-sizing property defines whether fixed sizes (such as <length>s and <percentage>s) are assigned to the content box or to the border box. CSS Box Sizing 3 §3.3
