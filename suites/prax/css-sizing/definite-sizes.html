CSS Box Sizing 3 · 2 Terminology

Definite and indefinite sizes

A definite size is A size that can be determined without performing layout; that is, a <length>, a measure of text (without consideration of line-wrapping), a size of the initial containing block, or a <percentage> or other formula (such the “stretch-fit” sizing of non-replaced blocks) that is resolved solely against definite sizes. A percentage resolves against a definite size

Each dashed parent holds an orange block of height: 50%, which is its 20px line where the percentage does not resolve.

Keywords are indefinite; an absolute box's containing block is definite

intrinsic sizing keywords such as max-content are indefinite, even if they can be determined without laying out the children. Additionally, the size of the containing block of an absolutely positioned element is always definite with respect to that element.
