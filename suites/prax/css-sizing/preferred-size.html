CSS Box Sizing 3 · 3.1.1 Preferred Size Properties

width, height, inline-size and block-size

The width and height (physical) and inline-size and block-size (flow-relative) are sizing properties that specify the preferred width and height (physical) or inline size and block size (flow-relative) of the box, respectively. They apply to all elements except non-replaced inlines. CSS Box Sizing 3 §3.1.1
