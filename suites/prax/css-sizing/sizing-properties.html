CSS Box Sizing 3 · 3.1 Sizing Properties

Sizing properties: the minimum wins

In CSS, while the minimum and maximum sizes both constrain the used size, the minimum size constraint is always the strongest constraint. Furthermore, the inner size is always floored at zero. CSS Box Sizing 3 §3.1

Minimum over maximum over preferred

Flow-relative variants follow the element's own writing mode

The flow-relative variants (inline-size, block-size, etc.) are mapped using the writing mode of the element itself. Each blue box has inline-size: 120px; block-size: 30px.
