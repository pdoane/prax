CSS Box Sizing 3 · 5.2 Intrinsic Contributions, replaced elements

Contributions of images without a natural size

A box’s min-content contribution/max-content contribution in each axis is the size of the content box of a hypothetical auto-sized float that contains only that box, if that hypothetical float's containing block is zero-sized/infinitely-sized. CSS Box Sizing 3 §5.2 In an infinite space an image with only a ratio takes its max-content size, which is an inline size matching the corresponding dimension of the initial containing block, 600px here; with no ratio, 300px or a length minimum. §5.1 Each dashed parent sizes itself to the image, and its width reads back below; the stages clip.
