CSS Box Sizing 3 · 3.2 Sizing Values, as limits

The keywords as minimums and maximums

The keywords are values of the minimum and maximum size properties as well. Using the min-width or max-width property in place of width here would apply these same sizes as the minimum width or maximum width (respectively), constraining the preferred width to find the used width.
