Lengths, percentages, auto and none

<box-size> = <length-percentage [0,∞]> | stretch | min-content | max-content | fit-content. A <length-percentage> Specifies the size of the box using <length> and/or <percentage>. Percentages are resolved against the width/height, as appropriate, of the box's containing block. CSS Box Sizing 3 §3.2
