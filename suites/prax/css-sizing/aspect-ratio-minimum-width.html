CSS Box Sizing 4 · 4.3 Automatic Content-based Minimum Sizes, inline axis

The content-based minimum, in the inline axis

This automatic minimum operates in both axes. The width of the container, being auto, resolves through the aspect ratio to 100px. However, its min-width, being auto, resolves to 150px. The resulting width of the container is thus 150px. To ignore the contents when sizing the container, min-width: 0 can be specified. CSS Box Sizing 4 §4.3

The spec's example

A blue height: 100px; aspect-ratio: 1 / 1 box, as a float so that its width is auto and not stretched, holds orange inline-blocks 50px and 150px wide.

A scroll container has no such minimum
