CSS Box Sizing 3 · 5.2 Intrinsic Contributions, sizes

Contributions of sized images

A contribution is the size of a hypothetical auto-sized float that contains only that box. For this purpose, stretch self-alignment and stretch-fit sizing (when they are able to resolve extrinsically) are considered definite the same way as resolveable percentages.
