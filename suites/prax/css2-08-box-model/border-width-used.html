CSS 2 · 8.5.1 Border width

Border width: no style, as a used value

CSS 2 makes a border's computed width 0 when its style is none or hidden. The border still takes no room, but the width it computes to, which a child can inherit, is now the one given.

Since CSS 2 · CSS Borders and Box Decorations 4 §2.3 (Editor's Draft)

The used width is 0, the computed width is kept

If the border-style corresponding to a given border-width is none or hidden, then the used width is 0. CSS Borders and Box Decorations 4 §2.3 The published draft of March 2024 still zeroes the computed value; the editor's draft moved it to the used value. In each figure the dashed parent has border-width: 20px; border-style: none.
