CSS 2 · 8.5.1 Border width

Border width: no style, and the initial value

border-*-width and border-width take thin | medium | thick | <length>. Every figure's border is solid unless it says otherwise.

A border with no style has no width

The computed width is 0 if the border style is none or hidden, so the border takes no room. Each box below has border-width: 20px. CSS 2 §8.5.1, §8.5.3
