CSS 2 · 8.3.1 Collapsing margins

Adjoining margins: parent and child

Adjoining vertical margins collapse into one. Every box is 20px tall and the guides are 10px apart. A dashed outline is a parent, which has no border or padding.

A box and its first child

The top margin of a box and top margin of its first in-flow child adjoin. The combined margin is outside the parent, so the parent starts where its child does. CSS 2 §8.3.1

A box and its last child

The bottom margin of a last in-flow child and bottom margin of its parent if the parent has 'auto' computed height adjoin. CSS 2 §8.3.1
