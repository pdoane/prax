CSS 2 · 8.3.1 Collapsing margins

What keeps margins apart: clearance and the root

Margins adjoin only if no line boxes, no clearance, no padding and no border separate them, and both boxes are in flow in one block formatting context. Every box is 20px tall; the guides are 10px apart.

Clearance

A box with clearance is moved below a float, and its top margin no longer adjoins its parent's. CSS 2 §8.3.1, §9.5.2

The root element

Margins of the root element's box do not collapse. The frame holds a document whose root and body both have top margins. CSS 2 §8.3.1
