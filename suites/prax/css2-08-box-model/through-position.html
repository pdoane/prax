CSS 2 · 8.3.1 Collapsing margins

Collapsing through a box: its position

If the top and bottom margins of a box are adjoining, then it is possible for margins to collapse through it. A dashed outline is such a box. Every named box is 20px tall; the guides are 10px apart.

Where the box is

A box that margins collapse through still has a position, which its descendants are laid out from: here a red float, which marks the box's top border edge. If the element's margins are collapsed with its parent's top margin, the top border edge of the box is defined to be the same as the parent's. Otherwise, either the element's parent is not taking part in the margin collapsing, or only the parent's bottom margin is involved. The position of the element's top border edge is the same as it would have been if the element had a non-zero bottom border. CSS 2 §8.3.1

Note that the positions of elements that have been collapsed through have no effect on the positions of the other elements with whose margins they are being collapsed; the top border edge position is only required for laying out descendants of these elements.
