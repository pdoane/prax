CSS 2 · 8.4 Padding properties

Padding: lengths

padding-top, padding-right, padding-bottom, padding-left and the shorthand padding. Each takes <length> | <percentage>. Initial 0, not inherited, and the computed value is the percentage as given or the absolute length.

paddingcontent
