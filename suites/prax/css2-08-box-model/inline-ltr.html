CSS 2 · 8.6 The box model for inline elements in bidirectional context

Inline boxes in bidirectional text: ltr

For each line box, UAs must take the inline boxes generated for each element and render the margins, borders and padding in visual order (not logical order). The element in each figure has a red 6px left border and a blue 6px right one.

direction: ltr

When the element's 'direction' property is 'ltr', the left-most generated box of the first line box in which the element appears has the left margin, left border and left padding, and the right-most generated box of the last line box in which the element appears has the right padding, right border and right margin.
