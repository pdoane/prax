CSS 2 · 8.1 Box dimensions

Box dimensions: size

Each box has a content area and optional padding, border and margin areas around it, drawn here in the colors browsers' inspectors use.

marginborderpaddingcontent

A box's size is the sum of its areas

The width of the margin box is the content width plus the left and right padding, border and margin; its height is the same sum in the vertical. The grey bar below each box is the size it is to have. CSS 2 §8.1
