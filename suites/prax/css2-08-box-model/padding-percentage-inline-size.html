CSS 2 · 8.4 Padding properties

Padding: percentages of the inline size

CSS 2 takes a padding's percentage of the containing block's width. Later specifications take it of the containing block's inline size, which is its width only in horizontal writing.

paddingcontent

Since CSS 2 · CSS Writing Modes 4 §7.2

Of the containing block's inline size

As a corollary, percentages on the margin and padding properties, which are always calculated with respect to the containing block width in CSS2.1, are calculated with respect to the inline size of the containing block in CSS3. CSS Writing Modes 4 §7.2 CSS Box 4, which replaces CSS 2's padding properties, says the same: Percentages: refer to logical width of containing block.
