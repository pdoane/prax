CSS 2 · 8.3 Margin properties

Margins: which boxes take them

margin-top, -right, -bottom, -left and margin take <length> | <percentage> | auto. The orange tint is each box's margin area.

Which boxes take margins

Applies to: all elements except elements with table display types other than table-caption, table and inline-table. CSS 2 §8.3

Inline boxes

A non-replaced inline box takes its left and right margins on the line, but its top and bottom margins do not move anything: a line's height comes from line-height alone. CSS 2 §10.6.1
