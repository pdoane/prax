CSS 2 · 8.3.1 Collapsing margins

What keeps margins apart: formatting context roots

Margins adjoin only if no line boxes, no clearance, no padding and no border separate them, and both boxes are in flow in one block formatting context. Every box is 20px tall; the guides are 10px apart.

Block formatting context roots

Margins of elements that establish new block formatting contexts (such as floats and elements with 'overflow' other than 'visible') do not collapse with their in-flow children. CSS 2 §8.3.1
