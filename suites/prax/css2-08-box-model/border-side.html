CSS 2 · 8.5.4 Border shorthand properties

Border shorthands: one side

border-top, border-right, border-bottom, border-left and border. Each takes [ <border-width> || <border-style> || <border-top-color> ]: any of the three, at most once each, in any order.

One side

This is a shorthand property for setting the width, style, and color of the top, right, bottom, and left border of a box. CSS 2 §8.5.4
