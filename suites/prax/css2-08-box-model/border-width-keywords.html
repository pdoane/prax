CSS 2 · 8.5.1 Border width

Border width: keywords

border-*-width and border-width take thin | medium | thick | <length>. Initial medium, not inherited; computed: an absolute length, or 0 if the style is none or hidden.

thin, medium and thick

The interpretation of the first three values depends on the user agent. The following relationships must hold, however: 'thin' <= 'medium' <= 'thick'. Furthermore, these widths must be constant throughout a document. CSS 2 §8.5.1

Since CSS 2 · CSS Borders and Box Decorations 4 §2.3

1px, 3px and 5px

Now fixed: The thin, medium, and thick keywords are equivalent to 1px, 3px, and 5px, respectively. CSS Borders and Box Decorations 4 §2.3
