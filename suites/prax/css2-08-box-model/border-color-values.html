CSS 2 · 8.5.2 Border color

Border color: values

border-top-color, border-right-color, border-bottom-color, border-left-color and the shorthand border-color. Each takes <color> | transparent. Initial: the value of the color property; not inherited. Every figure's border is solid and 10px wide.

<color>

Specifies a color value. CSS 2 §8.5.2

transparent

The border is transparent (though it may have width). The border still takes its room, and what is behind it shows through: the box's own background, which runs under the border, and nothing more. CSS 2 §8.5.2
