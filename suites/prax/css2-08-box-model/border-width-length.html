CSS 2 · 8.5.1 Border width

Border width: lengths

border-*-width and border-width take thin | medium | thick | <length>.

<length>

The border's thickness has an explicit value. CSS 2 §8.5.1

Since CSS 2 · CSS Borders and Box Decorations 4 §2.3

Snapped to device pixels

A border width's computed value is an absolute length, snapped as a border width. CSS Borders and Box Decorations 4 §2.3 If the absolute value of len is greater than zero, but less than 1 device pixel, round it away from zero to 1 or -1 device pixel. If the absolute value of len is greater than 1 device pixel, round it towards zero to the nearest integer number of device pixels. CSS Values and Units 4 §6
