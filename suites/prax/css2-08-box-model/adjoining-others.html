CSS 2 · 8.3.1 Collapsing margins

Adjoining margins: other boxes

Adjoining vertical margins collapse into one. Every box is 20px tall and the guides are 10px apart. A dashed outline is a parent, which has no border or padding.

Boxes that are neither siblings nor ancestors

A collapsed margin is considered adjoining to another margin if any of its component margins is adjoining to that margin. Adjoining margins can be generated by elements that are not siblings or ancestors. CSS 2 §8.3.1
