CSS 2 · 8.6 The box model for inline elements in bidirectional context

Inline boxes in bidirectional text: rtl

Margins, borders and padding of an inline element go on its line boxes in visual order. Its left border is red and its right blue.

direction: rtl

When the element's 'direction' property is 'rtl', the right-most generated box of the first line box in which the element appears has the right padding, right border and right margin, and the left-most generated box of the last line box in which the element appears has the left margin, left border and left padding. The text is Hebrew, which reads from the right. CSS 2 §8.6

The element's direction decides, not the text's

Which sides go where follows the element's direction. Here the element is right-to-left, but its text is English, so each line of it reads from the left. CSS 2 §8.6
