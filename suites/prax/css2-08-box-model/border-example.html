CSS 2 · 8.5.4 Border shorthand properties

Border shorthands: the specification's example

border-top, -right, -bottom, -left and border take a width, a style and a color, each at most once, in any order.

The specification's example

Since, to some extent, the properties have overlapping functionality, the order in which the rules are specified is important. CSS 2 §8.5.4

BLOCKQUOTE {
  border: solid red;
  border-left: double;
  color: black;
}
