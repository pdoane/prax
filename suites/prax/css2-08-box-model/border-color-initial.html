CSS 2 · 8.5.2 Border color

Border color: the initial value

border-*-color and border-color take <color> | transparent. Every figure's border is solid and 10px wide.

The initial value: the color property

A border whose color is not given takes the element's color, which is inherited. CSS 2 §8.5.2

Since CSS 2 · CSS Borders and Box Decorations 4 §2.1, CSS Color 4 §15.5

The initial value is currentcolor, which computes to itself

The initial border color is now the keyword currentColor CSS Borders and Box Decorations 4 §2.1, and The currentcolor keyword computes to itself. CSS Color 4 §15.5 A child that inherits the border color inherits the keyword, and so takes its own color; in CSS 2 it took the parent's color.
