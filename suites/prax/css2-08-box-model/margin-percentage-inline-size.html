CSS 2 · 8.3 Margin properties

Margins: percentages of the inline size

CSS 2 takes a margin's percentage of the containing block's width. Later specifications take it of the containing block's inline size, which is its width only in horizontal writing. The orange tint is each box's margin area.

Since CSS 2 · CSS Writing Modes 4 §7.2

Of the containing block's inline size

As a corollary, percentages on the margin and padding properties, which are always calculated with respect to the containing block width in CSS2.1, are calculated with respect to the inline size of the containing block in CSS3. CSS Writing Modes 4 §7.2 CSS Box 4, which replaces CSS 2's margin properties, says the same: Percentages: refer to logical width of containing block.
