CSS 2 · 8.3.1 Collapsing margins

What keeps margins apart: line boxes

Margins adjoin only if no line boxes, no clearance, no padding and no border separate them, and both boxes are in flow in one block formatting context. Every box is 20px tall; the guides are 10px apart.

Line boxes

A line of text between two margins keeps them apart. Certain zero-height line boxes (see 9.4.2) are ignored for this purpose: a line with no text and nothing else that takes room is as if it were not there. CSS 2 §8.3.1, §9.4.2
