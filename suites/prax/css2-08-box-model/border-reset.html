CSS 2 · 8.5.4 Border shorthand properties

Border shorthands: what is left out

border-top, -right, -bottom, -left and border take a width, a style and a color, each at most once, in any order.

What is left out is reset

A shorthand sets all three of its longhands; one it does not name takes its initial value: a width of medium, a style of none and a color of the element's color. The specification's example is H1 { border-bottom: thick solid red }, which with the color left out takes the text's color. CSS 2 §6.4.4, §8.5.4
