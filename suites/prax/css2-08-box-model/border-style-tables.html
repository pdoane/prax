CSS 2 · 8.5.3 Border style

Border style: hidden and none in tables

border-*-style and border-style take none | hidden | dotted | dashed | solid | double | groove | ridge | inset | outset.

hidden and none in a table

In the collapsing border model, borders with the 'border-style' of 'hidden' take precedence over all other conflicting borders, while none has the lowest priority. Each table has two cells with 6px solid borders; the first cell's right border is set as the caption says. CSS 2 §8.5.3, §17.6.2.1
