CSS 2 · 8.2 Example of margins, padding, and borders

The example

The specification's own example: a list whose items have margins, padding and, on the second, a border. CSS 2 §8.2

The example

UL {
  background: yellow;
  margin: 12px 12px 12px 12px;
  padding: 3px 3px 3px 3px;
}
LI {
  color: white;
  background: blue;
  margin: 12px 12px 12px 12px;
  padding: 12px 0px 12px 12px;
  list-style: none
}
LI.withborder {
  border-style: dashed;
  border-width: medium;
  border-color: lime;
}
