CSS 2 · 8.1 Box dimensions

Box dimensions: edges

Each box has a content area and optional padding, border and margin areas around it, drawn here in the colors browsers' inspectors use.

marginborderpaddingcontent

Edges

If the padding has 0 width, the padding edge is the same as the content edge. The same holds of a border of 0 width and the padding edge, and of a margin of 0 width and the border edge. CSS 2 §8.1
