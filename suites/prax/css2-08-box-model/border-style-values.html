CSS 2 · 8.5.3 Border style

Border style: the values

border-*-style and border-style take none | hidden | dotted | dashed | solid | double | groove | ridge | inset | outset. Initial none, not inherited. Every figure's border is 10px wide unless it says otherwise.

The values

The specification describes each value, and leaves the details of drawing it to the user agent. CSS 2 §8.5.3
