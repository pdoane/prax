CSS 2 · 8.4 Padding properties

Padding: which boxes take it

padding-top, -right, -bottom, -left and padding take <length> | <percentage>, never negative.

paddingcontent

Which boxes take padding

Applies to: all elements except table-row-group, table-header-group, table-footer-group, table-row, table-column-group and table-column. CSS 2 §8.4

Inline boxes

A non-replaced inline box takes its left and right padding on the line. Its top and bottom padding paint around its text, but the line's height comes from line-height alone, so they overlap the lines around it. CSS 2 §10.6.1
