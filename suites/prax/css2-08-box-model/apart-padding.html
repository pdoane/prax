CSS 2 · 8.3.1 Collapsing margins

What keeps margins apart: padding and borders

Margins adjoin only if no line boxes, no clearance, no padding and no border separate them, and both boxes are in flow in one block formatting context. Every box is 20px tall; the guides are 10px apart.

Padding and borders

Even 1px of padding or border between a parent and its first child keeps their margins apart. CSS 2 §8.3.1
