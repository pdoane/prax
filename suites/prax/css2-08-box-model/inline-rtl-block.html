CSS 2 · 8.6 The box model for inline elements in bidirectional context

Inline boxes in bidirectional text: broken around a block

An inline element that holds a block is broken around it, into a part before the block and a part after it. Its left border is red and its right blue; the block is blue.

The broken side follows the direction

In the right-most generated box of the first line box in which the element appears has the right padding, right border and right margin, and the left-most generated box of the last line box in which the element appears has the left margin, left border and left padding when direction is rtl, and the other way round in ltr. The part before a block is on the element's first line, and the part after it on its last. CSS 2 §8.6, §9.2.1.1
