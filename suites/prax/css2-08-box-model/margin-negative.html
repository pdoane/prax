CSS 2 · 8.3 Margin properties

Margins: negative values

margin-top, -right, -bottom, -left and margin take <length> | <percentage> | auto. The orange tint is each box's margin area.

Negative values

Negative values for margin properties are allowed, but there may be implementation-specific limits. A negative margin pulls the box's edge outward past where the containing block or a sibling would put it. CSS 2 §8.3
