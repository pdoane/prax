CSS Table 3 · 3.8.3 Computing Column Measures, fixed mode and percentages

Column measures in fixed mode, and percentages inside cells

For the purpose of measuring a column when laid out in fixed mode, the min-content and max-content width of cells is considered zero unless they are directly specified as a length-percentage, in which case they are resolved based on the table width (if it is definite, otherwise use 0). CSS Table 3 §3.8.3 Text is .pr-measure.

Fixed mode: percentages of the table's width

Each table is table-layout: fixed; width: 200px, two cells in one row.

Percentages inside a cell

For the purpose of calculating the outer min-content width of cells, descendants of table cells whose width depends on percentages of their parent cell's width are considered to have an auto width. Each table is width: 10px, so its columns take their min-content widths.
