CSS Table 3 · 5.3.1.1 Changes in collapsed-borders mode, the table

Collapsed borders: the table's border is the cells' to draw

Borders of a non-empty table-root are not painted in collapsed-borders mode, except if the 'border-image' property is set. CSS Table 3 §5.3.1.1 Each table is collapsed; its cells have 2px grey borders.

Painted by the cells

A note: Even if they are not drawn by the table, the table borders still occupy their space in the layout. Cells will render those shared borders.
