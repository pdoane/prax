CSS Table 3 · 3.6.2 Overrides applying in collapsed-borders mode

Collapsed borders: padding, spacing and radii ignored

When a table is laid out in collapsed-borders mode, the following rules apply. CSS Table 3 §3.6.2 Each table is border-collapse: collapse with a 4px blue border; two cells, 40 by 20 inside 2px orange borders.

The table's padding and spacing

The 'padding' of the table-root is ignored (as if it was set to 0px). The 'border-spacing' of the table-root is ignored (as if it was set to 0px).

Rounded corners

The 'border-radius' of both table-root and table-non-root boxes is ignored (as if it was set to 0px).
