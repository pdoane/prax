CSS Table 3 · 3.5.3 The Caption-Side property

caption-side: top and bottom

This property specifies the position of the caption box with respect to the table grid box. CSS Table 3 §3.5.3 The grid box is blue and outlined; text is .pr-measure.

Above or below the grid box

top: Positions the caption box above the table grid box. bottom: Positions the caption box below the table grid box.

Each caption on its own side

The property applies to table-caption boxes, so each caption of a table takes its own value.
