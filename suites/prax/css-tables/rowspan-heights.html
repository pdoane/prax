CSS Table 3 · 3.10.2 Row layout (first pass), spanning cells

Rows under a spanning cell

A cell spanning rows has its height distributed to them by running the same algorithm as the column measurement, with the span=1 value being initialized (for min-content) with the largest of the resulting height of the previous row layout, the height specified on the corresponding table-row (if any), and the largest height specified on cells that span this row only. CSS Table 3 §3.10.2 Each green cell spans a blue row and an orange row and holds a grey block; the rows' cells hold blocks too.

In proportion to the rows

As for columns, what the cell needs beyond the rows goes to them in proportion to their sizes.

The cell's box fills its rows

cell boxes that are smaller than the collective height of the rows they span receive extra top and/or bottom padding such that their content does not move vertically but their top/bottom edges meet the ones of the first/last row they span.
