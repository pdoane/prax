CSS Table 3 · 3.8.1 Computing Undistributable Space

Undistributable space

The undistributable space of the table is the sum of the distances between the borders of consecutive table-cells (and between the border of the table-root and the table-cells). CSS Table 3 §3.8.1 Each grey table is width: 10px, so it is as narrow as it can be: its columns' min-content widths and this space. Cells hold .pr-measure text: "aaa bbb", 30px at its narrowest, and "cc dd", 20px.

Spacing between the cells, and padding at the edges

The distance between the borders of two consecutive table-cells is the 'border-spacing', if any. The distance between the table border and the borders of the cells on the edge of the table is the table's padding for that side, plus the relevant border spacing distance (if any).
