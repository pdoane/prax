Row layout: percentage heights in the first pass

The minimum height of a row (without spanning-related height distribution) is defined as the height of a hypothetical linebox containing the cells originating in the row and where cells spanning multiple rows are considered having a height of 0px (but their correct baseline). CSS Table 3 §3.10.2

Auto, or 0px

descendants of table cells whose height depends on percentages of their parent cell's height are considered to have an auto height if they have 'overflow' set to visible, clip, or hidden or if they are replaced elements, and a 0px height if they have not.
