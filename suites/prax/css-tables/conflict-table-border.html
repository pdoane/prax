CSS Table 3 · 3.7.1.1 Conflict Resolution Algorithm for Collapsed Borders, the table's border

Collapsed borders: the table's border

After the cells, for that table-root, its own borders are harmonized with the cells on its edges. CSS Table 3 §3.7.1.1 Cells are grey, 40 by 20 inside their borders.

The table's border

Harmonize the table-root border-{top,bottom,left,right} with the corresponding border of all cells forming the border of the table (independently). If the table and the cell border styles have the same specificity, keep the cell border style. Once this is done, set the table-root border-{…}-width to half the maximum width found during the harmonization processes for that border.
