CSS Table 3 · 3.5.1 The Table-Layout property

table-layout: fixed mode and auto mode

A table-root is said to be laid out in fixed mode whenever the computed value of the 'table-layout' property is equal to fixed, and the specified width of the table root is not auto or max-content. CSS Table 3 §3.5.1 Every table here is table-layout: fixed and outlined: a blue cell of width: 50px, and an orange one holding a 100px block of .pr-measure text.

auto and max-content: auto mode

When the specified width is one of those values, or if the computed value of the 'table-layout' property is auto, then the table-root is said to be laid out in auto mode.

Any other width: fixed mode

When a table-root is laid out in fixed mode, the content of its table-cells is ignored for the purpose of width computation. The orange column has no width, and its content does not count, so it gets 0px where nothing is left, and the text overflows. The latest draft extends fixed mode to every width but the two above (csswg-drafts#10937).
