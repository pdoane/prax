CSS Table 3 · 3.10.3 Row layout (second pass)

Row layout, second pass: percentage heights

Once the table height has been determined, a second row layout pass will be performed, if necessary, to assign the correct minimum height to table rows, by taking percentages used in rows/cells specified 'height' into account. CSS Table 3 §3.10.3 Each table is height: 100px, outlined: a blue row and an orange one, each a line of .pr-measure text, 20px.

Percentages of the table's height

In the first pass the percentages are 0px; in the second they are of the 100px. The extra height then goes as §3.10.5 says: the auto row takes what the other leaves.
