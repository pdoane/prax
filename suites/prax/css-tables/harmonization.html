CSS Table 3 · 3.7.1.2 Harmonization Algorithm for Collapsed Borders

Collapsed borders: cells, then tracks, then groups

Each cell's border is considered, then, for a border between columns, the columns' and the column groups', and for one between rows, the rows' and the row groups'. To consider one is if its properties are more specific than CurrentlyWinningBorderProperties, set CurrentlyWinningBorderProperties to its properties.
