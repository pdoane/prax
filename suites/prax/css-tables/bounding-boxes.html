CSS Table 3 · 3.11 Positioning of cells, captions and other internal table boxes

Where cells, rows and groups lie

A cell's, track's or track group's width and height are the sum of the widths/heights of all spanned visible columns/rows and the horizontal/vertical 'border-spacing' times the amount of spanned visible columns/rows minus one. CSS Table 3 §3.11 Grey tables have border-spacing: 10px and cells 30 by 20; a red outline marks the box of the row or group named.

Spacing between tracks is inside a group, not around it

A note sums it up: the border-spacing before the first track or after the last track in a direction is not included in any track's or track-group's breadth. the border-spacing between tracks is not included in any track's breadth, but is included in the breadth of track-groups spanning both tracks.
