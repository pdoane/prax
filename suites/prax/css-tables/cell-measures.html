The max-content width, in a column with no width and in one with a width

A column is constrained if its column, group or a cell of it has a computed 'width' that is not "auto", and is not a percentage. The outer max-content width of a table-cell in a non-constrained column is max('min-width', 'width', min-content width, min('max-width', max-content width)); in a constrained column is max('min-width', 'width', min-content width, min('max-width', 'width')).
