CSS Table 3 · 3.1 Core layout principles

A table's width is fit-content

Unlike other block-level boxes, tables do not fill their containing block by default. When their 'width' computes to auto, they behave as if they had fit-content specified instead. CSS Table 3 §3.1 Text is .pr-measure, 10px a letter.

As wide as the content, up to the containing block

The table's min-content and max-content widths

The min-content width of a table is the width required to fit all of its columns min-content widths and its undistributable spaces, and its max-content width the same with their max-content widths. Each dashed block is sized to its content around a grey table with border-spacing: 10px.
