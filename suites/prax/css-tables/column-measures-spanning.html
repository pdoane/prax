CSS Table 3 · 3.8.3 Computing Column Measures, cells of span N

Column measures: cells spanning columns

A cell of colSpan N adds to each column it spans a share of what it needs beyond the columns' measures from cells of span up to N-1. CSS Table 3 §3.8.3 Blue "aa bbb" (min-content 30px, max-content 60px) and orange "cccc" (40px, 40px): baselines of 70px and 100px. A green cell spans both.

The min-content contribution

A column's min-content width grows by the ratio of: the max-content width … minus the min-content width … of the column, to the baseline max-content width minus the baseline min-content width times the outer min-content width of the cell minus the baseline min-content width and the baseline border spacing, clamped to be at least 0 and at most the difference between the baseline max-content width and the baseline min-content width, plus a share, in proportion to max-content widths, of what the cell needs beyond the baseline max-content width.

The max-content contribution

A column's max-content width grows by the ratio of the max-content width … of the column to the baseline max-content width times the outer max-content width of the cell minus the baseline max-content width and the baseline border spacing, or 0 if this is negative. These tables have room.
