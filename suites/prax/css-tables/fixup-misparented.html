Fixup, stage 3: misparented boxes

A table-row is misparented if its parent is neither a table-row-group nor a table-root box. A table-column box is misparented if its parent is neither a table-column-group box nor a table-root box. A table-row-group, table-column-group, or table-caption box is misparented if its parent is not a table-root box.
