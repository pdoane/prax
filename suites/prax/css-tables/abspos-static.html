CSS Table 3 · 4.3 With a table-internal box as non-containing block parent

Static positions in table parts

The only influence of non-containing block parent of an absolutely-positioned box is to define its static position, in case both top+bottom and/or left+right end up being auto. CSS Table 3 §4.3 Purple boxes are absolutely positioned with every inset auto, their containing block the page's; text is .pr-measure.

In a cell, as in a block

For table-cells, the absolutely-positioned content is positioned follows the rules for block layout as usual.

Elsewhere, a cell of its own

Due to table fixup, it is not possible to create an absolutely-positioned box that is the child of a table-internal box that is not a table-cell: the fixup takes it as inline elements of zero width and height (§2.2.1).
