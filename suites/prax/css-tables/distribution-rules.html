Width distribution: the rules

The section is not normative; it sums up what the algorithm of §3.9.3 does. Ideally, each column should get its preferred width (usually its max-content width). CSS Table 3 §3.9.2.1 Each table has three columns: blue "aaaa" with no width, orange "b" with width: 40px, green "c" with width: 30%; text is .pr-measure.

Rule 1: percent, then pixel, then auto

When assigning preferred widths, specified percent columns have a higher priority than specified unit value columns, which have a higher priority than auto columns.

Rule 2's exception: a percentage below the minimum

When giving its preferred percent width to a percent-column, if that would result in a size smaller than its min-content width, the column will be assigned its min-content width instead.
