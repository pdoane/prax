CSS Table 3 · 3.6.1 Overrides applying in all modes, table-internal boxes

Properties table parts ignore

Some properties do nothing on the boxes inside a table. CSS Table 3 §3.6.1 Each table is outlined; two cells, blue and orange, of .pr-measure text.

Columns

All css properties of table-column and table-column-group boxes are ignored, except when explicitly specified by this specification. 'width', 'visibility', borders in collapsed-borders mode and backgrounds are such exceptions; 'color' is not.

Rows, groups and cells

The 'margin', 'padding', 'overflow' and 'z-index' of table-track and table-track-group boxes are ignored. The 'margin' of table-cell boxes is ignored (as if it was set to 0px). Each table would be 40 by 20 without them.
