Collapsed borders: resolving conflicts

When they are laid out in collapsed-borders mode, table-root and table-cell boxes sharing a border attempt to unify their borders so that they render using the same style, width, and color (whenever this is possible). CSS Table 3 §3.7.1 Cells are grey, 40 by 20 inside their borders.
