CSS Table 3 · 6.1 Breaking across fragmentainers

Tables across columns

When fragmenting a table, user agents must attempt to preserve the table rows unfragmented if the cells spanning the row do not span any subsequent row, and their height is at least twice smaller than both the fragmentainer height and width. CSS Table 3 §6.1 Stages: two 90px columns, 80px tall.
