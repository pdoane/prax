CSS Table 3 · 3.8.2 Computing Cell Measures, percentages

Percentage contributions

The percentage contribution of a cell, column or column group is min(percentage 'width', percentage 'max-width'). If the computed values are not percentages, then 0% is used for 'width', and an infinite percentage is used for 'max-width'.
