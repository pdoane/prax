CSS Table 3 · 5.2 Empty cell rendering (separated-borders mode), collapsed borders

empty-cells in collapsed-borders mode

empty-cells belongs to separated-borders mode. CSS Table 3 §5.2 The table is black, with a 10px black border and empty-cells: hide; cells are white.

Not in collapsed-borders mode

In collapsed-borders mode, this property has no effect. Cells have 4px orange borders.
