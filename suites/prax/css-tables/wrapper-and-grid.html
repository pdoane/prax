CSS Table 3 · 2.1.1 Terminology

Terms: wrapper, grid box, consecutive boxes

A table wrapper box is A block container box generated around table grid boxes to account for any space occupied by each table-caption it owns. A table grid box is A block-level box containing the table-internal boxes, excluding its captions. CSS Table 3 §2.1.1

The grid box excludes the captions

The table's background is the grid box's, not the wrapper's (§5.3.1). Text is .pr-measure.

Consecutive boxes

Two sibling boxes are consecutive if they have no intervening siblings other than, optionally, an anonymous inline containing only white spaces. Each stage holds two blue cell elements in a plain block.
