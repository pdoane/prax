Fixup, stage 3: rows, and table or inline-table

Generate missing parents. CSS Table 3 §2.2.1 Blue boxes are cell elements; stages have border-spacing: 10px, which anonymous tables inherit.

A row around cells

An anonymous table-row box must be generated around each sequence of consecutive table-cell boxes whose parent is not a table-row.

A table, or an inline-table

An anonymous table or inline-table box must be generated around each sequence of consecutive proper table child boxes which are misparented. If the box's parent is an inline, run-in, or ruby box (or any box that would perform inlinification of its children), then an inline-table box must be generated; otherwise it must be a table box. Each stage holds "x", cells A and B, and "y".
