CSS Table 3 · 5.3.4 Border styles (collapsed-borders mode)

Collapsed borders: hidden, inset, outset

Some of the values of the 'border-style' have different meanings for tables in collapsed-borders mode than usual. CSS Table 3 §5.3.4 Each table is collapsed, one row of two cells.

hidden

Same as none, but also inhibits any other border.

inset as ridge, outset as groove

inset: Same as ridge. outset: Same as groove. Every border is 8px blue.
