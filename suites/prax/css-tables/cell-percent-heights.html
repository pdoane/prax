CSS Table 3 · 3.10.6 Table-cell content layout (second pass)

Percentage heights inside cells

After the rows are sized, a cell's content is laid out again, where, if appropriate, percentage-based heights are this time resolved against their parent cell used height. a cell is considered to have its height specified explicitly if the computed height of the cell is a length, or if the computed height of its table-root ancestor is a length or percentage, regardless of whether that percentage does behave as auto or not. CSS Table 3 §3.10.6 The section's example: in a blue cell a yellow block "A" of height: 100%; beside it an orange cell "B", "C" on two lines, 40px. Text is .pr-measure.
