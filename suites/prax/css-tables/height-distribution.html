CSS Table 3 · 3.10.5 Distribution algorithm

Height distribution

A row's base size is the size it would have got if the table didn’t have a specified height; its reference size the larger of that and its size with percentages resolved against the table height. CSS Table 3 §3.10.5 Each table is height: 100px, outlined; each row's cell is a line of .pr-measure text, 20px.

Too little room: between base and reference

If the table height is equal or smaller than sum of reference sizes, the final height assigned to each row will be the weighted mean of the base and the reference size that yields the correct total height.
