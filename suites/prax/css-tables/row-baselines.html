CSS Table 3 · 3.10.2 Row layout (first pass), baselines of rows and tables

The baselines of rows and tables

The maximum distance between the top of the cell box and the baseline over all cells that have 'vertical-align: baseline' is used to set the baseline of the row. The baseline of a table-root is the baseline of its first row, if any. CSS Table 3 §3.10.2 Each stage is a line: "x", an inline-table, "x", the red dashes the line's baseline.

A row with baseline cells

Without baseline cells, or without rows

If a row doesn't have any cell that has 'vertical-align: baseline', the baseline of that row is the bottom content edge of the lowest cell in the row. Otherwise, it is the bottom content edge of the table-root.
