CSS Table 3 · 3.9.3.2 Distributing excess width to columns, rules 1 to 3

Excess width: auto columns first

When the table is wider than the max-content sizing-guess, the excess goes to columns by the first of six rules that finds any. CSS Table 3 §3.9.3.2 Each table is 200px; text is .pr-measure, no spacing.

1. Auto columns with content, by max-content width

If there are non-constrained columns that have originating cells with intrinsic percentage width of 0% and with nonzero max-content width (aka the columns allowed to grow by this rule), the distributed widths of the columns allowed to grow by this rule are increased in proportion to max-content width.

2. Empty auto columns, equally

Otherwise, if there are non-constrained columns that have originating cells with intrinsic percentage width of 0%, they are increased by equal amounts.

3. Columns with widths, by max-content width

Otherwise, if there are constrained columns with intrinsic percentage width of 0% and with nonzero max-content width, in proportion to max-content width.
