CSS Table 3 · 3.10.1 Computing the table height

The table's height and its rows' minimum heights

The height of a table is the sum of the row heights plus any cell spacing or borders. If the table has a 'height' property with a value other than auto, it is treated as a minimum height for the table grid. If their collective size ends up being greater than the specified 'height', the specified 'height' will have no effect. A row's minimum height, and the table's

It is the largest of the computed 'height' (if definite, percentages being considered 0px) of its corresponding table-row (if any), the computed 'height' of each cell spanning the current row exclusively (if definite, percentages being treated as 0px), and the height its cells need.
