CSS Table 3 · 5.3.3.1 Changes in collapsed-borders mode, cells

Collapsed borders: how cells draw them

Borders of a table-cell are rendered in collapsed-borders mode as if the cell border was twice as big as its used value specify, and as if that excess was rendered in the margin area of the cell, with the added constraint that for each side of the border which isn’t located at one of the table edges, the border is actually clipped to the border-box drawing area as its real used value define except if the 'border-image' property is set.
