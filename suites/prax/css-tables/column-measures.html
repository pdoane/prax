CSS Table 3 · 3.8.3 Computing Column Measures, cells of span 1

Column measures: cells of one column

Each column has a min-content width, the smallest possible width attributed to this column, and a max-content width, the width that would be attributed to the column if no other constraint applied. CSS Table 3 §3.8.3 Cells hold .pr-measure text, with no padding, border or spacing.

The largest of the cells

The min-content width of a column is the largest of the outer min-content width of each cell that spans the column whose colSpan is 1, and its max-content width the largest of their outer max-content widths.

A column's width is a minimum, a cell's is not

A column's own measure counts too: the outer min-content width of its corresponding table-column, which is max('min-width', 'width'). A cell's outer min-content width is max('min-width', min-content width): its 'width' is left out. CSS Table 3 §3.8.2 Each table is width: 10px, so it shrinks to its columns' min-content widths.
