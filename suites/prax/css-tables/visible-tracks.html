CSS Table 3 · 3.11 Positioning of cells, captions and other internal table boxes, visible tracks

Collapsed tracks take no room

For the purpose of this algorithm, a column or row is considered a visible track if neither its corresponding table-track nor its table-track-group parent (if any) have 'visibility' set to collapse. Positions and sizes count only visible tracks, and the spacing between them. CSS Table 3 §3.11 The draft still carries the issue csswg-drafts#478, but it is closed, resolved that cells spanning collapsed tracks are clipped to their resulting bounds. Grey tables have border-spacing: 10px; cells are 30 by 20, blue, orange and green by column.
