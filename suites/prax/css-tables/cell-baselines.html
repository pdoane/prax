CSS Table 3 · 3.10.2 Row layout (first pass), the baseline of a cell

The baseline of a cell

The baseline of a cell is defined as the baseline of the first in-flow line box in the cell, or the first in-flow table-row in the cell, whichever comes first. If there is no such line box or table-row, the baseline is the bottom of content edge of the cell box.
