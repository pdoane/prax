CSS Table 3 · 10.1 Mapping between CSS & HTML attributes, other attributes

HTML's attributes: colors, hidden, captions

The rest of the mapping. CSS Table 3 §10.1 Tables have cellspacing=4 cellpadding=0, blue cells and a green caption; text is .pr-measure.

bgcolor and bordercolor

table[bgcolor=$color] { background-color: … }; table[bordercolor=$color] { border-color: … }, which its rows, groups and cells inherit.

hidden on table parts

:is(colgroup,col,thead,tbody,tfoot,tr,td,th)[hidden] { visibility: collapse; } (HTML's own style sheet also gives [hidden] display: none, which removes it outright.)

caption align=bottom

caption[align=bottom i] { caption-side: bottom; }
