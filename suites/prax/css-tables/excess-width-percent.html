CSS Table 3 · 3.9.3.2 Distributing excess width to columns, rules 4 to 6

Excess width: percentages, then any column

The last three rules, where no column without a percentage can take the excess. CSS Table 3 §3.9.3.2 Each table is 200px; text is .pr-measure, no spacing.

4. By percentage

Otherwise, if there are columns with intrinsic percentage width greater than 0%, they are increased in proportion to intrinsic percentage width.

5. Every column with a cell, equally

Otherwise, if there is any such column, the distributed widths of all columns that have originating cells are increased by equal amounts.

6. Every column, equally

Otherwise, the distributed widths of all columns are increased by equal amounts so the total increase adds to the excess width. A table with slots has a cell originating in its first column, so rule 5 always finds one; this rule has nothing to show.
