CSS Table 3 · 3.9.1 Computing the table width

The table's used width

GRIDMIN and GRIDMAX are the sums of the columns' min-content and max-content widths plus cell spacing or borders; The used min-width of a table is the greater of the resolved 'min-width', CAPMIN, and GRIDMIN. CSS Table 3 §3.9.1 Tables are outlined; text is .pr-measure, no spacing.

the used width is the greater of min(GRIDMAX, the table's containing block width), the used min-width of the table.

A specified width

If the table-root's 'width' property has a computed value (resolving to resolved-table-width) other than auto, the used width is the greater of resolved-table-width, and the used min-width of the table.
