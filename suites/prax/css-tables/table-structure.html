CSS Table 3 · 2.1 Table Structure

Table structure: rows first, columns derived

The table model is said to be "row primary" since authors specify rows, not columns, explicitly in the document language. Columns are derived once all the rows have been specified. CSS Table 3 §2.1 Tables are grey with border-spacing: 4px; text is .pr-measure, 10px a letter.

Each cell takes the next available column

the cells of the following rows each belong to the next available column for that row (taking rowspan into account), creating columns as needed.

Captions

Table captions are positioned between the table margins and its borders.
