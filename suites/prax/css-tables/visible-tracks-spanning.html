CSS Table 3 · 3.11 Positioning of cells, captions and other internal table boxes, spanning cells

Cells spanning collapsed tracks

A cell spanning a collapsed track is as wide or tall as its visible tracks. CSS Table 3 §3.11 csswg-drafts#478 resolved that cells spanning collapsed tracks are clipped to their resulting bounds. Grey tables have border-spacing: 10px; text is .pr-measure.
