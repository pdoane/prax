CSS Table 3 · 3.10.2 Row layout (first pass), vertical-align

vertical-align on cells

The 'vertical-align' property of each table cell determines its alignment within the row. CSS Table 3 §3.10.2 In the first card, each row has a blue cell with a large "Hx" on 40px lines; the red line is its baseline.

Values that do not apply

Other values do not apply to cells; the cell is aligned at the baseline instead. The orange cell holds a small "x".

Across the rows a cell spans

top: The top of the cell box is aligned with the top of the first row it spans. bottom: The bottom of the cell box is aligned with the bottom of the last row it spans. middle: The center of the cell is aligned with the center of the rows it spans. Blue cells "a", "b" and "c" make three rows; a green cell "z" spans them.
