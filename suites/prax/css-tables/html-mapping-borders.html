HTML's attributes: border, frame, rules

The style sheet maps the border attributes to borders on the table and its cells. CSS Table 3 §10.1 Each table has two rows of two cells, cellspacing=0; text is .pr-measure.

border

table[border=$border] gets outset rgb(128, 128, 128) at that many pixels, and its cells border: 1px inset rgb(128, 128, 128).

rules

Any rules makes the table border-collapse: collapse; border-style: hidden;; then table[rules=rows i] cells get border: 1px solid grey; border-left: none; border-right: none;, and cols the reverse.
