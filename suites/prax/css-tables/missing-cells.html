CSS Table 3 · 3.4 Missing cells fixup

Missing cells

Once the amount of columns in a table is known, any table-row box must be modified such that it owns enough cells to fill all the columns of the table, when taking spans into account. New table-cell anonymous boxes must be appended to its rows content until this condition is met. CSS Table 3 §3.4 Tables are grey with 4px spacing; rows are orange, which their cells draw; text is .pr-measure.

Anonymous cells fill the row

The new cells are empty and, as §5.3.2 says, do not render any of their backgrounds, so their row's orange is not drawn there.
