CSS Fonts 4 · 5.2 Matching font styles: the first available font

The first available font

The first available font, used for example in the definition of font-relative lengths such as 'ex' or in the definition of the 'line-height' property, is defined to be the first font for which the character U+0020 (space) is not excluded by a 'unicode-range'. CSS Fonts 4 §5.2

A face whose range excludes the space is skipped

"No Space" is Cousine for A to Z only. Each stage is 40px with line-height: normal; its bar is 10ex.
