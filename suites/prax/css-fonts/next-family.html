CSS Fonts 4 · 5.2 Matching font styles, steps 5 and 6

No glyph: the next family

If no matching face exists or the matched face does not contain a glyph for the character to be rendered, the next family name is selected. Glyphs from other faces in the family are not considered. The only exception is that user agents may optionally substitute a synthetically obliqued version of the default face. CSS Fonts 4 §5.2

Not from another face of the family

"Partial" is a handwriting face with no Greek, and Tinos Bold as its bold face, which has Greek. The stage names Partial, 'PR Arimo'.

Except an obliqued default face

"Upright Greek" has Tinos, with Greek, as its regular face, and a handwriting face without Greek as its italic.
