CSS Fonts 4 · 4.2 Font family: the @font-face 'font-family' descriptor

The family descriptor

This descriptor defines the font family name that will be used in all CSS font family name matching. It overrides the font family names contained in the underlying font data. CSS Fonts 4 §4.2

The rule's name, not the font's

Literata's own name table says "Literata"; each rule here gives it another name.

Hiding an installed family

If the font family name is the same as a font family available in a given user's environment, it effectively hides the underlying font for documents that use the stylesheet.
