CSS Fonts 4 · 5.2 Matching font styles, step 7

Installed font fallback

If there are no more font families to be evaluated and no matching face has been found, then the user agent performs an installed font fallback procedure to find the best match for the character to be rendered. The result of this procedure can vary across user agents. CSS Fonts 4 §5.2

By the content language

Each stage names only PR Tinos, which has no Han or Arabic. The language chooses the installed font.
