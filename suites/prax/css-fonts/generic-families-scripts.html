CSS Fonts 4 · 2.1.5 Generic font families

Generic families of one writing system

'generic(fangsong)', 'generic(kai)', 'generic(khmer-mul)' and 'generic(nastaliq)' are styles of one writing system. Each might not map to any locally installed font, but if it does, that font will be in that style. CSS Fonts 4 §2.1.5

Chinese: Fang Song and Kai

Safari draws each stage that names a generic() family in the family it inherits: it has none of them.

Fang Song is a relaxed, intermediate form between Song ('serif') and Kai; Kai shows notable handwriting features.

Khmer âksâr mul, and Urdu Nastaliq

Nastaliq has a sloping baseline for joined letters; It is important not to fall back to a naskh style for languages such as Urdu and Kashmiri.
