CSS Fonts 4 · 4.8.1 Font loading guidelines

Fonts load when used

user agents must only download those fonts that are referred to within the style rules applicable to a given page. User agents that download all fonts defined in @font-face rules without considering whether those fonts are in fact used within a page are considered non-conformant. CSS Fonts 4 §4.8.1
