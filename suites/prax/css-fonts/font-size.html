CSS Fonts 4 · 2.5 Font size: the 'font-size' property

font-size

For scalable fonts, the font-size is a scale factor applied to the EM unit of the font. CSS Fonts 4 §2.5

Lengths and percentages

Each stage's parent is 20px; each caption reads back the size the text is set at, which the guides cannot measure. A percentage value specifies an absolute font size relative to the parent element's computed 'font-size'.

larger and smaller

A <relative-size> keyword is interpreted relative to the computed 'font-size' of the parent element: the next entry in the table of sizes, or a ratio of about 1.2 to 1.5.
