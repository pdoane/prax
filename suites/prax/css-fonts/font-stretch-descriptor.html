CSS Fonts 4 · 4.4.1 Font width: the @font-face 'font-stretch' legacy name alias

The font-stretch descriptor

For historical reasons, a 'font-stretch' descriptor exists which is a legacy name alias and functions in the identical way to the 'font-width' descriptor. CSS Fonts 4 §4.4.1

Faces declared by width

Family "Widths" declares Tinos condensed, Cousine normal and a handwriting face expanded, with 'font-stretch'. 'font-width' chooses among them.
