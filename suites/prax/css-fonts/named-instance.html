CSS Fonts 4 · 4.7 Using named instances from variable fonts: the 'font-named-instance' descriptor

Named instances

A named instance's variation axis values are applied to the face. If no such named instance exists, this descriptor is treated as if it has a value of 'auto'. Roboto Flex names twenty, from "Thin" to "ExtraBlack Italic". CSS Fonts 4 §4.7
