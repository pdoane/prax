CSS Fonts 4 · 6.6 Capitalization: the 'font-variant-caps' property

font-variant-caps

The values select capital forms: small-caps (smcp), all-small-caps (c2sc and smcp), petite-caps, all-petite-caps, unicase and titling-caps. A font without them has small capitals synthesized. CSS Fonts 4 §6.6
