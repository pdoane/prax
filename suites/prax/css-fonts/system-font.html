CSS Fonts 4 · 10.4 System font

The system font

The System Font is the font which is used by the 'system-ui' generic font family name. It is an example of a Preinstalled Font. 'ui-sans-serif', 'ui-serif', 'ui-monospace' and 'ui-rounded' are preinstalled fonts too if the system provides them. CSS Fonts 4 §10.4
