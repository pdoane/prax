CSS Fonts 4 · 4.10 Default font language overriding: the 'font-language-override' descriptor

The font-language-override descriptor

The descriptor defines initial settings that apply when the font defined by an @font-face rule is rendered. It does not affect font selection. It names the OpenType language system the face's glyphs are chosen for. CSS Fonts 4 §4.10

Turkish forms from English text

Literata's Turkish (TRK) language system keeps the dot of an i that follows an f, so "fi" is not joined. Each stage is lang=en.
