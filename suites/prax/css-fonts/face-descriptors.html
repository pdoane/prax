CSS Fonts 4 · 4.4 Font property descriptors: 'font-style', 'font-weight' and 'font-width'

Face descriptors: weight, width and style

These descriptors define the characteristics of a font face and are used in the process of matching styles to specific faces. The value for these font face style attributes is used in place of the style implied by the underlying font data. CSS Fonts 4 §4.4

Choosing among a family's faces

Family "Pick" has three faces: Tinos as normal, Cousine as bold and a handwriting face as italic.

Ranges clamp variation

variation values applied to fonts defined with @font-face will be clamped to both the values specified in these descriptors and those the font supports. A decreasing range is swapped.
