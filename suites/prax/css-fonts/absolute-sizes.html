CSS Fonts 4 · 2.5.1 Absolute size keyword mapping table

The absolute size keywords

The 'medium' value is used as the reference middle value. The scaling factors are 3/5, 3/4, 8/9, 1, 6/5, 3/2, 2/1 and 3/1, from 'xx-small' to 'xxx-large'; The user agent may fine-tune these values. CSS Fonts 4 §2.5.1

From xx-small to xxx-large

With 'medium' at 16px, the factors give about 9.6px, 12px, 14.2px, 16px, 19.2px, 24px, 32px and 48px. Each line shows its keyword and, read back, the size its "Aa" is set at.
