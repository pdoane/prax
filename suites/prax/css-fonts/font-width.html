CSS Fonts 4 · 2.3 Font width: the 'font-width' property

font-width

The 'font-width' property selects a normal, condensed, or expanded face from a font family. Percentages represent the fractional width of the glyphs, with 100% representing “normal” glyph widths. CSS Fonts 4 §2.3

The keywords and their percentages

PR Roboto Flex has a wdth axis from 25% to 151%. On each line the black word sets 'font-width' to a keyword, from ultra-condensed to ultra-expanded, and the blue one to the keyword's percentage.

No width axis: no stretching

User agents must not synthesize condensed or expanded faces for font families which lack such faces and which do not have a width variation axis. §2.3.1
