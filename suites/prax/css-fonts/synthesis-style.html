CSS Fonts 4 · 2.8.2 Controlling synthesized oblique: the 'font-synthesis-style' property

font-synthesis-style

This property controls whether user agents are allowed to synthesize oblique font faces when a font family lacks oblique faces. CSS Fonts 4 §2.8.2

auto, none and oblique-only

PR Cousine has no italic or oblique face.

In vertical text

For positive oblique angles, the glyph is skewed such that the line-over edge shifts towards the line-right side while the line-under edge shifts towards the line-left side.
