CSS Fonts 4 · 2.7 Shorthand font property: the 'font' property

The font shorthand

'font' sets 'font-style', 'font-variant', 'font-weight' and 'font-width' in any order, then 'font-size', an optional '/ line-height', and 'font-family'. Only normal | small-caps of 'font-variant' and the CSS 3 keywords of 'font-width' are allowed. CSS Fonts 4 §2.7

What it resets

All subproperties of the 'font' property in the Set Explicitly and Reset Implicitly groups are first reset to their initial values. 'font-palette' and the 'font-synthesis' longhands are neither set nor reset.
