CSS Fonts 4 · 2.2.2 Missing weights

Missing weights

When a weight is specified for which no face exists, a face with a nearby weight is used. In general, bold weights map to faces with heavier weights and light weights map to faces with lighter weights. CSS Fonts 4 §2.2.2

Two faces: 400 and 700

PR Tinos has a regular face and a bold one. A weight up to 500 takes the regular face, and one above it the bold face. §5.2

One face: bold is synthesized

PR Cousine has only a regular face. A bold weight is drawn by emboldening it, as 'font-synthesis-weight' allows.
