CSS Fonts 4 · 4.6 Font features and variations: the 'font-feature-settings' and 'font-variation-settings' descriptors

Face features and variations

These descriptors define initial settings that apply when the font defined by an @font-face rule is rendered. They do not affect font selection. CSS Fonts 4 §4.6

Settings on the face

Only the glyphs of that face

These descriptors set features and variation values on the font object which the @font-face rule represents, rather than on an entire element.
