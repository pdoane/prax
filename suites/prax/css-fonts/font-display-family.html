CSS Fonts 4 · 4.9.1 Controlling font display per font-family via @font-feature-values

font-display for a family

When 'font-display' is omitted in an @font-face rule, the user agent uses the 'font-display' value set via @font-feature-values for the relevant font-family if one is set, and otherwise defaults to 'auto'. CSS Fonts 4 §4.9.1

The family's default, and a face's own

Family "Family Policy" sets swap in @font-feature-values. Its regular face gives no 'font-display'; its bold face gives block.
