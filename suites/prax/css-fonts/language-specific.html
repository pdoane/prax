CSS Fonts 4 · 6.2 Language-specific display

Language-specific display

If the content language of the element is known according to the rules of the document language, user agents are required to infer the OpenType language system from the content language and use that when selecting and positioning glyphs using an OpenType font. CSS Fonts 4 §6.2

Turkish fi

in languages such as Turkish which uses both a dotted-i and a dotless-i, it's important to not use this ligature. PR Literata has a Turkish language system.

Serbian Cyrillic

certain Cyrillic letters have different shapes in Russian text than in Bulgarian. PR Noto Sans has a Serbian language system, whose italic б, г, д, п and т take Serbian forms.
