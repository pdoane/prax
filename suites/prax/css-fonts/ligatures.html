CSS Fonts 4 · 6.4 Ligatures: the 'font-variant-ligatures' property

font-variant-ligatures

Ligatures and contextual forms are ways of combining glyphs to produce more harmonized forms. CSS Fonts 4 §6.4

Common and discretionary ligatures

PR Literata's common ligatures (liga) join Th, fi, fl and ff; its discretionary ligatures (dlig) join ch, ct and st.

Letter-spacing

Where letter-spacing is not zero, css-text says optional ligatures are not used, so the letters can be spaced evenly. CSS Text 3 §8.2
