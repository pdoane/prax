CSS Fonts 4 · 5.2 Matching font styles, step 4.2

Matching style

For 'italic', italic faces first, then oblique values greater than or equal to 11deg, then the rest. For 'oblique' of 11deg or more, oblique faces first, then italic. For 'normal', Oblique values greater than or equal to 0 are checked in ascending order before any italic. CSS Fonts 4 §5.2

Italic without an italic face

"Slants" has Tinos upright and Cousine declared oblique 20deg.

Oblique without an oblique face

"Cursive Only" has Tinos upright and a handwriting face declared italic.

Normal without an upright face

"Not Upright" has a handwriting face declared italic and Cousine declared oblique 20deg.
