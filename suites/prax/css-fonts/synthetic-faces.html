CSS Fonts 4 · 2.8 Controlling synthetic faces

Synthetic faces

Synthetic font faces are a fallback strategy to provide an approximation to the requested font when a font family lacks a suitable face. CSS Fonts 4 §2.8

What a user agent synthesizes

A bold face by drawing a thin stroke around each glyph, an oblique by geometrical shearing, and small capitals, superscripts and subscripts by rendering regular glyphs at a smaller size and positioning them appropriately. PR Cousine has only a regular face.

A variation axis is not synthesis

Variable fonts, where the font designer has provided one or more axes of variation do not count as font synthesis and their use is not affected by the 'font-synthesis' property.
