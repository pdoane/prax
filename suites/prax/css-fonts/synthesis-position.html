CSS Fonts 4 · 2.8.4 Controlling synthesized super- and subscripts: the 'font-synthesis-position' property

font-synthesis-position

This property controls whether user agents are required to synthesize superscript and subscript glyphs for 'font-variant-position' when a font lacks them. CSS Fonts 4 §2.8.4

PR Tinos has no sups or subs feature. Each stage writes H2O and x2 with 'font-variant-position'.
