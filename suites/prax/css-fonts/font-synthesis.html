CSS Fonts 4 · 2.8.5 Controlling synthetic faces: the 'font-synthesis' shorthand

The font-synthesis shorthand

'font-synthesis' is none | [ weight || style || small-caps || position ]: each keyword given sets its longhand to auto, and each left out sets it to none. CSS Fonts 4 §2.8.5

The longhands it sets

Each stage is bold, italic small capitals in PR Cousine, which has none of them.
