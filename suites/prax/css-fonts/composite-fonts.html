CSS Fonts 4 · 4.5.1 Using character ranges to define composite fonts

Composite fonts

Multiple @font-face rules with different unicode ranges for the same family and style descriptor values can be used to create composite fonts that mix the glyphs from different fonts for different scripts. CSS Fonts 4 §4.5.1

The last rule is checked first

If the unicode ranges overlap ... the last rule defined is the first to be checked for a given character. Family "Composite" is Tinos for ASCII, then Cousine for digits, then Noto Sans JP for kana and kanji.

Only the faces the text needs download

Since the user agent will only pull down the fonts it needs this helps reduce page bandwidth. Family "Unused" has a Japanese face that no text here uses. Each face's status, once the page has loaded:
