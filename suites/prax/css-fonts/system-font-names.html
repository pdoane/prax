CSS Fonts 4 · 2.1.3 Syntax of <system-font-family-name>

System font names

The system fonts are caption, icon, menu, message-box, small-caption and status-bar. A system font may not be used with the 'font-family' property, but can be used with the 'font' shorthand. CSS Fonts 4 §2.1

In the font shorthand: the platform's font

Each sets every longhand of 'font' to the platform's font for that use.

In font-family: a name like any other

An unquoted caption in 'font-family' is a family name, not the system font, and no family has that name.
