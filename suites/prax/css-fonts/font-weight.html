CSS Fonts 4 · 2.2 Font weight: the 'font-weight' property

font-weight: numbers from 1 to 1000

Each number indicates a weight that is at least as dark as its predecessor. Fractional weights are valid. CSS Fonts 4 §2.2

Any weight a variable face supports

PR Roboto Flex has a wght axis from 100 to 1000, so a user agent using a font which supports a range of weights should behave the same as if a font is present at each individual weight in the range. §2.2.2
