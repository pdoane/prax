CSS Fonts 4 · 3.2 The font display timeline

The font display timeline

A downloaded face's timer passes through the block period, in which text render[s] with an invisible fallback font face, the swap period, in which it renders with a visible fallback, and the failure period, after which the face is treated as failed. CSS Fonts 4 §3.2

A face that loads: used once loaded

If the font face successfully loads during the block period, the font face is then used normally. Once this page has settled, its fonts have loaded.

A face that fails: the fallback, visible

A face whose source is not found fails, and text in it is set in the next family, whatever its 'font-display'.
