CSS Fonts 4 · 2.1.5 Generic font families

Generic families of the user interface

'ui-serif', 'ui-sans-serif', 'ui-monospace' and 'ui-rounded' are the variants of the system's user interface font. Each is not expected to map to any font on platforms without an appropriate system font, and then the next family in the list is used. CSS Fonts 4 §2.1.5

The variants, or the next family

Each list ends in PR Cousine, a monospace, which shows where the platform has no such font.
