CSS Fonts 4 · 9.1 Controlling color font palettes: the 'font-palette' property

font-palette

'font-palette' is normal | light | dark | <palette-identifier> | <palette-mix()>. The names 'light' and 'dark' describe the background the color palette is usable on, not the colors in the color palette themselves. CSS Fonts 4 §9.1

Palettes of PR Nabla

PR Nabla has seven palettes: 0 is yellow and orange, 2 blue, 6 purple and red.

light and dark

PR Kalnia Glaze marks its palette 0 for light backgrounds and palette 1 for dark ones. PR Nabla marks none.
