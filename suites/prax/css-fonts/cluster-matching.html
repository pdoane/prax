CSS Fonts 4 · 5.3 Cluster matching

Cluster matching

When text contains characters such as combining marks, ideally the base character should be rendered using the same font as the mark, this assures proper placement of the mark. CSS Fonts 4 §5.3

A base and its marks in one font

If all characters in the sequence b + c1 + c2 … are completely supported by the font, select this font for the sequence. PR Architects Daughter has no combining marks.

Variation selectors

For sequences containing variation selectors, which indicate the precise glyph to be used for a given character, user agents always attempt installed font fallback to find the appropriate glyph before using the default glyph of the base character.
