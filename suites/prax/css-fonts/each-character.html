CSS Fonts 4 · 5 Font matching algorithm

A font for each character

For each character in the run a font family is chosen and a particular font face is selected containing a glyph for that character. The set of installed fonts available to the Font Matching Algorithm is explicitly undefined. CSS Fonts 4 §5

One run, several families

The stage is one text node in 'PR Architects Daughter', 'PR Tinos', 'PR Noto Sans JP', serif.

Characters no listed family has

The stage names PR Tinos only. Each script it lacks still draws, from an installed font that has it.
