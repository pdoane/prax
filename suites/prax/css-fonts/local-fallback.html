CSS Fonts 4 · 4.3.3.1 Local font fallback

local()

When authors would prefer to use a locally available copy of a given font and download it if it's not, local() can be used. Its name is matched against only the Postscript name or the full font name of an installed face. CSS Fonts 4 §4.3.3.1
