CSS Fonts 4 · 4.5 Character range: the 'unicode-range' descriptor

unicode-range

The union of these ranges defines the set of codepoints for which the corresponding font may be used. User agents must not download or use the font for codepoints outside this set. CSS Fonts 4 §4.5

Single code points, intervals and wildcards

Each family is Cousine, a monospace, for its range; each stage names it, then serif.

The effective character map

When the font is used, the effective character map is the intersection of the codepoints defined by 'unicode-range' with the font's character map.
