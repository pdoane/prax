CSS Fonts 4 · 4.11 Default font metrics overriding: 'ascent-override', 'descent-override' and 'line-gap-override'

Metric overrides

The descriptors define the ascent metric, descent metric and line gap metric of the font. When the descriptor value is a percentage, the corresponding metric value is resolved as the given percentage multiplied by the used font size. CSS Fonts 4 §4.11
