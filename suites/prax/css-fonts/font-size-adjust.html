CSS Fonts 4 · 2.6 Relative sizing: the 'font-size-adjust' property

font-size-adjust

The aspect value is the x-height of a font divided by the font size. 'font-size-adjust' scales each font so that its x-height is the aspect value times 'font-size': c = (a / a') s. CSS Fonts 4 §2.6

Equal x-heights across fonts

PR Tinos's aspect value is 0.459 and PR Arimo's 0.528. Each stage sets "x" in both at 40px.

The used size, not the computed one

The value of 'font-size-adjust' affects the used value of 'font-size' but does not affect the computed value. It changes ex but not em.
