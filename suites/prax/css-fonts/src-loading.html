Loading a src entry

As with other URLs in CSS, the URL can be relative, in which case it is resolved relative to the location of the style sheet containing the @font-face rule. CSS Fonts 4 §4.3.2

Relative to the style sheet

../shared/fonts.css gives its sources as url(../../../third_party/fonts/...), three levels up from the sheet, not from this page.

Fragment identifiers name a face

Conformant user agents must not use a face from the resource unless its PostScript name exactly matches the fragment identifier. Each rule falls back to Cousine, a monospace.
