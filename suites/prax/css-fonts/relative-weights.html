CSS Fonts 4 · 2.2.1 Relative weights

bolder and lighter

Specified values of 'bolder' and 'lighter' indicate weights relative to the weight of the parent element. The computed weight is calculated based on the inherited 'font-weight' value: CSS Fonts 4 §2.2.1

The table

Below 100, bolder is 400 and lighter no change; from 100, bolder 400 and lighter 100; from 350, 700 and 100; from 550, 900 and 400; from 750, 900 and 700; from 900, no change and 700. Each line is set at its parent's weight; on it, "Weight" set bolder or lighter, then, in blue, set at the weight the table gives.
