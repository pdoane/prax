CSS Fonts 4 · 4.3 Font reference: the 'src' descriptor

The src descriptor

'src' is a prioritized, comma-separated list of external references or locally-installed font face names. When a font is needed the user agent iterates over the set of references listed, using the first one it can successfully parse and activate. CSS Fonts 4 §4.3
