CSS Fonts 4 · 9.2 User-defined font color palettes: the @font-palette-values rule

@font-palette-values

The @font-palette-values rule defines a color palette and associates that color palette with a specific font. If multiple @font-palette-values rules are defined with the same name, the last one in document order wins. CSS Fonts 4 §9.2

One name, several fonts

--green is defined for PR Nabla as its palette 5 and for PR Bungee Spice as its palette 2.
