CSS Fonts 4 · 2.8.1 Controlling synthesized bold: the 'font-synthesis-weight' property

font-synthesis-weight

This property controls whether user agents are allowed to synthesize bold font faces when a font family lacks bold faces. CSS Fonts 4 §2.8.1
