CSS Fonts 4 · 5.2 Matching font styles, step 4

Width, then style, then weight

The family's faces are narrowed to one: 'font-width' is tried first, 'font-style' is tried next, and 'font-weight' is matched next. Each step keeps only the faces closest to the request. CSS Fonts 4 §5.2

Three faces, each nearest in one property

Family "Order" has Tinos (serif), condensed; Cousine (monospace), italic; and Arimo (sans-serif), bold. Each is otherwise normal.
