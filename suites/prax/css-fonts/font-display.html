CSS Fonts 4 · 4.9 Controlling font display per font-face: the 'font-display' descriptor

font-display

The 'font-display' descriptor for @font-face determines how a font face is displayed, based on whether and when it is downloaded and ready to use. CSS Fonts 4 §4.9

The policies, once the face has loaded

Each face is Literata, which loads from this page's origin; each stage names its family, then monospace. While a face loads, block draws invisible text for about 3s and then the fallback; swap draws the fallback at once; fallback blocks for about 100ms and swaps for about 3s; optional blocks for about 100ms and never swaps.
