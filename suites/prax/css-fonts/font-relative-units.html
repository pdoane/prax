CSS Fonts 4 · 1.2 Interaction with font-relative units

Font-affecting properties

The following properties defined in this specification are font-affecting properties: All longhands (including reset-only sub-properties) of the 'font' shorthand, except 'font-variant-emoji' and 'line-height', and All longhands of the 'font-synthesis' shorthand. A font-relative length reads the font they choose. CSS Fonts 4 §1.2

The family chooses the font that ex reads

Each bar is 10ex wide in 20px text. An ex is the x-height of the first available font.

font-size chooses the em; line-height chooses no font

Each bar is 5em wide. 'line-height' and 'font-variant-emoji' are longhands of 'font' that leave the font alone.
