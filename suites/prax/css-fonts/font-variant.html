CSS Fonts 4 · 6.11 Overall shorthand for font rendering: the 'font-variant' property

The font-variant shorthand

'font-variant' sets 'font-variant-ligatures', 'font-variant-caps', 'font-variant-alternates', 'font-variant-numeric', 'font-variant-east-asian', 'font-variant-position' and 'font-variant-emoji'. normal resets them all; none sets 'font-variant-ligatures' to none and the rest to their initial values.
