CSS Fonts 4 · 2.1.5 Generic font families

Generic families

A generic font family is a font family which has a standard name (as defined by CSS), but which is an alias for an existing installed font family present on the system. 'serif', 'sans-serif' and 'monospace' must always map to at least one matched font face. CSS Fonts 4 §2.1.5
