CSS Fonts 4 · 2.1 Font family: the 'font-family' property

font-family: a list of alternatives

A user agent iterates through the list of family names until it matches an available font that contains a glyph for the character to be rendered. CSS Fonts 4 §2.1

The first family that is available

A family that is not available is passed over, and the next one in the list sets the text.

Each character in the first family that has it

The list is walked for each character, so one run of text takes characters from several families.
