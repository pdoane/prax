CSS Fonts 4 · 8.2 Low-level font variation settings control: the 'font-variation-settings' property

font-variation-settings

'font-variation-settings' is normal | [ <opentype-tag> <number> ]#: values for a font's variation axes. Authors should use 'font-weight', 'font-width', 'font-style' and 'font-optical-sizing' for wght, wdth, slnt, ital and opsz. CSS Fonts 4 §8.2

Axes with no property

PR Roboto Flex has a grade axis, GRAD, from -200 to 150, which thickens strokes without changing advances, and parametric axes such as XTRA, the counters' width.
