CSS Fonts 4 · 2.4 Font style: the 'font-style' property

font-style: italic and oblique

Italic forms are generally cursive in nature while oblique faces are typically sloped versions of the regular face. CSS Fonts 4 §2.4

italic: an italic face

italic Matches against a font that is labeled as an italic face, or an oblique face if one does not exist.

oblique <angle>: a slant

Positive angles represent a clockwise slant; negative angles represent a counter-clockwise slant. The lack of an <angle> represents 14deg. PR Roboto Flex slants from 0 to 10 degrees.
