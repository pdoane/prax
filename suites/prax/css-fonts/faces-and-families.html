CSS Fonts 4 · 2.1.4 Relationship between faces and families

Faces and families

A font family name only specifies a name given to a set of font faces; it does not specify an individual face. CSS Fonts 4 §2.1.4

The other properties choose the face

PR Tinos is a family of three faces: regular, bold and italic. 'font-weight' and 'font-style' choose among them.

A face's name is not a family

A family is matched by its name only, so the name of one of its faces matches nothing.
