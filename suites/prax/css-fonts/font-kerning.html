CSS Fonts 4 · 6.3 Kerning: the 'font-kerning' property

font-kerning

Kerning is the contextual adjustment of inter-glyph spacing. This property controls metric kerning, kerning that utilizes adjustment data contained in the font. CSS Fonts 4 §6.3

auto, normal and none

PR Literata kerns AV, To and Yo.

Kerning, then letter-spacing

If the 'letter-spacing' property is defined, kerning adjustments are considered part of the default spacing and letter spacing adjustments are made after kerning has been applied.
