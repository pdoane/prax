CSS Fonts 4 · 4.3.1 Parsing the 'src' descriptor

Parsing src

If parsing a component value results in a parsing error or its format or tech are unsupported, do not add it to the list of supported sources. If there are no supported entries at the end of this process, the value for the 'src' descriptor is a parse error. CSS Fonts 4 §4.3.1

Unsupported entries are left out

Each rule's first entry is Cousine, a monospace, and its second Literata, a serif. Each stage names the family, then sans-serif.

The legacy format strings

format("truetype-variations") is accepted as format(truetype) tech(variations).
