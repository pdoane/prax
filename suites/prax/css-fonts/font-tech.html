CSS Fonts 4 · 11.1 Font tech

Font technologies

Web authors can specify the tech() function inside an @font-face 'src' descriptor to indicate that support is required for correct rendering of a font. This mechanism can be used for gracefully falling back to an ancillary font when requested support is not present. CSS Fonts 4 §11.1
