CSS Fonts 4 · 6.12 Low-level font feature settings control: the 'font-feature-settings' property

font-feature-settings

'font-feature-settings' is normal | <feature-tag-value>#: a four-letter tag and an optional value, 1 when left out, and on or off for 1 or 0. Authors should generally use 'font-variant' and its related subproperties whenever possible. CSS Fonts 4 §6.12
