CSS Fonts 4 · 7.2 Feature and variation precedence

Feature precedence

Settings apply in ascending order of precedence: defaults, the variations of 'font-weight', 'font-width' and 'font-style', the language, the @font-face descriptors, 'font-variant' and its subproperties, other properties, 'font-variation-settings', and last 'font-feature-settings'. For situations where the combined list of font feature settings contains more than one value for the same feature, the last value is used. CSS Fonts 4 §7.2
