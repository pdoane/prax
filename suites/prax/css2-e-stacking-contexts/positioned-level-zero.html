Painting order: positioned boxes at level 0

Step 8. Each stage forms the stacking context, and its absolutely positioned boxes are in the source in the order A, B, C.

auto and 0 together, in tree order

All positioned descendants with 'z-index: auto' or 'z-index: 0', in tree order. They come after the in-flow content and floats of steps 4 to 7. CSS 2 §E.2

auto: as if a context; 0: a context, whole

For those with 'z-index: auto', treat the element as if it created a new stacking context, but any positioned descendants and descendants which actually create a new stacking context should be considered part of the parent stacking context, not this new one. For those with 'z-index: 0', treat the stacking context generated atomically. In each figure, A holds a purple child with z-index: 1, and B overlaps it. CSS 2 §E.2
