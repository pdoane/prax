CSS 2 · E.1 Definitions

Definitions: elements, pseudo-elements and anonymous boxes

In this description, "element" refers to actual elements, pseudo-elements, and anonymous boxes. CSS 2 §E.1

Pseudo-elements take their places in the tree

Pseudo-elements and anonymous boxes are treated as descendants in the appropriate places. A :before box is the element's first child and an :after box its last. Each figure's orange box is the element's content, and a negative margin makes the pseudo-element overlap it by 24px. CSS 2 §E.1

The marker, then :before, then the content

For example, an outside list marker comes before an adjoining ':before' box in the line box, which comes before the content of the box, and so forth. In each figure, a list item has a red square marker outside it. CSS 2 §E.1
