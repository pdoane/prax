CSS 2 · E.2 Painting order

Painting order: an inline that forms a stacking context

Each stage forms a stacking context, and holds a relative span that forms one too, with a z-index. The span's own background and border are painted only on its lines.

Its steps in order

For the span, step 2 paints nothing: it is not a block. Then step 3, Stacking contexts formed by positioned descendants with negative z-indices; step 4, its in-flow, non-positioned, block-level descendants; step 5, All non-positioned floating descendants; and step 7: If the element is an inline element that generates a stacking context, then: For each line box that the element is in, its own background, border and content.
