CSS 2 · E.2 Painting order

Painting order: line by line

An inline's content is painted one line box at a time: its background on a line, then its text on that line, then the next line. In each figure, an inline has 10px of padding above and below, so that its background on one line reaches up over the text of the line before.

An inline that forms a stacking context

If the element is an inline element that generates a stacking context, then: For each line box that the element is in: Jump to 7.2.1 for the box(es) of the element in that line box (in tree order). CSS 2 §E.2

Any inline, line by line

Otherwise, for each line box of that element: For each box that is a child of that element, in that line box, in tree order: background color of element. background image of element. border of element. then its text and children, before the next line box. CSS 2 §E.2
