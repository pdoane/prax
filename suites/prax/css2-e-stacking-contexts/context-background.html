CSS 2 · E.2 Painting order

Painting order: the context's background and border

Step 2 paints the element that forms the stacking context, before all its content. Each figure's element forms one with position: relative; z-index: 0, and is orange.

Color, then image, then border

If the element is a block, list-item, or other block equivalent: background color of element unless it is the root element. background image of element unless it is the root element. border of element. CSS 2 §E.2

Before everything in it

The element's background and border are painted before any of its descendants, including those with negative stack levels (step 3). CSS 2 §E.2
