CSS 2 · E.2 Painting order

Painting order: outlines since CSS 2

CSS 2 placed outlines in step 7 or step 10 of their stacking context. A later specification takes outlines out of the painting order altogether. Each figure's red outline is 4px wide.

Since CSS 2 · CSS Basic User Interface 4 §3

Stacking left to the implementation

The stacking of the rendering of these outlines is explicitly left up to implementations to provide a better user experience per platform. This supersedes the stacking of outlines as defined in Appendix E of CSS 2.1 CSS Basic User Interface 4 §3. An outline may now be drawn above or below any content, including content of other stacking contexts; neither order in these figures is required.
