CSS 2 · E.2 Painting order

Painting order: text and its decorations

If this is a run of text, then: underlining, then overlining, then the text, then line-through. The decorations here are made thick, with text-decoration-thickness, so that the order shows.

Under and over lines below the text, line-through above it

any underlining affecting the text of the element, any overlining affecting the text of the element, the text., any line-through affecting the text of the element. CSS 2 §E.2

The deepest element's decoration on top

in tree order of the elements applying the underlining (such that the deepest element's underlining, if any, is painted topmost and the root element's underlining, if any, is drawn bottommost). CSS 2 §E.2
