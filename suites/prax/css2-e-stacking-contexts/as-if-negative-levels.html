CSS 2 · E.2 Painting order

Painting order: negative levels out of their boxes

Each stage forms the stacking context. The blue box in each has z-index: -1, and the stage is its containing block.

Into the stacking context's step 3

An inline block is painted as if it created a new stacking context, but any positioned descendants and descendants which actually create a new stacking context should be considered part of the parent stacking context, not this new one.
