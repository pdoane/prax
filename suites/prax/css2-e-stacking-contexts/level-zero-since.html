Since CSS 2 · CSS Positioned Layout 3 §2.2

A fixed box is a stacking context, whatever its z-index

When z-index is auto: Fixed and sticky positioned boxes nonetheless form a stacking context. CSS Positioned Layout 3 §2.2 In CSS 2, a fixed box's positioned descendants joined its parent's context; now they stay in its own.

Since CSS 2 · CSS Color 4 §3.3, CSS Transforms 1 §3

Stacking contexts that are not positioned

A box with opacity below 1 is otherwise painted on the same layer within its parent stacking context as positioned elements with stack level 0 CSS Color 4 §3.3, and so is one with a transform CSS Transforms 1 §3: whole, in step 8, not split between steps 4 and 7.
