CSS 2 · E.1 Definitions

Definitions: tree order

Where boxes are painted in the same step, tree order decides which comes first, and a later box covers an earlier one. Every box on this page is positioned with z-index: auto, so all of them are painted in one step.

Preorder, depth-first

Tree order is the Preorder depth-first traversal of the rendering tree, in logical (not visual) order for bidirectional content, after taking into account properties that move boxes around. CSS 2 §E.1

Logical, not visual, order

In bidirectional content, tree order follows the source, not the line's left to right. CSS 2 §E.1
