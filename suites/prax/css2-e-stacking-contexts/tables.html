CSS 2 · E.2 Painting order

Painting order: tables

A table is painted layer by layer, the same whether it forms the stacking context (step 2) or is one of its block-level descendants (step 4), as the tables here are.

Six layers of backgrounds

table backgrounds (color then image). column group backgrounds (color then image). column backgrounds (color then image). row group backgrounds (color then image). row backgrounds (color then image). cell backgrounds (color then image). CSS 2 §E.2

Borders after every background

all table borders (in tree order for separated borders). In the collapsing border model, a cell's border is shared with its neighbor, half in each cell. CSS 2 §E.2
