CSS Text Decoration 4 · 2.9 Text Decoration Line Uniformity

One line per decorating box per line

However, for underlines and overlines the UA must use a single thickness and position on each line for the decorations deriving from a single decorating box. CSS Text Decoration 4 §2.9 The outer underline is red, an inner one blue; the text is PR Literata.

A shifted decorating box moves its own line; a shifted descendant does not move its ancestor's

UAs must adjust line positions to match the shifted metrics of decorating boxes shifted with 'vertical-align' values other than baseline [CSS2] or subscripted/superscripted via 'font-variant-position' [CSS-FONTS-3], but must not adjust the line position or thickness in response to descendants of a decorating box that are so styled
