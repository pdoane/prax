CSS Text Decoration 4 · 2.10 Text Decoration Line Continuity: the text-decoration-skip shorthand and its sub-properties

text-decoration-skip

The none value sets all sub-properties to none, and the auto value sets all sub-properties to their initial values. CSS Text Decoration 4 §2.10 Each line is red and 3px thick.

none: nothing skipped; auto: the initial skipping

The sub-properties: text-decoration-skip-self, -skip-box, -skip-spaces and -skip-ink. Each stage has two spaces before "gyp" and two after, preserved.

ins and del

The following addition is made to the default UA stylesheet for HTML: ins, del { text-decoration-skip: none; }
