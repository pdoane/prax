CSS Text Decoration 4 · 2.9.1 Trimming, Expanding, and Shifting Text Decoration Lines: the text-decoration-inset property

text-decoration-inset

This property adjusts the start and end endpoints of line decorations. Positive values move an endpoint inward, trimming the decoration; negative values move it outward, extending the decoration. CSS Text Decoration 4 §2.9.1 The text is monospace, 10px a character, from x=40; each underline red and 3px thick.

Lengths and percentages

If two component values are given, the first applies to the start and the second to the end. Percentages refer to the total inline size of the decorating box under the initial box-decoration-break: slice.

auto: neighbors stay apart

auto: The UA chooses an inset amount that ensures that if two identical underlined elements appear side-by-side they do not appear to have a single underline. (This is important in Chinese, where underlining is a form of punctuation.)
