CSS Text Decoration 4 · 2.7 Text Underline Position: the text-underline-position property

text-underline-position

It sets the position of an underline with respect to the text. It affects all decorations originating from this element, even if descendant boxes specify a different position. It does not affect underlines specified by ancestor elements. CSS Text Decoration 4 §2.7 Each underline is red and 2px thick, and red dashes mark the baseline.

auto, under, from-font

auto: it must be placed at or under the alphabetic baseline. under: The underline is positioned under the element's text content. from-font: If the first available font has metrics indicating a preferred underline offset, use that offset.
