CSS Text Decoration 4 · 3.1 Emphasis Mark Style: the text-emphasis-style property

text-emphasis-style

This property applies emphasis marks to the element's text. CSS Text Decoration 4 §3.1 The marks should be drawn using the element's font settings with the addition of the ruby feature and the size scaled down 50%.

The shapes, filled and open

The shape is filled with solid color. The shape is hollow. If a shape keyword is specified but neither of filled nor open is specified, filled is assumed.

A string

Display the given string as marks. The UA may truncate or ignore strings consisting of more than one grapheme cluster.
