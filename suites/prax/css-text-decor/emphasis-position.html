CSS Text Decoration 4 · 3.4 Emphasis Mark Position: the text-emphasis-position property

text-emphasis-position

Emphasis marks are drawn exactly as if each character was assigned the mark as its ruby annotation text with the ruby position given by 'text-emphasis-position' and the ruby alignment as centered. CSS Text Decoration 4 §3.4 Red dots.

over and under across, right and left down

over, under: Draw marks over the text in horizontal typographic modes. and under it; right, left: Draw marks to the right of the text in vertical typographic modes. and to the left. The initial value is over right.

Room on the line as ruby takes it

The effect of emphasis marks on the line height is the same as for ruby text. Two lines of 20px text on 20px lines, each line's first two characters marked.
