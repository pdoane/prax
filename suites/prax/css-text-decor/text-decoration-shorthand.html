CSS Text Decoration 4 · 2.6 Text Decoration Shorthand: the text-decoration property

The text-decoration shorthand

This property is a shorthand for setting 'text-decoration-line', 'text-decoration-thickness', 'text-decoration-style', and 'text-decoration-color' in one declaration. Omitted values are set to their initial values. CSS Text Decoration 4 §2.6

All four in one declaration

Omitted values are reset; the position is not among them

The shorthand purposefully omits the 'text-underline-position' property, which is a language/writing-system–dependent setting that keys off the content, so that it can cascade and inherit independently from the (uninherited) stylistic settings of the 'text-decoration' shorthand.
