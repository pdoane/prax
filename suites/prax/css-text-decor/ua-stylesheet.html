CSS Text Decoration 4 · B Default UA Stylesheet

The default UA stylesheet

This appendix is informative, and is to help UA developers to implement default stylesheet, but UA developers are free to ignore or change. CSS Text Decoration 4 §B No browser is flagged here; each caption says what the sheet suggests.

HTML's decorated elements

s, strike, del { text-decoration: line-through; }
u, ins, :link, :visited { text-decoration: underline; }
abbr[title], acronym[title] { text-decoration: dotted underline; }
rt { text-emphasis: none; }

Positions by language

:root:lang(zh), [lang|=zh] { text-emphasis-position: under right; }
:root:lang(zh), [lang|=zh] { text-underline-position: left; }
:root:lang(ja), [lang|=ja] { text-underline-position: right; }
