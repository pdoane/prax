CSS Text Decoration 4 · 3.3 Emphasis Mark Shorthand: the text-emphasis property

The text-emphasis shorthand

This property is a shorthand for setting 'text-emphasis-style' and 'text-emphasis-color' in one declaration. Omitted values are set to their initial values. CSS Text Decoration 4 §3.3

Style and color

The position is not reset

Note that 'text-emphasis-position' is not reset in this shorthand.
