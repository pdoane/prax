CSS Text Decoration 4 · 2.8 Text Underline Offset: the text-underline-offset property

text-underline-offset

It sets the offset of underlines from their zero position. Positive offsets represent distances outward from the text; negative offsets inward. CSS Text Decoration 4 §2.8 Each underline is red and 2px thick; red dashes mark the baseline.

Lengths and percentages

A percentage value specifies the offset of underlines as a percentage of the used 'font-size'.

Outward, whichever side

In vertical-rl, with left and right, the underline moves away from the text by 10px.
