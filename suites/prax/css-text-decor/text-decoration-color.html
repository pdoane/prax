CSS Text Decoration 4 · 2.3 Text Decoration Color: the text-decoration-color property

text-decoration-color

It sets the color of underlines, overlines, and line-throughs specified on the element with 'text-decoration-line', and affects all decorations originating from this element even if descendant boxes specify a different color. CSS Text Decoration 4 §2.3 Its initial value is currentcolor. Each line is 3px thick.
