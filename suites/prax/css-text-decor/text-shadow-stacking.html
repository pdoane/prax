CSS Text Decoration 4 · 4 Text Shadows: the text-shadow property, painting

Where text shadows paint

Outer text shadows must be painted at a stack level between the element's border/background (if present) and the elements text and text decoration. CSS Text Decoration 4 §4

Over its background, under its text

No room in the layout

Like 'box-shadow', text shadows do not influence layout, and do not trigger scrolling or increase the size of the scrollable overflow region.
