CSS Text Decoration 4 · 2.1 Text Decoration Lines: the text-decoration-line property

spelling-error and grammar-error

This value indicates the type of text decoration used by the user agent to highlight spelling mistakes. Its appearance is UA-defined, and may be platform-dependent. CSS Text Decoration 4 §2.1 grammar-error is the same for grammar mistakes.

The user agent's own look

A note: It is often rendered as a red wavy underline. It is often rendered as a green wavy underline.

Nothing else changes it

When spelling-error or grammar-error apply, the user agent must disregard the other sub-properties of 'text-decoration', as well any other properties typically affecting the appearance of line decorations (such as 'text-underline-position', 'color', 'stroke', or 'fill') when rendering these decorations.
