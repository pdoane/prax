CSS Text Decoration 4 · 2.9.1 Trimming, Expanding, and Shifting Text Decoration Lines: the text-decoration-inset property, fragments

text-decoration-inset across lines

The adjustment of the text decoration's endpoints is subject to 'box-decoration-break'. CSS Text Decoration 4 §2.9.1 Each stage holds "aaaa bbbb cccc" in monospace: three lines, each x=0 to 40.

slice: the box's two ends

for slice (the default) endpoint adjustment is only applied to the start edge of the first fragment and the end edge of the last fragment, and may accumulate to other fragments if the amount of the inset is more than the length of the fragment.

clone: each fragment's ends

for clone endpoint adjustment is applied to each fragment independently. Percentages then refer to the inline size of each individual box fragment.
