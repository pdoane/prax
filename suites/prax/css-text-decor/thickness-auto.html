CSS Text Decoration 4 · 2.4.1 Automatic Thickness of Text Decoration Lines

Automatic thickness from the font

Some font formats (such as OpenType) can offer information about the appropriate thickness of a line decoration. The UA should use such font-based information when choosing auto line thicknesses wherever appropriate. CSS Text Decoration 4 §2.4.1
