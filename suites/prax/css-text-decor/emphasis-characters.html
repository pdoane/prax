CSS Text Decoration 4 · 3.1 Emphasis Mark Style: the text-emphasis-style property, characters

Which characters get emphasis marks

The marks are drawn once for each typographic character unit. However, emphasis marks are not drawn for: separators (Z*), most punctuation (P*), and control codes and unassigned characters (Cc, Cf, Cn). CSS Text Decoration 4 §3.1 Every stage has text-emphasis: dot, red.

One mark per character unit; none for spaces

Word separators or other characters that belong to the Unicode separator classes (Z*). (But note that emphasis marks are drawn for a space that combines with any combining characters.)

No marks on punctuation, but on these symbols

Punctuation--specifically, any characters that belong to the Unicode P* general category and do not NFKD normalize [UAX15] to any of the following symbols: # % ‰ ‱ ٪ ؉ ؊ & ⁊ @ § ¶ ⁋ ⁓ 〽.
