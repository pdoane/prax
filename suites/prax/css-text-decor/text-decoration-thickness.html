CSS Text Decoration 4 · 2.4 Text Decoration Line Thickness: the text-decoration-thickness property

text-decoration-thickness

It sets the stroke thickness of underlines, overlines, and line-throughs specified on the element with 'text-decoration-line', and affects all decorations originating from this element even if descendant boxes specify a different thickness. CSS Text Decoration 4 §2.4

A length, or a percentage of the font size

A percentage value specifies the thickness of text decoration lines as a percentage of the used 'font-size'. The UA should round the actual value to the nearest integer device pixel, and ensure it is at least one device pixel.

from-font

If the first available font has metrics indicating a preferred underline width, use that width, otherwise behaves as auto. Each says "Gag" at 60px; the underline is red.
