Emphasis marks

East Asian documents traditionally use small symbols next to each glyph to emphasize a run of text. The 'text-emphasis' shorthand, and its 'text-emphasis-style' and 'text-emphasis-color' longhands, can be used to apply such marks to the text. CSS Text Decoration 4 §3
