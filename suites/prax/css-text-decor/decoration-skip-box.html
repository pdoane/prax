CSS Text Decoration 4 · 2.10.2 Skipping Spaces: the text-decoration-skip-box property

text-decoration-skip-box

This property specifies what parts of the element's box area any text decoration affecting the element must skip over. It controls only text decoration lines drawn by its ancestors. CSS Text Decoration 4 §2.10.2 In each stage the outer span is underlined in red; "c" is in an inner span, dashed, with a 10px margin, a transparent 10px border and 10px padding on each side. The text is monospace, 10px a character.

none and all

none: Skip nothing: line decorations from ancestor decorating boxes are drawn from margin edge to margin edge. all: skip over the box's own margin, border, and padding areas and only draw line decorations within its content area.

Never over the decorating box's own

This value only has an effect for decorations imposed by an ancestor; a decorating box never draws over its own box decoration.
