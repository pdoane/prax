CSS Text Decoration 4 · 4 Text Shadows: the text-shadow property

text-shadow

This property accepts a comma-separated list of shadow effects to be applied to the text of the element. Values are interpreted as for 'box-shadow'. CSS Text Decoration 4 §4

Offset, blur and color

Several, the first on top; decorations shadowed too

Each layer shadows the element's text and all its text decorations (composited together). The shadow effects are applied front-to-back: the first shadow is on top.
