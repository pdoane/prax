CSS Text Decoration 4 · 3.1 Emphasis Mark Style: the text-emphasis-style property, vertical

text-emphasis-style in vertical text

If only filled or open is specified, the shape keyword computes to circle in horizontal typographic modes and sesame in vertical typographic modes. Marks must remain upright in vertical typographic modes: like CJK characters, they do not rotate to match the writing mode. CSS Text Decoration 4 §3.1
