CSS Text Decoration 4 · 2.8.2 Using Font Metrics for Automatic Positioning

The font's underline position

The UA should use such font-based information in its choice of auto offset wherever appropriate, and must use such information when from-font is specified for 'text-underline-position'. CSS Text Decoration 4 §2.8.2 "Gag" at 50px in two fonts: PR Underline Test Far puts its underline 300/2048 em below the baseline, 7px; PR Underline Test Thick, 150/2048 em, about 4px. Each line is red and 2px thick; red dashes mark the baseline.

from-font must use it

With from-font, auto offset must be zero if the computed value of 'text-underline-position' is from-font and the UA was able to extract an appropriate metric to use from the font.
