CSS Text Decoration 4 · 2.2 Text Decoration Style: the text-decoration-style property

text-decoration-style

It sets the line-drawing style of underlines, overlines, and line-throughs specified on the element with 'text-decoration-line', and affects all decorations originating from this element even if descendant boxes specify a different style. CSS Text Decoration 4 §2.2

The styles

Values have the same meaning as for the border-style properties. wavy indicates a wavy line. Each underline is red and 2px thick.

A descendant's style does not change it
