CSS 2 · 18.1 Cursors: the 'cursor' property

Cursor: resizing and inheritance

cursor takes [ [<uri> ,]* [ auto | crosshair | default | pointer | ... ] ] | inherit. Initial auto, inherited, applies to all elements. Hover a row to see its cursor.

Resize cursors

Indicate that some edge is to be moved. For example, the 'se-resize' cursor is used when the movement starts from the south-east corner of the box. CSS 2 §18.1

Initial value and inheritance

Initial: auto. Inherited: yes. CSS 2 §18.1
