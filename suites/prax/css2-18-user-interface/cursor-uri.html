CSS 2 · 18.1 Cursors: the 'cursor' property

Cursor: URIs

A list of cursor images, then a generic cursor that is used when none of them can be. Hover a row to see its cursor.

<uri>, with a generic cursor at the end

If the user agent cannot handle the first cursor of a list of cursors, it should attempt to handle the second, etc. If the user agent cannot handle any user-defined cursor, it must use the generic cursor at the end of the list. CSS 2 §18.1

Since CSS 2 · CSS Basic User Interface 4 §5.1.1

The next image must be tried, and PNG and SVG must work

If the user agent cannot handle the first cursor of a list of cursors, it must attempt to handle the second, etc. The UA must support the following image file formats: PNG and SVG if it has a natural size. CSS Basic User Interface 4 §5.1.1 CSS 2's should is now a must, and CSS 2 named no format.
