CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outline color

outline-color takes <color> | invert | inherit. Initial invert, not inherited; computed as specified. Every figure's outline is solid and 10px wide.

<color>

The 'outline-color' accepts all colors, as well as the keyword 'invert'. CSS 2 §18.4

invert, and the initial value

'Invert' is expected to perform a color inversion on the pixels on the screen. Conformant UAs may ignore the 'invert' value on platforms that do not support color inversion of the pixels on the screen. If the UA does not support the 'invert' value then the initial value of the 'outline-color' property is the value of the 'color' property. CSS 2 §18.4
