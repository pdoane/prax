CSS 2 · 18.2 System Colors

System colors

Note. The System Colors are deprecated in the CSS3 Color Module. Each name is a color the user agent takes from the operating system, so what these swatches show depends on the platform.

Colors of the user's graphic environment

Any color property (e.g., 'color' or 'background-color') can take one of the following names. They let authors specify colors in a manner that integrates them into the operating system's graphic environment. CSS 2 §18.2

The specification's example

For example, to set the foreground and background colors of a paragraph to the same foreground and background colors of the user's window, write the following: p { color: WindowText; background-color: Window }. The names are case-insensitive. CSS 2 §18.2
