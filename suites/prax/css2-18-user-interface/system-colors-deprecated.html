CSS 2 · 18.2 System Colors

System colors since CSS 2

CSS Color 4 keeps a smaller set of system colors, with new names, and maps every name of CSS 2's list that it dropped onto one of them.

Since CSS 2 · CSS Color 4 Appendix A

The deprecated names take the colors of the new ones

User agents must support these keywords, and to mitigate fingerprinting must map them to the (undeprecated) system colors as listed below. Authors must not use these keywords.
