CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outline style: the 3D values

outline-style takes <border-style> | inherit, without hidden. Every figure's outline is 10px wide, drawn round a light box 20px tall.

groove, ridge, inset and outset

The 'outline-style' property accepts the same values as 'border-style': four styles that draw the outline in shades of its color. CSS 2 §18.4, §8.5.3

In another color
