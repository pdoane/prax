CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outlines around split inline boxes

Outlines may be non-rectangular. Each figure's highlighted span breaks over three lines.

The minimum outline that encloses all the boxes

For example, if the element is broken across several lines, the outline is the minimum outline that encloses all the element's boxes. In contrast to borders, the outline is not open at the line box's end or start, but is always fully connected if possible. CSS 2 §18.4

Since CSS 2 · CSS Basic User Interface 4 §3.1

A set of outlines, each closed, following the corners

the outline should be an outline or minimum set of outlines that encloses all the element’s boxes. Each part of the outline should be fully connected rather than open on some sides. it should follow the border-radius curve. CSS Basic User Interface 4 §3.1
