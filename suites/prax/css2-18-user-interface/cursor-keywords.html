CSS 2 · 18.1 Cursors: the 'cursor' property

Cursor: the keywords

This property specifies the type of cursor to be displayed for the pointing device. A screenshot shows no cursor: hover a row, which names its declaration.

General cursors

auto: The UA determines the cursor to display based on the current context. The others name a cursor: The platform-dependent default cursor. Often rendered as an arrow. CSS 2 §18.1

Since CSS 2 · CSS Basic User Interface 4 §5.1.1.1

auto is text over text, default elsewhere

The UA determines the cursor to display based on the current context: auto behaves as text over selectable text or editable elements, and default otherwise. CSS Basic User Interface 4 §5.1.1.1
