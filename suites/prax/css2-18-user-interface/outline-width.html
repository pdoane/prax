CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outline width

outline-width takes <border-width> | inherit: thin | medium | thick | <length>. Initial medium, not inherited. Every figure's outline is solid and blue unless it says otherwise; a caption reads back a width too thin to measure off the guides.

Keywords and lengths

The 'outline-width' property accepts the same values as 'border-width'. CSS 2 §18.4

The initial value

Initial: medium. CSS 2 §18.4
