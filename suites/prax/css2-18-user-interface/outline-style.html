CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outline style: the values

outline-style takes <border-style> | inherit. Initial none, not inherited, applies to all elements. Every figure's outline is 10px wide and blue, drawn round a light box 20px tall with 20px of stage around it.

The values of border-style

The 'outline-style' property accepts the same values as 'border-style', except that 'hidden' is not a legal outline style. CSS 2 §18.4
