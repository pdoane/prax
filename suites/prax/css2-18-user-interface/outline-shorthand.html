CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outline: the shorthand

outline takes [ <'outline-color'> || <'outline-style'> || <'outline-width'> ] | inherit. Not inherited, applies to all elements.

Any of the three, in any order

The 'outline' property is a shorthand property, and sets all three of 'outline-style', 'outline-width', and 'outline-color'. One that is left out takes its initial value. CSS 2 §18.4

The same on all sides

The outline is the same on all sides. In contrast to borders, there is no 'outline-top' or 'outline-left' property. The specification's example: button { outline : thick solid}. CSS 2 §18.4
