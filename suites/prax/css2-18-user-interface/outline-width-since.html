CSS 2 · 18.4 Dynamic outlines: the 'outline' property

Outline width since CSS 2

Later specifications fix the widths of the keywords and round widths to whole device pixels. Every outline is solid and blue.

Since CSS 2 · CSS Borders and Box Decorations 4 §2.3, CSS Values and Units 4 §6

Keywords are 1px, 3px and 5px, and widths snap to device pixels

The thin, medium, and thick keywords are equivalent to 1px, 3px, and 5px, respectively. CSS Borders and Box Decorations 4 §2.3 Computed value: absolute length, snapped as a border width CSS Basic User Interface 4 §3.2: If the absolute value of len is greater than 1 device pixel, round it towards zero to the nearest integer number of device pixels. CSS Values and Units 4 §6 CSS 2 left the keywords to the UA and did not round.
