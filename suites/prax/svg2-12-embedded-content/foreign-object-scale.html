SVG 2 · 12.2 Placement of the embedded content

foreignObject: laid out in user units

The scale of the containing block is defined in the current coordinate system, including all explicit and implicit (e.g., ‘viewBox’) transformations. SVG 2 §12.2 Each stage is an SVG 160 by 60. In each, a foreignObject at 10, 5, 60 by 20 in user units, outlined dashed grey, holds the HTML box A, width: 20px; height: 10px.

Implicit and explicit scale

Each scales its user units by 2, so the foreignObject covers 20 to 140 across and 10 to 50 down on the stage, and a CSS pixel inside it is 2 of the stage's.
