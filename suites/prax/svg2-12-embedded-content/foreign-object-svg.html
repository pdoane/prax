SVG 2 · 12.4 The ‘foreignObject’ element

foreignObject: SVG only under an svg element

SVG-namespaced elements within a ‘foreignObject’ will not be rendered, except in the situation where a properly defined SVG fragment, including a root ‘svg’ element is defined as a descendent of the ‘foreignObject’. SVG 2 §12.4
