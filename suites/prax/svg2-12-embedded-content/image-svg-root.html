The root's preserveAspectRatio is ignored

For ‘image’ elements embedding an SVG image, the ‘preserveAspectRatio’ attribute on the root element in the referenced SVG image must be ignored, and instead treated as if it had a value of none.

No viewBox, but a size

The text does not say how such an SVG scales; the working group resolved to synthesize a viewBox from width and height (svgwg#249).
