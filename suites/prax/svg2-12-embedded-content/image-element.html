SVG 2 · 12.3 The ‘image’ element

image: a whole file in a rectangle

The ‘image’ element indicates that the contents of a complete file are to be rendered into a given rectangle within the current user coordinate system. SVG 2 §12.3 Each stage is an SVG 160 by 60 with an image at 40, 10, 80 by 40, of a flag 40 by 20 in quarters unless a figure says otherwise.

PNG, JPEG and SVG

Conforming SVG viewers need to support at least PNG, JPEG and SVG format files.

Always four channels

The result of processing an ‘image’ is always a four-channel RGBA result. An image with three channels is as if converted with the alpha channel uniformly set to 1; a grayscale one as if the single channel from the referenced object is used to compute the three color channels and the alpha channel is uniformly set to 1. A purple bar runs behind each image, from y 20 to 40.
