SVG 2 · 12.3 The ‘image’ element

image: a separate document

The resource referenced by the ‘image’ element represents a separate document which generates its own parse tree and document object model (if the resource is XML). Thus, there is no inheritance of properties into the image. SVG 2 §12.3 Each stage is an SVG 160 by 60 with an image at 40, 10, 80 by 40, of an SVG 40 by 20.

No inheritance, no styles

The SVG has two squares 20 by 20: the left one with no fill, the right one with fill="currentColor". Its own initial values make both black.

A secure mode

SVG files must be processed in secure animated mode if the current document supports animation, or in secure static mode if the current document is static. Neither loads external resources nor runs scripts §2.2.4.
