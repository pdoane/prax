SVG 2 · 12.3 The ‘image’ element

image: object-fit, then preserveAspectRatio

The ‘preserveAspectRatio’ attribute determines how the referenced image is scaled and positioned to fit into the concrete object size determined from the positioning rectangle and the object-fit and object-position properties. The result of applying this attribute defines an image-rendering rectangle used for actual image rendering. SVG 2 §12.3 Each stage is an SVG 160 by 60 with an image of the PNG flag, 40 by 20 in quarters, at 20, 10, 120 by 40, outlined dashed grey.

object-fit fill: preserveAspectRatio fits

With the initial object-fit: fill, the concrete object size is the rectangle, and preserveAspectRatio fits the image into it.

Any other object-fit: preserveAspectRatio has nothing to do

If a value of object-fit is used that ensures that the concrete object size matches the intrinsic aspect ratio (i.e., any value other than the default fill), then the ‘preserveAspectRatio’ value will have no effect; the image-rendering rectangle will be that determined when scaling and positioning the object with CSS.
