SVG 2 · 12.2 Placement of the embedded content

foreignObject: a containing block

When the embedded content consists of a document fragment (e.g., a ‘foreignObject’), the positioning rectangle defines the bounds of a containing block for laying out the child content using CSS. SVG 2 §12.2 Each stage is an SVG 160 by 60 with a foreignObject at 20, 10, 120 by 40, outlined dashed grey. A and B are HTML boxes, each a line 20 tall.

The containing block

Implicitly absolutely positioned

The ‘foreignObject’, or other element that is positioned using SVG layout attributes, is implicitly absolutely-positioned for the purposes of CSS layout. As a result, any absolutely-positioned child elements are positioned relative to this containing block. No box of the page around the stage is positioned.
