SVG 2 · 12.4 The ‘foreignObject’ element

foreignObject in a switch

A ‘foreignObject’ may be used in conjunction with the ‘switch’ element and the ‘requiredExtensions’ attribute to provide proper checking for user agent support and provide an alternate rendering in case user agent support is not available. SVG 2 §12.4 Each stage is an SVG 160 by 60 with a switch: a foreignObject at 20, 10, 120 by 40, holding the HTML box A, a line 20 tall, then an orange rect the same size and place.

The first child that passes

The rect is drawn only when the foreignObject fails its test, which passes If all of the given extensions are supported §5.6.4.

HTML's namespace as an extension

This specification does not define how ‘requiredExtensions’ values should be mapped to support for different XML languages; the working group since resolved to Limit namespaces for requiredExtensions to HTML and MathML (svgwg#138), so those two are supported.
