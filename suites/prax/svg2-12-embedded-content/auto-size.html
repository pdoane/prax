SVG 2 · 12.2 Placement of the embedded content

auto: an image sized from its resource

The 'auto' value for width or height is used to size the corresponding element automatically based on the intrinsic dimensions or intrinsic aspect ratio of the referenced resource. SVG 2 §12.2 It is the initial value. The flag is 40 by 20 in quarters, blue, orange, green, purple.

A natural size, a natural ratio

By the Default Sizing Algorithm defined for replaced elements in CSS layout. Each stage is an SVG 160 by 60, each image at 20, 10.

No natural size: 300 by 150

when the referenced resource does not have an intrinsic size (such as image types with no defined dimensions), it is assumed to have a width of 300px and a height of 150px. Each stage is an SVG 160 by 80 with viewBox="0 0 320 160", user units of half a pixel; each image at 0, 0 has neither attribute.
