SVG 2 · 12.3 The ‘image’ element

image: URL fragments

To link into particular view of an embedded SVG image, authors can use media fragments as defined in Linking into SVG content. SVG 2 §12.3 Each stage is an SVG 160 by 60 with an image at 40, 10, 80 by 40, outlined dashed grey, of the flag, 40 by 20 in quarters, blue, orange, green, purple.

Not an element within a file

Unlike ‘use’, the ‘image’ element cannot reference elements within an SVG file. image references always refer to a complete document. The SVG is the flag, 40 by 20 in quarters, each quarter a rect with an id.

A view of an SVG

The fragment specifies the initial view into the SVG document §16.3.1: each gives the orange quarter's 20 by 10 as the viewBox. Either type of fragment may affect the intrinsic dimensions and/or intrinsic aspect ratio of the image, but the quarter has the flag's ratio, 2 to 1.
