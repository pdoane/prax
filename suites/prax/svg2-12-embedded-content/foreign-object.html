SVG 2 · 12.4 The ‘foreignObject’ element

foreignObject: other vocabularies, under SVG's effects

The ‘foreignObject’ element allows for inclusion of elements in a non-SVG namespace which is rendered within a region of the SVG graphic using other user agent processes. SVG 2 §12.4 Each stage is an SVG 160 by 60 with a foreignObject at 40, 10, 80 by 40, holding the HTML boxes A and B, each a line 20 tall and 80 wide.

Transformed, filtered, clipped, masked, composited

The included foreign graphical content is subject to SVG transformations, filters, clipping, masking and compositing.
