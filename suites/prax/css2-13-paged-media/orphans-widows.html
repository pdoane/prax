CSS 2 · 13.3.2 Breaks inside elements: orphans, widows

orphans and widows

The 'orphans' property specifies the minimum number of lines in a block container that must be left at the bottom of a page. The 'widows' property specifies the minimum number of lines in a block container that must be left at the top of a page.
