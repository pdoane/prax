CSS 2 · 13.3.1 Page break properties: page-break-before, page-break-after, page-break-inside

page-break-before: left and right

A conforming user agent may interpret the values 'left' and 'right' as 'always'. CSS 2 §13.3.1 The stills print each figure's document on pages of 240 by 160, set by a CSS 3 size; the root's blue background marks each page area; Safari paints it on the last page only as far down as the content.

left and right

left: Force one or two page breaks before (after) the generated box so that the next page is formatted as a left page. Left pages have a 60px left margin, right pages a 60px right margin.
