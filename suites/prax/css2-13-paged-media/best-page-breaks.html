CSS 2 · 13.3.5 "Best" page breaks

"Best" page breaks

CSS 2 does not define which of a set of allowed page breaks must be used But CSS 2 does recommend that user agents observe the following heuristics: Break as few times as possible. Avoid breaking inside a replaced element.
