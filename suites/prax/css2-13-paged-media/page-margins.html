CSS 2 · 13.2.1 Page margins

Page margins

In CSS 2, only the margin properties ('margin-top', 'margin-right', 'margin-bottom', 'margin-left', and 'margin') apply within the page context. CSS 2 §13.2.1 The stills print each figure's document on pages of 240 by 160, set by a CSS 3 size; the root's blue background marks each page area; Safari paints it on the last page only as far down as the content.

Margins on all pages

Here is a simple example which sets all page margins on all pages, 3cm at the scale of these pages. Percentage values on the margin properties are relative to the dimensions of the page box; for left and right margins, they refer to the width of the page box while for top and bottom margins, they refer to the height of the page box.
