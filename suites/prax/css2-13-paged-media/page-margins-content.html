CSS 2 · 13.2.1 Page margins

Content in the page margins

The page context has no notion of fonts, so 'em' and 'ex' units are not allowed. CSS 2 §13.2.1 The stills print each figure's document on pages of 240 by 160, set by a CSS 3 size; the root's blue background marks each page area; Safari paints it on the last page only as far down as the content.

Content outside the page box

Due to negative margin values (either on the page box or on elements) or absolute positioning content may end up outside the page box, but this content may be "cut".

Since CSS 2 · CSS Paged Media 3 §6

Font-relative units in the page context

Values in units of 'em' and 'ex' are interpreted relative to the font associated with their context. CSS 2 allowed none: The page context has no notion of fonts. CSS Paged Media 3 §6
