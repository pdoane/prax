CSS 2 · 9.3.2 Box offsets: 'top', 'right', 'bottom', 'left'

Box offsets: percentages

top, right, bottom and left take <length> | <percentage> | auto. Each stage is 200 by 100 and the containing block of the absolutely positioned box in it, 60 by 20.

<percentage>

The offset is a percentage of the containing block's width (for 'left' or 'right') or height (for 'top' and 'bottom'). Negative values are allowed. CSS 2 §9.3.2
