CSS 2 · 9.5.2 Controlling flow next to floats: the 'clear' property

The clear property: when there is clearance

Clearance is computed from the hypothetical position of the box's top border edge, where the actual top border edge would have been if the element's 'clear' property had been 'none'. Every named box is 20px tall unless it says otherwise; the guides are 10px apart.

Level with the float's bottom

If this hypothetical position of the element's top border edge is not past the relevant floats, then clearance is introduced, and margins collapse according to the rules in 8.3.1.
