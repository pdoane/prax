CSS 2 · 9.2.4 The 'display' property

The display property

display takes inline | block | list-item | inline-block | table | inline-table | table-* and none. Initial inline, not inherited. Each orange box has width: 60px; height: 30px; margin: 0 10px.

block, inline-block and inline

block: This value causes an element to generate a principal block box. inline-block: ... The inside of an inline-block is formatted as a block box, and the element itself is formatted as an atomic inline-level box. inline: This value causes an element to generate one or more inline boxes. CSS 2 §9.2.4

list-item, and the initial value

list-item: This value causes an element (e.g., LI in HTML) to generate a principal block box and a marker box. An element no style sheet gives a display is inline. CSS 2 §9.2.4
