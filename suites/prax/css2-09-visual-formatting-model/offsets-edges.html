CSS 2 · 9.3.2 Box offsets: 'top', 'right', 'bottom', 'left'

Box offsets: from each edge

top, right, bottom and left take <length> | <percentage> | auto. Initial auto, not inherited, and they apply to positioned elements. Each stage is 200 by 100 and the containing block of the absolutely positioned box in it, 60 by 20.

From each edge

top specifies how far an absolutely positioned box's top margin edge is offset below the top edge of the box's containing block. right, bottom and left do the same from their edges, inward. CSS 2 §9.3.2
