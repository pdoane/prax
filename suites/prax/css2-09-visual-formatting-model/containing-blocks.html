CSS 2 · 9.1 Introduction to the visual formatting model

The viewport and containing blocks

Each element generates zero or more boxes, laid out by their dimensions and type, their positioning scheme, their relationships in the document tree, and information from outside it, such as the viewport's size.

The viewport

When the viewport is smaller than the area of the canvas on which the document is rendered, the user agent should offer a scrolling mechanism. CSS 2 §9.1.1

Containing blocks

Many box positions and sizes are calculated with respect to the edges of a rectangular box called a containing block. Each box is given a position with respect to its containing block, but it is not confined by this containing block; it may overflow. The dashed box is 100px wide. CSS 2 §9.1.2
