CSS 2 · 9.2.1.1 Anonymous block boxes

Anonymous block boxes: percentages and offsets

Inline content beside a block is wrapped in an anonymous block box, which stands between the content and the element around it.

Percentages skip anonymous boxes

Anonymous block boxes are ignored when resolving percentage values that would refer to it: the closest non-anonymous ancestor box is used instead. Each dashed box is 100px tall, and holds a line of text and a block. CSS 2 §9.2.1.1

Offsets carry the block

When such an inline box is affected by relative positioning, any resulting translation also affects the block-level box contained in the inline box. CSS 2 §9.2.1.1
