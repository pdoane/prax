CSS 2 · 9.3.1 Choosing a positioning scheme

The position property: static and relative

position takes static | relative | absolute | fixed. Initial static, not inherited. Every box is 20px tall; the guides are 10px apart.

static

The box is a normal box, laid out according to the normal flow. The 'top', 'right', 'bottom', and 'left' properties do not apply. CSS 2 §9.3.1

relative

The box's position is calculated according to the normal flow ... Then the box is offset relative to its normal position. When a box B is relatively positioned, the position of the following box is calculated as though B were not offset. CSS 2 §9.3.1
