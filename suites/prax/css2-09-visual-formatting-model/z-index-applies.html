CSS 2 · 9.9.1 Specifying the stack level: the 'z-index' property

The z-index property: positioned boxes only

In each stage, which forms the stacking context, blue A has z-index: 10, and orange B after it is position: relative at z-index: auto, pulled up 20px over A.

Not a static box

Applies to: positioned elements CSS 2 §9.9.1

Since CSS 2 · CSS Color 4 §3.3

Not even with opacity

A box with opacity below 1 forms a stacking context. Furthermore, if the 'z-index' property applies to the box, the auto value is treated as 0 for the element; it is otherwise painted on the same layer within its parent stacking context as positioned elements with stack level 0. CSS Color 4 §3.3
