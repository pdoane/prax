CSS 2 · 9.6.1 Fixed positioning

Fixed positioning: scrolling

Fixed positioning is a subcategory of absolute positioning. The only difference is that for a fixed positioned box, the containing block is established by the viewport. For continuous media, fixed boxes do not move when the document is scrolled. CSS 2 §9.6.1

Scrolling

Each frame is a document 300px tall, scrolled down 60px; the guides are 10px apart. A box at top: 10px in each.

Since CSS 2 · CSS Positioned Layout 3 §2.1

Nothing to scroll to

As a result, parts of fixed-positioned boxes that extend outside the layout viewport/page area cannot be scrolled to and will not print.
