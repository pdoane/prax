CSS 2 · 9.5 Floats

Floats: content before the float

Any content in the current line before a floated box is reflowed in the same line on the other side of the float. Each float is 60 by 40.

Reflowed on the other side

The specification's example: <P>a<SPAN style="float: right">b</SPAN></P> ... If the P element's width is enough, the a and the b will be side by side. CSS 2 §9.5.1

Before the text or within it

Formatting would have been exactly the same if the document had been written with the float after some of the line's text, because the content to the left of the float is displaced by the float and reflowed down its right side. CSS 2 §9.5
