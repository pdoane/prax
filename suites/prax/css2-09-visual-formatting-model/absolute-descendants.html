CSS 2 · 9.6 Absolute positioning

Absolute positioning: its descendants

In the absolute positioning model, a box is explicitly offset with respect to its containing block. It is removed from the normal flow entirely (it has no impact on later siblings). Each stage is positioned.

A containing block for its descendants

An absolutely positioned box establishes a new containing block for normal flow children and absolutely (but not fixed) positioned descendants. CSS 2 §9.6
