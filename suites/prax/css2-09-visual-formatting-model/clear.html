CSS 2 · 9.5.2 Controlling flow next to floats: the 'clear' property

The clear property

clear takes none | left | right | both. Initial none, not inherited, and it applies to block-level elements. In each figure, a left float 60px tall and a right float 40px tall come before the orange block.

The values

left: Requires that the top border edge of the box be below the bottom outer edge of any left-floating boxes that resulted from elements earlier in the source document. right does the same for right floats, and both for both. CSS 2 §9.5.2

Floats it does not consider

The 'clear' property does not consider floats inside the element itself or in other block formatting contexts. CSS 2 §9.5.2
