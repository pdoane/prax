CSS 2 · 9.9.1 Specifying the stack level: the 'z-index' property

The z-index property: stacking contexts

A stacking context is atomic from the point of view of its parent stacking context; boxes in other stacking contexts may not come between any of its boxes. CSS 2 §9.9.1

A child's level counts only inside its context

<integer>: This integer is the stack level of the generated box in the current stacking context. The box also establishes a new stacking context. In each figure, the dashed parent holds the blue child with z-index: 100, and the orange sibling has z-index: 2. CSS 2 §9.9.1
