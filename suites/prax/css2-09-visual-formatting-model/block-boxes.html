CSS 2 · 9.2.1 Block-level elements and block boxes

Block-level boxes and block containers

Block-level boxes are boxes that participate in a block formatting context. A block container holds either only block-level boxes or only inline-level ones. The two are different things: some boxes are one and not the other.

Block-level

Values of the 'display' property that make an element block-level include: 'block', 'list-item', and 'table'. A block-level box is on lines of its own, between the text before and after it. CSS 2 §9.2.1

Block containers that are not block-level

Non-replaced inline blocks and non-replaced table cells are block containers but are not block-level. Each orange box holds two block boxes, stacked, and sits on the line. CSS 2 §9.2.1
