CSS 2 · 9.2.2.1 Anonymous inline boxes

Anonymous inline boxes

Any text that is directly contained inside a block container element (not inside an inline element) must be treated as an anonymous inline element.

Text in a block

In <p>Some <em>emphasized</em> text</p>, "Some" and "text" are anonymous inline boxes. Such anonymous inline boxes inherit inheritable properties from their block parent box. Non-inherited properties have their initial value. In the example, the color of the anonymous inline boxes is inherited from the P, but the background is transparent. CSS 2 §9.2.2.1
