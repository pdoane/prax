CSS 2 · 9.9.1 Specifying the stack level: the 'z-index' property

The z-index property

z-index takes auto | <integer>. Initial auto, not inherited, and it applies to positioned elements. Each figure's boxes are absolutely positioned, overlapping, and in source order A, B, C.

Stack levels

Boxes with greater stack levels are always formatted in front of boxes with lower stack levels. Boxes with the same stack level in a stacking context are stacked back-to-front according to document tree order. CSS 2 §9.9.1
