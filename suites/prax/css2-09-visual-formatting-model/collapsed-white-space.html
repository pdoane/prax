CSS 2 · 9.2.2.1 Anonymous inline boxes

Anonymous inline boxes: white space

Any text that is directly contained inside a block container element (not inside an inline element) must be treated as an anonymous inline element. Every named box is 20px tall; the guides are 10px apart.

White space that collapses away

White space content that would subsequently be collapsed away according to the 'white-space' property does not generate any anonymous inline boxes. CSS 2 §9.2.2.1
