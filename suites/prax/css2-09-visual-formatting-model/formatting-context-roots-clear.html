CSS 2 · 9.4.1 Block formatting contexts

Block formatting contexts: roots clear of floats

A box that establishes a block formatting context keeps clear of the floats beside it, and of no others. Each orange box has overflow: hidden. CSS 2 §9.4.1

With no float beside it

Where no float is beside the box, it is laid out as any block box is, whether or not a float lies further down: a negative margin takes it past the edge, and a box too wide overflows. Each stage has a 40px block, then a float at 40, then the orange box with margin-top: -40px, at the stage's top. CSS 2 §10.3.3
