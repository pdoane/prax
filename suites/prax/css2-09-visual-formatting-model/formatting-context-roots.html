CSS 2 · 9.4.1 Block formatting contexts

Block formatting contexts: their roots

Floats, absolutely positioned elements, block containers (such as inline-blocks, table-cells, and table-captions) that are not block boxes, and block boxes with 'overflow' other than 'visible' ... establish new block formatting contexts for their contents. CSS 2 §9.4.1

Beside a float

A box that establishes a block formatting context does not run under a float: in which case the box itself may become narrower due to the floats. Each orange box comes after a 60px float. CSS 2 §9.4.1, §9.5

Its floats are its own

Floats belong to the block formatting context they are in, so a root holds its floats, and its height takes them in. Each dashed box holds a 60px float and nothing else. CSS 2 §9.4.1, §10.6.7
