CSS 2 · 9.5.2 Controlling flow next to floats: the 'clear' property

The clear property: how much clearance

CSS 2 allows two amounts of clearance, which differ where the box's hypothetical position is past the float's bottom. Every named box is 20px tall unless it says otherwise; the guides are 10px apart.

The greater amount, or the float's bottom

Then the amount of clearance is set to the greater of: 1. The amount necessary to place the border edge of the block even with the bottom outer edge of the lowest float that is to be cleared. 2. The amount necessary to place the top border edge of the block at its hypothetical position. Alternatively, clearance is set exactly to the amount necessary to place the border edge of the block even with the bottom outer edge of the lowest float that is to be cleared. Both behaviors are allowed. CSS 2 §9.5.2
