CSS 2 · 9.5.2 Controlling flow next to floats: the 'clear' property

The clear property: clearance

Clearance inhibits margin collapsing and acts as spacing above the margin-top of an element. It is used to push the element vertically past the float. Every named box is 20px tall unless it says otherwise; the guides are 10px apart.

The specification's examples

Example 1: B1 with a bottom margin M1, a float F of height H, and B2 with a top margin M2 and clear: both. Clearance puts B2's top border edge at the bottom of F, so C1 = H - M2. Example 2: the clearance is -1em, as here in pixels: clearance + margin-top = 2em. CSS 2 §9.5.2
