CSS 2 · 9.9.1 Specifying the stack level: the 'z-index' property

The z-index property: negative and very large levels

z-index takes auto | <integer>. Initial auto, not inherited, and it applies to positioned elements. Each figure's boxes are absolutely positioned, overlapping, and in source order A, B, C.

Negative levels

Boxes may have negative stack levels. They paint after the background of the element that forms the stacking context, and before its in-flow content. The stage forms the stacking context here. CSS 2 §9.9.1

Since CSS 2 · CSS Values and Units 4 §5

Levels past what is supported

The precision and supported range of numeric values in CSS is implementation-defined; When a value cannot be explicitly supported due to range/precision limitations, it must be converted to the closest value supported by the implementation. CSS Values and Units 4 §5 Browsers keep a level in 32 bits, up to 2147483647.
