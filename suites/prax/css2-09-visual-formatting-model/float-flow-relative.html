CSS 2 · 9.5.1 Positioning the float: the 'float' property

The float property: start and end

CSS 2's float names a physical side, left or right, whatever the direction of the text. A later specification adds values that name the start or the end of the line. Each float is 60 by 40.

Since CSS 2 · CSS Logical Properties and Values 1 §2.2

inline-start and inline-end

The values inline-start | inline-end are new for float. The mapping on these properties uses the writing mode of the element’s containing block.
