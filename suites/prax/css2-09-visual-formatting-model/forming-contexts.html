CSS 2 · 9.9.1 Specifying the stack level: the 'z-index' property

The z-index property: what forms a stacking context

Each dashed parent holds the blue child with z-index: 100; the orange sibling has z-index: 2. The child is in front only if its parent forms no stacking context.

What forms one

The root element forms the root stacking context. Other stacking contexts are generated by any positioned element (including relatively positioned elements) having a computed value of 'z-index' other than 'auto'. CSS 2 §9.9.1

Since CSS 2 · CSS Positioned Layout 3 §2.2

Fixed and sticky boxes always form one

When z-index is auto: Fixed and sticky positioned boxes nonetheless form a stacking context. Relative and absolute positioned boxes do not form a stacking context CSS Positioned Layout 3 §2.2 In CSS 2, only z-index did. Each parent here has z-index: auto.
