CSS 2 · 9.2.1.1 Anonymous block boxes

Anonymous block boxes: floats and white space around a block in an inline

In each figure the orange block is inside a span, which is broken around it. Text is 13px on 20px lines; the guides are 10px apart.

Floats reach the block

The block becomes a sibling of those anonymous boxes, so it is placed beside, below or clear of the floats before it as any block is. CSS 2 §9.2.1.1, §9.5 Each span starts with a blue left float, 60 by 20.

White space beside the block

A block ends the line before it and starts a line after it, so white space that would collapse at the end or start of a line is removed there, and a preserved newline still ends a line. CSS 2 §16.6.1
