CSS 2 · 9.5.2 Controlling flow next to floats: the 'clear' property

The clear property: start and end

CSS 2's clear names physical sides: left, right or both. A later specification adds values that name the start or the end of the line. In each figure, a left float 60px tall and a right float 40px tall come before the orange block.

Since CSS 2 · CSS Logical Properties and Values 1 §2.2

inline-start and inline-end

The values inline-start | inline-end are new for clear. The mapping on these properties uses the writing mode of the element’s containing block.
