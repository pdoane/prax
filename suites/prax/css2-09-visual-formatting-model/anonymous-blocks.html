CSS 2 · 9.2.1.1 Anonymous block boxes

Anonymous block boxes

If a block container box ... has a block-level box inside it ..., then we force it to have only block-level boxes inside it. Inline content beside a block is wrapped in an anonymous block box.

Text beside a block

In <DIV>Some text <P>More text</DIV>, we assume that there is an anonymous block box around "Some text". The properties of anonymous boxes are inherited from the enclosing non-anonymous box; the others take their initial values. CSS 2 §9.2.1.1

A block inside an inline

When an inline box contains an in-flow block-level box, the inline box ... is broken around the block-level box, and the lines before and after are wrapped in anonymous block boxes. If a border had been set on the P element in the above example, the border would be drawn around C1 (open at the end of the line) and C2 (open at the start of the line). CSS 2 §9.2.1.1
