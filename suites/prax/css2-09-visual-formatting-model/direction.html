CSS 2 · 9.10 Text direction: the 'direction' and 'unicode-bidi' properties

The direction property

direction takes ltr | rtl. Initial ltr, inherited. This property specifies the base writing direction of blocks and the direction of embeddings and overrides ... for the Unicode bidirectional algorithm. CSS 2 §9.10

The base direction of a block

The paragraph embedding level is set according to the value of the 'direction' property of the containing block rather than by the heuristic given in steps P2 and P3 of the Unicode algorithm. The base direction decides where a line starts and where neutral characters at its ends go. CSS 2 §9.10
