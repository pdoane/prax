CSS 2 · 9.2.4 The 'display' property

The display property: two keywords

Each of CSS 2's display values is one keyword. A later specification names each by two: how the box takes part in the flow around it, and how it lays out its content.

Since CSS 2 · CSS Display 4 §2

An outer and an inner display type

The 'display' property defines an element's display type, which consists of the two basic qualities of how an element generates boxes: the inner display type and the outer. Each orange box has width: 60px; height: 30px; margin: 0 10px.
