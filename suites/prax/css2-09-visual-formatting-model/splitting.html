CSS 2 · 9.4.2 Inline formatting contexts

Inline formatting contexts: splitting inline boxes

When an inline box exceeds the width of a line box, it is split into several boxes and these boxes are distributed across several line boxes.

Where a box splits

When an inline box is split, margins, borders, and padding have no visual effect where the split occurs.
