CSS 2 · 9.4.2 Inline formatting contexts

Inline formatting contexts: edges and empty lines

Between the boxes A and B, a dashed block holds only an empty span, whose margins, borders or padding decide whether it makes a line. Text is 13px on 20px lines; the guides are 10px apart.

Each edge on its own

A line that holds no inline elements with non-zero margins, padding, or borders is zero high. CSS 2 §9.4.2

Since CSS 2 · CSS Inline Layout 3 §2.3

Only inline-axis edges

A phantom line box holds no inline boxes with non-zero inline-axis margins, padding, or borders. Such boxes must be treated as zero-height line boxes. CSS Inline Layout 3 §2.3
