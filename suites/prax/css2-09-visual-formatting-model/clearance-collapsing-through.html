CSS 2 · 9.5.2 Controlling flow next to floats: the 'clear' property

The clear property: an empty box with clearance

The dashed line E is an empty box with clear: both, after a float 50px tall: it is put below the float, and margins collapse through it. The guides are 10px apart.

The margins after it

If the top and bottom margins of an element with clearance are adjoining, its margins collapse with the adjoining margins of following siblings but that resulting margin does not collapse with the bottom margin of the parent block. CSS 2 §8.3.1, §9.5.2

Not through the parent's end

The dashed parent, with margin-bottom: 20px, ends with the anchor, the float and E; N follows it. CSS 2 §8.3.1
