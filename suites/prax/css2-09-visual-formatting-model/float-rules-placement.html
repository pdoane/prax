CSS 2 · 9.5.1 Positioning the float: the 'float' property

The float property: as high as possible

The precise rules that govern floats, numbered as the specification numbers them. Every named box is 20px tall unless it says otherwise; the guides are 10px apart.

Rules 8 and 9: higher before further

8. A floating box must be placed as high as possible. 9. A left-floating box must be put as far to the left as possible, a right-floating box as far to the right as possible. A higher position is preferred over one that is further to the left/right. CSS 2 §9.5.1

A float between collapsing margins

When the float occurs between two collapsing margins, the float is positioned as if it had an otherwise empty anonymous block parent taking part in the flow. That parent's position follows from §8.3.1. CSS 2 §9.5.1
