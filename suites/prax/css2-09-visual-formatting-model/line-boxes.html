CSS 2 · 9.4.2 Inline formatting contexts

Inline formatting contexts: line boxes

An inline formatting context is established by a block container box that contains no block-level boxes. The rectangular area that contains the boxes that form a line is called a line box.

Horizontally, one after the other

In an inline formatting context, boxes are laid out horizontally, one after the other, beginning at the top of a containing block. Horizontal margins, borders, and padding are respected between these boxes. CSS 2 §9.4.2

A line box's height and width

A line box is always tall enough for all of the boxes it contains. The width of a line box is determined by a containing block and the presence of floats. CSS 2 §9.4.2
