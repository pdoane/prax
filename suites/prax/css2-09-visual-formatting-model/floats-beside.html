CSS 2 · 9.5 Floats

Floats: boxes beside them

A box that may not overlap a float sits in the space beside it. Each float is 60 by 60, in a stage 200px wide.

A block-level replaced element

The border box of a table, a block-level replaced element, or an element in the normal flow that establishes a new block formatting context (such as an element with 'overflow' other than 'visible') must not overlap the margin box of any floats in the same block formatting context as the element itself. CSS 2 §9.5

Auto margins beside a float

CSS 2 does not say how auto margins resolve for a box beside a float. The browsers share between them what the box leaves of the space beside the float. CSS 2 §9.5, §10.3.3
