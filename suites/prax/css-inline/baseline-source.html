CSS Inline Layout 3 · 4.2.1 Alignment Baseline Source: the baseline-source longhand

baseline-source: first and last

When an inline-level box has more than one possible source for baseline information (such as for a multi-line inline block or inline flex container) this property specifies whether the first baseline set or last baseline set is preferred for alignment. CSS Inline Layout 3 §4.2.1 Each orange box holds three lines, one, two and three; the red line is the line's baseline.

auto

auto Specifies last-baseline alignment for inline-block, first-baseline alignment for everything else.

first and last

first Specifies first-baseline alignment. last Specifies last-baseline alignment.
