CSS Inline Layout 3 · 2 Inline Layout Model

The inline layout model

Any block container that directly contains inline-level content—such as inline boxes, atomic inlines, and text sequences—establishes an inline formatting context to lay out its contents using inline layout. CSS Inline Layout 3 §2

The root inline box

The block container also generates a root inline box, which is an anonymous inline box that holds all of its inline-level contents. The root inline box inherits from its parent block container, but is otherwise unstyleable. In each stage, the text is an orange span of 10px text on 10px lines.

Inline-axis margins, borders and padding

Inline-axis margins, borders, and padding are respected between inline-level boxes (and their margins do not collapse).
