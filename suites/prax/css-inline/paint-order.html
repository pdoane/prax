CSS Inline Layout 3 · 2.4 Painting Order

Painting order of inline-level boxes

Except as specified for positioned boxes … inline-level boxes are painted in document order; the z-index property does not generally apply. CSS Inline Layout 3 §2.4

Document order

In each stage A comes first and B second, B pulled 30px over A by a negative margin.

Positioned boxes

A positioned box is painted in its stacking context's order. CSS Positioned Layout 3 §2.2
