CSS Inline Layout 3 · 7.3.1 Applicability

initial-letter: which boxes

initial-letter applies to any inline-level box—including any such ::first-letter or ::marker box—that is the first child of its parent box and whose ancestors (if any) that are descendants of its containing block are all first-child inline boxes that have a computed initial-letter value of normal. CSS Inline Layout 3 §7.3.1 Each paragraph is 13px PR Literata on 20px lines.

First-most inline-level boxes, and markers

The spec's example: em { initial-letter: 2; } b, strong { initial-letter: 3; }. The initial-letter property will take effect only on the <em>. It also applies to list-style-position/inside-positioned ::marker pseudo-elements.

Not at the start of the line

If initial-letter is applied to an inline-level box that is not positioned at the start of the line due to bidi reordering or which is otherwise preceded by other inline-level content, its used value is normal.
