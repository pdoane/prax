Synthesized baselines for atomic inlines

If an atomic inline … does not have a content-derived baseline set … then the UA must synthesize its baselines. CSS Inline Layout 3 §A.3 Each stage is 72px PR Baseline Diagnostic, whose glyph fills from the named baseline to alphabetic, and an empty blue inline-block with the same vertical-align.

Bottom, middle, top

at its line-under margin edge: text-under, ideographic-under, ideographic-ink-under, alphabetic. halfway between its line-under and line-over margin edges: central, math, x-middle. at its line-over margin edge: text-over, ideographic-over, ideographic-ink-over, cap-height, hanging, x-height.

Margins move it

Authors can use margins (positive or negative) to adjust the alignment of replaced content within a line. The red line is the baseline.
