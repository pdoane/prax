CSS Inline Layout 3 · 7.1.1 Drop Initial, other scripts

Drop initials in other scripts

A dropped initial (or “drop cap”) is a larger-than-usual letter at the start of a paragraph, with a baseline at least one line lower than the first baseline of the paragraph. The size of the drop initial is usually indicated by how many lines it occupies. CSS Inline Layout 3 §7.1.1 Each paragraph's ::first-letter, in blue, has the caption's initial-letter.

Other scripts

In Han-derived scripts, the initial letter extends from the block-start edge of the glyphs on the first line to the block-end edge of the glyphs on the Nth line. In certain Indic scripts, the top alignment point is the hanging baseline, and the bottom alignment point is the text-after-edge.
