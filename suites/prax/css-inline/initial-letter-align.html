CSS Inline Layout 3 · 7.4 Alignment of Initial Letters: the initial-letter-align property

initial-letter-align

This property specifies the alignment points used to size and position an initial letter. the over and under alignment points of the initial letter are matched to corresponding over and under points of the root inline box. CSS Inline Layout 3 §7.4 Each paragraph is 14px PR Baseline Diagnostic on 24px lines, whose glyphs each fill the band between two of its baselines; its first letter, a B with initial-letter: 2, is Latin, so its own alignment points are its cap height and alphabetic baseline, the band B fills.

Each value

Each figure's text is the glyph that fills the band between the surrounding text's two points for the value, so the B's top is level with the first line's glyphs and its foot with the second's.
