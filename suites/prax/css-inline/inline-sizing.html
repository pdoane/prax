CSS Inline Layout 3 · 6.4 Inline Box Drawing Height: the inline-sizing property

inline-sizing

This property specifies how the logical height of the content area of an inline box is measured in relation to its contents. It has no effect on the size or position of the box’s contents, the line box, or any other content. normal and stretch

normal: The content area of the inline box is sized and positioned to fit (possibly hypothetical) text from its first available font. stretch: the inline box’s box edges are shifted such that its over/under margin edges coincide with the corresponding line box’s edges.
