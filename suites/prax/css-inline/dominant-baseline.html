CSS Inline Layout 3 · 4.1 Dominant Baselines: the dominant-baseline property

dominant-baseline: each value

This property specifies the dominant baseline, which is the default baseline type used to align content within the box. For inline boxes, the dominant baseline is used to align the box’s text … by aligning each glyph/box’s corresponding baseline to the box’s own dominant baseline. CSS Inline Layout 3 §4.1

Each <baseline-metric>

Each stage is a block of 72px PR Baseline Diagnostic, whose baselines each have their own height, holding a glyph and a 36px span of it, under the caption's dominant-baseline. Each glyph fills the band between two of the font's baselines: █ the ascent and descent, H hanging and alphabetic, I ideographic over and under, x x-height and alphabetic, + math and alphabetic.
