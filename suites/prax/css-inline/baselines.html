CSS Inline Layout 3 · 3.1 Introduction to Baselines

Baselines

A baseline is a line along the inline axis of a line box along which individual glyphs of text are aligned. Baselines guide the alignment of glyphs from different fonts or font sizes when typesetting. CSS Inline Layout 3 §3.1

Two sizes on one baseline

Each stage is 20px text on 60px lines; the red line is the line's alphabetic baseline.

Each script its baseline

Different writing systems prefer different baselines. A well-constructed font contains a baseline table, which indicates the position of one or more baselines within the font's design coordinate space. In each stage the parent's dominant-baseline names the baseline its text and a 44px span are aligned by; the red line is that baseline, marked by a rule with vertical-align set to it.
