CSS Inline Layout 3 · 7.4.1 UA Default Stylesheet for initial-letter-align

initial-letter-align: the UA style sheet

In order to provide the better behavior by default, UAs must include in their default UA style sheet the following rules: [lang]:lang(zh, ja, ko, ii) ideographic; [lang]:lang(hi, mr, ne, pi, kok, brx, mai, sd, sa) hanging; [lang]:lang('*-Latn', '*-Cyrl') alphabetic; [lang]:lang('*-Hani', '*-Hant', '*-Hans') ideographic. CSS Inline Layout 3 §7.4.1

By language, then by script

Each paragraph's first letter is two lines tall, aligned by the initial-letter-align its language gives it.
