CSS Inline Layout 3 · 4.2.2 Alignment Baseline Type: the alignment-baseline longhand

alignment-baseline: each value

This property specifies the box’s alignment baseline: the baseline used to align the box prior to applying its post-alignment shift (if applicable). Values have the same meanings as for dominant-baseline. CSS Inline Layout 3 §4.2.2

Each <baseline-metric>

Each stage is a block of 72px PR Baseline Diagnostic, whose baselines each have their own height, holding a glyph and a 36px span of it with the caption's alignment-baseline. Each glyph fills the band between two baselines: █ the ascent and descent, H hanging and alphabetic, I ideographic over and under, x x-height and alphabetic, + math and alphabetic.
