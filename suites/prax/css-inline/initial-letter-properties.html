CSS Inline Layout 3 · 7.5.1 Properties Applying to Initial Letters

Properties of initial letters

All properties that apply to an inline box also apply to an inline initial letter except for vertical-align and its sub-properties, font-size, line-height, line-fit-edge, and inline-sizing. Additionally, all of the sizing properties and box-sizing also apply to initial letters.
