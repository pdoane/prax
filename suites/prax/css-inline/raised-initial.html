CSS Inline Layout 3 · 7.1.3 Raised Initial Letters

Raised initials

A raised initial (often called a “raised cap” or “stick-up cap”) “sinks” to the first text baseline. CSS Inline Layout 3 §7.1.3 Each paragraph is 13px PR Literata on 20px lines, its first letter in blue.

Better than a larger font

A proper raised initial has several advantages over simply increasing the font size of a first letter. The line spacing in the rest of the paragraph will not be altered.
