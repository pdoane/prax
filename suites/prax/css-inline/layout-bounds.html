CSS Inline Layout 3 · 5.3 Calculating the Logical Height Contributions (“Layout Bounds”) of Inline Boxes

Layout bounds: leading and the strut

The contribution of an inline box to the logical height of its line box, here referred to as its layout bounds, is always calculated with respect to its own text metrics. CSS Inline Layout 3 §5.3

Leading, split in half

Calculate the leading L as L = line-height - (A + D). Half the leading (its half-leading) is added above A of the first available font, and the other half below D. Note: L may be negative. Each stage is 20px PR Baseline Diagnostic, whose █ fills its ascent to its descent, 20px.

The strut

If the inline box contains no glyphs at all, or if it contains only glyphs from fallback fonts, it is considered to contain a “strut” (an invisible glyph of zero width) with the metrics of the box's first available font. Each stage is 13px PR Arimo; the span's font is 40px PR Noto Sans Arabic, at line-height: normal.
