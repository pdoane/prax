CSS Inline Layout 3 · 6 Trimming Leading Over/Under Text

Trimming leading over and under text

The text-box property allows trimming this additional space above and below the first and last lines of a block, allowing more precise control over spacing around the glyphs. CSS Inline Layout 3 §6

Centering text on an icon

The spec's example: because the visual boundaries of Latin text are the cap height and the alphabetic baseline, rather than the ascent and descent, centering a text's box does not center its letters. By using text-box-trim to strip out the spacing above the cap height and below the alphabetic baseline, centering the box actually centers the text. Each row centers a 50px blue square and an orange block of 40px PR Literata capitals on 60px lines.

Whatever the font

Even though different fonts have different cap heights, by using the font's metric rather than a magic number, the layout intention is met even as the font is changed.
