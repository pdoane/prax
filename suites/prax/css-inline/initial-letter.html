CSS Inline Layout 3 · 7.3 Creating Initial Letters: the initial-letter property

initial-letter: size and sink

This property specifies the size and sink for dropped, raised, and sunken initial letters as the number of lines spanned. CSS Inline Layout 3 §7.3 Each paragraph is 11px PR Literata on 16px lines; its first letter, in blue, has the caption's initial-letter. Safari supports only -webkit-initial-letter, and Firefox none, so both draw a plain first letter in every figure.
