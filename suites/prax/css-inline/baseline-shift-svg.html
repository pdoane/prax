CSS Inline Layout 3 · 4.2.3.1 Legacy Values for SVG

baseline-shift: the legacy SVG value

User agents may additionally support the keyword baseline as computing to 0 if is necessary for them to support legacy SVG content. This value is not allowed in the vertical-align shorthand. CSS Inline Layout 3 §4.2.3.1

In SVG text

Each SVG holds a text element of 30px PR Baseline Diagnostic at y = 40, dashed in red, whose last █ is a tspan with the caption's baseline-shift.

Not in vertical-align

The span declares vertical-align: 10px and then vertical-align: baseline, which is valid as alignment-baseline's keyword, not as this one.
