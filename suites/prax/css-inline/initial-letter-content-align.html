CSS Inline Layout 3 · 7.5.6 Alignment Within an Initial Letter Box

Alignment within an initial letter box

By default (i.e. under automatic sizing), the content box of an inline initial letter is fitted exactly to its content, and alignment properties like text-align or align-content do not apply. However, if the box is not sized automatically, they do. CSS Inline Layout 3 §7.5.6 Each paragraph is 13px PR Literata on 20px lines; its ::first-letter, blue on orange, has initial-letter: 2. Safari supports only -webkit-initial-letter and Firefox none.

text-align and align-content

If the inline size is definite, text-align is honored; If the block size is definite, align-content is honored.
