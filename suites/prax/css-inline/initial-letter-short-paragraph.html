CSS Inline Layout 3 · 7.9.2 Short paragraphs with initial letters

Short paragraphs with initial letters

A paragraph with an initial letter can have fewer lines of text than the initial letter occupies. In this case, the initial letter’s top alignment is still honored, and its exclusion area continues into any subsequent blocks. CSS Inline Layout 3 §7.9.2 Each red paragraph is one line of 13px PR Literata on 20px lines with initial-letter: 3. Safari supports only -webkit-initial-letter and Firefox none.

The next paragraph wraps around it

The next paragraph's text wraps exactly as if that block's text were part of its own containing block.

Clearing it

If the subsequent block starts with an initial letter, establishes an independent formatting context, or specifies clear in the initial letter’s containing block’s start direction, then it must clear the previous block’s initial letter.
