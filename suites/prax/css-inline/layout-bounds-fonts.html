CSS Inline Layout 3 · 5.3 Calculating the Logical Height Contributions (“Layout Bounds”) of Inline Boxes, fonts

Layout bounds: the fonts a line uses

When its computed line-height is normal, the layout bounds of an inline box encloses all its glyphs, going from the highest A to the deepest D. When its computed line-height is not normal, its layout bounds are derived solely from metrics of its first available font (ignoring glyphs from other fonts). CSS Inline Layout 3 §5.3

normal: the faces used on each line

Each stage is 20px PR Arimo, then PR Noto Sans JP, whose ascent and descent are taller; its lines are in orange spans. Arimo has no Japanese, so 漢 is Noto Sans JP's. Arimo's own lines at normal are 23px.

Aligned by the first available font

The layout bounds size the line; the box is aligned by its baseline set, which derives from its first available font regardless of whether the box actually contains any glyphs from that font. §3.3 Each stage is 13px Arimo on 20px lines; the orange span is 30px at line-height: normal with vertical-align: middle.
