CSS Inline Layout 3 · 2.2 Layout Within Line Boxes

Layout within line boxes

Within each line box: All in-flow inline-level boxes in the line box are aligned to each other in the block axis; then The layout bounds (i.e. the size contributions) of each inline-level box in the line box are calculated; then The line box’s logical height is sized to exactly include the aligned layout bounds of all its inline-level boxes. CSS Inline Layout 3 §2.2 Each stage's text is 13px on 20px lines.

Layout bounds

For atomic inlines such as replaced elements and inline blocks: this is their margin box. For the root inline box, and for inline boxes with line-fit-edge: leading: this derived from their used line-height, ignoring any margin/border/padding.

The line box sized to the aligned bounds

The line box exactly includes the layout bounds once they are aligned. Empty inline boxes still have margins, padding, borders, and a line-height, and thus influence these calculations just like boxes with content.
