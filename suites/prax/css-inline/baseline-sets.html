CSS Inline Layout 3 · 3.3 Baselines of Glyphs and Boxes

Baselines of glyphs and boxes

Each font, glyph, and inline-level box is assumed to have a baseline coordinate for each baseline type indicating that baseline’s position on its block axis. The set of such baselines is called its baseline set. CSS Inline Layout 3 §3.3

An inline box's set from its first available font

For an inline box, it derives from its first available font regardless of whether the box actually contains any glyphs from that font. A blue square at vertical-align: text-top in a 40px span of Japanese marks the span's ascent.

An atomic inline's set from its contents, or its margin box

Another box's set is nominally derived from its contents. For an atomic inline box with no baseline set in the inline formatting context’s inline axis its alignment baselines are synthesized from its margin box, its alphabetic baseline at its bottom margin edge.
