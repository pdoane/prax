CSS Inline Layout 3 · 5.2 Text Edge Metrics: the line-fit-edge property

line-fit-edge

Inline boxes, whose primary purpose is to contain text, are sized in the block axis based on their font metrics. The line-fit-edge property controls which metrics are used. Which metrics

leading: Use the ascent/descent plus any positive half-leading. Other values use the named metrics, and if the half-leading is positive, treat it as zero. Each first line holds a 40px span on 30px lines.

Margins, borders and padding

Unless line-fit-edge is leading—in which case the box’s own line-height is used to add spacing—the box’s margin, padding, and border also contribute to the layout bounds. Each orange span has 10px of padding above and below.
