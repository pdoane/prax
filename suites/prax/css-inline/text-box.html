CSS Inline Layout 3 · 6.1 Shorthand for Text Box Trimming: the text-box property

text-box: the shorthand

This property is a shorthand for setting the text-box-trim and text-box-edge properties in a single declaration. CSS Inline Layout 3 §6.1 Each orange block is a line of 40px PR Baseline Diagnostic on 80px lines: B fills its cap height down to its alphabetic baseline, and █ its ascent to its descent.

normal

If the single keyword normal is specified, it sets text-box-trim to none and text-box-edge to auto.

A value left out

Otherwise, omitting the text-box-trim value sets it to trim-both (not the initial value), while omitting the text-box-edge value sets it to auto (the initial value).
