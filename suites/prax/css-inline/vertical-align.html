CSS Inline Layout 3 · 4.2 Transverse Box Alignment: the vertical-align property

vertical-align: the shorthand

This shorthand property specifies how an inline-level box is aligned within the line by specifying its alignment baseline type (alignment-baseline), baseline alignment preference (baseline-source), and post-alignment shift (baseline-shift) in a single declaration. CSS Inline Layout 3 §4.2

Its longhands

If first or last is specified, it sets baseline-source (which is otherwise reset to auto). Other values are as for the corresponding longhand properties. The red line is the line's baseline.

Several longhands at once

vertical-align takes [ first | last] || <'alignment-baseline'> || <'baseline-shift'>. The red line is the line's baseline.
