Synthesized baselines for text

User agents may use the following strategies in the absence of a required metric. CSS Inline Layout 3 §A.2 Each line is a rule with no height, aligned by vertical-align to the baseline it names, of a font that lacks it.

Measured from the glyphs

The top edge of the center of the letter Ka can be taken as the hanging baseline. The center of the minus sign (U+2212) can be taken as the mathematical baseline.

From related metrics

The central baseline is defined to be halfway between the ideographic-over and ideographic-under baselines; In CJK fonts the ascent and descent typically match the ideographic-over and ideographic-under baselines, so can be used as a fallback when both are missing.
