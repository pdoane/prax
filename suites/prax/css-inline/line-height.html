CSS Inline Layout 3 · 5.1 Line Spacing: the line-height property

line-height: its values

This property specifies the box’s preferred line height, which is used in calculating its “layout bounds”, i.e. its contribution to the logical height of its line box. CSS Inline Layout 3 §5.1 Each line's text is in an orange span.

A number, a length, a percentage

The spec's example: The three rules in the example below have the same used line height: 1.2, 1.2em and 120% at font-size: 10pt, all 16px. Each block's second line is 20pt.

The minimum height of the lines

Because it applies to the root inline box when specified on a block container, line-height effectively establishes the minimum height of the block’s line boxes.
