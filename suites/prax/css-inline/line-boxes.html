CSS Inline Layout 3 · 2.1 Layout of Line Boxes

Layout of line boxes

Line boxes are created as needed to hold inline-level content within an inline formatting context. CSS Inline Layout 3 §2.1

Inline boxes split across line boxes

When an inline box exceeds the logical width of a line box, or contains a forced line break, it is split … into several fragments, which are partitioned across multiple line boxes.

Stacked, and as wide as the containing block

Line boxes are stacked with no separation … and they never overlap. They are aligned within this container as specified by 'align-content'. Floating boxes or initial letter boxes can come between the containing block edge and the line box edge, reducing … the logical width of, any such impacted line boxes.
