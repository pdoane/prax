CSS Inline Layout 3 · 7.8.2 Edge Effects: Indentation and Hanging Punctuation

Initial letters and text-indent

text-indent and hanging-punctuation apply to an initial letter’s originating line box as usual, and cause a shift in the start of the line’s contents including the initial letter itself. Subsequent lines affected by the exclusion are shortened as usual. CSS Inline Layout 3 §7.8.2 Each paragraph is 13px PR Literata on 20px lines, its first letter blue with initial-letter: 3. Safari supports only -webkit-initial-letter and Firefox none.
