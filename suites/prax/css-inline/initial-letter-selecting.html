CSS Inline Layout 3 · 7.2 Selecting Initial Letters

Selecting initial letters

The ::first-letter pseudo-element, defined in [SELECT] and [CSS-PSEUDO-4], can be used to select the character(s) to be formatted as initial letters. CSS Inline Layout 3 §7.2 Each paragraph is 13px PR Literata on 20px lines; what has initial-letter: 2 is in blue.

::first-letter, an image, a span

The spec's example: ::first-letter, /* style first paragraph's T */ img, /* style illuminated H */ span /* style phrase inside span */ { initial-letter: 2; }

Punctuation with the letter

since ::first-letter selects punctuation before or after the first letter, these characters are included in the initial letter when ::first-letter is used.
