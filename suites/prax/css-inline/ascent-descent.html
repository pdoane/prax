CSS Inline Layout 3 · 3.2.1 Ascent and Descent Metrics

Ascent and descent

CSS assumes that every font has font metrics that specify a characteristic height above the baseline—called the ascent metric—and a characteristic depth below it—called the descent metric—which CSS uses for laying out text and boxes in an inline formatting context. CSS Inline Layout 3 §3.2.1

sTypoAscender and sTypoDescender

A note, so a recommendation and not a requirement: It is recommended that implementations that use OpenType or TrueType fonts use the metrics sTypoAscender and sTypoDescender from the font's OS/2 table (after scaling to the current element's font size). Each orange block is one line of 20px text at line-height: normal, which is the ascent, the descent and the line gap.

Of the font, not of the glyphs

Note that these are metrics of the font as a whole and need not correspond to the ascender and descender of any individual glyph.
