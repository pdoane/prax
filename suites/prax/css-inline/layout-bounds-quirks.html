CSS Inline Layout 3 · 5.3 Calculating the Logical Height Contributions (“Layout Bounds”) of Inline Boxes, quirks

Layout bounds in quirks mode

The contribution of an inline box to the logical height of its line box, here referred to as its layout bounds, is always calculated with respect to its own text metrics. CSS Inline Layout 3 §5.3

Quirks mode

In Quirks Mode, any inline box fragment that has zero borders and padding and that does not directly contain text or preserved white space is ignored when sizing the line box. Each frame holds a line of 13px text on 20px lines and an empty span on 60px lines.
