CSS Inline Layout 3 · 3.2 Baselines and Metrics, edges

Baselines and metrics: edges

CSS uses the following text-based metrics as baselines for inline layout functions such as alignment, box sizing, and initial letter layout. CSS Inline Layout 3 §3.2 The stages use 70px PR Baseline Diagnostic, whose baseline table and metrics put each at its own height: ascent 0.8em, ideographic-over 0.75em, ideographic ink over 0.65em, cap height 0.55em, x-height 0.25em, alphabetic and ideographic ink under 0.05em, ideographic-under -0.05em and descent -0.2em.

Edges to trim to

text-box trims each orange block, 140px tall untrimmed, to two of them; each glyph fills the band between the same two, so it fills the block. cap is the top of capital letters, ex the top of short lowercase letters.
