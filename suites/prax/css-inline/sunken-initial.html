CSS Inline Layout 3 · 7.1.2 Sunken Initial Letters

Sunken initials

Some styles of drop initials do not align with the first line of text. A sunken initial (or “sunken cap”) both sinks below the first baseline, and extends above the first line of text. CSS Inline Layout 3 §7.1.2 Each paragraph is 13px PR Literata on 20px lines, its first letter in blue.

Three lines tall, two lines deep
