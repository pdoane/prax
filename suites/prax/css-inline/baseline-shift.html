CSS Inline Layout 3 · 4.2.3 Post-Alignment Shift: the baseline-shift longhand

baseline-shift: lengths, sub and super

The baseline-relative shift values <length-percentage>, sub, super shift the box relative to its baseline-aligned position. CSS Inline Layout 3 §4.2.3 Each stage is 30px text on 60px lines; the red line is the line's baseline, and each blue square sits on it before its shift.

Lengths and percentages

Raise (positive value) or lower (negative value) by the specified length. A percentage is the specified percentage of the line-height, the box's own.

sub and super

sub: Lower by the offset appropriate for subscripts of the parent’s box. The UA may use the parent’s font metrics to find this offset; otherwise it defaults to dropping by one fifth of the parent’s used font-size. super: otherwise it defaults to raising by one third of the parent’s used font-size.
