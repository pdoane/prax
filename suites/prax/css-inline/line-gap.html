CSS Inline Layout 3 · 3.2.2 Line Gap Metrics

The line gap

Font formats can allow for a font-recommended “line gap” or “external leading” metric. This metric is referred to as the line gap metric, and may be incorporated into the line box logical height calculations when line-height is normal. UAs must floor the line gap metric at zero.
