CSS Inline Layout 3 · 7.9.4 Interaction with Fragmentation (Pagination)

Initial letters across columns

an initial letter is considered monolithic for the purpose of block-axis fragmentation (breaking across pages, columns, regions, etc.). Additionally, breaks between the in-flow lines alongside an initial letter box are avoided, much as breaks between line boxes affected be widows and orphans are avoided. CSS Inline Layout 3 §7.9.4 Each stage is two columns 60px tall, three 20px lines each, of 13px PR Literata, with initial-letter: 3. Safari supports only -webkit-initial-letter and Firefox none.
