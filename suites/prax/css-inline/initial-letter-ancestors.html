CSS Inline Layout 3 · 7.8.3 Ancestor Inlines

Initial letters in inline boxes

If the initial letter box is contained by inline box ancestors, the boundaries of those inline boxes are drawn to exclude the initial letter box, as if it were outside their startmost margin edge. CSS Inline Layout 3 §7.8.3 Each paragraph is 13px PR Literata on 20px lines; its first letter, blue, has initial-letter: 3. Safari supports only -webkit-initial-letter and Firefox none.

The ancestor's border starts after the letter

This is a purely geometric operation: it does not affect e.g. property inheritance. The orange span holds the first words, the letter among them, and is font-style: italic.
