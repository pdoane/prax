CSS Inline Layout 3 · 3.2 Baselines and Metrics

Baselines and metrics

CSS uses the following text-based metrics as baselines for inline layout functions such as alignment, box sizing, and initial letter layout. CSS Inline Layout 3 §3.2 The stages use PR Baseline Diagnostic, whose "X" draws each of its baselines as a labeled line: its baseline table has every one at its own height, its alphabetic baseline (romn) 0.05em above the glyphs' origin.

Baselines to align to

Each colored line is a 2px rule with no other height, aligned by vertical-align to the baseline it names. The alphabetic baseline is Often represented as zero in font design coordinate systems; assigned to romn in OpenType; text-top and text-bottom are the metric used as the line-over edge and line-under edge of an inline’s content box per CSS2, its ascent and descent.
