CSS Inline Layout 3 · 6.3 Text Trimming Metrics: the text-box-edge property

text-box-edge

This property specifies the metrics to use for text-box-trim effects. Values have the same meanings as for line-fit-edge. CSS Inline Layout 3 §6.3 Each orange block is text-box-trim: trim-both and a line of 30px PR Baseline Diagnostic on 60px lines: B fills its cap height down to its alphabetic baseline, x its x-height, and █ its ascent to its descent.

auto

the auto keyword uses the value of line-fit-edge, interpreting leading (the initial value) as text.

Two edges, and one

The first value specifies the text over edge; the second value specifies the text under edge. If only one value is specified, both edges are assigned that same keyword if possible; else text is assumed as the missing value. §5.2
