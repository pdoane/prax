CSS Inline Layout 3 · 7.5.3 Font Sizing of Initial Letters

Font size of initial letters

For an inline initial letter, the font size used for sizing the initial letter contents is calculated to fulfill its specified size (see initial-letter) as anchored by its specified alignment points. For an N-line drop initial in a Western script, the cap-height of the letter needs to be (N – 1) times the line-height, plus the cap-height of the surrounding text. CSS Inline Layout 3 §7.5.3 Each paragraph is 13px on 20px lines. Safari supports only -webkit-initial-letter and Firefox none.

(N – 1) × line-height + cap height

PR Literata's cap height is 0.7em, so the surrounding text's is 9.1px: two lines make the letter's cap height 29.1px, a 41.6px font; three lines 49.1px, a 70.1px font.

The computed font size is not changed

These used font size calculations do not affect the computed font-size, and therefore have no effect on the computation of em length values. The letter's right border is 1em.
