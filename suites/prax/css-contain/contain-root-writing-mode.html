Containment on the body and the writing mode

when any containments are active on either the HTML html or body elements, propagation of properties from the body element to the initial containing block, the viewport, or the canvas background, is disabled. The body's writing mode

The root draws an orange square 50 by 50 before the body, which is vertical-rl, 100 by 50. The initial containing block takes the body's writing mode, and the root is placed at its block-start, unless containment stops it.
