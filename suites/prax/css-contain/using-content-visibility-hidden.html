Using content-visibility: hidden

content-visibility: hidden lays powerful restrictions onto an element, and so should be used with caution. It also enables some very useful scenarios, often improving on existing techniques. CSS Containment 2 §4.2 The section is informative; what it describes follows from skipping.

Content that is never drawn, however big

If the wrapper has no border, background, etc, then it and its skipped contents are guaranteed to never render anything to the screen, no matter how big they get. The wrapper holds an orange box 300 wide; "after" follows it. A "single-page app" often consists of several independent panes or "views", of which only one is displayed at a time.

Unlike visibility: hidden, descendants cannot undo it

descendants of a visibility: hidden element can set visibility: visible and start showing up again; content-visibility: hidden performs a very similar purpose, but descendants can't turn it "off" and start displaying. Each blue box is 40px tall and holds "shown?" with visibility: visible.
