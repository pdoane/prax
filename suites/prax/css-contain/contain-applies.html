CSS Containment 2 · 2 Strong Containment, what it applies to

What contain applies to

This property generally applies to all elements (including generated content), although some types of containment have no effect on some elements. CSS Containment 2 §2 Where each type has no effect is on its own section's pages. Text is 10px a letter.

Generated content

SVG

In addition, in the case of SVG2, the 'contain' property only applies to svg elements that have an associated CSS layout box. Each svg, outlined in red, is 60 by 40 with overflow: visible, and holds a blue rect 100 by 60.
