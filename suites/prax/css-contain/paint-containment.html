CSS Containment 2 · 3.5 Paint Containment

Paint containment: clipped to the overflow clip edge

The contents of the element including any ink or scrollable overflow must be clipped to the overflow clip edge of the paint containment box, taking corner clipping into account. CSS Containment 2 §3.5 Each blue box is 100 by 40 inside a 5px dark border, at 10, 10, and holds an orange box 140 by 70.

The edge, and its margin

The overflow clip edge is the padding edge, moved out by overflow-clip-margin, CSS Overflow 3 §3.2 allowing an element with paint containment to still slightly overflow its normal bounds.
