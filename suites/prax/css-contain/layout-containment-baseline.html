CSS Containment 2 · 3.3 Layout Containment, baselines

Layout containment: no baseline

For the purpose of the 'vertical-align' property, or any other property whose effects need to relate the position of the layout containment box's baseline to something other than its descendants, the containment box is treated as having no baseline. CSS Containment 2 §3.3 The dashed red line is the outer baseline; text is 10px a letter.

Inline-blocks

An inline-block with no baseline sits with its bottom margin edge on its line's baseline.

Flex and grid items, and table cells

A flex or grid item with no baseline has one synthesized from its border box: its bottom edge. The orange item has 30px of padding above "out".
