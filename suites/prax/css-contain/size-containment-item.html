CSS Containment 2 · 3.1 Size Containment, in its parent

Size containment as an item, and its baseline

The intrinsic sizes of the size containment box are determined as if the element had no content, and so is what it gives its parent to size. CSS Containment 2 §3.1 Each blue box has contain: size; text is 10px a letter.

As an item: what the parent sizes to

This affects explicit invocations of the min-content or max-content keywords, as well as any calculation that depends on these measurement, such as sizing grid tracks into which a size contained item is placed.

The baseline is kept

Size containment does not suppress baseline alignment. See layout containment for that. Compare Layout containment: no baseline.
