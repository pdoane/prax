Paint containment: containing block, stacking context, formatting context

The paint containment box establishes an absolute positioning containing block and a fixed positioning containing block. The paint containment box creates a stacking context. The paint containment box establishes an independent formatting context. CSS Containment 2 §3.5 Each blue box has contain: paint.
