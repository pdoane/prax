CSS Containment 2 · 4 Suppressing An Element’s Contents Entirely, auto

content-visibility: auto and relevance to the user

If the element is not relevant to the user, it also skips its contents. CSS Containment 2 §4 Each frame, 150 by 60, holds an orange box with 5px padding around a blue one, content-visibility: auto, whose content is 40px tall.

Close to the viewport, or far away

The element is close to the viewport when its paint containment box's overflow clip edge intersects with the viewport, or a user-agent defined margin around the viewport.

Focus, selection, the top layer

It is also relevant if Either the element or its contents are focused, are selected, or are placed in the top layer.
