CSS Containment 2 · 3.4 Style Containment

Style containment: counters

The 'counter-increment' and 'counter-set' properties must be scoped to the element's sub-tree and create a new counter. CSS Containment 2 §3.4 Text is 10px a letter.

The spec's example

Every div increments foo and shows counters(foo, ".") before its content; the second has contain: style. the style-contained element still interacts with the foo counter normally, Later siblings of the style-contained element don't see anything that goes on within the boundary, and inside, they'll create a fresh (nested) foo counter.
