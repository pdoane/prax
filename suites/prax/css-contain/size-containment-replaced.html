CSS Containment 2 · 3.1 Size Containment, replaced elements

Size containment of replaced elements

Replaced elements must be treated as having a natural width and height of 0 and no natural aspect ratio. CSS Containment 2 §3.1 The purple image is an SVG 80 by 40; its box is outlined in red.

Natural size 0, and no ratio

aspect-ratio is honored

Size containment only suppresses the natural aspect ratio, so properties like 'aspect-ratio' which affect that preferred aspect ratio directly are honored.
