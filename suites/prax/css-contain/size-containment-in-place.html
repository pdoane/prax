CSS Containment 2 · 3.1 Size Containment, the two phases

Size containment: measured empty, laid out in place

Laying out a size containment box and its content is conceptually done in two phases: sizing as if empty, then laying out in place. CSS Containment 2 §3.1 Each blue box has contain: size; text is 10px a letter.

What sizing from content finds

This affects explicit invocations of the min-content or max-content keywords, as well as any calculation that depends on these measurement, such as fit-content sizing the containment box's parent.

Then laid out in place

The containment box's content (including any pseudo-elements) must then be laid out into the now fixed-size containment box normally.
