CSS Containment 2 · 3.4 Style Containment, quotes

Style containment: quotes

The effects of the 'content' property's open-quote, close-quote, no-open-quote and no-close-quote must be scoped to the element's sub-tree. CSS Containment 2 §3.4 Each stage has quotes: "«" "»" "‹" "›"; the quote marks are red, and the blue span has contain: style. Each line is contained too, so that its quotes do not reach the next.

The depth inside starts from outside

This implies that the depth of quote nesting in the subtree is unchanged and starts at the value that its context normally implies.

Changes inside do not leave

but that changes to the depth of quote nesting by these values inside the subtree do not affect the depth of quote nesting outside the subtree. Each pair: without containment, then with it.
