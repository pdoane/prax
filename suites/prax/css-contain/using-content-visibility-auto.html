CSS Containment 2 · 4.3 Using content-visibility: auto

Using content-visibility: auto

Because content-visibility: auto imposes size containment when the element skips its contents, if the element depends on its contents to determine its size the layout of the page (or at least, the scrollbar position) can "jump around" as elements go off-screen and start skipping. CSS Containment 2 §4.3 The section is informative.

An estimate in place of the contents

One fix is using 'contain-intrinsic-size' to set an estimate of the element's size.
