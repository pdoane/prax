CSS Containment 2 · 3.1 Size Containment, the box's own properties

Size containment keeps the box's own properties

All CSS properties of the size containment box are taken into account as they would be when performing layout normally. Even when the element's sizing properties specify an intrinsic size, this does not necessarily make the element zero-sized.
