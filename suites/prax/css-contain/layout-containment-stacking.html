CSS Containment 2 · 3.3 Layout Containment, stacking and overflow

Layout containment: a stacking context, and overflow as ink

The layout containment box creates a stacking context. If the computed value of the 'overflow' property is either visible or clip or a combination thereof, any overflow must be treated as ink overflow. CSS Containment 2 §3.3
