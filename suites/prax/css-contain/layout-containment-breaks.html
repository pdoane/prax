CSS Containment 2 · 3.3 Layout Containment, fragmentation

Layout containment and fragmentation

Forced breaks are allowed within layout containment boxes but do not propagate to the parent as otherwise described in CSS Fragmentation 3 §4.1. CSS Containment 2 §3.3 Its trapping of a fragmented flow has no figure: no stable specification is affected by this point.

Breaks inside are allowed

Each multicol, dashed, has two columns 60px tall, filled in turn. The blue box has contain: layout and a dark 10px top border.

A first child's break does not propagate

A forced break before a first child would propagate, to break before its parent. A line "before" comes first, then the blue box, whose first child, orange, has break-before: column.
