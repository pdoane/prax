CSS Containment 2 · 3.5 Paint Containment, where it does not apply

Where paint containment has no effect

However, giving an element paint containment has no effect if any of the following are true: no principal box; an internal table box other than table-cell; an internal ruby box or a non-atomic inline-level box. CSS Containment 2 §3.5 In each figure the blue box has contain: paint, and an orange span in it is shifted 10px down and 10px right, out of it. Where containment applies, the span is cut; where not, it is drawn whole.
