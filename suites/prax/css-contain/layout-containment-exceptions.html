CSS Containment 2 · 3.3 Layout Containment, where it does not apply

Where layout containment has no effect

However, giving an element layout containment has no effect if any of the following are true: no principal box; an internal table box other than table-cell; an internal ruby box or a non-atomic inline-level box. CSS Containment 2 §3.3 Each stage is positioned; its orange square, position: absolute; right: 0; bottom: 0, is in the box with contain: layout, blue. Where containment applies, the square is at that box's corner; where not, at the stage's.
