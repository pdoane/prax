CSS Containment 2 · 3.1 Size Containment

Size containment: sized as if empty

The used 'width' and 'height' of the containment box are determined as if performing a normal layout of the box, except that it is treated as having no content. CSS Containment 2 §3.1 Each blue box has contain: size; text is 10px a letter. What it sizes to in place of its content, contain-intrinsic-size, is on CSS Box Sizing 4's page.

No content

The intrinsic sizes of the size containment box are determined as if the element had no content.

Not even pseudo-elements

not even through pseudo-elements such as ::before, ::after, or ::marker.
