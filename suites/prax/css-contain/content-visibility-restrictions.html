Skipped contents: the top layer and scrolling

Of the section's points, these two have something to see; the others concern observers, script, animation timing and the event loop. CSS Containment 2 §4.5 Each frame is a document 200 by 100 whose first line, blue, reads "top".

The top layer under content-visibility: hidden

If an element has an ancestor with content-visibility: hidden, and it is placed in the top layer, it does not generate any boxes, as if it were display: none. A script shows a popover inside a box with the value given.

No scrolling to skipped contents

If an element is not available to user-agent features (for example, if it is skipped due to a content-visibility: hidden ancestor), then scrolling operations must not scroll to it at all, as if it did not have a layout box. A script calls scrollIntoView() on a line "target" 300px down.
