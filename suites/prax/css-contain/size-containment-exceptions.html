CSS Containment 2 · 3.1 Size Containment, where it does not apply

Where size containment has no effect

However, giving an element size containment has no effect if any of the following are true: no principal box; a table; an internal table box; an internal ruby box or a non-atomic inline-level box. CSS Containment 2 §3.1 Each figure has contain: size on the box named; text is 10px a letter.

Tables but not captions, and no principal box

Internal table boxes, which do not include table captions, are excluded, because the table layout algorithm does not allow boxes to become smaller than their inflow content.
