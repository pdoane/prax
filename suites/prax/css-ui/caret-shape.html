CSS Basic User Interface 4 · 5.2.3 Shape of the insertion caret: caret-shape

caret-shape: underscore

This property allows authors to specify the desired shape of the insertion caret. CSS Basic User Interface 4 §5.2.3

underscore

The UA must render the insertion caret as a thin line under (as defined in CSS-WRITING-MODES-3) the next visible character following the insertion point. The width of the block and underscore carets should be the advance measure of the next visible character after the insertion point. The box has caret-shape: underscore, caret-animation: manual and a red caret-color.

A script gives the focus to the editable box and puts the insertion point in it. Safari and Firefox draw no caret in these stills.
