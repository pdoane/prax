CSS Basic User Interface 4 · 3.1 Outlines Shorthand: the outline property

outline: auto

In the ambiguous case where a lone auto value is specified, or if auto is specified together with an <'outline-width'> value, but without an explicit <'outline-style'> or <'outline-color'> value, both outline-style and outline-color are set to auto. CSS Basic User Interface 4 §3.1

Style and color both auto

With both auto, the outline is the browser's own, in the accent color §3.4. Each box has color: #c0392b, red, and accent-color: #27ae60, green.
