CSS Basic User Interface 4 · 6.3 Preventing All Interaction: the interactivity property

interactivity: inert

The interactivity property specifies whether an element and its flat tree descendants (including text nodes) are inert or not. When inert, Text selection must act as if user-select was none, regardless of its actual value. CSS Basic User Interface 4 §6.3 Pointer events, focus and find-in-page are not drawn.
