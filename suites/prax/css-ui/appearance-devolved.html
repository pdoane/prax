CSS Basic User Interface 4 · 7.2.1 Properties Disabling Native Appearance

Devolved widgets

Certain properties, when declared in the Author Origin, will disable the native appearance of certain widgets. The rendering of a devolved widget is identical to that of the widget in its primitive appearance, except when specified otherwise by the host language. CSS Basic User Interface 4 §7.2.1

A background or a border devolves a widget

The properties are the backgrounds', borders' and border radii's. Each stage holds a button, a text field and a select.

Only properties that cascade to a value

A widget devolves after having rolled back any number revert or revert-layer values, if a value is left. Properties not in the list, as color and padding, do not devolve it.
