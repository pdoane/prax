CSS Basic User Interface 4 · 7.2.3 Effects of appearance on Semantic Aspects of Elements

appearance: none keeps what operates a widget

When showing the primitive appearance of a widget or its devolved state, user agents must preserve aspects of the widget which are necessary to operate the widget with its original semantics. Aspects of a widget which are merely needed to observe the state the widget is in and are not needed to operate it should be suppressed as well when the same information can be conveyed using ordinary CSS.
