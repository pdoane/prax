appearance: the compatibility keywords

<compat-auto> is searchfield, textarea, checkbox, radio, menulist, listbox, meter, progress-bar and button: They all have the same effect as auto. CSS Basic User Interface 4 §7.2

The same as auto, whatever the element

A keyword brings back a widget's own native appearance, and a div stays a div.

textfield and menulist-button

<compat-special> is textfield and menulist-button: the host language may also take these values into account when defining the native appearance of the element. HTML does.
