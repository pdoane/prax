CSS Basic User Interface 4 · 5.2.3 Shape of the insertion caret, writing modes

caret-shape in vertical text

When determining the orientation and appearance of the caret, UAs must take into account the writing mode and must apply transformations. CSS Basic User Interface 4 §5.2.3

Under, in vertical-rl

In vertical-rl, “under” is the left side of the line. The box has writing-mode: vertical-rl; caret-shape: underscore; caret-animation: manual and a red caret-color.

A script gives the focus to the editable box and puts the insertion point in it. Safari and Firefox draw no caret in these stills.
