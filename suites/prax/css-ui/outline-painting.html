CSS Basic User Interface 4 · 3 Outline properties

Outlines: where they are painted

Outlines differ from borders in the following ways: Outlines do not take up space. Outlines contribute to the ink overflow area of an element. Outlines may be non-rectangular. CSS Basic User Interface 4 §3 That they take no space and add no scrollable overflow is shown on CSS 2's outline pages.

The stacking is left to the browser

The stacking of the rendering of these outlines is explicitly left up to implementations to provide a better user experience per platform. This supersedes the stacking of outlines as defined in Appendix E of CSS 2.1. A has a 6px red outline; B overlaps its lower edge.

Transforms are undefined

The rendering of applying transforms to outlines is left explicitly undefined.
