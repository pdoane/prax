CSS Basic User Interface 4 · 3.2 Outline Thickness: the outline-width property

outline-width: snapped as a border width

The outline-width property accepts the same values as border-width with the same meaning. Its computed value is an absolute length, snapped as a border width. CSS Basic User Interface 4 §3.2 The keywords are on CSS 2's outline-width pages.

As wide as a border of the same width

Snapping at one device pixel per CSS px: a width under 1px but above 0 rounds up to 1px, any other rounds down to whole pixels. In each figure a blue border of the same width is above a red outline.

A width with no style

Level 3 made the computed width 0 when the style is none; level 4 does not, but an outline of style none is still not drawn.
