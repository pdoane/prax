CSS Basic User Interface 4 · 5.2.3 Shape of the insertion caret, after the last character

caret-shape: block, at the end of the text

If there is no visible character after the insertion point, the UA must render the caret after the last visible character. CSS Basic User Interface 4 §5.2.3

A block after the last character

The width is 1ch if there is no next visible character. The box has caret-shape: block and caret-animation: manual, in a monospace font whose 1ch is 18px.

A script gives the focus to the editable box and puts the insertion point in it. Safari and Firefox draw no caret in these stills.
