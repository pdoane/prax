CSS Basic User Interface 4 · 7.2 Switching appearance: the appearance property

appearance: none and auto

Using appearance: none allows authors to suppress the native appearance of widgets, giving them a primitive appearance where CSS can be used to restyle them. CSS Basic User Interface 4 §7.2 How a widget looks natively is each platform's; the figures compare a browser with itself.

Native, then primitive

For auto, elements representing widgets should have the native appearance of that widget. For none, Widgets must not have their native appearance, and instead must have their primitive appearance. Each stage holds a checked checkbox, a button, a text field, a select and a range.

Elements that are not widgets

Elements other than widgets must be rendered as for none.
