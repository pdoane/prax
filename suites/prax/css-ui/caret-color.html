CSS Basic User Interface 4 · 5.2.1 Coloring the Insertion Caret: the caret-color property

caret-color

This property controls the color of the insertion caret. CSS Basic User Interface 4 §5.2.1

A color of its own

The caret is colored with the specified color. The box's text is dark blue, and it has caret-color: #c0392b.

A script gives the focus to the editable box and puts the insertion point in it. Safari and Firefox draw no caret in these stills.
