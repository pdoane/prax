CSS Basic User Interface 4 · 7.2.2 Effects of appearance on Decorative Aspects of Elements

appearance: none removes decorations

All decorative visual aspects of a widget which are not caused by a CSS style rule must be suppressed when the appearance is changed from native to primitive using appearance, even if the UA's internal representation for this element was composed of multiple elements or pseudo-elements combined together. CSS Basic User Interface 4 §7.2.2

The select's arrow, and a search field's decorations

the HTML select element is often rendered with an arrow on the right side indicating that the list will be expanded if the element is clicked. If the computed value of appearance on a select element is none, this must disappear.

Still recognizable

UAs should include in their user agent stylesheet style rules to give widgets a recognizable shape when appearance is none.
