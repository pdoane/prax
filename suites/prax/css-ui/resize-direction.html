CSS Basic User Interface 4 · 4.1 Resizing Boxes, block and inline

resize: block, inline, and the direction of resizing

The UA should consider the direction of resizing (as determined by CSS layout), as well as platform conventions and constraints, when deciding how to convey the resizing mechanism to the user. CSS Basic User Interface 4 §4.1

Flow-relative values

block resizes only the block size and inline only the inline size. In vertical-rl, the block end is on the left, and the inline end at the bottom.

Optionally, replaced elements

UAs may also apply it, regardless of the value of the overflow property, to: Replaced elements representing images or videos. HTML's textarea is a scroll container, and resizable by default.
