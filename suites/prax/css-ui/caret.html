CSS Basic User Interface 4 · 5.2 Insertion caret

The insertion caret

The insertion caret (or “caret” for short) is a visible indicator of the insertion point in an element that accepts text input, where text (and potentially other content) can be inserted by the user. CSS Basic User Interface 4 §5.2

In an editable element

The box has contenteditable, so it accepts text input. Its text is dark blue, and its caret has every property at its initial value: caret-color: auto, where User agents should use currentColor §5.2.1, and caret-shape: auto.

A script gives the focus to the editable box and puts the insertion point in it. Safari and Firefox draw no caret in these stills.
