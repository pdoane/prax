CSS Basic User Interface 4 · 6.1 Controlling content selection, all

user-select: all

For all, The content of the element must be selected atomically: If a selection would contain part of the element, then the selection must contain the entire element including all its descendants. CSS Basic User Interface 4 §6.1

A script in each frame makes the selection, highlighted orange. Safari draws no selection in these stills.

Selected whole

Each frame's script places the start of a selection and extends it one character forward, as Shift and the right arrow key would. The span “all of it” has user-select: all.
