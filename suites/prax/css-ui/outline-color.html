CSS Basic User Interface 4 · 3.4 Outline Colors: the outline-color property

outline-color: auto and stripes

When outline-style is auto, outline-color: auto computes to auto and represents the accent color. Otherwise, outline-color: auto computes to currentColor. CSS Basic User Interface 4 §3.4

auto, the initial value

Each box has color: #2c5a8f, dark blue, and accent-color: #27ae60, green, and no outline-color.

Stripes, as in borders

The outline-color property accepts all values of <'border-top-color'>. A stripes() color of border-top-color draws bands, whose stripes defined by <image-1D> follow the shape of the border CSS Borders and Box Decorations 4 §2.1. The box has outline: 9px solid; outline-color: stripes(#4f81bd, #d68a3c, #6aa36a).
