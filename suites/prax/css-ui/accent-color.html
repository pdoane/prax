CSS Basic User Interface 4 · 7.1 Widget Accent Colors: the accent-color property

accent-color

The accent-color CSS property allows the author to specify the accent color for user-interface controls generated by the element. The UA should use the specified accent-color to draw whichever parts of the element’s control(s) would have otherwise been styled with an accent color. CSS Basic User Interface 4 §7.1

The platform's color, or the author's

A checked checkbox, a checked radio button, a range and a progress bar. Which parts take the accent color is the platform's; a style that uses none is unchanged.

A translucent color is made opaque over Canvas

If the color supplied is partially or fully transparent, the user agent must first pre-compose it over the Canvas system color and use the resulting (now opaque) color as the accent color. Canvas is white here.
