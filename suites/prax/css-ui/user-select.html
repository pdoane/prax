CSS Basic User Interface 4 · 6.1 Controlling content selection

user-select: none

The user-select property enables authors to specify which elements in the document can be selected by the user and how. CSS Basic User Interface 4 §6.1

A script in each frame makes the selection, highlighted orange. Safari draws no selection in these stills.

Excluded from a selection across it

For none, The UA must allow selections to extend across this element, and must exclude this element from such a selection. HTML's style sheet adds button, meter, progress, select { user-select: none; }.

Generated content, and ::first-line

On ::before and ::after, the used value is none for auto, and User agents must not apply the user-select property to the ::first-line and ::first-letter pseudo-elements.
