CSS Basic User Interface 4 · 7.2 Switching appearance, disregarded properties

A native widget's box

For auto, The element's box is laid out like a regular replaced element. User agents may disregard some CSS properties used to size and paint the contents of widgets rendered with their native appearance. CSS Basic User Interface 4 §7.2

Size, position and what is drawn outside the box apply

CSS properties that impact the box sizing or position of the widget's box (such as the sizing properties), or their visual appearance outside of the box (such as transform, filter or box-shadow), must be applied to widgets rendered with their native appearance. Each checkbox is native and has width: 40px; height: 40px, with a dashed outline round its box.

Painting inside the box may be disregarded

Padding and border may be disregarded when needed. Other properties that affect painting (like background-color) may be disregarded when needed.
