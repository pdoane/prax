CSS Basic User Interface 4 · 3.3 Outline Patterns: the outline-style property

outline-style: auto

The auto value permits the user agent to render a custom outline style, typically a style which is either a user interface default for the platform, or perhaps a style that is richer than can be described in detail in CSS. User agents may treat auto as solid. CSS Basic User Interface 4 §3.3 The other styles are those of borders, on CSS 2's outline-style pages.

The width is ignored

The outline-width property is ignored when outline-style is auto.

A style of the browser's own

User agents may enable authors to influence the rendering of auto style outlines via the outline-color property, but this specification does not define how the rendering is impacted (if at all).
