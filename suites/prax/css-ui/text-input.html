CSS Basic User Interface 4 · 7.3.1 Single-Line Text Input Controls

Single-line text fields

When appearance is auto, single-line text input controls such as HTML <input type=text> must be rendered so that the content is clipped in the inline direction to the content edge and in the block direction to the padding edge, is vertically centered, does not wrap, and The text-overflow property applies regardless of the value of the overflow property. Each field is native, 100px wide in .pr-measure text, 10px a letter, with 20px of padding left and right; its value is "a value too long".
