CSS Basic User Interface 4 · 4.1 Resizing Boxes: the resize property

resize: the resizing mechanism

The resize property allows the author to specify whether or not an element is resizable by the user, and if so, along which axis/axes. CSS Basic User Interface 4 §4.1 A still shows the mechanism, not its use: dragging a box's corner sets its width and height, held only by min- and max- sizes.

The values

The UA presents a bidirectional resizing mechanism for both, a horizontal or vertical one for horizontal and vertical, and none for none. Each box has overflow: auto.

Scroll containers, and not generated content

The resize property applies to elements that are scroll containers. Implementations should not apply the resize property to generated content.
