CSS Basic User Interface 4 · 3.5 Offsetting the Outline, negative values

Large negative outline-offset

Both the height and the width of the outside of the shape drawn by the outline should not become smaller than twice the computed value of the outline-width property to make sure that an outline can be rendered even with large negative values. User agents should apply this constraint independently in each dimension. CSS Basic User Interface 4 §3.5

No smaller than twice the width, in each dimension

Each box is 120 by 40 with a 5px red outline, so the outline's outside is never less than 10px either way.

Each shape separately

If the outline is drawn as multiple disconnected shapes, this constraint applies to each shape separately. The span, broken over two lines with a gap between its pieces, has a 3px outline and outline-offset: -20px.
