CSS Basic User Interface 4 · 7.2 Switching appearance, base

appearance: base and base-select

Using appearance: base gives widgets a base appearance. Widgets in base appearance have their native appearance suppressed where CSS can be used to restyle them, just like primitive appearance, but also have default styles which are usable and interoperable. CSS Basic User Interface 4 §7.2

base-select

For base-select, The select element or ::picker(select) is rendered as for base. Everything else is rendered as for auto. HTML defines the base appearance of select.

base

Widgets which don't have a base appearance must be rendered as for auto. But appearance:base is not ready to ship until its stylesheet has been fully defined in the HTML specification, so what a widget looks like in it is not settled.
