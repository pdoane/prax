CSS Values and Units 4 · 10.3 Stepped Value Functions

round(), mod() and rem()

The round(<rounding-strategy>?, A, B?) function contains an optional rounding strategy, and two calculations A and B, and returns the value of A, rounded according to the rounding strategy, to the nearest integer multiple of B either above or below A. CSS Values and Units 4 §10.3 Each bar's width is under it.

Rounding 117px to a multiple of 50px

mod() and rem() of −18px by 5px

mod(-18px, 5px) resolves to the value 2px, rem(-18px, 5px) resolves to the value -3px. Each width is 100px plus ten of them.
