CSS Values and Units 4 · 5.6 Mixing Percentages and Dimensions

Lengths and percentages together

<length-percentage> is Equivalent to [ <length> | <percentage> ], where the <percentage> will resolve to a <length>. This means that width: calc(500px + 50%); is allowed-- both values are converted to absolute lengths and added. CSS Values and Units 4 §5.6 Each stage is 200px wide.
