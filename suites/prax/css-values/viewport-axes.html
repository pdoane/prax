CSS Values and Units 4 · 6.1.2.2 The Various Viewport-relative Units

vi and vb: the box's axes

vi is equal to 1% of the size of the viewport in the box’s inline axis, and vb in the box’s block axis; vmin is equal to the smaller of *vw or *vh and vmax the larger. CSS Values and Units 4 §6.1.2.2 Each frame is a viewport 200 by 100, and holds a blue box width: 50vi; height: 50vb.
