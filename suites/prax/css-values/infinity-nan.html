CSS Values and Units 4 · 10.7.2 Degenerate Numeric Constants

infinity, -infinity and NaN

These constants are defined mostly to make serialization of infinite/NaN values simpler and more obvious, but can be used to indicate a "largest possible value", since an infinite value gets clamped to the allowed range. CSS Values and Units 4 §10.7.2 to get an infinite length, for example, requires an expression like calc(infinity * 1px).
