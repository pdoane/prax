CSS Values and Units 4 · 6.1.1 Font-relative Lengths, in font-affecting properties

Font-relative lengths in font-size and line-height

When used in the value of any font-affecting property on the element they refer to, the font-relative lengths resolve against the computed metrics of the parent element CSS Values and Units 4 §6.1.1

In font-size, the parent's font, or the initial one

In line-height, the parent's lh, and the element's own em

when lh or rlh units are used in the value of the 'line-height' property they resolve against the computed 'line-height' and font metrics of the parent element (The other font-relative lengths continue to resolve against the element’s own metrics when used in 'line-height'.)
