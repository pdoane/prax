CSS Values and Units 4 · 10.9 Type Checking

Types multiply and divide

Operators form sub-expressions, which gain types based on their arguments. In previous versions of this specification, multiplication and division were limited in what arguments they could take This version now relaxes those restrictions. CSS Values and Units 4 §10.9

A length over a length

At a / sub-expression, the right type is inverted and multiplied in: a length divided by a length is a number, and a length squared over a length a length. Each bar's width is under it.

A number where an integer goes

math functions that resolve to <number> can be used in any place that only accepts <integer>; the value is rounded to the nearest integer as it resolves.
