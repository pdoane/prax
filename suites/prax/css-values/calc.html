CSS Values and Units 4 · 10.1 Basic Arithmetic: calc()

calc(): arithmetic on lengths

A calc() represents the result of evaluating the expression using standard operator precedence rules (* and / bind tighter than + and -, and operators are otherwise evaluated left-to-right). CSS Values and Units 4 §10.1

Precedence

Different units, one length

In this example the author wants the margin box of each section to take up 1/3 of the space: three floats, each margin: 1em; border: solid 1px; width: calc(100% / 3 - 2 * 1em - 2 * 1px) in 10px text.
