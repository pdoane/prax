CSS Values and Units 4 · 6 Distance Units: the <length> type

Border widths snap to device pixels

<length>s in 'border-width' and a few other properties are rounded in a specific fashion to ensure reasonable visual display. CSS Values and Units 4 §6

Snap a length as a line width

If the absolute value of len is greater than zero, but less than 1 device pixel, round it away from zero to 1 or -1 device pixel. If the absolute value of len is greater than 1 device pixel, round it towards zero to the nearest integer number of device pixels. Each box is a light 10px strip with a top border.
