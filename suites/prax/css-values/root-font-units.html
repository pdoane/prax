CSS Values and Units 4 · 6.1.1 Font-relative Lengths, the root units

rem, rex, rcap, rch, ric, rlh: the root's font

The root font-relative lengths refer to the font metrics of the root element: rem is the computed value of the em unit on the root element, and rex, rcap, rch, ric and rlh are each equal to the value of the ex, cap, ch, ic and lh units on the root element. CSS Values and Units 4 §6.1.1
