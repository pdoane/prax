Exponential functions at their limits

In pow(A, B), if A is negative and finite, and B is finite, B must be an integer, or else the result is NaN. In sqrt(A) If A is less than 0, the result is NaN. CSS Values and Units 4 §10.5.1 A NaN is censored to zero and an infinity clamped (§10.9.2). Each bar's width is under it.
