CSS Values and Units 4 · 5.2 Integers

Rounding to the nearest integer

Unless otherwise specified, in the CSS specifications rounding to the nearest integer requires rounding in the direction of +∞ when the fractional portion is exactly 0.5. (For example, 1.5 rounds to 2, while -1.5 rounds to -1.) CSS Values and Units 4 §5.2 A calc() that gives a number where an integer goes is rounded so (§10.9).
