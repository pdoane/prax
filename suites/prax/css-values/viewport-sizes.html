CSS Values and Units 4 · 6.1.2.1 The Large, Small, and Dynamic Viewport Sizes

Small, large and dynamic viewport units

The large viewport-percentage units (lv*) and default viewport-percentage units (v*) assume interfaces that expand and retract to be retracted, the small viewport-percentage units (sv*) assume them expanded, and the dynamic viewport-percentage units (dv*) follow them. CSS Values and Units 4 §6.1.2.1 Each frame is a viewport 200 by 100.

A frame has no such interface

So the three sizes are one. Four bars side by side, each 40px wide.

Scrollbars on the root

if the value of 'overflow' or 'scrollbar-gutter' on the root element in either axis would cause scrollbars to appear (or space to be reserved for them) unconditionally (for example, overflow: scroll, but not overflow: auto), the computed values of the viewport-percentage lengths in that axis are reduced in accordance with the initial containing block. Each bar is 100vw wide, and each frame's content overflows it.
