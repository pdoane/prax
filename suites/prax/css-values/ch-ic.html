CSS Values and Units 4 · 6.1.1 Font-relative Lengths, ch and ic

ch and ic: the advance of 0 and of 水

A ch is measured as the used advance measure of the “0” (ZERO, U+0030) glyph in the font used to render it, and an ic as the used advance measure of the “水” (CJK water ideograph, U+6C34) glyph found in the font used to render it. CSS Values and Units 4 §6.1.1 Each stage is 40px text, and under it a blue bar.

ch

This measurement is an approximation (and in monospace fonts, an exact measure) of a single narrow glyph’s advance measure. Under three zeros, a bar 3ch wide.

ic

This measurement is a typically an exact measure (in the few fonts with proportional fullwidth glyphs, an approximation) of a single fullwidth glyph’s advance measure. Under three ideographs, a bar 3ic wide.
