CSS Values and Units 4 · 6.1.1 Font-relative Lengths, ex and cap

ex and cap: the font's x-height and cap height

An ex is the used x-height of the first available font, and a cap the used cap-height of the first available font. CSS Values and Units 4 §6.1.1 In each stage, 80px text and a blue box on its baseline, dashed red.

ex

Some fonts contain reliable metrics for the x-height. Both of these do. The box is 1ex tall.

cap

The cap-height is so called because it is approximately equal to the height of a capital Latin letter. The box is 1cap tall.
