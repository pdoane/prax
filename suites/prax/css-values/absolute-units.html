CSS Values and Units 4 · 6.2 Absolute Lengths

in, cm, mm, Q, pt, pc, px: fixed ratios

The absolute length units are fixed in relation to each other and anchored to some physical measurement. For screen media it is recommended instead that the anchor unit be the pixel unit. CSS Values and Units 4 §6.2 Each bar is as wide as the length beside it.

One inch

1in = 2.54cm = 96px, 1pc = 1/6th of 1in, 1pt = 1/72nd of 1in, 1mm = 1/10th of 1cm, 1Q = 1/40th of 1cm.
