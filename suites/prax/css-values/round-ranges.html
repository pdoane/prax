CSS Values and Units 4 · 10.3.1 Argument Ranges

round(), mod() and rem() at zero and infinity

In round(A, B), if B is 0, the result is NaN. If A is finite but B is infinite, the result depends on the <rounding-strategy> and the sign of A. CSS Values and Units 4 §10.3.1 A NaN is censored into a zero value, and an infinity clamped (§10.9.2). Each bar's width is under it; ∞ is infinity * 1px.

round()

mod() and rem()

In mod(A, B) only, if B is infinite and A has opposite sign to B (including an oppositely-signed zero), the result is NaN. All other "infinite B" cases are valid, and just return A immediately.
