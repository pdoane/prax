CSS Values and Units 4 · 10.6 Sign-Related Functions

abs() and sign()

The abs(A) function contains one calculation A, and returns the absolute value of A. The sign(A) function contains one calculation A, and returns -1 if A's numeric value is negative, +1 if A's numeric value is positive. CSS Values and Units 4 §10.6

On lengths

Each bar's width is under it.

On a resolved percentage

The functions operate on the fully simplified/resolved form of their arguments. in 'background-position' positive percentages resolve to a negative length if the background image is larger than the background area. The image is 300px wide in a 200px area, so 10% is −10px.
