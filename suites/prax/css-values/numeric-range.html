Values beyond what an engine supports

The precision and supported range of numeric values in CSS is implementation-defined. When a value cannot be explicitly supported due to range/precision limitations, it must be converted to the closest value supported by the implementation. CSS Values and Units 4 §5

An integer too large

Blue A is z-index: 99999999999; orange B, after it, is z-index: 2147483647, the largest 32-bit integer, which all three browsers support.
