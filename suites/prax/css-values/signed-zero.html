CSS Values and Units 4 · 10.9.2 Infinities, NaN, and Signed Zero

Infinities, NaN and signed zeros

Math functions follow IEEE-754 semantics. However, these concepts are only retained within a calculation tree; if a top-level calculation (a math function not nested directly inside of another math function) would result in one of these special values, they're instead "censored" into a standard representable value. Division by zero, by sign

Dividing a value by zero produces either +∞ or −∞, according to the standard sign rules. Negative zero (0⁻) can be produced by a multiplication or division that produces zero with exactly one negative argument.

NaN

Dividing zero by zero, dividing ±∞ by ±∞, multiplying 0 by ±∞, adding +∞ to −∞, or subtracting two infinities of the same sign produces NaN. it's censored into a zero value.
