CSS Values and Units 4 · 5.7 Ratios

Ratios: width to height

A ratio most often represents an aspect ratio, relating a width (first) to a height (second). The second <number> is optional, defaulting to 1. CSS Values and Units 4 §5.7 Each blue box has a width and aspect-ratio, and its height from them.

Width first, height second

Degenerate ratios

If either number in the <ratio> is 0 or infinite, it represents a degenerate ratio (and, generally, won't do anything).
