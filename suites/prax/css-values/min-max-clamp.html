CSS Values and Units 4 · 10.2 Comparison Functions

min(), max() and clamp()

The min() or max() functions contain one or more comma-separated calculations, and represent the smallest (most negative) or largest (most positive) of them, respectively. CSS Values and Units 4 §10.2 Each bar's width is the function under it, in a 200px stage.

min() and max()

clamp()

given clamp(MIN, VAL, MAX), it represents exactly the same value as max(MIN, min(VAL, MAX)). Either the min or max calculations (or even both) can instead be the keyword none.
