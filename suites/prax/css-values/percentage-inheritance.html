CSS Values and Units 4 · 5.5.1 Computation and Combination of <percentage>

A percentage computes to a percentage

Unless otherwise specified (such as in 'font-size', which computes its <percentage> values to <length>), the computed value of a percentage is the specified percentage. CSS Values and Units 4 §5.5.1 So what a child inherits is the percentage, resolved again against its own base.
