CSS Values and Units 4 · 10.4.1 Argument Ranges

Trigonometric functions at their limits

In sin(A), cos(A), or tan(A), if A is infinite, the result is NaN. In asin(A) or acos(A), if A is less than -1 or greater than 1, the result is NaN. In atan(A), if A is +∞, the result is 90deg. CSS Values and Units 4 §10.4.1 A NaN is censored into a zero value (§10.9.2).
