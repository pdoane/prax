CSS Values and Units 4 · 10.4 Trigonometric Functions

sin(), cos(), tan() and their inverses

sin(), cos() and tan() compute their corresponding function by interpreting the result of their argument as radians. (That is, sin(45deg), sin(.125turn), and sin(3.14159 / 4) all represent the same value, approximately .707.) CSS Values and Units 4 §10.4

A number from an angle

Each bar's width is under it.

An angle from a number

Each bar is rotate()d by the angle under it. atan2(1, -1), corresponding to the point (-1, 1), returns 135deg, distinct from atan2(-1, 1), corresponding to the point (1, -1), which returns -45deg.
