CSS Values and Units 4 · 6.1 Relative Lengths

Relative lengths inherit as absolute lengths

Relative length units specify a length relative to another length. Child elements do not inherit the relative values as specified for their parent; they inherit the computed values. CSS Values and Units 4 §6.1 In each stage, a parent in 10px text holds a child in 20px text.
