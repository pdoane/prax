CSS Values and Units 4 · 9.1 Numeric Functions

Functions out of range are clamped and rounded

numeric functions returning out-of-range values never cause a declaration to become invalid. Instead, the value of a numeric function is clamped to the range allowed in the context it is used at computed value time if possible, and at used value time otherwise. CSS Values and Units 4 §9.1

Clamped

Since widths smaller than 0px are not allowed, these three declarations are equivalent: width: calc(5px - 10px); width: calc(-5px); width: 0px; Each box has a 2px border.

Rounded

if a numeric function returns a non-integer value, but is used in a position that expects an <integer>, the computed value and used value are rounded to the nearest integer.
