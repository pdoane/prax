CSS Values and Units 4 · 10.9.1 Calculation Contexts

Percentages in a function resolve as the property's do

Math functions always inherit the calculation context from wherever they're used. That is, in top: calc(25% + 50px), the <percentage> is resolved as normal for 'top', as if top: 25% were specified (and then has 50px added to its value). CSS Values and Units 4 §10.9.1 Each stage is 200 by 100.

One context per property

Two contexts in one property

in 'background-size' one value resolves <percentage>s against the width of the background positioning area while the other resolves them against the height.
