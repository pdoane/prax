CSS Pseudo-Elements 4 · 3.5 Cascading and Per-Element Highlight Styles

Custom properties in highlights

All custom properties inherit from the originating element, regardless of whether that property is a custom property that is registered to inherit or not. CSS Pseudo-Elements 4 §3.5 Each stage's text is all in one custom highlight.

Declared on the element, or on the highlight

The text box sets --shade: green; its highlight uses background-color: var(--shade, red).

From the element, not the parent's highlight

The text box sets --shade: green and its span --shade: orange, and every highlight uses background-color: var(--shade).
