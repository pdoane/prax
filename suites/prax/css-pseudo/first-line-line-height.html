CSS Pseudo-Elements 4 · 2.1.2 Styling the ::first-line Pseudo-element

line-height on ::first-line

Setting line-height on ::first-line inherits to the fragment of the root inline box that wraps the contents of the first line, and therefore can both increase and decrease the height of the first line box.
