CSS Pseudo-Elements 4 · 4.2 List Markers: the ::marker pseudo-element

::marker and the other pseudo-elements

The ::marker pseudo-element represents the automatically generated marker box of a list item. CSS Pseudo-Elements 4 §4.2 What it is and which properties apply to it are CSS Lists'; this page shows how it meets the other pseudo-elements.

Not selected by ::first-letter

The contents of a ::marker are ignored (not selected) by ::first-letter. Each item has ::first-letter in bold red.

And ::first-line, under discussion

Interaction of ::marker and ::first-line is currently under discussion in Issue 4506. csswg-drafts#4506
