CSS Pseudo-Elements 4 · 2.1.3 Inheritance and the ::first-line Pseudo-element

Inheriting from ::first-line

the fragment of a child that occurs on the first line inherits any standard inherited properties—except the properties excluded above—from the ::first-line pseudo-element. For all other properties, including all custom properties, inheritance is from the non-pseudo parent. CSS Pseudo-Elements 4 §2.1.3 The text is 10px a character, 20 to a line; each p::first-line is orange.

A child across the break

The portion of a child element that does not occur on the first line always inherits from the non-pseudo parent. The spans are light orange.
