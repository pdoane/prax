CSS Pseudo-Elements 4 · 2.1.2 Styling the ::first-line Pseudo-element

Properties on ::first-line

The ::first-line pseudo-element’s generated box behaves similar to that of an inline-level box, but with certain restrictions. CSS Pseudo-Elements 4 §2.1.2 Each paragraph is 10px a character, 20 characters to a line; backgrounds, margins and borders on ::first-line are CSS Backgrounds', CSS Box's and CSS Borders' to show.

Font, typesetting, decoration and opacity apply

all font properties, the color and opacity properties, any typesetting properties that apply to inline elements, all text decoration properties.

Never the writing mode

User agents may apply other properties as well except for the following excluded properties: writing-mode, direction, text-orientation
