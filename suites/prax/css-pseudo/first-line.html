CSS Pseudo-Elements 4 · 2.1 First-Line Text: the ::first-line pseudo-element

::first-line: the first formatted line

The ::first-line pseudo-element represents the contents of the first formatted line of its originating element. CSS Pseudo-Elements 4 §2.1 Each paragraph's text is 10px a character on 20px lines.

After the text wraps

the ::first-line pseudo-element can select content on the first formatted line of an element after text wrapping §1. The same paragraph, p::first-line { color: orange }, in two widths.

The section's example

text-transform is one of any typesetting properties that apply to inline elements §2.1.2, so it applies; the example would change the letters of the first line of every p element to uppercase: p::first-line { text-transform: uppercase }.
