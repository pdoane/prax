CSS Pseudo-Elements 4 · 2.2.3 Inheritance and Box Tree Structure of the First-Letter Pseudo-elements

Where ::first-letter sits in the box tree

The ::first-letter pseudo-element is wrapped immediately around the first-letter text it represents, even if that text is in a descendant. When a first-letter text is represented by multiple ::first-letter pseudo-elements, they are nested in the same order as their originating elements. Inheritance behaves accordingly.
