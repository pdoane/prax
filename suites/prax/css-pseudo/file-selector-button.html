CSS Pseudo-Elements 4 · 5.1 File Selector Button: the ::file-selector-button pseudo-element

::file-selector-button

The ::file-selector-button pseudo-element targets the <button> inside an <input> element with type=file, if the UA renders such a button. There is no restriction on which properties apply to the ::file-selector-button pseudo-element. CSS Pseudo-Elements 4 §5.1 The button's label and the text after it are each browser's own.
