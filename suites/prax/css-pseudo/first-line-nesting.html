CSS Pseudo-Elements 4 · 2.1.1 Finding the First Formatted Line

Nested ::first-line pseudo-elements

When a first formatted line is represented by multiple ::first-line pseudo-elements, they are nested in the same order as their originating elements. The inline-level contents of this line—including its root inline box fragment—are nested within the innermost ::first-line pseudo-element. CSS Pseudo-Elements 4 §2.1.1 The text is 10px a character on 20px lines.

The div's outside, the p's inside

The section's example: <div><p>First paragraph</p><p>Second paragraph</p></div> as <P><DIV::first-line><P::first-line>First paragraph</P::first-line></DIV::first-line></P>. The div's ::first-line is orange on light orange; each p's is blue.

The inner one inherits from the outer one

Nested inside the div's ::first-line, the p's inherits from it what it does not set itself, and the line's contents, its root inline box fragment among them, inherit from the p's.
