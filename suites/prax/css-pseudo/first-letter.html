CSS Pseudo-Elements 4 · 2.2 First-Letter Text: ::first-letter pseudo-element and its ::prefix and ::suffix children

::first-letter: a letter, number or symbol

The ::first-letter pseudo-element represents the first Letter, Number, or Symbol (Unicode category L*, N*, or S*) typographic character unit on the first formatted line of its originating element (the first letter) as well as its associated punctuation. CSS Pseudo-Elements 4 §2.2 In each stage the first letter is white on orange; every character is 10px wide.
