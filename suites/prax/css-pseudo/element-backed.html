Element-backed pseudo-elements

The element-backed pseudo-elements, interact with most CSS and other platform features as if they were real elements CSS Pseudo-Elements 4 §5 Each x-card is blue text with a shadow tree: a green div around a span that is part="label", reading "label", the div's first child.

Selected as if a type selector

All pseudo-classes and pseudo-elements are syntactically allowed after an element-backed pseudo-element but some are disallowed from matching: The structural pseudo-classes, :has() pseudo-class, :scope pseudo-class, and :host/:host()/:host-context() pseudo-classes never match.

Inheriting from another element

they can be defined to inherit from another element instead. (For example, ::part() inherits from the parent of the element it represents in the shadow tree.)
