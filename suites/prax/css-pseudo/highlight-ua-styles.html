CSS Pseudo-Elements 4 · 3.3 Default UA Styles

The user agent's highlight colors

Some highlight pseudo-elements should have paired default highlight colors—a default color and background-color provided by the UA that are either used or overridden together. CSS Pseudo-Elements 4 §3.3 The selection is set by a script. Safari's stills show no selection: their window is never the focused one.

::selection, and the system colors it should match

For ::selection they should correspond to HighlightText and Highlight, while for ::target-text they should correspond to MarkText and Mark. The page sets no style on ::selection.

What CSS does not control

UAs may apply additional effects to enhance the presentation of highlighted content, for example dimming content other than the highlighted text or transitioning out a highlight style based on user interactions or timing. These are not controlled by CSS. The recommended rules :root::spelling-error { text-decoration: spelling-error; } and its grammar-error counterpart style what a spell checker marks, which a still cannot show.
