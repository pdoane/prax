CSS Pseudo-Elements 4 · 3.6.4 Replaced Elements

Highlighted replaced elements

For non-replaced content, the UA must honor the color and background-color (including their alpha channels) as specified. However, for replaced content, the UA should create a semi-transparent wash to coat the content so that it can show through the selection. CSS Pseudo-Elements 4 §3.6.4

An image: a wash

This wash should be of the specified background-color if that is not transparent, else of the specified color; however the UA may adjust the alpha channel.
