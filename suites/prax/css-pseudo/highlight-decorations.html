CSS Pseudo-Elements 4 · 3.6.3 Text and Text Decorations

Decorations of highlighted text

Any text decorations introduced by each highlight pseudo-element are stacked in the same order as their backgrounds over the text’s original decorations and are all drawn, each decoration in its own color. CSS Pseudo-Elements 4 §3.6.3 Each stage holds dark grey text, all or part of it in a custom highlight.

The highlight redraws the text (and those decorations) using that highlight’s own color.
