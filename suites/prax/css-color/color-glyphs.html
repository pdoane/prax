CSS Color 4 · 3.2 Foreground Color: the color property, color glyphs

The color property and color glyphs

When applied to text, this property, including its alpha component, has no effect on “color glyphs” (such as the emoji in some fonts), which are colored by a built-in palette. CSS Color 4 §3.2

The foreground color in a palette

some colored fonts are able to refer to a contextual “foreground color”, such as by palette entry 0xFFFF in the COLR table of OpenType [...] In such cases, the foreground color is set by this property, identical to how it sets the currentcolor value.
