CSS Color 4 · 10.13 Simple Alpha Compositing

Simple alpha compositing

When drawing, implementations must handle alpha according to the rules in Section 5.1 Simple alpha compositing of [Compositing]. CSS Color 4 §10.13 There, a color of alpha αs over a backdrop of alpha αb gives co = cs × αs + cb × αb × (1 − αs).

A color over an opaque backdrop

Each first swatch is a box of the backdrop holding a box of the color; each second is the result in rgb().
