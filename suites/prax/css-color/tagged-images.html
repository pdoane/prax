CSS Color 4 · 3.4 Color Space of Tagged Images

Tagged images

Tagged RGB images, and tagged images using a transformation of RGB such as YCbCr, if the color profile or other identifying information is valid, must be treated as being in the specified color space. CSS Color 4 §3.4

The profile decides the color

The image swap-990000-iCCP.png stores the pixel values of #990000, a dark red, and embeds an ICC profile that is sRGB with its red and green colorants swapped. In that space the pixels are #009900, a green. It must not treat the [...] values as if they were [another space's] values, which would produce incorrect colors.
