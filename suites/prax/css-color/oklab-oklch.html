CSS Color 4 · 9.4 Specifying Oklab and OkLCh: the oklab() and oklch() functional notations

oklab() and oklch()

CSS allows colors to be directly expressed in Oklab and OkLCh. CSS Color 4 §9.4 Each pair is the specification's example, then the rgb() it converts to.

oklab() and oklch()

for L: 0% = 0.0, 100% = 1.0; for a and b: -100% = -0.4, 100% = 0.4; for C: 0% = 0.0 100% = 0.4.

Lightness 0 and 1

If the lightness of an OkLCh color is 0% or 0, or 100% or 1.0, the color will be displayed as black, or white, respectively due to gamut mapping to the display.
