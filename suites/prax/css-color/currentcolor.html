CSS Color 4 · 6.4 The currentcolor keyword

currentcolor

The keyword currentcolor represents value of the 'color' property on the same element. Unlike <named-color>s, it is not restricted to sRGB; the value can be any <color>. CSS Color 4 §6.4

The element's color

A property whose initial value is currentcolor

the 'text-emphasis-color' property, whose initial value is currentcolor, by default matches the text color even as the 'color' property changes across elements. Black text in em with text-emphasis: dot, and a strong in red.
