CSS Color 4 · 3.3 Transparency: the opacity property, values

opacity: numbers and percentages

Represented as a <number>, the useful range of the value is 0 (representing full transparency) to 1 (representing full opacity). CSS Color 4 §3.3

Numbers and percentages, clamped

A percentage computes to the equivalent <number>; values outside [0,1] are clamped to the range [0, 1] in computed values.
