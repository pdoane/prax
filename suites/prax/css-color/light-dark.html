CSS Color 5 · 7 Reacting to the used color-scheme: the light-dark() Function

light-dark()

For the color form, this function computes to the computed value of the first color, if the element color scheme is light, or to the computed value of the second color, if the element color scheme is dark. The stages set color-scheme (CSS Color Adjustment 1 §2.2). CSS Color 5 §7

Colors

Text in light-dark(#2c5a8f, #f6d7b4) on light-dark(#ffffff, #1f2430).

Images

For the image form, this function returns the first image, if the element color scheme is light, or the second image; The none keyword computes to image(transparent).
