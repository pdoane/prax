CSS Color 4 · 13.1 Component-wise Linear Interpolation

Component-wise linear interpolation

Given a percentage progress P and the starting and ending component values Cs and Ce, the interpolated result is (Cs × (1 - P) + Ce × P). CSS Color 4 §13.1

Each component on its own

From oklab(0.4 0.1 0.05), a brick red, to oklab(0.8 -0.1 0.1), a light green, at 30%: L = 0.4 × 0.7 + 0.8 × 0.3 = 0.52, a = 0.04, b = 0.065.

Quantities

Given a pair of percentage quantities Qa and Qb, which have been normalized to add to 100%, [...] the interpolated result is (Ca × Qa) + ( Cb × Qb). the progress is the amount of the second color. The swatch shows 30% along linear-gradient(to right, oklab(0.4 0.1 0.05), oklab(0.8 -0.1 0.1)) (CSS Images 4 §3.1): 70% of the first, 30% of the second.
