CSS Color 4 · 13.2 Color Space for Interpolation, legacy colors

Legacy colors interpolate in sRGB

However, user agents must handle interpolation between legacy sRGB color formats (hex colors, named colors, rgb(), hsl() or hwb() and the equivalent alpha-including forms) in gamma-encoded sRGB space. CSS Color 4 §13.2
