CSS Color 4 · 4.4 “Missing” Color Components and the none Keyword

Missing components: none

A component can be specified explicitly, by providing the keyword none for a component in a color function. CSS Color 4 §4.4

Drawn as zero

For all other purposes, a missing component behaves as a zero value, in the appropriate unit for that component: 0, 0%, or 0deg.. Each pair is the color with none, then with zero.

In interpolation, the other color's value

to animate a color to "grayscale", no matter what the color is, one can interpolate it with oklch(none 0 none).
