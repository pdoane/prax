CSS Color 5 · 5.3 Specifying a Color Profile: the @color-profile at-rule

@color-profile

The @color-profile rule defines and names a color profile which can later be used in the color() function to specify a color. CSS Color 5 §5.3 Each pair is the color, then the color it should be, written out.

The last rule of a name wins

If multiple @color-profile rules are defined with the same name, the last one in document order wins, and all preceding ones are ignored. --late is first a profile that does not exist, then swapped.icc.

Named components

The value of this descriptor is a comma-separated list of <ident> tokens. Each <ident>> names a component, for relative colors (§5.1). --named is swapped.icc with components: p, q, r.
