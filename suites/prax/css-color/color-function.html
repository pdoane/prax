CSS Color 4 · 10.1 Specifying Predefined Colors: the color() function

The color() function

The color() function allows a color to be specified in a particular, specified color space (rather than the implicit sRGB color space that most of the other color functions operate in). CSS Color 4 §10.1

A space, three components, and alpha

An <ident> denoting one of the predefined color spaces, The three parameter values that the color space takes, An optional slash-separated <alpha-value>. 10.2 to 10.9 show each space.

Out-of-range values are kept

An out of gamut color has component values less than 0 or 0%, or greater than 1 or 100%. These are not invalid, and are retained for intermediate computations. Each swatch is the middle of linear-gradient(in srgb to right, A, black) (CSS Images 4 §3.1), its middle 40px of 4000px.
