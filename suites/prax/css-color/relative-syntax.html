CSS Color 5 · 4.2 Relative Color Syntax

Relative color syntax

The component keywords return a <number>, or none; if they were originally specified as a <percentage> or an <angle>, that <percentage> is resolved to a <number> and the <angle> is resolved to a <number> of degrees. CSS Color 5 §4.2 Each pair is the relative color, then the color it should be, written out.

Keywords are numbers

oklab(from oklab(54.3% -22.5% -5%) calc(1.0 - l) calc(a * 0.8) b): the specified percentages are resolved to numbers, giving oklab(0.543 -0.09 -0.02) and the result is oklab(0.457 -0.072 -0.02). oklch(from oklch(52.6% 0.115 44.6deg) l c calc(h + 90)) is oklch(0.526 0.115 134.6).

No magic scaling

when percentages are resolved to numbers, there is no "magic scaling" to account for the changed position. The origin's alpha is 0.6 in both.
