CSS Color 5 · 4.8 Relative LCH Colors

Relative lch()

l is a <number> that corresponds to the origin color's CIE Lightness, c [...] LCH chroma, h [...] LCH hue, in degrees. CSS Color 5 §4.8 Each pair is the relative color, then the color it should be, written out.

Darker, and the complement

lch(from peru calc(l * 0.8) c h) produces a color that is 20% darker than peru or lch(62.2532% 54.0114 63.6769), with its chroma and hue left unchanged.

The hue kept through gray

orchid: --mygray: lch(from var(--mycolor) l 0 h), then since the hue was preserved) re-saturating again: lch(from var(--mygray) l 30 h) is lch(62.753 30 326.973) which is rgb(72.710% 53.293% 71.224%).
