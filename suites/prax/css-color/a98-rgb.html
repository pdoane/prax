CSS Color 4 · 10.6 The Predefined A98 RGB Color Space: the a98-rgb keyword

color(a98-rgb …)

The a98-rgb color space accepts three numeric parameters, representing the red, green, and blue components of the color. The transfer curve is a gamma function, close to but not exactly 1/2.2. CSS Color 4 §10.6
