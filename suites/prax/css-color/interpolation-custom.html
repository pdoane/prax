CSS Color 5 · 9.1 Color Space for Interpolation

Interpolating in a custom space

The <color-interpolation-method>, as defined in [css-color-4#interpolation-space], is extended to allow use of the custom color spaces: in <dashed-ident>. --swap is the profile swapped.icc, sRGB with red and green swapped; interpolating in it is interpolating in sRGB. CSS Color 5 §9.1

A gradient in --swap

Red to blue, linear-gradient(in --swap to right, red, blue) (CSS Images 4 §3.1).
