CSS Color 4 · 3.3 Transparency: the opacity property

opacity: the element as a whole

The 'opacity' property applies the specified opacity to the element as a whole, including its contents, rather than applying it to each descendant individually. CSS Color 4 §3.3

An opaque child still occludes

an opaque child occluding part of the element's background will continue to do so even when 'opacity' is less than 1, but the element and child as a whole will show the underlying page through themselves. A blue box holds an orange child, over a dark stripe.

Overlapping glyphs

the glyphs corresponding to all characters in the element are treated as a whole; any overlapping portions do not increase the opacity. The letters overlap by letter-spacing: -22px.
