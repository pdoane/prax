CSS Color 4 · 5.1 The RGB functions: rgb() and rgba()

rgb() and rgba()

The rgb() and rgba() functions define an sRGB color by specifying the r, g and b (red, green, and blue) components directly. CSS Color 4 §5.1

Numbers to 255, percentages to 100%

For r, g and b: 0% = 0.0, 100% = 255.0. 0% represents the minimum value for that color component in the sRGB gamut, and 100% represents the maximum value. Values outside these ranges are not invalid, but are clamped to the ranges defined here at parsed-value time.

Alpha, and the legacy syntax

The final argument, the <alpha-value>, specifies the alpha of the color. If omitted, it defaults to 100%. For historical reasons, rgb() and rgba() also support a legacy color syntax. The stage is a checkerboard.
