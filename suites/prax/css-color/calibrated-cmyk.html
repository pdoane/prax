CSS Color 5 · 5.4 CSS and Print: Using Calibrated CMYK and Other Printed Color Spaces

Calibrated CMYK

The @color-profile at-rule is not restricted to RGB color spaces. Because the actual color resulting from a given CMYK combination is known, an on-screen visualization of the printed output (soft-proof) can be made. --fogra39 is the specification's FOGRA39 profile, Coated_Fogra39L_VIGC_300.icc. CSS Color 5 §5.4 Each pair is the color, then the color it should be, written out.

Ink percentages to a color

color(--fogra39 0% 70% 20% 0%): In this profile, this resolves to the color lab(63.673303% 51.576902 5.811058).

Outside the sRGB gamut

a bright green which is outside the sRGB gamut: color(--fogra39 90% 0% 90% 0%) corresponds to lab(56.596645% -58.995875 28.072154); on an sRGB display it is gamut mapped.
