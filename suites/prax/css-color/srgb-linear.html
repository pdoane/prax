CSS Color 4 · 10.3 The Predefined Linear-Light sRGB Color Space: the srgb-linear keyword

color(srgb-linear …)

The sRGB-linear predefined color space is the same as srgb except that the transfer function is linear-light (there is no gamma-encoding). CSS Color 4 §10.3

Linear light

these are the same color: color(srgb 0.691 0.139 0.259) and color(srgb-linear 0.435 0.017 0.055).

Out of gamut

Clipping shows color(srgb-linear 0.5 1 3), out of gamut.
