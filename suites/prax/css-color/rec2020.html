CSS Color 4 · 10.8 The Predefined ITU-R BT.2020-2 Color Space: the rec2020 keyword

color(rec2020 …)

The rec2020 [Rec.2020] color space accepts three numeric parameters, representing the red, green, and blue components of the color. Its transfer function is gamma 2.40, from [REC_BT.1886]. CSS Color 4 §10.8 The text took gamma 2.4 as csswg-drafts#12574 resolved.
