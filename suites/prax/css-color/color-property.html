CSS Color 4 · 3.2 Foreground Color: the color property

The color property

This property specifies the primary foreground color of the element. This is used as the fill color of its text content, and in addition specifies the used value that currentcolor resolves to CSS Color 4 §3.2

The fill of text

Initial: CanvasText. The page's own style sheet makes its text a dark blue-gray; each word below sets color itself.

What currentcolor resolves to

It affects the initial values of various other color properties such as 'border-color'. Each box sets color: #d68a3c (orange).
