CSS Color 4 · 10.5 The Predefined Linear-Light Display P3 Color Space: the display-p3-linear keyword

color(display-p3-linear …)

The display-p3-linear predefined color space is the same as display-p3 except that the transfer function is linear-light (there is no gamma-encoding). CSS Color 4 §10.5

Linear light

these are the same color: color(display-p3 0.591 0.123 0.264) and color(display-p3-linear 0.3081 0.014 0.0567), which is rgb(64.55% 2.065% 26.03%).
