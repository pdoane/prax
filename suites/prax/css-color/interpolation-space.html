CSS Color 4 · 13.2 Color Space for Interpolation

The color space for interpolation

Mixing or otherwise combining colors has different results depending on the interpolation color space used. CSS Color 4 §13.2 The space is given by <color-interpolation-method>, as in linear-gradient(in oklab, …) (CSS Images 4 §3.1).

Black to white

Each bar is linear-gradient(in S to right, black, white); below, each bar's middle, then the gray it should be.

Oklab by default

If the host syntax does not define what color space interpolation should take place in, it defaults to Oklab. Gradients default to Oklab, except between legacy colors (the next page).
