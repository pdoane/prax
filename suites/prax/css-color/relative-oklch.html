CSS Color 5 · 4.9 Relative OkLCh Colors

Relative oklch()

Because OkLCh is both perceptually uniform and chroma-preserving, and because the axes correspond to easily understood attributes of a color, OkLCh is a good choice for color manipulation. CSS Color 5 §4.9 Each pair is the relative color, then the color it should be, written out.

A triad, out of gamut

oklch(from lch(60% 90 320) l c calc(h - 120)): the origin is oklch(0.69012 0.25077 319.893), and the result, oklch(0.69012 0.25077 199.893), is out of sRGB gamut. Bring this into gamut by reducing OkLCh Chroma, yields oklch(0.69012 0.1173 199.893).

Gray, the same lightness

oklch(from var(--color) l 0 h) preserves the lightness, but zeroes out the chroma.
