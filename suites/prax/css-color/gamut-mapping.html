CSS Color 4 · 14.2 CSS Gamut Mapping to an RGB Destination

CSS gamut mapping

All three CSS gamut mapping algorithms aim at constant-lightness, constant-hue chroma reduction in the OkLCh color space. Implementations must use their chosen algorithm wherever CSS mandates that gamut mapping be performed. CSS Color 4 §14.2 On the stills' sRGB display, each pair is a color out of gamut, then the rgb() it maps to. Which algorithms qualify is open, csswg-drafts#14521; clipping is none of them.
