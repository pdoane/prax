CSS Color 4 · 3.3 Transparency: the opacity property, stacking

opacity and stacking

If a box has 'opacity' less than 1, it forms a stacking context for its children. CSS Color 4 §3.3

A stacking context for its children

This prevents its contents from interleaving in the z-axis with content outside it. A holds B with position: relative; z-index: 10; C, after A, has position: relative; z-index: 1 and overlaps B.

Painted as if z-index: 0

it is otherwise painted on the same layer within its parent stacking context as positioned elements with stack level 0 (as if it were a positioned element with ''z-index:0''). B, first, has position: relative; A follows it in flow, with no position, and overlaps it.
