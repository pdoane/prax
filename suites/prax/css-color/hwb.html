CSS Color 4 · 8 HWB Colors: hwb() function

hwb()

It describes colors with a starting hue, then a degree of whiteness and blackness to mix into that base hue. HWB colors resolve to sRGB. CSS Color 4 §8 Each pair is the HWB color, then the color it converts to.

Whiteness and blackness

The second argument specifies the amount of white to mix in, as a percentage from 0% (no whiteness) to 100% (full whiteness). Similarly, the third argument specifies the amount of black to mix in.

W + B of 100% or more: a gray

If the sum white+black is greater than or equal to 100%, it defines an achromatic color, i.e. a shade of gray; when converted to sRGB the R, G and B values are identical and have the value white / (white + black).
