CSS Color 4 · 6.3 The transparent keyword

transparent

The keyword transparent specifies a transparent black. It is a type of <named-color>. CSS Color 4 §6.3

Nothing drawn

Transparent black, in a gradient

A gradient from red to transparent interpolates premultiplied (§13.4), so transparent's black does not show: the red only fades. The bars are linear-gradient(to right, red, T) (CSS Images 4 §3.1).
