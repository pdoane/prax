CSS Color 4 · 15.5 Resolving other colors

currentcolor, inherited as a keyword

The currentcolor keyword computes to itself. In the 'color' property, the used value of currentcolor is the resolved inherited value. In any other property, its used value is the used value of the 'color' property on the same element. CSS Color 4 §15.5

In color, the parent's; elsewhere, inherited as the keyword

if the currentcolor value is inherited, it’s inherited as a keyword. Each stage sets color: #2c5a8f (blue) and text-emphasis: dot currentcolor, which inherits; its span sets color: #c0392b (red).

On the first line

A forestgreen block with text-shadow: 3px 3px currentcolor holds a mediumseagreen paragraph whose ::first-line is yellowgreen: The used value of the inherited property text-shadow on the first line fragment would be yellowgreen.
