CSS Color 4 · 4.2 Representing Transparency in Colors: the <alpha-value> syntax

Alpha in a color

Every color has an alpha component, indicating how transparent it is, and thus how much of the backdrop one can see through the color. CSS Color 4 §4 Each stage here is a checkerboard of white and gray 10px squares, the backdrop.

From opaque to transparent

<alpha-value> = <number> | <percentage>; Unless otherwise specified, an <alpha-value> component of a color defaults to 100% when omitted. CSS Color 4 §4.2

Clamped to [0,1]

Values outside the range [0,1] are not invalid, but are clamped to that range at parsed-value time.
