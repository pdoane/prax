CSS Color 4 · 13.5.3 increasing

Hue interpolation: increasing

Hue angles are interpolated so that, as they progress from the first color to the second, the angle is always increasing. CSS Color 4 §13.5.3 Bars are linear-gradient(in oklch increasing hue to right, A, B) (CSS Images 4 §3.1).

Brown to turquoise

From a deep brown, oklch(0.5 0.1 30), to a turquoise, oklch(0.7 0.1 190): the midpoint [...] would be at a hue angle of (30 + 190) * 0.5 = 110 degrees, giving a khaki.

Past 180 apart, still increasing

To oklch(0.7 0.1 230) instead: the midpoint of the interpolation will be (30 + 230) * 0.5 = 130 degrees, continuing in the same increasing direction, though the shorter arc now runs the other way.
