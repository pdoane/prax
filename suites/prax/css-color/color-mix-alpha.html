CSS Color 5 · 3.5 Effect of Non-Unity Alpha on color-mix

color-mix() with alpha

colors may have non-unity alpha components and thus the premultiply, interpolate, unpremultiply steps must not be omitted. CSS Color 5 §3.5

Premultiplied

color-mix(in srgb, rgb(100% 0% 0% / 0.7) 25%, rgb(0% 100% 0% / 0.2)): the mixed color is color(srgb 0.53846 0.46154 0 / 0.325); not premultiplied, it would be color(srgb 0.25 0.75 0 / 0.325). On a checkerboard.

With an alpha multiplier

The same colors at 20% and 60%, which add to 80%: so the alpha of the mixed result is actually 0.325 * 0.8 = 0.260 so the mixed color is actually color(srgb 0.53846 0.46154 0 / 0.260).
