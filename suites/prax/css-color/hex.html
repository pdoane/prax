CSS Color 4 · 5.2 The RGB Hexadecimal Notations: #RRGGBB

Hex colors

The number of hex digits given determines how to decode the hex notation into an RGB color. Each pair is the hex color, then rgb() with the same components. CSS Color 4 §5.2

Six digits and three

Six digits: The first pair of digits, interpreted as a hexadecimal number, specifies the red component of the color, where 00 represents the minimum value and ff (255 in decimal) represents the maximum. Three: a shorter variant of the 6-digit notation, each digit doubled.

Eight digits and four: alpha

The last pair of digits [...] specifies the alpha component of the color, where 00 represents a fully transparent color and ff represent a fully opaque color. The stage is a checkerboard.
