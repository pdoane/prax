CSS Color 4 · 13.5.4 decreasing

Hue interpolation: decreasing

Hue angles are interpolated so that, as they progress from the first color to the second, the angle is always decreasing. CSS Color 4 §13.5.4 Bars are linear-gradient(in oklch decreasing hue to right, A, B) (CSS Images 4 §3.1).

Brown to turquoise, downward

The same brown and turquoise: the midpoint [...] would be at a hue angle of (30 + 360 + 190) * 0.5 = 290 degrees, giving a purple.

Still decreasing

To oklch(0.7 0.1 230): the midpoint of the interpolation will be (30 + 360 + 230) * 0.5 = 310 degrees, continuing in the same decreasing direction.
