CSS Color 4 · 10.9 The Predefined CIE XYZ Color Spaces: the xyz-d50, xyz-d65, and xyz keywords

color(xyz …)

It represents the CIE XYZ [COLORIMETRY] color space, scaled such that diffuse white has a luminance (Y) of 1.0. and, if necessary, chromatically adapted to the reference white. The reference white for xyz-d50 is D50, while the reference white for xyz-d65 and xyz is D65. CSS Color 4 §10.9

The same color in each

These are exactly equivalent: #7654CD, lab(44.36% 36.05 -58.99), color(xyz-d50 0.2005 0.14089 0.4472), color(xyz-d65 0.21661 0.14602 0.59452).

Different white points

The same numbers in the two spaces are two colors, one adapted from D50.
