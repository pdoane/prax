CSS Color 5 · 4.6 Relative Lab Colors

Relative lab()

l is a <number> that corresponds to the origin color's CIE Lightness; a and b are <number>s that correspond to the origin color's CIE Lab a and b axes. CSS Color 5 §4.6 Each pair is the relative color, then the color it should be, written out.

A gray of the same lightness

Fully desaturating a color to gray, keeping the exact same lightness: orchid is lab(62.753 52.460 -34.103), and lab(from orchid l 0 0) is lab(62.753 0 0) which is rgb(59.515% 59.515% 59.515%).

Alpha

lab(from var(--mycolor) l a b / calc(alpha * 0.8)) reduces the alpha [...] by 20% of its original value. On a checkerboard.
