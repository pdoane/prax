CSS Color 4 · 3.5 Color Spaces of Untagged Colors

Untagged images and HTML colors

For compatibility, colors specified in HTML, and untagged images must be treated as being in the sRGB color space unless otherwise specified. CSS Color 4 §3.5

An untagged image is sRGB

The image 009900.png has pixels of #009900 and no profile, gamma or sRGB chunk; 009900-sRGB.png has the same pixels, tagged sRGB.

A color in an HTML attribute is sRGB
