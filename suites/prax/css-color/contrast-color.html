CSS Color 5 · 8 Dynamically specifying a text color with adequate contrast: the contrast-color() Function

contrast-color()

contrast-color() resolves to either white or black, whichever produces maximum color contrast for text when the input color is used as a solid background. Each chip has background: B; color: contrast-color(B). CSS Color 5 §8

White or black

The precise color contrast algorithm for determining whether to output a light or dark color is UA-defined at this level.
