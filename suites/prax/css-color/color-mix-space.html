CSS Color 5 · 3.1 Colorspace for mixing

color-mix(): the mixing space

If no color interpolation method is specified, assume Oklab. Otherwise, use the specified colorspace for mixing. CSS Color 5 §3.1

Oklab when none is given

these two are exactly equivalent: color-mix(in oklab, firebrick, goldenrod) and color-mix(firebrick, goldenrod); the result is oklab(0.6242 0.0879 0.1136).
