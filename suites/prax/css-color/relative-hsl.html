CSS Color 5 · 4.4 Relative HSL Colors

Relative hsl()

h is a <number> that corresponds to the origin color's HSL hue, in degrees; s and l are <number>s that correspond to the origin color's HSL saturation and lightness. CSS Color 5 §4.4 Each pair is the relative color, then the color it should be, written out.

A complementary color

This adds 180 degrees to the hue angle, giving a complementary color. lightseagreen is hsl(176.71 69.52% 41.18%).
