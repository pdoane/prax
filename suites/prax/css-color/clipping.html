CSS Color 4 · 14.1.1 Clipping

Clipping

The section is not normative. The simplest and least acceptable method is simply to clip the component values to the displayable range. This changes the proportions of the three primary colors (for an RGB display), resulting in a hue shift. CSS Color 4 §14.1.1

A hue shift

consider the color color(srgb-linear 0.5 1 3). There is six times as much blue primary as red. In OkLCh, this color has a hue angle of 265.1°. If we now clip this color to bring it into gamut for sRGB, we get color(srgb-linear 0.5 1 1). In OkLCh, this color has a hue angle of 196.1°, a substantial change of 69°.

When clipping is close enough

When colors are not too far out of gamut, clipping can give acceptable results. This is particularly true for darker (or negative) component values.
