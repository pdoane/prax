CSS Color 4 · 13.3 Interpolating with Missing Components

Interpolating with missing components

If a color with a carried forward missing component is interpolated with another color which is not missing that component, the missing component is treated as having the other color's component value. CSS Color 4 §13.3

A missing hue takes the other's

The specification's example, in OkLCh, from oklch(78.3% 0.108 326.5) to oklch(39.2% 0.4 none): the actual colors to be interpolated are oklch(78.3% 0.108 326.5) [and] oklch(39.2% 0.4 326.5). Bars are linear-gradient(in oklch to right, …) (CSS Images 4 §3.1).

A missing alpha takes the other's

If the carried forward missing component is alpha, the color must be premultiplied with this carried forward value. On a checkerboard, from oklch(0.783 0.108 326.5 / 0.5) to oklch(0.392 0.4 0 / none).
