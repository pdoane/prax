CSS Color 5 · 3.3 Calculating the Result of color-mix

color-mix(): the result

Interpolate a and b’s colors as described in [css-color-4#interpolation], with a progress percentage equal to (b’s percentage) / combined percentage), two at a time, in order. CSS Color 5 §3.3

Three colors

In this example three colors are mixed, and no percentages are given so each color contributes one-third of the final result: color-mix(in oklab, teal, olive, blue), mixed result is oklab(52.53% -0.0550 -0.0720).

One color

If items is length 1, set color to the color of that sole item, converted to the specified interpolation <color-space>.
