CSS Color 4 · 6.2 System Colors, color schemes and accent-color

System colors and the color scheme

To maintain legibility, the <system-color> keywords also respond to the element color scheme. CSS Color 4 §6.2

Light and dark

Each stage is background: Canvas with text in CanvasText and LinkText; the second has color-scheme: dark (CSS Color Adjustment 1 §2.2).

AccentColor follows accent-color

To maintain consistency with widget accent color styling, AccentColor takes its value from 'accent-color', unless Forced Colors Mode is enabled. AccentColorText takes its value from the contrasting foreground color to AccentColor.
