CSS Color 4 · 6.1 Named Colors

Named colors

CSS defines a large set of named colors, so that common colors can be written and read more easily. The names resolve to colors in sRGB. CSS Color 4 §6.1 The next four pages hold all 148.

The sixteen from the VGA palette

16 of CSS's named colors come from the VGA palette originally, and were then adopted into HTML. Each pair is the named color, then the hex color the table gives it (in the source): each pair one color.

Names that mislead

A note: the names are not even internally consistent (darkgray is lighter than gray, while lightpink is darker than pink).
