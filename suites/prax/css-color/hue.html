CSS Color 4 · 4.3 Representing Cylindrical-coordinate Hues: the <hue> syntax

Hues: angles and numbers

Hue is represented as an angle of the color circle: <hue> = <number> | <angle>. CSS Color 4 §4.3

A number is degrees

the argument can also be given as a number, which is interpreted as a number of degrees. Each swatch is hsl(H 100% 25%), a dark green, with H written another way.

Normalized to [0,360)

This number is normalized to the range [0,360).
