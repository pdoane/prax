SVG 2 · 3.6.1 Object and group opacity: the effect of the ‘opacity’ property

Object and group opacity

Conceptually, the object or group to which opacity applies is rendered into an RGBA offscreen image. The offscreen image as whole is then blended into the canvas with the specified opacity value used uniformly across the offscreen image. SVG 2 §3.6.1 Each stage is an SVG 160 by 60 on a blue band, with a red circle of radius 20 at 70, 30 and a green one at 90, 30.
