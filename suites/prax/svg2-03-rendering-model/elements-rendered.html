SVG 2 · 3.5 How elements are rendered

How elements and groups are rendered

Individual graphics elements are treated as if they are a non-isolated group, the components (fill, stroke, etc) that make up a graphic element (See Painting shapes and text) being members of that group. SVG 2 §3.5 Each stage is an SVG 160 by 60.
