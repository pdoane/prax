SVG 2 · 3.2.3 Controlling visibility: the effect of the ‘display’ and ‘visibility’ properties

display and visibility

Although they have a similar visible effect in static documents, they are conceptually distinct. SVG 2 §3.2.3 Each stage is an SVG 160 by 60.

display: none

setting display to none results in the element (and all its descendents) not becoming part of the rendering tree. The display property affects the direct processing of a given element, but it does not prevent it from being referenced by other elements.

visibility: hidden

A hidden element is, however, still part of the rendering tree. It contributes to bounding box calculations and clipping paths, and does affect text layout. Since visibility is an inherited property, however, although it has no effect on a ‘use’ element or container element itself, its inherited value can affect descendant elements.
