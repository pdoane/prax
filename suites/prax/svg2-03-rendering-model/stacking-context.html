SVG 2 · 3.4.1 Establishing a stacking context in SVG

Establishing a stacking context

A new stacking context must be established at an SVG element for its descendants if any of the following conditions are met. SVG 2 §3.4.1 A stacking context is a group, isolated for blending: a blend inside it does not reach what is behind it. Each stage is an SVG 160 by 60 with an orange band behind a g or nested svg holding a blue square at 60, 10 with mix-blend-mode: multiply.

Not a stacking context

Stacking contexts

Among the conditions: Inner ‘svg’ with overflow computed value other than visible; clip-path property computed value other than none; opacity property computed value other than 1.
