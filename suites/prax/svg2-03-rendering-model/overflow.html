SVG 2 · 3.11 The effect of the ‘overflow’ property

The overflow property

If the overflow property has a value of ‘visible’, the property has no effect (i.e., a clipping rectangle is not created). If the overflow property has the value hidden or scroll, a clip, the exact size of the SVG viewport is applied. The values on a nested svg

The table gives, for other svg: auto visible | scroll, visible visible, hidden hidden, scroll scroll. If the user agent has no scrolling mechanism, the content would not be clipped, or the value ‘scroll’ is treated as hidden, then the value auto must be treated as visible.
