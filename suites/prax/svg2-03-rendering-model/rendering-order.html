SVG 2 · 3.4 Rendering order

Rendering order

By default, elements are painted in document order: an element that appears later in the markup is painted on top of an element that appears earlier. SVG 2 §3.4 Each stage is an SVG 160 by 60: a blue square at 20, 10, an orange one at 50, 10 and a green one at 80, 10, each 60 by 40.

In tree order, groups and all

Elements in a given stacking context must be stacked according to document order. The back to front order of a stacking context is its descendants, in tree order.
