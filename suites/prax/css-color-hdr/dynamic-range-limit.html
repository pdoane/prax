CSS Color HDR 1 · 3.1 The dynamic-range-limit property

dynamic-range-limit

The highest luminance color that is displayed is the same as HDR Reference White, i.e. the CSS color white. CSS Color HDR 1 §3.1

The three values, on an HDR image

Each image is four gray steps encoded in PQ, at 100, 500, 1,000 and 5,000 cd/m², about 0.5, 2.5, 4.9 and 25 times reference white, under a white bar.
