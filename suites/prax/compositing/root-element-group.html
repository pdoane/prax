Compositing and Blending 2 · 8.3 The Root Element Group

The root element group

The background of the root element (if specified) is painted into the root element group, and any filter, clip-path, mask and and opacity is then applied, before compositing into the root group, if present. Compositing and Blending 2 §8.3 Each frame, 200 by 100, holds a document whose root element has a lime background and an empty body. Under a frame's document the root group is transparent in each browser, so the stage shows where the root's background does not cover it.

The root's effects reach its background
