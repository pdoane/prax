Stacking contexts are isolated groups

Everything in CSS that creates a stacking context must be considered an ‘isolated’ group. An element that has blending applied, must blend with all the underlying content of the stacking context that that element belongs to. Compositing and Blending 2 §3.2 Each stage has a lime band 180 by 40 under a red square with mix-blend-mode: multiply: red times lime is black; in an isolated group, the red blends with the group's transparent start and stays red.
