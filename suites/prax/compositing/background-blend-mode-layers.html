Compositing and Blending 2 · 3.4.3 The background-blend-mode property

background-blend-mode: one value per layer

The background-blend-mode list must be applied in the same order as background-image. This means that the first element in the list will apply to the layer that is on top. If a property doesn't have enough comma-separated values to match the number of layers, the UA must calculate its used value by repeating the list of values until there are enough. If the background shorthand is used, the background-blend-mode property for that element must be reset to its initial value. Compositing and Blending 2 §3.4.3

Layers, top first, and the shorthand
