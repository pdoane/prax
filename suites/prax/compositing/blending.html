Blending: mixing, then weighting by the backdrop's alpha

The result of the mixing function is modulated by the backdrop alpha. A fully opaque backdrop allows the mixing function to be fully realized. A transparent backdrop will cause the final result to be a weighted average between the source color and mixed color with the weight controlled by the backdrop alpha. Compositing and Blending 2 §10

Cr = (1 - αb) x Cs + αb x B(Cb, Cs)
