Compositing and Blending 2 · 3.3 Behavior specific to SVG

SVG groups, isolated or not

By default, every element must create a non-isolated group. However, certain operations in SVG will create isolated groups. Compositing and Blending 2 §3.3 Each SVG is a lime rectangle 80 by 40, then a g holding a red 40px square with mix-blend-mode: multiply: black where it blends with the lime, red in an isolated group.

Not isolated, then isolated

If one of the following features is used, the group must become isolated: opacity, filters, 3D transforms, blending, masking.
