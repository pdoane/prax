Filter Effects 1 · 9.20 Filter primitive feTile

feTile

This filter primitive fills a target rectangle with a repeated, tiled pattern of an input image. The target rectangle is as large as the filter primitive subregion established by the feTile element. Filter Effects 1 §9.20 Each stage is an SVG 200 by 80 whose filter region is the whole stage. The tile is a merge with the subregion 20 by 20 at (10, 10): orange, with a blue square 10 by 10 at its top left.

Tiles from the input's subregion

The top/left corner of each given tile is at location (x + i*width, y + j*height), where (x,y) represents the top/left of the input image's filter primitive subregion, width and height represent the width and height of the input image's filter primitive subregion, and i and j can be any integer value.
