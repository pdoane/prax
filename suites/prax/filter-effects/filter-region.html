Filter Effects 1 · 8 Filter Region

The filter region

The bounds of this rectangle act as a hard clipping region for each filter primitive included with a given filter element. Filter Effects 1 §8 Each box is 100 by 40, 50px in from the stage's edge, with an SVG filter.

The default region, and a wider one

The initial value for x and y is -10%. The initial value for width and height is 120%. The filter is an feGaussianBlur of stdDeviation="10".

filterUnits

The initial value for filterUnits is objectBoundingBox. Each filter floods its region orange.
