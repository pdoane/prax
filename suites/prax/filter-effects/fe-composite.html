feComposite: Porter-Duff and arithmetic

All of the operator types except arithmetic match the corresponding operation as described in [COMPOSITING-1] with in representing the source and in2 representing the destination. Filter Effects 1 §9.8 In each canvas, 160 by 30, in is an orange flood from x 0 to 100 and in2 a blue one from x 60 to 160, in sRGB.

The Porter-Duff operators

arithmetic

result = k1*i1*i2 + k2*i1 + k3*i2 + k4, for each channel of the premultiplied pixels, with the result clamped between [0..1].
