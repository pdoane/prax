Filter Effects 1 · 5 Graphic filters: the filter property

filter: a group, a stacking context, a containing block

A computed value of other than none results in the creation of a stacking context the same way that CSS opacity does. All the elements descendants are rendered together as a group with the filter effect applied to the group as a whole. Filter Effects 1 §5

A group filtered as a whole, and a stacking context

A containing block

A value other than none for the filter property results in the creation of a containing block for absolute and fixed positioned descendants.
