Filter Effects 1 · 9.5 Filter primitive feBlend

feBlend: blending two inputs

One of the blend modes defined by “Compositing and Blending Level 1” with the input in representing the source Cs and the second input in2 representing the backdrop Cb. Filter Effects 1 §9.5 In each canvas, 160 by 40, the source is an orange rectangle from x 0 to 100 and the backdrop a blue flood from x 60 to 160. Each filter computes in sRGB. The bar below a canvas is the color the mode gives where they overlap.

The modes, with Source Over

Otherwise, implementations must combine the blend mode specified by mode with the Source Over composite operator. Both inputs are opaque where they overlap, so the overlap is the blend itself.

no-composite

If the no-composite attribute is present, the specified blend mode must not apply alpha compositing. The source here is half opaque. Without compositing the result keeps the source's alpha, and nothing of the backdrop shows where the source is absent.
