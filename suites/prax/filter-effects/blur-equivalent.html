Filter Effects 1 · 13.1.9 blur

blur() as feGaussianBlur

The function is <feGaussianBlur stdDeviation="[radius radius]" edgeMode="[edge mode]">, Where edge mode computes to none for the filter property. Filter Effects 1 §13.1.9

Two radii

In each stage, at the left, a box 60 by 40 of four colored quarters with the filter function, at the right the same box with filter: url() to the equivalent. Each equivalent's filter region runs 40px or more past the box on every side, as the shorthand's must cover what it draws (§13.2); the default region of an SVG filter, 10% past the box, would clip it.
