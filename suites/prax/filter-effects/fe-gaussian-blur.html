Filter Effects 1 · 9.14 Filter primitive feGaussianBlur

feGaussianBlur

This filter primitive performs a Gaussian blur on the input image. Filter Effects 1 §9.14 In the first card each stage is an SVG 100 by 60 with an orange square 20 by 20 at (40, 20), outlined dashed, and a filter region three times its size. A blur kernel is an approximation, so the browsers' soft edges differ slightly.

One or two deviations

If one number is provided, then that value is used for both X and Y. If stdDeviation is 0 in only one of X or Y, then the effect is that the blur is only applied in the direction that has a non-zero value. A negative value or a value of zero disables the effect of the given filter primitive (i.e., the result is the filter input image).

Past the input's edges: edgeMode

Each rectangle fills its own filter region, 120 by 40 at (20, 10), so the blur reaches past the edges of its input. The initial value for edgeMode is none.
