Filter Effects 1 · 9.4 Filter primitive subregion

The filter primitive subregion

x, y, width and height default to the union (i.e., tightest fitting bounding box) of the subregions defined for all referenced nodes. Filter Effects 1 §9.4 Each canvas is 160 by 40.

The default subregion

The first two filter an orange flood at x 20 to 40 wide, moved 20; the last takes the input, an orange rectangle at x 0 to 40. For a standard input the default subregion is 0%, 0%, 100%, 100% of the filter region.

Hard clips

The filter primitive subregion acts as a hard clip clipping rectangle on the filter primitive result. The filter region acts as a hard clip clipping rectangle on the filter primitive's input image(s).
