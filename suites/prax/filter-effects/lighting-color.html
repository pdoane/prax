Filter Effects 1 · 11.5 The lighting-color property

lighting-color

The lighting-color property defines the color of the light source for filter primitives feDiffuseLighting and feSpecularLighting. Filter Effects 1 §11.5 Each stage is an SVG 160 by 60 filled by one flat, opaque rectangle; its filter lights it in sRGB, by default with a distant light from straight in front, which a flat surface returns in full.

The light's color

A property, as well as an attribute

The lighting-color property is a presentation attribute for SVG elements.
