Filter Effects 1 · 6.1 Supported Filter Functions

blur() and drop-shadow()

Applies a Gaussian blur to the input image. The passed parameter defines the value of the standard deviation to the Gaussian function. Filter Effects 1 §6.1 Each blue box is 60 by 30, 20px in from the stage's edge.

blur()

The ink overflow rectangle for a Gaussian blur is the axis-aligned boundary of the area in which the implementation draws the blur.

drop-shadow()

A drop shadow is effectively a blurred, offset version of the input image's alpha mask drawn in a particular color, composited below the image.
