Filter Effects 2 · 2.1 Filtering and Clipping

backdrop-filter: clipped to the border box

Apply a clip to the contents of T’, using the border box of element B, including border-radius if specified. Note that the children of B are not considered for the sizing or location of this clip. Filter Effects 2 §2.1 The box, 100 by 40, has no background, and backdrop-filter: grayscale(1) unless the caption gives another. Safari's and Firefox's stills show no backdrop filter, as backdrop-filter.html says.

The blur's edges, and B's own effects

If the filter functions list includes a blur() filter, the filter will be applied with edgeMode="mirror", with the edge defined by the clipped, transformed border box of the element. If element B has any transforms, effects, or clips, apply those to T’.
