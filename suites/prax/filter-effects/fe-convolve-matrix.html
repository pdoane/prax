feConvolveMatrix: a kernel over neighboring pixels

A convolution combines pixels in the input image with neighboring pixels to produce a resulting image. Filter Effects 1 §9.9 Each canvas is 160 by 40, filtered in sRGB. A kernel works on pixels, so what it does at an edge is a pixel wide; inside a flat color, every neighbor is the same, and the result can be read off a bar.

The divisor, preserveAlpha and bias

The source is an orange rectangle, #d68a3c, from x 20 to 140. The initial value is the sum of all values in kernelMatrix; A value of false indicates that the convolution will apply to all channels, including the alpha channel.

A kernel that sums to zero, and edgeMode

if the sum is zero, then the divisor is set to 1. duplicate indicates that the input image is extended along each of its borders as necessary by duplicating the color values at the given edge; with none, the input image is extended with pixel values of zero. Here the orange fills the canvas.
