Filter Effects 1 · 9.7 Filter primitive feComponentTransfer

feComponentTransfer: a function per channel

This filter primitive performs component-wise remapping of data: R' = feFuncR( R ), G' = feFuncG( G ), B' = feFuncB( B ), A' = feFuncA( A ). Filter Effects 1 §9.7 Each canvas, 160 by 40, is an orange rectangle, #d68a3c, filtered in sRGB; the bar below it is the color the functions give.

Each channel its own function

Unpremultiplied

The calculations are performed on non-premultiplied color values.
