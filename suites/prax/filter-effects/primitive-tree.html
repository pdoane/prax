Filter Effects 1 · 9.3 Filter primitive tree

The filter primitive tree

Filter primitives with no or one filter primitive input can be linked together to a filter chain. Every filter primitive takes the result of the previous filter primitive as input. Filter Effects 1 §9.3 Each canvas, 160 by 40, holds an orange rectangle from x 0 to 40.

A chain

The primary tree

Only the primary filter primitive tree contributes to the filter process. If a filter element has no filter primitive tree then the element the filter applies to does not get rendered.
