Filter Effects 1 · 13.2 Filter region for shorthands

The filter region of the filter functions

The filter region must cover the visual content of an element including overflowing content, graphical control elements such as scrollbars, border/border-image, box-shadow, text-shadow and outline. Filter Effects 1 §13.2 Each blue box is 60 by 30, 20px in, with grayscale(1): whatever the region covers is gray.
