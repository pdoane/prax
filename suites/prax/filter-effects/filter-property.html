Filter Effects 1 · 5 Graphic filters: the filter property

filter: a list applied in order

The list of functions are applied in the order provided. Filter Effects 1 §5 Each blue box is 60 by 30.

Each function takes the one before's output

Subsequent operations take the output from the previous filter function or filter reference as the input image.

A reference to nothing, or to something not a filter

If the filter references a non-existent object or the referenced object is not a filter element, then the whole filter chain is ignored. No filter is applied to the object.
