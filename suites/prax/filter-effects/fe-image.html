Filter Effects 1 · 9.15 Filter primitive feImage

feImage

This filter primitive refers to a graphic external to this filter element, which is loaded or rendered into an RGBA raster and becomes the result of the filter primitive. Filter Effects 1 §9.15 Each stage is an SVG 200 by 64 with a light blue rectangle 120 by 40 at (40, 20), outlined dashed; its filter region is 144 by 48 at (28, 16). The image is the flag, a PNG 40 by 20.

An image resource

Rendered according to the behavior of the image element: The initial value for preserveAspectRatio is xMidYMid meet.

An element, or nothing

otherwise, the referenced resource is rendered according to the behavior of the use element. A href reference that is an empty image (zero width or zero height), that fails to download, is non-existent, or that cannot be displayed (e.g. because it is not in a supported image format) fills the filter primitive subregion with transparent black.
