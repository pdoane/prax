Filter Effects 1 · 15.1 Tainted Filter Primitives

Tainted filter primitives

The following filter primitives may have access to pixel values that potentially contain privacy-sensitive information, either from the filtered object itself or other sources such as CSS styling. These primitives must be flagged as "tainted". Filter Effects 1 §15.1 What a still can show of it is the one rule that changes what is drawn: If feDisplacementMap has a "tainted" flagged filter primitive as input and this input filter primitive is used as displacement map (referenced by in2), then feDisplacementMap must not proceed with the filter operation and acts as a pass through filter. §15.2
