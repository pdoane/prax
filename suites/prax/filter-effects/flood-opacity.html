Filter Effects 1 · 9.13.2 The flood-opacity property

flood-opacity

The flood-opacity property defines the opacity value to use across the entire filter primitive subregion. If the flood-color value includes an alpha channel, the alpha channel gets multiplied with the computed value of the flood-opacity property.
