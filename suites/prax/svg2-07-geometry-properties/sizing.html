SVG 2 · 7.8 Sizing properties: the effect of the ‘width’ and ‘height’ properties

width and height: the elements they size

The CSS width and height properties are used for sizing some SVG elements. Specifically, they are used to size ‘rect’, ‘image’, ‘foreignObject’, and the outermost ‘svg’ element. SVG 2 §7.8 Each stage is an SVG 160 by 60, in user units of 1px.

rect, image and foreignObject

All of these elements have ‘width’ and ‘height’ presentation attributes. A style sheet's width: 120px; height: 40px over width="40" height="20"; each element is at 20, 10, and a dashed outline marks 120 by 40.

The outermost svg, and a nested one

Other SVG elements, such as nested ‘svg’ elements, the ‘use’ element, and the ‘symbol’ element, also have ‘width’ and ‘height’ attributes, but do not accept them as CSS properties. A purple rect fills each svg.
