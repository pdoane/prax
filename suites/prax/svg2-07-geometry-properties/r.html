SVG 2 · 7.3 Radius: The ‘r’ property

r: the radius

The ‘r’ property describes the radius of the ‘circle’ element. SVG 2 §7.3

A property, from CSS, and animated

A style sheet's r: 30px over r="10". Its animation type is by computed value. Each stage is an SVG 160 by 70.

A percentage, of the normalized diagonal

Percentages refer to the normalized diagonal of the current SVG viewport, which must be calculated with sqrt((width)**2 + (height)**2)/sqrt(2) §8.9. Each stage is an SVG 170 by 70, whose normalized diagonal is 130; each circle is about 85, 35 with r: 20%. The dashed square is 52 across, the circle's bounds for 26.
