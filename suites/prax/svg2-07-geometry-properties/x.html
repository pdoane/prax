SVG 2 · 7.6 Horizontal coordinate: The ‘x’ property

x: the horizontal coordinate

The ‘x’ property describes the horizontal coordinate of the position of the element. SVG 2 §7.6 It applies to svg, rect, image and foreignObject. Each stage is an SVG 160 by 60, in user units of 1px.

On each element it applies to, from CSS

A style sheet's x: 80px over x="20". Each element is 40 by 40 at y 10; a dashed outline marks where x="20" would put it.

A percentage, of the viewport's width

Percentages refer to the width of the current SVG viewport.
