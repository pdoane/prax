SVG 2 · 7.5 Vertical radius: The ‘ry’ property

ry: the vertical radius

The ‘ry’ property describes the vertical radius of the ‘ellipse’ element and the vertical curve radius of the ‘rect’ element. SVG 2 §7.5 Each stage is an SVG 160 by 80, in user units of 1px.

An ellipse's, from CSS, or auto

Its percentages refer to the height of the current SVG viewport. When the computed value of ‘ry’ is auto, the used radius is equal to the absolute length used for ‘rx’, creating a circular arc. Each ellipse is about 80, 40.

A rect's, at most half its height

Regardless of how the value is calculated, the used value of ‘ry’ for a ‘rect’ is never more than 50% of the used value of height for the same shape. Each rect is 120 by 60 at 20, 10, outlined dashed.
