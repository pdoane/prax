SVG 2 · 7.4 Horizontal radius: The ‘rx’ property

rx: the horizontal radius

The ‘rx’ property describes the horizontal radius of the ‘ellipse’ element and the curve radius of the ‘rect’ element. SVG 2 §7.4 Each stage is an SVG 160 by 60, in user units of 1px.

An ellipse's, from CSS, or auto

Its percentages refer to the width of the current SVG viewport. When the computed value of ‘rx’ is auto, the used radius is equal to the absolute length used for ‘ry’, creating a circular arc. If both ‘rx’ and ‘ry’ have a computed value of auto, the used value is 0. auto is the initial value. Each ellipse is about 80, 30.

A rect's, at most half its width

Regardless of how the value is calculated, the used value of ‘rx’ for a ‘rect’ is never more than 50% of the used value of width for the same shape. Each rect is 120 by 40 at 20, 10, outlined dashed.
