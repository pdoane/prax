CSS Masking 1 · 7.5 Masking Area: the mask-clip property

mask-clip: the mask painting area

mask-clip determines the mask painting area, which determines the area that is affected by the mask. The painted content of an element must be restricted to this area. CSS Masking 1 §7.5 Each box is 80 by 50 at 20, 20 with a green 10px shadow around it. Its mask is opaque, so only the painting area decides what is drawn.
