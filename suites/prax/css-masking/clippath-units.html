CSS Masking 1 · 6.1 The clipPath element

clipPathUnits

Defines the coordinate system for the contents of the clipPath. If attribute clipPathUnits is not specified, then the effect is as if a value of userSpaceOnUse were specified. CSS Masking 1 §6.1 Each clip path is the rectangle 0, 0 to 50, 50, in user units or as 0.5 by 0.5 of the bounding box.

userSpaceOnUse: the referencing element's user space

the user coordinate system for the element referencing the clipPath element via the clip-path property. Each SVG is 160 by 80; its blue rectangle is 100 by 60 at 40, 10.

objectBoundingBox: fractions of the bounding box

The coordinate system has its origin at the top left corner of the bounding box of the element to which the clipping path applies to and the same width and height of this bounding box.
