CSS Masking 1 · 9.1 The mask element

The mask element's units and region

If at least one of the attributes x, y, width or height are specified, the given object and the rectangle defined by x, y, width and height establish a current clipping path. The rendered content of the mask must be clipped by this current clipping path. CSS Masking 1 §9.1 Each box is 140 by 60 and blue; each mask holds one white rectangle.
