CSS Masking 1 · 8.6 Mask Border Image Tiling: the mask-border-repeat property

mask-border-repeat

This property specifies how the images for the sides and the middle part of the mask border image are scaled and tiled. The first keyword applies to the horizontal sides, the second to the vertical ones. CSS Masking 1 §8.6 Each box is blue, masked by a 30 by 30 image sliced at 10: opaque 10px squares in the corners, and one dot 6px across in each edge piece. Its middle is empty, and fill uses it, so the middle is masked away.
