CSS Masking 1 · 8.2 Mask Border Image Interpretation: the mask-border-mode property

mask-border-mode: alpha or luminance

The mask-border-mode property indicates whether the <image> value for mask-border-source is treated as luminance mask or alpha mask. CSS Masking 1 §8.2 Each box is 140 by 60 and blue, with mask-border-slice: 10 fill. One image is the frame of discs, bars and a square opaque on transparency; the other draws the same shapes white on opaque black.

alpha, the initial value

luminance

A value of luminance indicates that the luminance values of the mask border image should be used as the mask values. The mask-mode and mask-type properties must have no affect on the mask border image type.
