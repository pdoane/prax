CSS Masking 1 · 7.6 Positioning Area: the mask-origin property

mask-origin: the mask positioning area

The mask-origin property is similar to the background-origin property, but it has a different set of values, and a different initial value. (a Note) CSS Masking 1 §7.6 Each box is 80 by 50 at 10, 10, masked by one 20px disc at 0 0.

The disc's corner, at each box's corner

SVG's boxes

For elements with associated CSS layout box, the values fill-box, stroke-box and view-box compute to the initial value of mask-origin. For SVG elements without associated CSS layout box, the values content-box, padding-box and border-box compute to fill-box. Each SVG rectangle is 60 by 30 at 30, 20, its orange stroke 20 wide, with mask-clip: no-clip.
