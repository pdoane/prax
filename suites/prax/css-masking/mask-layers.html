CSS Masking 1 · 7.10.2 Layering Multiple Mask Images

Layering multiple mask images

The mask of a box can have multiple layers. The number of layers is determined by the number of comma-separated values for the mask-image property. A value of none in a list of values with other <mask-reference>s still creates a layer. CSS Masking 1 §7.10.2 Each box is 140 by 60 and blue.

none is a layer, and a list's extra values are unused

mask-composite's list, repeated

If a property doesn’t have enough comma-separated values to match the number of layers, the UA must calculate its used value by repeating the list of values until there are enough. Three layers, top first: left half, right half, top half.
