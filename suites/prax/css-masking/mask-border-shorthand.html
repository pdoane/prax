CSS Masking 1 · 8.7 Mask Border Image Shorthand: the mask-border property

The mask-border shorthand

This is a shorthand property for setting mask-border-source, mask-border-slice, mask-border-width, mask-border-outset, mask-border-repeat and mask-border-mode. Omitted values are set to their initial values.
