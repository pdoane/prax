Clipping paths: what is clipped

The clipping path restricts the region to which paint can be applied, the so-called clipping region. Conceptually, any parts of the drawing that lie outside of this region are not drawn. CSS Masking 1 §5 Each box is 100 by 70 at 10, 10: an orange 10px border, light blue padding and blue content.

Everything the element draws, and its descendants

This includes any content, background, borders, text decoration, outline and visible scrolling mechanism of the element to which the clipping path is applied, and those of its descendants. Each box has clip-path: inset(0), its own border box.

Geometry stays, and ancestors clip too

The geometry of a clipped element … must remain the same as if it were not clipped. What is rendered is the cumulative intersection.
