mask-type: luminance or alpha

The mask-type property defines whether the content of the mask element is treated as as luminance mask or alpha mask. CSS Masking 1 §9.2 Each box is 140 by 60 and blue; each mask holds an opaque black rectangle over the box's left half: luminance 0, alpha 1.
