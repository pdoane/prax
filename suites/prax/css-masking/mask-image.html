mask-image: the mask layer image

This property sets the mask layer image of an element. CSS Masking 1 §7.1 Each box is 80 by 50 at 10, 10: an orange 10px border, light blue padding and blue content, masked with no-repeat.

An image, or a mask element; and a stacking context

A computed value of other than none results in the creation of a stacking context the way opacity does.

Layers that draw nothing

A value of none counts as a transparent black image layer. A reference that fails still counts as an image layer of transparent black.
