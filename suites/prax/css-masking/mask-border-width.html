CSS Masking 1 · 8.4 Masking Areas: the mask-border-width property

mask-border-width

The mask border image is drawn inside an area called the mask border image area. This is an area whose boundaries by default correspond to the border box. See the border-image-width property for the definitions of the property values. auto, the initial value, and lengths

Unlike border-image-width, whose initial value is 1, a multiple of the border width, this one is auto: the slice's own size.
