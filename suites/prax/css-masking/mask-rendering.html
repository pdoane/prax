CSS Masking 1 · 7.10 The Mask Image Rendering Model

The mask image rendering model

The application of the mask-image property with a value other than none to an element formatted with the CSS box model establishes a stacking context in the same way that CSS opacity does, and all the element's descendants are rendered together as a group with the masking applied to the group as a whole. CSS Masking 1 §7.10 The masks here are an opaque linear-gradient(black, black), or one that keeps a half.

A stacking context, and a group

No effect on geometry

The mask-image property has no effect on the geometry or hit-testing of any element's CSS boxes.
