CSS 2 · 11.2 Visibility: the 'visibility' property

The visibility property: hidden

visibility takes visible | hidden | collapse. Initial visible, inherited, and it applies to all elements. Every box is 20px tall; the guides are 10px apart.

Invisible, and still laid out

hidden: The generated box is invisible (fully transparent, nothing is drawn), but still affects layout. CSS 2 §11.2

Visible descendants

Furthermore, descendants of the element will be visible if they have 'visibility: visible'. The property is inherited, so the others are hidden too. CSS 2 §11.2
