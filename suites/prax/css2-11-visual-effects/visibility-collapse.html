CSS 2 · 11.2 Visibility: the 'visibility' property

The visibility property: collapsed rows and columns

collapse: Please consult the section on dynamic row and column effects in tables. If used on elements other than rows, row groups, columns, or column groups, 'collapse' has the same meaning as 'hidden'. CSS 2 §11.2

Rows and columns

On a row or column, the row or column is removed from display, and the space normally taken up by the row or column is made available for other content. Each cell is 50 by 20. CSS 2 §17.5.5
