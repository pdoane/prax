CSS 2 · 11.2 Visibility: the 'visibility' property

The visibility property: the dynamic example

This property may be used in conjunction with scripts to create dynamic effects. CSS 2 §11.2

The source

#container1 { position: absolute;
              top: 2in; left: 2in; width: 2in }
#container2 { position: absolute;
              top: 2in; left: 2in; width: 2in;
              visibility: hidden; }

The containers hold a photograph, a name and a residence; the buttons call show() on one and hide() on the other. Here, the containers are at 10, 10 and 180px wide, and a colored square stands in for each photograph.

One replaces the other

Pressing either form button invokes an author-defined script function that causes the corresponding box to become visible and the other to be hidden. Since these boxes have the same size and position, the effect is that one replaces the other. CSS 2 §11.2
