CSS 2 · 11.1.1 Overflow: the 'overflow' property

The overflow property: overlay scroll bars

CSS 2 places every scroll bar between the border and the padding, and shows it whenever a box is scroll. Each dashed box here is 120 by 60, with overflow: scroll.

Since CSS 2 · CSS Overflow 3 §5.2

Classic or overlay, as the user agent chooses

Scrollbars which by default are placed over the content box and do not cause scrollbar gutters to be created are called overlay scrollbars. Their appearance and size may vary based on whether and how the user is interacting with them. Whether classic scrollbars or overlay scrollbars are used, the appearance and size of the scrollbar, and whether scrollbars appear on the start or end edge of the box, is UA defined.
