CSS 2 · 11.1.1 Overflow: the 'overflow' property

The overflow property: room for scroll bars

A scroll bar takes its room from inside the box's border. Each dashed box is 120 by 60, and each caption reads a width back from the tinted child.

Between the border and the padding

In the case of a scrollbar being placed on an edge of the element's box, it should be inserted between the inner border edge and the outer padding edge. Any space taken up by the scrollbars should be taken out of (subtracted from the dimensions of) the containing block formed by the element with the scrollbars. CSS 2 §11.1.1

Percentages and offsets

The smaller containing block is what percentages and offsets of the box's children resolve against. CSS 2 §11.1.1, §10.1
