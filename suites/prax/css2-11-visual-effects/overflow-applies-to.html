CSS 2 · 11.1.1 Overflow: the 'overflow' property

The overflow property: which boxes clip

overflow applies to block containers and boxes that establish a formatting context. Inline boxes and the boxes of tables do not take all its values.

Inline boxes

An inline box is not a block container, and overflow does not apply to it. CSS 2 §11.1.1

Tables

On a table element ('display: table'), 'overflow' applies to the table box (i.e., not the table wrapper box) and all values other than 'hidden' are treated as 'visible'. CSS 2 §11.1.1
