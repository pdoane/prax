CSS 2 · 11.1.2 Clipping: the 'clip' property

The clip property: which boxes clip

Each blue box is 120px wide, at 40 across, and keeps its left 60px: with clip: rect(auto, 60px, auto, auto) in the first card, and with clip-path: inset(0 60px 0 0) in the second.

Absolutely positioned elements only

The 'clip' property applies only to absolutely positioned elements. A fixed box is absolutely positioned. CSS 2 §11.1.2

Since CSS 2 · CSS Masking 1 Appendix A, §5.1

clip is deprecated for clip-path

With this specification the clip property is deprecated. Authors are encouraged to use the clip-path property instead. UAs must support the clip property. CSS Masking 1 Appendix A clip-path applies to All elements. CSS Masking 1 §5.1 clip still clips as CSS 2 says; inset() in clip-path does the same with offsets in from each edge, on any box.
