CSS 2 · 11.1.1 Overflow: the 'overflow' property

The overflow property: visible and hidden

overflow takes visible | hidden | scroll | auto. Initial visible, not inherited, and it applies to block containers and boxes that establish a formatting context. Each dashed box is 120 by 40 and holds a 150px wide A and two 60px wide boxes, 60px of content.

visible and hidden

visible: content is not clipped, i.e., it may be rendered outside the block box. hidden: the content is clipped and that no scrolling user interface should be provided to view the content outside the clipping region. CSS 2 §11.1.1

Since CSS 2 · CSS Overflow 3 §3.1

hidden still scrolls by script

hidden keeps the user from scrolling, However, the content must still be scrollable programmatically, for example using the mechanisms defined in [CSSOM-VIEW]. CSS Overflow 3 §3.1 CSS 2 asked only that no scrolling interface be shown; a hidden box is now a scroll container, and the boxes below are the ones above, scrolled by script.
