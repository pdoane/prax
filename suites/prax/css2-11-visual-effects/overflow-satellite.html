CSS 2 · 11.1.1 Overflow: the 'overflow' property

The overflow property: the satellite example

Finally, consider this case where an absolutely positioned element is mixed with an overflow parent. CSS 2 §11.1.1

The scroller does not scroll the satellite

In this example, the "scroller" element will not scroll the "satellite" element, because the latter's containing block is outside the element whose overflow is being clipped and scrolled. CSS 2 §11.1.1

container { position: relative; border: solid; }
scroller { overflow: scroll; height: 5em; margin: 5em; }
satellite { position: absolute; top: 0; }
body { height: 10em; }
<container>
 <scroller>
  <satellite/>
  <body/>
 </scroller>
</container>
