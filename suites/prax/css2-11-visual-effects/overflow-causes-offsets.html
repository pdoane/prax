CSS 2 · 11.1 Overflow and clipping

Overflow: boxes moved outside

Content can also lie outside a box because it is placed there. Each dashed box is 120px wide, 40px from the stage's left, with overflow: visible, the initial value.

Absolute positioning and negative margins

A descendant box is positioned absolutely, partly outside the box. A descendant box has negative margins, causing it to be positioned partly outside the box. CSS 2 §11.1

text-indent

The 'text-indent' property causes an inline box to hang off either the left or right edge of the block box. CSS 2 §11.1
