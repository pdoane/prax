CSS 2 · 11.2 Visibility: the 'visibility' property

The visibility property: collapse elsewhere

On boxes other than table rows and columns, CSS 2 makes collapse the same as hidden. Every box is 20px tall unless its caption says otherwise.

Other elements: as hidden

A block or an inline box with collapse keeps its room. CSS 2 §11.2

Since CSS 2 · CSS Display 3 §4

Flex items collapse too

collapse Indicates that the box is collapsed, which can cause it to take up less space than otherwise in a formatting-context–specific way. See dynamic row and column effects in tables [CSS2] and collapsed flex items in flex layout [CSS-FLEXBOX-1]. CSS Display 3 §4 the collapsed flex item is removed from rendering entirely, but leaves behind a "strut" that keeps the flex line's cross-size stable. CSS Flexible Box Layout 2 §4.4 A flex item is no longer one of the other elements.
