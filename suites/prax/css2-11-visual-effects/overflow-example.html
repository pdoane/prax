CSS 2 · 11.1.1 Overflow: the 'overflow' property

The overflow property: the blockquote example

Consider the following example of a block quotation (<blockquote>) that is too big for its containing block (established by a <div>). CSS 2 §11.1.1

The source

div { width : 100px; height: 100px;
      border: thin solid red; }
blockquote { width : 125px;
      height : 100px;
      margin-top: 50px;
      margin-left: 50px;
      border: thin dashed black }
cite { display: block;
       text-align : right;
       border: none }
<div>
<blockquote>
<p>I didn't like the play,
but then I saw it under
adverse conditions - the
curtain was up.</p>
<cite>- Groucho Marx</cite>
</blockquote>
</div>

visible and hidden

The initial value of 'overflow' is 'visible', so the <blockquote> would be formatted without clipping. Setting 'overflow' to 'hidden' for the <div>, on the other hand, causes the <blockquote> to be clipped by the containing <div>. CSS 2 §11.1.1
