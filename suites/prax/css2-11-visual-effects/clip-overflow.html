CSS 2 · 11.1.2 Clipping: the 'clip' property

The clip property: clipped content and overflow

Each dashed box is 120px wide with overflow: auto, and holds a 120px wide blue box at 40, 10 in it, which ends 40px past its right edge unless it is clipped.

Clipped content does not overflow

Content that has been clipped does not cause overflow. Each caption reads the dashed box's scrollWidth, how wide the content it scrolls over is. CSS 2 §11.1.2

Since CSS 2 · CSS Overflow 3 §3.3

The border box counts, clipped or not

The scrollable overflow area includes The border boxes of all boxes for which it is the containing block. Note: The clip, clip-path, and mask-* properties [CSS-MASKING-1] do not affect the scrollable overflow area. Only effects that clip to the overflow clip edge are taken into account. CSS Overflow 3 §3.3 CSS 2's rule is reversed: a clipped box scrolls as if it were whole.
