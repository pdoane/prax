From body, unless the root has a value

User agents must instead apply the 'overflow' property from the first such child element to the viewport, if the value on the root element is 'visible'. CSS 2 §11.1.1

The viewport clips and scrolls

UAs must apply the 'overflow' property set on the root element to the viewport. The element from which the value is propagated must have a used value for 'overflow' of 'visible'. The 'visible' value when used for the viewport must be interpreted as 'auto'. CSS 2 §11.1.1
