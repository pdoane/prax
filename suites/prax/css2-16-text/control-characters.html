CSS 2 · 16.6.3 Control and combining characters' details

Control characters

Characters that are neither white space nor letters, and how they are drawn.

Control characters

Control characters other than U+0009 (tab), U+000A (line feed), U+0020 (space), and U+202x (bidi formatting characters) are treated as characters to render in the same way as any normal character. CSS 2 §16.6.3

Since CSS 2 · CSS Text 3 §4

Control characters are visible

Control characters (Unicode category Cc)—other than tabs (U+0009), line feeds (U+000A), carriage returns (U+000D) and sequences that form a segment break—must be rendered as a visible glyph which the UA must synthesize if the glyphs found in the font are not visible. As required by Unicode, unsupported Default_ignorable characters must be ignored for text rendering. CSS Text 3 §4
