CSS 2 · 16.2 Alignment: the 'text-align' property

The text-align property: justify

Every stage here has text-align: justify. The actual justification algorithm used depends on the user-agent and the language/script of the text. CSS 2 §16.2

Else aligned as for the initial value

A line that cannot be made flush, such as the last line of a block or a line ended by a forced break, is aligned as for the initial value. CSS 2 §16.2
