CSS 2 · 16.2 Alignment: the 'text-align' property

The text-align property: initial value and inheritance

text-align takes left | right | center | justify. Its initial value has no name, and it is inherited.

The initial value follows direction

Initial: a nameless value that acts as 'left' if 'direction' is 'ltr', 'right' if 'direction' is 'rtl'. Computed value: the initial value or as specified. CSS 2 §16.2

Since CSS 2 · CSS Text 3 §6.1

The initial value is start

text-align is now a shorthand of text-align-all and text-align-last, with Initial: start: Inline-level content is aligned to the start edge of the line box. CSS Text 3 §6.1

Inherited, and aligned in the line box

Note that since 'text-align' is inherited, all block-level elements inside DIV elements with a class name of 'important' will have their inline content centered. Alignment is not with respect to the viewport. CSS 2 §16.2
