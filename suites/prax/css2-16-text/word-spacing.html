CSS 2 · 16.4 Letter and word spacing: the 'letter-spacing' and 'word-spacing' properties

The word-spacing property

word-spacing takes normal | <length>. Initial normal, inherited, applies to all elements. Computed value: for 'normal' the value '0'; otherwise the absolute length. Each word is on orange, so the gaps between them are the spaces.

normal and <length>

The normal inter-word space, as defined by the current font and/or the UA. This value indicates inter-word space in addition to the default space between words. Values may be negative, but there may be implementation-specific limits. CSS 2 §16.4

Which characters

Word spacing affects each space (U+0020) and non-breaking space (U+00A0), left in the text after the white space processing rules have been applied. Fixed-width spaces (such as U+3000 and U+2000 through U+200A) are not affected. CSS 2 §16.4
