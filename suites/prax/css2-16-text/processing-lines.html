CSS 2 · 16.6.1 The 'white-space' processing model

White space processing: line starts and tabs

Then, the block container's inlines are laid out. As each line is laid out, four more steps apply. Orange spans show the white space they hold. CSS 2 §16.6.1

Steps 1 and 2: the start of a line, and tabs

1. If a space (U+0020) at the beginning of a line has 'white-space' set to 'normal', 'nowrap', or 'pre-line', it is removed. 2. All tabs (U+0009) are rendered as a horizontal shift that lines up the start edge of the next glyph with the next tab stop. Tab stops occur at points that are multiples of 8 times the width of a space (U+0020) rendered in the block's font from the block's starting content edge. CSS 2 §16.6.1
