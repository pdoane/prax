CSS 2 · 16.3.1 Underlining, overlining, striking, and blinking: the 'text-decoration' property

The text-decoration property: only text

In each figure, the underlined element has a red color.

Text, not margins, borders, padding or images

Underlines, overlines, and line-throughs are applied only to text (including white space, letter spacing, and word spacing): margins, borders, and padding are skipped. User agents must not render these text decorations on content that is not text. For example, images and inline blocks must not be underlined. CSS 2 §16.3.1

Since CSS 2 · CSS Text Decoration 3 §2

Descendants' boxes are decorated; line ends are not

Lines are drawn across all text (including white space, letter spacing, and word spacing) except spacing (white space, letter spacing, and word spacing) at the beginning and end of a line. Margins, borders, and padding of the decorating box are always skipped, however the margins, border, and padding of descendant inline boxes are not. CSS Text Decoration 3 §2
