CSS 2 · 16.1 Indentation: the 'text-indent' property

The text-indent property: percentages

text-indent takes <length> | <percentage>. Initial 0, inherited. The blue box starts each first line.

<percentage>

The indentation is a percentage of the containing block width. Percentages refer to width of containing block, and the computed value is the percentage as specified or the absolute length, so a child inherits the percentage. CSS 2 §16.1

Since CSS 2 · CSS Text 3 §8.1

A percentage of the block's own width

Percentages now refers to block container’s own inline-axis inner size: Gives the amount of the indent as a percentage of the block container’s own logical width. CSS Text 3 §8.1 The containing block no longer matters.
