CSS 2 · 16.2 Alignment: the 'text-align' property

The text-align property: block containers and long lines

text-align places a line's content in its line box. Each blue box is 30px wide, and the guides are 10px apart.

Only on block containers

text-align Applies to: block containers. This property describes how inline-level content of a block container is aligned. CSS 2 §16.2

Since CSS 2 · CSS Text 3 §6.1

Too long for the line

If (after justification, if any) the inline contents of a line box are too long to fit within it, then the contents are start-aligned: any content that doesn’t fit overflows the line box’s end edge. CSS Text 3 §6.1
