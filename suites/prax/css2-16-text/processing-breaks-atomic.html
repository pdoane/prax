CSS 2 · 16.6.1 The 'white-space' processing model

White space processing: breaks beside inline blocks

CSS 2.2 does not fully define where line breaking opportunities occur. CSS 2 §16.6.1 Each stage here is 100px wide and holds two 60px inline-blocks, which do not fit on one line together.

Since CSS 2 · CSS Text 3 §5.5

Before and after every atomic inline

For Web-compatibility there is a soft wrap opportunity before and after each replaced element or other atomic inline, even when adjacent to a character that would normally suppress them, including U+00A0 NO-BREAK SPACE. However, with the exception of U+00A0 NO-BREAK SPACE, there must be no soft wrap opportunity between atomic inlines and adjacent characters belonging to the Unicode GL, WJ, or ZWJ line breaking classes.
