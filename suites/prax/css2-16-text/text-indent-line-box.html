CSS 2 · 16.1 Indentation: the 'text-indent' property

The text-indent property: in the line box

In each figure the blue box is the first box on the first line, and the guides are 10px apart.

From the line box's edge

The box is indented with respect to the left (or right, for right-to-left layout) edge of the line box. CSS 2 §16.1 A line beside a float is shortened, so its edge is past the float.

Since CSS 2 · CSS Text 3 §8.1

A margin at the line's start

The indent is treated as a margin applied to the start edge of the line box. CSS Text 3 §8.1 So the line is aligned in the room the indent leaves.
