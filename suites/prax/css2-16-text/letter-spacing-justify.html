CSS 2 · 16.4 Letter and word spacing: the 'letter-spacing' and 'word-spacing' properties

The letter-spacing property: justification and ligatures

letter-spacing takes normal | <length>. Initial normal, inherited, all elements.

Justification and ligatures

With normal, This value allows the user agent to alter the space between characters in order to justify text. With a length, User agents may not further increase or decrease the inter-character space in order to justify text. When the resultant space between two characters is not the same as the default space, user agents should not use ligatures. CSS 2 §16.4

Since CSS 2 · CSS Text 3 §7.2

Justification may add to any letter-spacing

Depending on the justification rules in effect, user agents may further increase or decrease the space between typographic character units in order to justify text. CSS Text 3 §7.2 Space distributed by justification is in addition to the spacing defined by the letter-spacing or word-spacing properties. CSS Text 3 §6.4.1
