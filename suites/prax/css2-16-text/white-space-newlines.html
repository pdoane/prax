CSS 2 · 16.6 White space: the 'white-space' property

The white-space property: newlines

white-space takes normal | pre | nowrap | pre-wrap | pre-line. Initial normal, inherited.

Newlines

The CSS 'white-space' processing model assumes all newlines have been normalized to line feeds. If no newline rules are specified for the document language, each carriage return (U+000D) and CRLF sequence (U+000D U+000A) in the document text is treated as single line feed character. UAs must recognize line feeds (U+000A) as newline characters. CSS 2 §16.6

Since CSS 2 · CSS Text 3 §4

A carriage return is a space

Carriage returns (U+000D) are treated identically to spaces (U+0020) in all respects. For HTML documents, carriage returns present in the source code are converted to line feeds at the parsing stage; However, the character is preserved—and the above rule observable—when encoded using an escape sequence (&#x0d;). CSS Text 3 §4 A carriage return that reaches CSS no longer breaks a line.
