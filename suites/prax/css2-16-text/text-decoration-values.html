CSS 2 · 16.3.1 Underlining, overlining, striking, and blinking: the 'text-decoration' property

The text-decoration property: values

text-decoration takes none | [ underline || overline || line-through || blink ]. Initial none, not inherited (but see the next pages), applies to all elements.

The values

Produces no text decoration. Each line of text is underlined. Each line of text has a line above it. Each line of text has a line through the middle. Text blinks (alternates between visible and invisible). Conforming user agents may simply not blink the text. CSS 2 §16.3.1

Since CSS 2 · CSS Text Decoration 3 §2.1

blink is deprecated

The keywords are now values of text-decoration-line, which text-decoration sets as a shorthand. Of blink: Conforming user agents may simply not blink the text. This value is deprecated in favor of Animations [CSS-ANIMATIONS-1]. CSS Text Decoration 3 §2.1 It still may blink; authors are to use an animation instead.
