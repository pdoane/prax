CSS 2 · 16.6.1 The 'white-space' processing model

White space processing: line breaking opportunities

Each stage here is 100px wide, narrower than the two words in it, so that a line breaks wherever it may. CSS 2.2 does not fully define where line breaking opportunities occur. CSS 2 §16.6.1

Opportunities come from the text before collapsing

Inlines are laid out, taking bidi reordering into account, and wrapping as specified by the 'white-space' property. When wrapping, line breaking opportunities are determined based on the text prior to the white space collapsing steps above. CSS 2 §16.6.1

Floats and absolutely positioned boxes

Floated and absolutely-positioned elements do not introduce a line breaking opportunity. CSS 2 §16.6.1
