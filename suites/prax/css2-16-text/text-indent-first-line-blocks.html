CSS 2 · 16.1 Indentation: the 'text-indent' property

The text-indent property: a block inside an inline

Every stage here has text-indent: 30px, and holds a span that holds a block, dashed. The span is broken around the block, and the lines on either side go in anonymous blocks. The blue box is the first box on a line that is indented; the orange one is on a line that is not.

Only the first formatted line

'Text-indent' only affects a line if it is the first formatted line of an element. For example, the first line of an anonymous block box is only affected if it is the first child of its parent element. CSS 2 §16.1 The block inherits the indent, and indents its own first line.
