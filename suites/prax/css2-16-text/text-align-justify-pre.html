CSS 2 · 16.2 Alignment: the 'text-align' property

The text-align property: preserved white space

Every stage here has text-align: justify. The actual justification algorithm used depends on the user-agent and the language/script of the text. CSS 2 §16.2

Not with pre or pre-wrap

If an element has a computed value for 'white-space' of 'pre' or 'pre-wrap', then neither the glyphs of that element's text content nor its white space may be altered for the purpose of justification. CSS 2 §16.2
