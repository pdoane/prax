CSS 2 · 16.4 Letter and word spacing: the 'letter-spacing' and 'word-spacing' properties

The letter-spacing property

letter-spacing takes normal | <length>. Initial normal, inherited, applies to all elements. Computed value: 'normal' or absolute length. Each orange span is the same word.

normal and <length>

This property specifies spacing behavior between text characters. The spacing is the normal spacing for the current font. This value indicates inter-character space in addition to the default space between characters. Values may be negative, but there may be implementation-specific limits. CSS 2 §16.4

Since CSS 2 · CSS Text 3 §7.2

Half on each side, none at the line's ends

Letter-spacing is applied to each typographic character unit by inserting half of the additional spacing on each side; except it is not applied at the beginning or end of a line. CSS Text 3 §7.2
