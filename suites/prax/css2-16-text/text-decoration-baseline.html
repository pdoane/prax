CSS 2 · 16.3.1 Underlining, overlining, striking, and blinking: the 'text-decoration' property

The text-decoration property: one line per line

In each figure, the underlined element has a red color.

The same baseline and thickness on each line

In determining the position of and thickness of text decoration lines, user agents may consider the font sizes of and dominant baselines of descendants, but must use the same baseline and thickness on each line. CSS 2 §16.3.1

Since CSS 2 · CSS Text Decoration 3 §2.5

Not moved by a descendant's vertical-align

UAs must adjust line positions to match the shifted metrics of decorating boxes shifted with vertical-align values other than baseline [CSS2] or subscripted/superscripted via font-variant-position [CSS-FONTS-3], but must not adjust the line position or thickness in response to descendants of a decorating box that are so styled. CSS Text Decoration 3 §2.5 CSS 2 let the descendants' baselines be considered; a raised or lowered descendant may no longer move its ancestor's line (Text Decoration 4 §2.9 keeps this).
