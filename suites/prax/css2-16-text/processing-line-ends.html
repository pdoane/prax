CSS 2 · 16.6.1 The 'white-space' processing model

White space processing: line ends

Then, the block container's inlines are laid out. As each line is laid out, four more steps apply; these are the last two. Orange spans show the white space they hold. CSS 2 §16.6.1

Steps 3 and 4: the end of a line

3. If a space (U+0020) at the end of a line has 'white-space' set to 'normal', 'nowrap', or 'pre-line', it is also removed. 4. If spaces (U+0020) or tabs (U+0009) at the end of a line have 'white-space' set to 'pre-wrap', UAs may visually collapse them. For pre-wrap, a line breaking opportunity exists at the end of the sequence of spaces. CSS 2 §16.6.1

Since CSS 2 · CSS Text 3 §4.1.2

Preserved spaces at a line's end hang

If white-space is set to pre-wrap, the UA must (unconditionally) hang this sequence, unless the sequence is followed by a forced line break, in which case it must conditionally hang the sequence instead. It may also visually collapse the character advance widths of any that would otherwise overflow. CSS Text 3 §4.1.2 Hanging spaces are not counted when the line is aligned.
