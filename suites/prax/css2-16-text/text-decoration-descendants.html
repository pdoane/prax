CSS 2 · 16.3.1 Underlining, overlining, striking, and blinking: the 'text-decoration' property

The text-decoration property: descendants

In each figure, the underlined element has a red color, and the descendant in it a blue one.

The ancestor's color, and the ancestor's decoration

The color(s) required for the text decoration must be derived from the 'color' property value of the element on which 'text-decoration' is set. The color of decorations must remain the same even if descendant elements have different 'color' values. The 'text-decoration' property on descendant elements cannot have any effect on the decoration of the ancestor. CSS 2 §16.3.1

Relative positioning moves the decoration

Relatively positioning a descendant moves all text decorations affecting it along with the descendant's text; it does not affect calculation of the decoration's initial position on that line. CSS 2 §16.3.1
