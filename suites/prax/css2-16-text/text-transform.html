CSS 2 · 16.5 Capitalization: the 'text-transform' property

The text-transform property

text-transform takes capitalize | uppercase | lowercase | none. Initial none, inherited, applies to all elements. This property controls capitalization effects of an element's text. CSS 2 §16.5

The values

Puts the first character of each word in uppercase; other characters are unaffected. Puts all characters of each word in uppercase. Puts all characters of each word in lowercase. No capitalization effects. CSS 2 §16.5

Since CSS 2 · CSS Text 3 §2.1

Titlecase, full mappings, and words across elements

Puts the first typographic letter unit of each word, if lowercase, in titlecase; other characters are unaffected. The UA must use the full case mappings for Unicode characters. Out-of-flow boxes and inline box boundaries must not introduce a text-transform word boundary. CSS Text 3 §2.1
