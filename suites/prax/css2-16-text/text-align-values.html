CSS 2 · 16.2 Alignment: the 'text-align' property

The text-align property: values

text-align takes left | right | center | justify. Inherited, applies to block containers. This property describes how inline-level content of a block container is aligned. CSS 2 §16.2

left, right, center

A block of text is a stack of line boxes. In the case of 'left', 'right' and 'center', this property specifies how the inline-level boxes within each line box align with respect to the line box's left and right sides. CSS 2 §16.2

justify

In the case of 'justify', this property specifies that the inline-level boxes are to be made flush with both sides of the line box if possible, by expanding or contracting the contents of inline boxes, else aligned as for the initial value. CSS 2 §16.2
