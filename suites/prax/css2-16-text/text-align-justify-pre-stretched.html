CSS 2 · 16.2 Alignment: the 'text-align' property

The text-align property: preserved white space stretched

Every stage here has text-align: justify. CSS 2 keeps preserved white space as it is; a later specification lets it stretch.

Since CSS 2 · CSS Text 3 §6.1

Preserved white space may be stretched

If an element’s white space is not collapsible, then the UA is not required to adjust its text for the purpose of justification and may instead treat the text as having no justification opportunities. If the UA chooses to adjust the text, then it must ensure that tab stops continue to line up as required by the white space processing rules. CSS Text 3 §6.1
