CSS 2 · 16.6.3 Control and combining characters' details

Combining characters

Characters that combine with the one before them into a single glyph.

Combining characters

Combining characters should be treated as part of the character with which they are supposed to combine. For example, :first-letter styles the entire glyph if you have content like "o<span>&#x308;</span>"; it does not just match the base character. CSS 2 §16.6.3
