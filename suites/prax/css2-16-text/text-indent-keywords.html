CSS 2 · 16.1 Indentation: the 'text-indent' property

The text-indent property: each-line, hanging and intrinsic sizes

CSS 2 indents only the first formatted line, by a length or a percentage. Each box is 30px wide, and the guides are 10px apart.

Since CSS 2 · CSS Text 3 §8.1

each-line and hanging

text-indent takes [ <length-percentage> ] && hanging? && each-line?. each-line: Indentation affects the first line of each block container and each line after a forced line break (but not lines after a soft wrap break). hanging: Inverts which lines are affected. CSS Text 3 §8.1 Each stage is 100px wide.

Since CSS 2 · CSS Text 3 §8.1

Intrinsic sizes

The indent is part of the first line's width, so it counts in the size of a shrink-to-fit box. But Percentages must be treated as '0' for the purpose of calculating intrinsic size contributions, but are always resolved normally when performing layout. CSS Text 3 §8.1 Each dashed box is an inline-block that holds one box.
