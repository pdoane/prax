CSS 2 · 16.1 Indentation: the 'text-indent' property

The text-indent property: lengths

text-indent takes <length> | <percentage>. Initial 0, inherited, applies to block containers. In each figure the blue box is the first box on the first line.

<length>

This property specifies the indentation of the first line of text in a block container. More precisely, it specifies the indentation of the first box that flows into the block's first line box. The indentation is a fixed length. User agents must render this indentation as blank space. CSS 2 §16.1

Negative, and wider than the block

The value of 'text-indent' may be negative, but there may be implementation-specific limits. If the value of 'text-indent' is either negative or exceeds the width of the block, that first box, described above, can overflow the block. The value of 'overflow' will affect whether such text that overflows the block is visible. CSS 2 §16.1
