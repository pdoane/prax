CSS 2 · 16.1 Indentation: the 'text-indent' property

The text-indent property: the first formatted line

Every stage here has text-indent: 30px. The blue box is the first box on a line that is indented; the orange one is on a line that is not.

Only the element's first formatted line

'Text-indent' only affects a line if it is the first formatted line of an element. For example, the first line of an anonymous block box is only affected if it is the first child of its parent element. CSS 2 §16.1

Inherited into inline blocks

Since the 'text-indent' property inherits, when specified on a block element, it will affect descendant inline-block elements. For this reason, it is often wise to specify 'text-indent: 0' on elements that are specified 'display:inline-block'. CSS 2 §16.1
