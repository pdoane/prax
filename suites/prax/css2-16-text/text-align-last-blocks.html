The text-align property: the last line before a block

Each blue box is 30px wide, and the guides are 10px apart.

Not stretched

Inline content is made flush with both sides of the line box if possible, by expanding or contracting the contents of inline boxes, else aligned as for the initial value. CSS 2 §16.2 As the last line of a block is not stretched, nor is the last line of the anonymous block before a block inside an inline.

The last line before a block

text-align-last describes how the last line of a block or a line right before a forced line break is aligned. CSS Text 3 §6.3 A block inside an inline ends the anonymous block before it, so the line before it is a last line.
