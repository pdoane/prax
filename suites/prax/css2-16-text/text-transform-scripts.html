CSS 2 · 16.5 Capitalization: the 'text-transform' property

The text-transform property: scripts and languages

text-transform takes capitalize | uppercase | lowercase | none. Initial none, inherited, applies to all elements. This property controls capitalization effects of an element's text. CSS 2 §16.5

Only bicameral scripts, by language

The actual transformation in each case is written language dependent. Only characters belonging to "bicameral scripts" are affected. CSS 2 §16.5
