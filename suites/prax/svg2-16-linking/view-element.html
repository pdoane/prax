SVG 2 · 16.3.3 Predefined views: the ‘view’ element

The view element

If the SVG fragment identifier addresses a ‘view’ element within an SVG document (e.g., MyDrawing.svg#MyView) then the root ‘svg’ element is displayed in the SVG viewport. Any view specification attributes included on the given ‘view’ element override the corresponding view specification attributes on the root ‘svg’ element.
