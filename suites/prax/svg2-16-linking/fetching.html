SVG 2 · 16.1.7.2 Fetching the document

Fetching the document

If the document containing the reference is being processed in secure static mode or secure animated mode, external file references are disallowed. Unless the reference is a data URL, the user agent must treat the reference as if there was a network error, making this an invalid reference. SVG 2 §16.1.7.2 Each stage is 160 by 60.

A document in an img: external files disallowed

An SVG document drawn as an image is processed in secure animated mode §2.3. The document has two image elements, outlined: the flag, another file, at 30, 20, and a blue data URL at 90, 20.

Animation elements: the same document only

If the URL reference is from the href attribute on SVG animation elements, only same-document URL references are allowed. A URL referring to a different document is invalid and the document must not be fetched. A set that would turn a square orange, by href.
