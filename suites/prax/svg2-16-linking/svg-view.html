SVG 2 · 16.3.2 SVG fragment identifiers definitions

svgView(): viewBox, preserveAspectRatio, transform

Parameters of the svgView specification override the parameters defined on the root ‘svg’ element of the referenced document. Unspecified parameters of the svgView specification don't reset the values defined on the root ‘svg’ element of the referenced document.
