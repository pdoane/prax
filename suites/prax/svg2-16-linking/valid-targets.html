SVG 2 · 16.1.7.5 Valid URL targets

Valid URL targets

In all other cases, if the resolved target element type (or document type) is not allowed for the URL reference, it is an invalid reference. SVG 2 §16.1.7.5 Each stage is an SVG 160 by 60.

Each reference, its own targets

the ‘textPath’ element must reference an element type that implements the SVGGeometryElement interface; the ‘use’ element must reference an SVG-namespaced element; the ‘marker’, ‘marker-start’, ‘marker-mid’ and ‘marker-end’ properties must reference a ‘marker’ element.
