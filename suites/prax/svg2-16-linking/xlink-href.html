SVG 2 · 16.1.6 Deprecated XLink URL reference attributes

The deprecated xlink:href

For backwards compatibility, elements with an ‘href’ attribute also recognize an ‘href’ attribute in the XLink namespace. When the ‘href’ attribute is present in both the XLink namespace and without a namespace, the value of the attribute without a namespace shall be used.
