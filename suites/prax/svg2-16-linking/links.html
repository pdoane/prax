SVG 2 · 16.2 Links out of SVG content: the ‘a’ element

The a element

An ‘a’ element forms a link if it has a ‘href’ or ‘xlink:href’ attribute; without these attributes the ‘a’ element is an inactive placeholder for a link. SVG 2 §16.2 A style sheet fills the rects of a link, a:link, blue, and dark blue under the pointer; other rects orange.

Links, placeholders, and nested links

if an ‘a’ element is a descendent of another hyperlink element (whether in the SVG namespace or another namespace), user agents must ignore its href attribute and treat it as inactive. The invalid ‘a’ element must still be rendered as a generic container element. Three a elements, each around a rect 70 by 40: with href, without, and nested in an HTML link.

A hit region for each rendered element

a linked hit region is defined for each separate rendered element contained within the ‘a’ element, rather than for the bounding box of the ‘a’ element itself. One link around two rects, 60 by 40 at 30, 10 and 210, 10; dashed, the link's bounding box.
