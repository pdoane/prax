SVG 2 · 11.2.1 Attributes

textLength

The user agent is required to achieve correct start and end positions for the text strings. SVG 2 §11.2.1 The text is PR Noto Sans Mono, 10 a letter, at x="20"; red ticks mark the length to fill.

Spread and squeezed

spacing: Indicates that only the advance values are adjusted. The glyphs themselves are not stretched or compressed. It is the initial value of lengthAdjust.

Where it does not apply

The ‘textLength’ attribute is only applied when the wrapping area is not defined by the inline-size property. It is also not applied for any ‘text’ or ‘tspan’ element that has forced line breaks (due to a white-space value of pre or pre-line).
