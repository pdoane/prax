SVG 2 · 11.8.2 Attributes

textPath: whose coordinates

The path data coordinates within the referenced ‘path’ element or basic shape element are assumed to be in the same coordinate system as the current ‘text’ element, not in the coordinate system where the ‘path’ element is defined. SVG 2 §11.8.2 "abcdefgh" is PR Noto Sans Mono, 10 a letter; the path it is to follow is dashed in red.

The text's coordinates

The path's own transform

The ‘transform’ attribute on the referenced ‘path’ element or basic shape element represents a supplemental transformation relative to the current user coordinate system for the current ‘text’ element; it scales the path (equivalent to multiplying every coordinate by 2 for simple linear paths), but does not scale the text placed along the path.
