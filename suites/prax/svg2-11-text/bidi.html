SVG 2 · 11.1.3 Glyph metrics and layout

Bidirectional text

The user agent processes the characters which are provided in logical order (i.e., the order the characters appear in the original document). After processing the Unicode bidirectional algorithm and properties direction and unicode-bidi on each of the independent text blocks, the user agent will have a potentially re-ordered list of characters which are now in left-to-right rendering order. SVG 2 §11.1.3 Each stage is an SVG 160 by 60, the baseline at y 35 dashed in red. The Latin text is PR Noto Sans Mono at calc(50px / 3), each letter 10 wide.
