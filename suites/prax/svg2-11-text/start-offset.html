SVG 2 · 11.8.2 Attributes

startOffset

An offset from the start of the path for the initial current text position, calculated using the user agent's distance along the path algorithm. SVG 2 §11.8.2 Each stage is an SVG 160 by 60 holding "abcdef" in PR Noto Sans Mono at calc(50px / 3), 10 a letter, on a path from 20, 40 to 140, 40, 120 long, dashed in red with its ends marked.

A length, and a percentage

If a percentage is given, then the ‘startOffset’ represents a percentage distance along the entire path.

Off the path

Negative values and values larger than the path length (e.g. 150%) are allowed. Any typographic characters with mid-points that are not on the path are not rendered.
