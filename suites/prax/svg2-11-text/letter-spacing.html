SVG 2 · 11.10.2.8 The ‘letter-spacing’ property

letter-spacing in SVG text

The property is CSS Text's; SVG 1.1 allowed percentage values in the letter-spacing property. Percentage values based on the SVG viewport are not seen as useful, so this was removed in SVG 2. This brings the definition of 'letter-spacing' in line with CSS.
