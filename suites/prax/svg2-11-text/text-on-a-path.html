SVG 2 · 11.8 Text on a path

Text on a path

SVG can place text along a path defined either by a ‘path’ element or the path equivalent of a basic shape. SVG 2 §11.8 Each stage is an SVG 160 by 80 holding "abcdefghij…" in PR Noto Sans Mono at calc(50px / 3), each letter 10 along the path, which is dashed in red.

A path, and a path's data

Basic shapes

The ability to place text along a basic shape is new in SVG 2. A shape's equivalent path starts at the top of a rect, at x + rx, and at the right of a circle, going clockwise.
