SVG 2 · 11.10.2.7 The ‘baseline-shift’ property

baseline-shift

The dominant baseline can be temporarily shifted (as needed for superscripts or subscripts) by using either the shorthand vertical-align property (preferred) or the longhand baseline-shift property. SVG 2 §11.1.3 The property is defined in CSS Inline Layout, SVG 2 §11.10.2.7, where a percentage raises the text by the specified percentage of the line-height CSS Inline Layout 3 §4.2.3. Each stage is an SVG 160 by 80 holding "HH" in 30px PR Baseline Diagnostic Zero, whose H stands on its baseline, at x="20" y="45", the y dashed in red; the second H, orange, is a tspan with the caption's shift.
