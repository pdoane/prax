SVG 2 · 11.8.3 Text on a path layout rules

Off the end, and vertical, on a path

Conceptually, for text on a path the target path is stretched out into either a horizontal or vertical straight line segment. SVG 2 §11.8.3 Paths are dashed in red.

Off the end, and vertical text

Glyphs whose midpoint-on-the-path are off the path are not rendered. For vertical text layout flows, the default orientation for a given glyph is along the vector that starts at the intersection point on the path to which the glyph is attached and which points in the direction 180 degrees from the angle of the curve at the intersection point.
