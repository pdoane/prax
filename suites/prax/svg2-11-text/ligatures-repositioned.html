SVG 2 · 11.1.2 Fonts and glyphs

Ligatures kept when repositioned

For this reason SVG requires support for downloadable fonts as defined in the Font Resources section of the CSS Fonts Module. In particular, support for the Web Open Font Format [WOFF] is required. SVG 2 §11.1.2 Each stage is an SVG 160 by 60, the baseline at y 45 dashed in red. The ligature figures set "flo" in 56px PR Literata, whose "fl" is one ligature, the f's hook running into the l's top.

Repositioning keeps ligatures

SVG attributes such as ‘dx’, ‘textLength’, and ‘spacing’ (in ‘textPath’) that may reposition typographic characters do not break discretionary ligatures.
