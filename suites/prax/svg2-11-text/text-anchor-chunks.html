SVG 2 · 11.10.1.1 Text alignment, the ‘text-anchor’ property

text-anchor and text chunks

The text-anchor property is applied to each individual text chunk within a given ‘text’ element. Each text chunk has an initial current text position. Each text chunk also has a final current text position which is the current text position after placing the last glyph in the text chunk. The positions are determined before applying the text-anchor property. SVG 2 §11.10.1.1 Anchors are solid red, baselines dashed.
