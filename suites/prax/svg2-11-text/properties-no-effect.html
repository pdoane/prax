SVG 2 · 11.10 Properties and pseudo-elements

Properties without effect on text

A number of CSS properties must not have any effect on SVG text elements. SVG 2 §11.10 Each stage is an SVG 160 by 60 holding "abcdef" in PR Noto Sans Mono at calc(50px / 3), 10 a letter, at x="20" y="35", the baseline dashed in red; "cd" is a tspan where a figure needs one.

Borders and content

Border properties (such as border-top-style). Boxes generated by the CSS layout process must not be sized as if they had any borders. The content property, whose used value on SVG text elements is none.

Properties for wrapped text only

The text-align property when text is pre-formatted, whose used value on such SVG text elements is start. Of the Properties that apply only to auto-wrapped text, the first is text-indent.
