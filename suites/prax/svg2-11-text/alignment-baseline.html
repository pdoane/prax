SVG 2 · 11.10.2.6 The ‘alignment-baseline’ property

alignment-baseline

SVG 2 introduces some changes to the definition of this property. In particular: the values 'auto', 'before-edge', and 'after-edge' have been removed. For backwards compatibility, 'text-before-edge' should be mapped to 'text-top' and 'text-after-edge' should be mapped to 'text-bottom'. SVG 2 §11.10.2.6 In SVG text, these values instead specify the baseline that is aligned to the SVG current text position.
