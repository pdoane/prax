SVG 2 · 11.6 Pre-formatted text

Pre-formatted text

In this layout method, no automatic line breaking or word wrapping is done. Nominally, the text is rendered as a single line inside a rectangular content area of infinite width and height. Multiple lines of text can be obtained by precomputing line breaks. SVG 2 §11.6 Each stage is an SVG 160 by 80. The text is PR Noto Sans Mono at calc(50px / 3), each letter 10 wide, its baselines dashed in red.

No wrapping

Lines broken in advance

Use a single ‘text’ element with one or more ‘tspan’ child elements with appropriate values for attributes ‘x’, ‘y’, ‘dx’ and ‘dy’ to set new start positions for those characters which start new lines. Use multiple ‘text’ elements, one for each line of text.
