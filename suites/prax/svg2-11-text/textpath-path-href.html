SVG 2 · 11.8.1 The ‘textPath’ element

textPath: path and href

If both attributes are specified on a ‘textPath’ element, the path that is used must follow the following order of precedence: ‘path’ attribute, ‘href’ attribute, ‘xlink:href’ attribute. path before href

Errors

If the ‘path’ attribute contains valid path segments before the first error, the path is used up to the error following the rules in Error handling in path data, and the ‘href’ attribute is not used as a fallback. For href: If the attribute is used, and the <url> is an invalid reference (e.g., no such element exists, or the referenced element is not a ‘path’ element) or basic shape, then the ‘textPath’ element is in error and its entire contents shall not be rendered by the user agent.
