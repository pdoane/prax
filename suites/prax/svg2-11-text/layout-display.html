SVG 2 · 11.5 Text layout – Algorithm

A block of inline boxes

The ‘text’ element is treated as a block element and its descendant ‘tspan’, ‘textPath’ and ‘a’ elements are treated as inline elements. SVG 2 §11.5 Each stage is an SVG 160 by 60. The text is PR Noto Sans Mono at calc(50px / 3), each letter 10 wide, at x="20" y="35", the baseline dashed in red.

Used values of display

If the computed value of the display property on a correctly parented text content child element or ‘a’ element, is anything other than none, then its used value must be inline. The used value of the display property on an element that is a descendant of a text content block element and is not a correctly parented text content child element or ‘a’ element must be none.

Box properties have their initial values

The used value of each of the following properties on a text content element (and its pseudo-elements, if any) and on an ‘a’ element within a text content block element must be the property's initial values: ‘border-style’, ‘float’, ‘margin’, ‘padding’, ‘position’ and ‘text-align’.
