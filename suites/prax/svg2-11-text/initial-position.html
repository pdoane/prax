SVG 2 · 11.1.3 Glyph metrics and layout

The current text position

The initial current text position is established by the ‘x’ and ‘y’ attributes on the ‘text’ element or first rendered ‘tspan’ element for pre-formatted text. SVG 2 §11.1.3 Each stage is an SVG 160 wide. The text is PR Noto Sans Mono at calc(50px / 3), each letter 10 wide, with the baseline dashed in red.

Where the first glyph goes

If no ‘x’ (‘y’) attribute establishes the initial current text position, then its X (Y) coordinate is 0 in the current user coordinate system.

Advancing

After each glyph is placed, the current text position is advanced by the glyph's advance value (typically the width for horizontal text or height for vertical text). The inline-base direction position of the alignment point is on the start-edge of the glyph.
