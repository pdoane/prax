Multi-line text via white-space

Multi-line pre-formatted text may be created by using the white-space values pre or pre-line. In these cases, a line-feed or carriage return is preserved as a forced line break which creates a new line box. The line boxes are stacked following the rules of CSS. SVG 2 §11.6.1 Each stage is an SVG 160 by 80. The text is PR Noto Sans Mono at calc(50px / 3) on 20px lines, each letter 10 wide, at x="20" y="25", each line written on a line of its own in the source, the second indented two spaces. The expected baselines are dashed in red.
