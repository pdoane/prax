SVG 2 · 11.2.2 Notes on 'x', 'y', 'dx', 'dy' and 'rotate'

rotate through nested tspans

The example demonstrates the propagation of the ‘rotate’ attribute. SVG 2 §11.2.2 Here eight L's in 30px PR Noto Sans Mono, 18 a letter; orange L's are in a tspan.

A child's own values, and its parent's going on

The next immediate ‘tspan’ element specifies rotate values for the text, hence the current ‘rotate’ value will change to the next value in the list (but is not used) as each character is processed until the last value of 55 degrees is reached.

Children without values

The "child4" ‘tspan’ element does not specify any ‘rotate’ values and thus uses the current ‘rotate’ of its ancestor; and a parent's values left over go on to such a child.
