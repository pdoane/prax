SVG 2 · 11.9 Text rendering order

Text rendering order

A ‘text’ element is rendered in one or more chunks. Each rendered chunk, which consists of one or more glyphs, is filled and stroked as if it were a single path. SVG 2 §11.9 Each stage is an SVG 160 by 70 holding "OOO" in 48px bold PR Arimo with letter-spacing: -20px, so that the O's overlap, filled blue and stroked orange 3 wide.

One chunk, one path

This means that all glyphs in the chunk should be filled, then all glyphs stroked at once, or the reverse according to the value of the paint-order property. A recommendation.
